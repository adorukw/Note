# 硬件更换清理记录

## 背景

从 **Intel i7-13700HX + NVIDIA RTX 5060 笔记本** 换到 **AMD R7-5700X + AMD RX 9060 XT 台式机**，Arch Linux 系统迁移后残留大量旧硬件配置。

---

## 问题 1：KWin 窗口管理器 CPU 占用 1500%+

### 现象
- KWin（Wayland）占用 1500%+ CPU，GPU 负载 0%
- 系统极度卡顿，load average 高达 17

### 原因
`~/.config/environment.d/gpu.conf` 中设置了：
```
MESA_LOADER_DRIVER_OVERRIDE=iris
```
`iris` 是 **Intel GPU** 驱动，但实际使用的是 AMD RX 9060 XT，导致 Mesa 加载错误驱动，KWin 陷入渲染死循环。

### 解决
```bash
rm ~/.config/environment.d/gpu.conf
```

---

## 问题 2：NVIDIA 驱动包残留

### 残留包
```
nvidia-open, nvidia-utils, nvidia-settings, lib32-nvidia-utils
waydroid-nvidia-bin, egl-wayland, egl-wayland2, egl-gbm, egl-x11
libxnvctrl, libvdpau, linux-firmware-nvidia
```

### 依赖冲突处理
| 包 | 冲突原因 | 解决方法 |
|---|---|---|
| `lib32-nvidia-utils` | steam 依赖 `lib32-vulkan-driver` | 先装 `lib32-vulkan-radeon` 替代 |
| `linux-firmware-nvidia` | `linux-firmware` 元包依赖 | 用 `pacman -Rdd` 强制移除 |
| `linux-firmware-intel` | `linux-firmware` 元包依赖 | 用 `pacman -Rdd` 强制移除 |
| `libvdpau` | ffmpeg/mpv 依赖 | 保留（通用库，非 NVIDIA 专属） |
| `waydroid-nvidia-bin` | waydroid 依赖 | 用 `pacman -Rdd` 强制移除 |

### 清理命令
```bash
sudo pacman -S --noconfirm lib32-vulkan-radeon
sudo pacman -Rns --noconfirm nvidia-open nvidia-utils nvidia-settings lib32-nvidia-utils egl-wayland egl-wayland2 egl-gbm egl-x11 libxnvctrl
sudo pacman -Rdd --noconfirm linux-firmware-nvidia linux-firmware-intel waydroid-nvidia-bin
```

## 问题 3：NVIDIA systemd 服务残留

### 残留服务
```
nvidia-powerd.service (enabled)
nvidia-hibernate.service
nvidia-persistenced.service
nvidia-resume.service
nvidia-suspend.service
nvidia-suspend-then-hibernate.service
```

### 解决
卸载 `nvidia-utils` 包后自动移除，无需单独处理。

## 问题 4：GRUB 残留（Intel 配置）

### 现象
- 实际引导加载器是 **systemd-boot**，GRUB 未被使用
- GRUB grub.cfg 引用了 `intel-ucode.img`（老笔记本配置），但 `/boot/` 下只有 `amd-ucode.img`
- 两套引导系统共存（systemd-boot + GRUB）

### 残留文件
```
/boot/grub/（整个目录）
/boot/EFI/Arch/grubx64.efi
/boot/EFI/BOOT/BOOTX64.EFI（GRUB fallback 副本）
```

### 清理命令
```bash
sudo pacman -Rns --noconfirm grub
sudo rm -rf /boot/grub
sudo rm -rf /boot/EFI/Arch
sudo cp /boot/EFI/systemd/systemd-bootx64.efi /boot/EFI/BOOT/BOOTX64.EFI
sudo mkinitcpio -P
```

## 引导系统对比

| 对比 | systemd-boot | GRUB |
|------|-------------|------|
| 复杂度 | 简单，配置文件少 | 复杂，需 grub-mkconfig |
| 速度 | 启动更快 | 稍慢 |
| 维护 | 内核更新自动处理 | 需手动跑 grub-mkconfig |

当前使用 systemd-boot，配置正确。
