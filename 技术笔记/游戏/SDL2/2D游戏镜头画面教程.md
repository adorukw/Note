# 第 1 章 · 镜头基础

2D 游戏的镜头看似简单——"把世界的一部分显示在屏幕上"——但背后涉及坐标变换、可见性判断、平滑跟随、构图美学等复杂问题。本章从最基础的视口变换开始，建立镜头的数学模型，理解世界坐标与屏幕坐标的关系，计算可见区域，并定义镜头的属性模型。这些是后续所有高级技巧的基石。

## 第 01 讲 · 2D 镜头的本质：视口与坐标变换

### 概念

**2D 镜头（Camera）** 本质上是一个矩形观察窗口，定义了"世界中的哪一部分被显示到屏幕上"。它不是物理相机，而是一个数学变换——把世界坐标系中的点转换为屏幕坐标系中的点。

镜头的核心作用有三个：

1. **选择可见区域**：决定玩家看到世界的哪一部分。
2. **坐标变换**：把世界坐标转换为屏幕坐标。
3. **构图引导**：通过位置、缩放、旋转引导玩家注意力。

### 原理

**视口变换的数学模型**：

设镜头在世界中的位置为 `(cx, cy)`，缩放为 `zoom`，屏幕尺寸为 `(screen_w, screen_h)`。世界坐标 `(wx, wy)` 转换为屏幕坐标 `(sx, sy)` 的公式：

```
sx = (wx - cx) * zoom + screen_w / 2
sy = (wy - cy) * zoom + screen_h / 2
```

反向变换（屏幕坐标 → 世界坐标，用于鼠标拾取）：

```
wx = (sx - screen_w / 2) / zoom + cx
wy = (sy - screen_h / 2) / zoom + cy
```

**变换的分解**：

这个变换可分解为三步：

1. **平移**：把镜头位置移到原点 `(wx - cx, wy - cy)`。
2. **缩放**：乘以 zoom。
3. **再平移**：把原点移到屏幕中心 `(+ screen_w/2, + screen_h/2)`。

用矩阵表示（齐次坐标）：

```
[zoom  0     screen_w/2 - cx*zoom]   [wx]   [sx]
[0     zoom  screen_h/2 - cy*zoom] · [wy] = [sy]
[0     0     1                     ]   [1 ]   [1 ]
```

**Y 轴方向的处理**：

- **屏幕坐标**：Y 向下（左上角为原点），SDL2、Direct2D 默认。
- **世界坐标**：Y 向上（数学坐标），适合物理模拟。
- **统一方案**：让世界坐标也 Y 向下（与屏幕一致），省去翻转。本教程采用此方案。

**镜头的"虚拟性"**：

镜头本身不改变世界——世界中的物体位置不变，只是渲染时根据镜头变换决定哪些被绘制、绘制在哪里。镜头是一个"观察者"，不是"修改者"。

### 例子

```cpp
#include <SDL2/SDL.h>

// 2D 镜头
struct Camera {
    float x, y;          // 镜头在世界中的位置
    float zoom;          // 缩放（1.0 = 原始大小）
    int screen_w, screen_h;

    // 世界坐标 → 屏幕坐标
    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = (wx - x) * zoom + screen_w / 2.0f;
        sy = (wy - y) * zoom + screen_h / 2.0f;
    }

    // 屏幕坐标 → 世界坐标
    void screen_to_world(float sx, float sy, float& wx, float& wy) const {
        wx = (sx - screen_w / 2.0f) / zoom + x;
        wy = (sy - screen_h / 2.0f) / zoom + y;
    }

    // 可见区域的左上角（世界坐标）
    float view_left()   const { return x - screen_w / 2.0f / zoom; }
    float view_top()    const { return y - screen_h / 2.0f / zoom; }
    float view_right()  const { return x + screen_w / 2.0f / zoom; }
    float view_bottom() const { return y + screen_h / 2.0f / zoom; }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Camera Basics",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 1.0f, 800, 600 };

    // 世界中的物体（网格点）
    struct WorldPoint { float x, y; };
    WorldPoint points[100];
    for (int i = 0; i < 100; ++i) {
        points[i] = { (float)(rand() % 2000 - 1000),
                      (float)(rand() % 2000 - 1000) };
    }

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
        }

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 5;
        if (keys[SDL_SCANCODE_LEFT])  cam.x -= speed;
        if (keys[SDL_SCANCODE_RIGHT]) cam.x += speed;
        if (keys[SDL_SCANCODE_UP])    cam.y -= speed;
        if (keys[SDL_SCANCODE_DOWN])  cam.y += speed;
        if (keys[SDL_SCANCODE_W]) cam.zoom *= 1.02f;
        if (keys[SDL_SCANCODE_S]) cam.zoom *= 0.98f;

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 绘制世界网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        int grid_size = 100;
        for (int gx = (int)cam.view_left() / grid_size * grid_size;
             gx <= (int)cam.view_right(); gx += grid_size) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(gx, cam.view_top(), sx1, sy1);
            cam.world_to_screen(gx, cam.view_bottom(), sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }
        for (int gy = (int)cam.view_top() / grid_size * grid_size;
             gy <= (int)cam.view_bottom(); gy += grid_size) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(cam.view_left(), gy, sx1, sy1);
            cam.world_to_screen(cam.view_right(), gy, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 绘制世界原点
        float ox, oy;
        cam.world_to_screen(0, 0, ox, oy);
        SDL_SetRenderDrawColor(renderer, 100, 255, 100, 255);
        SDL_Rect origin = { (int)ox - 5, (int)oy - 5, 10, 10 };
        SDL_RenderFillRect(renderer, &origin);

        // 绘制世界中的点
        SDL_SetRenderDrawColor(renderer, 255, 200, 100, 255);
        for (const auto& p : points) {
            if (p.x < cam.view_left() || p.x > cam.view_right() ||
                p.y < cam.view_top() || p.y > cam.view_bottom()) continue;
            float sx, sy;
            cam.world_to_screen(p.x, p.y, sx, sy);
            SDL_Rect r = { (int)sx - 2, (int)sy - 2, 4, 4 };
            SDL_RenderFillRect(renderer, &r);
        }

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 2D 镜头本质是坐标变换：`sx = (wx - cx) * zoom + screen_w/2`。
- 变换分解：平移（镜头到原点）→ 缩放 → 平移（到屏幕中心）。
- **Y 轴方向**：建议世界与屏幕统一（都向下），省去翻转。
- 镜头是"观察者"而非"修改者"，不改变世界，只改变渲染。
- **常见坑**：忘记除以 zoom 计算可见区域；缩放后物体位置偏移。

## 第 02 讲 · 世界坐标与屏幕坐标

### 概念

**世界坐标（World Coordinates）** 是物体在游戏世界中的绝对位置，独立于镜头。世界可以无限大，物体在世界中有固定坐标。

**屏幕坐标（Screen Coordinates）** 是物体在屏幕上的像素位置，依赖镜头。镜头移动时，同一物体的屏幕坐标变化，但世界坐标不变。

区分这两个坐标系是理解镜头的基础——所有游戏逻辑用世界坐标，所有渲染用屏幕坐标，镜头负责两者间的转换。

### 原理

**两套坐标系的对应关系**：

```
世界坐标 (wx, wy)
    ↓ 镜头变换
屏幕坐标 (sx, sy)
```

镜头变换由镜头位置、缩放、旋转决定（本讲暂不考虑旋转）。

**坐标变换的逆**：

屏幕坐标 → 世界坐标的逆变换用于：

- **鼠标拾取**：玩家点击屏幕，转换为世界坐标判断点击了什么。
- **屏幕到世界的尺寸转换**：UI 元素的屏幕尺寸转换为世界尺寸。

**尺寸的变换**：

不仅位置需要变换，尺寸也要：

```
screen_size = world_size * zoom
world_size = screen_size / zoom
```

例如，一个 100 像素的世界物体在 zoom=2 时显示为 200 像素。

**旋转的引入**：

若镜头有旋转角度 θ，变换变为：

```
dx = wx - cx
dy = wy - cy
// 反向旋转
rx = dx * cos(-θ) - dy * sin(-θ)
ry = dx * sin(-θ) + dy * cos(-θ)
// 缩放与平移
sx = rx * zoom + screen_w / 2
sy = ry * zoom + screen_h / 2
```

**坐标系的层次**：

复杂游戏可能有多个坐标系：

```
本地坐标（物体自身）
    ↓ 模型矩阵
世界坐标（场景全局）
    ↓ 视图矩阵（镜头）
屏幕坐标（像素）
```

2D 游戏通常简化为世界 → 屏幕两层，但理解层次有助于处理复杂场景（如载具上的角色）。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct Camera {
    float x, y, zoom, rotation;
    int screen_w, screen_h;

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        float dx = wx - x;
        float dy = wy - y;
        // 反向旋转
        float cos_r = cosf(-rotation), sin_r = sinf(-rotation);
        float rx = dx * cos_r - dy * sin_r;
        float ry = dx * sin_r + dy * cos_r;
        // 缩放与平移
        sx = rx * zoom + screen_w / 2.0f;
        sy = ry * zoom + screen_h / 2.0f;
    }

    void screen_to_world(float sx, float sy, float& wx, float& wy) const {
        float rx = (sx - screen_w / 2.0f) / zoom;
        float ry = (sy - screen_h / 2.0f) / zoom;
        float cos_r = cosf(rotation), sin_r = sinf(rotation);
        float dx = rx * cos_r - ry * sin_r;
        float dy = rx * sin_r + ry * cos_r;
        wx = dx + x;
        wy = dy + y;
    }

    // 世界尺寸 → 屏幕尺寸
    float world_size_to_screen(float world_size) const {
        return world_size * zoom;
    }

    // 屏幕尺寸 → 世界尺寸
    float screen_size_to_world(float screen_size) const {
        return screen_size / zoom;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Coordinate Systems",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 1.0f, 0, 800, 600 };

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_MOUSEMOTION) {
                // 鼠标拾取：屏幕坐标 → 世界坐标
                float wx, wy;
                cam.screen_to_world(e.motion.x, e.motion.y, wx, wy);
                // printf("Mouse world: (%.1f, %.1f)\n", wx, wy);
            }
        }

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        if (keys[SDL_SCANCODE_A]) cam.x -= 5;
        if (keys[SDL_SCANCODE_D]) cam.x += 5;
        if (keys[SDL_SCANCODE_W]) cam.y -= 5;
        if (keys[SDL_SCANCODE_S]) cam.y += 5;
        if (keys[SDL_SCANCODE_Q]) cam.zoom *= 1.02f;
        if (keys[SDL_SCANCODE_E]) cam.zoom *= 0.98f;
        if (keys[SDL_SCANCODE_Z]) cam.rotation -= 0.02f;
        if (keys[SDL_SCANCODE_X]) cam.rotation += 0.02f;

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 绘制世界网格（每 100 世界单位）
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int gx = -2000; gx <= 2000; gx += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(gx, -2000, sx1, sy1);
            cam.world_to_screen(gx, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }
        for (int gy = -2000; gy <= 2000; gy += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(-2000, gy, sx1, sy1);
            cam.world_to_screen(2000, gy, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 绘制世界原点标记
        float ox, oy;
        cam.world_to_screen(0, 0, ox, oy);
        SDL_SetRenderDrawColor(renderer, 100, 255, 100, 255);
        SDL_Rect origin = { (int)ox - 10, (int)oy - 10, 20, 20 };
        SDL_RenderFillRect(renderer, &origin);

        // 绘制一个世界尺寸为 100 的方块（在 200, 200）
        float bx, by;
        cam.world_to_screen(200, 200, bx, by);
        float bs = cam.world_size_to_screen(100);
        SDL_SetRenderDrawColor(renderer, 255, 100, 100, 255);
        SDL_Rect box = { (int)(bx - bs/2), (int)(by - bs/2), (int)bs, (int)bs };
        SDL_RenderFillRect(renderer, &box);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 世界坐标是物体的绝对位置，屏幕坐标是渲染位置，镜头负责转换。
- 尺寸也要变换：`screen_size = world_size * zoom`。
- 旋转引入后，变换需先反向旋转再缩放平移。
- **鼠标拾取**用屏幕 → 世界逆变换。
- **常见坑**：旋转方向混淆（镜头旋转 vs 世界反向旋转）；尺寸忘记随 zoom 缩放。

## 第 03 讲 · 可见区域与裁剪

### 概念

**可见区域（Visible Area）** 是镜头当前能看到的世界矩形范围。计算可见区域是性能优化的基础——只渲染可见区域内的物体，跳过区域外的，避免无谓的绘制。

**裁剪（Culling）** 是根据可见区域剔除不可见物体的过程。2D 游戏中常用**视锥裁剪**（其实是视口矩形裁剪）——判断物体的包围盒是否与可见矩形相交。

### 原理

**可见区域的计算**：

给定镜头位置 `(cx, cy)`、缩放 `zoom`、屏幕尺寸 `(w, h)`：

```
view_width = w / zoom
view_height = h / zoom
view_left = cx - view_width / 2
view_right = cx + view_width / 2
view_top = cy - view_height / 2
view_bottom = cy + view_height / 2
```

可见区域是 `[view_left, view_right] × [view_top, view_bottom]` 的矩形。

**AABB 裁剪测试**：

判断物体（用 AABB 包围盒表示）是否可见：

```
bool visible = (obj.right  > view_left  &&
                obj.left   < view_right &&
                obj.bottom > view_top   &&
                obj.top    < view_bottom);
```

若物体 AABB 完全在可见区域外，跳过渲染。

**安全边距（Margin）**：

由于动画、阴影、粒子等可能超出物体 AABB，常加一个安全边距：

```
view_left   -= margin
view_right  += margin
view_top    -= margin
view_bottom += margin
```

边距避免边缘物体"突然出现/消失"。

**空间分区优化**：

逐个检查所有物体的 AABB 在物体数量大时（>1000）仍慢。空间分区（网格、四叉树）把物体按位置分组，只检查可见区域内的组：

```
grid = 空间网格
visible_cells = grid.query(view_left, view_top, view_right, view_bottom)
for cell in visible_cells:
    for obj in cell.objects:
        render(obj)
```

**旋转镜头的可见区域**：

镜头旋转后，可见区域不再是轴对齐矩形，而是旋转矩形。简化处理：

1. 计算屏幕四角的世界坐标。
2. 用这四点构造旋转矩形或凸多边形。
3. 用多边形裁剪测试。

实际中，旋转角度通常很小，用 AABB 近似（旋转矩形的 AABB）即可。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <vector>

struct Camera {
    float x, y, zoom;
    int screen_w, screen_h;

    float view_left()   const { return x - screen_w / 2.0f / zoom; }
    float view_right()  const { return x + screen_w / 2.0f / zoom; }
    float view_top()    const { return y - screen_h / 2.0f / zoom; }
    float view_bottom() const { return y + screen_h / 2.0f / zoom; }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = (wx - x) * zoom + screen_w / 2.0f;
        sy = (wy - y) * zoom + screen_h / 2.0f;
    }
};

struct GameObject {
    float x, y, w, h;  // 世界位置与尺寸
    Uint8 r, g, b;

    float left()   const { return x; }
    float right()  const { return x + w; }
    float top()    const { return y; }
    float bottom() const { return y + h; }

    bool is_visible(const Camera& cam, float margin = 50) const {
        return right()  > cam.view_left()   - margin &&
               left()   < cam.view_right()  + margin &&
               bottom() > cam.view_top()    - margin &&
               top()    < cam.view_bottom() + margin;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Culling",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 1.0f, 800, 600 };

    // 生成 1000 个物体
    std::vector<GameObject> objects;
    for (int i = 0; i < 1000; ++i) {
        GameObject obj;
        obj.x = (rand() % 4000 - 2000);
        obj.y = (rand() % 4000 - 2000);
        obj.w = 20 + rand() % 40;
        obj.h = 20 + rand() % 40;
        obj.r = rand() % 200 + 50;
        obj.g = rand() % 200 + 50;
        obj.b = rand() % 200 + 50;
        objects.push_back(obj);
    }

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) if (e.type == SDL_QUIT) running = false;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        if (keys[SDL_SCANCODE_LEFT])  cam.x -= 10;
        if (keys[SDL_SCANCODE_RIGHT]) cam.x += 10;
        if (keys[SDL_SCANCODE_UP])    cam.y -= 10;
        if (keys[SDL_SCANCODE_DOWN])  cam.y += 10;
        if (keys[SDL_SCANCODE_W]) cam.zoom *= 1.05f;
        if (keys[SDL_SCANCODE_S]) cam.zoom *= 0.95f;

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        int rendered_count = 0;
        int culled_count = 0;

        for (const auto& obj : objects) {
            if (!obj.is_visible(cam)) {
                culled_count++;
                continue;
            }
            rendered_count++;

            float sx, sy;
            cam.world_to_screen(obj.x, obj.y, sx, sy);
            SDL_SetRenderDrawColor(renderer, obj.r, obj.g, obj.b, 255);
            SDL_Rect r = { (int)sx, (int)sy, (int)(obj.w * cam.zoom), (int)(obj.h * cam.zoom) };
            SDL_RenderFillRect(renderer, &r);
        }

        // 显示统计
        // printf("Rendered: %d, Culled: %d\n", rendered_count, culled_count);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 可见区域 = `[cx ± w/2/zoom, cy ± h/2/zoom]` 的矩形。
- AABB 裁剪：物体 AABB 与可见矩形相交则渲染。
- **安全边距**避免边缘物体突然出现/消失。
- **空间分区**（网格、四叉树）优化大量物体的裁剪。
- **性能**：1000 物体中通常只有 50~100 可见，裁剪节省 90% 渲染。
- **常见坑**：忘记乘/除 zoom；旋转镜头用 AABB 近似可能误判。

## 第 04 讲 · 镜头的属性模型

### 概念

一个完整的 2D 镜头不止有位置和缩放，还包含多个属性：位置、缩放、旋转、跟随目标、边界限制、死区、前瞻等。把这些属性组织成一个**镜头模型（Camera Model）**，是构建可维护镜头系统的基础。

### 原理

**镜头的核心属性**：

```cpp
struct Camera {
    // 变换属性
    Vec2 position;       // 当前位置
    float zoom;          // 缩放
    float rotation;      // 旋转

    // 跟随属性
    Vec2* target;        // 跟随目标（通常玩家）
    float follow_speed;  // 跟随速度（Lerp 系数）

    // 限制属性
    Rect bounds;         // 镜头活动边界
    bool use_bounds;     // 是否启用边界

    // 死区
    Rect deadzone;       // 死区矩形（相对屏幕）

    // 前瞻
    Vec2 look_ahead;     // 前瞻偏移
    float look_ahead_factor;  // 前瞻系数

    // 特效
    float shake_intensity;  // 震动强度
    float shake_duration;   // 震动剩余时间
    Vec2 shake_offset;      // 当前震动偏移

    // 视口
    Viewport viewport;   // 屏幕渲染区域
};
```

**属性的分类**：

1. **变换属性**：position、zoom、rotation——决定镜头的当前状态。
2. **跟随属性**：target、follow_speed——控制镜头如何跟随目标。
3. **限制属性**：bounds、deadzone——约束镜头行为。
4. **特效属性**：shake、offset——临时视觉效果。
5. **视口属性**：viewport——屏幕渲染区域（分屏用）。

**更新顺序**：

镜头每帧的更新顺序很重要：

```
1. 跟随目标（计算理想位置）
2. 应用前瞻（理想位置 += 前瞻偏移）
3. 应用死区（若目标在死区内，不移动）
4. 平滑插值（当前位置 → 理想位置）
5. 应用边界（限制在 bounds 内）
6. 应用震动（最终位置 += 震动偏移）
7. 计算变换矩阵
```

**属性的分离**：

把"逻辑位置"（跟随、平滑后的位置）与"渲染位置"（加震动后的位置）分离，避免震动影响跟随逻辑：

```cpp
Vec2 logic_position;   // 逻辑位置（跟随、平滑）
Vec2 render_position;  // 渲染位置（logic + shake）
```

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>
#include <algorithm>

struct Vec2 { float x, y; };
struct Rect { float x, y, w, h; };

class Camera {
public:
    // 变换
    Vec2 position = {0, 0};
    float zoom = 1.0f;
    float rotation = 0;

    // 跟随
    Vec2* target = nullptr;
    float follow_speed = 0.1f;

    // 边界
    Rect bounds = {0, 0, 0, 0};
    bool use_bounds = false;

    // 死区（屏幕比例，0~1）
    float deadzone_x = 0.3f;  // 水平死区宽度比例
    float deadzone_y = 0.3f;  // 垂直死区高度比例

    // 前瞻
    float look_ahead_factor = 0.5f;
    Vec2 target_velocity = {0, 0};

    // 震动
    float shake_intensity = 0;
    float shake_duration = 0;
    Vec2 shake_offset = {0, 0};

    int screen_w = 800, screen_h = 600;

    void update(float dt) {
        if (!target) return;

        // 1. 计算理想位置（目标位置 + 前瞻）
        Vec2 ideal = {
            target->x + target_velocity.x * look_ahead_factor,
            target->y + target_velocity.y * look_ahead_factor
        };

        // 2. 死区检查
        float dz_w = screen_w * deadzone_x / zoom;
        float dz_h = screen_h * deadzone_y / zoom;
        float dz_left = position.x - dz_w / 2;
        float dz_right = position.x + dz_w / 2;
        float dz_top = position.y - dz_h / 2;
        float dz_bottom = position.y + dz_h / 2;

        Vec2 desired = position;
        if (target->x < dz_left)   desired.x = target->x + dz_w / 2;
        if (target->x > dz_right)  desired.x = target->x - dz_w / 2;
        if (target->y < dz_top)    desired.y = target->y + dz_h / 2;
        if (target->y > dz_bottom) desired.y = target->y - dz_h / 2;

        // 3. 平滑插值
        position.x += (desired.x - position.x) * follow_speed;
        position.y += (desired.y - position.y) * follow_speed;

        // 4. 边界限制
        if (use_bounds) {
            float half_w = screen_w / 2.0f / zoom;
            float half_h = screen_h / 2.0f / zoom;
            position.x = std::clamp(position.x,
                bounds.x + half_w, bounds.x + bounds.w - half_w);
            position.y = std::clamp(position.y,
                bounds.y + half_h, bounds.y + bounds.h - half_h);
        }

        // 5. 震动
        if (shake_duration > 0) {
            shake_offset.x = (rand() % 200 - 100) / 100.0f * shake_intensity;
            shake_offset.y = (rand() % 200 - 100) / 100.0f * shake_intensity;
            shake_duration -= dt;
            shake_intensity *= 0.92f;  // 衰减
        } else {
            shake_offset = {0, 0};
        }
    }

    Vec2 get_render_position() const {
        return { position.x + shake_offset.x, position.y + shake_offset.y };
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        Vec2 rp = get_render_position();
        sx = (wx - rp.x) * zoom + screen_w / 2.0f;
        sy = (wy - rp.y) * zoom + screen_h / 2.0f;
    }

    void trigger_shake(float intensity, float duration) {
        shake_intensity = intensity;
        shake_duration = duration;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Camera Model",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam;
    cam.bounds = { -1000, -1000, 2000, 2000 };
    cam.use_bounds = true;

    Vec2 player = { 0, 0 };
    Vec2 player_vel = { 0, 0 };
    cam.target = &player;

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN && e.key.keysym.sym == SDLK_SPACE) {
                cam.trigger_shake(15, 0.5f);
            }
        }

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 5;
        player_vel = {0, 0};
        if (keys[SDL_SCANCODE_LEFT])  player_vel.x = -speed;
        if (keys[SDL_SCANCODE_RIGHT]) player_vel.x = speed;
        if (keys[SDL_SCANCODE_UP])    player_vel.y = -speed;
        if (keys[SDL_SCANCODE_DOWN])  player_vel.y = speed;
        player.x += player_vel.x;
        player.y += player_vel.y;
        cam.target_velocity = player_vel;

        cam.update(1.0f / 60.0f);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 世界网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -1000; g <= 1000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -1000, sx1, sy1);
            cam.world_to_screen(g, 1000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-1000, g, sx1, sy1);
            cam.world_to_screen(1000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 死区可视化
        float dz_w = 800 * cam.deadzone_x;
        float dz_h = 600 * cam.deadzone_y;
        SDL_SetRenderDrawColor(renderer, 100, 100, 100, 100);
        SDL_Rect dz = { (int)(400 - dz_w/2), (int)(300 - dz_h/2), (int)dz_w, (int)dz_h };
        SDL_RenderDrawRect(renderer, &dz);

        // 玩家
        float px, py;
        cam.world_to_screen(player.x, player.y, px, py);
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_Rect pr = { (int)px - 15, (int)py - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &pr);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 镜头模型包含变换、跟随、限制、特效、视口五类属性。
- 更新顺序：跟随 → 前瞻 → 死区 → 平滑 → 边界 → 震动。
- **逻辑位置与渲染位置分离**：震动不影响跟随逻辑。
- **死区**让镜头在目标小幅移动时保持静止，避免抖动。
- **边界**限制镜头不超出世界范围。
- **常见坑**：震动影响跟随导致抖动传染；边界未考虑 zoom 导致显示世界外。

# 第 2 章 · 跟随与平滑

镜头跟随是 2D 游戏最常见的镜头行为——镜头跟随玩家移动，让玩家始终在屏幕上。但"硬跟随"（镜头位置 = 玩家位置）会产生生硬、抖动的体验。本章从硬跟随的问题出发，逐步讲解线性插值（Lerp）、弹簧物理、临界阻尼、前瞻预测等平滑跟随技术。掌握这些，你的镜头就能像《空洞骑士》《死亡细胞》那样流畅自然。

## 第 05 讲 · 硬跟随与瞬移的问题

### 概念

**硬跟随（Hard Follow）** 是最简单的跟随方式——每帧把镜头位置直接设为目标位置：

```
camera.position = target.position
```

这种方式实现简单，但体验极差：镜头与目标完全同步，任何微小移动都立即反映到镜头，产生抖动；快速移动时镜头"贴脸"，玩家无法观察前方。

### 原理

**硬跟随的问题**：

1. **抖动**：目标位置每帧微小变化（如浮点误差、动画偏移），镜头立即跟随，产生高频抖动。
2. **无前瞻**：镜头始终把目标放在屏幕中心，玩家看不到前方，快速移动时反应不及。
3. **无缓冲**：目标突然停止时，镜头也突然停止，缺乏惯性感。
4. **眩晕**：镜头与目标完全同步，玩家感觉"被拖着走"，长时间游戏易眩晕。

**为什么硬跟随仍然有用**：

尽管体验差，硬跟随在某些场景仍适用：

- **回合制游戏**：玩家不连续移动，镜头瞬移到目标可接受。
- **地图编辑器**：精确控制镜头位置，不需要平滑。
- **调试模式**：直接观察目标，排除平滑干扰。

**瞬移（Teleport）的特殊处理**：

当目标瞬移（如传送门、重生）时，镜头不应平滑跟随（会扫过整个地图），而应立即跳到新位置。需区分"连续移动"与"瞬移"：

```
if (distance(target, camera) > teleport_threshold):
    camera.position = target.position  // 瞬移
else:
    camera.position = smooth_follow(camera.position, target.position)
```

**抖动的量化**：

抖动可用镜头位置的帧间变化量衡量：

```
jitter = |camera.position - camera.last_position|
```

硬跟随的 jitter 等于目标的 jitter，若目标有 1 像素抖动，镜头也有 1 像素抖动。平滑跟随可把 jitter 降低到原来的 10%~20%。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct Camera {
    float x, y;
    int screen_w, screen_h;

    // 硬跟随
    void hard_follow(float target_x, float target_y) {
        x = target_x;
        y = target_y;
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = wx - x + screen_w / 2.0f;
        sy = wy - y + screen_h / 2.0f;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Hard Follow",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 800, 600 };

    float player_x = 0, player_y = 0;
    bool use_hard_follow = true;

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN && e.key.keysym.sym == SDLK_SPACE) {
                use_hard_follow = !use_hard_follow;
            }
        }

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 5;
        if (keys[SDL_SCANCODE_LEFT])  player_x -= speed;
        if (keys[SDL_SCANCODE_RIGHT]) player_x += speed;
        if (keys[SDL_SCANCODE_UP])    player_y -= speed;
        if (keys[SDL_SCANCODE_DOWN])  player_y += speed;

        // 模拟抖动（角色动画偏移）
        float jitter_x = (rand() % 100 - 50) / 10.0f;
        float jitter_y = (rand() % 100 - 50) / 10.0f;

        if (use_hard_follow) {
            cam.hard_follow(player_x + jitter_x, player_y + jitter_y);
        } else {
            // 简单 Lerp（下一讲详讲）
            cam.x += (player_x - cam.x) * 0.1f;
            cam.y += (player_y - cam.y) * 0.1f;
        }

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_Rect pr = { (int)px - 15, (int)py - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &pr);

        // 状态
        SDL_SetRenderDrawColor(renderer, use_hard_follow ? 255 : 100,
                               use_hard_follow ? 100 : 255, 100, 255);
        SDL_Rect status = { 10, 10, 20, 20 };
        SDL_RenderFillRect(renderer, &status);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 硬跟随 `camera = target` 实现简单但体验差：抖动、无前瞻、无缓冲、眩晕。
- **抖动**：目标的小变化直接传给镜头，产生高频抖动。
- 硬跟随适用于回合制、编辑器、调试，不适合动作游戏。
- **瞬移处理**：距离过大时直接跳转，不平滑跟随。
- **改进方向**：用 Lerp、弹簧等平滑算法替代硬跟随。

## 第 06 讲 · 线性插值（Lerp）跟随

### 概念

**线性插值（Linear Interpolation, Lerp）** 是最常用的平滑跟随算法。每帧把镜头位置向目标位置移动一定比例：

```
camera.position += (target.position - camera.position) * t
```

`t` 是插值系数，取值 (0, 1)。t 越大跟随越快，t 越小越慢。t=1 等价于硬跟随，t=0 镜头不动。

Lerp 让镜头"追"目标，产生平滑的滞后感，是《超级马里奥》等经典游戏的标配。

### 原理

**Lerp 的数学**：

```
P(t) = P0 + (P1 - P0) * t,  t ∈ [0, 1]
```

t=0 时 P=P0（起点），t=1 时 P=P1（终点）。每帧应用一次 Lerp，镜头位置指数逼近目标。

**指数衰减特性**：

Lerp 跟随是指数衰减——每帧消除剩余距离的 t 比例：

```
帧 0: 距离 = D
帧 1: 距离 = D * (1 - t)
帧 2: 距离 = D * (1 - t)²
帧 n: 距离 = D * (1 - t)ⁿ
```

理论上永远到不了目标（指数衰减），但几帧后距离就小到不可见。

**帧率无关的 Lerp**：

标准 Lerp 依赖帧率——60fps 下 t=0.1 的跟随速度，30fps 下会慢一半。帧率无关版本：

```
t_frame = 1 - pow(1 - t_per_second, dt)
camera.position += (target.position - camera.position) * t_frame
```

或简化（dt 以秒为单位）：

```
camera.position += (target.position - camera.position) * (1 - exp(-speed * dt))
```

其中 `speed` 是跟随速度（如 5 表示每秒消除 63% 距离）。

**Lerp 的参数调优**：

| t 值 | 跟随速度 | 适用场景 |
|------|---------|---------|
| 0.05 | 很慢 | 电影感慢镜头 |
| 0.1 | 慢 | 平台游戏（马里奥） |
| 0.15 | 中等 | 动作游戏（空洞骑士） |
| 0.25 | 快 | 快节奏游戏（死亡细胞） |
| 0.5 | 很快 | 射击游戏 |
| 1.0 | 瞬间 | 硬跟随 |

**Lerp 的局限**：

1. **无惯性**：目标停止时，镜头立即开始减速，无"过冲"。
2. **无前瞻**：始终把目标作为中心，不预测前方。
3. **速度无关**：目标快慢不影响镜头行为，缺乏动态感。

这些局限可通过弹簧物理（下一讲）与前瞻（第 08 讲）解决。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct Camera {
    float x, y;
    float follow_speed = 5.0f;  // 每秒消除 63% 距离
    int screen_w, screen_h;

    // 帧率无关的 Lerp
    void follow(float target_x, float target_y, float dt) {
        float t = 1.0f - expf(-follow_speed * dt);
        x += (target_x - x) * t;
        y += (target_y - y) * t;
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = wx - x + screen_w / 2.0f;
        sy = wy - y + screen_h / 2.0f;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Lerp Follow",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 5.0f, 800, 600 };

    float player_x = 0, player_y = 0;
    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN) {
                if (e.key.keysym.sym == SDLK_1) cam.follow_speed = 2.0f;
                if (e.key.keysym.sym == SDLK_2) cam.follow_speed = 5.0f;
                if (e.key.keysym.sym == SDLK_3) cam.follow_speed = 10.0f;
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 300;  // 像素/秒
        if (keys[SDL_SCANCODE_LEFT])  player_x -= speed * dt;
        if (keys[SDL_SCANCODE_RIGHT]) player_x += speed * dt;
        if (keys[SDL_SCANCODE_UP])    player_y -= speed * dt;
        if (keys[SDL_SCANCODE_DOWN])  player_y += speed * dt;

        cam.follow(player_x, player_y, dt);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 目标位置标记（镜头理想中心）
        float tx, ty;
        cam.world_to_screen(player_x, player_y, tx, ty);
        SDL_SetRenderDrawColor(renderer, 100, 100, 100, 150);
        SDL_Rect target_mark = { (int)tx - 20, (int)ty - 20, 40, 40 };
        SDL_RenderDrawRect(renderer, &target_mark);

        // 玩家
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_Rect pr = { (int)tx - 15, (int)ty - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &pr);

        // 镜头中心标记
        SDL_SetRenderDrawColor(renderer, 255, 100, 100, 255);
        SDL_Rect cam_mark = { 395, 295, 10, 10 };
        SDL_RenderFillRect(renderer, &cam_mark);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- Lerp 每帧把镜头向目标移动 t 比例，产生指数衰减的平滑跟随。
- **帧率无关**：`t = 1 - exp(-speed * dt)`，保证不同帧率下行为一致。
- 跟随速度 t：0.1 慢（平台游戏），0.15 中（动作游戏），0.25 快（射击游戏）。
- **局限**：无惯性、无前瞻、速度无关。
- **改进**：弹簧物理（过冲感）、前瞻（预测前方）。
- **常见坑**：用固定 t 不考虑帧率；t 过大近似硬跟随。

## 第 07 讲 · 弹簧物理与临界阻尼

### 概念

**弹簧物理（Spring Physics）** 把镜头模拟为连接到目标的弹簧，产生自然的惯性与过冲。镜头"追"目标时会有轻微过冲，然后回弹，像真实的弹簧。

**临界阻尼（Critical Damping）** 是弹簧的特殊配置——阻尼恰好让弹簧最快回到平衡位置而不振荡。临界阻尼的镜头既快速跟随又无振荡，是商业游戏的首选。

### 原理

**弹簧物理模型**：

镜头受弹簧力（拉向目标）与阻尼力（减速）：

```
F_spring = -k * (position - target)       // 弹簧力，k 是刚度
F_damper = -c * velocity                   // 阻尼力，c 是阻尼系数

acceleration = (F_spring + F_damper) / mass
velocity += acceleration * dt
position += velocity * dt
```

**阻尼比（Damping Ratio, ζ）**：

阻尼比决定弹簧的行为：

- ζ < 1：欠阻尼，振荡（过冲后回弹多次）。
- ζ = 1：临界阻尼，最快无振荡（推荐）。
- ζ > 1：过阻尼，缓慢无振荡。

```
ζ = c / (2 * sqrt(k * mass))
```

临界阻尼时 `c = 2 * sqrt(k * mass)`。

**简化实现（基于位置的弹簧）**：

无需显式存储速度，用位置差分：

```
// 每帧
float stiffness = 100;   // 刚度
float damping = 2 * sqrt(stiffness);  // 临界阻尼

Vec2 force = (target - position) * stiffness - velocity * damping;
velocity += force * dt;
position += velocity * dt;
```

**半隐式 Euler 积分**：

弹簧物理需用半隐式 Euler（先更新速度再更新位置），比显式 Euler 更稳定：

```
velocity += acceleration * dt;  // 先更新速度
position += velocity * dt;       // 再用新速度更新位置
```

**参数调优**：

| 刚度 k | 阻尼比 ζ | 行为 |
|--------|---------|------|
| 50 | 1.0 | 慢速跟随，轻微过冲 |
| 100 | 1.0 | 中速跟随，推荐 |
| 200 | 1.0 | 快速跟随，紧凑 |
| 100 | 0.5 | 振荡（弹跳感） |
| 100 | 2.0 | 缓慢无过冲 |

**弹簧 vs Lerp**：

| 特性 | Lerp | 弹簧 |
|------|------|------|
| 过冲 | 无 | 有（可调） |
| 惯性 | 无 | 有 |
| 速度 | 指数衰减 | 振荡衰减 |
| 复杂度 | 低 | 中 |
| 适用 | 简单跟随 | 动作游戏 |

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct SpringCamera {
    float x, y;
    float vx = 0, vy = 0;  // 速度
    float stiffness = 100.0f;  // 刚度
    float damping = 1.0f;      // 阻尼比（1.0 = 临界）
    int screen_w, screen_h;

    void follow(float target_x, float target_y, float dt) {
        // 计算临界阻尼系数
        float c = 2.0f * sqrtf(stiffness) * damping;

        float fx = (target_x - x) * stiffness - vx * c;
        float fy = (target_y - y) * stiffness - vy * c;

        // 半隐式 Euler
        vx += fx * dt;
        vy += fy * dt;
        x += vx * dt;
        y += vy * dt;
    }

        sx = wx - x + screen_w / 2.0f;

    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN) {
                if (e.key.keysym.sym == SDLK_1) { cam.stiffness = 50; cam.damping = 1.0; }
                if (e.key.keysym.sym == SDLK_2) { cam.stiffness = 100; cam.damping = 1.0; }
                if (e.key.keysym.sym == SDLK_3) { cam.stiffness = 100; cam.damping = 0.5; }
                if (e.key.keysym.sym == SDLK_4) { cam.stiffness = 100; cam.damping = 2.0; }
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;
        if (dt > 0.05f) dt = 0.05f;  // 防止大步长

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 300;
        if (keys[SDL_SCANCODE_LEFT])  player_x -= speed * dt;
        if (keys[SDL_SCANCODE_RIGHT]) player_x += speed * dt;
        if (keys[SDL_SCANCODE_UP])    player_y -= speed * dt;
        if (keys[SDL_SCANCODE_DOWN])  player_y += speed * dt;

        cam.follow(player_x, player_y, dt);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_Rect pr = { (int)px - 15, (int)py - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &pr);

        // 镜头中心
        SDL_SetRenderDrawColor(renderer, 255, 100, 100, 255);
        SDL_Rect cm = { 395, 295, 10, 10 };
        SDL_RenderFillRect(renderer, &cm);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;

```

### 总结

- 弹簧物理把镜头模拟为连接目标的弹簧，有惯性与过冲。
- **临界阻尼**（ζ=1）最快无振荡，是商业游戏首选。
- 阻尼比 ζ：< 1 振荡，= 1 临界，> 1 过阻尼。
- 用半隐式 Euler 积分保证稳定性。
- **弹簧 vs Lerp**：弹簧有惯性过冲，Lerp 无；动作游戏用弹簧，休闲游戏用 Lerp。
- **常见坑**：dt 过大导致弹簧爆炸；阻尼比设置不当导致振荡或不收敛。

## 第 08 讲 · 前瞻与速度预测

### 概念

**前瞻（Look-ahead）** 让镜头根据目标速度前移，让玩家看到前方。目标向右移动时，镜头也向右偏移，把目标放在屏幕左侧，前方空间显示在右侧。

前瞻解决了"镜头贴脸"问题——玩家快速移动时，镜头提前显示前方，给玩家反应时间。这是《空洞骑士》《死亡细胞》等动作游戏的标准配置。

### 原理

**前瞻的原理**：

```
camera_target = player.position + player.velocity * look_ahead_factor
```

`look_ahead_factor` 是前瞻系数，通常 0.3~0.8。系数越大，镜头前移越多。

**前瞻的方向**：

前瞻应只在目标移动方向上偏移，静止时无偏移：

```
if (player.velocity.length() > threshold):
    look_ahead = player.velocity.normalized() * player.velocity.length() * factor
else:
    look_ahead = (0, 0)
```

**平滑的前瞻**：

直接用速度计算前瞻会导致前瞻"突变"（目标突然转向时，前瞻方向瞬间反转）。需对前瞻偏移本身做平滑：

```
desired_look_ahead = velocity * factor
current_look_ahead = lerp(current_look_ahead, desired_look_ahead, 0.1)
camera_target = player.position + current_look_ahead
```

**双向前瞻**：

某些游戏（如射击游戏）根据鼠标位置而非移动方向做前瞻——镜头偏向鼠标方向，让玩家看到瞄准的位置：

```
look_ahead = (mouse_position - screen_center) * factor
camera_target = player.position + look_ahead
```

**速度预测**：

更高级的前瞻用加速度预测未来位置：

```
future_position = player.position + player.velocity * t + 0.5 * player.acceleration * t²
camera_target = future_position
```

这适合有强惯性的游戏（如赛车），镜头提前预测玩家未来位置。

**前瞻的限制**：

前瞻偏移应限制在最大值内，避免镜头偏移过大：

```
look_ahead = clamp(look_ahead, -max_offset, max_offset)
```

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct Vec2 { float x, y; float length() const { return sqrtf(x*x + y*y); }
              void normalize() { float l = length(); if (l > 0) { x /= l; y /= l; } } };

struct Camera {
    float x, y;
    Vec2 look_ahead_offset = {0, 0};
    float look_ahead_factor = 0.4f;
    float look_ahead_smooth = 0.05f;  // 前瞻平滑系数
    float max_look_ahead = 150;
    int screen_w, screen_h;

    void follow(float target_x, float target_y,
                float vel_x, float vel_y, float dt) {
        // 计算理想前瞻
        Vec2 desired = { vel_x * look_ahead_factor, vel_y * look_ahead_factor };
        float dl = desired.length();
        if (dl > max_look_ahead) {
            desired.normalize();
            desired.x *= max_look_ahead;
            desired.y *= max_look_ahead;
        }

        // 平滑前瞻
        look_ahead_offset.x += (desired.x - look_ahead_offset.x) * look_ahead_smooth;
        look_ahead_offset.y += (desired.y - look_ahead_offset.y) * look_ahead_smooth;

        // 镜头目标 = 玩家位置 + 前瞻
        float cam_target_x = target_x + look_ahead_offset.x;
        float cam_target_y = target_y + look_ahead_offset.y;

        // Lerp 跟随
        float t = 1.0f - expf(-8.0f * dt);
        x += (cam_target_x - x) * t;
        y += (cam_target_y - y) * t;
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = wx - x + screen_w / 2.0f;
        sy = wy - y + screen_h / 2.0f;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Look-ahead",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, {0,0}, 0.4f, 0.05f, 150, 800, 600 };

    float player_x = 0, player_y = 0;
    float player_vx = 0, player_vy = 0;
    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN) {
                if (e.key.keysym.sym == SDLK_1) cam.look_ahead_factor = 0.0f;
                if (e.key.keysym.sym == SDLK_2) cam.look_ahead_factor = 0.4f;
                if (e.key.keysym.sym == SDLK_3) cam.look_ahead_factor = 0.8f;
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 400;
        float target_vx = 0, target_vy = 0;
        if (keys[SDL_SCANCODE_LEFT])  target_vx = -speed;
        if (keys[SDL_SCANCODE_RIGHT]) target_vx = speed;
        if (keys[SDL_SCANCODE_UP])    target_vy = -speed;
        if (keys[SDL_SCANCODE_DOWN])  target_vy = speed;

        // 平滑速度（避免突变）
        player_vx += (target_vx - player_vx) * 0.1f;
        player_vy += (target_vy - player_vy) * 0.1f;
        player_x += player_vx * dt;
        player_y += player_vy * dt;

        cam.follow(player_x, player_y, player_vx, player_vy, dt);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_Rect pr = { (int)px - 15, (int)py - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &pr);

        // 前瞻目标标记
        float tx, ty;
        cam.world_to_screen(player_x + cam.look_ahead_offset.x,
                            player_y + cam.look_ahead_offset.y, tx, ty);
        SDL_SetRenderDrawColor(renderer, 100, 255, 100, 150);
        SDL_Rect tr = { (int)tx - 5, (int)ty - 5, 10, 10 };
        SDL_RenderFillRect(renderer, &tr);

        // 镜头中心
        SDL_SetRenderDrawColor(renderer, 255, 100, 100, 255);
        SDL_Rect cm = { 395, 295, 10, 10 };
        SDL_RenderFillRect(renderer, &cm);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 前瞻让镜头根据目标速度前移，玩家看到前方。
- `camera_target = player.position + velocity * factor`，factor 通常 0.3~0.8。
- **平滑前瞻**：对前瞻偏移本身做 Lerp，避免转向时突变。
- **双向前瞻**：射击游戏用鼠标位置做前瞻。
- **速度预测**：用加速度预测未来位置，适合惯性强的游戏。
- **应用场景**：动作游戏（空洞骑士）、射击游戏（Enter the Gungeon）、赛车游戏。
- **常见坑**：前瞻系数过大导致镜头偏移过度；转向时前瞻突变。

# 第 3 章 · 构图与引导

镜头不仅是技术问题，更是艺术问题——"把什么放在屏幕的什么位置"决定了玩家的视觉体验。本章从电影摄影借鉴构图技巧：三分法与黄金构图、引导线与视觉流向、负空间与呼吸感、焦点引导与注意力。掌握这些，你的游戏画面就能像电影一样有"镜头感"，引导玩家看到你想让他们看到的内容。

## 第 09 讲 · 三分法与黄金构图

### 概念

**三分法（Rule of Thirds）** 是摄影与绘画的经典构图法则——把画面用两条水平线、两条垂直线分为 9 个等份，4 个交叉点是"视觉兴趣点"。把主体放在交叉点上（而非正中心），画面更生动、有张力。

**黄金构图（Golden Ratio Composition）** 基于黄金比例 φ ≈ 1.618，把画面按黄金比例分割。黄金构图与三分法类似但分割比例不同，产生更和谐的视觉效果。

### 原理

**三分法的原理**：

人眼对画面的注意力分布不均——中心区域注意力高但显得"呆板"，偏移中心的位置更有动感。三分法的交叉点（距边缘 1/3 处）是注意力与动感的平衡点。

```
+-----+-----+-----+
|     |     |     |
|  *  |     |  *  |   * = 兴趣点
|     |     |     |
+-----+-----+-----+
|     |     |     |
|     |     |     |
|     |     |     |
+-----+-----+-----+
|     |     |     |
|  *  |     |  *  |
|     |     |     |
+-----+-----+-----+
```

**在游戏镜头中的应用**：

- **角色偏移**：把角色放在左侧或右侧交叉点，而非正中心，前方留出更多空间（行进方向）。
- **地平线偏移**：地平线放在上 1/3 或下 1/3，而非正中，避免"分裂感"。
- **焦点物体**：重要物体（宝箱、敌人、出口）放在交叉点。

**黄金构图的分割**：

```
黄金比例：φ = (1 + √5) / 2 ≈ 1.618
黄金分割点：距边缘 1/φ ≈ 0.618 处

+--------+----+
|        |    |
|        |    |
|   *    |    |   * 在黄金分割点
|        |    |
|        |    |
+--------+----+
```

黄金构图比三分法更"内聚"——兴趣点更靠近中心，适合需要稳定感的场景。

**动态构图**：

游戏是动态的，构图随玩家移动变化。镜头系统应：

1. **跟随偏移**：镜头目标 = 玩家位置 + 构图偏移，让玩家偏向一侧。
2. **方向感知**：玩家向右移动时，玩家在屏幕左侧（前方留空间）；向左移动时反之。
3. **场景感知**：接近重要物体时，镜头调整让物体在交叉点。

**构图偏移的实现**：

```cpp
// 玩家在屏幕上的目标位置（归一化 0~1）
Vec2 frame_target = Vec2(0.33, 0.5);  // 左侧三分点

// 镜头目标 = 玩家世界位置 - 屏幕偏移
Vec2 screen_offset = (frame_target - Vec2(0.5, 0.5)) * screen_size;
camera_target = player.position - screen_offset;
```

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct Camera {
    float x, y;
    float frame_offset_x = 0.33f;  // 玩家在屏幕的水平位置（0~1）
    float frame_offset_y = 0.5f;
    int screen_w, screen_h;

    void follow(float target_x, float target_y, float dt) {
        // 构图偏移：让玩家偏向屏幕一侧
        float offset_x = (frame_offset_x - 0.5f) * screen_w;
        float offset_y = (frame_offset_y - 0.5f) * screen_h;

        float cam_target_x = target_x - offset_x;
        float cam_target_y = target_y - offset_y;

        float t = 1.0f - expf(-5.0f * dt);
        x += (cam_target_x - x) * t;
        y += (cam_target_y - y) * t;
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = wx - x + screen_w / 2.0f;
        sy = wy - y + screen_h / 2.0f;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Rule of Thirds",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 0.33f, 0.5f, 800, 600 };

    float player_x = 0, player_y = 0;
    float player_vx = 0;
    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN) {
                if (e.key.keysym.sym == SDLK_1) cam.frame_offset_x = 0.5f;   // 中心
                if (e.key.keysym.sym == SDLK_2) cam.frame_offset_x = 0.33f;  // 左三分
                if (e.key.keysym.sym == SDLK_3) cam.frame_offset_x = 0.67f;  // 右三分
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 300;
        float target_vx = 0;
        if (keys[SDL_SCANCODE_LEFT])  target_vx = -speed;
        if (keys[SDL_SCANCODE_RIGHT]) target_vx = speed;
        if (keys[SDL_SCANCODE_UP])    player_y -= speed * dt;
        if (keys[SDL_SCANCODE_DOWN])  player_y += speed * dt;

        player_vx += (target_vx - player_vx) * 0.1f;
        player_x += player_vx * dt;

        // 动态构图：根据移动方向调整偏移
        if (fabsf(player_vx) > 50) {
            float target_offset = player_vx > 0 ? 0.33f : 0.67f;
            cam.frame_offset_x += (target_offset - cam.frame_offset_x) * 0.05f;
        }

        cam.follow(player_x, player_y, dt);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 三分线
        SDL_SetRenderDrawColor(renderer, 100, 100, 100, 100);
        SDL_RenderDrawLine(renderer, 800/3, 0, 800/3, 600);
        SDL_RenderDrawLine(renderer, 800*2/3, 0, 800*2/3, 600);
        SDL_RenderDrawLine(renderer, 0, 600/3, 800, 600/3);
        SDL_RenderDrawLine(renderer, 0, 600*2/3, 800, 600*2/3);

        // 交叉点
        SDL_SetRenderDrawColor(renderer, 255, 255, 0, 150);
        for (int i = 0; i < 2; ++i) {
            for (int j = 0; j < 2; ++j) {
                SDL_Rect dot = { 800*(i+1)/3 - 3, 600*(j+1)/3 - 3, 6, 6 };
                SDL_RenderFillRect(renderer, &dot);
            }
        }

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_Rect pr = { (int)px - 15, (int)py - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &pr);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 三分法把画面分 9 等份，4 个交叉点是视觉兴趣点。
- 把主体放在交叉点（而非中心），画面更有张力。
- **动态构图**：玩家移动方向决定偏移侧，前方留空间。
- **黄金构图**基于 φ≈1.618，比三分法更内聚，适合稳定场景。
- **应用场景**：平台游戏（角色偏移）、RPG（焦点物体）、过场动画。
- **常见坑**：偏移过大导致玩家"贴边"；转向时偏移突变。

## 第 10 讲 · 引导线与视觉流向

### 概念

**引导线（Leading Lines）** 是画面中引导视线的线条——道路、河流、栏杆、阴影。人眼会自然沿线条移动，引导线把玩家视线引向焦点。

**视觉流向（Visual Flow）** 是玩家视线在画面中的移动路径。好的构图让视线从入口（如左下角）沿引导线流向焦点，再扩散到整体。

### 原理

**引导线的类型**：

1. **直线引导**：道路、走廊、栏杆，直接指向焦点。
2. **曲线引导**：河流、小径、山脊，柔和引导视线。
3. **对角线引导**：动态感强，常用于动作场景。
4. **汇聚线**：多条线汇聚于一点（如隧道），强烈聚焦。

**在游戏中的应用**：

- **关卡设计**：用道路、墙壁、装饰物构成引导线，指向目标。
- **镜头角度**：镜头与引导线对齐，强化引导效果。
- **光影引导**：用光照方向作为引导线，把视线引向亮处。

**视觉流向的设计**：

```
入口（左下）→ 引导线 → 焦点（右上）→ 扩散到整体
```

人眼习惯从左下到右上（西方阅读习惯），把重要物体放在右上能自然吸引注意。

**镜头与引导线的配合**：

镜头角度影响引导线效果：

- **水平镜头**：引导线水平，平静感。
- **俯角镜头**：引导线向下汇聚，压迫感。
- **仰角镜头**：引导线向上延伸，崇高感。

**2D 中的引导线实现**：

2D 游戏没有真正的镜头角度，但可通过：

1. **视差层**：背景层移动慢，前景层快，产生深度引导。
2. **渐变光照**：从暗到亮的渐变引导视线。
3. **装饰物排列**：树木、岩石按引导线排列。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>
#include <vector>

struct Camera {
    float x, y;
    int screen_w, screen_h;

    void follow(float target_x, float target_y, float dt) {
        float t = 1.0f - expf(-5.0f * dt);
        x += (target_x - x) * t;
        y += (target_y - y) * t;
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = wx - x + screen_w / 2.0f;
        sy = wy - y + screen_h / 2.0f;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Leading Lines",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 800, 600 };

    float player_x = 0, player_y = 0;
    Uint32 last_time = SDL_GetTicks();

    // 引导线：从左下到右上的"道路"
    struct Line { float x1, y1, x2, y2; };
    std::vector<Line> guide_lines = {
        {-500, 300, 500, -300},   // 主道路
        {-400, 350, 400, -250},   // 平行道路
        {-300, 400, 300, -200},   // 平行道路
    };

    // 焦点物体（右上）
    float focus_x = 500, focus_y = -300;

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) if (e.type == SDL_QUIT) running = false;

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 200;
        if (keys[SDL_SCANCODE_LEFT])  player_x -= speed * dt;
        if (keys[SDL_SCANCODE_RIGHT]) player_x += speed * dt;
        if (keys[SDL_SCANCODE_UP])    player_y -= speed * dt;
        if (keys[SDL_SCANCODE_DOWN])  player_y += speed * dt;

        cam.follow(player_x, player_y, dt);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 引导线（道路）
        SDL_SetRenderDrawColor(renderer, 100, 80, 60, 255);
        for (const auto& line : guide_lines) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(line.x1, line.y1, sx1, sy1);
            cam.world_to_screen(line.x2, line.y2, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 焦点物体（发光的宝箱）
        float fx, fy;
        cam.world_to_screen(focus_x, focus_y, fx, fy);
        // 光晕
        SDL_SetRenderDrawColor(renderer, 255, 200, 100, 50);
        for (int r = 40; r > 20; --r) {
            SDL_Rect glow = { (int)fx - r, (int)fy - r, r*2, r*2 };
            SDL_RenderDrawRect(renderer, &glow);
        }
        // 宝箱
        SDL_SetRenderDrawColor(renderer, 255, 200, 50, 255);
        SDL_Rect focus_rect = { (int)fx - 15, (int)fy - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &focus_rect);

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect pr = { (int)px - 10, (int)py - 10, 20, 20 };
        SDL_RenderFillRect(renderer, &pr);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 引导线是画面中引导视线的线条，把玩家视线引向焦点。
- 类型：直线、曲线、对角线、汇聚线。
- **视觉流向**：入口 → 引导线 → 焦点 → 整体，符合阅读习惯。
- 2D 中用视差、光照、装饰物排列创造引导线。
- **应用场景**：关卡设计（路径引导）、过场动画（视线引导）、UI（按钮引导）。
- **常见坑**：引导线过多导致视线混乱；引导线方向与焦点不一致。

## 第 11 讲 · 负空间与呼吸感

### 概念

**负空间（Negative Space）** 是画面中主体周围的空白区域。负空间不是"无"，而是"呼吸"——它给主体留出空间，避免画面拥挤，营造氛围。

**呼吸感（Breathing Room）** 是负空间带来的视觉舒适感。紧凑的构图（少负空间）紧张、压迫；宽松的构图（多负空间）舒缓、开阔。

### 原理

**负空间的作用**：

1. **突出主体**：周围空白让主体更醒目。
2. **营造氛围**：大片天空、空旷地面产生孤独、开阔感。
3. **控制节奏**：紧凑与宽松交替，形成视觉节奏。
4. **引导视线**：负空间的方向性引导视线（如大片天空引向上方）。

**正负空间的平衡**：

```
正空间（主体）: 负空间 = 1 : 1  → 平衡
正空间 : 负空间 = 1 : 2  → 宽松（开阔感）
正空间 : 负空间 = 2 : 1  → 紧凑（压迫感）
```

**在游戏镜头中的应用**：

- **开阔场景**：镜头拉远，增加负空间，营造孤独感（如《空洞骑士》的荒原）。
- **紧张场景**：镜头拉近，减少负空间，营造压迫感（如 Boss 战）。
- **探索场景**：中等负空间，让玩家观察环境。
- **战斗场景**：较少负空间，聚焦动作。

**动态负空间**：

镜头缩放动态调整负空间：

```cpp
// 战斗时拉近，减少负空间
if (in_combat) {
    target_zoom = 1.2;  // 放大
} else {
    target_zoom = 1.0;  // 正常
}
zoom = lerp(zoom, target_zoom, 0.05);
```

**负空间的方向性**：

负空间的位置影响氛围：

- **上方负空间**（大片天空）：开阔、自由、希望。
- **下方负空间**（空旷地面）：稳定、孤独、沉思。
- **侧方负空间**（前方留空）：前进、探索、未知。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct Camera {
    float x, y;
    float zoom = 1.0f;
    float target_zoom = 1.0f;
    int screen_w, screen_h;

    void follow(float target_x, float target_y, float dt, bool in_combat) {
        // 动态缩放：战斗时拉近
        target_zoom = in_combat ? 1.3f : 1.0f;
        zoom += (target_zoom - zoom) * 0.05f;

        float t = 1.0f - expf(-5.0f * dt);
        x += (target_x - x) * t;
        y += (target_y - y) * t;
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = (wx - x) * zoom + screen_w / 2.0f;
        sy = (wy - y) * zoom + screen_h / 2.0f;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Negative Space",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 1.0f, 1.0f, 800, 600 };

    float player_x = 0, player_y = 0;
    Uint32 last_time = SDL_GetTicks();

    // 敌人位置
    float enemy_x = 200, enemy_y = 0;
    bool in_combat = false;

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) if (e.type == SDL_QUIT) running = false;

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 200;
        if (keys[SDL_SCANCODE_LEFT])  player_x -= speed * dt;
        if (keys[SDL_SCANCODE_RIGHT]) player_x += speed * dt;
        if (keys[SDL_SCANCODE_UP])    player_y -= speed * dt;
        if (keys[SDL_SCANCODE_DOWN])  player_y += speed * dt;

        // 检测战斗（接近敌人）
        float dx = player_x - enemy_x;
        float dy = player_y - enemy_y;
        in_combat = (dx*dx + dy*dy) < 200*200;

        cam.follow(player_x, player_y, dt, in_combat);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 远景（天空，负空间）
        SDL_SetRenderDrawColor(renderer, 40, 50, 80, 255);
        SDL_Rect sky = { 0, 0, 800, 300 };
        SDL_RenderFillRect(renderer, &sky);

        // 地面
        SDL_SetRenderDrawColor(renderer, 60, 50, 40, 255);
        SDL_Rect ground = { 0, 300, 800, 300 };
        SDL_RenderFillRect(renderer, &ground);

        // 网格（地面）
        SDL_SetRenderDrawColor(renderer, 80, 70, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, 0, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            if (sx1 >= -100 && sx1 <= 900)
                SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 敌人
        float ex, ey;
        cam.world_to_screen(enemy_x, enemy_y, ex, ey);
        SDL_SetRenderDrawColor(renderer, 255, 80, 80, 255);
        SDL_Rect er = { (int)ex - 15, (int)ey - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &er);

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect pr = { (int)px - 10, (int)py - 10, 20, 20 };
        SDL_RenderFillRect(renderer, &pr);

        // 战斗状态指示
        if (in_combat) {
            SDL_SetRenderDrawColor(renderer, 255, 50, 50, 100);
            SDL_Rect border = { 5, 5, 790, 590 };
            SDL_RenderDrawRect(renderer, &border);
        }

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 负空间是主体周围的空白，给画面"呼吸感"。
- 正负比 1:1 平衡，1:2 宽松，2:1 紧凑。
- **动态负空间**：战斗时拉近减少负空间，探索时拉远增加。
- 负空间方向影响氛围：上方开阔，下方稳定，侧方前进。
- **应用场景**：Boss 战（拉近压迫）、探索（拉远开阔）、过场（氛围营造）。
- **常见坑**：负空间过多导致画面空洞；过少导致拥挤眩晕。

## 第 12 讲 · 焦点引导与注意力

### 概念

**焦点引导（Focus Guidance）** 通过视觉手段把玩家注意力引向特定物体或区域。人眼对某些视觉特征更敏感——亮度、颜色、运动、对比度。镜头系统可利用这些特征引导玩家。

**注意力（Attention）** 是玩家有限的认知资源。好的镜头设计让玩家注意力自然流向重要内容，而非被杂乱信息分散。

### 原理

**人眼的视觉优先级**（从高到低）：

1. **运动**：动的物体最吸引注意。
2. **亮度**：亮的物体比暗的更醒目。
3. **对比度**：与背景差异大的物体突出。
4. **颜色**：暖色（红、橙）比冷色（蓝、绿）更吸引。
5. **大小**：大的物体比小的更醒目。
6. **位置**：中心比边缘更受注意。

**镜头引导注意力的手段**：

1. **镜头聚焦**：把目标放在屏幕中心或交叉点。
2. **缩放引导**：拉近聚焦物体，让其他物体出屏。
3. **景深引导**：模糊背景，突出主体（2D 用模糊模拟）。
4. **光照引导**：增加目标亮度，暗化其他区域。
5. **色彩引导**：目标用饱和色，背景用低饱和色。
6. **运动引导**：目标动，背景静。

**焦点切换**：

游戏中的焦点会动态变化——玩家移动时焦点是玩家，Boss 出现时焦点是 Boss。镜头需平滑切换焦点：

```cpp
// 焦点目标
Vec2 focus_target;
if (boss_active) {
    // 焦点在玩家与 Boss 中点
    focus_target = (player.pos + boss.pos) / 2;
} else {
    focus_target = player.pos;
}
camera.follow(focus_target);
```

**多焦点**：

多个重要物体时，镜头需兼顾所有：

1. **中点法**：镜头对准所有焦点的中点。
2. **包围法**：镜头缩放使所有焦点可见。
3. **权重法**：重要物体权重高，镜头偏向它。

```cpp
// 包围法：计算包围所有焦点的 AABB，缩放使其填满屏幕
AABB bounds = compute_bounds(focuses);
camera.target = bounds.center();
camera.zoom = screen_size / bounds.size() * margin;
```

**注意力过载**：

避免同时呈现过多焦点，导致玩家注意力过载。原则：

- 同时焦点不超过 3 个。
- 主焦点突出，次焦点弱化。
- 用时间差揭示焦点（先 A，再 B，再 C）。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>
#include <vector>

struct Camera {
    float x, y;
    float zoom = 1.0f;
    int screen_w, screen_h;

    void follow(float target_x, float target_y, float target_zoom, float dt) {
        zoom += (target_zoom - zoom) * 0.05f;
        float t = 1.0f - expf(-5.0f * dt);
        x += (target_x - x) * t;
        y += (target_y - y) * t;
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = (wx - x) * zoom + screen_w / 2.0f;
        sy = (wy - y) * zoom + screen_h / 2.0f;
    }
};

struct FocusPoint {
    float x, y;
    float weight;  // 权重
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Focus Guidance",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 1.0f, 800, 600 };

    float player_x = 0, player_y = 0;
    Uint32 last_time = SDL_GetTicks();

    // 多个焦点
    std::vector<FocusPoint> focuses = {
        {0, 0, 1.0f},      // 玩家（运行时更新）
        {300, -100, 0.5f}, // 宝箱
        {-200, 100, 0.3f}, // 敌人
    };

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) if (e.type == SDL_QUIT) running = false;

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 200;
        if (keys[SDL_SCANCODE_LEFT])  player_x -= speed * dt;
        if (keys[SDL_SCANCODE_RIGHT]) player_x += speed * dt;
        if (keys[SDL_SCANCODE_UP])    player_y -= speed * dt;
        if (keys[SDL_SCANCODE_DOWN])  player_y += speed * dt;

        // 更新玩家焦点
        focuses[0].x = player_x;
        focuses[0].y = player_y;

        // 加权焦点
        float total_weight = 0;
        float focus_x = 0, focus_y = 0;
        for (const auto& f : focuses) {
            focus_x += f.x * f.weight;
            focus_y += f.y * f.weight;
            total_weight += f.weight;
        }
        focus_x /= total_weight;
        focus_y /= total_weight;

        // 计算包围盒，决定缩放
        float min_x = player_x, max_x = player_x;
        float min_y = player_y, max_y = player_y;
        for (const auto& f : focuses) {
            min_x = fminf(min_x, f.x); max_x = fmaxf(max_x, f.x);
            min_y = fminf(min_y, f.y); max_y = fmaxf(max_y, f.y);
        }
        float bounds_w = max_x - min_x + 200;  // 加边距
        float bounds_h = max_y - min_y + 200;
        float target_zoom = fminf(800.0f / bounds_w, 600.0f / bounds_h);
        target_zoom = fminf(target_zoom, 1.5f);  // 限制最大缩放

        cam.follow(focus_x, focus_y, target_zoom, dt);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 焦点物体（宝箱 - 亮色）
        float bx, by;
        cam.world_to_screen(focuses[1].x, focuses[1].y, bx, by);
        SDL_SetRenderDrawColor(renderer, 255, 220, 100, 255);
        SDL_Rect br = { (int)bx - 12, (int)by - 12, 24, 24 };
        SDL_RenderFillRect(renderer, &br);

        // 敌人（红色）
        float ex, ey;
        cam.world_to_screen(focuses[2].x, focuses[2].y, ex, ey);
        SDL_SetRenderDrawColor(renderer, 255, 80, 80, 255);
        SDL_Rect er = { (int)ex - 12, (int)ey - 12, 24, 24 };
        SDL_RenderFillRect(renderer, &er);

        // 玩家（蓝色，最亮）
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect pr = { (int)px - 10, (int)py - 10, 20, 20 };
        SDL_RenderFillRect(renderer, &pr);

        // 焦点中心标记
        float fcx, fcy;
        cam.world_to_screen(focus_x, focus_y, fcx, fcy);
        SDL_SetRenderDrawColor(renderer, 255, 255, 0, 150);
        SDL_Rect fc = { (int)fcx - 3, (int)fcy - 3, 6, 6 };
        SDL_RenderFillRect(renderer, &fc);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 焦点引导通过亮度、对比度、颜色、运动等引导玩家注意力。
- 视觉优先级：运动 > 亮度 > 对比度 > 颜色 > 大小 > 位置。
- **多焦点**：加权平均或包围法兼顾多个焦点。
- **注意力过载**：同时焦点不超过 3 个，用时间差揭示。
- **应用场景**：Boss 战（聚焦 Boss）、解谜（聚焦线索）、过场（焦点切换）。
- **常见坑**：焦点过多导致注意力分散；焦点切换过快导致眩晕。

# 第 4 章 · 镜头特效

镜头特效是游戏"手感"的关键——缩放营造紧张感、震动传递冲击力、偏移增加动感、缓动让运动有"性格"。本章讲解四大镜头特效：缩放与 FOV、镜头震动、镜头偏移与倾斜、缓动函数与时间曲线。掌握这些，你的游戏镜头就能像《以撒的结合》《死亡细胞》那样充满表现力。

## 第 13 讲 · 缩放与 FOV

### 概念

**镜头缩放（Zoom）** 改变镜头的视野范围——放大（zoom > 1）显示更少区域但更大，缩小（zoom < 1）显示更多区域但更小。缩放是 2D 游戏最常用的特效，用于聚焦、营造氛围、适应场景。

**FOV（Field of View，视场）** 在 2D 中等价于缩放——FOV 大相当于缩小（看得广），FOV 小相当于放大（看得窄）。2D 通常直接用 zoom 系数而非角度表示。

### 原理

**缩放的数学**：

```
screen_pos = (world_pos - camera_pos) * zoom + screen_center
```

zoom > 1：世界被放大，物体看起来更大。
zoom < 1：世界被缩小，物体看起来更小，可见范围更大。

**缩放中心**：

缩放围绕镜头中心（屏幕中心）进行。若要围绕其他点缩放（如玩家），需调整镜头位置：

```
// 围绕玩家缩放
camera_pos = player_pos - (screen_center - player_screen_pos) / zoom
```

**动态缩放的应用**：

1. **战斗拉近**：进入战斗时 zoom 增大，聚焦动作。
2. **探索拉远**：探索时 zoom 减小，观察环境。
3. **冲刺拉远**：高速移动时拉远，让玩家看到前方。
4. **Boss 出场**：zoom 拉近 Boss，强调威胁。
5. **死亡特写**：zoom 极度拉近死亡角色。

**缩放的平滑**：

缩放变化应平滑，避免突变：

```
target_zoom = compute_target_zoom(state);
zoom += (target_zoom - zoom) * 0.05;  // 缓慢插值
```

**缩放的限制**：

- **最小 zoom**：避免过小导致看不清角色。
- **最大 zoom**：避免过大导致像素化或看不到环境。
- 通常范围 [0.5, 2.0]。

**FOV 效应（速度感）**：

虽然 2D 没有真正的透视，但缩放变化可模拟"速度感"——高速移动时略微拉远，产生"视野扩大"的感觉，类似 3D 游戏的 FOV 增大。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct Camera {
    float x, y;
    float zoom = 1.0f;
    float target_zoom = 1.0f;
    float min_zoom = 0.5f;
    float max_zoom = 2.0f;
    int screen_w, screen_h;

    void follow(float target_x, float target_y, float dt, float player_speed) {
        // 根据速度动态缩放
        if (player_speed > 300) {
            target_zoom = 0.85f;  // 高速时拉远
        } else if (player_speed > 50) {
            target_zoom = 1.0f;   // 正常
        } else {
            target_zoom = 1.1f;   // 静止时略拉近
        }

        // 平滑缩放
        zoom += (target_zoom - zoom) * 0.05f;
        zoom = std::clamp(zoom, min_zoom, max_zoom);

        // 平滑跟随
        float t = 1.0f - expf(-5.0f * dt);
        x += (target_x - x) * t;
        y += (target_y - y) * t;
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = (wx - x) * zoom + screen_w / 2.0f;
        sy = (wy - y) * zoom + screen_h / 2.0f;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Zoom & FOV",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 1.0f, 1.0f, 0.5f, 2.0f, 800, 600 };

    float player_x = 0, player_y = 0;
    float player_vx = 0, player_vy = 0;
    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN) {
                if (e.key.keysym.sym == SDLK_1) cam.target_zoom = 0.7f;
                if (e.key.keysym.sym == SDLK_2) cam.target_zoom = 1.0f;
                if (e.key.keysym.sym == SDLK_3) cam.target_zoom = 1.5f;
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 400;
        float target_vx = 0, target_vy = 0;
        if (keys[SDL_SCANCODE_LEFT])  target_vx = -speed;
        if (keys[SDL_SCANCODE_RIGHT]) target_vx = speed;
        if (keys[SDL_SCANCODE_UP])    target_vy = -speed;
        if (keys[SDL_SCANCODE_DOWN])  target_vy = speed;

        player_vx += (target_vx - player_vx) * 0.1f;
        player_vy += (target_vy - player_vy) * 0.1f;
        player_x += player_vx * dt;
        player_y += player_vy * dt;

        float player_speed = sqrtf(player_vx*player_vx + player_vy*player_vy);
        cam.follow(player_x, player_y, dt, player_speed);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        int size = (int)(30 * cam.zoom);
        SDL_Rect pr = { (int)px - size/2, (int)py - size/2, size, size };
        SDL_RenderFillRect(renderer, &pr);

        // 缩放指示
        SDL_SetRenderDrawColor(renderer, 255, 255, 0, 255);
        SDL_Rect zoom_bar = { 10, 10, (int)((cam.zoom - 0.5f) / 1.5f * 200), 10 };
        SDL_RenderFillRect(renderer, &zoom_bar);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 缩放改变视野范围，zoom > 1 放大，zoom < 1 缩小。
- **动态缩放**：战斗拉近、探索拉远、冲刺拉远、死亡特写。
- 缩放需平滑过渡，限制在 [0.5, 2.0] 范围。
- **FOV 效应**：高速时拉远模拟速度感。
- **应用场景**：Boss 战、冲刺、过场、死亡特写。
- **常见坑**：缩放过大导致像素化；缩放中心错误导致物体偏移。

## 第 14 讲 · 镜头震动

### 概念

**镜头震动（Camera Shake）** 让镜头快速随机偏移，模拟冲击、爆炸、地震等效果。震动是最直接的力量反馈——玩家看到画面晃动，立即感受到"发生了大事"。

好的震动有"冲击感"——快速达到峰值，逐渐衰减，而非持续均匀晃动。震动过度会导致眩晕，需精心设计。

### 原理

**震动的数学模型**：

```
shake_offset = random_direction() * intensity * decay(t)
```

- `random_direction()`：单位随机向量。
- `intensity`：震动强度（像素）。
- `decay(t)`：衰减函数，随时间减弱。

**衰减函数**：

1. **指数衰减**：`decay = exp(-t / tau)`，平滑衰减。
2. **线性衰减**：`decay = 1 - t / duration`，匀速衰减。
3. **平方衰减**：`decay = (1 - t / duration)²`，快速衰减。

指数衰减最自然，推荐使用。

**震动的触发**：

```
// 触发震动
void trigger_shake(float intensity, float duration) {
    shake_intensity = intensity;
    shake_duration = duration;
    shake_timer = duration;
}

// 每帧更新
void update_shake(float dt) {
    if (shake_timer > 0) {
        shake_timer -= dt;
        float t = 1 - shake_timer / shake_duration;  // 0~1
        float decay = expf(-t * 5);  // 指数衰减
        float current = shake_intensity * decay;
        shake_offset.x = (rand() % 200 - 100) / 100.0f * current;
        shake_offset.y = (rand() % 200 - 100) / 100.0f * current;
    } else {
        shake_offset = {0, 0};
    }
}
```

**震动的方向**：

- **全向震动**：随机方向，模拟爆炸。
- **定向震动**：固定方向，模拟撞击（如向撞击方向偏移）。
- **轴向震动**：仅水平或垂直，模拟地震。

**震动的频率**：

高频震动（每帧随机）显得"嘈杂"，低频震动（缓变方向）显得"沉重"。可用 Perlin 噪声生成平滑的震动方向：

```
shake_offset.x = perlin_noise(time * frequency) * intensity;
shake_offset.y = perlin_noise(time * frequency + 100) * intensity;
```

**震动与逻辑分离**：

震动偏移只影响渲染，不影响镜头逻辑位置：

```
logic_position = follow(target);
render_position = logic_position + shake_offset;
```

这避免震动干扰跟随逻辑。

**震动的限制**：

- **最大强度**：避免过大导致玩家迷失。
- **最大时长**：通常 < 0.5 秒，避免疲劳。
- **可关闭**：提供"减少震动"选项，照顾敏感玩家。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct Camera {
    float x, y;           // 逻辑位置
    float shake_x, shake_y;  // 震动偏移
    float shake_intensity = 0;
    float shake_timer = 0;
    float shake_duration = 0;
    int screen_w, screen_h;

    void trigger_shake(float intensity, float duration) {
        shake_intensity = intensity;
        shake_duration = duration;
        shake_timer = duration;
    }

    void follow(float target_x, float target_y, float dt) {
        float t = 1.0f - expf(-5.0f * dt);
        x += (target_x - x) * t;
        y += (target_y - y) * t;

        // 更新震动
        if (shake_timer > 0) {
            shake_timer -= dt;
            float progress = 1.0f - shake_timer / shake_duration;
            float decay = expf(-progress * 5.0f);
            float current = shake_intensity * decay;
            shake_x = (rand() % 200 - 100) / 100.0f * current;
            shake_y = (rand() % 200 - 100) / 100.0f * current;
        } else {
            shake_x = 0;
            shake_y = 0;
        }
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        // 渲染时加震动偏移
        sx = wx - x - shake_x + screen_w / 2.0f;
        sy = wy - y - shake_y + screen_h / 2.0f;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Camera Shake",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 0, 0, 0, 0, 0, 800, 600 };

    float player_x = 0, player_y = 0;
    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN) {
                if (e.key.keysym.sym == SDLK_1) cam.trigger_shake(5, 0.3);   // 轻震
                if (e.key.keysym.sym == SDLK_2) cam.trigger_shake(15, 0.5);  // 中震
                if (e.key.keysym.sym == SDLK_3) cam.trigger_shake(30, 0.8);  // 强震
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 200;
        if (keys[SDL_SCANCODE_LEFT])  player_x -= speed * dt;
        if (keys[SDL_SCANCODE_RIGHT]) player_x += speed * dt;
        if (keys[SDL_SCANCODE_UP])    player_y -= speed * dt;
        if (keys[SDL_SCANCODE_DOWN])  player_y += speed * dt;

        cam.follow(player_x, player_y, dt);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_Rect pr = { (int)px - 15, (int)py - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &pr);

        // 震动强度指示
        if (cam.shake_timer > 0) {
            float intensity = cam.shake_intensity * expf(-(1 - cam.shake_timer / cam.shake_duration) * 5);
            SDL_SetRenderDrawColor(renderer, 255, 100, 100, 255);
            SDL_Rect bar = { 10, 10, (int)(intensity * 5), 10 };
            SDL_RenderFillRect(renderer, &bar);
        }

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 镜头震动用随机偏移模拟冲击，强度指数衰减。
- **衰减**：`decay = exp(-t * 5)`，快速达到峰值后衰减。
- **方向**：全向（爆炸）、定向（撞击）、轴向（地震）。
- **逻辑与渲染分离**：震动只影响渲染位置，不影响跟随逻辑。
- **限制**：最大强度、最大时长、可关闭选项。
- **应用场景**：爆炸、受击、地震、Boss 技能、冲刺。
- **常见坑**：震动过度导致眩晕；震动影响跟随导致抖动传染。

## 第 15 讲 · 镜头偏移与倾斜

### 概念

**镜头偏移（Camera Offset）** 让镜头中心偏离目标，产生"歪斜"效果。偏移用于：冲刺时镜头前倾、受击时镜头后仰、特殊技能的镜头摆动。

**镜头倾斜（Camera Tilt）** 让镜头旋转一个角度，产生"歪头"效果。倾斜用于：眩晕状态、特殊氛围、漫画感表达。

### 原理

**镜头偏移的实现**：

```
render_position = logic_position + offset
```

偏移是额外的位移，不影响跟随逻辑。偏移可动态变化：

```
// 冲刺时镜头前倾
if (dashing) {
    target_offset = dash_direction * 50;
}
offset = lerp(offset, target_offset, 0.1);
```

**镜头倾斜的实现**：

```
screen_pos = rotate(world_pos - camera_pos, tilt_angle) + screen_center
```

倾斜需在坐标变换中加入旋转矩阵。

**偏移与倾斜的组合**：

```
// 受击时镜头后仰 + 倾斜
if (hit) {
    target_offset = -hit_direction * 30;
    target_tilt = hit_direction.x > 0 ? -0.05 : 0.05;  // 弧度
}
```

**倾斜的限制**：

倾斜角度通常很小（< 10°），过大导致眩晕与方向感丧失。倾斜应快速恢复：

```
tilt = lerp(tilt, 0, 0.1);  // 逐渐回正
```

**偏移的应用场景**：

1. **冲刺前倾**：冲刺时镜头向冲刺方向偏移，增强速度感。
2. **受击后仰**：受击时镜头向受击方向反方向偏移，表现冲击。
3. **瞄准偏移**：射击游戏镜头偏向瞄准方向。
4. **呼吸效果**：镜头轻微上下浮动，模拟呼吸（待机状态）。

**倾斜的应用场景**：

1. **眩晕状态**：镜头倾斜 + 摇晃，表现角色眩晕。
2. **特殊技能**：技能释放时镜头倾斜，增加表现力。
3. **过场动画**：倾斜镜头产生戏剧感。
4. **漫画感**：受击瞬间镜头倾斜 + 缩放，模仿漫画分镜。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct Camera {
    float x, y;
    float offset_x = 0, offset_y = 0;
    float target_offset_x = 0, target_offset_y = 0;
    float tilt = 0;           // 倾斜角度（弧度）
    float target_tilt = 0;
    int screen_w, screen_h;

    void follow(float target_x, float target_y, float dt) {
        float t = 1.0f - expf(-5.0f * dt);
        x += (target_x - x) * t;
        y += (target_y - y) * t;

        // 平滑偏移与倾斜
        offset_x += (target_offset_x - offset_x) * 0.1f;
        offset_y += (target_offset_y - offset_y) * 0.1f;
        tilt += (target_tilt - tilt) * 0.1f;
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        // 相对镜头的位置
        float dx = wx - x - offset_x;
        float dy = wy - y - offset_y;
        // 旋转（倾斜）
        float cos_t = cosf(tilt), sin_t = sinf(tilt);
        float rx = dx * cos_t - dy * sin_t;
        float ry = dx * sin_t + dy * cos_t;
        sx = rx + screen_w / 2.0f;
        sy = ry + screen_h / 2.0f;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Offset & Tilt",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 0, 0, 0, 0, 0, 0, 800, 600 };

    float player_x = 0, player_y = 0;
    float player_vx = 0;
    bool dashing = false;
    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN) {
                if (e.key.keysym.sym == SDLK_LSHIFT) dashing = true;
                if (e.key.keysym.sym == SDLK_1) {  // 受击
                    cam.target_offset_x = -30;
                    cam.target_tilt = -0.05f;
                }
            }
            if (e.type == SDL_KEYUP && e.key.keysym.sym == SDLK_LSHIFT) dashing = false;
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = dashing ? 600 : 200;
        float target_vx = 0;
        if (keys[SDL_SCANCODE_LEFT])  target_vx = -speed;
        if (keys[SDL_SCANCODE_RIGHT]) target_vx = speed;

        player_vx += (target_vx - player_vx) * 0.2f;
        player_x += player_vx * dt;

        // 冲刺时镜头前倾
        if (dashing && fabsf(player_vx) > 50) {
            cam.target_offset_x = player_vx > 0 ? 50 : -50;
            cam.target_tilt = player_vx > 0 ? 0.03f : -0.03f;
        } else {
            cam.target_offset_x = 0;
            cam.target_tilt = 0;
        }

        cam.follow(player_x, player_y, dt);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_Rect pr = { (int)px - 15, (int)py - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &pr);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 镜头偏移让镜头中心偏离目标，增强速度感与冲击感。
- 镜头倾斜旋转镜头，表现眩晕或戏剧感。
- 偏移与倾斜都应平滑过渡，快速恢复。
- **倾斜限制**：< 10°，避免眩晕。
- **应用场景**：冲刺前倾、受击后仰、眩晕倾斜、漫画感分镜。
- **常见坑**：倾斜过大导致方向感丧失；偏移不恢复导致镜头永久偏移。

## 第 16 讲 · 缓动函数与时间曲线

### 概念

**缓动函数（Easing Function）** 定义值随时间变化的曲线——线性、加速、减速、弹性、回弹。缓动让镜头运动有"性格"——线性生硬，缓入缓出自然，弹性活泼，回弹俏皮。

**时间曲线（Timing Curve）** 是缓动的可视化表示，横轴时间，纵轴进度。不同曲线产生不同感觉：线性机械、缓入缓出自然、缓入重、缓出轻。

### 原理

**常见缓动函数**：

1. **线性（Linear）**：`t`，匀速，机械感。
2. **缓入（Ease In）**：`t²`，开始慢后快，沉重感。
3. **缓出（Ease Out）**：`1-(1-t)²`，开始快后慢，轻盈感。
4. **缓入缓出（Ease In Out）**：`t²(3-2t)`，两端慢中间快，自然感。
5. **弹性（Elastic）**：振荡衰减，活泼感。
6. **回弹（Bounce）**：多次反弹，俏皮感。
7. **Back**：略微过冲后回正，强调感。

**缓动函数的数学**：

```
// 线性
float linear(float t) { return t; }

// 二次缓入
float ease_in_quad(float t) { return t * t; }

// 二次缓出
float ease_out_quad(float t) { return 1 - (1 - t) * (1 - t); }

// 二次缓入缓出
float ease_in_out_quad(float t) {
    return t < 0.5f ? 2 * t * t : 1 - pow(-2 * t + 2, 2) / 2;
}

// 三次缓入缓出（更平滑）
float ease_in_out_cubic(float t) {
    return t < 0.5f ? 4 * t * t * t : 1 - pow(-2 * t + 2, 3) / 2;
}

// 弹性
float ease_elastic(float t) {
    if (t == 0 || t == 1) return t;
    return pow(2, -10 * t) * sin((t - 0.075) * (2 * M_PI) / 0.3) + 1;
}

// 回弹
float ease_bounce(float t) {
    if (t < 1/2.75) return 7.5625 * t * t;
    else if (t < 2/2.75) { t -= 1.5/2.75; return 7.5625 * t * t + 0.75; }
    else if (t < 2.5/2.75) { t -= 2.25/2.75; return 7.5625 * t * t + 0.9375; }
    else { t -= 2.625/2.75; return 7.5625 * t * t + 0.984375; }
}
```

**缓动的应用**：

```
// 镜头从 A 移动到 B，持续 1 秒，用缓出
float t = elapsed_time / duration;  // 0~1
t = clamp(t, 0, 1);
float eased_t = ease_out_quad(t);
position = lerp(A, B, eased_t);
```

**选择缓动的原则**：

| 场景 | 推荐缓动 | 原因 |
|------|---------|------|
| 镜头跟随 | 线性或缓出 | 自然 |
| UI 弹出 | 缓出或 Back | 轻盈 |
| UI 关闭 | 缓入 | 自然消失 |
| 过场动画 | 缓入缓出 | 电影感 |
| 弹跳效果 | Bounce | 俏皮 |
| 强调效果 | Elastic | 活泼 |
| 受击反馈 | 缓出 | 冲击 |

**缓动的时长**：

- **快速**（0.1~0.3 秒）：UI 反馈、受击。
- **中速**（0.3~0.8 秒）：镜头移动、过场。
- **慢速**（0.8~2 秒）：氛围营造、电影感。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

// 缓动函数
namespace Ease {
    float linear(float t) { return t; }
    float ease_in_quad(float t) { return t * t; }
    float ease_out_quad(float t) { return 1 - (1 - t) * (1 - t); }
    float ease_in_out_quad(float t) {
        return t < 0.5f ? 2 * t * t : 1 - pow(-2 * t + 2, 2) / 2;
    }
    float ease_out_cubic(float t) { return 1 - pow(1 - t, 3); }
    float ease_out_back(float t) {
        float c1 = 1.70158f, c3 = c1 + 1;
        return 1 + c3 * pow(t - 1, 3) + c1 * pow(t - 1, 2);
    }
    float ease_out_elastic(float t) {
        if (t == 0 || t == 1) return t;
        return pow(2, -10 * t) * sin((t - 0.075f) * (2 * M_PI) / 0.3f) + 1;
    }
    float ease_out_bounce(float t) {
        if (t < 1/2.75f) return 7.5625f * t * t;
        else if (t < 2/2.75f) { t -= 1.5f/2.75f; return 7.5625f * t * t + 0.75f; }
        else if (t < 2.5f/2.75f) { t -= 2.25f/2.75f; return 7.5625f * t * t + 0.9375f; }
        else { t -= 2.625f/2.75f; return 7.5625f * t * t + 0.984375f; }
    }
}

struct Camera {
    float x, y;
    int screen_w, screen_h;

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = wx - x + screen_w / 2.0f;
        sy = wy - y + screen_h / 2.0f;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Easing",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 800, 600 };

    // 镜头动画
    float start_x = 0, start_y = 0;
    float end_x = 500, end_y = 0;
    float duration = 2.0f;
    float elapsed = 0;
    int ease_mode = 0;  // 0~6

    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN) {
                if (e.key.keysym.sym >= SDLK_1 && e.key.keysym.sym <= SDLK_7) {
                    ease_mode = e.key.keysym.sym - SDLK_1;
                    elapsed = 0;  // 重新开始
                }
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        elapsed += dt;
        float t = std::clamp(elapsed / duration, 0.0f, 1.0f);

        // 应用缓动
        float eased_t;
        switch (ease_mode) {
            case 0: eased_t = Ease::linear(t); break;
            case 1: eased_t = Ease::ease_in_quad(t); break;
            case 2: eased_t = Ease::ease_out_quad(t); break;
            case 3: eased_t = Ease::ease_in_out_quad(t); break;
            case 4: eased_t = Ease::ease_out_cubic(t); break;
            case 5: eased_t = Ease::ease_out_back(t); break;
            case 6: eased_t = Ease::ease_out_bounce(t); break;
            default: eased_t = t;
        }

        cam.x = start_x + (end_x - start_x) * eased_t;
        cam.y = start_y + (end_y - start_y) * eased_t;

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 起点与终点标记
        float sx, sy;
        cam.world_to_screen(start_x, start_y, sx, sy);
        SDL_SetRenderDrawColor(renderer, 100, 255, 100, 255);
        SDL_Rect sr = { (int)sx - 10, (int)sy - 10, 20, 20 };
        SDL_RenderFillRect(renderer, &sr);

        cam.world_to_screen(end_x, end_y, sx, sy);
        SDL_SetRenderDrawColor(renderer, 255, 100, 100, 255);
        SDL_Rect er = { (int)sx - 10, (int)sy - 10, 20, 20 };
        SDL_RenderFillRect(renderer, &er);

        // 当前位置
        cam.world_to_screen(cam.x, cam.y, sx, sy);
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_Rect cr = { (int)sx - 15, (int)sy - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &cr);

        // 进度条
        SDL_SetRenderDrawColor(renderer, 255, 255, 0, 255);
        SDL_Rect bar = { 10, 10, (int)(eased_t * 200), 10 };
        SDL_RenderFillRect(renderer, &bar);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 缓动函数定义值随时间变化的曲线，赋予镜头运动"性格"。
- 常见缓动：线性、缓入、缓出、缓入缓出、Back、Elastic、Bounce。
- **选择**：跟随用线性/缓出，UI 用缓出/Back，过场用缓入缓出。
- **时长**：快速 0.1~0.3s，中速 0.3~0.8s，慢速 0.8~2s。
- **应用场景**：镜头移动、UI 动画、过场转场、受击反馈。
- **常见坑**：所有动画用线性导致机械感；缓动时长不当导致拖沓或突兀。

# 第 5 章 · 视角与投影

2D 游戏虽然本质是平面的，但通过视角技巧可以营造深度感与立体感。本章讲解三种视角技术：正交视角与缩放（经典 2D）、伪 3D 透视（用缩放模拟深度）、视差滚动（多层背景产生层次感）。掌握这些，你的 2D 游戏就能突破"平面"限制，营造丰富的空间感。

## 第 17 讲 · 正交视角与缩放

### 概念

**正交视角（Orthographic View）** 是 2D 游戏的默认视角——所有物体无论远近都同样大小，没有透视收缩。这是最简单也最"2D"的视角，适用于平台游戏、俯视游戏、横版动作。

**正交缩放（Orthographic Zoom）** 通过改变视野范围实现"放大/缩小"，但不引入透视效果——所有物体等比例缩放，远处的物体不会变小。

### 原理

**正交投影的特点**：

1. **平行线保持平行**：现实中的铁轨在远处汇聚，正交视角中铁轨永远平行。
2. **大小与距离无关**：远处物体与近处物体同样大小。
3. **无消失点**：没有透视的"消失点"，画面扁平。

**正交缩放的实现**：

```
screen_pos = (world_pos - camera_pos) * zoom + screen_center
```

zoom 改变所有物体的显示大小，但不改变它们的相对关系——远处物体仍与近处同样大小。

**正交视角的适用场景**：

- **平台游戏**（超级马里奥）：横版，所有物体等大。
- **俯视游戏**（塞尔达）：俯视，所有物体等大。
- **格斗游戏**（街头霸王）：固定视角，角色等大。
- **解谜游戏**（俄罗斯方块）：网格化，等大。

**正交视角的优势**：

1. **实现简单**：无需透视计算。
2. **玩法清晰**：物体大小一致，玩家容易判断距离与位置。
3. **性能高**：无透视除法，渲染快。
4. **美术友好**：精灵无需透视变形。

**正交视角的局限**：

1. **无深度感**：所有物体在同一平面，缺乏远近层次。
2. **无法表现"远近"**：远处的敌人与近处同样大，难以判断距离。
3. **视觉单调**：画面扁平，缺乏立体感。

为弥补这些局限，可用伪 3D 透视（下一讲）或视差滚动（第 19 讲）。

**正交缩放的应用**：

虽然正交视角无透视，但缩放仍可用于：

- **聚焦**：拉近聚焦关键物体。
- **氛围**：拉远营造孤独感。
- **适应**：根据屏幕尺寸调整视野。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct OrthoCamera {
    float x, y;
    float zoom = 1.0f;
    int screen_w, screen_h;

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = (wx - x) * zoom + screen_w / 2.0f;
        sy = (wy - y) * zoom + screen_h / 2.0f;
    }

    // 屏幕到世界（用于鼠标拾取）
    void screen_to_world(float sx, float sy, float& wx, float& wy) const {
        wx = (sx - screen_w / 2.0f) / zoom + x;
        wy = (sy - screen_h / 2.0f) / zoom + y;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Orthographic",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    OrthoCamera cam = { 0, 0, 1.0f, 800, 600 };

    float player_x = 0, player_y = 0;
    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_MOUSEWHEEL) {
                // 滚轮缩放
                cam.zoom *= (e.wheel.y > 0) ? 1.1f : 0.9f;
                cam.zoom = std::clamp(cam.zoom, 0.3f, 3.0f);
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 300;
        if (keys[SDL_SCANCODE_LEFT])  player_x -= speed * dt;
        if (keys[SDL_SCANCODE_RIGHT]) player_x += speed * dt;
        if (keys[SDL_SCANCODE_UP])    player_y -= speed * dt;
        if (keys[SDL_SCANCODE_DOWN])  player_y += speed * dt;

        // 镜头跟随
        float t = 1.0f - expf(-5.0f * dt);
        cam.x += (player_x - cam.x) * t;
        cam.y += (player_y - cam.y) * t;

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格（正交，所有网格等大）
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 不同"深度"的物体（正交视角下同样大小）
        for (int i = 0; i < 5; ++i) {
            float obj_x = i * 150 - 300;
            float obj_y = 0;
            float sx, sy;
            cam.world_to_screen(obj_x, obj_y, sx, sy);
            // 所有物体同样大小（正交特点）
            int size = (int)(40 * cam.zoom);
            SDL_SetRenderDrawColor(renderer, 100 + i * 30, 150, 200, 255);
            SDL_Rect r = { (int)sx - size/2, (int)sy - size/2, size, size };
            SDL_RenderFillRect(renderer, &r);
        }

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        int psize = (int)(30 * cam.zoom);
        SDL_Rect pr = { (int)px - psize/2, (int)py - psize/2, psize, psize };
        SDL_RenderFillRect(renderer, &pr);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 正交视角是 2D 默认视角，所有物体无论远近同样大小。
- 特点：平行线保持平行，大小与距离无关，无消失点。
- **适用**：平台、俯视、格斗、解谜游戏。
- **优势**：实现简单、玩法清晰、性能高。
- **局限**：无深度感、无法表现远近、视觉单调。
- **缩放**：改变视野范围，但不引入透视。

## 第 18 讲 · 伪 3D 透视（缩放深度）

### 概念

**伪 3D 透视（Pseudo-3D Perspective）** 在 2D 中用缩放模拟深度——离镜头"远"的物体缩小，"近"的物体放大。这不是真正的 3D 透视，但能营造立体感。

典型应用：赛车游戏（道路远端变窄）、RPG 的战斗视角（远处的敌人缩小）、纵版射击（远处的敌人小）。

### 原理

**伪 3D 的核心思想**：

给每个物体一个"深度"值 z，根据 z 缩放物体：

```
display_scale = base_scale / (1 + z * perspective_factor)
display_y = screen_y + z * y_offset  // 远的物体偏上（模拟地平线）
```

z=0 时物体在"前景"，原大小；z 越大物体越远，越小且越靠上。

**与真 3D 透视的区别**：

真 3D 透视用投影矩阵：

```
screen_x = world_x / world_z * focal_length
screen_y = world_y / world_z * focal_length
```

伪 3D 只缩放物体大小，不改变其屏幕位置（或简单偏移），计算更简单。

**伪 3D 的实现**：

```cpp
struct Pseudo3DObject {
    float world_x, world_y;  // 世界位置
    float depth;             // 深度（0=近，1=远）
};

void render(const Pseudo3DObject& obj, const Camera& cam) {
    float scale = 1.0f / (1.0f + obj.depth * 2.0f);  // 远的缩小
    float screen_x, screen_y;
    cam.world_to_screen(obj.world_x, obj.world_y, screen_x, screen_y);
    // 远的物体偏上（模拟地平线收缩）
    screen_y -= obj.depth * 100;

    int size = (int)(40 * scale);
    SDL_Rect r = { (int)screen_x - size/2, (int)screen_y - size/2, size, size };
    SDL_RenderFillRect(renderer, &r);
}
```

**深度排序**：

伪 3D 需按深度排序——远的先画，近的后画（覆盖远的）：

```
sort objects by depth (descending)
for each object: render(object)
```

**伪 3D 的应用场景**：

1. **赛车游戏**：道路远端变窄，营造速度感。
2. **RPG 战斗**：敌人排成前后排，后排缩小。
3. **纵版射击**：远处的敌人小，近处的大。
4. **格斗游戏**：角色前后移动时缩放。
5. **过场动画**：用伪 3D 营造电影感。

**伪 3D 的局限**：

1. **无真正的透视**：物体只是缩放，不会"消失"到地平线。
2. **碰撞复杂**：屏幕大小变化，但世界碰撞需用原始大小。
3. **美术工作量**：需为不同深度准备不同大小的精灵，或实时缩放（可能模糊）。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>
#include <vector>
#include <algorithm>

struct Camera {
    float x, y;
    int screen_w, screen_h;

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = wx - x + screen_w / 2.0f;
        sy = wy - y + screen_h / 2.0f;
    }
};

struct Pseudo3DObject {
    float world_x, world_y;
    float depth;  // 0=近，1=远
    Uint8 r, g, b;
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Pseudo 3D",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 800, 600 };

    // 创建不同深度的物体
    std::vector<Pseudo3DObject> objects;
    for (int i = 0; i < 10; ++i) {
        Pseudo3DObject obj;
        obj.world_x = (rand() % 800 - 400);
        obj.world_y = 0;
        obj.depth = i / 10.0f;  // 0~0.9
        obj.r = rand() % 200 + 50;
        obj.g = rand() % 200 + 50;
        obj.b = rand() % 200 + 50;
        objects.push_back(obj);
    }

    Uint32 last_time = SDL_GetTicks();
    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) if (e.type == SDL_QUIT) running = false;

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 300;
        if (keys[SDL_SCANCODE_LEFT])  cam.x -= speed * dt;
        if (keys[SDL_SCANCODE_RIGHT]) cam.x += speed * dt;
        if (keys[SDL_SCANCODE_UP])    cam.y -= speed * dt;
        if (keys[SDL_SCANCODE_DOWN])  cam.y += speed * dt;

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 地平线
        SDL_SetRenderDrawColor(renderer, 40, 50, 80, 255);
        SDL_Rect sky = { 0, 0, 800, 300 };
        SDL_RenderFillRect(renderer, &sky);
        SDL_SetRenderDrawColor(renderer, 60, 50, 40, 255);
        SDL_Rect ground = { 0, 300, 800, 300 };
        SDL_RenderFillRect(renderer, &ground);

        // 按深度排序（远到近）
        std::sort(objects.begin(), objects.end(),
                  [](const Pseudo3DObject& a, const Pseudo3DObject& b) {
                      return a.depth > b.depth;
                  });

        // 渲染物体（伪 3D 缩放）
        for (const auto& obj : objects) {
            float scale = 1.0f / (1.0f + obj.depth * 2.0f);
            float sx, sy;
            cam.world_to_screen(obj.world_x, obj.world_y, sx, sy);
            // 远的物体偏上（模拟地平线）
            sy -= obj.depth * 200;
            // 远的物体颜色偏暗（大气透视）
            Uint8 r = (Uint8)(obj.r * (1 - obj.depth * 0.5));
            Uint8 g = (Uint8)(obj.g * (1 - obj.depth * 0.5));
            Uint8 b = (Uint8)(obj.b * (1 - obj.depth * 0.5));

            int size = (int)(60 * scale);
            SDL_SetRenderDrawColor(renderer, r, g, b, 255);
            SDL_Rect rect = { (int)sx - size/2, (int)sy - size/2, size, size };
            SDL_RenderFillRect(renderer, &rect);
        }

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 伪 3D 用缩放模拟深度，远的物体小，近的物体大。
- `scale = 1 / (1 + depth * factor)`，depth 越大越远越小。
- **深度排序**：远的先画，近的后画。
- **大气透视**：远处物体颜色偏暗，模拟空气散射。
- **应用场景**：赛车、RPG 战斗、纵版射击、格斗。
- **局限**：无真正透视，碰撞需用原始大小。
- **常见坑**：缩放后碰撞检测错误；深度排序不稳定导致闪烁。

## 第 19 讲 · 视差滚动与层次感

### 概念

**视差滚动（Parallax Scrolling）** 是 2D 游戏营造深度感的最常用技术——多层背景以不同速度滚动，远的层慢，近的层快，产生立体错觉。

视差滚动让 2D 游戏有"空间感"——背景不是扁平的贴图，而是有层次的深度。这是《空洞骑士》《奥日》等美术精致的 2D 游戏的核心技术。

### 原理

**视差的基本原理**：

现实世界中，远处的物体移动慢，近处的移动快——坐火车时，远山缓慢移动，近树飞速掠过。视差滚动模拟这一现象：

```
layer_offset = camera_position * parallax_factor
```

`parallax_factor` 是视差系数：

- 0：层完全静止（最远的背景，如天空）。
- 0.5：层以一半速度滚动（远景，如山脉）。
- 1.0：层与镜头同步（游戏层，如地面）。
- > 1.0：层比镜头快（前景，如草丛）。

**视差层的组织**：

```
层 0：天空（factor = 0）      → 静止
层 1：远山（factor = 0.2）    → 很慢
层 2：中山（factor = 0.5）    → 慢
层 3：近景树（factor = 0.8）  → 较慢
层 4：游戏层（factor = 1.0）  → 正常
层 5：前景草（factor = 1.2）  → 快
```

**视差的实现**：

```cpp
struct ParallaxLayer {
    SDL_Texture* texture;
    float parallax_factor;
    float y_offset;  // 垂直偏移
};

void render_layer(const ParallaxLayer& layer, const Camera& cam) {
    float layer_x = cam.x * layer.parallax_factor;
    // 平铺纹理（如果纹理比屏幕窄）
    int tex_w;
    SDL_QueryTexture(layer.texture, nullptr, nullptr, &tex_w, nullptr);
    float offset = fmodf(layer_x, tex_w);
    for (int x = (int)offset - tex_w; x < screen_w; x += tex_w) {
        SDL_Rect dst = { x, (int)layer.y_offset, tex_w, ... };
        SDL_RenderCopy(renderer, layer.texture, nullptr, &dst);
    }
}
```

**视差的增强技巧**：

1. **大气透视**：远景用低饱和、偏蓝色，模拟空气散射。
2. **模糊**：远景略微模糊，模拟焦距。
3. **光照差异**：远景暗，近景亮。
4. **动态层**：云朵缓慢移动，水面波纹动画。

**视差的性能**：

视差层多会增加 Draw Call，但每层通常只需一次纹理绘制，开销不大。优化：

- 用纹理图集合并多层。
- 远景用低分辨率纹理。
- 限制视差层数（通常 3~5 层足够）。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct Camera {
    float x, y;
    int screen_w, screen_h;
};

struct ParallaxLayer {
    int color_r, color_g, color_b;
    float parallax_factor;
    int y_offset;
    int height;
    int spacing;  // 装饰物间距
};

void render_layer(SDL_Renderer* r, const ParallaxLayer& layer,
                  const Camera& cam) {
    float layer_x = cam.x * layer.parallax_factor;

    // 背景填充
    SDL_SetRenderDrawColor(r, layer.color_r, layer.color_g, layer.color_b, 255);
    SDL_Rect bg = { 0, layer.y_offset, cam.screen_w, layer.height };
    SDL_RenderFillRect(r, &bg);

    // 装饰物（按间距平铺）
    int start_x = (int)(-layer_x) % layer.spacing;
    if (start_x > 0) start_x -= layer.spacing;
    for (int x = start_x; x < cam.screen_w; x += layer.spacing) {
        // 绘制装饰物（简化为矩形）
        SDL_SetRenderDrawColor(r,
            layer.color_r + 30, layer.color_g + 30, layer.color_b + 30, 255);
        SDL_Rect deco = { x, layer.y_offset + 20, 30, layer.height - 20 };
        SDL_RenderFillRect(r, &deco);
    }
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Parallax",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 800, 600 };

    // 视差层（从远到近）
    ParallaxLayer layers[] = {
        { 30, 40, 80,  0.0f, 0,   200, 100 },  // 天空（静止）
        { 50, 60, 100, 0.2f, 100, 150, 120 },  // 远山
        { 70, 80, 80,  0.5f, 200, 150, 100 },  // 中山
        { 90, 100, 60, 0.8f, 300, 150, 80 },   // 近景树
        { 60, 50, 40,  1.0f, 450, 150, 60 },   // 地面
    };

    Uint32 last_time = SDL_GetTicks();
    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) if (e.type == SDL_QUIT) running = false;

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 300;
        if (keys[SDL_SCANCODE_LEFT])  cam.x -= speed * dt;
        if (keys[SDL_SCANCODE_RIGHT]) cam.x += speed * dt;

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 渲染视差层（远到近）
        for (const auto& layer : layers) {
            render_layer(renderer, layer, cam);
        }

        // 玩家（在地面层）
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_Rect player = { 400 - 15, 450 - 30, 30, 30 };
        SDL_RenderFillRect(renderer, &player);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 视差滚动用多层背景不同速度滚动，营造深度感。
- `layer_offset = camera * parallax_factor`，factor 0=静止，1=同步，>1=更快。
- 典型层次：天空(0) → 远山(0.2) → 中景(0.5) → 近景(0.8) → 游戏(1.0) → 前景(1.2)。
- **增强技巧**：大气透视、模糊、光照差异、动态层。
- **应用场景**：平台游戏、横版动作、射击游戏、过场。
- **性能**：3~5 层足够，用图集合并优化。
- **常见坑**：层数过多导致性能下降；视差系数设置不当导致层次混乱。

# 第 6 章 · 分屏与多镜头

多人游戏需要同时显示多个视角——双人分屏、画中画、小地图。本章讲解分屏与多镜头系统的实现：双人分屏（水平/垂直分割）、画中画与小地图（缩略视角）、动态镜头切换（多镜头间平滑过渡）。掌握这些，你就能支持多人游戏与复杂视角需求。

## 第 20 讲 · 双人分屏

### 概念

**双人分屏（Split Screen）** 把屏幕分为两个区域，每个玩家一个独立镜头。常见布局有水平分屏（左右各半，适合宽屏）和垂直分屏（上下各半，适合竖屏）。

分屏让两名玩家在同一台设备上同时游戏，是合作游戏（如《双人成行》）与对战游戏（如《马里奥赛车》）的标准配置。

### 原理

**分屏的实现**：

每个玩家有独立的镜头，渲染时把屏幕分为两个视口（viewport），各自渲染：

```
// 玩家 1 的视口（左半屏）
set_viewport(0, 0, screen_w/2, screen_h);
render_scene(camera1);

// 玩家 2 的视口（右半屏）
set_viewport(screen_w/2, 0, screen_w/2, screen_h);
render_scene(camera2);

// 恢复全屏视口
set_viewport(0, 0, screen_w, screen_h);
```

**视口（Viewport）** 是屏幕上的渲染区域。SDL2 用 `SDL_RenderSetClipRect` 设置裁剪矩形，限制渲染区域。

**分屏的镜头独立**：

每个镜头独立跟随各自玩家，有自己的位置、缩放、特效。两个镜头互不干扰。

**分屏的分隔线**：

两个视口之间通常有分隔线（黑色或装饰性边框），视觉上区分两个区域：

```
// 绘制分隔线
SDL_SetRenderDrawColor(renderer, 0, 0, 0, 255);
SDL_Rect divider = { screen_w/2 - 2, 0, 4, screen_h };
SDL_RenderFillRect(renderer, &divider);
```

**动态分屏（合并/分离）**：

高级分屏系统支持动态合并——两名玩家靠近时合并为单镜头，远离时分离为分屏：

```
float distance = sqrt((p1.x - p2.x)² + (p1.y - p2.y)²);
if (distance < merge_threshold) {
    // 单镜头，对准两人中点
    camera.target = (p1.pos + p2.pos) / 2;
    use_split = false;
} else {
    // 分屏
    use_split = true;
}
```

**分屏的过渡**：

合并/分离切换应平滑，避免突变。可用淡入淡出或缩放过渡。

**分屏的挑战**：

1. **视野缩小**：每个玩家只看到半个屏幕，视野受限。
2. **性能翻倍**：需渲染两次场景，性能开销大。
3. **UI 布局**：每个玩家的 UI 需适配半屏。
4. **跨屏交互**：玩家不能跨屏交互（除非动态合并）。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct Camera {
    float x, y;
    int viewport_x, viewport_y, viewport_w, viewport_h;

    void follow(float target_x, float target_y, float dt) {
        float t = 1.0f - expf(-5.0f * dt);
        x += (target_x - x) * t;
        y += (target_y - y) * t;
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = (wx - x) + viewport_x + viewport_w / 2.0f;
        sy = (wy - y) + viewport_y + viewport_h / 2.0f;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Split Screen",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    // 两个镜头（水平分屏）
    Camera cam1 = { 0, 0, 0, 0, 400, 600 };
    Camera cam2 = { 0, 0, 400, 0, 400, 600 };

    float p1_x = 0, p1_y = 0;
    float p2_x = 200, p2_y = 0;
    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) if (e.type == SDL_QUIT) running = false;

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 200;
        // 玩家 1：WASD
        if (keys[SDL_SCANCODE_A]) p1_x -= speed * dt;
        if (keys[SDL_SCANCODE_D]) p1_x += speed * dt;
        if (keys[SDL_SCANCODE_W]) p1_y -= speed * dt;
        if (keys[SDL_SCANCODE_S]) p1_y += speed * dt;
        // 玩家 2：方向键
        if (keys[SDL_SCANCODE_LEFT])  p2_x -= speed * dt;
        if (keys[SDL_SCANCODE_RIGHT]) p2_x += speed * dt;
        if (keys[SDL_SCANCODE_UP])    p2_y -= speed * dt;
        if (keys[SDL_SCANCODE_DOWN])  p2_y += speed * dt;

        cam1.follow(p1_x, p1_y, dt);
        cam2.follow(p2_x, p2_y, dt);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 渲染玩家 1 的视口（左半）
        SDL_Rect clip1 = { 0, 0, 400, 600 };
        SDL_RenderSetClipRect(renderer, &clip1);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam1.world_to_screen(g, -2000, sx1, sy1);
            cam1.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam1.world_to_screen(-2000, g, sx1, sy1);
            cam1.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 玩家 1
        float p1sx, p1sy;
        cam1.world_to_screen(p1_x, p1_y, p1sx, p1sy);
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect r1 = { (int)p1sx - 15, (int)p1sy - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &r1);

        // 渲染玩家 2 的视口（右半）
        SDL_Rect clip2 = { 400, 0, 400, 600 };
        SDL_RenderSetClipRect(renderer, &clip2);

        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam2.world_to_screen(g, -2000, sx1, sy1);
            cam2.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam2.world_to_screen(-2000, g, sx1, sy1);
            cam2.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        float p2sx, p2sy;
        cam2.world_to_screen(p2_x, p2_y, p2sx, p2sy);
        SDL_SetRenderDrawColor(renderer, 255, 150, 100, 255);
        SDL_Rect r2 = { (int)p2sx - 15, (int)p2sy - 15, 30, 30 };
        SDL_RenderFillRect(renderer, &r2);

        // 取消裁剪，绘制分隔线
        SDL_RenderSetClipRect(renderer, nullptr);
        SDL_SetRenderDrawColor(renderer, 0, 0, 0, 255);
        SDL_Rect divider = { 398, 0, 4, 600 };
        SDL_RenderFillRect(renderer, &divider);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 双人分屏把屏幕分为两个视口，每个玩家独立镜头。
- 用 `SDL_RenderSetClipRect` 设置裁剪矩形限制渲染区域。
- **动态分屏**：玩家靠近时合并单镜头，远离时分屏。
- **挑战**：视野缩小、性能翻倍、UI 适配、跨屏交互。
- **应用场景**：合作游戏、对战游戏、本地多人。
- **常见坑**：忘记取消裁剪导致后续渲染被限制；分隔线位置错误。

## 第 21 讲 · 画中画与小地图

### 概念

**画中画（Picture-in-Picture, PiP）** 在主画面上叠加一个小窗口，显示另一个视角。常见用途：监控摄像头、回放、副视角。

**小地图（Minimap）** 是画中画的特殊形式——缩略显示整个地图，标注玩家、敌人、目标位置。小地图是开放世界游戏（如《塞尔达》《GTA》）的标配。

### 原理

**画中画的实现**：

主画面正常渲染，然后在屏幕一角叠加一个小视口，用独立镜头渲染：

```
// 1. 渲染主画面
render_main_scene(main_camera);

// 2. 渲染画中画（小窗口）
SDL_Rect pip_rect = { screen_w - 200, 20, 180, 180 };
SDL_RenderSetClipRect(renderer, &pip_rect);
render_scene(pip_camera);
SDL_RenderSetClipRect(renderer, nullptr);

// 3. 绘制边框
SDL_RenderDrawRect(renderer, &pip_rect);
```

**小地图的实现**：

小地图通常是俯视图，把整个世界缩放到小窗口：

```
struct Minimap {
    float world_x, world_y;    // 小地图对应的世界区域
    float world_w, world_h;
    int screen_x, screen_y;    // 小地图屏幕位置
    int screen_w, screen_h;

    void world_to_minimap(float wx, float wy, float& mx, float& my) {
        mx = (wx - world_x) / world_w * screen_w + screen_x;
        my = (wy - world_y) / world_h * screen_h + screen_y;
    }
};
```

**小地图的标注**：

小地图上标注重要物体（玩家、敌人、目标）：

```
// 玩家（中心点）
draw_dot(minimap.world_to_minimap(player.pos), white);

// 敌人（红点）
for (enemy : enemies)
    draw_dot(minimap.world_to_minimap(enemy.pos), red);

// 目标（黄星）
draw_star(minimap.world_to_minimap(objective.pos), yellow);
```

**小地图的视野指示**：

主镜头的可见范围在小地图上用矩形或扇形标注，让玩家知道当前看到的是地图的哪部分：

```
// 绘制镜头视野矩形
SDL_Rect view_rect = {
    minimap.world_to_minimap_x(camera.x - screen_w/2),
    minimap.world_to_minimap_y(camera.y - screen_h/2),
    screen_w / world_w * minimap.screen_w,
    screen_h / world_h * minimap.screen_h
};
SDL_RenderDrawRect(renderer, &view_rect);
```

**小地图的旋转**：

某些游戏的小地图随玩家朝向旋转（玩家始终朝上），需旋转换算：

```
// 相对玩家的位置
dx = world_x - player.x
dy = world_y - player.y
// 旋转（玩家朝向为上）
rotated_x = dx * cos(-player.angle) - dy * sin(-player.angle)
rotated_y = dx * sin(-player.angle) + dy * cos(-player.angle)
// 映射到小地图
mx = minimap_center_x + rotated_x * scale
my = minimap_center_y - rotated_y * scale  // Y 翻转（朝上）
```

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

struct Camera {
    float x, y;
    int screen_w, screen_h;

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = wx - x + screen_w / 2.0f;
        sy = wy - y + screen_h / 2.0f;
    }
};

struct Minimap {
    float world_x = -1000, world_y = -1000;
    float world_w = 2000, world_h = 2000;
    int screen_x = 600, screen_y = 20;
    int screen_w = 180, screen_h = 180;

    void world_to_minimap(float wx, float wy, float& mx, float& my) const {
        mx = (wx - world_x) / world_w * screen_w + screen_x;
        my = (wy - world_y) / world_h * screen_h + screen_y;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Minimap",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 800, 600 };
    Minimap minimap;

    float player_x = 0, player_y = 0;
    Uint32 last_time = SDL_GetTicks();

    // 一些敌人
    struct Enemy { float x, y; };
    std::vector<Enemy> enemies = {
        {200, 100}, {-150, 200}, {300, -100}, {-200, -200}, {100, 300}
    };

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) if (e.type == SDL_QUIT) running = false;

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 300;
        if (keys[SDL_SCANCODE_LEFT])  player_x -= speed * dt;
        if (keys[SDL_SCANCODE_RIGHT]) player_x += speed * dt;
        if (keys[SDL_SCANCODE_UP])    player_y -= speed * dt;
        if (keys[SDL_SCANCODE_DOWN])  player_y += speed * dt;

        cam.x += (player_x - cam.x) * 0.1f;
        cam.y += (player_y - cam.y) * 0.1f;

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 主画面：网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 敌人
        for (const auto& en : enemies) {
            float ex, ey;
            cam.world_to_screen(en.x, en.y, ex, ey);
            if (ex > -20 && ex < 820 && ey > -20 && ey < 620) {
                SDL_SetRenderDrawColor(renderer, 255, 80, 80, 255);
                SDL_Rect r = { (int)ex - 8, (int)ey - 8, 16, 16 };
                SDL_RenderFillRect(renderer, &r);
            }
        }

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect pr = { (int)px - 10, (int)py - 10, 20, 20 };
        SDL_RenderFillRect(renderer, &pr);

        // 小地图背景
        SDL_SetRenderDrawColor(renderer, 0, 0, 0, 200);
        SDL_Rect mm_bg = { minimap.screen_x - 2, minimap.screen_y - 2,
                           minimap.screen_w + 4, minimap.screen_h + 4 };
        SDL_RenderFillRect(renderer, &mm_bg);

        SDL_SetRenderDrawColor(renderer, 30, 40, 50, 255);
        SDL_Rect mm_rect = { minimap.screen_x, minimap.screen_y,
                             minimap.screen_w, minimap.screen_h };
        SDL_RenderFillRect(renderer, &mm_rect);

        // 小地图网格
        SDL_SetRenderDrawColor(renderer, 60, 70, 80, 255);
        for (int g = 0; g <= 4; ++g) {
            int x = minimap.screen_x + g * minimap.screen_w / 4;
            int y = minimap.screen_y + g * minimap.screen_h / 4;
            SDL_RenderDrawLine(renderer, x, minimap.screen_y,
                                        x, minimap.screen_y + minimap.screen_h);
            SDL_RenderDrawLine(renderer, minimap.screen_x, y,
                                        minimap.screen_x + minimap.screen_w, y);
        }

        // 小地图上的敌人
        for (const auto& en : enemies) {
            float mx, my;
            minimap.world_to_minimap(en.x, en.y, mx, my);
            if (mx >= minimap.screen_x && mx < minimap.screen_x + minimap.screen_w &&
                my >= minimap.screen_y && my < minimap.screen_y + minimap.screen_h) {
                SDL_SetRenderDrawColor(renderer, 255, 80, 80, 255);
                SDL_Rect r = { (int)mx - 2, (int)my - 2, 4, 4 };
                SDL_RenderFillRect(renderer, &r);
            }
        }

        // 小地图上的玩家
        float pmx, pmy;
        minimap.world_to_minimap(player_x, player_y, pmx, pmy);
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect pmr = { (int)pmx - 3, (int)pmy - 3, 6, 6 };
        SDL_RenderFillRect(renderer, &pmr);

        // 小地图上的镜头视野
        float vx1, vy1;
        minimap.world_to_minimap(cam.x - 400, cam.y - 300, vx1, vy1);
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 150);
        SDL_Rect view = { (int)vx1, (int)vy1,
                          (int)(800.0f / minimap.world_w * minimap.screen_w),
                          (int)(600.0f / minimap.world_h * minimap.screen_h) };
        SDL_RenderDrawRect(renderer, &view);

        // 小地图边框
        SDL_SetRenderDrawColor(renderer, 200, 200, 200, 255);
        SDL_RenderDrawRect(renderer, &mm_rect);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 画中画在主画面叠加小窗口，显示另一视角。
- 小地图是俯视缩略图，标注玩家、敌人、目标。
- **视野指示**：在小地图上标注主镜头可见范围。
- **旋转小地图**：玩家始终朝上，需旋转换算。
- **应用场景**：开放世界、RTS、RPG、监控。
- **常见坑**：小地图过小看不清；标注过多导致混乱。

## 第 22 讲 · 动态镜头切换

### 概念

**动态镜头切换（Dynamic Camera Switching）** 在多个预设镜头间平滑切换。不同于分屏（同时显示多镜头），动态切换是**时序切换**——某一时刻只显示一个镜头，但可在镜头间平滑过渡。

典型应用：过场动画（镜头切换不同视角）、Boss 战（镜头切换聚焦 Boss）、解谜（镜头切换到谜题区域）。

### 原理

**镜头预设（Camera Preset）**：

每个预设定义镜头的位置、朝向、缩放等参数：

```cpp
struct CameraPreset {
    Vec2 position;
    float zoom;
    float rotation;
    float duration;  // 停留时间
};
```

**镜头切换的方式**：

1. **硬切（Cut）**：瞬间切换，无过渡。适合快速剪辑。
2. **淡入淡出（Fade）**：当前镜头淡出，新镜头淡入。
3. **插值过渡（Tween）**：在一段时间内平滑插值到新镜头。
4. **聚焦过渡（Focus Pull）**：保持位置，改变焦点与缩放。

**插值过渡的实现**：

```cpp
struct CameraTransition {
    CameraPreset from;
    CameraPreset to;
    float elapsed;
    float duration;
    EaseFunction ease;

    void update(float dt) {
        elapsed += dt;
        float t = clamp(elapsed / duration, 0, 1);
        float eased_t = ease(t);
        current.position = lerp(from.position, to.position, eased_t);
        current.zoom = lerp(from.zoom, to.zoom, eased_t);
    }
};
```

**镜头序列（Camera Sequence）**：

过场动画由多个预设组成序列，按时间播放：

```cpp
struct CameraSequence {
    std::vector<CameraPreset> presets;
    int current_index = 0;
    float timer = 0;

    void update(float dt) {
        timer += dt;
        if (timer >= presets[current_index].duration) {
            timer = 0;
            current_index = (current_index + 1) % presets.size();
            // 触发过渡
        }
    }
};
```

**触发式切换**：

根据游戏事件触发镜头切换：

- 进入区域 → 切换到区域镜头。
- Boss 出现 → 切换到 Boss 特写。
- 解谜完成 → 切换到解谜结果镜头。

**切换的时机**：

- **玩家可控时**：避免切换，保持跟随。
- **过场动画时**：接管镜头，按脚本切换。
- **特殊事件时**：短暂切换后回归。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>
#include <vector>

struct CameraPreset {
    float x, y;
    float zoom;
    float duration;
    const char* name;
};

float ease_in_out(float t) {
    return t < 0.5f ? 2 * t * t : 1 - pow(-2 * t + 2, 2) / 2;
}

struct Camera {
    float x, y;
    float zoom = 1.0f;
    int screen_w, screen_h;

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = (wx - x) * zoom + screen_w / 2.0f;
        sy = (wy - y) * zoom + screen_h / 2.0f;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Camera Switch",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam = { 0, 0, 1.0f, 800, 600 };

    // 镜头预设序列
    std::vector<CameraPreset> presets = {
        { 0, 0, 1.0f, 3.0f, "全景" },
        { 200, 100, 1.5f, 2.0f, "近景 A" },
        { -200, -100, 2.0f, 2.0f, "特写 B" },
        { 0, 0, 0.7f, 3.0f, "远景" },
    };

    int current_preset = 0;
    int next_preset = 1;
    float transition_time = 0;
    float transition_duration = 1.0f;
    bool in_transition = true;

    Uint32 last_time = SDL_GetTicks();
    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN && e.key.keysym.sym == SDLK_SPACE) {
                // 手动切换到下一个
                current_preset = next_preset;
                next_preset = (next_preset + 1) % presets.size();
                transition_time = 0;
                in_transition = true;
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        if (in_transition) {
            transition_time += dt;
            float t = std::clamp(transition_time / transition_duration, 0.0f, 1.0f);
            float eased_t = ease_in_out(t);

            cam.x = presets[current_preset].x + (presets[next_preset].x - presets[current_preset].x) * eased_t;
            cam.y = presets[current_preset].y + (presets[next_preset].y - presets[current_preset].y) * eased_t;
            cam.zoom = presets[current_preset].zoom + (presets[next_preset].zoom - presets[current_preset].zoom) * eased_t;

            if (t >= 1.0f) {
                in_transition = false;
                current_preset = next_preset;
            }
        }

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 标记点
        for (size_t i = 0; i < presets.size(); ++i) {
            float sx, sy;
            cam.world_to_screen(presets[i].x, presets[i].y, sx, sy);
            SDL_SetRenderDrawColor(renderer,
                i == current_preset ? 255 : 100,
                i == current_preset ? 255 : 100,
                i == current_preset ? 100 : 100, 255);
            int size = (i == current_preset) ? 20 : 12;
            SDL_Rect r = { (int)sx - size/2, (int)sy - size/2, size, size };
            SDL_RenderFillRect(renderer, &r);
        }

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 动态镜头切换在多个预设镜头间平滑过渡。
- 切换方式：硬切、淡入淡出、插值过渡、聚焦过渡。
- **镜头序列**：过场动画按时间播放多个预设。
- **触发式切换**：根据游戏事件（区域、Boss、解谜）触发。
- **应用场景**：过场动画、Boss 战、解谜、剧情。
- **常见坑**：切换过频繁导致眩晕；过渡时间不当导致拖沓。

# 第 7 章 · 过渡与转场

场景切换是游戏的常见需求——进入新关卡、触发剧情、打开菜单。直接切换会显得突兀，过渡与转场让切换平滑自然。本章讲解三种转场技术：淡入淡出与遮罩（经典电影转场）、滑动与推动转场（空间感转场）、聚焦切换与镜头动画（电影感转场）。掌握这些，你的游戏场景切换就能像电影一样流畅专业。

## 第 23 讲 · 淡入淡出与遮罩

### 概念

**淡入淡出（Fade In/Out）** 是最经典的转场——画面逐渐变黑（淡出），然后从黑色逐渐显现新画面（淡入）。简单、优雅、通用，适用于几乎所有场景切换。

**遮罩转场（Mask Transition）** 用一张遮罩图控制转场——遮罩的亮度决定哪些区域先显现，产生渐变、形状、溶解等效果。

### 原理

**淡入淡出的实现**：

用一个全屏黑色矩形，控制其 Alpha 值：

```
// 淡出：alpha 从 0 增加到 255
// 淡入：alpha 从 255 减少到 0

enum FadeState { IDLE, FADING_OUT, FADING_IN };
FadeState state = IDLE;
float alpha = 0;
float fade_speed = 500;  // 每秒 alpha 变化量

void update(float dt) {
    if (state == FADING_OUT) {
        alpha += fade_speed * dt;
        if (alpha >= 255) {
            alpha = 255;
            state = FADING_IN;
            // 在此处切换场景
            switch_scene();
        }
    } else if (state == FADING_IN) {
        alpha -= fade_speed * dt;
        if (alpha <= 0) {
            alpha = 0;
            state = IDLE;
        }
    }
}

void render() {
    render_scene();
    if (alpha > 0) {
        SDL_SetRenderDrawColor(renderer, 0, 0, 0, (Uint8)alpha);
        SDL_SetRenderDrawBlendMode(renderer, SDL_BLENDMODE_BLEND);
        SDL_Rect full = { 0, 0, screen_w, screen_h };
        SDL_RenderFillRect(renderer, &full);
    }
}
```

**淡入淡出的颜色**：

虽然黑色最常见，但也可用其他颜色：

- **白色**：梦境、回忆、闪光。
- **红色**：死亡、危险、愤怒。
- **主题色**：与游戏风格一致。

**淡入淡出的时长**：

- **快速**（0.3~0.5 秒）：场景内切换、菜单。
- **中速**（0.5~1.0 秒）：关卡切换。
- **慢速**（1.0~2.0 秒）：剧情转场、章节切换。

**遮罩转场**：

遮罩是一张灰度图，亮度决定转场顺序——亮的区域先显现，暗的区域后显现：

```
// 遮罩转场
for each pixel (x, y):
    mask_value = mask[x, y]  // 0~255
    if transition_progress > mask_value / 255:
        show new_scene[x, y]
    else:
        show old_scene[x, y]
```

**遮罩的形状**：

- **径向遮罩**：从中心向外扩散（圆形展开）。
- **线性遮罩**：从一侧到另一侧（滑动）。
- **噪声遮罩**：随机像素显现（溶解）。
- **形状遮罩**：特定形状（如星形、心形）展开。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

enum FadeState { IDLE, FADING_OUT, FADING_IN };

struct Transition {
    FadeState state = IDLE;
    float alpha = 0;
    float speed = 500;  // alpha 每秒变化量
    Uint8 r = 0, g = 0, b = 0;  // 淡入淡出颜色
    bool scene_switched = false;

    void start() {
        state = FADING_OUT;
        alpha = 0;
        scene_switched = false;
    }

    void update(float dt) {
        if (state == FADING_OUT) {
            alpha += speed * dt;
            if (alpha >= 255) {
                alpha = 255;
                state = FADING_IN;
                scene_switched = true;  // 信号：切换场景
            }
        } else if (state == FADING_IN) {
            alpha -= speed * dt;
            if (alpha <= 0) {
                alpha = 0;
                state = IDLE;
            }
        }
    }

    void render(SDL_Renderer* renderer) {
        if (alpha > 0) {
            SDL_SetRenderDrawBlendMode(renderer, SDL_BLENDMODE_BLEND);
            SDL_SetRenderDrawColor(renderer, r, g, b, (Uint8)alpha);
            SDL_Rect full = { 0, 0, 800, 600 };
            SDL_RenderFillRect(renderer, &full);
        }
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Fade Transition",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Transition transition;
    int scene = 0;  // 0 或 1
    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN && e.key.keysym.sym == SDLK_SPACE) {
                if (transition.state == IDLE) {
                    transition.start();
                }
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        transition.update(dt);
        if (transition.scene_switched) {
            scene = 1 - scene;  // 切换场景
            transition.scene_switched = false;
        }

        // 渲染当前场景
        if (scene == 0) {
            SDL_SetRenderDrawColor(renderer, 40, 60, 100, 255);  // 蓝色场景
        } else {
            SDL_SetRenderDrawColor(renderer, 100, 60, 40, 255);  // 橙色场景
        }
        SDL_RenderClear(renderer);

        // 场景内容
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_Rect obj = { 400 - 30, 300 - 30, 60, 60 };
        SDL_RenderFillRect(renderer, &obj);

        // 渲染转场遮罩
        transition.render(renderer);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 淡入淡出用全屏矩形控制 Alpha，经典且通用。
- 淡出（alpha 增）→ 切换场景 → 淡入（alpha 减）。
- **颜色**：黑（默认）、白（梦境）、红（死亡）、主题色。
- **时长**：快速 0.3~0.5s，中速 0.5~1.0s，慢速 1.0~2.0s。
- **遮罩转场**：用灰度图控制显现顺序，产生展开、溶解效果。
- **应用场景**：场景切换、关卡加载、剧情转场。

## 第 24 讲 · 滑动与推动转场

### 概念

**滑动转场（Slide Transition）** 让旧场景向一侧滑出，新场景从另一侧滑入，产生空间连续感。适合表示"移动到相邻区域"。

**推动转场（Push Transition）** 类似滑动，但新场景"推"旧场景出去——新场景从一侧进入，旧场景被推着退出。适合表示"前进"。

### 原理

**滑动转场的实现**：

两个场景同时渲染，各自有水平/垂直偏移：

```
// 旧场景向左滑出，新场景从右滑入
old_offset_x = -transition_progress * screen_w
new_offset_x = (1 - transition_progress) * screen_w

render old_scene at (old_offset_x, 0)
render new_scene at (new_offset_x, 0)
```

**推动转场**：

新场景覆盖旧场景，旧场景被"推"着移动：

```
// 新场景从右推入，旧场景向左被推
offset = -transition_progress * screen_w
render old_scene at (offset, 0)
render new_scene at (offset + screen_w, 0)
```

**滑动方向**：

- **水平**：左右滑动，适合横版游戏。
- **垂直**：上下滑动，适合纵版游戏。
- **对角线**：斜向滑动，较少见。

**滑动的缓动**：

滑动应使用缓动函数，避免线性滑动的机械感：

```
progress = ease_in_out(raw_progress)
```

**滑动的应用场景**：

1. **关卡切换**：相邻关卡间滑动，表示空间连续。
2. **菜单导航**：主菜单与子菜单间滑动。
3. **地图切换**：区域间滑动。
4. **页面切换**：UI 页面间滑动。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>

float ease_in_out(float t) {
    return t < 0.5f ? 2 * t * t : 1 - pow(-2 * t + 2, 2) / 2;
}

struct SlideTransition {
    bool active = false;
    float progress = 0;
    float duration = 0.8f;
    int direction = 1;  // 1=右到左, -1=左到右

    void start(int dir = 1) {
        active = true;
        progress = 0;
        direction = dir;
    }

    void update(float dt) {
        if (active) {
            progress += dt / duration;
            if (progress >= 1.0f) {
                progress = 1.0f;
                active = false;
            }
        }
    }

    void render(SDL_Renderer* r, int scene_from, int scene_to) {
        if (!active) {
            render_scene(r, scene_from);
            return;
        }

        float t = ease_in_out(progress);
        int offset = (int)(t * 800 * direction);

        // 旧场景滑出
        SDL_Rect from_rect = { -offset, 0, 800, 600 };
        render_scene_in_rect(r, scene_from, from_rect);

        // 新场景滑入
        SDL_Rect to_rect = { 800 * direction - offset, 0, 800, 600 };
        render_scene_in_rect(r, scene_to, to_rect);
    }

    void render_scene(SDL_Renderer* r, int scene) {
        if (scene == 0) {
            SDL_SetRenderDrawColor(r, 40, 60, 100, 255);
            SDL_RenderClear(r);
            SDL_SetRenderDrawColor(r, 255, 255, 255, 255);
            SDL_Rect obj = { 370, 270, 60, 60 };
            SDL_RenderFillRect(r, &obj);
        } else {
            SDL_SetRenderDrawColor(r, 100, 60, 40, 255);
            SDL_RenderClear(r);
            SDL_SetRenderDrawColor(r, 255, 255, 100, 255);
            SDL_Rect obj = { 370, 270, 60, 60 };
            SDL_RenderFillRect(r, &obj);
        }
    }

    void render_scene_in_rect(SDL_Renderer* r, int scene, SDL_Rect rect) {
        // 简化：用裁剪矩形渲染场景
        SDL_RenderSetClipRect(r, &rect);
        // 调整场景渲染偏移
        // 实际实现需把场景渲染到纹理，再 RenderCopy 到 rect
        // 这里简化为直接填充颜色
        if (scene == 0) {
            SDL_SetRenderDrawColor(r, 40, 60, 100, 255);
        } else {
            SDL_SetRenderDrawColor(r, 100, 60, 40, 255);
        }
        SDL_RenderFillRect(r, &rect);
        SDL_SetRenderDrawColor(r, 255, 255, 255, 255);
        SDL_Rect obj = { rect.x + 370, rect.y + 270, 60, 60 };
        SDL_RenderFillRect(r, &obj);
        SDL_RenderSetClipRect(r, nullptr);
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Slide Transition",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    SlideTransition transition;
    int current_scene = 0;
    int next_scene = 1;
    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN && e.key.keysym.sym == SDLK_SPACE) {
                if (!transition.active) {
                    next_scene = 1 - current_scene;
                    transition.start(1);
                }
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        transition.update(dt);
        if (!transition.active && current_scene != next_scene) {
            current_scene = next_scene;
        }

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        transition.render(renderer, current_scene, next_scene);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 滑动转场让旧场景滑出、新场景滑入，产生空间连续感。
- 推动转场是新场景"推"旧场景出去。
- **方向**：水平（横版）、垂直（纵版）、对角线。
- 用缓动函数避免线性滑动的机械感。
- **应用场景**：关卡切换、菜单导航、地图切换、页面切换。
- **常见坑**：滑动过快导致看不清；无缓动导致生硬。

## 第 25 讲 · 聚焦切换与镜头动画

### 概念

**聚焦切换（Focus Pull）** 是电影感的转场——镜头从一个焦点移到另一个焦点，同时改变缩放，产生"镜头移动"的感觉。无需黑屏，转场自然流畅。

**镜头动画（Camera Animation）** 是更广义的概念——用关键帧或脚本控制镜头参数随时间变化，实现复杂的镜头运动。这是过场动画的核心技术。

### 原理

**聚焦切换的实现**：

```
// 从焦点 A 切换到焦点 B
focus_A = { position: (x1, y1), zoom: z1 }
focus_B = { position: (x2, y2), zoom: z2 }

progress = elapsed / duration
eased_progress = ease_in_out(progress)

camera.position = lerp(focus_A.position, focus_B.position, eased_progress)
camera.zoom = lerp(focus_A.zoom, focus_B.zoom, eased_progress)
```

聚焦切换保持画面连续（无黑屏），适合"镜头扫过场景"的效果。

**关键帧动画**：

定义多个关键帧，每帧指定时间与镜头参数，中间帧用插值生成：

```cpp
struct Keyframe {
    float time;
    Vec2 position;
    float zoom;
    float rotation;
};

std::vector<Keyframe> keyframes = {
    { 0.0f, {0, 0}, 1.0f, 0 },
    { 2.0f, {100, 50}, 1.5f, 0 },
    { 4.0f, {200, 0}, 1.0f, 0.1f },
    { 6.0f, {0, 0}, 1.0f, 0 },
};

void update(float time) {
    // 找到当前时间所在的关键帧区间
    for (size_t i = 0; i + 1 < keyframes.size(); ++i) {
        if (time >= keyframes[i].time && time < keyframes[i+1].time) {
            float t = (time - keyframes[i].time) / (keyframes[i+1].time - keyframes[i].time);
            t = ease_in_out(t);
            camera.position = lerp(keyframes[i].position, keyframes[i+1].position, t);
            camera.zoom = lerp(keyframes[i].zoom, keyframes[i+1].zoom, t);
            camera.rotation = lerp(keyframes[i].rotation, keyframes[i+1].rotation, t);
            return;
        }
    }
}
```

**镜头脚本**：

更高级的镜头系统用脚本描述镜头行为：

```
// 伪代码：镜头脚本
sequence "intro":
    move_to (100, 0) over 2s with ease_in_out
    wait 1s
    zoom_to 1.5 over 1s
    move_to (200, 50) over 2s
    zoom_to 1.0 over 0.5s
```

脚本系统让设计师（非程序员）能控制镜头，是商业引擎的标配。

**镜头动画的应用**：

1. **过场动画**：剧情时镜头按脚本运动。
2. **开场介绍**：游戏开始时镜头扫过场景。
3. **Boss 出场**：镜头聚焦 Boss，强调威胁。
4. **解谜提示**：镜头移到谜题关键位置。
5. **胜利庆祝**：镜头环绕角色庆祝。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>
#include <vector>

struct Vec2 { float x, y; };

struct Keyframe {
    float time;
    float x, y;
    float zoom;
};

float ease_in_out(float t) {
    return t < 0.5f ? 2 * t * t : 1 - pow(-2 * t + 2, 2) / 2;
}

struct CameraAnimation {
    std::vector<Keyframe> keyframes;
    float current_time = 0;
    bool playing = false;
    bool loop = true;

    void play() { playing = true; current_time = 0; }

    void update(float dt) {
        if (!playing) return;
        current_time += dt;

        float total_duration = keyframes.back().time;
        if (current_time >= total_duration) {
            if (loop) {
                current_time = fmodf(current_time, total_duration);
            } else {
                current_time = total_duration;
                playing = false;
            }
        }
    }

    void get_state(float& x, float& y, float& zoom) const {
        if (keyframes.empty()) { x = y = 0; zoom = 1; return; }

        // 找到当前时间所在区间
        for (size_t i = 0; i + 1 < keyframes.size(); ++i) {
            if (current_time >= keyframes[i].time && current_time < keyframes[i+1].time) {
                float t = (current_time - keyframes[i].time) /
                          (keyframes[i+1].time - keyframes[i].time);
                t = ease_in_out(t);
                x = keyframes[i].x + (keyframes[i+1].x - keyframes[i].x) * t;
                y = keyframes[i].y + (keyframes[i+1].y - keyframes[i].y) * t;
                zoom = keyframes[i].zoom + (keyframes[i+1].zoom - keyframes[i].zoom) * t;
                return;
            }
        }
        // 最后一帧
        x = keyframes.back().x;
        y = keyframes.back().y;
        zoom = keyframes.back().zoom;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Camera Animation",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    CameraAnimation anim;
    anim.keyframes = {
        { 0.0f, 0, 0, 1.0f },
        { 2.0f, 200, 100, 1.5f },
        { 4.0f, -200, -100, 2.0f },
        { 6.0f, 0, 0, 0.7f },
        { 8.0f, 0, 0, 1.0f },
    };
    anim.play();

    Uint32 last_time = SDL_GetTicks();
    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN && e.key.keysym.sym == SDLK_SPACE) {
                anim.play();
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        anim.update(dt);
```

## 第 26 讲 · 镜头状态机

### 概念

**镜头状态机（Camera State Machine）** 管理镜头的多种模式——跟随、战斗、过场、对话等。每种模式有自己的行为逻辑，根据游戏状态自动切换。状态机让镜头系统模块化、可维护，避免所有逻辑堆在一起。

### 原理

**镜头状态的类型**：

```cpp
enum CameraState {
    FOLLOW,         // 跟随玩家
    COMBAT,         // 战斗模式（拉近、聚焦敌人）
    CINEMATIC,      // 过场动画（脚本控制）
    DIALOGUE,       // 对话（聚焦对话角色）
    PUZZLE,         // 解谜（聚焦谜题）
    DEAD,           // 死亡（特写、慢动作）
    MENU            // 菜单（固定或缓慢移动）
};
```

**状态机的设计**：

```cpp
class CameraStateMachine {
    CameraState current_state;
    std::map<CameraState, CameraBehavior*> behaviors;

    void update(float dt) {
        behaviors[current_state]->update(dt);
    }

    void transition_to(CameraState new_state) {
        behaviors[current_state]->on_exit();
        current_state = new_state;
        behaviors[current_state]->on_enter();
    }
};
```

**状态的行为接口**：

```cpp
class CameraBehavior {
public:
    virtual void on_enter() {}
    virtual void update(float dt) = 0;
    virtual void on_exit() {}
};
```

**状态转换的条件**：

- FOLLOW → COMBAT：进入战斗（敌人靠近）。
- COMBAT → FOLLOW：脱离战斗（敌人死亡）。
- FOLLOW → CINEMATIC：触发过场。
- CINEMATIC → FOLLOW：过场结束。
- FOLLOW → DEAD：玩家死亡。
- DEAD → FOLLOW：重生。

**转换的平滑**：

状态切换时镜头参数（位置、缩放）应平滑过渡，避免突变。可在 `on_enter` 时记录起始状态，用插值过渡到目标状态。

**状态机的优势**：

1. **模块化**：每种状态独立，便于维护。
2. **可扩展**：新增状态不影响其他状态。
3. **清晰**：状态转换规则明确，易于调试。
4. **复用**：状态行为可在多个游戏中复用。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>
#include <map>

float ease_out(float t) { return 1 - (1 - t) * (1 - t); }

// 镜头状态
enum CameraState { FOLLOW, COMBAT, CINEMATIC, DEAD };

// 镜头行为基类
class CameraBehavior {
public:
    virtual void on_enter() {}
    virtual void update(float dt) = 0;
    virtual void on_exit() {}
    virtual ~CameraBehavior() = default;
};

// 镜头系统
struct Camera {
    float x = 0, y = 0;
    float zoom = 1.0f;
    int screen_w = 800, screen_h = 600;

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = (wx - x) * zoom + screen_w / 2.0f;
        sy = (wy - y) * zoom + screen_h / 2.0f;
    }
};

// 跟随行为
class FollowBehavior : public CameraBehavior {
public:
    Camera* camera;
    float* target_x, *target_y;

    FollowBehavior(Camera* cam, float* tx, float* ty)
        : camera(cam), target_x(tx), target_y(ty) {}

    void update(float dt) override {
        float t = 1.0f - expf(-5.0f * dt);
        camera->x += (*target_x - camera->x) * t;
        camera->y += (*target_y - camera->y) * t;
        camera->zoom += (1.0f - camera->zoom) * t;
    }
};

// 战斗行为
class CombatBehavior : public CameraBehavior {
public:
    Camera* camera;
    float* player_x, *player_y, *enemy_x, *enemy_y;

    CombatBehavior(Camera* cam, float* px, float* py, float* ex, float* ey)
        : camera(cam), player_x(px), player_y(py), enemy_x(ex), enemy_y(ey) {}

    void update(float dt) override {
        // 聚焦玩家与敌人中点
        float target_x = (*player_x + *enemy_x) / 2;
        float target_y = (*player_y + *enemy_y) / 2;
        float t = 1.0f - expf(-3.0f * dt);  // 较慢跟随
        camera->x += (target_x - camera->x) * t;
        camera->y += (target_y - camera->y) * t;
        camera->zoom += (1.3f - camera->zoom) * t;  // 拉近
    }
};

// 死亡行为
class DeadBehavior : public CameraBehavior {
public:
    Camera* camera;
    float* target_x, *target_y;
    float timer = 0;

    DeadBehavior(Camera* cam, float* tx, float* ty)
        : camera(cam), target_x(tx), target_y(ty) {}

    void on_enter() override { timer = 0; }

    void update(float dt) override {
        timer += dt;
        float t = 1.0f - expf(-2.0f * dt);
        camera->x += (*target_x - camera->x) * t;
        camera->y += (*target_y - camera->y) * t;
        camera->zoom += (1.8f - camera->zoom) * t;  // 强烈拉近
    }
};

// 镜头状态机
class CameraStateMachine {
public:
    Camera* camera;
    CameraState current = FOLLOW;
    std::map<CameraState, CameraBehavior*> behaviors;

    void update(float dt) {
        behaviors[current]->update(dt);
    }

    void transition_to(CameraState new_state) {
        if (behaviors.count(current)) behaviors[current]->on_exit();
        current = new_state;
        if (behaviors.count(current)) behaviors[current]->on_enter();
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Camera State Machine",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    Camera cam;
    float player_x = 0, player_y = 0;
    float enemy_x = 200, enemy_y = 0;

    CameraStateMachine sm;
    sm.camera = &cam;
    sm.behaviors[FOLLOW] = new FollowBehavior(&cam, &player_x, &player_y);
    sm.behaviors[COMBAT] = new CombatBehavior(&cam, &player_x, &player_y, &enemy_x, &enemy_y);
    sm.behaviors[DEAD] = new DeadBehavior(&cam, &player_x, &player_y);

    Uint32 last_time = SDL_GetTicks();
    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN) {
                if (e.key.keysym.sym == SDLK_1) sm.transition_to(FOLLOW);
                if (e.key.keysym.sym == SDLK_2) sm.transition_to(COMBAT);
                if (e.key.keysym.sym == SDLK_3) sm.transition_to(DEAD);
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = 200;
        if (keys[SDL_SCANCODE_LEFT])  player_x -= speed * dt;
        if (keys[SDL_SCANCODE_RIGHT]) player_x += speed * dt;
        if (keys[SDL_SCANCODE_UP])    player_y -= speed * dt;
        if (keys[SDL_SCANCODE_DOWN])  player_y += speed * dt;

        sm.update(dt);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 敌人
        float ex, ey;
        cam.world_to_screen(enemy_x, enemy_y, ex, ey);
        SDL_SetRenderDrawColor(renderer, 255, 80, 80, 255);
        int esize = (int)(30 * cam.zoom);
        SDL_Rect er = { (int)ex - esize/2, (int)ey - esize/2, esize, esize };
        SDL_RenderFillRect(renderer, &er);

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        int psize = (int)(30 * cam.zoom);
        SDL_Rect pr = { (int)px - psize/2, (int)py - psize/2, psize, psize };
        SDL_RenderFillRect(renderer, &pr);

        // 状态指示
        const char* state_names[] = {"FOLLOW", "COMBAT", "CINEMATIC", "DEAD"};
        SDL_SetRenderDrawColor(renderer, 255, 255, 0, 255);
        SDL_Rect indicator = { 10, 10, 20, 20 };
        SDL_RenderFillRect(renderer, &indicator);

        SDL_RenderPresent(renderer);
    }

    for (auto& p : sm.behaviors) delete p.second;
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 镜头状态机管理多种镜头模式（跟随、战斗、过场、死亡等）。
- 每种状态有独立行为类，实现 on_enter/update/on_exit。
- 状态转换由游戏事件触发（进入战斗、死亡、过场）。
- **优势**：模块化、可扩展、清晰、复用。
- **应用场景**：动作游戏、RPG、冒险游戏。
- **常见坑**：状态转换无平滑导致突变；状态过多导致复杂。

## 第 27 讲 · 脚本化镜头与过场

### 概念

**脚本化镜头（Scripted Camera）** 用脚本描述镜头行为，让设计师（非程序员）控制镜头。脚本定义镜头的移动、缩放、等待、事件触发等，按时间执行。

**过场（Cutscene）** 是脚本化镜头的典型应用——剧情时镜头按脚本运动，配合角色对话、动画、特效，讲述故事。

### 原理

**镜头脚本的指令**：

```
move_to (x, y) over duration [ease]
zoom_to zoom over duration [ease]
wait duration
look_at (x, y) over duration
shake intensity duration
fade color duration
play_animation name
wait_for_event event_name
```

**脚本的执行**：

```cpp
struct CameraCommand {
    enum Type { MOVE, ZOOM, WAIT, SHAKE, FADE } type;
    float x, y;        // 目标位置
    float zoom;        // 目标缩放
    float duration;    // 持续时间
    float intensity;   // 震动强度
    // ...
};

class CameraScript {
    std::vector<CameraCommand> commands;
    int current_command = 0;
    float command_timer = 0;

    void update(float dt) {
        if (current_command >= commands.size()) return;

        auto& cmd = commands[current_command];
        command_timer += dt;

        switch (cmd.type) {
            case CameraCommand::MOVE:
                // 插值移动
                break;
            case CameraCommand::WAIT:
                if (command_timer >= cmd.duration) {
                    next_command();
                }
                break;
            // ...
        }
    }
};
```

**脚本的编写方式**：

1. **代码内定义**：在 C++ 中用结构体定义命令序列。
2. **数据驱动**：从 JSON/XML/Lua 文件加载。
3. **可视化编辑**：用编辑器拖拽关键帧。

**过场的组成**：

```
过场 = 镜头脚本 + 角色动画 + 对话 + 音效 + 特效
```

镜头脚本与其他系统协同，按时间轴触发：

```
时间 0s: 镜头移到角色 A，角色 A 播放"惊讶"动画
时间 2s: 镜头移到角色 B，角色 B 说"你好"
时间 4s: 镜头拉远，显示全景
时间 6s: 过场结束，恢复玩家控制
```

**过场的玩家控制**：

过场期间通常禁用玩家输入，镜头由脚本控制。过场结束后恢复：

```
void start_cutscene() {
    player_input_enabled = false;
    camera_script.play(intro_script);
}

void update() {
    if (in_cutscene) {
        camera_script.update(dt);
        if (camera_script.finished()) {
            end_cutscene();
        }
    }
}

void end_cutscene() {
    player_input_enabled = true;
    camera.transition_to(FOLLOW);
}
```

**跳过过场**：

提供跳过功能（按 Esc 跳过），尊重玩家时间：

```
if (skip_pressed && in_cutscene) {
    camera_script.skip_to_end();
    end_cutscene();
}
```

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>
#include <vector>

float ease_in_out(float t) {
    return t < 0.5f ? 2 * t * t : 1 - pow(-2 * t + 2, 2) / 2;
}

// 镜头命令
struct CameraCommand {
    enum Type { MOVE, ZOOM, WAIT, SHAKE } type;
    float x = 0, y = 0;
    float zoom = 1;
    float duration = 0;
    float intensity = 0;
};

// 镜头脚本
class CameraScript {
public:
    std::vector<CameraCommand> commands;
    int current = 0;
    float timer = 0;
    bool playing = false;

    // 镜头状态
    float cam_x = 0, cam_y = 0, cam_zoom = 1;
    float start_x = 0, start_y = 0, start_zoom = 1;
    float shake_x = 0, shake_y = 0;
    float shake_intensity = 0;

    void play() {
        current = 0;
        timer = 0;
        playing = true;
        if (!commands.empty()) {
            start_x = cam_x; start_y = cam_y; start_zoom = cam_zoom;
        }
    }

    void update(float dt) {
        if (!playing || current >= commands.size()) {
            playing = false;
            return;
        }

        // 震动衰减
        shake_intensity *= expf(-5.0f * dt);
        shake_x = (rand() % 200 - 100) / 100.0f * shake_intensity;
        shake_y = (rand() % 200 - 100) / 100.0f * shake_intensity;

        auto& cmd = commands[current];
        timer += dt;
        float t = std::clamp(timer / cmd.duration, 0.0f, 1.0f);
        float eased_t = ease_in_out(t);

        switch (cmd.type) {
            case CameraCommand::MOVE:
                cam_x = start_x + (cmd.x - start_x) * eased_t;
                cam_y = start_y + (cmd.y - start_y) * eased_t;
                break;
            case CameraCommand::ZOOM:
                cam_zoom = start_zoom + (cmd.zoom - start_zoom) * eased_t;
                break;
            case CameraCommand::WAIT:
                break;
            case CameraCommand::SHAKE:
                if (timer == 0) shake_intensity = cmd.intensity;
                break;
        }

        if (t >= 1.0f) {
            current++;
            timer = 0;
            start_x = cam_x; start_y = cam_y; start_zoom = cam_zoom;
        }
    }

    bool finished() const { return !playing; }

    void skip_to_end() {
        current = commands.size();
        playing = false;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Scripted Camera",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    CameraScript script;
    // 定义过场脚本
    script.commands = {
        { CameraCommand::MOVE, 0, 0, 1, 2.0f },       // 移到 (0,0)，2秒
        { CameraCommand::WAIT, 0, 0, 1, 1.0f },        // 等待 1秒
        { CameraCommand::MOVE, 200, 100, 1, 2.0f },    // 移到 (200,100)
        { CameraCommand::ZOOM, 200, 100, 1.5f, 1.5f }, // 缩放到 1.5
        { CameraCommand::SHAKE, 0, 0, 1, 0.5f, 20 },   // 震动 0.5秒
        { CameraCommand::MOVE, 0, 0, 1, 2.0f },        // 回到 (0,0)
        { CameraCommand::ZOOM, 0, 0, 1.0f, 1.0f },     // 缩放恢复
    };
    script.play();

    Uint32 last_time = SDL_GetTicks();
    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN) {
                if (e.key.keysym.sym == SDLK_SPACE) {
                    script.play();  // 重新播放
                }
                if (e.key.keysym.sym == SDLK_ESCAPE) {
                    script.skip_to_end();  // 跳过
                }
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f;
        last_time = now;

        script.update(dt);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格（应用镜头与震动）
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1 = (g - script.cam_x - script.shake_x) * script.cam_zoom + 400;
            float sy1 = (-2000 - script.cam_y - script.shake_y) * script.cam_zoom + 300;
            float sx2 = (g - script.cam_x - script.shake_x) * script.cam_zoom + 400;
            float sy2 = (2000 - script.cam_y - script.shake_y) * script.cam_zoom + 300;
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            sx1 = (-2000 - script.cam_x - script.shake_x) * script.cam_zoom + 400;
            sy1 = (g - script.cam_y - script.shake_y) * script.cam_zoom + 300;
            sx2 = (2000 - script.cam_x - script.shake_x) * script.cam_zoom + 400;
            sy2 = (g - script.cam_y - script.shake_y) * script.cam_zoom + 300;
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 关键点
        float px = (200 - script.cam_x - script.shake_x) * script.cam_zoom + 400;
        float py = (100 - script.cam_y - script.shake_y) * script.cam_zoom + 300;
        SDL_SetRenderDrawColor(renderer, 255, 200, 100, 255);
        int size = (int)(30 * script.cam_zoom);
        SDL_Rect pr = { (int)px - size/2, (int)py - size/2, size, size };
        SDL_RenderFillRect(renderer, &pr);

        // 进度指示
        SDL_SetRenderDrawColor(renderer, 255, 255, 0, 255);
        float progress = (float)script.current / script.commands.size();
        SDL_Rect bar = { 10, 10, (int)(progress * 200), 10 };
        SDL_RenderFillRect(renderer, &bar);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

- 命令类型：MOVE、ZOOM、WAIT、SHAKE、FADE。
- **过场** = 镜头脚本 + 角色动画 + 对话 + 音效 + 特效。
- 过场期间禁用玩家输入，结束后恢复。
- **跳过功能**：尊重玩家时间，按 Esc 跳过。

## 第 28 讲 · 电影感镜头系统设计

### 概念

**电影感镜头系统（Cinematic Camera System）** 是镜头设计的最高境界——综合运用前 27 讲的所有技术，让游戏画面有电影般的质感与表现力。这不是单一技术，而是一套设计哲学：每个镜头都有目的，每次切换都有理由，每个特效都服务于体验。

### 原理

**电影感的核心原则**：

1. **每个镜头有目的**：镜头不是"跟随玩家"那么简单，而是"引导玩家注意"、"营造氛围"、"强调情感"。
2. **节奏感**：镜头运动有快有慢，有动有静，形成节奏。
3. **空间感**：用景深、视差、缩放营造立体感。
4. **情感共鸣**：镜头配合剧情，强化情感（紧张时拉近，开阔时拉远）。
5. **隐藏技术感**：玩家不应意识到"镜头在动"，而应感到"自然"。

**电影感镜头的要素**：

```
电影感 = 构图 + 运动 + 节奏 + 特效 + 情感
```

- **构图**：三分法、引导线、负空间（第 3 章）。
- **运动**：平滑跟随、前瞻、聚焦切换（第 2、7 章）。
- **节奏**：缓动函数、时间控制（第 16 讲）。
- **特效**：缩放、震动、偏移（第 4 章）。
- **情感**：根据剧情调整镜头（紧张、舒缓、震撼）。

**电影感镜头的设计流程**：

1. **分析场景**：这个场景想表达什么？（紧张战斗、宁静探索、震撼 Boss）
2. **选择镜头模式**：跟随、战斗、过场、特写？
3. **设计构图**：主体在哪？焦点是什么？负空间多少？
4. **规划运动**：镜头如何移动？缓动曲线？时长？
5. **添加特效**：需要震动吗？缩放？偏移？
6. **测试调整**：实际体验，微调参数。

**经典电影感镜头技巧**：

1. **开场长镜头**：游戏开始时镜头缓慢扫过场景，建立世界观。
2. **Boss 登场特写**：Boss 出现时镜头聚焦 Boss，缓慢拉近，强调威胁。
3. **死亡慢镜头**：玩家死亡时镜头拉近、慢动作、震动。
4. **胜利环绕**：胜利时镜头环绕角色，庆祝感。
5. **环境过渡**：进入新区域时镜头从远景过渡到近景。
6. **情感特写**：剧情高潮时镜头特写角色表情。

**电影感镜头的禁忌**：

1. **过度震动**：频繁震动导致眩晕，削弱冲击力。
2. **快速切换**：镜头频繁切换导致混乱。
3. **无目的运动**：镜头无理由地动，分散注意。
4. **遮挡视线**：镜头角度导致关键信息被遮挡。
5. **破坏玩法**：镜头特效影响玩家操作（如战斗时拉近太多）。

### 例子

```cpp
#include <SDL2/SDL.h>
#include <cmath>
#include <vector>

// 综合镜头系统
struct CinematicCamera {
    float x, y;           // 逻辑位置
    float render_x, render_y;  // 渲染位置（含特效）
    float zoom = 1.0f;
    float target_zoom = 1.0f;

    // 跟随
    float follow_speed = 5.0f;
    float look_ahead_factor = 0.3f;
    float look_ahead_x = 0, look_ahead_y = 0;

    // 构图
    float frame_offset_x = 0.33f;  // 三分法偏移

    // 震动
    float shake_intensity = 0;
    float shake_x = 0, shake_y = 0;

    // 倾斜
    float tilt = 0;
    float target_tilt = 0;

    // 状态
    bool in_combat = false;
    bool slow_motion = false;
    float time_scale = 1.0f;

    void update(float dt, float target_x, float target_y,
                float vel_x, float vel_y) {
        // 1. 前瞻
        float desired_lx = vel_x * look_ahead_factor;
        float desired_ly = vel_y * look_ahead_factor;
        look_ahead_x += (desired_lx - look_ahead_x) * 0.05f;
        look_ahead_y += (desired_ly - look_ahead_y) * 0.05f;

        // 2. 构图偏移
        float frame_offset = (frame_offset_x - 0.5f) * 800;

        // 3. 目标位置
        float cam_target_x = target_x + look_ahead_x - frame_offset;
        float cam_target_y = target_y + look_ahead_y;

        // 4. 动态缩放
        float speed = sqrtf(vel_x*vel_x + vel_y*vel_y);
        if (in_combat) {
            target_zoom = 1.2f;
        } else if (speed > 300) {
            target_zoom = 0.9f;
        } else {
            target_zoom = 1.0f;
        }

        // 5. 平滑跟随
        float t = 1.0f - expf(-follow_speed * dt);
        x += (cam_target_x - x) * t;
        y += (cam_target_y - y) * t;
        zoom += (target_zoom - zoom) * 0.05f;
        tilt += (target_tilt - tilt) * 0.1f;

        // 6. 震动
        shake_intensity *= expf(-5.0f * dt);
        shake_x = (rand() % 200 - 100) / 100.0f * shake_intensity;
        shake_y = (rand() % 200 - 100) / 100.0f * shake_intensity;

        // 7. 渲染位置
        render_x = x + shake_x;
        render_y = y + shake_y;

        // 8. 慢动作
        time_scale += ((slow_motion ? 0.2f : 1.0f) - time_scale) * 0.1f;
    }

    void trigger_shake(float intensity) {
        shake_intensity = fmaxf(shake_intensity, intensity);
    }

    void world_to_screen(float wx, float wy, float& sx, float& sy) const {
        sx = (wx - render_x) * zoom + 400;
        sy = (wy - render_y) * zoom + 300;
    }
};

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow("Cinematic Camera",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 800, 600, 0);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    CinematicCamera cam = { 0, 0, 0, 0, 1.0f, 1.0f };

    float player_x = 0, player_y = 0;
    float player_vx = 0, player_vy = 0;
    Uint32 last_time = SDL_GetTicks();

    bool running = true;
    while (running) {
        SDL_Event e;
        while (SDL_PollEvent(&e)) {
            if (e.type == SDL_QUIT) running = false;
            if (e.type == SDL_KEYDOWN) {
                if (e.key.keysym.sym == SDLK_1) cam.trigger_shake(15);  // 震动
                if (e.key.keysym.sym == SDLK_2) cam.in_combat = !cam.in_combat;  // 战斗
                if (e.key.keysym.sym == SDLK_3) cam.slow_motion = !cam.slow_motion;  // 慢动作
                if (e.key.keysym.sym == SDLK_4) cam.target_tilt = cam.target_tilt > 0 ? 0 : 0.05f;  // 倾斜
            }
        }

        Uint32 now = SDL_GetTicks();
        float dt = (now - last_time) / 1000.0f * cam.time_scale;  // 慢动作
        last_time = now;

        const Uint8* keys = SDL_GetKeyboardState(nullptr);
        float speed = cam.in_combat ? 250 : 400;
        float target_vx = 0, target_vy = 0;
        if (keys[SDL_SCANCODE_LEFT])  target_vx = -speed;
        if (keys[SDL_SCANCODE_RIGHT]) target_vx = speed;
        if (keys[SDL_SCANCODE_UP])    target_vy = -speed;
        if (keys[SDL_SCANCODE_DOWN])  target_vy = speed;

        player_vx += (target_vx - player_vx) * 0.1f;
        player_vy += (target_vy - player_vy) * 0.1f;
        player_x += player_vx * dt;
        player_y += player_vy * dt;

        cam.update(dt, player_x, player_y, player_vx, player_vy);

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        // 网格
        SDL_SetRenderDrawColor(renderer, 50, 50, 60, 255);
        for (int g = -2000; g <= 2000; g += 100) {
            float sx1, sy1, sx2, sy2;
            cam.world_to_screen(g, -2000, sx1, sy1);
            cam.world_to_screen(g, 2000, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
            cam.world_to_screen(-2000, g, sx1, sy1);
            cam.world_to_screen(2000, g, sx2, sy2);
            SDL_RenderDrawLine(renderer, sx1, sy1, sx2, sy2);
        }

        // 玩家
        float px, py;
        cam.world_to_screen(player_x, player_y, px, py);
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        int size = (int)(30 * cam.zoom);
        SDL_Rect pr = { (int)px - size/2, (int)py - size/2, size, size };
        SDL_RenderFillRect(renderer, &pr);

        // 战斗状态边框
        if (cam.in_combat) {
            SDL_SetRenderDrawColor(renderer, 255, 50, 50, 100);
            SDL_Rect border = { 5, 5, 790, 590 };
            SDL_RenderDrawRect(renderer, &border);
        }

        // 慢动作指示
        if (cam.slow_motion) {
            SDL_SetRenderDrawColor(renderer, 100, 150, 255, 100);
            SDL_Rect overlay = { 0, 0, 800, 600 };
            SDL_SetRenderDrawBlendMode(renderer, SDL_BLENDMODE_BLEND);
            SDL_RenderFillRect(renderer, &overlay);
        }

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 电影感镜头系统综合运用构图、运动、节奏、特效、情感。
- **核心原则**：每个镜头有目的、有节奏、有空间感、有情感、隐藏技术感。
- **设计流程**：分析场景 → 选择模式 → 设计构图 → 规划运动 → 添加特效 → 测试调整。
- **经典技巧**：开场长镜头、Boss 登场特写、死亡慢镜头、胜利环绕、环境过渡、情感特写。
- **禁忌**：过度震动、快速切换、无目的运动、遮挡视线、破坏玩法。
- **应用场景**：剧情游戏、动作游戏、冒险游戏、独立游戏。
- **终极目标**：让玩家忘记镜头的存在，沉浸于游戏世界。

## 课程结语

恭喜你完成了《2D 游戏的镜头、画面和视角》的全部 28 讲！让我们回顾这段旅程：

**第 1 章 镜头基础**：理解镜头的本质是视口变换，掌握世界/屏幕坐标转换，计算可见区域，建立镜头属性模型。

**第 2 章 跟随与平滑**：从硬跟随的问题出发，学习 Lerp、弹簧物理、临界阻尼、前瞻预测，实现流畅自然的镜头跟随。

**第 3 章 构图与引导**：借鉴电影摄影，掌握三分法、引导线、负空间、焦点引导，让画面有"镜头感"。

**第 4 章 镜头特效**：实现缩放与 FOV、镜头震动、镜头偏移与倾斜、缓动函数，让镜头充满表现力。

**第 5 章 视角与投影**：学习正交视角、伪 3D 透视、视差滚动，突破 2D 平面限制，营造空间感。

**第 6 章 分屏与多镜头**：实现双人分屏、画中画与小地图、动态镜头切换，支持多人游戏与复杂视角。

**第 7 章 过渡与转场**：掌握淡入淡出、滑动推动、聚焦切换与镜头动画，让场景切换平滑专业。

**第 8 章 高级与实战**：构建镜头状态机、脚本化镜头与过场、电影感镜头系统，达到专业级镜头设计。
