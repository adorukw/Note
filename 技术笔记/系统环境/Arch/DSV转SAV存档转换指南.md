# NDS 存档格式转换指南：.dsv → .sav（DeSmuME → melonDS）

## 背景

- **`.dsv`** 是 DeSmuME（NDS 模拟器）的存档格式。它 = **原始存档数据 + 122 字节脚注**（footer），脚注内容大致是：

  ```
  |<--Snip above here to create a raw sav by excluding this DeSmuME savedata footer:
  ...
  |-DESMUME SAVE-|
  ```

- **melonDS** 只认**裸存档** `.sav`（就是原始存档数据本身，不带任何附加信息）。

- 因此 `.dsv` 不能直接改后缀用，必须先把尾部 122 字节脚注切掉，得到纯裸存档，再命名为 `.sav`。

## 一、如何判断存档的原始大小

存档原始大小 = 文件总大小 − 122（脚注长度）。

以口袋妖怪魂银为例：

```
文件总大小：524410 字节
脚注长度：  122 字节
原始存档：  524410 − 122 = 524288 字节（512KB）
```

也可以直接看文件尾部是否有 `|-DESMUME SAVE-|` 字样来确认是 DeSmuME 格式：

```bash
xxd -s -128 你的存档.dsv
```

## 二、转换命令（核心）

```bash
cd "存档所在目录"
head -c 524288 口袋妖怪魂银.dsv > 口袋妖怪魂银.sav
```

- `head -c <大小>` 表示只取文件前 `<大小>` 字节（即原始存档部分）
- 大小按第一步算出来的 524288（或你自己算出的值）填
- **原始 `.dsv` 不会被修改**，只是读它来生成新文件

## 三、命名规则（关键）

melonDS 加载存档靠的是**和 ROM 同名**：

```
游戏.nds  →  游戏.sav
```

即 `.sav` 的主文件名必须和 `.nds` 完全一致，且放在**同一目录**。

## 四、验证

```bash
# 1. 确认大小 = 原始存档大小（例：524288）
stat -c %s 口袋妖怪魂银.sav

# 2. 确认结尾已无 DeSmuME 脚注
xxd -s -16 口袋妖怪魂银.sav

# 3. 确认与 .dsv 前 524288 字节完全一致（切割正确性）
cmp <(head -c 524288 口袋妖怪魂银.dsv) 口袋妖怪魂银.sav && echo "一致"
```

## 五、在 melonDS 中使用

1. 打开 melonDS
2. `File → Open ROM…` 选择对应的 `.nds`
3. 存档自动加载，直接继续游玩

> 补充：melonDS 运行 `.nds` 时若发现存档没读上（进了新游戏），
> 检查存档文件名是否与 ROM 完全同名、是否在同一目录。

## 六、小结

| 步骤 | 命令/要点 |
|---|---|
| 算原始大小 | 总大小 − 122（或看尾部 DESMUME 脚注） |
| 切脚注 | `head -c <大小> 原.dsv > 新.sav` |
| 命名 | 与 `.nds` 主文件名完全一致，同目录 |
| 验证 | `stat` / `xxd` / `cmp` |
| 使用 | melonDS 打开 ROM 自动加载 |
