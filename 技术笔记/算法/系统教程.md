# 第一章：基础入门

## 第1讲：ACM竞赛概述与环境搭建

### 概念

ACM国际大学生程序设计竞赛（ICPC）是全球最具影响力的大学生计算机竞赛之一，由美国计算机协会（ACM）主办。竞赛以三人一组的形式参加，使用一台计算机，在5小时内解决8-13道算法题目。题目考察选手的算法设计能力、编程实现能力、数学建模能力以及团队协作能力。

在ACM竞赛中，每道题目给出问题描述、输入输出格式和样例，选手需要编写程序，使其能够对所有合法输入在规定时间和内存限制内给出正确输出。竞赛采用实时反馈机制，提交结果分为AC（Accepted，通过）、WA（Wrong Answer，答案错误）、TLE（Time Limit Exceeded，超时）、MLE（Memory Limit Exceeded，超内存）、RE（Runtime Error，运行时错误）等。

### 原理

ACM竞赛的核心评判原理基于"黑盒测试"：评判系统准备了大量测试数据，选手的程序对这些数据逐一运行，只有全部通过才算AC。这意味着程序不仅要对样例正确，还要处理各种边界情况和极端数据。

竞赛中常用的编程语言包括C++、Java、Python，其中C++因其执行效率高、STL功能强大而成为绝大多数选手的首选。一道题目的典型限制为：时间1-2秒，内存256MB，这要求选手在算法选择和实现上都要精打细算。

环境搭建方面，推荐使用VS Code或Dev-C++作为本地IDE，配合G++编译器。在线练习平台主要有Codeforces、洛谷、AtCoder、POJ等，这些平台提供海量题目和实时评测。

### 例子

以下是一个标准的ACM程序模板，展示了基本的输入输出和程序结构：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    while (cin >> n) {
        // 处理每个测试用例
        long long sum = 0;
        for (int i = 0; i < n; i++) {
            int x;
            cin >> x;
            sum += x;
        }
        cout << sum << '\n';
    }
    return 0;
}
```

**关键说明**：
- `#include <bits/stdc++.h>` 是G++编译器特有的万能头文件，包含了所有标准库
- `ios::sync_with_stdio(false)` 取消C++流与C标准流的同步，加速输入输出
- `cin.tie(nullptr)` 解除cin与cout的绑定，进一步加速
- 使用 `'\n'` 而非 `endl` 避免频繁刷新缓冲区

### 总结

本讲介绍了ACM竞赛的基本概念、评判机制和环境搭建。关键要点包括：竞赛以团队形式进行，采用黑盒测试评判；C++是主流语言，需掌握快速输入输出技巧；推荐使用VS Code + G++进行本地开发，在Codeforces、洛谷等平台练习。常见注意事项是：不要忘记关闭流同步，不要混用scanf/printf与cin/cout（在关闭同步后），养成使用万能头文件的习惯以节省编码时间。

## 第2讲：C++ STL基础与输入输出优化

### 概念

C++标准模板库（STL，Standard Template Library）是ACM竞赛中最重要的工具集，它提供了大量通用的数据结构和算法实现。STL由六大组件构成：容器（Container）、迭代器（Iterator）、算法（Algorithm）、函数对象（Functor）、适配器（Adapter）和空间配置器（Allocator）。在竞赛中，我们主要使用容器和算法两大组件。

常用的STL容器包括：`vector`（动态数组）、`string`（字符串）、`map/set`（有序映射/集合）、`unordered_map/unordered_set`（哈希映射/集合）、`priority_queue`（优先队列/堆）、`stack/queue`（栈/队列）、`deque`（双端队列）等。常用算法包括`sort`、`lower_bound`、`upper_bound`、`unique`、`__gcd`等。

### 原理

STL容器的设计基于泛型编程，通过模板实现类型无关性。以`vector`为例，它在底层是一块连续的内存空间，当容量不足时会自动扩容（通常扩为原来的2倍），均摊时间复杂度为O(1)。`map`和`set`底层是红黑树，保证O(log n)的插入、删除和查询；`unordered_map`底层是哈希表，平均O(1)但最坏O(n)。

输入输出优化的原理在于：C++默认将cin/cout与scanf/printf同步，这会带来性能开销。关闭同步后，cin/cout的速度可以接近scanf/printf。对于极端数据量（如10^6级别输入），还可以手写快速读入函数，利用`getchar`逐字符读取并组装数字，比标准库快数倍。

### 例子

**STL容器使用示例**：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // vector 动态数组
    vector<int> v = {3, 1, 4, 1, 5, 9, 2, 6};
    sort(v.begin(), v.end());  // 排序：1 1 2 3 4 5 6 9
    v.erase(unique(v.begin(), v.end()), v.end());  // 去重：1 2 3 4 5 6 9
    
    // 二分查找
    int pos = lower_bound(v.begin(), v.end(), 4) - v.begin();  // 返回3
    
    // map 有序映射
    map<string, int> mp;
    mp["apple"] = 3;
    mp["banana"] = 5;
    for (auto& [key, val] : mp) {  // C++17结构化绑定
        cout << key << ": " << val << '\n';
    }
    
    // priority_queue 优先队列（默认大根堆）
    priority_queue<int> pq;
    pq.push(3); pq.push(1); pq.push(4);
    cout << pq.top() << '\n';  // 输出4
    
    // 小根堆写法
    priority_queue<int, vector<int>, greater<int>> min_pq;
    
    return 0;
}
```

**快速读入函数**：

```cpp
inline int read() {
    int x = 0, f = 1;
    char ch = getchar();
    while (ch < '0' || ch > '9') {
        if (ch == '-') f = -1;
        ch = getchar();
    }
    while (ch >= '0' && ch <= '9') {
        x = x * 10 + ch - '0';
        ch = getchar();
    }
    return x * f;
}

// 使用：int n = read();
```

### 总结

本讲介绍了STL的核心容器和算法，以及输入输出优化技巧。关键要点：`vector`是最常用的动态数组，配合`sort`/`unique`/`lower_bound`能解决大量问题；`map/set`适合需要有序性的场景，`unordered_map`适合纯查找；`priority_queue`默认大根堆，小根堆需指定`greater`。输入输出优化方面，关闭流同步是基本操作，面对百万级输入时考虑手写快读。常见注意事项：`unordered_map`在竞赛中可能被特殊数据卡成O(n)，关键场景慎用；迭代器失效问题需注意（如在遍历中删除元素）。

## 第3讲：复杂度分析

### 概念

复杂度分析是评估算法效率的核心工具，分为时间复杂度和空间复杂度。时间复杂度描述算法运行时间随输入规模增长的变化趋势，用大O记号表示；空间复杂度描述算法所需额外内存随输入规模增长的变化趋势。在ACM竞赛中，复杂度分析直接决定算法能否在时限内通过。

大O记号表示算法在最坏情况下的渐进复杂度，忽略常数因子和低阶项。例如，一个执行 `3n² + 5n + 100` 次操作的算法，其时间复杂度为O(n²)。常见的复杂度从优到劣排列为：O(1) < O(log n) < O(√n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2^n) < O(n!)。

### 原理

复杂度分析的理论依据是：在n足够大时，高阶项主导整体增长趋势。竞赛中通常以1秒能执行约10^8次简单运算为基准进行估算。由此可以反推：若n=10^5，则O(n²)约10^10次运算会超时，需要O(n log n)或更优算法；若n=20，则O(2^n)约10^6次运算可行，可以使用暴力搜索。

分析循环的复杂度时，嵌套循环的复杂度相乘，顺序循环的复杂度相加。递归算法的复杂度可用主定理（Master Theorem）分析：对于 `T(n) = aT(n/b) + f(n)` 的分治递归，根据a、b和f(n)的关系确定总复杂度。例如归并排序 `T(n) = 2T(n/2) + O(n)`，属于主定理的第二种情况，复杂度为O(n log n)。

空间复杂度方面，除了输入数据本身占用的空间，还需考虑算法使用的额外空间。递归调用会消耗栈空间，深度为d的递归需O(d)栈空间。在内存限制256MB的情况下，一个int数组最多约6×10^7个元素。

### 例子

**复杂度分析实例**：

```cpp
// 示例1：O(n) - 单层循环
int sum1(int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += i;
    return s;
}

// 示例2：O(n²) - 嵌套循环
int sum2(int n) {
    int s = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            s += i * j;
    return s;
}

// 示例3：O(log n) - 每次折半
int countBits(int n) {
    int cnt = 0;
    while (n > 0) {
        cnt++;
        n /= 2;
    }
    return cnt;
}

// 示例4：O(n log n) - 归并排序
void mergeSort(vector<int>& a, int l, int r) {
    if (l >= r) return;
    int mid = (l + r) / 2;
    mergeSort(a, l, mid);      // T(n/2)
    mergeSort(a, mid+1, r);    // T(n/2)
    // 合并过程 O(n)
    vector<int> tmp;
    int i = l, j = mid + 1;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp.push_back(a[i++]);
        else tmp.push_back(a[j++]);
    }
    while (i <= mid) tmp.push_back(a[i++]);
    while (j <= r) tmp.push_back(a[j++]);
    for (int k = 0; k < tmp.size(); k++) a[l + k] = tmp[k];
}
```

**竞赛时限速查表**：

| n的规模 | 可接受复杂度 | 典型算法 |
|---------|-------------|---------|
| n ≤ 20 | O(2^n) | 状压搜索、暴力枚举 |
| n ≤ 100 | O(n³) | Floyd、三层循环DP |
| n ≤ 1000 | O(n²) | 简单DP、矩阵操作 |
| n ≤ 10^5 | O(n log n) | 排序、线段树、二分 |
| n ≤ 10^6 | O(n) | 线性扫描、线性DP |
| n ≤ 10^18 | O(log n) | 快速幂、矩阵快速幂 |

### 总结

本讲介绍了时间复杂度和空间复杂度的分析方法。关键要点：大O记号描述最坏情况的渐进趋势；竞赛中以10^8次运算/秒为基准估算；嵌套循环复杂度相乘，顺序结构相加；递归算法可用主定理分析。常见注意事项：不要忽略常数因子，虽然大O记号忽略常数，但常数过大的O(n)算法可能比O(n log n)还慢；注意最坏情况与平均情况的差异，如快速排序最坏O(n²)但平均O(n log n)；空间复杂度也要考虑，特别是递归深度和数组大小。

# 第二章：基础算法

## 第4讲：枚举与模拟

### 概念

枚举（Enumeration）是最基础的算法思想，通过遍历所有可能的情况来寻找答案。模拟（Simulation）则是按照题目描述的规则，一步步重现过程得到结果。这两种方法虽然看似简单，但在ACM竞赛中极为重要——许多题目需要先正确理解题意，再用枚举或模拟实现，且往往是其他高级算法的基础。

枚举的关键在于"不重不漏"地遍历所有候选解，同时通过剪枝优化减少无效计算。模拟的关键在于准确理解题目规则，将自然语言描述的过程转化为精确的代码逻辑。当题目数据规模较小时（如n≤20），纯枚举往往就能解决；数据规模大时，需要结合数学优化或更高级算法。

### 原理

枚举算法的原理基于"穷举思想"：如果解空间有限且可枚举，那么逐一验证就能找到答案。其正确性依赖于解空间的完整性——必须保证最优解在枚举范围内。效率则取决于解空间的大小和单次验证的代价。

模拟算法的原理是"状态机模型"：将问题抽象为初始状态、终止条件和状态转移规则，然后从初始状态出发，按规则一步步推进直到终止。模拟过程中需要维护所有相关变量，确保状态转移的正确性。复杂模拟题常涉及多个对象、多种操作的交互，需要清晰的数据组织。

优化枚举的常用策略包括：减少枚举变量个数（利用数学关系消元）、缩小枚举范围（利用单调性或约束条件）、改变枚举顺序（从大到小提前终止）。这些优化能将指数级枚举降为多项式级。

### 例子

**例题1：枚举——日期问题**

给定年份范围，统计"回文日期"的数量（日期格式YYYYMMDD为回文串）。

```cpp
#include <bits/stdc++.h>
using namespace std;

int days[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

bool isLeap(int y) {
    return (y % 400 == 0) || (y % 4 == 0 && y % 100 != 0);
}

bool valid(int y, int m, int d) {
    if (m < 1 || m > 12) return false;
    int maxd = days[m];
    if (m == 2 && isLeap(y)) maxd = 29;
    return d >= 1 && d <= maxd;
}

int main() {
    int date1, date2;
    cin >> date1 >> date2;
    int cnt = 0;
    // 枚举年份，构造回文日期
    for (int y = 1000; y <= 9999; y++) {
        // 构造回文：年份 + 年份逆序
        int m = (y % 10) * 10 + (y / 10 % 10);
        int d = (y / 100 % 10) * 10 + (y / 1000);
        int date = y * 10000 + m * 100 + d;
        if (date < date1 || date > date2) continue;
        if (valid(y, m, d)) cnt++;
    }
    cout << cnt << '\n';
    return 0;
}
```

**例题2：模拟——约瑟夫环**

n个人围成一圈，从第1个人开始报数，报到m的人出列，求最后剩下的人的编号。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    list<int> circle;
    for (int i = 1; i <= n; i++) circle.push_back(i);
    
    auto it = circle.begin();
    while (circle.size() > 1) {
        // 报数m-1次（因为当前人算第1次）
        for (int i = 1; i < m; i++) {
            it++;
            if (it == circle.end()) it = circle.begin();
        }
        // 删除当前人
        auto next_it = next(it);
        if (next_it == circle.end()) next_it = circle.begin();
        circle.erase(it);
        it = next_it;
    }
    cout << *circle.begin() << '\n';
    return 0;
}
```

### 总结

本讲介绍了枚举与模拟两种基础算法。关键要点：枚举要保证"不重不漏"，通过减少变量、缩小范围、改变顺序来优化；模拟要准确理解题意，用状态机模型组织逻辑。枚举适用于解空间小的问题，模拟适用于规则明确的过程。常见注意事项：模拟题最容易在边界条件出错（如循环边界、空列表处理），务必仔细处理；枚举时要充分利用题目约束缩小范围，避免不必要的计算；对于复杂模拟，建议先在纸上推演样例再编码。

## 第5讲：递归与分治

### 概念

递归（Recursion）是一种函数直接或间接调用自身的编程技巧，它将大问题分解为结构相同的子问题来求解。分治（Divide and Conquer）是一种算法设计范式，其核心思想是"分而治之"——将原问题分解为若干规模更小的同类子问题，递归求解后合并结果。

递归由两个要素构成：基准情形（Base Case，递归的终止条件）和递归情形（Recursive Case，将问题分解并调用自身）。分治由三个步骤构成：分解（Divide，将问题分为子问题）、解决（Conquer，递归求解子问题）、合并（Combine，将子问题的解组合为原问题的解）。两者密切相关：分治通常通过递归实现，但递归不一定都是分治。

### 原理

递归的工作原理基于函数调用栈：每次递归调用会在栈上压入一个新的栈帧，保存局部变量和返回地址；当递归返回时，弹出栈帧恢复现场。这意味着递归深度受限于栈大小（通常约10^5层），过深会导致栈溢出。递归的正确性依赖于数学归纳法：若基准情形正确，且递归情形能从子问题的正确解推导出原问题的正确解，则递归正确。

分治算法的效率分析使用主定理。对于递推式 `T(n) = aT(n/b) + f(n)`，其中a是子问题个数，n/b是子问题规模，f(n)是分解与合并的代价。主定理给出三种情况的解：若f(n) = O(n^c)且c < log_b(a)，则T(n) = O(n^(log_b(a)))；若c = log_b(a)，则T(n) = O(n^c · log n)；若c > log_b(a)且满足正则条件，则T(n) = O(f(n))。

分治的有效性在于：将O(n²)的暴力算法优化为O(n log n)，如归并排序、快速排序；将O(n)的线性扫描优化为O(log n)，如二分查找。关键在于每次分解都能有效缩小问题规模，且合并代价不超过子问题求解代价。

### 例子

**例题1：递归——汉诺塔**

将n个圆盘从柱A移到柱C，借助柱B，每次移动一个圆盘，大盘不能压在小盘上。

```cpp
#include <bits/stdc++.h>
using namespace std;

void hanoi(int n, char from, char via, char to) {
    if (n == 1) {  // 基准情形
        cout << from << " -> " << to << '\n';
        return;
    }
    hanoi(n - 1, from, to, via);   // 将n-1个盘从A移到B
    cout << from << " -> " << to << '\n';  // 移动最大盘
    hanoi(n - 1, via, from, to);   // 将n-1个盘从B移到C
}

int main() {
    int n;
    cin >> n;
    hanoi(n, 'A', 'B', 'C');
    return 0;
}
// 复杂度：O(2^n)，移动次数为2^n - 1
```

**例题2：分治——归并排序求逆序对**

给定数组，求逆序对数量（i<j且a[i]>a[j]的对数）。

```cpp
#include <bits/stdc++.h>
using namespace std;

long long mergeSort(vector<int>& a, int l, int r) {
    if (l >= r) return 0;
    int mid = (l + r) / 2;
    long long cnt = mergeSort(a, l, mid) + mergeSort(a, mid + 1, r);
    
    // 合并阶段统计逆序对
    vector<int> tmp(r - l + 1);
    int i = l, j = mid + 1, k = 0;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) {
            tmp[k++] = a[i++];
        } else {
            // a[i..mid] 都大于 a[j]，构成逆序对
            cnt += mid - i + 1;
            tmp[k++] = a[j++];
        }
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (int t = 0; t < k; t++) a[l + t] = tmp[t];
    return cnt;
}

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    cout << mergeSort(a, 0, n - 1) << '\n';
    return 0;
}
// 复杂度：O(n log n)
```

### 总结

本讲介绍了递归与分治。关键要点：递归由基准情形和递归情形构成，正确性基于数学归纳法；分治通过分解-解决-合并三步将问题化简，效率可用主定理分析。归并排序是分治的经典应用，还能顺便求逆序对。常见注意事项：递归深度过大会栈溢出，必要时改为迭代实现；分治的合并步骤往往是关键，设计不当会退化为O(n²)；注意递归的边界条件，避免无限递归。

## 第6讲：贪心算法

### 概念

贪心算法（Greedy Algorithm）是一种在每一步选择中都采取当前状态下最优（或最有利）选择的策略，期望通过局部最优达到全局最优。贪心算法不回溯、不后悔，一旦做出选择就不再改变，因此实现简单、效率高。

贪心算法适用于具有"贪心选择性质"和"最优子结构"的问题。贪心选择性质指：所求问题的整体最优解可以通过一系列局部最优选择来达到；最优子结构指：问题的最优解包含子问题的最优解。需要注意的是，并非所有问题都适合贪心——如果局部最优不能保证全局最优，贪心就会失败，此时应考虑动态规划。

### 原理

贪心算法的正确性证明通常使用两种方法：交换论证（Exchange Argument）和数学归纳法。交换论证的核心是：假设存在一个最优解与贪心解不同，证明可以通过有限次交换将最优解转化为贪心解，且每次交换不改变解的优劣，从而证明贪心解也是最优的。

贪心算法的设计关键在于选择合适的贪心策略。常见的贪心策略包括：排序后按某种顺序处理（如按截止时间、按性价比）、优先队列动态选择（如Huffman编码）、区间问题中的端点排序等。选择哪种策略取决于问题的具体结构。

以经典的"活动选择问题"为例：有n个活动，每个活动有开始时间和结束时间，问最多能选多少个不冲突的活动。贪心策略是：按结束时间排序，每次选结束最早的活动。正确性在于：选结束最早的活动能为后续活动留出最多时间，这是最优的局部选择。

### 例子

**例题1：区间调度——活动选择**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<pair<int, int>> act(n);  // {结束时间, 开始时间}
    for (int i = 0; i < n; i++) {
        cin >> act[i].second >> act[i].first;
    }
    // 按结束时间排序
    sort(act.begin(), act.end());
    
    int cnt = 0, lastEnd = -1;
    for (int i = 0; i < n; i++) {
        if (act[i].second >= lastEnd) {  // 不冲突
            cnt++;
            lastEnd = act[i].first;
        }
    }
    cout << cnt << '\n';
    return 0;
}
```

**例题2：区间覆盖——最少区间覆盖目标区间**

给定目标区间[s, t]和若干区间，求最少用多少个区间能完全覆盖[s, t]。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int s, t;
    cin >> s >> t;
    int n;
    cin >> n;
    vector<pair<int, int>> seg(n);
    for (int i = 0; i < n; i++) cin >> seg[i].first >> seg[i].second;
    sort(seg.begin(), seg.end());  // 按左端点排序
    
    int cnt = 0, cur = s, i = 0;
    while (cur < t) {
        // 在所有左端点<=cur的区间中，选右端点最大的
        int maxR = cur;
        while (i < n && seg[i].first <= cur) {
            maxR = max(maxR, seg[i].second);
            i++;
        }
        if (maxR == cur) {  // 无法扩展
            cout << -1 << '\n';
            return 0;
        }
        cur = maxR;
        cnt++;
    }
    cout << cnt << '\n';
    return 0;
}
```

### 总结

本讲介绍了贪心算法。关键要点：贪心在每步选当前最优，适用于具有贪心选择性质和最优子结构的问题；正确性常用交换论证证明；常见策略包括排序处理和优先队列。区间问题是贪心的经典应用场景，按端点排序是通用技巧。常见注意事项：贪心策略不一定正确，需严格证明或用反例验证；不同问题需要不同的贪心标准（按开始时间、结束时间、长度等），选错会导致错误；当贪心失效时，应考虑动态规划。

## 第7讲：二分查找与二分答案

### 概念

二分查找（Binary Search）是一种在有序序列中高效查找目标的算法，每次将搜索区间折半，时间复杂度为O(log n)。二分答案（Binary Answer）是二分查找的推广应用：当答案具有单调性时（即存在一个阈值，使得一侧都满足条件、另一侧都不满足），可以二分枚举答案，将优化问题转化为判定问题。

二分查找的核心是"折半思想"：维护一个搜索区间[l, r]，每次取中点mid = (l+r)/2，根据mid处的状态决定向左还是向右缩小区间，直到区间为空或找到目标。二分答案的核心是"单调性"：如果答案为x时可行，那么答案为x' > x时也可行（或反之），则可以二分确定临界答案。

### 原理

二分查找的正确性依赖于序列的有序性：通过比较中点与目标值，可以确定目标值不在的半区间，从而安全地舍弃。每次操作将区间缩小一半，因此最多log n次即可定位目标。

二分答案的原理更为深刻：它将"求最优解"转化为"判定给定解是否可行"。设原问题是"求最大的x使得f(x)成立"，若f(x)关于x单调（即x增大时f(x)从成立变为不成立），则可以二分x：若f(mid)成立，则答案≥mid，向右搜索；否则答案<mid，向左搜索。

二分的实现难点在于边界处理。整数二分有两种常见写法：`l <= r` 配合 `l = mid + 1` / `r = mid - 1`（查找确切值），以及 `l < r` 配合 `l = mid + 1` / `r = mid` 或 `l = mid` / `r = mid - 1`（查找边界）。浮点数二分则用 `r - l > eps` 控制精度。关键是明确"二分的对象"和"判定的条件"，避免死循环和越界。

### 例子

**例题1：二分查找——在有序数组中找目标**

```cpp
#include <bits/stdc++.h>
using namespace std;

// 标准二分查找
int binarySearch(vector<int>& a, int target) {
    int l = 0, r = a.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;  // 防溢出
        if (a[mid] == target) return mid;
        else if (a[mid] < target) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}

// STL方式：lower_bound返回第一个>=target的位置
// upper_bound返回第一个>target的位置
int main() {
    vector<int> a = {1, 2, 4, 4, 4, 6, 7, 9};
    int pos = lower_bound(a.begin(), a.end(), 4) - a.begin();  // 2
    int cnt = upper_bound(a.begin(), a.end(), 4) 
            - lower_bound(a.begin(), a.end(), 4);  // 3（4的个数）
    cout << pos << " " << cnt << '\n';
    return 0;
}
```

**例题2：二分答案——木材切割**

有n根木材，需要切出m段等长的木材（可拼接），求每段最长能多长。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<long long> len(n);
    for (int i = 0; i < n; i++) cin >> len[i];
    
    // 二分答案：每段长度
    long long l = 1, r = *max_element(len.begin(), len.end());
    long long ans = 0;
    while (l <= r) {
        long long mid = (l + r) / 2;
        // 判定：长度为mid时能切出多少段
        long long cnt = 0;
        for (int i = 0; i < n; i++) cnt += len[i] / mid;
        if (cnt >= m) {  // 可行，尝试更长
            ans = mid;
            l = mid + 1;
        } else {  // 不可行，缩短
            r = mid - 1;
        }
    }
    cout << ans << '\n';
    return 0;
}
```

**例题3：浮点二分——求方程的根**

求方程 x³ - 5x² + 3x + 7 = 0 在区间[0, 10]内的根，精度1e-6。

```cpp
#include <bits/stdc++.h>
using namespace std;

double f(double x) {
    return x*x*x - 5*x*x + 3*x + 7;
}

int main() {
    double l = 0, r = 10;
    while (r - l > 1e-7) {
        double mid = (l + r) / 2;
        if (f(mid) * f(l) <= 0) r = mid;  // 根在[l, mid]
        else l = mid;  // 根在[mid, r]
    }
    cout << fixed << setprecision(6) << l << '\n';
    return 0;
}
```

### 总结

本讲介绍了二分查找与二分答案。关键要点：二分查找依赖有序性，复杂度O(log n)；二分答案依赖单调性，将优化问题转化为判定问题；STL的`lower_bound`/`upper_bound`是二分查找的便捷工具。二分答案的通用框架是：二分答案值，用判定函数检查可行性，根据结果调整搜索方向。常见注意事项：整数二分注意边界写法，避免死循环（`mid = l + (r-l)/2`防溢出，`l=mid`时用`mid = (l+r+1)/2`）；浮点二分用固定迭代次数或精度控制；二分答案的关键是设计高效的判定函数。

# 第三章：数据结构

## 第8讲：栈、队列与单调结构

### 概念

栈（Stack）是一种后进先出（LIFO，Last In First Out）的线性数据结构，只允许在栈顶进行插入和删除。队列（Queue）是一种先进先出（FIFO，First In First Out）的线性数据结构，在队尾插入、队头删除。单调栈（Monotone Stack）是栈的特殊应用，维护栈内元素的单调性（递增或递减），用于高效解决"下一个更大/更小元素"类问题。单调队列（Monotone Queue）是队列的特殊应用，维护队列内元素的单调性，常用于滑动窗口最值问题。

这些数据结构看似简单，但在算法竞赛中应用极广。栈用于括号匹配、表达式求值、DFS非递归实现；队列用于BFS、层次遍历；单调结构则能将O(n²)的暴力优化为O(n)，是处理序列问题的利器。

### 原理

栈和队列的原理直接：栈用数组+栈顶指针实现，push/pop均为O(1)；队列用数组+头尾指针实现（循环队列），入队出队均为O(1)。C++ STL提供了`stack`和`queue`容器适配器，底层默认基于`deque`实现。

单调栈的原理是：在遍历序列时，维护一个栈，使得栈内元素保持单调性。当新元素破坏单调性时，弹出栈顶元素直到恢复单调——弹出的过程中，新元素就是被弹元素的"下一个更大/更小元素"。每个元素最多入栈一次、出栈一次，因此总复杂度为O(n)。

单调队列的原理类似：维护一个双端队列，使得队列内元素保持单调性。在滑动窗口移动时，从队尾删除破坏单调的元素，从队头删除超出窗口的元素。这样队头始终是当前窗口的最值。每个元素最多入队出队各一次，总复杂度O(n)。

单调性之所以能优化，关键在于：如果存在i<j且a[i]≥a[j]（求最小值时），那么a[i]永远不会成为后续窗口的最小值（因为a[j]更小且更晚离开窗口），可以安全删除。这种"提前淘汰不可能成为答案的元素"的思想是单调结构的精髓。

### 例子

**例题1：单调栈——下一个更大元素**

给定数组，对每个元素求右边第一个比它大的元素的位置。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n), ans(n, -1);
    for (int i = 0; i < n; i++) cin >> a[i];
    
    stack<int> stk;  // 存下标，维护递减栈
    for (int i = 0; i < n; i++) {
        while (!stk.empty() && a[stk.top()] < a[i]) {
            ans[stk.top()] = i;  // a[i]是a[stk.top()]的下一个更大元素
            stk.pop();
        }
        stk.push(i);
    }
    
    for (int i = 0; i < n; i++) cout << ans[i] << " \n"[i == n-1];
    return 0;
}
// 输入：5 2 4 3 1 6
// 输出：1 2 5 4 5 -1
```

**例题2：单调队列——滑动窗口最小值**

有一个大小为k的滑动窗口从数组左端滑到右端，求每个位置的窗口最小值。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    
    deque<int> dq;  // 存下标，维护递增队列
    for (int i = 0; i < n; i++) {
        // 队头超出窗口
        while (!dq.empty() && dq.front() <= i - k) dq.pop_front();
        // 队尾大于a[i]的元素不可能成为最小值，删除
        while (!dq.empty() && a[dq.back()] >= a[i]) dq.pop_back();
        dq.push_back(i);
        if (i >= k - 1) cout << a[dq.front()] << " \n"[i == n-1];
    }
    return 0;
}
// 输入：n=8 k=3, a=[1 3 -1 -3 5 3 6 7]
// 输出：-1 -3 -3 -3 3 3
```

**例题3：栈的应用——括号匹配**

```cpp
#include <bits/stdc++.h>
using namespace std;

bool isValid(string s) {
    stack<char> stk;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            stk.push(c);
        } else {
            if (stk.empty()) return false;
            char t = stk.top(); stk.pop();
            if ((c == ')' && t != '(') ||
                (c == ']' && t != '[') ||
                (c == '}' && t != '{')) return false;
        }
    }
    return stk.empty();
}

int main() {
    string s;
    cin >> s;
    cout << (isValid(s) ? "Yes" : "No") << '\n';
    return 0;
}
```

### 总结

本讲介绍了栈、队列及单调结构。关键要点：栈LIFO、队列FIFO，基本操作均O(1)；单调栈解决"下一个更大/更小元素"问题，单调队列解决滑动窗口最值问题，复杂度均为O(n)。单调结构的核心思想是"提前淘汰不可能成为答案的元素"。常见注意事项：单调栈/队列中通常存下标而非值，便于计算位置和窗口范围；注意弹出条件的方向（递增还是递减取决于求最大还是最小）；单调队列要同时维护窗口范围和单调性两个约束。

## 第9讲：并查集

### 概念

并查集（Disjoint Set Union，DSU）是一种用于管理不相交集合的数据结构，支持两种操作：查找（Find，确定元素属于哪个集合）和合并（Union，将两个集合合并为一个）。并查集在ACM竞赛中应用广泛，常用于连通性问题、等价类划分、最小生成树的Kruskal算法等。

并查集的特点是：实现简单但功能强大，配合路径压缩和按秩合并两种优化后，单次操作的平均复杂度接近O(1)（准确说是O(α(n))，其中α是反阿克曼函数，增长极慢，对于任何实际n都不超过4）。这使得并查集成为处理动态连通性问题的高效工具。

### 原理

并查集用"树"来表示集合：每个集合是一棵树，树根作为集合的代表元。每个节点维护一个父指针`fa[x]`，指向父节点；根节点的`fa[root] = root`。查找操作从元素出发，沿父指针一直找到根；合并操作将一棵树的根指向另一棵树的根。

朴素并查集的效率问题在于：树可能退化为链，导致查找O(n)。两种优化解决此问题：

**路径压缩（Path Compression）**：在查找时，将路径上所有节点直接指向根。这样下次查找这些节点就是O(1)。路径压缩是"懒优化"——只在查找时修改结构，不主动维护。

**按秩合并（Union by Rank）**：合并时，将矮的树挂到高的树下，避免树高度增加。秩（rank）记录树的高度近似值，只有当两棵树秩相等时才增加秩。这保证树高最多O(log n)。

两种优化同时使用时，单次操作的均摊复杂度为O(α(n))，其中α是反阿克曼函数。对于n≤10^80，α(n)≤4，实际可视为常数。

### 例子

**标准并查集实现**：

```cpp
#include <bits/stdc++.h>
using namespace std;

int fa[10005], rnk[10005];

void init(int n) {
    for (int i = 1; i <= n; i++) {
        fa[i] = i;
        rnk[i] = 0;
    }
}

// 查找（带路径压缩）
int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

// 合并（按秩合并）
bool unite(int x, int y) {
    x = find(x); y = find(y);
    if (x == y) return false;  // 已在同一集合
    if (rnk[x] < rnk[y]) swap(x, y);
    fa[y] = x;
    if (rnk[x] == rnk[y]) rnk[x]++;
    return true;
}

int main() {
    int n, m;
    cin >> n >> m;
    init(n);
    while (m--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (op == 1) unite(x, y);
        else cout << (find(x) == find(y) ? "Y" : "N") << '\n';
    }
    return 0;
}
```

**进阶：带权并查集（食物链问题）**

有A吃B、B吃C、C吃A的食物链，给定若干关系判断，求有多少条是假话。

```cpp
#include <bits/stdc++.h>
using namespace std;

int fa[50005], d[50005];  // d[x]表示x到fa[x]的关系：0同类，1吃fa[x]，2被fa[x]吃

int find(int x) {
    if (fa[x] == x) return x;
    int root = find(fa[x]);
    d[x] = (d[x] + d[fa[x]]) % 3;  // 路径压缩时更新关系
    return fa[x] = root;
}

int main() {
    int n, k;
    cin >> n >> k;
    for (int i = 1; i <= n; i++) { fa[i] = i; d[i] = 0; }
    
    int ans = 0;
    while (k--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (x > n || y > n || (op == 2 && x == y)) { ans++; continue; }
        int fx = find(x), fy = find(y);
        if (op == 1) {  // x和y同类
            if (fx == fy) {
                if (d[x] != d[y]) ans++;  // 矛盾
            } else {
                fa[fx] = fy;
                d[fx] = (d[y] - d[x] + 3) % 3;
            }
        } else {  // x吃y
            if (fx == fy) {
                if ((d[x] - d[y] + 3) % 3 != 1) ans++;
            } else {
                fa[fx] = fy;
                d[fx] = (d[y] - d[x] + 4) % 3;
            }
        }
    }
    cout << ans << '\n';
    return 0;
}
```

本讲介绍了并查集。关键要点：并查集用树表示集合，支持Find和Union操作；路径压缩和按秩合并使单次操作接近O(1)；带权并查集可维护节点间的关系信息。并查集适用于连通性判断、等价类划分等场景。常见注意事项：初始化时`fa[i]=i`别忘了；路径压缩的递归写法简洁但注意栈深度，数据量大时可改迭代；带权并查集的关系更新公式需仔细推导，建议画图验证；合并时注意方向，避免破坏已有关系。

## 第10讲：树状数组与线段树

### 概念

树状数组（Binary Indexed Tree，BIT，又称Fenwick树）和线段树（Segment Tree）是两种支持区间查询和单点/区间修改的高效数据结构。它们能在O(log n)时间内完成更新和查询，是处理动态序列问题的核心工具。

树状数组基于二进制lowbit思想，结构轻量、常数小，但功能有限——主要用于前缀和查询和单点修改，配合差分技巧可扩展到区间修改+区间查询。线段树基于分治思想，结构灵活、功能强大，支持各种区间操作（求和、最值、区间赋值、区间加等），但常数较大、实现复杂。

选择原则：能用树状数组就用树状数组（代码短、常数小），需要复杂区间操作时才用线段树。

### 原理

**树状数组原理**：将数组划分为若干区间，每个区间长度为lowbit的值。定义`c[i]`管理区间`[i-lowbit(i)+1, i]`，其中`lowbit(i) = i & (-i)`表示i的二进制最低位1的值。查询前缀和`sum(i)`时，将i不断减去lowbit累加c值；修改`a[i]`时，将i不断加上lowbit更新c值。两者都是O(log n)。

树状数组的精妙之处在于：利用二进制分解，任意前缀`[1, x]`可以分解为若干个互不重叠的区间，这些区间恰好对应树状数组的若干节点。例如`sum(13) = sum([1,8]) + sum([9,12]) + sum([13,13])`，对应`c[8] + c[12] + c[13]`。

**线段树原理**：将区间`[1, n]`递归二分为子区间，每个节点管理一个区间。叶子节点管理单点，内部节点管理子区间并维护区间信息（如和、最值）。查询和修改时，从根出发递归访问相关节点，利用"懒标记"（Lazy Tag）延迟区间修改。

懒标记的原理是：当对一个区间整体修改时，不立即更新所有叶子，而是在管理该区间的节点上打标记，记录"这个区间需要整体加/乘某个值"。只有当需要访问该区间的子区间时，才将标记下传（pushdown）。这样区间修改也是O(log n)。

### 例子

**树状数组：单点修改+前缀查询**

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
int c[500005];

int lowbit(int x) { return x & (-x); }

void update(int i, int v) {  // a[i] += v
    for (; i <= n; i += lowbit(i)) c[i] += v;
}

int query(int i) {  // 求a[1]+...+a[i]
    int s = 0;
    for (; i > 0; i -= lowbit(i)) s += c[i];
    return s;
}

int main() {
    int m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        int x; cin >> x;
        update(i, x);
    }
    while (m--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (op == 1) update(x, y);       // a[x] += y
        else cout << query(y) - query(x-1) << '\n';  // 区间[x,y]的和
    }
    return 0;
}
```

**线段树：区间修改+区间查询（带懒标记）**

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int N = 100005;
ll a[N], tree[4*N], lazy[4*N];

void build(int p, int l, int r) {
    if (l == r) { tree[p] = a[l]; return; }
    int mid = (l + r) / 2;
    build(2*p, l, mid);
    build(2*p+1, mid+1, r);
    tree[p] = tree[2*p] + tree[2*p+1];
}

void pushdown(int p, int l, int r) {
    if (lazy[p]) {
        int mid = (l + r) / 2;
        tree[2*p] += lazy[p] * (mid - l + 1);
        lazy[2*p] += lazy[p];
        tree[2*p+1] += lazy[p] * (r - mid);
        lazy[2*p+1] += lazy[p];
        lazy[p] = 0;
    }
}

void update(int p, int l, int r, int ql, int qr, ll v) {
    if (qr < l || r < ql) return;
    if (ql <= l && r <= qr) {
        tree[p] += v * (r - l + 1);
        lazy[p] += v;
        return;
    }
    pushdown(p, l, r);
    int mid = (l + r) / 2;
    update(2*p, l, mid, ql, qr, v);
    update(2*p+1, mid+1, r, ql, qr, v);
    tree[p] = tree[2*p] + tree[2*p+1];
}

ll query(int p, int l, int r, int ql, int qr) {
    if (qr < l || r < ql) return 0;
    if (ql <= l && r <= qr) return tree[p];
    pushdown(p, l, r);
    int mid = (l + r) / 2;
    return query(2*p, l, mid, ql, qr) + query(2*p+1, mid+1, r, ql, qr);
}

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];
    build(1, 1, n);
    while (m--) {
        int op, l, r;
        cin >> op >> l >> r;
        if (op == 1) {
            ll v; cin >> v;
            update(1, 1, n, l, r, v);  // 区间加v
        } else {
            cout << query(1, 1, n, l, r) << '\n';  // 区间求和
        }
    }
    return 0;
}
```

### 总结

本讲介绍了树状数组和线段树。关键要点：树状数组基于lowbit，轻量高效，适合前缀和类问题；线段树基于分治，功能强大，支持各种区间操作；懒标记实现区间修改的延迟传播。选择上优先树状数组，复杂需求用线段树。常见注意事项：树状数组下标从1开始（lowbit(0)=0会死循环）；线段树数组开4倍空间防越界；懒标记要及时pushdown，否则查询结果错误；线段树的pushup（向上更新）和pushdown（向下传播）要成对出现。

## 第11讲：ST表与RMQ问题

### 概念

ST表（Sparse Table，稀疏表）是一种基于倍增思想的数据结构，用于解决静态RMQ（Range Minimum/Maximum Query，区间最值查询）问题。所谓"静态"指数据预处理后不再修改，只支持查询。ST表能在O(n log n)预处理后，以O(1)的时间回答任意区间最值查询，是处理静态RMQ的最优方案。

ST表的核心思想是倍增（Doubling）：预处理出所有长度为2^k的区间的最值，查询时将任意区间分解为两个（可能重叠的）2^k长度区间，取最值即可。这种"用两个区间覆盖查询区间"的技巧使得查询只需O(1)。

需要注意的是，ST表只适用于满足"可重复贡献"性质的操作，即`f(a,a) = a`的操作，如max、min、gcd、按位与/或。对于加法、乘法等不满足此性质的操作，区间查询不能用ST表（因为重叠区间会被计算两次），需要用前缀和或线段树。

### 原理

ST表的预处理基于递推：设`st[i][j]`表示从位置i开始、长度为2^j的区间的最值。递推公式为：

```
st[i][j] = max(st[i][j-1], st[i + 2^(j-1)][j-1])
```

即长度为2^j的区间可以拆分为两个长度为2^(j-1)的子区间。预处理时按j从小到大递推，总共有O(log n)层，每层O(n)个元素，故预处理O(n log n)。

查询区间`[l, r]`时，令`k = log2(r - l + 1)`，则：

```
ans = max(st[l][k], st[r - 2^k + 1][k])
```

这两个区间长度都是2^k，一个从l开始向右，一个从r开始向左，它们的并集恰好覆盖`[l, r]`（可能重叠，但max操作允许重叠）。由于只查两个值，查询是O(1)的。

对数函数可以预处理：`log2[i] = log2[i/2] + 1`，避免每次调用库函数。也可以直接用`__lg(x)`或`31 - __builtin_clz(x)`等内置函数。

### 例子

**ST表求区间最大值**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005, MAXLOG = 17;
int st[MAXN][MAXLOG];
int lg2[MAXN];

void init(int n, int a[]) {
    // 预处理log2表
    lg2[1] = 0;
    for (int i = 2; i <= n; i++) lg2[i] = lg2[i/2] + 1;
    
    // 初始化长度为1的区间
    for (int i = 1; i <= n; i++) st[i][0] = a[i];
    
    // 递推预处理
    for (int j = 1; (1 << j) <= n; j++) {
        for (int i = 1; i + (1 << j) - 1 <= n; i++) {
            st[i][j] = max(st[i][j-1], st[i + (1 << (j-1))][j-1]);
        }
    }
}

int query(int l, int r) {
    int k = lg2[r - l + 1];
    return max(st[l][k], st[r - (1 << k) + 1][k]);
}

int main() {
    int n, m;
    cin >> n >> m;
    int a[MAXN];
    for (int i = 1; i <= n; i++) cin >> a[i];
    init(n, a);
    while (m--) {
        int l, r;
        cin >> l >> r;
        cout << query(l, r) << '\n';
    }
    return 0;
}
```

### 总结

本讲介绍了ST表与RMQ问题。关键要点：ST表基于倍增思想，预处理O(n log n)、查询O(1)；只适用于"可重复贡献"操作（max/min/gcd等）；查询时用两个2^k区间覆盖目标区间。ST表是静态RMQ的最优解，动态RMQ需用线段树。常见注意事项：log2表要预处理，避免每次调用库函数；注意区间边界，`r - 2^k + 1`不要越界；ST表不支持修改，若数据动态变化需换用线段树；空间复杂度O(n log n)，注意数组大小。

# 第四章：图论

## 第12讲：图的存储与遍历

### 概念

图（Graph）是由顶点集V和边集E组成的数据结构，记为G=(V,E)。图分为有向图（边有方向）和无向图（边无方向），边可以带权（有权图）或不带权（无权图）。在ACM竞赛中，图论是最大的知识板块之一，涉及存储、遍历、最短路、生成树、网络流等众多专题。

图的存储主要有两种方式：邻接矩阵和邻接表。邻接矩阵用二维数组`g[i][j]`表示边(i,j)，适合稠密图（边数接近点数平方），但空间O(V²)。邻接表为每个顶点维护一个链表（或vector），存储其所有邻接边，适合稀疏图（边数远小于点数平方），空间O(V+E)。竞赛中绝大多数图是稀疏图，因此邻接表更常用。

图的遍历主要有两种方式：深度优先搜索（DFS）和广度优先搜索（BFS）。DFS沿一条路径深入到底再回溯，用递归或栈实现；BFS逐层扩展，用队列实现。两者都是O(V+E)复杂度，是图论算法的基础。

### 原理

**邻接表存储原理**：使用`vector`数组，`adj[u]`存储从u出发的所有边。对于带权图，边通常用结构体或pair存储`(目标点, 权值)`。邻接表的优势在于：空间高效（只存实际存在的边）、遍历邻接边快速（O(度数)）、支持重边和自环。

**链式前向星**是竞赛中另一种常用的存储方式，用数组模拟链表，比vector更省内存、稍快。其结构为：`head[u]`指向u的第一条边，每条边记录`to`、`weight`、`next`（下一条边的下标）。添加边时头插法插入。

**DFS原理**：从起点出发，访问一个未访问的邻接点，递归深入，直到没有未访问邻接点时回溯。DFS用`visited`数组标记已访问点，避免重复访问。DFS的特点是"深入优先"，适合连通性判断、环检测、拓扑排序等。

**BFS原理**：从起点出发，将起点入队，每次取出队头，访问其所有未访问邻接点并入队。BFS的特点是"逐层扩展"，在无权图中最先到达某点的路径就是最短路径。BFS适合求无权图最短路、层次遍历、连通块统计等。

### 例子

**图的存储与DFS/BFS遍历**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
vector<pair<int,int>> adj[N];  // 邻接表：{目标点, 权值}
bool vis[N];

// DFS遍历
void dfs(int u) {
    vis[u] = true;
    cout << u << " ";
    for (auto& [v, w] : adj[u]) {
        if (!vis[v]) dfs(v);
    }
}

// BFS遍历
void bfs(int start) {
    queue<int> q;
    q.push(start);
    vis[start] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        cout << u << " ";
        for (auto& [v, w] : adj[u]) {
            if (!vis[v]) {
                vis[v] = true;
                q.push(v);
            }
        }
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        adj[u].push_back({v, w});
        adj[v].push_back({u, w});  // 无向图，双向加边
    }
    
    memset(vis, false, sizeof(vis));
    dfs(1);
    cout << '\n';
    
    memset(vis, false, sizeof(vis));
    bfs(1);
    cout << '\n';
    return 0;
}
```

**链式前向星存储**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005, M = 200005;
int head[N], cnt = 0;
struct Edge {
    int to, w, next;
} edge[M];

void addEdge(int u, int v, int w) {
    edge[++cnt] = {v, w, head[u]};
    head[u] = cnt;
}

void dfs(int u, bool vis[]) {
    vis[u] = true;
    for (int i = head[u]; i; i = edge[i].next) {
        int v = edge[i].to;
        if (!vis[v]) dfs(v, vis);
    }
}
```

**应用：求连通块数量**

```cpp

    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        if (!vis[i]) {
            dfs(i);
            cnt++;
        }
    }
    cout << cnt << '\n';  // 连通块数
    return 0;
}
```

### 总结

本讲介绍了图的存储与遍历。关键要点：邻接表适合稀疏图，邻接矩阵适合稠密图；链式前向星是竞赛中省内存的选择；DFS用递归/栈，BFS用队列，均为O(V+E)。DFS适合连通性和环检测，BFS适合无权最短路和层次遍历。常见注意事项：无向图每条边要在两个方向各加一次；DFS递归深度大时可能栈溢出，可改用栈模拟或手动扩栈；遍历前务必初始化vis数组；注意图可能不连通，需要遍历所有未访问点。

## 第13讲：最短路径算法

### 概念

最短路径问题是图论中最经典的问题之一：给定图和起点（可能还有终点），求两点间权值和最小的路径。根据图的特性不同，有不同的算法：Dijkstra算法适用于非负权图的单源最短路，Bellman-Ford和SPFA适用于含负权图的单源最短路，Floyd算法适用于求所有点对间的最短路。

Dijkstra算法基于贪心思想，每次从未确定最短路的点中选距离最小的，用它更新邻接点。时间复杂度O((V+E)log V)（堆优化版），是竞赛中最常用的最短路算法。Bellman-Ford基于松弛操作，能处理负权并检测负环，复杂度O(VE)。SPFA是Bellman-Ford的队列优化版，平均复杂度O(kE)但最坏O(VE)。Floyd基于动态规划，复杂度O(V³)，适合点数少的稠密图。

### 原理

**Dijkstra原理**：维护一个距离数组`dist[]`，初始时起点dist为0、其余为无穷。使用优先队列（小根堆）每次取出dist最小的未确定点u，标记u已确定，然后用`dist[u] + w(u,v)`更新u的邻接点v的dist。由于非负权保证已确定点的dist不会更优，贪心是正确的。堆优化使得每次取最小是O(log V)，总复杂度O((V+E)log V)。

**Bellman-Ford原理**：对每条边进行V-1轮松弛操作（`dist[v] = min(dist[v], dist[u] + w)`）。由于最短路径最多V-1条边，V-1轮松弛必能收敛。若第V轮仍能松弛，说明存在负环。复杂度O(VE)。

**SPFA原理**：Bellman-Ford的优化——只有dist被更新过的点才可能更新其邻接点，因此用队列维护待松弛的点。每次取出队首u，松弛其所有出边，若v的dist被更新且v不在队中则入队。SPFA在随机图上很快，但可被特殊数据卡到O(VE)，竞赛中慎用。

**Floyd原理**：动态规划思想，`dist[k][i][j]`表示只经过前k个点时i到j的最短路。递推：`dist[k][i][j] = min(dist[k-1][i][j], dist[k-1][i][k] + dist[k-1][k][j])`。空间优化为二维后，注意k必须是最外层循环。

### 例子

**Dijkstra（堆优化）**：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef pair<ll,int> pli;

const int N = 100005;
vector<pair<int,ll>> adj[N];  // {目标, 权值}
ll dist[N];

int main() {
    int n, m, s;
    cin >> n >> m >> s;
    for (int i = 0; i < m; i++) {
        int u, v; ll w;
        cin >> u >> v >> w;
        adj[u].push_back({v, w});
    }
    
    // 初始化
    for (int i = 1; i <= n; i++) dist[i] = LLONG_MAX;
    dist[s] = 0;
    
    priority_queue<pli, vector<pli>, greater<pli>> pq;  // 小根堆
    pq.push({0, s});
    
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;  // 过期数据，跳过
        for (auto& [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    
    for (int i = 1; i <= n; i++)
        cout << (dist[i] == LLONG_MAX ? -1 : dist[i]) << " \n"[i==n];
    return 0;
}
```

**SPFA（含负权检测）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 2005;
vector<pair<int,int>> adj[N];
int dist[N], cnt[N];  // cnt记录入队次数，用于检测负环
bool inQueue[N];

bool spfa(int n, int s) {
    queue<int> q;
    memset(dist, 0x3f, sizeof(dist));
    memset(cnt, 0, sizeof(cnt));
    memset(inQueue, false, sizeof(inQueue));
    
    dist[s] = 0;
    q.push(s);
    inQueue[s] = true;
    cnt[s] = 1;
    
    while (!q.empty()) {
        int u = q.front(); q.pop();
        inQueue[u] = false;
        for (auto& [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                if (!inQueue[v]) {
                    q.push(v);
                    inQueue[v] = true;
                    if (++cnt[v] >= n) return false;  // 负环
                }
            }
        }
    }
    return true;
}
```

**Floyd（全源最短路）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 205;
int dist[N][N];
const int INF = 0x3f3f3f3f;

int main() {
    int n, m;
    cin >> n >> m;
    memset(dist, 0x3f, sizeof(dist));
    for (int i = 1; i <= n; i++) dist[i][i] = 0;
    for (int i = 0; i < m; i++) {
        int u, v, w; cin >> u >> v >> w;
        dist[u][v] = min(dist[u][v], w);  // 处理重边
    }
    
    // Floyd：注意k在最外层
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                if (dist[i][k] + dist[k][j] < dist[i][j])
                    dist[i][j] = dist[i][k] + dist[k][j];
    
    // 输出1到n的最短路
    cout << (dist[1][n] >= INF ? -1 : dist[1][n]) << '\n';
    return 0;
}
```

### 总结

本讲介绍了三种最短路算法。关键要点：Dijkstra适用于非负权图，堆优化O((V+E)log V)，是首选；SPFA处理负权但可能被卡，慎用；Floyd全源最短路O(V³)，适合n≤200的稠密图。选择策略：非负权用Dijkstra，有负权用SPFA，求所有点对用Floyd。常见注意事项：Dijkstra不能处理负权（贪心失效）；注意INF的大小，既要足够大表示无穷，又不能太大导致加法溢出；Floyd的k循环必须最外层；SPFA判负环用入队次数≥n。

## 第14讲：最小生成树

### 概念

最小生成树（Minimum Spanning Tree，MST）是无向连通图中边权之和最小的生成树。生成树是包含图中所有顶点的无环连通子图，n个顶点的生成树恰好有n-1条边。最小生成树在网络设计、聚类分析等领域有广泛应用。

求最小生成树有两种经典算法：Kruskal算法和Prim算法。Kruskal算法基于并查集，按边权从小到大排序，依次加入不构成环的边，时间复杂度O(E log E)。Prim算法基于贪心扩展，从一个点出发逐步加入最小权值的跨边，用堆优化后复杂度O(E log V)。稀疏图（E小）适合Kruskal，稠密图（E大）适合Prim。

### 原理

**Kruskal原理**：基于"避圈思想"——按边权升序考察每条边，若该边两端点不在同一连通块（加入不形成环），则选中该边并合并两个连通块。选够n-1条边即得MST。正确性基于贪心：权值最小的边若不形成环，必在某个MST中（可用割边定理证明）。并查集用于高效判断连通性和合并，单次操作接近O(1)，排序是主要开销O(E log E)。

**Prim原理**：基于"扩展思想"——从一个点出发，维护已选点集S和未选点集T，每次从连接S和T的边中选权值最小的，将对应T中点加入S。重复n-1次。正确性同样基于割边定理：连接S和T的最小边必在MST中。用优先队列维护跨边，每次取最小O(log V)，总复杂度O(E log V)。

**割边定理（Cut Property）**：对图的任意一个割（将顶点分为S和T两部分），连接S和T的权值最小的边必在某个MST中。这是两种算法正确性的理论基础。

### 例子

**Kruskal算法**：

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Edge {
    int u, v, w;
    bool operator<(const Edge& o) const { return w < o.w; }
};

int fa[5005];

int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

int main() {
    int n, m;
    cin >> n >> m;
    vector<Edge> edges(m);
    for (int i = 0; i < m; i++)
        cin >> edges[i].u >> edges[i].v >> edges[i].w;
    
    sort(edges.begin(), edges.end());
    for (int i = 1; i <= n; i++) fa[i] = i;
    
    long long total = 0;
    int cnt = 0;
    for (auto& e : edges) {
        int fu = find(e.u), fv = find(e.v);
        if (fu != fv) {
            fa[fu] = fv;
            total += e.w;
            cnt++;
            if (cnt == n - 1) break;
        }
    }
    
    if (cnt < n - 1) cout << "orz\n";  // 图不连通
    else cout << total << '\n';
    return 0;
}
```

**Prim算法（堆优化）**：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef pair<int,int> pii;

const int N = 5005;
vector<pii> adj[N];  // {目标, 权值}
bool vis[N];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v, w; cin >> u >> v >> w;
        adj[u].push_back({v, w});
        adj[v].push_back({u, w});
    }
    
    priority_queue<pii, vector<pii>, greater<pii>> pq;  // {权值, 点}
    pq.push({0, 1});
    
    long long total = 0;
    int cnt = 0;
    while (!pq.empty() && cnt < n) {
        auto [w, u] = pq.top(); pq.pop();
        if (vis[u]) continue;
        vis[u] = true;
        total += w;
        cnt++;
        for (auto& [v, w2] : adj[u]) {
            if (!vis[v]) pq.push({w2, v});
        }
    }
    
    if (cnt < n) cout << "orz\n";
    else cout << total << '\n';
    return 0;
}
```

### 总结

本讲介绍了最小生成树的两种算法。关键要点：Kruskal基于并查集，按边排序贪心选边，O(E log E)；Prim基于堆，从点扩展选最小跨边，O(E log V)。稀疏图用Kruskal，稠密图用Prim。两者都基于割边定理保证正确性。常见注意事项：Kruskal注意图是否连通，选不够n-1条边说明不连通；Prim的堆中可能有同一点的多条边，用vis数组去重；注意无向图加双向边；处理重边时Kruskal自动取最小（排序后先选小的），Prim需在加边时取min。

## 第15讲：拓扑排序与关键路径

### 概念

拓扑排序（Topological Sort）是对有向无环图（DAG）的顶点进行线性排序，使得对每条有向边(u,v)，u在排序中位于v之前。拓扑排序在任务调度、编译依赖、课程安排等场景有广泛应用。若图中存在环，则不存在拓扑排序。

拓扑排序有两种实现方式：Kahn算法（基于入度）和DFS算法（基于后序）。Kahn算法维护入度为0的点集，每次取出一个并删除其出边，重复直到所有点处理完。DFS算法在递归返回时记录节点，最终逆序即为拓扑序。

关键路径（Critical Path）是AOE网（Activity On Edge，边表示活动）中从源点到汇点的最长路径，决定了工程的最短完成时间。关键路径上的活动称为关键活动，任何延迟都会影响总工期。关键路径基于拓扑排序和逆拓扑排序计算。

### 原理

**Kahn算法原理**：维护每个顶点的入度，将入度为0的点入队。每次取出队首u，将其所有出边删除（即邻接点入度减1），若某邻接点入度变为0则入队。最终若处理了所有n个点则得到拓扑序，否则存在环。算法正确性在于：入度为0的点没有前驱，可以安全排在最前；删除其出边后，新的入度为0的点也没有前驱了。

**DFS拓扑排序原理**：对DAG做DFS，在递归返回时（即节点的所有后继都已处理完）将节点压入栈。最终栈的弹出顺序就是拓扑序。正确性在于：若存在边(u,v)，则v在u之前完成DFS（v是u的后继，先被访问完），因此v先入栈，u后入栈，弹出时u在v前。若DFS遇到正在访问的点（非已访问），说明有环。

**关键路径原理**：计算两个数组——最早发生时间ve[v]（从源点到v的最长路径）和最晚发生时间vl[v]（不延误总工期的前提下v的最晚发生时间）。ve用拓扑序正向计算：`ve[v] = max(ve[u] + w(u,v))`。vl用逆拓扑序反向计算：`vl[u] = min(vl[v] - w(u,v))`。若某边满足`ve[u] == vl[v] - w(u,v)`，则为关键活动。

### 例子

**拓扑排序（Kahn算法）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100005;
vector<int> adj[N];
int inDeg[N];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v);
        inDeg[v]++;
    }
    
    queue<int> q;
    for (int i = 1; i <= n; i++)
        if (inDeg[i] == 0) q.push(i);
    
    vector<int> topo;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo.push_back(u);
        for (int v : adj[u]) {
            if (--inDeg[v] == 0) q.push(v);
        }
    }
    
    if (topo.size() < n) {
        cout << "有环\n";
    } else {
        for (int x : topo) cout << x << " ";
        cout << '\n';
    }
    return 0;
}
```

**关键路径（AOE网）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1005;
vector<pair<int,int>> adj[N], radj[N];  // 正图和反图
int inDeg[N], outDeg[N];
int ve[N], vl[N];  // 最早/最晚发生时间

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v, w; cin >> u >> v >> w;
        adj[u].push_back({v, w});
        radj[v].push_back({u, w});
        inDeg[v]++;
        outDeg[u]++;
    }
    
    // 找源点（入度为0）和汇点（出度为0）
    // 正向拓扑求ve
    queue<int> q;
    for (int i = 1; i <= n; i++)
        if (inDeg[i] == 0) { q.push(i); ve[i] = 0; }
    
    vector<int> topo;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo.push_back(u);
        for (auto& [v, w] : adj[u]) {
            ve[v] = max(ve[v], ve[u] + w);
            if (--inDeg[v] == 0) q.push(v);
        }
    }
    
    // 找汇点，其ve值即为总工期
    int sink = 0, total = 0;
    for (int i = 1; i <= n; i++)
        if (outDeg[i] == 0) { sink = i; total = ve[i]; }
    
    // 反向求vl
    for (int i = 1; i <= n; i++) vl[i] = total;
    for (int i = topo.size() - 1; i >= 0; i--) {
        int u = topo[i];
        for (auto& [v, w] : adj[u]) {
            vl[u] = min(vl[u], vl[v] - w);
        }
    }
    
    // 输出关键活动
    cout << "关键活动：\n";
    for (int u = 1; u <= n; u++) {
        for (auto& [v, w] : adj[u]) {
            if (ve[u] == vl[v] - w) {  // 关键活动
                cout << u << " -> " << v << " : " << w << '\n';
            }
        }
    }
    cout << "总工期：" << total << '\n';
    return 0;
}
```

### 总结

本讲介绍了拓扑排序与关键路径。关键要点：拓扑排序只对DAG存在，Kahn算法基于入度，DFS基于后序；关键路径是AOE网的最长路径，决定工程最短工期。拓扑排序是很多图论算法的预处理步骤（如DP求DAG最长路）。常见注意事项：拓扑排序前先判环，有环则无解；Kahn算法处理完若点数不足n说明有环；关键路径中ve正向取max、vl反向取min，注意初始化；关键活动可能不止一条关键路径，需全部考虑。

# 第五章：动态规划

## 第16讲：线性DP

### 概念

动态规划（Dynamic Programming，DP）是一种通过将复杂问题分解为子问题、存储子问题解来避免重复计算的算法思想。线性DP是最基础的DP类型，状态按线性顺序（一维或二维）排列，状态转移从前往后或从后往前进行。

线性DP的核心要素包括：状态定义（dp数组表示什么）、状态转移方程（dp如何从其他状态推导）、初始条件（边界值）、计算顺序（保证依赖关系满足）。掌握线性DP是学习更高级DP（背包、区间、树形等）的基础。

经典的线性DP问题包括：最长上升子序列（LIS）、最长公共子序列（LCS）、数字三角形、编辑距离等。这些问题虽然形式各异，但都遵循"定义状态→推导转移方程→确定计算顺序"的统一框架。

### 原理

动态规划的有效性基于两个性质：**最优子结构**（问题的最优解包含子问题的最优解）和**无后效性**（当前状态确定后，未来的决策不受过去路径的影响）。满足这两个性质的问题才能用DP求解。

**状态设计原则**：状态应完整描述问题的子结构，同时满足无后效性。状态数过多会导致空间/时间超限，状态过少会破坏无后效性。通常从"问题所求"出发设计状态：求什么就定义dp表示什么。

**转移方程推导**：考虑当前状态的"最后一步"决策——从哪些前驱状态可以转移到当前状态，转移代价是什么。例如LIS中，dp[i]表示以a[i]结尾的最长上升子序列长度，转移为`dp[i] = max(dp[j]) + 1`（对所有j<i且a[j]<a[i]）。

**计算顺序**：按依赖关系确定。若dp[i]依赖dp[j]（j<i），则从前往后计算；若依赖dp[j]（j>i），则从后往前。二维DP通常按行或列顺序计算。滚动数组可优化空间：若dp[i]只依赖dp[i-1]，则只需两行。

### 例子

**最长上升子序列（LIS）——O(n²)做法**：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    
    vector<int> dp(n, 1);  // dp[i]: 以a[i]结尾的LIS长度
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (a[j] < a[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
    }
    cout << *max_element(dp.begin(), dp.end()) << '\n';
    return 0;
}
```

**LIS——O(n log n)做法（二分优化）**：

```cpp
#include <bits/stdc++.h>

    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    for (int x : a) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    cout << tails.size() << '\n';  // LIS长度
```

**最长公共子序列（LCS）**：

```cpp
#include <bits/stdc++.h>

int main() {

    cin >> s >> t;
    int n = s.size(), m = t.size();

    vector<vector<int>> dp(n+1, vector<int>(m+1, 0));
    
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (s[i-1] == t[j-1]) {
                dp[i][j] = dp[i-1][j-1] + 1;
            } else {
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
            }
        }
    }
```

```cpp
            dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + a[i][j];

}
```

## 第17讲：背包问题

### 概念

背包问题是DP中最经典的一类问题：有n个物品和一个容量为W的背包，每个物品有重量和价值，求在不超过背包容量的前提下，能获得的最大价值。根据物品的选取限制，背包问题分为多种类型：0-1背包（每件物品最多选一次）、完全背包（每件物品可选无限次）、多重背包（每件物品有数量限制）、分组背包（物品分组，每组最多选一件）。

背包问题是DP思想的集中体现，其状态设计和转移方程清晰规范，是学习DP的绝佳素材。掌握各类背包问题的解法，不仅能应对直接考察背包的题目，还能将许多看似无关的问题转化为背包模型求解。

### 原理

**0-1背包原理**：定义`dp[j]`为容量为j时的最大价值。对每个物品，从大到小遍历容量j（保证每件物品只选一次），转移`dp[j] = max(dp[j], dp[j-w[i]] + v[i])`。倒序遍历是关键——若正序遍历，同一物品可能被选多次。时间O(nW)，空间O(W)。

**完全背包原理**：与0-1背包类似，但物品可选无限次。关键区别是正序遍历容量j——这样dp[j-w[i]]可能已经包含了当前物品，相当于选了多次。转移方程相同：`dp[j] = max(dp[j], dp[j-w[i]] + v[i])`。

**多重背包原理**：每件物品有s[i]个。朴素做法是将s[i]个物品拆成s[i]个独立物品做0-1背包，但复杂度O(nW·s)。优化方法有二进制拆分和单调队列优化。二进制拆分将s[i]拆成1,2,4,...,2^k,剩余的数，用这些组合可以表示1~s[i]的任意数量，复杂度降为O(nW·log s)。

**分组背包原理**：物品分为若干组，每组最多选一件。对每组，遍历容量从大到小，对组内每件物品做0-1背包转移。关键在于"组"是外层循环，保证每组只选一件。

### 例子

**0-1背包**：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, W;
    cin >> n >> W;
    vector<int> w(n), v(n);
    for (int i = 0; i < n; i++) cin >> w[i] >> v[i];
    
    vector<int> dp(W+1, 0);
    for (int i = 0; i < n; i++) {
        for (int j = W; j >= w[i]; j--) {  // 倒序！
            dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
        }
    }
    cout << dp[W] << '\n';
    return 0;
}
```

**完全背包**：

**多重背包（二进制拆分）**：

```cpp
#include <bits/stdc++.h>

int main() {
    int n, W;
    cin >> n >> W;
    vector<int> dp(W+1, 0);
    
    for (int i = 0; i < n; i++) {
        int w, v, s;
        cin >> w >> v >> s;

        for (int k = 1; k <= s; k *= 2) {

            }
            s -= k;
        }
        if (s > 0) {  // 剩余部分
            for (int j = W; j >= s * w; j--) {
                dp[j] = max(dp[j], dp[j - s*w] + s*v);
            }
        }
    }
    cout << dp[W] << '\n';
    return 0;
}
```

## 第18讲：区间DP与树形DP

### 概念

区间DP是一类特殊的状态设计：`dp[i][j]`表示区间[i,j]上的最优解。状态转移通常通过"枚举分割点k"实现：将区间[i,j]分为[i,k]和[k+1,j]两部分，合并两部分的解得到整体解。经典问题包括石子合并、矩阵链乘、回文串等。区间DP的计算顺序按区间长度从小到大，时间复杂度通常为O(n³)。

树形DP是在树结构上进行动态规划。树的特殊性质——无环、父子关系明确——使得DP可以沿树自底向上（从叶子到根）进行。树形DP的状态通常定义在"以节点u为根的子树"上，转移时合并各子树的信息。经典问题包括没有上司的舞会、树的最长路径、树的直径等。

### 原理

**区间DP原理**：大区间的解依赖于小区间的解。计算时按区间长度len从1到n枚举，对每个长度枚举起点i（终点j=i+len-1），再枚举分割点k（i≤k<j），用`dp[i][k]`和`dp[k+1][j]`合并出`dp[i][j]`。这种"由短到长"的计算顺序保证了计算大区间时所需的小区间已计算完毕。

以石子合并为例：`dp[i][j]`表示合并区间[i,j]的最小代价，转移为`dp[i][j] = min(dp[i][k] + dp[k+1][j] + sum[i,j])`，其中sum[i,j]是区间和（最后一次合并的代价）。利用前缀和可O(1)计算区间和。

**树形DP原理**：在树上做后序DFS，先递归处理所有子树，再在当前节点合并子树信息。树形DP的关键是"子树独立性"——每个子树的内部决策不影响其他子树，因此可以独立求解后合并。

以"没有上司的舞会"为例：`dp[u][0/1]`表示以u为根的子树中，u不参加/参加舞会时的最大快乐值。转移：`dp[u][0] = sum(max(dp[v][0], dp[v][1]))`（u不参加，下属可参加可不参加）；`dp[u][1] = val[u] + sum(dp[v][0])`（u参加，下属都不能参加）。

### 例子

**石子合并（区间DP）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n+1), sum(n+1, 0);
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        sum[i] = sum[i-1] + a[i];  // 前缀和
    }
    
    // dp[i][j]: 合并区间[i,j]的最小代价
    vector<vector<int>> dp(n+1, vector<int>(n+1, 0));
    
    for (int len = 2; len <= n; len++) {  // 区间长度
        for (int i = 1; i + len - 1 <= n; i++) {  // 起点
            int j = i + len - 1;
            dp[i][j] = INT_MAX;
            for (int k = i; k < j; k++) {  // 分割点
                int cost = dp[i][k] + dp[k+1][j] + sum[j] - sum[i-1];
                dp[i][j] = min(dp[i][j], cost);
            }
        }
    }
    cout << dp[1][n] << '\n';
    return 0;
}
```

**没有上司的舞会（树形DP）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<int> children[6005];
int val[6005];
int dp[6005][2];  // dp[u][0]: u不参加, dp[u][1]: u参加
bool hasParent[6005];

void dfs(int u) {
    dp[u][0] = 0;
    dp[u][1] = val[u];
    for (int v : children[u]) {
        dfs(v);
        dp[u][0] += max(dp[v][0], dp[v][1]);  // u不参加，下属自由
        dp[u][1] += dp[v][0];  // u参加，下属不参加
    }
}

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> val[i];
    for (int i = 0; i < n - 1; i++) {
        int u, v;  // v是u的上司
        cin >> u >> v;
        children[v].push_back(u);
        hasParent[u] = true;
    }
    // 找根节点（没有父节点的）
    int root = 1;
    for (int i = 1; i <= n; i++)
        if (!hasParent[i]) { root = i; break; }
    
    dfs(root);
    cout << max(dp[root][0], dp[root][1]) << '\n';
    return 0;
}
```

**树的直径（树形DP）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<pair<int,int>> adj[200005];  // {目标, 权值}
int ans = 0;

// 返回从u出发向下的最长路径
int dfs(int u, int parent) {
    int maxLen = 0;  // 最长下行路径
    for (auto& [v, w] : adj[u]) {
        if (v == parent) continue;
        int len = dfs(v, u) + w;
        ans = max(ans, maxLen + len);  // 经过u的最长路径
        maxLen = max(maxLen, len);
    }
    return maxLen;
}

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n - 1; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        adj[u].push_back({v, w});
        adj[v].push_back({u, w});
    }
    dfs(1, 0);
    cout << ans << '\n';  // 树的直径
    return 0;
}
```

### 总结

本讲介绍了区间DP和树形DP。关键要点：区间DP按长度枚举，枚举分割点合并，O(n³)；树形DP自底向上DFS，合并子树信息。区间DP适用于"合并"类问题，树形DP适用于树结构上的最优化问题。常见注意事项：区间DP注意计算顺序（先短后长）和边界（len=1时dp[i][i]）；树形DP注意找根节点、避免重复访问父节点（传parent参数）；树形DP可能需要换根（两次DFS）处理"以每个点为根"的问题；区间DP可用四边形不等式优化到O(n²)，但竞赛中较少需要。

## 第19讲：状压DP与数位DP

### 概念

状态压缩DP（状压DP）是将集合状态用二进制整数表示的DP技术。当问题涉及"选取若干元素的子集"且元素总数较少（通常≤20）时，可以用一个整数的每一位表示某元素是否被选，将2^n种子集状态压缩为整数下标。状压DP在旅行商问题（TSP）、棋盘覆盖、集合划分等问题中广泛应用。

数位DP是处理"1到N中满足某条件的数有多少个"类问题的DP技术。通过逐位（个位、十位、百位...）枚举，利用数字的位结构进行状态转移。数位DP的核心思想是"记忆化搜索+限制标志"：用dp[pos][...][limit]表示处理到第pos位时的方案数，limit标记当前位是否受上界限制。

这两种DP都是线性DP的进阶应用，状态设计更加精巧，需要理解二进制和数位的本质。

### 原理

**状压DP原理**：用n位二进制数表示n个元素的选择状态，第i位为1表示选了第i个元素，为0表示没选。状态总数2^n，每个状态用整数下标访问。转移时用位运算操作集合：`S | (1<<i)`表示加入元素i，`S & (1<<i)`判断是否含元素i，`S ^ (1<<i)`表示移除元素i。

以TSP为例：`dp[S][u]`表示已访问集合S、当前在点u时的最短路径。转移：`dp[S | (1<<v)][v] = min(dp[S][u] + dist[u][v])`，对所有不在S中的v。初始`dp[{0}][0] = 0`，答案`min(dp[全集][u] + dist[u][0])`。复杂度O(2^n · n²)。

**数位DP原理**：将数N的各位数字从高到低处理，用记忆化搜索。状态`dp[pos][sum][limit]`表示：处理到第pos位，前缀的某属性（如数位和）为sum，当前是否受上界限制（limit=1表示前面都贴着上界，当前位不能超过N对应位；limit=0表示前面已小于上界，当前位可取0-9任意值）。

limit标志的作用：当limit=1时，当前位最大只能取N的对应位；当limit=0时，当前位可取0-9。这样能精确计算[0, N]范围内的方案数。记忆化时只对limit=0的状态记忆（因为limit=1的状态依赖于具体上界，无法复用）。

### 例子

**状压DP——旅行商问题（TSP）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

int dist[20][20];
int dp[1 << 20][20];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> dist[i][j];
    
    memset(dp, 0x3f, sizeof(dp));
    dp[1][0] = 0;  // 从点0出发，已访问{0}
    
    for (int S = 1; S < (1 << n); S++) {
        for (int u = 0; u < n; u++) {
            if (!(S & (1 << u))) continue;  // u不在S中
            if (dp[S][u] == 0x3f3f3f3f) continue;
            for (int v = 0; v < n; v++) {
                if (S & (1 << v)) continue;  // v已在S中
                int newS = S | (1 << v);
                dp[newS][v] = min(dp[newS][v], dp[S][u] + dist[u][v]);
            }
        }
    }
    
    int ans = INT_MAX;
    int full = (1 << n) - 1;
    for (int u = 0; u < n; u++) {
        ans = min(ans, dp[full][u] + dist[u][0]);  // 回到起点
    }
    cout << ans << '\n';
    return 0;
}
```

**数位DP——统计不含62的数字个数**：

```cpp
#include <bits/stdc++.h>
using namespace std;

int digit[15];
int dp[15][2][2];  // [pos][prev6][limit]

// pos: 当前位, prev6: 上一位是否为6, limit: 是否受上界限制
int dfs(int pos, bool prev6, bool limit) {
    if (pos == 0) return 1;  // 找到一个合法数
    if (!limit && dp[pos][prev6][0] != -1) return dp[pos][prev6][0];
    
    int maxD = limit ? digit[pos] : 9;
    int sum = 0;
    for (int d = 0; d <= maxD; d++) {
        if (prev6 && d == 2) continue;  // 跳过62
        if (d == 4) continue;  // 跳过4
        sum += dfs(pos - 1, d == 6, limit && d == maxD);
    }
    
    if (!limit) dp[pos][prev6][0] = sum;
    return sum;
}

int solve(int n) {
    int len = 0;
    while (n) { digit[++len] = n % 10; n /= 10; }
    memset(dp, -1, sizeof(dp));
    return dfs(len, false, true);
}

int main() {
    int l, r;
    cin >> l >> r;
    cout << solve(r) - solve(l - 1) << '\n';
    return 0;
}
```

**状压DP——棋盘覆盖（骨牌铺满）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

// 在n×m棋盘上用1×2骨牌铺满的方案数
int main() {
    int n, m;
    while (cin >> n >> m && (n || m)) {
        // dp[j]表示上一行状态为j时的方案数
        vector<long long> dp(1 << m, 0);
        dp[0] = 1;
        
        for (int row = 0; row < n; row++) {
            vector<long long> newDp(1 << m, 0);
            for (int prev = 0; prev < (1 << m); prev++) {
                if (dp[prev] == 0) continue;
                // 枚举当前行的放置方式
                function<void(int,int)> dfs = [&](int col, int cur) {
                    if (col == m) {
                        newDp[cur] += dp[prev];
                        return;
                    }
                    // 当前格已被上一行的竖骨牌占据
                    if (prev & (1 << col)) {
                        dfs(col + 1, cur);
                    } else {
                        // 横放
                        if (col + 1 < m && !(prev & (1 << (col+1)))) {
                            dfs(col + 2, cur);
                        }
                        // 竖放（向下延伸）
                        dfs(col + 1, cur | (1 << col));
                    }
                };
                dfs(0, 0);
            }
            dp = newDp;
        }
        cout << dp[0] << '\n';  // 最后一行必须没有向下延伸
    }
    return 0;
}
```

### 总结

本讲介绍了状压DP和数位DP。关键要点：状压DP用二进制表示集合状态，适用于n≤20的子集问题；数位DP逐位处理，用limit标志控制上界，记忆化搜索实现。状压DP的位运算是核心技巧，数位DP的关键是"只记忆化非限制状态"。常见注意事项：状压DP注意状态数2^n，n超过20基本不可用；位运算优先级低，多用括号；数位DP的limit只在false时记忆化；数位DP通常用solve(r) - solve(l-1)求区间答案；注意前导零的处理（某些问题前导零有特殊含义）。

# 第六章：进阶专题

## 第20讲：字符串算法（KMP、Trie、AC自动机）

### 概念

字符串算法是ACM竞赛中的重要专题，涉及模式匹配、字符串搜索、前缀处理等问题。本讲介绍三种核心字符串数据结构和算法：KMP算法用于单模式串匹配，Trie树用于多字符串存储与前缀检索，AC自动机用于多模式串匹配。

KMP算法（Knuth-Morris-Pratt）是经典的单模式串匹配算法，能在O(n+m)时间内判断模式串是否在主串中出现及出现位置。其核心是next数组（失败指针），利用已匹配的信息避免主串指针回退。KMP不仅用于匹配，其next数组还能高效处理字符串的周期性、border等性质。

Trie树（字典树/前缀树）是一种树形数据结构，用于高效存储和检索字符串集合。Trie将字符串的公共前缀共享存储，节省空间且支持快速前缀查询。Trie是AC自动机的基础，也常用于自动补全、拼写检查等场景。

AC自动机（Aho-Corasick Automaton）是Trie树与KMP思想的结合，用于多模式串匹配——在主串中同时查找多个模式串的出现位置。AC自动机在Trie上构建fail指针（类似KMP的next），实现匹配失败时的自动跳转，复杂度O(n + m + z)，其中z是匹配数。

### 原理

**KMP原理**：朴素匹配在失配时主串指针回退，效率低。KMP的核心是预处理next数组：`next[i]`表示模式串前缀`p[0..i-1]`的最长真前缀（同时也是后缀）的长度。失配时，模式串指针跳到`next[j]`而非回退到0，主串指针不动。

next数组的计算本身也是一个自匹配过程：用两个指针i、j，若`p[i]==p[j]`则`next[i+1]=j+1`，i、j同时前进；否则j跳到`next[j]`继续比较。这样next数组的计算也是O(m)。

匹配过程类似：i遍历主串，j遍历模式串。若`s[i]==p[j]`则i、j前进；若j==m则找到匹配；否则j跳到`next[j]`。整个匹配O(n)。

**Trie原理**：每个节点代表一个字符串前缀，根节点代表空串。插入字符串时从根出发，按字符逐层向下，没有对应子节点则创建。在字符串结束的节点打标记（isEnd）。查找时同样逐层向下，若能走到结束标记则存在。Trie的高度等于最长字符串长度，查找/插入复杂度O(L)。

**AC自动机原理**：在Trie上为每个节点构建fail指针，指向"当前节点代表的最长后缀对应的另一个Trie节点"。fail指针的构建用BFS：根的子节点fail指向根；对于其他节点u（父节点p，字符c），u的fail = p的fail节点沿字符c的子节点（若不存在则继续跳fail）。匹配时，若当前字符匹配失败，沿fail指针跳转而非回退主串。每个节点还可能通过fail链关联多个模式串（用last指针优化跳转）。

### 例子

**KMP算法**：

```cpp
#include <bits/stdc++.h>
using namespace std;

// 计算next数组
vector<int> getNext(const string& p) {
    int m = p.size();
    vector<int> nxt(m + 1);
    nxt[0] = -1;
    int i = 0, j = -1;
    while (i < m) {
        if (j == -1 || p[i] == p[j]) {
            i++; j++;
            nxt[i] = (i < m && p[i] == p[j]) ? nxt[j] : j;  // 优化
        } else {
            j = nxt[j];
        }
    }
    return nxt;
}

// 返回所有匹配位置
vector<int> kmp(const string& s, const string& p) {
    vector<int> result;
    if (p.empty()) return result;
    vector<int> nxt = getNext(p);
    int n = s.size(), m = p.size();
    int i = 0, j = 0;
    while (i < n) {
        if (j == -1 || s[i] == p[j]) {
            i++; j++;
            if (j == m) {
                result.push_back(i - m);  // 匹配位置
                j = nxt[j];  // 继续找下一个
            }
        } else {
            j = nxt[j];
        }
    }
    return result;
}

int main() {
    string s, p;
    cin >> s >> p;
    auto pos = kmp(s, p);
    for (int x : pos) cout << x + 1 << '\n';  // 1-indexed
    cout << "匹配次数：" << pos.size() << '\n';
    return 0;
}
```

```cpp
using namespace std;

struct TrieNode {
    TrieNode* children[26];
    bool isEnd;
    int count;  // 经过此节点的字符串数
    TrieNode() {
        fill(children, children + 26, nullptr);
        isEnd = false;
        count = 0;
    }
};

class Trie {
    TrieNode* root;
public:
    Trie() : root(new TrieNode()) {}
    
    void insert(const string& s) {
        TrieNode* cur = root;
        for (char c : s) {
            int idx = c - 'a';
            if (!cur->children[idx])
                cur->children[idx] = new TrieNode();
            cur = cur->children[idx];
            cur->count++;
        }
        cur->isEnd = true;
    }
    
    bool search(const string& s) {
        TrieNode* cur = root;
        for (char c : s) {
            int idx = c - 'a';
            if (!cur->children[idx]) return false;
            cur = cur->children[idx];
        }
        return cur->isEnd;
    }
    
    // 以prefix为前缀的字符串数
    int countPrefix(const string& prefix) {
        TrieNode* cur = root;
        for (char c : prefix) {
            int idx = c - 'a';
            if (!cur->children[idx]) return 0;
            cur = cur->children[idx];
        }
        return cur->count;
    }
};

int main() {
    int n;
    cin >> n;
    Trie trie;
    while (n--) {
        string op, s;
        cin >> op >> s;
        if (op == "insert") trie.insert(s);
        else if (op == "search") cout << (trie.search(s) ? "Yes" : "No") << '\n';
        else if (op == "prefix") cout << trie.countPrefix(s) << '\n';
    }
    return 0;
}
```

**AC自动机（多模式匹配）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

struct ACNode {
    int children[26];
    int fail;
    int count;  // 以此节点结尾的模式串数
    ACNode() : fail(0), count(0) {
        fill(children, children + 26, 0);
    }
};

vector<ACNode> trie;
int nodeCount = 0;

void insert(const string& s) {
    int cur = 0;
    for (char c : s) {
        int idx = c - 'a';
        if (!trie[cur].children[idx]) {
            trie.push_back(ACNode());
            trie[cur].children[idx] = ++nodeCount;
        }
        cur = trie[cur].children[idx];
    }
    trie[cur].count++;
}

void buildFail() {
    queue<int> q;
    for (int i = 0; i < 26; i++) {
        if (trie[0].children[i]) {
            trie[trie[0].children[i]].fail = 0;
            q.push(trie[0].children[i]);
        }
    }
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int i = 0; i < 26; i++) {
            int v = trie[u].children[i];
            if (v) {
                trie[v].fail = trie[trie[u].fail].children[i];
                trie[v].count += trie[trie[v].fail].count;  // 累加fail链上的count
                q.push(v);
            } else {
                trie[u].children[i] = trie[trie[u].fail].children[i];  // 路径压缩
            }
        }
    }
}

// 在主串中查找模式串出现总次数
int query(const string& s) {
    int cur = 0, total = 0;
    for (char c : s) {
        cur = trie[cur].children[c - 'a'];
        total += trie[cur].count;
    }
    return total;
}

int main() {
    trie.push_back(ACNode());  // 根节点
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        string p; cin >> p;
        insert(p);
    }
    buildFail();
    
    string text;
    cin >> text;
    cout << query(text) << '\n';  // 模式串出现总次数
    return 0;
}
```

### 总结

本讲介绍了KMP、Trie和AC自动机三种字符串算法。关键要点：KMP用next数组实现O(n+m)单模式匹配；Trie用树形结构存储字符串，支持高效前缀查询；AC自动机结合Trie和KMP思想，实现多模式匹配。常见注意事项：KMP的next数组有多种定义（是否优化），注意区分；Trie注意内存，节点数可能很多，可用数组模拟；AC自动机的fail指针构建用BFS，注意路径压缩优化；AC自动机匹配时累加fail链上的count，可用last指针优化避免重复跳转。

## 第21讲：数论基础

### 概念

数论是ACM竞赛中重要的数学专题，涉及整数的性质和运算。本讲介绍竞赛常用的数论知识：最大公约数（GCD）、扩展欧几里得算法、模运算与快速幂、逆元、素数判定与筛法、欧拉函数等。这些知识不仅是数论题的基础，也是组合数学、密码学等专题的工具。

最大公约数（GCD）是数论的基础概念，欧几里得算法（辗转相除法）能在O(log min(a,b))内求出GCD。扩展欧几里得算法还能求出贝祖等式`ax + by = gcd(a,b)`的一组解，是求解线性同余方程的工具。模运算中，快速幂能在O(log n)内计算a^n mod m，是处理大数模运算的核心算法。乘法逆元用于模意义下的除法，当模数为素数时可用费马小定理求逆。

素数相关算法包括：试除法判定（O(√n)）、埃氏筛（O(n log log n)）、欧拉筛（线性筛，O(n)）。欧拉函数φ(n)表示1到n中与n互素的数个数，在数论中有重要地位。

### 原理

**欧几里得算法原理**：基于`gcd(a,b) = gcd(b, a mod b)`，递归直到b=0，此时a即为gcd。正确性基于：a和b的公约数等于b和a mod b的公约数（因为a = kb + r，能整除a和b的数也能整除r）。

**扩展欧几里得原理**：在求gcd的同时递归求解贝祖等式。设`gcd(a,b) = ax + by`，递归到`gcd(b, a mod b) = bx' + (a mod b)y'`。由于`a mod b = a - (a/b)*b`，代入得`gcd = bx' + (a - (a/b)*b)y' = ay' + b(x' - (a/b)y')`。因此`x = y'`，`y = x' - (a/b)*y'`。

**快速幂原理**：将n分解为二进制，利用`a^n = (a^(n/2))^2`（n偶数）或`a^n = a * a^(n-1)`（n奇数）。每次将指数减半，O(log n)次乘法即可。模意义下每步取模防止溢出。

**逆元原理**：若`ax ≡ 1 (mod m)`，则x是a模m的逆元。当m为素数且a不被m整除时，由费马小定理`a^(m-1) ≡ 1 (mod m)`，故`a^(m-2) ≡ a^(-1) (mod m)`，用快速幂计算。当m不一定是素数时，若gcd(a,m)=1，可用扩展欧几里得求逆。

**埃氏筛原理**：从2开始，将每个素数的倍数标记为合数。优化：只标记素数p的p²以上倍数（更小的倍数已被更小素数标记）。复杂度O(n log log n)。

**欧拉筛（线性筛）原理**：每个合数只被最小质因子筛一次。维护一个素数表，对每个数i，用i乘以素数表中≤i最小质因子的素数来筛合数。这样每个合数恰好被筛一次，复杂度O(n)。

**欧拉函数原理**：φ(n)的计算公式：若`n = p1^a1 * p2^a2 * ... * pk^ak`，则`φ(n) = n * (1-1/p1) * (1-1/p2) * ... * (1-1/pk)`。欧拉函数的重要性质：若gcd(a,n)=1，则`a^φ(n) ≡ 1 (mod n)`（欧拉定理）。

### 例子

**GCD与扩展欧几里得**：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

ll gcd(ll a, ll b) {
    return b == 0 ? a : gcd(b, a % b);
}

// 扩展欧几里得：求ax + by = gcd(a,b)
ll exgcd(ll a, ll b, ll& x, ll& y) {
    if (b == 0) { x = 1; y = 0; return a; }
    ll x1, y1;
    ll g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - (a / b) * y1;
    return g;
}

int main() {
    ll a, b;
    cin >> a >> b;
    cout << "gcd: " << gcd(a, b) << '\n';
    
    ll x, y;
    ll g = exgcd(a, b, x, y);
    cout << a << "*" << x << " + " << b << "*" << y << " = " << g << '\n';
    return 0;
}
```

**快速幂与逆元**：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

// 快速幂：a^n mod m
ll qpow(ll a, ll n, ll m) {
    ll res = 1;
    a %= m;
    while (n > 0) {
        if (n & 1) res = res * a % m;
        a = a * a % m;
        n >>= 1;
    }
    return res;
}

// 费马小定理求逆元（m为素数）
ll inv(ll a, ll m) {
    return qpow(a, m - 2, m);
}

int main() {
    ll a, n, m;
    cin >> a >> n >> m;
    cout << a << "^" << n << " mod " << m << " = " << qpow(a, n, m) << '\n';
    cout << a << "的逆元 mod " << m << " = " << inv(a, m) << '\n';
    // 验证：a * inv(a) ≡ 1 (mod m)
    cout << "验证：" << a * inv(a, m) % m << '\n';
    return 0;
}
```

**欧拉筛（线性筛素数）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 10000001;
bool isComp[N];  // true表示合数
vector<int> primes;
int phi[N];  // 欧拉函数

void sieve(int n) {
    phi[1] = 1;
    for (int i = 2; i <= n; i++) {
        if (!isComp[i]) {
            primes.push_back(i);
            phi[i] = i - 1;  // 素数的φ = i-1
        }
        for (int p : primes) {
            if (i * p > n) break;
            isComp[i * p] = true;
            if (i % p == 0) {
                phi[i * p] = phi[i] * p;  // p是i*p的最小质因子且在i中
                break;  // 保证线性
            } else {
                phi[i * p] = phi[i] * (p - 1);  // p与i互质
            }
        }
    }
}

int main() {
    int n;
    cin >> n;
    sieve(n);
    cout << "素数个数：" << primes.size() << '\n';
    cout << "前10个素数：";
    for (int i = 0; i < min(10, (int)primes.size()); i++)
        cout << primes[i] << " ";
    cout << '\n';
    cout << "φ(" << n << ") = " << phi[n] << '\n';
    return 0;
}
```

**应用：求解线性同余方程 ax ≡ b (mod m)**：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

ll exgcd(ll a, ll b, ll& x, ll& y) {
    if (b == 0) { x = 1; y = 0; return a; }
    ll x1, y1;
    ll g = exgcd(b, a % b, x1, y1);
    x = y1; y = x1 - (a / b) * y1;
    return g;
}

// 求解 ax ≡ b (mod m)
// 返回最小非负解，无解返回-1
ll solve(ll a, ll b, ll m) {
    ll x, y;
    ll g = exgcd(a, m, x, y);
    if (b % g != 0) return -1;  // 无解
    ll mod = m / g;
    x = (x * (b / g) % mod + mod) % mod;
    return x;
}

int main() {
    ll a, b, m;
    cin >> a >> b >> m;
    ll x = solve(a, b, m);
    if (x == -1) cout << "无解\n";
    else cout << "x = " << x << '\n';  // 验证: a*x % m == b % m
    return 0;
}
```

本讲介绍了数论基础算法。关键要点：GCD用欧几里得算法O(log n)；扩展欧几里得求贝祖等式解；快速幂O(log n)计算模幂；逆元用费马小定理（素数模）或扩展欧几里得（一般模）；线性筛O(n)求素数和欧拉函数。数论是组合数学和密码学的基础。常见注意事项：注意模运算中每步取模防溢出；负数取模要处理（`(x%m+m)%m`）；逆元要求gcd(a,m)=1；线性筛的break保证每个合数只筛一次；欧拉函数和莫比乌斯函数可在筛中同时计算。

## 第22讲：组合数学与博弈论

### 概念

组合数学研究离散对象的计数、存在性和构造问题，是ACM竞赛中常见的数学专题。核心知识包括排列组合、二项式系数、卢卡斯定理、卡特兰数、容斥原理等。博弈论研究决策对抗问题，竞赛中主要考察公平组合游戏（ICG），核心工具是SG函数和Nim游戏。

排列组合是组合数学的基础：排列数A(n,m)表示从n个不同元素中选m个排列的方案数，组合数C(n,m)表示选m个的组合数。二项式系数C(n,m)有丰富的性质，可用杨辉三角递推或卢卡斯定理计算大数取模。卡特兰数是特殊的组合数，出现在括号匹配、二叉树计数、多边形三角剖分等问题中。

容斥原理是计数的重要技巧：|A∪B∪C| = |A|+|B|+|C| - |A∩B| - |A∩C| - |B∩C| + |A∩B∩C|，通过"加加减减"消除重复计数。

博弈论中，Nim游戏是经典模型：n堆石子，两人轮流从任一堆取任意个，取完者胜。Bouton定理指出：先手必胜当且仅当各堆石子数的异或和非零。SG函数将此推广到一般ICG：每个状态的SG值等于其后继状态SG值的mex（最小未出现正整数），SG值为0的状态是必败态。

### 原理

**组合数计算原理**：小规模用杨辉三角递推`C(n,m) = C(n-1,m-1) + C(n-1,m)`，O(n²)预处理；大规模用公式`C(n,m) = n! / (m! * (n-m)!)`，预处理阶乘和逆元后O(1)查询；模数为小素数p时用卢卡斯定理`C(n,m) mod p = C(n mod p, m mod p) * C(n/p, m/p) mod p`。

**卢卡斯定理原理**：将n和m按p进制分解，组合数C(n,m) mod p等于各对应位组合数的乘积 mod p。这是因为`C(n,m) mod p`只与n、m的p进制表示有关。卢卡斯定理将大组合数分解为小组合数的乘积，每个小组合数≤p，可用公式直接计算。

**卡特兰数原理**：C(n) = C(2n,n) / (n+1)，递推式`C(n) = sum(C(i)*C(n-1-i)) for i in 0..n-1`。卡特兰数满足`C(n) = C(2n,n) - C(2n,n+1)`，可用组合数公式计算。卡特兰数出现在：n对括号的合法匹配数、n个节点的二叉树形态数、n+1边凸多边形的三角剖分数等。

**容斥原理原理**：对多个集合的并集计数，先加上各集合大小，减去两两交集，加上三三交集……交替加减。一般形式：`|∪Ai| = Σ|Ai| - Σ|Ai∩Aj| + Σ|Ai∩Aj∩Ak| - ...`。容斥的关键是"补集转化"——直接求并集难，但求每个交集容易时，用容斥转化。

**Nim游戏与SG函数原理**：定义每个状态的SG值为后继状态SG值的mex。SG=0是必败态（P-position），SG≠0是必胜态（N-position）。N-position的后继中必有P-position（mex非零说明有后继SG=0），P-position的所有后继都是N-position（mex=0说明无后继SG=0）。

**Bouton定理**：Nim游戏中，n堆石子的SG值等于各堆石子数的异或和。这是因为：每堆石子是独立的子游戏，其SG值就是石子数（因为从k个石子可以转移到0到k-1的任意状态，mex为k）。多个独立子游戏的SG值等于各子游戏SG值的异或——这是SG定理的核心结论。

### 例子

**组合数预处理（阶乘+逆元）**：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int N = 1000005, MOD = 1e9 + 7;
ll fact[N], invFact[N];

ll qpow(ll a, ll n, ll m) {
    ll res = 1; a %= m;
    while (n > 0) {
        if (n & 1) res = res * a % m;
        a = a * a % m;
        n >>= 1;
    }
    return res;
}

void init() {
    fact[0] = 1;
    for (int i = 1; i < N; i++) fact[i] = fact[i-1] * i % MOD;
    invFact[N-1] = qpow(fact[N-1], MOD - 2, MOD);
    for (int i = N - 2; i >= 0; i--) invFact[i] = invFact[i+1] * (i+1) % MOD;
}

ll C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return fact[n] * invFact[m] % MOD * invFact[n-m] % MOD;
}

int main() {
    init();
    int n, m;
    cin >> n >> m;
    cout << "C(" << n << "," << m << ") mod " << MOD << " = " << C(n, m) << '\n';
    return 0;
}
```

**卢卡斯定理**：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

ll p;

ll qpow(ll a, ll n) {
    ll res = 1; a %= p;
    while (n > 0) {
        if (n & 1) res = res * a % p;
        a = a * a % p;
        n >>= 1;
    }
    return res;
}

ll C(ll n, ll m) {
    if (m < 0 || m > n) return 0;
    ll num = 1, den = 1;
    for (ll i = 1; i <= m; i++) {
        num = num * (n - m + i) % p;
        den = den * i % p;
    }
    return num * qpow(den, p - 2) % p;
}

ll lucas(ll n, ll m) {
    if (m == 0) return 1;
    return C(n % p, m % p) * lucas(n / p, m / p) % p;
}

int main() {
    ll n, m;
    cin >> n >> m >> p;
    cout << lucas(n, m) << '\n';
    return 0;
}
```

**卡特兰数**：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
const int MOD = 1e9 + 7;

ll qpow(ll a, ll n, ll m) {
    ll res = 1; a %= m;
    while (n > 0) {
        if (n & 1) res = res * a % m;
        a = a * a % m; n >>= 1;
    }
    return res;
}

// 卡特兰数：C(n) = C(2n,n) / (n+1)
ll catalan(int n) {
    // 预处理阶乘（简化版，直接计算）
    auto C = [](int n, int k) -> ll {
        // C(2n, n) = (2n)! / (n!)^2
        ll num = 1, den = 1;
        for (int i = 1; i <= n; i++) {
            num = num * (n + i) % MOD;
            den = den * i % MOD;
        }
        return num * qpow(den, MOD - 2, MOD) % MOD;
    };
    return C(n, n) * qpow(n + 1, MOD - 2, MOD) % MOD;
}

int main() {
    int n;
    cin >> n;
    cout << "卡特兰数C(" << n << ") = " << catalan(n) << '\n';
    // C(0)=1, C(1)=1, C(2)=2, C(3)=5, C(4)=14, C(5)=42...
    return 0;
}
```

**SG函数（一般ICG）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

// 计算SG函数（以"取石子游戏，每次取1~3个"为例）
int sg[1005];

void initSG(int n) {
    sg[0] = 0;  // 终止状态SG=0
    for (int i = 1; i <= n; i++) {
        set<int> s;
        for (int j = 1; j <= min(3, i); j++) {
            s.insert(sg[i - j]);  // 后继状态的SG值
        }
        // mex：最小未出现的非负整数
        int mex = 0;
        while (s.count(mex)) mex++;
        sg[i] = mex;
    }
}

int main() {
    int n;
    cin >> n;
    initSG(n);
    // 规律：sg[i] = i % 4
    cout << "SG(" << n << ") = " << sg[n] << '\n';
    cout << (sg[n] != 0 ? "先手必胜" : "先手必败") << '\n';
    return 0;
}
```

**容斥原理应用——求1到n中能被a或b整除的数个数**：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

ll gcd(ll a, ll b) { return b == 0 ? a : gcd(b, a % b); }
ll lcm(ll a, ll b) { return a / gcd(a, b) * b; }

int main() {
    ll n, a, b;
    cin >> n >> a >> b;
    // |A∪B| = |A| + |B| - |A∩B|
    ll cntA = n / a;        // 能被a整除的数
    ll cntB = n / b;        // 能被b整除的数
    ll cntAB = n / lcm(a, b);  // 能被a和b同时整除（即被lcm整除）
    ll ans = cntA + cntB - cntAB;
    cout << ans << '\n';
    return 0;
}
```

### 总结

本讲介绍了组合数学与博弈论。关键要点：组合数用阶乘+逆元预处理O(1)查询，大数取模用卢卡斯定理；卡特兰数解决括号匹配、二叉树计数等问题；容斥原理通过"加减交替"消除重复计数；Nim游戏先手必胜当且仅当异或和非零；SG函数将博弈推广到一般ICG，SG=0为必败态。常见注意事项：组合数取模注意预处理阶乘和逆元；卢卡斯定理要求模数p为素数；容斥注意符号（奇数项加、偶数项减）；SG函数的mex是"最小未出现的非负整数"；多个独立子游戏的SG等于各SG的异或。
