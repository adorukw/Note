## 第1讲 Python 简介与环境搭建

### 概念

Python 是一种高级、解释型、通用型编程语言，由 Guido van Rossum 于 1989 年圣诞节期间开始设计，1991 年正式发布。它以"优雅、明确、简单"为设计哲学，强调代码的可读性和简洁的语法，尤其使用缩进来表示代码块，而非花括号或关键字。Python 是一门多范式语言，支持面向对象、命令式、函数式和过程式编程风格，广泛应用于 Web 开发、数据科学、人工智能、自动化运维、科学计算等领域。

### 原理

Python 的运行机制基于"解释执行"模型。源代码（`.py` 文件）首先被编译为字节码（`.pyc` 文件），然后由 Python 虚拟机（PVM）逐条解释执行字节码。这种"先编译后解释"的混合模式使得 Python 兼具跨平台能力和开发效率。Python 采用动态类型系统，变量在运行时绑定类型，无需事先声明；同时支持自动内存管理，通过引用计数和分代垃圾回收机制自动回收不再使用的对象。Python 的标准库极其丰富，遵循"内置电池"（batteries included）理念，开箱即用。

CPython 是官方参考实现，使用 C 语言编写；此外还有 Jython（运行在 JVM 上）、IronPython（.NET 平台）、PyPy（带 JIT 编译器，执行速度更快）等实现版本。

### 例子

**安装 Python（以 Ubuntu 为例）：**

```bash
# 更新包管理器
sudo apt update

# 安装 Python 3 和 pip 包管理器
sudo apt install python3 python3-pip

# 验证安装
python3 --version    # 输出类似: Python 3.10.12
pip3 --version       # 输出 pip 版本信息
```

**第一个 Python 程序：**

```python

# 查看 Python 版本信息

print(f"Python 版本: {sys.version}")
```

运行方式：在终端执行 `python3 hello.py`，输出：
```

```

**使用交互式解释器：**

### 总结

- Python 是高级、解释型、动态类型语言，强调代码可读性和简洁性
- 运行机制为"源码 → 字节码 → PVM 解释执行"，跨平台且开发效率高
- 官方实现为 CPython，推荐使用 Python 3.x 版本
- 开发时建议使用虚拟环境（`venv`）隔离项目依赖，避免全局污染
- 常见注意事项：区分 Python 2 与 Python 3（本课程基于 Python 3）；安装第三方包使用 `pip`；生产环境建议锁定依赖版本（`pip freeze > requirements.txt`）

## 第2讲 变量与基本数据类型

### 概念

变量是存储数据的命名容器，在 Python 中变量本质是"指向对象的引用"——变量名绑定到内存中的对象，而非直接存储值。Python 的基本数据类型包括：整数（`int`）、浮点数（`float`）、布尔值（`bool`）、字符串（`str`）以及特殊值 `None`。此外还有复数（`complex`）类型用于科学计算。Python 采用动态类型，变量可以随时重新绑定到不同类型的对象。

### 原理

Python 中"一切皆对象"。每个对象包含三要素：身份（identity，可通过 `id()` 获取）、类型（type，可通过 `type()` 获取）、值（value）。变量名只是绑定到对象的标签，多个变量可以指向同一个对象。整数在 Python 3 中没有大小限制，可以表示任意精度的整数（自动大整数支持）；浮点数遵循 IEEE 754 双精度标准（64 位），约 15-17 位有效数字。布尔值是 `int` 的子类，`True` 等价于 1，`False` 等价于 0。字符串是不可变的 Unicode 字符序列，Python 3 默认使用 UTF-8 编码。

小整数缓存机制：CPython 会缓存 `-5` 到 `256` 之间的整数对象，这些范围内的整数赋值会复用同一对象，因此 `a is b` 可能返回 `True`。字符串也有类似的驻留（intern）机制。

### 例子

```python
# === 整数与浮点数 ===
age = 25                  # 整数
price = 19.99             # 浮点数
big_num = 10 ** 100       # 大整数，无溢出
print(type(age))          # <class 'int'>
print(type(price))        # <class 'float'>
print(big_num)            # 10000000000...（100个0）

# 整数不同进制表示
binary = 0b1010           # 二进制，等于 10
octal = 0o17              # 八进制，等于 15
hexadecimal = 0xFF        # 十六进制，等于 255
print(f"二进制1010={binary}, 八进制17={octal}, 十六进制FF={hexadecimal}")

# === 布尔值 ===
is_active = True
is_admin = False
print(type(is_active))    # <class 'bool'>
print(True + True)        # 2，布尔值可参与数值运算
print(bool(0))            # False，0 为假
print(bool(""))           # False，空字符串为假
print(bool("hello"))      # True，非空字符串为真
print(bool([]))           # False，空列表为假

# === 字符串 ===
name = "Alice"
greeting = '你好'
multiline = """这是
多行
字符串"""
print(type(name))         # <class 'str'>

# 字符串是不可变的
s = "hello"
# s[0] = "H"              # 报错：TypeError
new_s = "H" + s[1:]       # 正确做法：创建新字符串
print(new_s)              # Hello

# === None 类型 ===
result = None
print(type(result))       # <class 'NoneType'>
print(result is None)     # True，用 is 判断 None

# === 动态类型 ===
x = 10                    # x 是 int
print(type(x))
x = "now string"          # x 重新绑定为 str
print(type(x))
x = [1, 2, 3]             # x 重新绑定为 list
print(type(x))

# === 类型转换 ===
num_str = "42"
num = int(num_str)        # 字符串转整数：42
float_val = float("3.14") # 字符串转浮点：3.14
str_val = str(100)        # 数字转字符串："100"
print(num, float_val, str_val)

# === 多重赋值与链式比较 ===
a, b, c = 1, 2, 3         # 多重赋值
x = y = 0                 # 链式赋值
print(a, b, c, x, y)
```

### 总结

- Python 变量是"对象引用"，一切皆对象，包含身份、类型、值三要素
- 基本类型：`int`（任意精度）、`float`（IEEE 754 双精度）、`bool`（int 子类）、`str`（不可变 Unicode 序列）、`NoneType`
- 动态类型：变量可随时重新绑定，类型随对象变化
- 类型转换使用 `int()`、`float()`、`str()`、`bool()` 等内置函数
- 注意事项：判断 `None` 用 `is` 而非 `==`；浮点数运算有精度误差（如 `0.1 + 0.2 != 0.3`）；字符串不可变，修改需创建新对象；小整数缓存范围 `-5` 到 `256` 内 `is` 比较可能为 `True`，但不应依赖此特性

## 第3讲 运算符与表达式

### 概念

运算符是执行特定运算的特殊符号，表达式由运算符和操作数组成，求值后产生一个值。Python 的运算符分为：算术运算符、比较运算符、逻辑运算符、赋值运算符、位运算符、成员运算符、身份运算符。Python 还支持运算符重载（通过魔术方法），使自定义类型也能使用这些运算符。

### 原理

Python 运算符有明确的优先级和结合性。算术运算符中 `**`（幂）优先级最高，其次是 `~`（按位取反）、`*` `/` `//` `%`、`+` `-`。比较运算符优先级低于算术运算符，逻辑运算符中 `not` > `and` > `or`。Python 的 `//` 是地板除（向下取整），`%` 的结果符号与除数一致。逻辑运算符采用"短路求值"：`and` 在左操作数为假时直接返回左操作数，`or` 在左操作数为真时直接返回左操作数，不会计算右操作数。这一特性常用于设置默认值。

比较运算可以链式使用，如 `1 < x < 10` 等价于 `1 < x and x < 10`，但只计算一次 `x`。

### 例子

```python
# === 算术运算符 ===
print(7 + 3)      # 10 加
print(7 - 3)      # 4  减
print(7 * 3)      # 21 乘
print(7 / 2)      # 3.5 普通除法，结果总是浮点数
print(7 // 2)     # 3  地板除，向下取整
print(-7 // 2)    # -4 注意：向负无穷取整
print(7 % 2)      # 1  取模
print(-7 % 2)     # 1  结果符号与除数一致
print(2 ** 10)    # 1024 幂运算
print(9 ** 0.5)   # 3.0 开平方

# === 比较运算符 ===
print(3 == 3.0)   # True，值相等
print(3 != 4)     # True
print(3 < 4)      # True
print(3 >= 3)     # True
# 链式比较
x = 5
print(1 < x < 10) # True，等价于 1 < x and x < 10
print(1 < x > 3)  # True，链式比较可混合方向

# === 逻辑运算符（短路求值）===
print(True and False)   # False
print(True or False)    # True
print(not True)         # False

# 短路特性：返回操作数本身，而非布尔值
print(0 or "default")   # "default"，0 为假，返回右操作数
print("" or [])         # []，空字符串为假，返回右操作数
print(3 and 5)          # 5，3 为真，返回右操作数
print(0 and 5)          # 0，0 为假，直接返回

# 实用：设置默认值
name = ""
display_name = name or "匿名用户"
print(display_name)     # 匿名用户

# === 赋值运算符 ===
a = 10
a += 5      # 等价于 a = a + 5
print(a)    # 15
a *= 2      # a = 30
a //= 7     # a = 4
a **= 2     # a = 16
print(a)    # 16

# 海象运算符 :=（Python 3.8+）
data = "hello world"
if (n := len(data)) > 10:
    print(f"字符串长度 {n} 超过 10")

# === 成员运算符 ===
print(3 in [1, 2, 3])          # True
print(5 not in [1, 2, 3])      # True
print("a" in "apple")          # True
print("name" in {"name": "Tom"}) # True，检查字典的键

# === 身份运算符 ===
a = [1, 2, 3]
b = a
c = [1, 2, 3]
print(a is b)      # True，a 和 b 指向同一对象
print(a is c)      # False，a 和 c 值相同但是不同对象
print(a == c)      # True，值相等
print(a is not c)  # True

# === 位运算符 ===
print(5 & 3)    # 1   按位与: 101 & 011 = 001
print(5 | 3)    # 7   按位或: 101 | 011 = 111
print(5 ^ 3)    # 6   按位异或: 101 ^ 011 = 110
print(~5)       # -6  按位取反
print(5 << 1)   # 10  左移一位相当于乘2
print(5 >> 1)   # 2   右移一位相当于除2
```

### 总结

- 算术运算符：`+ - * / // % **`，注意 `/` 总返回浮点数，`//` 向负无穷取整
- 比较运算符可链式使用：`a < b < c` 简洁高效
- 逻辑运算符 `and/or/not` 采用短路求值，返回操作数本身而非布尔值，常用于默认值设置
- `is` 比较身份（同一对象），`==` 比较值；判断 `None` 必须用 `is`
- 海象运算符 `:=` 可在表达式内赋值，简化代码
- 注意事项：浮点数比较不要用 `==`，应使用 `abs(a-b) < 1e-9`；位运算符优先级低于算术运算符，复杂表达式建议加括号

## 第4讲 输入输出与字符串基础

### 概念

输入输出（I/O）是程序与外部交互的桥梁。Python 的标准输入通过 `input()` 函数获取用户输入，标准输出通过 `print()` 函数输出信息。字符串格式化是将变量嵌入字符串的过程，Python 提供了多种方式：`%` 格式化（旧式）、`str.format()` 方法、f-string（Python 3.6+，推荐）。字符串还有丰富的内置方法用于查找、替换、分割、连接等操作。

### 原理

`input()` 函数从标准输入读取一行文本（以换行符结束），返回值始终是字符串类型，需要数值时必须显式转换。`print()` 函数默认以空格分隔多个参数，以换行符结尾，可通过 `sep` 和 `end` 参数自定义分隔符和结尾符。输出会被缓冲，可通过 `flush=True` 立即刷新。

f-string（格式化字符串字面量）在运行时求值花括号内的表达式，支持格式说明符（如 `:.2f` 保留两位小数、`:>10` 右对齐宽度10、`:08d` 补零）。f-string 比 `%` 和 `format()` 更高效，因为它在编译时解析，运行时直接求值，避免了方法调用开销。

字符串方法大多返回新字符串（因为字符串不可变），原字符串不变。`split()` 和 `join()` 是互逆操作，常配合使用处理文本。

### 例子

```python
# === 基本输入输出 ===
# input() 总是返回字符串
name = input("请输入你的名字：")
print("你好，" + name + "！")

# 数值输入需要转换
age_str = input("请输入你的年龄：")
age = int(age_str)
print(f"明年你 {age + 1} 岁")

# print() 的参数
print("Python", "Java", "Go")              # Python Java Go（默认空格分隔）
print("Python", "Java", "Go", sep="-")     # Python-Java-Go
print("第一行", end="")                    # 不换行
print("第二行")                            # 紧接上一行

# === 字符串格式化三种方式 ===
name = "Alice"
age = 25
score = 95.678

# 方式1：% 格式化（旧式，不推荐）
print("姓名：%s，年龄：%d" % (name, age))

# 方式2：str.format()
print("姓名：{}，年龄：{}".format(name, age))
print("姓名：{n}，年龄：{a}".format(n=name, a=age))

# 方式3：f-string（推荐，Python 3.6+）
print(f"姓名：{name}，年龄：{age}")
print(f"成绩：{score:.2f}")          # 95.68，保留两位小数
print(f"成绩：{score:>10.2f}")       # 右对齐宽度10
print(f"年龄：{age:08d}")            # 00000025，补零
print(f"百分比：{score/100:.1%}")    # 95.7%

# f-string 进阶：表达式、调用函数
print(f"2的10次方 = {2**10}")
print(f"名字大写：{name.upper()}")
print(f"{'居中':=^20}")              # ========居中========

# === 字符串常用方法 ===
s = "Hello, World"

# 大小写转换
print(s.upper())           # HELLO, WORLD
print(s.lower())           # hello, world
print(s.title())           # Hello, World
print(s.swapcase())        # hELLO, wORLD

# 查找
print(s.find("World"))     # 7，返回索引，找不到返回 -1
print(s.index("World"))    # 7，找不到抛异常
print("World" in s)        # True
print(s.startswith("Hello"))  # True
print(s.endswith("World"))    # True
print(s.count("l"))        # 3，统计字符出现次数

# 替换与分割
print(s.replace("World", "Python"))  # Hello, Python
print(s.split(","))        # ['Hello', ' World']
print(s.split(", "))       # ['Hello', 'World']

# 连接
words = ["Hello", "World"]
print("-".join(words))     # Hello-World
print(" ".join(words))     # Hello World

# 去除空白
s2 = "  hello  "
print(s2.strip())          # hello，去除两端空白
print(s2.lstrip())         # "hello  "，去除左端
print(s2.rstrip())         # "  hello"，去除右端

# 判断方法
print("123".isdigit())     # True
print("abc".isalpha())     # True
print("abc123".isalnum())  # True
print("   ".isspace())     # True

# === 综合示例：用户信息卡片 ===
def format_user_info(name, age, height):
    """格式化用户信息为卡片"""
    line = "+" + "-" * 20 + "+"
    return f"""
{line}
| 姓名：{name:<12s}|
| 年龄：{age:<12d}|
| 身高：{height:<12.1f}|
{line}
"""

print(format_user_info("张三", 25, 175.5))
```

输出：
```
+--------------------+
| 姓名：张三          |
| 年龄：25           |
| 身高：175.5        |
+--------------------+
```

### 总结

- `input()` 返回字符串，数值输入需 `int()`/`float()` 转换
- `print()` 通过 `sep` 和 `end` 自定义分隔符和结尾符
- 字符串格式化推荐 f-string（高效、可读），支持 `:.2f`、`:>10`、`:08d`、`:.1%` 等格式说明符
- 字符串方法：`upper/lower/find/replace/split/join/strip` 等，均返回新字符串
- 注意事项：`input()` 在 EOF 时抛 `EOFError`；f-string 中不能包含反斜杠的表达式（3.12 前）；`split()` 无参数时按任意空白分割并去除空项；`join()` 只能连接字符串列表，需先转换非字符串元素

# 第2章 控制流程

控制流程决定程序的执行路径。本章讲解条件判断、循环结构及循环控制语句，这是编写逻辑复杂程序的基础。

---

## 第5讲 条件语句

### 概念

条件语句根据条件的真假选择执行不同的代码块。Python 使用 `if`、`elif`、`else` 关键字实现条件分支。`if` 后跟条件表达式，为真时执行其代码块；`elif`（else if 的缩写）提供额外的条件分支；`else` 处理所有未匹配的情况。Python 没有其他语言的 `switch/case`（3.10+ 引入了 `match/case` 结构模式匹配），条件分支主要通过 `if-elif-else` 实现。

### 原理

Python 条件判断基于"真值测试"（truthiness）：任何对象都可以在布尔上下文中求值。以下值被视为假（falsy）：`False`、`None`、数值零（`0`、`0.0`、`0j`）、空序列/集合（`""`、`()`、`[]`、`{}`、`set()`）、空映射。其他所有值视为真（truthy）。这一机制使条件判断可以省略显式比较，如 `if my_list:` 判断列表非空。

条件表达式从上到下依次求值，一旦某个分支为真，执行该分支后跳过后续所有 `elif` 和 `else`。因此分支顺序很重要：应将更具体/严格的条件放在前面。Python 还支持三元条件表达式 `value_if_true if condition else value_if_false`，用于简洁地赋值。条件可以嵌套，但过深的嵌套会降低可读性，建议通过提前返回（guard clause）或重构来扁平化。

### 例子

```python
# === 基本条件语句 ===
score = 85

if score >= 90:
    grade = "优秀"
elif score >= 80:
    grade = "良好"
elif score >= 70:
    grade = "中等"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"

print(f"成绩 {score}，等级：{grade}")  # 成绩 85，等级：良好

# === 真值测试 ===
# 省略显式比较，利用 truthiness
name = ""
if name:                          # 空字符串为假
    print(f"你好，{name}")
else:
    print("名字为空")              # 输出：名字为空

items = [1, 2, 3]
if items:                         # 非空列表为真
    print(f"列表有 {len(items)} 个元素")

user = None
if not user:                      # None 为假
    print("用户未登录")

# === 三元条件表达式 ===
age = 20
status = "成年" if age >= 18 else "未成年"
print(status)                     # 成年

# 嵌套三元（不推荐过度使用）
score = 75
result = "优秀" if score >= 90 else ("及格" if score >= 60 else "不及格")
print(result)                     # 及格

# === 多条件组合 ===
age = 25
has_license = True

# 逻辑运算符组合条件
if age >= 18 and has_license:
    print("可以驾驶")
elif age >= 18 and not has_license:
    print("成年但无驾照")
else:
    print("未成年")

# 成员运算符判断
day = "周六"
if day in ["周六", "周日"]:
    print("周末")
else:
    print("工作日")

# === 嵌套条件与 guard clause ===
# 不推荐：嵌套过深
def process_order_bad(order):
    if order is not None:
        if "items" in order:
            if len(order["items"]) > 0:
                total = sum(item["price"] for item in order["items"])
                return total
    return 0

# 推荐：guard clause 提前返回，扁平化逻辑
def process_order(order):
    if order is None:
        return 0
    if "items" not in order:
        return 0
    if len(order["items"]) == 0:
        return 0
    return sum(item["price"] for item in order["items"])

print(process_order({"items": [{"price": 10}, {"price": 20}]}))  # 30

# === Python 3.10+ 结构模式匹配 match/case ===
# 类似 switch，但功能更强大
def handle_command(command):
    match command.split():
        case ["quit"]:
            return "退出程序"
        case ["hello", name]:
            return f"你好，{name}"
        case ["move", direction] if direction in ["up", "down", "left", "right"]:
            return f"向{direction}移动"
        case ["add", *nums]:
            return f"求和：{sum(int(n) for n in nums)}"
        case _:
            return "未知命令"

print(handle_command("hello Alice"))    # 你好，Alice
print(handle_command("add 1 2 3 4"))    # 求和：10
print(handle_command("move up"))        # 向up移动
print(handle_command("fly"))            # 未知命令
```

### 总结

- 条件语句：`if-elif-else`，从上到下匹配，命中即跳出
- 真值测试：空值、零、空容器为假，其余为真，可省略显式比较
- 三元表达式 `a if cond else b` 适合简单赋值，避免过度嵌套
- 推荐使用 guard clause（提前返回）替代深层嵌套，提升可读性
- Python 3.10+ 的 `match/case` 支持结构模式匹配，比 `switch` 更强大
- 注意事项：`elif` 而非 `else if`；条件分支顺序影响结果，严格条件放前面；避免在条件中赋值（除非用海象运算符）；`==` 比较值，`is` 比较身份，条件判断一般用 `==`

## 第6讲 循环语句

### 概念

循环语句重复执行一段代码。Python 提供两种循环：`while` 循环（条件为真时重复执行）和 `for` 循环（遍历可迭代对象的元素）。`for` 循环是 Python 中最常用的循环形式，配合 `range()`、列表、字典等可迭代对象使用。Python 的 `for` 循环本质是"foreach"迭代，而非 C 语言的 `for(init;cond;update)` 形式。

### 原理

`while` 循环在每次迭代前求值条件表达式，为真则执行循环体，为假则退出。需确保循环体内有改变条件的逻辑，否则会无限循环。`for` 循环通过迭代器协议工作：调用可迭代对象的 `__iter__()` 方法获取迭代器，反复调用迭代器的 `__next__()` 方法获取元素，直到抛出 `StopIteration` 异常结束。这一统一机制使 `for` 能遍历列表、元组、字符串、字典、集合、文件等所有可迭代对象。

`range(start, stop, step)` 生成不可变的整数序列，惰性求值（不占用内存存储所有值），常用于控制循环次数。`enumerate()` 函数在遍历时同时获取索引和元素，避免手动维护计数器。`zip()` 函数并行遍历多个可迭代对象，以最短的为准。这些内置函数是 Python 循环的"惯用法"，比手动索引更 Pythonic。

### 例子

```python
# === while 循环 ===
# 基本计数循环
count = 0
while count < 5:
    print(f"计数：{count}")
    count += 1

# while 处理用户输入
# while True:
#     user_input = input("输入 quit 退出：")
#     if user_input == "quit":
#         break
#     print(f"你输入了：{user_input}")

# while 计算 1 到 100 的和
total = 0
n = 1
while n <= 100:
    total += n
    n += 1
print(f"1到100的和：{total}")  # 5050

# === for 循环遍历可迭代对象 ===
# 遍历列表
fruits = ["苹果", "香蕉", "橘子"]
for fruit in fruits:
    print(fruit)

# 遍历字符串
for char in "Python":
    print(char, end=" ")   # P y t h o n
print()

# 遍历字典
person = {"name": "Alice", "age": 25, "city": "北京"}
for key in person:                    # 默认遍历键
    print(f"{key}: {person[key]}")
for key, value in person.items():     # 同时遍历键值对
    print(f"{key} = {value}")

# === range() 函数 ===
for i in range(5):          # 0 1 2 3 4
    print(i, end=" ")
print()

for i in range(2, 8):       # 2 3 4 5 6 7
    print(i, end=" ")
print()

for i in range(0, 10, 2):   # 0 2 4 6 8（步长2）
    print(i, end=" ")
print()

for i in range(10, 0, -1):  # 10 9 8 ... 1（倒序）
    print(i, end=" ")
print()

# range 对象是惰性的，不占用大量内存
r = range(10**6)
print(f"range 对象大小：{r}")           # range(0, 1000000)
print(f"第5个元素：{r[5]}")             # 5
print(f"内存占用很小，未实际生成列表")

# === enumerate() 获取索引 ===
# 不推荐：手动维护索引
# i = 0
# for fruit in fruits:
#     print(f"{i}: {fruit}")
#     i += 1

# 推荐：enumerate
for index, fruit in enumerate(fruits):
    print(f"{index}: {fruit}")
# 0: 苹果
# 1: 香蕉
# 2: 橘子

for index, fruit in enumerate(fruits, start=1):  # 索引从1开始
    print(f"第{index}个：{fruit}")

# === zip() 并行遍历 ===
names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]
cities = ["北京", "上海", "广州"]

for name, age, city in zip(names, ages, cities):
    print(f"{name}, {age}岁, 住在{city}")

# zip 创建字典
name_age = dict(zip(names, ages))
print(name_age)  # {'Alice': 25, 'Bob': 30, 'Charlie': 35}

# zip_longest：以最长的为准（需 itertools）
from itertools import zip_longest
short = [1, 2, 3]
long = [1, 2, 3, 4, 5]
for a, b in zip_longest(short, long, fillvalue=0):
    print(a, b, end=" | ")  # 1 1 | 2 2 | 3 3 | 0 4 | 0 5 |
print()

# === for-else 和 while-else ===
# else 在循环正常结束（未 break）时执行
for i in range(5):
    if i == 3:
        print(f"找到 {i}")
        # break    # 若取消注释，else 不执行
else:
    print("循环正常结束，未触发 break")

# 实用：查找素数
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    else:
        return True

print(f"17 是素数吗？{is_prime(17)}")  # True
print(f"18 是素数吗？{is_prime(18)}")  # False
```

### 总结

- `while` 循环：条件为真时重复，需确保有终止条件，避免死循环
- `for` 循环：基于迭代器协议遍历可迭代对象，是 Python 最常用循环
- `range(start, stop, step)` 惰性生成整数序列，控制循环次数
- `enumerate()` 同时获取索引和元素，`zip()` 并行遍历多个序列
- `for-else`/`while-else`：`else` 在循环未被 `break` 时执行，适合查找逻辑
- 注意事项：遍历时不要修改正在遍历的列表（会导致跳过元素或索引错误）；`range()` 不含 `stop` 值；`zip()` 以最短序列为准；优先用 `for` 遍历而非 `while` 加索引

## 第7讲 循环控制与嵌套

### 概念

循环控制语句改变循环的正常执行流程：`break` 立即跳出当前循环，`continue` 跳过本次迭代剩余代码进入下一次迭代，`pass` 是空操作占位符。循环可以嵌套（循环内套循环），用于处理多维数据、矩阵、组合等问题。Python 还支持列表推导式等"函数式"构造，能在不显式写循环的情况下生成数据。

### 原理

`break` 和 `continue` 只作用于最内层循环，嵌套循环中无法直接跳出外层循环（除非用标志变量、`return`、异常或 `else` 配合）。`pass` 不做任何事，主要用于语法上需要语句但逻辑上无需操作的场合（如空函数体、空类体、占位）。`continue` 会跳到循环顶部重新检查条件（`while`）或获取下一个元素（`for`）。

嵌套循环的时间复杂度是各层循环次数的乘积，三层以上嵌套往往性能堪忧，应考虑算法优化或使用内置函数（如 `itertools.product`）。列表推导式在底层仍是循环，但用 C 实现，通常比等价的显式 `for` 循环加 `append` 快 20%-30%。推导式有三种形式：列表推导式 `[expr for item in iterable if cond]`、字典推导式 `{k:v for ...}`、集合推导式 `{expr for ...}`，以及生成器表达式 `(expr for ...)`（惰性求值）。

### 例子

```python
# === break：跳出循环 ===
# 查找第一个能被7整除的数
for i in range(1, 100):
    if i % 7 == 0:
        print(f"找到：{i}")   # 找到：7
        break

# break 只跳出最内层
for i in range(3):
    for j in range(3):
        if j == 1:
            break             # 只跳出内层 j 循环
        print(f"i={i}, j={j}")
# 输出：i=0,j=0 / i=1,j=0 / i=2,j=0

# === continue：跳过本次迭代 ===
# 打印 1-10 中的奇数
for i in range(1, 11):
    if i % 2 == 0:
        continue              # 跳过偶数
    print(i, end=" ")         # 1 3 5 7 9
print()

# 过滤无效数据
data = ["Alice", "", "Bob", None, "Charlie", "   "]
valid_names = []
for name in data:
    if not name or not name.strip():   # 跳过空值和空白
        continue
    valid_names.append(name.strip())
print(valid_names)           # ['Alice', 'Bob', 'Charlie']

# === pass：占位符 ===
# 空函数/类占位
def todo_function():
    pass                     # 待实现，避免语法错误

class EmptyClass:
    pass

# if 分支占位
if False:
    pass                     # 什么都不做
else:
    print("执行 else 分支")

# === 嵌套循环：九九乘法表 ===
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i*j}", end="\t")
    print()                  # 每行结束后换行

# === 嵌套循环：查找二维矩阵中的元素 ===
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
target = 5
found = False
for i, row in enumerate(matrix):
    for j, val in enumerate(row):
        if val == target:
            print(f"找到 {target} 在位置 ({i}, {j})")
            found = True
            break
    if found:
        break                # 跳出外层循环

# 更优雅的方式：用 for-else
for i, row in enumerate(matrix):
    for j, val in enumerate(row):
        if val == target:
            print(f"位置 ({i}, {j})")
            break
    else:
        continue             # 内层未找到，继续外层
    break                    # 内层找到，跳出外层

# === 列表推导式 ===
# 生成平方数列表
squares = [x**2 for x in range(1, 11)]
print(squares)               # [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]

# 带条件的推导式
even_squares = [x**2 for x in range(1, 11) if x % 2 == 0]
print(even_squares)          # [4, 16, 36, 64, 100]

# 嵌套推导式：扁平化二维列表
nested = [[1, 2, 3], [4, 5], [6, 7, 8, 9]]
flat = [num for row in nested for num in row]
print(flat)                  # [1, 2, 3, 4, 5, 6, 7, 8, 9]

# 字典推导式
word_len = {word: len(word) for word in ["apple", "banana", "cherry"]}
print(word_len)              # {'apple': 5, 'banana': 6, 'cherry': 6}

# 集合推导式
unique_chars = {char for char in "hello world"}
print(unique_chars)          # {'h', 'e', 'l', 'o', ' ', 'w', 'r', 'd'}

# 生成器表达式（惰性，用圆括号）
gen = (x**2 for x in range(10**6))
print(f"生成器不立即计算：{gen}")   # <generator object>
print(f"取前5个：{list(gen)[:5]}")  # 实际计算时才求值

# === itertools.product 替代嵌套循环 ===
from itertools import product

# 笛卡尔积
colors = ["红", "蓝"]
sizes = ["S", "M", "L"]
for color, size in product(colors, sizes):
    print(f"{color}-{size}", end=" ")
print()
# 红-S 红-M 红-L 蓝-S 蓝-M 蓝-L
```

### 总结

- `break` 跳出当前循环，`continue` 跳过本次迭代，`pass` 是空占位符
- 嵌套循环中 `break/continue` 只作用于最内层，跨层跳出需用标志变量或重构
- 列表推导式 `[expr for x in iterable if cond]` 比显式循环更简洁高效
- 字典推导式 `{k:v for ...}`、集合推导式 `{x for ...}`、生成器表达式 `(expr for ...)` 惰性求值
- `itertools.product` 可替代简单嵌套循环，更清晰
- 注意事项：避免三层以上嵌套，考虑拆分函数或用内置工具；推导式过长时拆为多行或改用普通循环以保可读性；遍历时修改列表应先复制（`for x in lst[:]`）或用推导式生成新列表；生成器表达式比列表推导式省内存，适合大数据

# 第3章 数据结构

数据结构是组织和管理数据的方式。Python 内置了强大的数据结构：列表、元组、集合、字典。本章详细讲解它们的特性、操作与应用场景，这是 Python 编程的核心。

## 第8讲 列表

### 概念

列表（`list`）是 Python 最常用的数据结构，是一个有序、可变的元素序列。列表用方括号 `[]` 表示，元素之间用逗号分隔，可以包含任意类型的元素（甚至混合类型），也可以嵌套其他列表。列表支持索引访问（正索引从 0 开始，负索引从 -1 开始）、切片、追加、插入、删除、排序等丰富操作。

### 原理

列表在底层是动态数组（C 语言实现的 `PyListObject`），存储的是对象的引用（指针）而非对象本身。这使得列表可以容纳异构元素，但也意味着访问元素需要一次指针解引用。列表的内存预分配策略：当容量不足时，会按 `new_size + (new_size >> 3) + 6` 的公式扩容，分摊后追加操作的平均时间复杂度为 O(1)。在列表头部或中间插入/删除元素需要移动后续元素，时间复杂度为 O(n)。

索引访问 O(1)，切片操作 O(k)（k 为切片长度），`in` 成员判断 O(n)（需线性扫描）。列表是可变对象，赋值是引用传递，修改一个会影响所有引用同一列表的变量。若需独立副本，使用 `copy()`、`list()` 或切片 `[:]` 进行浅拷贝，使用 `copy.deepcopy()` 进行深拷贝。

### 例子

```python
# === 创建列表 ===
empty = []                          # 空列表
numbers = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]    # 混合类型
nested = [[1, 2], [3, 4], [5, 6]]   # 嵌套
from_list = list("abc")             # ['a', 'b', 'c']，从可迭代对象创建
from_range = list(range(5))         # [0, 1, 2, 3, 4]

# === 索引访问 ===
fruits = ["苹果", "香蕉", "橘子", "葡萄", "西瓜"]
print(fruits[0])        # 苹果（正索引）
print(fruits[-1])       # 西瓜（负索引，最后一个）
print(fruits[-2])       # 葡萄
# print(fruits[10])     # IndexError: 索引越界

# === 切片 [start:stop:step] ===
print(fruits[1:4])      # ['香蕉', '橘子', '葡萄']，不含 stop
print(fruits[:3])       # ['苹果', '香蕉', '橘子']，从头开始
print(fruits[2:])       # ['橘子', '葡萄', '西瓜']，到末尾
print(fruits[:])        # 全部，创建浅拷贝
print(fruits[::2])      # ['苹果', '橘子', '西瓜']，步长2
print(fruits[::-1])     # 反转列表：['西瓜', '葡萄', '橘子', '香蕉', '苹果']

# 切片赋值（可改变列表长度）
nums = [1, 2, 3, 4, 5]
nums[1:3] = [20, 30, 40]
print(nums)             # [1, 20, 30, 40, 4, 5]
nums[2:4] = []          # 删除切片
print(nums)             # [1, 20, 4, 5]

# === 添加元素 ===
lst = [1, 2, 3]
lst.append(4)           # 追加到末尾，O(1)
print(lst)              # [1, 2, 3, 4]
lst.insert(0, 0)        # 在索引0插入，O(n)
print(lst)              # [0, 1, 2, 3, 4]
lst.extend([5, 6])      # 扩展另一个可迭代对象
print(lst)              # [0, 1, 2, 3, 4, 5, 6]
# 等价于 lst += [5, 6]

# === 删除元素 ===
lst = [1, 2, 3, 2, 4, 2]
lst.remove(2)           # 删除第一个匹配的 2
print(lst)              # [1, 3, 2, 4, 2]
popped = lst.pop()      # 弹出末尾元素
print(popped, lst)      # 2 [1, 3, 2, 4]
popped = lst.pop(0)     # 弹出指定索引
print(popped, lst)      # 1 [3, 2, 4]
del lst[0]              # 删除指定索引
print(lst)              # [2, 4]
lst.clear()             # 清空列表
print(lst)              # []

# === 查找与统计 ===
nums = [10, 20, 30, 20, 40]
print(nums.index(20))   # 1，第一个匹配的索引
print(nums.count(20))   # 2，出现次数
print(30 in nums)       # True，成员判断

# === 排序与反转 ===
scores = [88, 75, 92, 67, 95]
scores.sort()           # 原地升序排序
print(scores)           # [67, 75, 88, 92, 95]
scores.sort(reverse=True)  # 原地降序
print(scores)           # [95, 92, 88, 75, 67]
scores.reverse()        # 原地反转
print(scores)           # [67, 75, 88, 92, 95]

# sorted() 返回新列表，不修改原列表
original = [3, 1, 4, 1, 5, 9, 2, 6]
sorted_list = sorted(original)
print(original)         # [3, 1, 4, 1, 5, 9, 2, 6] 不变
print(sorted_list)      # [1, 1, 2, 3, 4, 5, 6, 9]

# 自定义排序 key
students = [("Alice", 85), ("Bob", 92), ("Charlie", 78)]
students.sort(key=lambda x: x[1], reverse=True)  # 按分数降序
print(students)         # [('Bob', 92), ('Alice', 85), ('Charlie', 78)]

# 多级排序
students.sort(key=lambda x: (-x[1], x[0]))  # 分数降序，名字升序

# === 浅拷贝与深拷贝 ===
original = [[1, 2], [3, 4]]
# 浅拷贝：外层新列表，内层共享
shallow = original.copy()
shallow[0][0] = 99
print(original)         # [[99, 2], [3, 4]]，内层被影响！

# 深拷贝：完全独立
import copy
original2 = [[1, 2], [3, 4]]
deep = copy.deepcopy(original2)
deep[0][0] = 99
print(original2)        # [[1, 2], [3, 4]]，不受影响

# === 列表推导式（复习）===
# 过滤 + 转换

result = [x**2 for x in nums if x % 2 == 0]
print(result)           # [4, 16, 36, 64, 100, 144, 196, 256, 324]

# === 实用示例：学生成绩管理 ===
class GradeBook:
    def __init__(self):
        self.students = []   # 每个元素: [name, [score1, score2, ...]]

    def add_student(self, name):
        self.students.append([name, []])

    def add_score(self, name, score):
        for student in self.students:
            if student[0] == name:
                student[1].append(score)
                return
        print(f"未找到学生 {name}")

    def average(self, name):
        for student in self.students:
            if student[0] == name:
                scores = student[1]
                return sum(scores) / len(scores) if scores else 0

    def ranking(self):
        return sorted(self.students, key=lambda s: -self.average(s[0]))

book = GradeBook()
book.add_student("Alice")
book.add_student("Bob")
book.add_score("Alice", 85)
book.add_score("Alice", 90)
book.add_score("Bob", 78)
book.add_score("Bob", 88)
for name, _ in book.ranking():
    print(f"{name}: {book.average(name):.1f}")
# Alice: 87.5
# Bob: 83.0
```

### 总结

- 列表是有序、可变、可异构的序列，底层是动态数组，存储对象引用
- 索引 O(1)，切片 O(k)，`append` 均摊 O(1)，`insert(0)`/`remove` O(n)
- `sort()` 原地排序，`sorted()` 返回新列表，均支持 `key` 和 `reverse` 参数
- 浅拷贝（`copy()`/`[:]`/`list()`）只复制外层，深拷贝（`copy.deepcopy()`）完全独立
- 注意事项：列表是引用类型，函数传参修改会影响原列表；`append` 与 `extend` 区别（单个元素 vs 可迭代对象）；遍历时删除元素易出错，建议用推导式生成新列表；`sort()` 只能排同类型元素，混合类型需自定义 `key`

## 第9讲 元组与集合

### 概念

元组（`tuple`）是有序、不可变的序列，用圆括号 `()` 表示。一旦创建，元素不可增删改。元组常用于固定数据集合、函数多返回值、字典键等场景。集合（`set`）是无序、可变、元素唯一的容器，用花括号 `{}` 或 `set()` 创建，支持数学集合运算（并、交、差、对称差）。还有不可变集合 `frozenset`，可作为字典键或集合元素。

### 原理

元组的不可变性指元素引用不可变——若元素本身是可变对象（如列表），该对象内部仍可修改。元组比列表更省内存（无扩容开销），创建速度更快，可作为字典键（因可哈希）。单元素元组必须加逗号 `(1,)`，否则 `(1)` 被解析为括号表达式。元组支持与列表相同的索引、切片、`in`、`count`、`index` 操作，但不支持修改类方法。

集合基于哈希表实现，元素必须可哈希（不可变类型如数字、字符串、元组；列表、字典、集合不可哈希）。集合的成员判断 `in` 是 O(1) 平均复杂度（远快于列表的 O(n)），这是集合的核心优势。集合不保证元素顺序（虽然 Python 3.7+ 字典保序，但集合仍不保证）。添加元素时若已存在则忽略，自动去重。`frozenset` 是不可变集合，创建后不能增删元素，可哈希，可作为字典键。

### 例子


### 总结

- 元组：有序、不可变、可哈希，省内存，常用于固定数据、多返回值、字典键
- 单元素元组必须加逗号 `(1,)`；元组解包支持 `a, *b, c = ...` 形式
- 集合：无序、元素唯一、基于哈希表，`in` 操作 O(1)，适合去重和成员判断
- 集合运算：`|` 并、`&` 交、`-` 差、`^` 对称差，对应方法 `union/intersection/difference/symmetric_difference`

- 注意事项：空集合用 `set()` 而非 `{}`；集合元素必须可哈希（列表、字典不能作为元素）；集合无序，不要依赖顺序；元组不可变指引用不可变，内部可变对象仍可修改；`namedtuple` 适合替代简单类

## 第10讲 字典

### 概念

字典（`dict`）是 Python 中最重要的数据结构之一，是键值对（key-value）映射容器，用花括号 `{}` 表示。字典通过键快速查找对应的值，键必须可哈希（不可变类型），值可以是任意类型。Python 3.7+ 保证字典保持插入顺序。字典支持增删改查、推导式、`get`/`setdefault` 等方法，是处理结构化数据、缓存、计数等场景的首选。

### 原理

字典基于哈希表实现。插入时，对键调用 `hash()` 计算哈希值，再映射到桶（bucket）位置存储键值对。查找时同样计算哈希定位桶，再通过 `==` 比较键。平均情况下，查找、插入、删除均为 O(1)；最坏情况（哈希冲突严重）退化为 O(n)，但 Python 的哈希算法设计良好，实际几乎不会发生。键必须可哈希，即实现 `__hash__()` 和 `__eq__()` 方法，所以列表、字典、集合（可变）不能作键，而数字、字符串、元组、`frozenset`（不可变）可以。

Python 3.6+ 采用紧凑字典实现，内存占用比旧版减少 20%-25%，且保持插入顺序（3.7+ 成为语言规范保证）。`collections.OrderedDict` 在需要显式顺序操作（如 `move_to_end`、`popitem(last=False)`）时仍有用。`collections.defaultdict` 提供默认值工厂，避免 `KeyError`；`collections.Counter` 专用于计数。

### 例子

```python
# === 创建字典 ===

from_pairs = dict([("a", 1), ("b", 2)]) # 从键值对列表
from_kwargs = dict(name="Bob", age=30)  # 从关键字参数
comprehension = {x: x**2 for x in range(5)}  # 字典推导式

person = {"name": "Alice", "age": 25}
print(person["name"])                   # Alice
# print(person["email"])                # KeyError: 键不存在

# get() 安全访问，不存在返回默认值
print(person.get("email"))              # None
print(person.get("email", "未设置"))     # 未设置

def fib(n, memo={}):
    """带缓存的斐波那契数列"""
    if n in memo:
        return memo[n]
    if n < 2:
        return n
    memo[n] = fib(n-1, memo) + fib(n-2, memo)
    return memo[n]

print(fib(100))                         # 354224848179261915075（瞬间完成）

# === 实用：JSON 风格数据 ===

    "id": 1,
    "name": "Alice",
    "roles": ["admin", "editor"],
    "profile": {
        "age": 25,
        "city": "北京"
    }
}
```

- 字典是键值对映射，基于哈希表，查找/插入/删除平均 O(1)
- 键必须可哈希（不可变类型），值任意；3.7+ 保证插入顺序
- `get(key, default)` 安全访问，`setdefault` 设置默认值，`update` 批量更新
- `defaultdict` 自动默认值，`Counter` 计数，`OrderedDict` 高级顺序操作
- 字典推导式 `{k:v for ... if ...}` 简洁高效
- 注意事项：`in` 判断的是键不是值；遍历时修改字典会抛 `RuntimeError`，应先收集再修改或遍历 `list(d.keys())`；嵌套字典访问用链式 `d["a"]["b"]`；`memo={}` 默认参数在函数间共享（可用于缓存，但需注意副作用）

## 第11讲 字符串进阶

### 概念

字符串是 Python 中处理文本的核心类型。本讲深入讲解字符串的高级特性：字符串的不可变性与内存机制、格式化进阶、正则表达式基础、编码与解码、f-string 高级用法。掌握这些内容能高效处理日志解析、数据清洗、文本分析等实际任务。

### 原理

Python 3 的字符串是 Unicode 字符序列（`str` 类型），每个字符是一个 Unicode 码点。字符串不可变，任何"修改"操作都返回新字符串。CPython 对字符串有驻留优化：看起来像标识符的字符串（仅含字母数字下划线）会被驻留，相同字面量共享同一对象，节省内存。`sys.intern()` 可手动驻留字符串。

字符串编码：`str` 是 Unicode 文本，`bytes` 是字节序列。`encode()` 将 `str` 编码为 `bytes`（如 UTF-8、GBK），`decode()` 将 `bytes` 解码为 `str`。文件 I/O、网络传输涉及编码转换，乱码多源于编码不一致。推荐统一使用 UTF-8。

正则表达式通过 `re` 模块支持，用于模式匹配与文本提取。`re.match` 从开头匹配，`re.search` 全文搜索，`re.findall` 返回所有匹配，`re.sub` 替换，`re.split` 分割。`re.compile` 预编译模式可提升多次匹配性能。原始字符串 `r"..."` 避免反斜杠转义，写正则时强烈推荐。

### 例子

```python
# === 字符串不可变性与驻留 ===
s1 = "hello"
s2 = "hello"
print(s1 is s2)        # True，标识符风格字符串被驻留

s3 = "hello world!"
s4 = "hello world!"
print(s3 is s4)        # 可能 False，含空格不被自动驻留

# 修改字符串需创建新对象
s = "hello"
s += " world"          # 实际创建新字符串，原对象不变
print(s)               # hello world

# 大量拼接用 join 而非 +=，性能更好
parts = ["a"] * 10000
# 慢：result = ""; for p in parts: result += p
# 快：
result = "".join(parts)

# === 字符串格式化进阶 ===
# f-string 高级用法
name = "Alice"
data = {"age": 25, "score": 95.5}

# 访问字典
print(f"年龄：{data['age']}")           # 注意用单引号

# 调用方法
```

## 第12讲 函数定义与参数

### 概念

函数是一段可复用的代码块，通过 `def` 关键字定义，接收输入（参数），执行逻辑，返回输出（返回值）。Python 函数支持丰富的参数形式：位置参数、关键字参数、默认参数、可变位置参数（`*args`）、可变关键字参数（`**kwargs`）、仅关键字参数、仅位置参数（3.8+）。函数是一等对象，可作为参数传递、作为返回值、赋值给变量。

### 原理

Python 函数参数传递采用"对象引用传递"（pass by object reference），也称"传共享"。函数接收的是对象的引用副本，对可变对象（列表、字典）的内部修改会影响原对象，对不可变对象（数字、字符串、元组）的"修改"实际是重新绑定，不影响原对象。

参数匹配顺序：先匹配位置参数，再匹配关键字参数，最后处理 `*args` 和 `**kwargs`。默认参数在函数定义时求值一次，因此可变默认参数（如 `def f(lst=[])`）会共享同一对象，是常见陷阱——应改用 `None` 作哨兵值。`*args` 收集多余位置参数为元组，`**kwargs` 收集多余关键字参数为字典。`/` 之前的参数为仅位置参数，`*` 之后的参数为仅关键字参数。

函数返回值通过 `return` 语句，无 `return` 或 `return` 无值则返回 `None`。返回多个值实际是返回元组，配合解包使用。

- `lambda` 适合简短一次性函数，排序 `key`、`map`/`filter` 常用，但推导式通常更 Pythonic
- 注意事项：参数顺序为 `位置/默认/*args/仅关键字/**kwargs`；多返回值是元组；文档字符串用三引号；避免函数过长，单一职责

## 第13讲 作用域与闭包

### 概念

作用域是变量名的可见范围。Python 采用 LEGB 规则查找变量：Local（局部）→ Enclosing（嵌套函数的外层）→ Global（全局）→ Built-in（内置）。函数内部可读取外层变量，但修改需用 `global`（全局）或 `nonlocal`（外层函数）声明。闭包是引用了自由变量的内层函数，即使外层函数已返回，内层函数仍能访问这些变量，是装饰器和函数式编程的基础。

### 原理

Python 在编译函数时确定变量的作用域：函数内赋值的变量默认为局部变量，无论赋值位置。若函数内某处赋值，则整个函数中该变量视为局部——即使在赋值前引用也会报 `UnboundLocalError`。`global` 声明变量指向模块级全局，`nonlocal` 声明变量指向最近的外层函数作用域（非全局）。

闭包的本质：函数对象携带一个 `__closure__` 属性，存储其引用的自由变量（cell 对象）。即使外层函数栈帧销毁，闭包仍持有这些变量的引用，因此能"记住"外层环境。每次调用外层函数会创建新的闭包，各自独立。闭包常用于：工厂函数（生成配置化的函数）、装饰器、回调、状态保持（替代简单类）。

注意：闭包捕获的是变量本身（引用），而非值。在循环中创建闭包若直接引用循环变量，所有闭包会共享最后一次的值，需通过默认参数或 `functools.partial` 绑定当前值。

### 例子

```python
# === LEGB 规则 ===
x = "global"           # Global

def outer():
    x = "enclosing"    # Enclosing

    def inner():
        x = "local"    # Local
        print(x)       # 找到 Local
    inner()
    print(x)           # Enclosing

outer()
print(x)               # global

# 查找顺序演示
name = "全局"

def test_scope():
    name = "局部"
    print(name)        # 局部（优先 Local）

test_scope()
print(name)            # 全局

# === 读取外层变量 ===
counter = 0

def show_counter():
    print(counter)     # 读取全局变量，OK

show_counter()         # 0

# === global：修改全局变量 ===
counter = 0

def increment():
    global counter     # 声明使用全局变量
    counter += 1

increment()
increment()
print(counter)         # 2

# 不用 global 会怎样
def bad_increment():
    # counter += 1     # UnboundLocalError: 赋值使其成为局部变量，但赋值前引用
    pass

# === nonlocal：修改外层函数变量 ===
def make_counter():
    count = 0          # 外层函数的局部变量

    def increment():
        nonlocal count # 声明使用外层变量
        count += 1
        return count

    return increment

c = make_counter()
print(c())             # 1
print(c())             # 2
print(c())             # 3
# count 被"记住"了，即使 make_counter 已返回

# === 闭包基础 ===
def make_greeting(greeting):
    """工厂函数：生成不同问候语的函数"""
    def greet(name):
        return f"{greeting}, {name}!"   # greeting 是自由变量
    return greet

hello = make_greeting("Hello")
nihao = make_greeting("你好")
print(hello("Alice"))    # Hello, Alice!
print(nihao("Bob"))      # 你好，Bob！

# 查看闭包
print(hello.__closure__)             # 包含 greeting 的 cell
print(hello.__closure__[0].cell_contents)  # Hello

# === 闭包保持状态 ===
def make_account(initial_balance):
    balance = initial_balance

    def deposit(amount):
        nonlocal balance
        balance += amount
        return balance

    def withdraw(amount):
        nonlocal balance
        if amount > balance:
            return "余额不足"
        balance -= amount
        return balance

    def get_balance():
        return balance

    return deposit, withdraw, get_balance

deposit, withdraw, get_balance = make_account(100)
print(deposit(50))      # 150
print(withdraw(30))     # 120
print(get_balance())    # 120

# === 闭包陷阱：循环变量 ===
# 错误：所有闭包共享同一个 i

for i in range(3):
    funcs_bad.append(lambda: i)
print([f() for f in funcs_bad])    # [2, 2, 2]！都是最后的 i

# 正确1：用默认参数绑定当前值
funcs_good = []
for i in range(3):
    funcs_good.append(lambda x=i: x)
print([f() for f in funcs_good])   # [0, 1, 2]

# 正确2：用工厂函数
def make_func(x):
    return lambda: x

funcs_good2 = [make_func(i) for i in range(3)]
print([f() for f in funcs_good2])  # [0, 1, 2]

# === 闭包实现装饰器（预告）===
def log_calls(func):
    call_count = 0

    def wrapper(*args, **kwargs):
        nonlocal call_count
        call_count += 1
        print(f"第 {call_count} 次调用 {func.__name__}")
        return func(*args, **kwargs)

    return wrapper

@log_calls
def say_hi(name):
    return f"Hi, {name}"

print(say_hi("Alice"))   # 第 1 次调用 say_hi / Hi, Alice
print(say_hi("Bob"))     # 第 2 次调用 say_hi / Hi, Bob

# === 实用：缓存装饰器（简化版）===
def memoize(func):
    cache = {}

    def wrapper(*args):
        if args not in cache:
            cache[args] = func(*args)
        return cache[args]

    return wrapper

@memoize
def fib(n):
    if n < 2:
        return n
    return fib(n-1) + fib(n-2)

print(fib(50))           # 12586269025，瞬间完成（无缓存会极慢）

# === globals() 和 locals() ===
def show_scopes():
    local_var = 10
    print("局部变量：", locals())

show_scopes()
print("全局变量中的 x：", "x" in globals())
```

### 总结

- LEGB 查找规则：Local → Enclosing → Global → Built-in
- 函数内赋值的变量默认局部，修改全局用 `global`，修改外层函数变量用 `nonlocal`
- 闭包是引用自由变量的内层函数，外层返回后仍能访问这些变量，`__closure__` 存储引用
- 闭包用途：工厂函数、状态保持、装饰器、回调
- 循环中创建闭包需注意变量绑定陷阱，用默认参数或工厂函数解决
- 注意事项：避免滥用全局变量，破坏封装；闭包比类轻量但状态管理不如类清晰；`nonlocal` 只能用于嵌套函数，不能跳到全局；闭包捕获的是变量引用，延迟求值时注意

## 第14讲 模块与包

### 概念

模块（module）是一个 `.py` 文件，包含函数、类、变量的定义。包（package）是包含 `__init__.py` 的目录，组织多个相关模块。模块化使代码可复用、可维护、避免命名冲突。Python 通过 `import` 语句导入模块，支持多种导入形式。标准库提供数百个模块（如 `os`、`sys`、`math`、`datetime`、`json`），第三方包通过 `pip` 安装。

### 原理

Python 导入模块时，在 `sys.path` 列表的目录中搜索。找到后执行模块代码（仅首次导入，后续从 `sys.modules` 缓存读取），创建模块对象，绑定到当前命名空间。`import module` 绑定模块名，`from module import name` 绑定具体名称，`import module as alias` 使用别名。`from module import *` 导入所有公开名称（不推荐，污染命名空间）。

每个模块有 `__name__` 属性：直接运行时为 `"__main__"`，被导入时为模块名。`if __name__ == "__main__":` 惯用法使模块既能作为脚本运行，又能被安全导入。包的 `__init__.py` 在导入包时执行，可用于初始化、暴露子模块。Python 3.3+ 支持命名空间包（无 `__init__.py` 的目录也可作为包）。

`__all__` 列表控制 `from module import *` 导入的名称，也用于文档化公开 API。相对导入（`from . import sibling`）用于包内部模块引用，绝对导入（`import package.module`）用于跨包引用。

## 第15讲 类与对象

### 概念

类（class）是创建对象的蓝图，定义属性（数据）和方法（行为）。对象（instance）是类的具体实例。Python 是一门面向对象语言，"一切皆对象"——数字、字符串、函数、类本身都是对象。类通过 `class` 关键字定义，`__init__` 是初始化方法（构造器），`self` 指向当前实例。类支持实例属性、类属性、实例方法、类方法、静态方法。

### 原理

Python 类基于"类型-对象"模型。类本身也是对象（`type` 的实例），称为元类机制。定义类时，Python 创建一个类对象，包含方法字典和类属性。实例化（`ClassName()`）调用类的 `__call__`，进而调用 `__new__`（创建实例）和 `__init__`（初始化实例）。`self` 是约定俗成的名称，本质是实例对象的引用，作为方法的第一个参数自动传入。

属性查找机制：访问 `obj.attr` 时，先在实例的 `__dict__` 中查找，找不到再到类的 `__dict__`，再到父类（按 MRO 顺序），最后到 `type`。实例属性存储在 `instance.__dict__`，类属性存储在 `class.__dict__`。通过实例赋值创建的是实例属性，不影响类属性；但通过实例读取时若类属性存在则可访问。

`__init__` 不是真正的构造器（`__new__` 才是），但通常只重写 `__init__`。类方法（`@classmethod`）接收类作为第一参数（`cls`），常用于工厂方法；静态方法（`@staticmethod`）不接收 self/cls，是放在类命名空间的普通函数。`@property` 装饰器将方法变为属性访问，实现 getter/setter 控制。

### 例子

```python

    """狗类"""

    # 类属性：所有实例共享

    # 初始化方法（构造器）
    def __init__(self, name, age):
        self.name = name    # 实例属性
        self.age = age

    def bark(self):
        return f"{self.name} 汪汪叫！"

    def describe(self):
        return f"{self.name} 是一只 {self.age} 岁的狗"

    def __init__(self, radius):
        self.radius = radius            # 这里会触发 setter

    @property
    def radius(self):
        """getter"""
        return self._radius

    @radius.setter
    def radius(self, value):
        """setter：添加验证"""
        if value < 0:
            raise ValueError("半径不能为负")
        self._radius = value

    @property
    def area(self):
        """只读属性"""
        return 3.14159 * self._radius ** 2

    @property
    def perimeter(self):
        return 2 * 3.14159 * self._radius

        self.month = month

    def from_string(cls, date_str):

    def today(cls):
        """创建今天的日期"""
        import datetime
        t = datetime.date.today()

        return f"{self.year}-{self.month:02d}-{self.day:02d}"

        self._balance = balance    # 约定：_ 开头表示内部使用

        if amount <= 0:
            raise ValueError("存款金额必须为正")
        self._balance += amount
        return self._balance

    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError("取款金额必须为正")
        if amount > self._balance:
            raise ValueError("余额不足")
        self._balance -= amount
        return self._balance

    @property
    def balance(self):
        return self._balance

    def __str__(self):
        return f"账户({self.owner}, 余额: {self._balance:.2f})"

acc.deposit(500)
acc.withdraw(200)

# acc.balance = 500         # AttributeError，无 setter
```

- 类用 `class` 定义，`__init__` 初始化，`self` 指向实例
- 类属性所有实例共享，实例属性各实例独立；通过实例赋值创建实例属性
- `@classmethod`（第一参数 `cls`）适合工厂方法，`@staticmethod` 是类命名空间的普通函数
- `@property` 将方法变为属性，可定义 getter/setter 实现验证和只读控制
- `__slots__` 限制可添加的属性，节省内存，适合大量实例
- 注意事项：`self` 是约定名，可改但不推荐；`_name` 约定内部使用，`__name` 触发名称改写（伪私有）；属性查找先实例后类；动态添加属性灵活但易出错，大型项目可用 `dataclasses` 或类型注解约束

## 第16讲 继承与多态

### 概念

继承是面向对象的核心特性，子类继承父类的属性和方法，并可扩展或覆盖。Python 支持单继承和多继承，通过 `class Child(Parent)` 语法。多态指不同类的对象对同一消息（方法调用）作出不同响应，Python 的多态基于"鸭子类型"——不关心对象类型，只关心是否有需要的方法。`super()` 调用父类方法，MRO（方法解析顺序）决定多继承下的查找顺序。

### 原理

Python 继承机制：子类实例包含父类的属性和方法。方法查找沿 MRO（Method Resolution Order）链进行，Python 3 使用 C3 线性化算法计算 MRO，可通过 `ClassName.__mro__` 查看。`super()` 返回 MRO 中下一个类的代理对象，并非严格意义的"父类"——在多继承下，`super()` 可能指向兄弟类（协作多继承）。

多继承的菱形继承问题（D 继承 B 和 C，B 和 C 都继承 A）通过 MRO 和 `super()` 协作解决：`super()` 调用会沿 MRO 传递，每个类只初始化一次。但多继承增加复杂性，推荐优先使用组合（has-a）而非继承（is-a），遵循"组合优于继承"原则。

鸭子类型：`len()`、`for` 循环、`+` 运算等不检查类型，只检查是否实现相应协议（`__len__`、`__iter__`、`__add__`）。这使得自定义类型能无缝接入 Python 内置功能。`isinstance()` 检查类型（考虑继承），`issubclass()` 检查类关系。抽象基类（ABC）通过 `abc` 模块定义接口，强制子类实现方法。

### 例子

```python

        pass

    def area(self):

    def perimeter(self):
```

## 第17讲 魔术方法与封装

### 概念

魔术方法（magic methods / dunder methods）是以双下划线开头和结尾的特殊方法，如 `__init__`、`__str__`、`__len__`、`__add__`、`__eq__` 等。它们定义了对象与 Python 内置操作的交互行为，是实现运算符重载、自定义容器、对象比较等的核心机制。封装通过访问控制（`_`/`__` 前缀）和 property 实现数据隐藏，`@dataclass`（3.7+）简化数据类定义。

### 原理

魔术方法由 Python 解释器在特定操作时自动调用，而非直接调用。例如 `len(obj)` 调用 `obj.__len__()`，`obj + other` 调用 `obj.__add__(other)`，`print(obj)` 调用 `obj.__str__()` 或 `obj.__repr__()`，`obj[key]` 调用 `obj.__getitem__(key)`。通过实现这些方法，自定义类能像内置类型一样自然使用。

`__str__` 面向用户（`print`/`str`），应可读；`__repr__` 面向开发者（`repr`/交互式），应明确且尽量能重建对象。若只实现一个，实现 `__repr__`（`__str__` 默认回退到 `__repr__`）。

封装：Python 没有真正的访问控制，靠约定。`_name` 表示"内部使用"（可访问但不推荐），`__name` 触发名称改写为 `_ClassName__name`（伪私有，仍可访问但更难误用）。`@property` 提供受控访问。`@dataclass` 装饰器自动生成 `__init__`、`__repr__`、`__eq__` 等，大幅简化数据类代码。

```python
class Stack:
    def __init__(self):
        self._items = []

    def push(self, item):
        self._items.append(item)

    def pop(self):
        if self.is_empty():
            raise IndexError("pop from empty stack")
        return self._items.pop()

    def peek(self):
        if self.is_empty():
            raise IndexError("peek from empty stack")
        return self._items[-1]

    def is_empty(self):
        return len(self._items) == 0

    def __len__(self):
        return len(self._items)

    def __repr__(self):
        return f"Stack({self._items})"

stack = Stack()
stack.push(1)
stack.push(2)
stack.push(3)
print(stack)             # Stack([1, 2, 3])
print(stack.pop())       # 3
```

## 第18讲 异常处理

### 概念

异常（exception）是程序运行时发生的错误，如除零、索引越界、文件不存在等。Python 用 `try-except-else-finally` 结构捕获和处理异常，`raise` 主动抛出异常，可自定义异常类。良好的异常处理使程序健壮，能优雅应对错误而非崩溃。异常是对象，所有异常继承自 `BaseException`，自定义异常应继承 `Exception`。

### 原理

Python 异常机制基于"抛出-捕获"模型。发生错误时，解释器创建异常对象并抛出，沿调用栈向上查找匹配的 `except` 块。若找到则执行处理，否则程序终止并打印 traceback。`try` 块监视可能出错的代码，`except` 捕获特定异常，`else` 在无异常时执行，`finally` 无论是否异常都执行（常用于资源清理）。

异常匹配按顺序进行，先匹配具体的子类异常，再匹配父类。捕获 `Exception` 可捕获大多数常规异常（但不含 `KeyboardInterrupt`、`SystemExit` 等）。`except` 可同时捕获多种异常（元组形式），可用 `as` 绑定异常对象获取详情。

`raise` 抛出异常，可重新抛出当前异常（`raise` 无参数，在 except 块中）或抛出新异常并保留原异常链（`raise NewError from original`）。自定义异常继承 `Exception`，可添加属性传递错误上下文。异常处理有性能开销，不应替代正常控制流（不要用异常做循环退出等）。

```python
# === 实用：重试装饰器 ===
import time
import functools

def retry(max_attempts=3, delay=1, exceptions=(Exception,)):
    """重试装饰器"""
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last_exception = None
            for attempt in range(1, max_attempts + 1):
                try:
                    return func(*args, **kwargs)
                except exceptions as e:
                    last_exception = e
                    print(f"第 {attempt} 次尝试失败：{e}")
                    if attempt < max_attempts:
                        time.sleep(delay)
            raise last_exception
        return wrapper
    return decorator

@retry(max_attempts=3, delay=0.1)
def unreliable_api():
    import random
    if random.random() < 0.7:
        raise ConnectionError("网络错误")
    return "成功"

try:
    print(unreliable_api())
except ConnectionError:
    print("最终失败")
```

- `try-except-else-finally`：`try` 监视，`except` 捕获，`else` 无异常时执行，`finally` 总是执行（资源清理）
- 异常匹配按顺序，先具体后宽泛，`Exception` 捕获大多数常规异常
- `raise` 抛出异常，`raise ... from ...` 保留异常链，`raise` 无参数重新抛出
- 自定义异常继承 `Exception`，可添加属性传递错误上下文
- `assert` 用于调试，可被 `-O` 优化掉，不用于生产数据验证
- 注意事项：不要裸 `except:`（捕获所有异常包括 `KeyboardInterrupt`），用 `except Exception:`；异常有性能开销，不替代正常控制流；`finally` 中避免抛出新异常；自定义异常层次清晰，便于上层统一处理

## 第19讲 文件操作与上下文管理

### 概念

文件操作是程序与外部数据交互的基础。Python 通过内置 `open()` 函数读写文件，支持文本模式（`t`）和二进制模式（`b`）。上下文管理器（`with` 语句）确保资源自动释放，即使发生异常也能正确关闭文件。`pathlib`（3.4+）提供面向对象的路径操作，比 `os.path` 更现代。`json`、`csv`、`pickle` 等模块处理结构化数据。

### 原理

`open(filename, mode)` 返回文件对象。模式：`r` 读（默认）、`w` 写（覆盖）、`a` 追加、`x` 独占创建（存在则失败）、`b` 二进制、`t` 文本（默认）、`+` 读写。文本模式自动处理编码转换和换行符（`\n` 在 Windows 转为 `\r\n`），二进制模式按字节操作。文件对象是迭代器，可逐行遍历，大文件处理内存友好。

`with` 语句调用对象的 `__enter__` 和 `__exit__` 方法，确保资源释放。`__exit__` 即使在异常时也会执行，因此 `with open(...) as f:` 保证文件关闭，是推荐的文件操作方式。`contextlib.contextmanager` 装饰器可将生成器函数转为上下文管理器，简化自定义实现。

`pathlib.Path` 用面向对象方式操作路径，支持 `/` 运算符拼接、`.parent`/`.name`/`.suffix` 属性、`.exists()`/`.mkdir()`/`.glob()` 方法，跨平台一致。`json` 模块序列化 Python 对象为 JSON，`pickle` 序列化任意 Python 对象（但不安全，不用于不受信数据）。`csv` 模块处理 CSV 文件，`shutil` 提供高级文件操作（复制、移动、删除目录）。

## 第20讲 迭代器、生成器与装饰器

### 概念

迭代器是实现了 `__iter__` 和 `__next__` 的对象，支持逐个产出元素。生成器是一种特殊的迭代器，用 `yield` 关键字定义，函数暂停执行并产出值，下次调用从暂停处继续。生成器表达式是列表推导式的惰性版本。装饰器是接收函数返回函数的高阶函数，用 `@decorator` 语法应用，用于在不修改原函数的前提下扩展功能（日志、缓存、权限、重试等）。

### 原理

迭代器协议：对象实现 `__iter__()`（返回自身）和 `__next__()`（返回下一个元素，无元素时抛 `StopIteration`）。`for` 循环、`list()`、`sum()` 等通过 `iter()` 获取迭代器，反复调用 `next()` 直到 `StopIteration`。可迭代对象（iterable）实现 `__iter__` 返回迭代器，或实现 `__getitem__` 支持索引访问。

生成器函数包含 `yield`，调用时返回生成器对象而不执行函数体。每次 `next()` 执行到 `yield` 暂停并产出值，保留局部变量和执行位置；再次 `next()` 从暂停处继续。`yield from` 委托给子生成器（3.3+）。生成器是"惰性求值"的，按需产出，内存效率高，适合处理大数据流、无限序列、管道。

装饰器本质：`@decorator` 等价于 `func = decorator(func)`。装饰器接收原函数，返回新函数（通常用 `functools.wraps` 保留原函数元信息）。装饰器可叠加（从下往上应用，从上往下执行）、可带参数（多一层嵌套）、可作为类实现（`__call__`）。常见用途：日志、计时、缓存（`functools.lru_cache`）、权限检查、注册（路由注册）、重试。

```python
class CountDown:
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self                      # 迭代器返回自身

    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        self.current -= 1
        return self.current + 1

    print(n, end=" ")                    # 5 4 3 2 1
```

### 总结

- 迭代器实现 `__iter__` 和 `__next__`，`for` 循环通过 `iter()`/`next()` 驱动，`StopIteration` 终止
- 生成器用 `yield` 定义，惰性求值，保留执行状态，适合大数据流、无限序列、管道
- 生成器表达式 `(expr for x in iter)` 是列表推导式的惰性版本，省内存
- `yield from` 委托子生成器，简化嵌套；`itertools` 模块提供丰富迭代工具（`islice`/`chain`/`groupby` 等）
- 装饰器 `@decorator` 等价于 `func = decorator(func)`，用 `functools.wraps` 保留元信息
- 装饰器可带参数（多一层嵌套）、可叠加（从下往上应用）、可用类实现（`__call__`）
- 常用装饰器：`lru_cache`（缓存）、`@property`、`@staticmethod`/`@classmethod`、`@dataclass`
- 注意事项：生成器只能迭代一次，需重复使用则用列表或重新创建；装饰器务必用 `wraps` 保留 `__name__`/`__doc__`；`lru_cache` 的参数必须可哈希；装饰器叠加顺序影响结果

3. **阅读源码**：阅读优秀开源项目的代码，学习 Pythonic 的写法和设计模式
4. **持续深入**：本课程是基础，后续可学习异步编程（asyncio）、类型注解、测试（pytest）、Web 框架（Django/Flask）、数据科学（NumPy/Pandas）等方向

Python 的哲学是"简单优于复杂，明确优于晦暗"。保持这份理念，写出优雅、可读、实用的代码。祝你编程愉快！
