# 第一章：C++ 基础入门

## 第 1 讲：C++ 简介与第一个程序

### 概念

C++ 是一种通用的、编译型的、大小写敏感的编程语言，由 Bjarne Stroustrup 于 1979 年在贝尔实验室开发，最初被称为 "C with Classes"（带类的 C）。它是在 C 语言基础上扩展而来，既保留了 C 语言的高效性和底层控制能力，又引入了面向对象编程、泛型编程等现代编程范式。C++ 是一种多范式语言，支持过程式编程、面向对象编程、泛型编程和函数式编程等多种风格，这使得它既能编写贴近硬件的系统级代码，也能构建大型抽象的应用程序。

C++ 广泛应用于系统软件（操作系统、驱动程序）、游戏开发（Unreal Engine）、嵌入式系统、高性能服务器、金融交易系统、浏览器引擎等领域。其设计哲学是"零开销抽象"——你不需要为你没有使用的功能付出代价，而你使用的功能也尽可能高效。

### 原理

C++ 是一种**编译型语言**，源代码需要通过编译器转换为机器码才能执行。完整的 C++ 程序生命周期包含四个阶段：

1. **预处理**：处理以 `#` 开头的预处理指令，如 `#include` 会将头文件内容插入源文件，`#define` 进行宏替换。
2. **编译**：将预处理后的源代码翻译成汇编代码，进行语法和语义检查。
3. **汇编**：将汇编代码转换为目标文件（`.o` 或 `.obj`），包含机器码但地址尚未最终确定。
4. **链接**：将多个目标文件和库文件链接成最终的可执行文件，解析外部符号引用。

C++ 程序的入口点是 `main` 函数，操作系统调用它来启动程序。`main` 函数返回一个 `int` 值，0 通常表示程序成功执行，非零值表示错误。C++ 标准库提供了大量功能，通过包含相应的头文件（如 `<iostream>`）即可使用，这些功能位于 `std` 命名空间中，需要通过 `std::` 前缀或 `using` 声明来访问。

### 例子

下面是 C++ 的经典入门程序 "Hello World"：

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

**代码解析**：
- `#include <iostream>`：预处理指令，引入输入输出流标准库，使我们可以使用 `std::cout` 和 `std::endl`。
- `int main()`：程序入口函数，返回类型为 `int`。
- `std::cout`：标准输出流对象，`<<` 是流插入运算符，将右侧内容输出到左侧的流。
- `std::endl`：插入换行符并刷新输出缓冲区。
- `return 0;`：表示程序正常结束。

**编译与运行**（以 g++ 为例）：

```bash
g++ -std=c++17 -o hello hello.cpp    # 编译
./hello                                # 运行
# 输出：Hello, World!
```

一个稍复杂的例子，展示输入输出：

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    std::cout << "请输入你的名字：";
    std::cin >> name;
    std::cout << "你好，" << name << "！欢迎学习 C++。" << std::endl;
    return 0;
}
```

### 总结

- C++ 是 C 语言的超集，支持多范式编程，兼具高效性与抽象能力。
- 程序从 `main` 函数开始执行，返回 0 表示成功。
- 编译流程：预处理 → 编译 → 汇编 → 链接。
- 标准库功能位于 `std` 命名空间，需通过 `#include` 引入头文件。
- **注意事项**：初学者常犯的错误包括忘记分号、混淆 `>>` 和 `<<`、忘记 `return 0`（虽然现代 C++ 允许省略 main 的 return，但显式写出更清晰）。建议使用支持 C++17 或更高标准的编译器。

## 第 2 讲：基本数据类型与变量

### 概念

数据类型决定了变量在内存中占据的空间大小、能存储的值的范围，以及可以对其进行哪些操作。C++ 提供了丰富的内置数据类型，主要分为四大类：**整型**（表示整数）、**浮点型**（表示实数）、**字符型**（表示字符）和**布尔型**（表示真/假）。此外，C++11 引入了 `nullptr` 表示空指针，以及 `auto` 关键字进行类型推导。

变量是内存中一块有名字的存储区域，程序通过变量名来访问和修改这块内存中的数据。每个变量都有三个基本属性：名称、类型和值。在 C++ 中，变量必须"先声明后使用"，声明时需要指定类型，这使编译器能够为变量分配合适的内存空间并进行类型检查。

### 原理

C++ 的数据类型在内存中占用固定的字节数（具体大小取决于编译器和平台），但标准规定了最小范围。以常见的 64 位系统为例：

| 类型 | 关键字 | 字节数 | 典型范围 |
|------|--------|--------|----------|
| 短整型 | `short` | 2 | -32768 ~ 32767 |
| 整型 | `int` | 4 | -2^31 ~ 2^31-1 |
| 长整型 | `long` | 8 (64位) | -2^63 ~ 2^63-1 |
| 长长整型 | `long long` | 8 | -2^63 ~ 2^63-1 |
| 单精度浮点 | `float` | 4 | 约 6-7 位有效数字 |
| 双精度浮点 | `double` | 8 | 约 15-16 位有效数字 |
| 字符型 | `char` | 1 | -128 ~ 127 或 0 ~ 255 |
| 布尔型 | `bool` | 1 | true / false |

整型可以加上 `signed`（有符号，默认）或 `unsigned`（无符号）修饰符。无符号整型只能表示非负数，但正数范围翻倍。C++11 引入了 `<cstdint>` 头文件，提供 `int32_t`、`uint64_t` 等固定宽度整型，保证跨平台一致性。

变量的存储分为**栈区**（局部变量，自动管理）和**堆区**（动态分配，手动管理）。基本类型变量默认存储在栈上，作用域结束时自动销毁。C++ 是**静态类型语言**，类型在编译期确定，编译器会进行严格的类型检查，不匹配的类型需要显式转换。

### 例子

```cpp
#include <iostream>
#include <cstdint>

int main() {
    // 整型变量
    int age = 25;
    unsigned int score = 95u;        // u 后缀表示 unsigned
    long long bigNum = 9223372036854775807LL;  // LL 后缀

    // 浮点型
    float pi = 3.14f;                // f 后缀表示 float
    double e = 2.718281828459045;

    // 字符型与布尔型
    char grade = 'A';
    bool isPassed = true;

    // C++11: auto 类型推导
    auto count = 100;                // 推导为 int
    auto price = 9.99;               // 推导为 double
    auto initial = 'X';              // 推导为 char

    // C++11: 固定宽度整型
    int32_t fixedInt = 42;
    uint64_t bigUnsigned = 10000000000ULL;

    // const 常量
    const double GRAVITY = 9.8;

    std::cout << "age = " << age << ", size = " << sizeof(age) << " bytes" << std::endl;
    std::cout << "pi = " << pi << ", size = " << sizeof(pi) << " bytes" << std::endl;
    std::cout << "grade = " << grade << ", as int = " << (int)grade << std::endl;
    std::cout << "count type size = " << sizeof(count) << " bytes" << std::endl;

    return 0;
}
```

**输出**：
```
age = 25, size = 4 bytes
pi = 3.14, size = 4 bytes
grade = A, as int = 65
count type size = 4 bytes
```

### 总结

- C++ 内置类型分为整型、浮点型、字符型、布尔型四大类。
- 使用 `sizeof` 运算符可查看类型占用的字节数。
- `auto` 关键字让编译器自动推导类型，提高代码可读性和可维护性。
- `const` 修饰的变量不可修改，用于定义常量，比 `#define` 更安全（有类型检查）。
- **注意事项**：浮点数比较不要直接用 `==`，因为浮点数存在精度误差；整型溢出是未定义行为（有符号）或回绕（无符号），需注意范围；`char` 在 C++ 中既可作字符也可作小整数，注意区分。

## 第 3 讲：运算符与表达式

### 概念

运算符是对数据进行操作的符号，表达式是由运算符和操作数组成的、能计算出结果的式子。C++ 提供了极其丰富的运算符，按功能可分为：**算术运算符**（`+`、`-`、`*`、`/`、`%`）、**关系运算符**（`==`、`!=`、`<`、`>`、`<=`、`>=`）、**逻辑运算符**（`&&`、`||`、`!`）、**位运算符**（`&`、`|`、`^`、`~`、`<<`、`>>`）、**赋值运算符**（`=`、`+=`、`-=` 等）、**条件运算符**（`?:`）以及其他运算符（`sizeof`、`逗号`、`作用域`等）。

每个运算符都有**优先级**和**结合性**。优先级决定了运算的先后顺序（如 `*` 优先于 `+`），结合性决定了同优先级运算符的计算方向（多数为左结合，赋值和单目运算符为右结合）。理解运算符是编写正确表达式的基础，建议在不确定时使用括号明确优先级。

### 原理

C++ 运算符的核心机制包括以下几个方面：

**1. 类型转换**：当不同类型的操作数参与运算时，C++ 会进行隐式类型转换（提升）。规则是"低精度向高精度转换"，例如 `int` 与 `double` 运算时，`int` 会先转换为 `double`。也可以使用 `static_cast<type>(value)` 进行显式转换，这是 C++ 推荐的转换方式，比 C 风格的 `(type)value` 更安全。

**2. 短路求值**：逻辑运算符 `&&` 和 `||` 采用短路求值策略。对于 `&&`，如果左侧为 `false`，则右侧不再计算（结果必为 `false`）；对于 `||`，如果左侧为 `true`，则右侧不再计算（结果必为 `true`）。这一特性常用于避免空指针解引用等安全检查。

**3. 自增自减**：`++i`（前置）先加 1 再使用，`i++`（后置）先使用再加 1。对于基本类型两者效率相同，但对于迭代器等复杂对象，前置版本效率更高（后置需要保存临时副本）。

**4. 位运算**：直接对整数的二进制位进行操作，常用于底层编程、标志位管理、加密算法等场景。左移 `<<` 相当于乘 2 的幂，右移 `>>` 相当于除 2 的幂（对无符号数）。

### 例子

```cpp
#include <iostream>

int main() {
    // 算术运算
    int a = 17, b = 5;
    std::cout << "a / b = " << a / b << std::endl;      // 整数除法，结果 3
    std::cout << "a % b = " << a % b << std::endl;      // 取模，结果 2
    std::cout << "a / (double)b = " << a / (double)b << std::endl;  // 3.4

    // 关系与逻辑运算（短路求值）
    int *p = nullptr;
    if (p != nullptr && *p > 0) {   // p 为空，短路，不会解引用
        std::cout << "positive" << std::endl;
    } else {
        std::cout << "safe check" << std::endl;
    }

    // 自增自减
    int i = 5;
    int j = i++;        // j=5, i=6（后置：先赋值再自增）
    int k = ++i;        // i=7, k=7（前置：先自增再赋值）
    std::cout << "i=" << i << ", j=" << j << ", k=" << k << std::endl;

    // 位运算：权限标志管理
    const int READ = 0b001;     // 1
    const int WRITE = 0b010;    // 2
    const int EXEC = 0b100;     // 4
    int permission = READ | WRITE;          // 组合权限：3
    bool canWrite = (permission & WRITE) != 0;  // 检查是否有写权限
    std::cout << "permission = " << permission << ", canWrite = " << canWrite << std::endl;

    // 条件运算符（三目）
    int max = (a > b) ? a : b;
    std::cout << "max = " << max << std::endl;

    // 显式类型转换
    double d = 3.99;
    int n = static_cast<int>(d);    // 3，截断小数部分
    std::cout << "n = " << n << std::endl;

    return 0;
}
```

**输出**：
```
a / b = 3
a % b = 2
a / (double)b = 3.4
safe check
i=7, j=5, k=7
permission = 3, canWrite = 1
max = 17
n = 3
```

### 总结

- 运算符按功能分为算术、关系、逻辑、位、赋值等类别，优先级决定计算顺序。
- 整数除法会截断小数部分，需要浮点结果时至少一个操作数要是浮点型。
- 逻辑运算符 `&&` 和 `||` 采用短路求值，可用于安全检查。
- 位运算常用于标志位管理，用 `|` 组合权限，用 `&` 检查权限。
- 推荐使用 `static_cast` 进行显式类型转换，比 C 风格转换更安全。
- **注意事项**：不要依赖运算符优先级的复杂记忆，多用括号；避免在表达式中对同一变量多次自增（如 `i = i++`），这是未定义行为。

## 第 4 讲：控制流：条件与循环

### 概念

控制流语句决定了程序中语句的执行顺序，使程序能够根据不同条件执行不同分支，或重复执行某些操作。C++ 的控制流主要分为两类：**条件分支语句**（`if`、`if-else`、`switch`）和**循环语句**（`while`、`do-while`、`for`、范围 `for`）。此外还有 `break`（跳出循环）、`continue`（跳过本次循环）、`goto`（无条件跳转，不推荐使用）等控制转移语句。

条件语句让程序具备"判断"能力，根据运行时的状态选择不同的执行路径。循环语句让程序具备"重复"能力，避免代码冗余，是处理批量数据的核心工具。C++11 引入的范围 `for` 循环（range-based for）简化了容器遍历的写法，使代码更简洁安全。

### 原理

**`if-else` 语句**：条件为真（非零）时执行 `if` 分支，否则执行 `else` 分支。`else` 总是与最近的未配对的 `if` 匹配（悬空 else 问题）。C++17 引入了带初始化的 `if` 语句：`if (auto x = getValue(); x > 0)`，将变量声明与条件判断结合，缩小变量作用域。

**`switch` 语句**：根据整型或枚举表达式的值跳转到匹配的 `case` 标签。`case` 标签必须是编译期常量。如果忘记 `break`，会发生"贯穿"（fall-through），继续执行下一个 case 的代码——这有时是故意的，但多数情况是 bug。`default` 处理所有未匹配的情况。

**`while` 循环**：先判断条件，为真则执行循环体，适合循环次数不确定的场景。**`do-while` 循环**：先执行一次循环体再判断条件，保证至少执行一次。**`for` 循环**：将初始化、条件判断、迭代操作集中在一行，适合循环次数确定的场景。

**范围 `for` 循环**：`for (auto& elem : container)` 遍历容器中每个元素。使用引用 `&` 可以修改原元素，避免拷贝开销。其底层原理是通过 `begin()` 和 `end()` 迭代器实现的。

### 例子

```cpp
#include <iostream>
#include <vector>

int main() {
    // if-else 分支
    int score = 85;
    if (score >= 90) {
        std::cout << "优秀" << std::endl;
    } else if (score >= 80) {
        std::cout << "良好" << std::endl;
    } else if (score >= 60) {
        std::cout << "及格" << std::endl;
    } else {
        std::cout << "不及格" << std::endl;
    }

    // switch 语句
    int day = 3;
    switch (day) {
        case 1: case 2: case 3: case 4: case 5:
            std::cout << "工作日" << std::endl;
            break;
        case 6: case 7:
            std::cout << "周末" << std::endl;
            break;
        default:
            std::cout << "无效日期" << std::endl;
    }

    // for 循环：计算 1~100 的和
    int sum = 0;
    for (int i = 1; i <= 100; ++i) {
        sum += i;
    }
    std::cout << "1+2+...+100 = " << sum << std::endl;  // 5050

    // while 循环：计算数字位数
    int num = 12345, digits = 0;
    int temp = num;
    while (temp > 0) {
        temp /= 10;
        ++digits;
    }
    std::cout << num << " 有 " << digits << " 位" << std::endl;

    // do-while：至少执行一次
    int n = 0;
    do {
        std::cout << "n = " << n << std::endl;
        ++n;
    } while (n < 3);

    // 范围 for 循环遍历容器
    std::vector<int> nums = {10, 20, 30, 40, 50};
    int total = 0;
    for (const auto& x : nums) {    // const 引用避免拷贝
        total += x;
    }
    std::cout << "总和 = " << total << std::endl;

    // break 和 continue
    for (int i = 1; i <= 10; ++i) {
        if (i % 2 == 0) continue;   // 跳过偶数
        if (i > 7) break;           // 超过 7 停止
        std::cout << i << " ";      // 输出：1 3 5 7
    }
    std::cout << std::endl;

    return 0;
}
```

**输出**：
```
良好
工作日
1+2+...+100 = 5050
12345 有 5 位
n = 0
n = 1
n = 2
总和 = 150
1 3 5 7
```

### 总结

- `if-else` 适合区间判断和复杂条件，`switch` 适合离散值的等值匹配。
- `for` 适合已知循环次数，`while` 适合条件驱动循环，`do-while` 保证至少执行一次。
- 范围 `for` 循环简化容器遍历，推荐使用 `const auto&` 避免拷贝。
- `break` 跳出整个循环，`continue` 跳过本次循环剩余部分。
- **注意事项**：`switch` 的每个 `case` 记得加 `break`（除非故意贯穿）；避免死循环（确保循环条件最终会变为假）；浮点数不要直接用作循环变量（精度问题可能导致无限循环）；不推荐使用 `goto`，它破坏结构化编程。

# 第二章：函数与核心数据结构

## 第 5 讲：函数基础

### 概念

函数是完成特定任务的、可复用的代码块，是 C++ 程序模块化的基本单位。一个函数由**返回类型**、**函数名**、**参数列表**和**函数体**四部分组成。通过函数，我们可以将复杂问题分解为若干小任务，提高代码的可读性、可维护性和复用性。C++ 程序至少包含一个 `main` 函数，程序从 `main` 开始执行，可以在其中调用其他函数。

函数的使用分为**声明**（原型）和**定义**两部分。声明告诉编译器函数的签名（返回类型、名称、参数类型），使编译器能在定义之前识别该函数；定义则提供函数的具体实现。参数传递方式有三种：**值传递**（拷贝实参的值）、**引用传递**（传递实参的别名，可修改原变量）、**指针传递**（传递地址）。此外，C++ 支持**默认参数**、**内联函数**和**函数重载**等特性。

### 原理

**函数调用机制**：当函数被调用时，系统会在调用栈上为该函数分配一个**栈帧**，存储局部变量、参数和返回地址。参数按照声明的顺序被压入栈中（或通过寄存器传递），然后程序跳转到函数体执行。函数执行完毕后，返回值被传递给调用者，栈帧被销毁，程序返回到调用点继续执行。这一过程有开销，对于频繁调用的小函数，可使用 `inline` 关键字建议编译器将函数体直接展开到调用处，消除调用开销。

**值传递 vs 引用传递**：值传递会创建实参的副本，函数内对参数的修改不影响原变量，适合小型数据或不需要修改的场景。引用传递直接操作原变量，避免拷贝开销，适合大型对象或需要修改实参的场景。常量引用 `const T&` 兼顾了安全和效率——既避免拷贝，又防止意外修改。

**默认参数**：在函数声明中为参数指定默认值，调用时若不提供该参数则使用默认值。默认参数必须从右向左连续定义，即有默认值的参数右边不能有没有默认值的参数。

**函数重载**：C++ 允许同一作用域内定义多个同名函数，只要它们的参数列表不同（参数个数或类型不同）。编译器根据调用时实参的类型和数量选择最匹配的版本，这一过程称为**重载决议**。返回类型不参与重载决议。

### 例子

```cpp
#include <iostream>
#include <string>
#include <vector>

// 1. 值传递：交换副本，不影响原变量
void swapByValue(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

// 2. 引用传递：真正交换原变量
void swapByRef(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

// 3. 默认参数
void printInfo(std::string name, int age = 18, std::string city = "北京") {
    std::cout << "姓名：" << name << "，年龄：" << age << "，城市：" << city << std::endl;
}

// 4. 函数重载
int add(int a, int b) {
    return a + b;
}
double add(double a, double b) {
    return a + b;
}
std::string add(const std::string& a, const std::string& b) {
    return a + b;
}

// 5. const 引用传递大型对象，避免拷贝
void printVector(const std::vector<int>& vec) {
    for (const auto& x : vec) {
        std::cout << x << " ";
    }
    std::cout << std::endl;
}

// 6. 内联函数
inline int square(int x) {
    return x * x;
}

int main() {
    int x = 10, y = 20;
    swapByValue(x, y);
    std::cout << "值传递后：x=" << x << ", y=" << y << std::endl;  // 不变

    swapByRef(x, y);
    std::cout << "引用传递后：x=" << x << ", y=" << y << std::endl;  // 交换

    printInfo("张三");                          // 使用所有默认参数
    printInfo("李四", 25);                      // 部分使用默认
    printInfo("王五", 30, "上海");              // 不使用默认

    std::cout << "int add: " << add(3, 5) << std::endl;
    std::cout << "double add: " << add(3.5, 2.5) << std::endl;
    std::cout << "string add: " << add("Hello, ", "World!") << std::endl;

    std::vector<int> v = {1, 2, 3, 4, 5};
    printVector(v);

    std::cout << "square(7) = " << square(7) << std::endl;

    return 0;
}
```

**输出**：
```
值传递后：x=10, y=20
引用传递后：x=20, y=10
姓名：张三，年龄：18，城市：北京
姓名：李四，年龄：25，城市：北京
姓名：王五，年龄：30，城市：上海
int add: 8
double add: 6
string add: Hello, World!
1 2 3 4 5
square(7) = 49
```

### 总结

- 函数由返回类型、函数名、参数列表和函数体组成，是模块化的基本单位。
- 值传递拷贝实参，引用传递直接操作原变量，`const` 引用兼顾安全与效率。
- 默认参数必须从右向左连续定义，调用时从左到右匹配。
- 函数重载通过参数列表区分，编译器自动选择最匹配版本。
- `inline` 适合频繁调用的小函数，建议编译器展开代码。
- **注意事项**：避免过多使用默认参数导致调用歧义；重载函数的参数差异要明显；不要返回局部变量的引用或指针（悬空引用）；递归函数要注意终止条件和栈溢出风险。

## 第 6 讲：数组与字符串

### 概念

数组是相同类型元素的有序集合，在内存中连续存储，通过下标（索引）访问元素，下标从 0 开始。C++ 中的数组分为 **C 风格数组**（继承自 C 语言，如 `int arr[10]`）和 **STL 容器**（如 `std::vector`、`std::array`）。C 风格数组大小固定，效率高但不够安全；`std::vector` 是动态数组，大小可变，是现代 C++ 中最常用的数组容器；`std::array` 是 C++11 引入的固定大小数组，封装了 C 数组并提供了更安全的接口。

字符串是字符的序列。C++ 提供两种字符串：**C 风格字符串**（以 `\0` 结尾的 `char` 数组，如 `"hello"`）和 **`std::string`** 类（C++ 标准库提供的字符串类）。`std::string` 自动管理内存，提供丰富的成员函数，是处理字符串的首选。C++11 还引入了原始字符串字面量 `R"(...)"` 和 `std::string_view`（C++17）用于高效地只读引用字符串。

### 原理

**数组内存布局**：数组元素在内存中连续存放，数组名实际上是首元素的地址（在大多数表达式中会退化为指针）。因此，可以通过指针算术访问数组元素：`arr[i]` 等价于 `*(arr + i)`。这种连续存储使得数组具有极高的随机访问效率——O(1) 时间复杂度，但插入和删除中间元素需要移动后续元素，时间复杂度为 O(n)。

**C 风格数组的问题**：数组大小信息在传递给函数时会丢失（退化为指针），导致函数内无法获知数组长度，容易越界访问。`std::array` 和 `std::vector` 保留了大小信息，并提供 `at()` 方法进行边界检查（越界抛出异常），更安全。

**`std::vector` 的动态扩容机制**：`vector` 内部维护一块连续内存，当元素数量超过当前容量时，会分配一块更大的内存（通常是原来的 2 倍），将旧元素拷贝/移动到新内存，再释放旧内存。这一过程的时间复杂度为 O(n)，但由于扩容是按倍数进行的，均摊到每次 `push_back` 的成本是 O(1)。可以使用 `reserve()` 预先分配容量，避免多次扩容。

**`std::string` 的实现**：现代 `std::string` 通常采用**小字符串优化（SSO）**：对于较短的字符串（通常 15-22 字节），直接存储在对象内部，不分配堆内存，提高效率；长字符串则在堆上分配。`string` 支持拼接（`+`、`append`）、查找（`find`）、子串（`substr`）、比较等操作。

### 例子

```cpp
#include <iostream>
#include <array>
#include <vector>
#include <string>
#include <string_view>

int main() {
    // 1. C 风格数组
    int cArr[5] = {10, 20, 30, 40, 50};
    std::cout << "C 数组第三个元素：" << cArr[2] << std::endl;  // 30

    // 2. std::array（固定大小，更安全）
    std::array<int, 5> arr = {1, 2, 3, 4, 5};
    std::cout << "array 大小：" << arr.size() << std::endl;
    std::cout << "array 第一个：" << arr.front() << "，最后一个：" << arr.back() << std::endl;
    // arr.at(10);  // 越界，抛出 std::out_of_range 异常

    // 3. std::vector（动态数组）
    std::vector<int> vec;
    vec.reserve(5);             // 预分配容量，避免多次扩容
    for (int i = 1; i <= 5; ++i) {
        vec.push_back(i * 10);
    }
    std::cout << "vector: ";
    for (const auto& x : vec) {
        std::cout << x << " ";
    }
    std::cout << "(大小=" << vec.size() << ", 容量=" << vec.capacity() << ")" << std::endl;

    vec.pop_back();             // 删除末尾元素
    vec.insert(vec.begin(), 0); // 在头部插入
    std::cout << "修改后 vector: ";
    for (const auto& x : vec) std::cout << x << " ";
    std::cout << std::endl;

    // 4. 二维数组
    std::vector<std::vector<int>> matrix = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };
    std::cout << "矩阵 [1][2] = " << matrix[1][2] << std::endl;  // 6

    // 5. std::string 字符串操作
    std::string s1 = "Hello";
    std::string s2 = " World";
    std::string s3 = s1 + s2;                   // 拼接
    std::cout << s3 << " (长度=" << s3.length() << ")" << std::endl;

    size_t pos = s3.find("World");              // 查找
    if (pos != std::string::npos) {
        std::cout << "找到 World，位置：" << pos << std::endl;
    }

    std::string sub = s3.substr(0, 5);          // 子串
    std::cout << "子串：" << sub << std::endl;

    // 6. string_view（C++17，轻量只读引用）
    std::string_view sv = "Hello C++17";
    std::cout << "string_view: " << sv.substr(0, 5) << std::endl;

    return 0;
}
```

**输出**：
```
C 数组第三个元素：30
array 大小：5
array 第一个：1，最后一个：5
vector: 10 20 30 40 50 (大小=5, 容量=5)
修改后 vector: 0 10 20 30 40
矩阵 [1][2] = 6
Hello World (长度=11)
找到 World，位置：6
子串：Hello
string_view: Hello
```

### 总结

- 优先使用 `std::vector`（动态）和 `std::array`（固定），避免裸用 C 风格数组。
- `vector` 的 `push_back` 均摊 O(1)，`reserve()` 可预分配容量提升性能。
- `std::string` 自动管理内存，提供丰富的字符串操作，优于 C 风格字符串。
- `std::string_view`（C++17）是轻量只读字符串引用，避免不必要的拷贝。
- **注意事项**：数组下标从 0 开始，越界访问是未定义行为；C 数组作为函数参数会退化为指针，丢失大小信息；`vector` 在头部插入/删除是 O(n)，频繁此操作考虑用 `std::deque`；`string::find` 找不到时返回 `std::string::npos`，不要与 0 混淆。

## 第 7 讲：指针深入理解

### 概念

指针是 C/C++ 中最强大也最容易出错的特性之一。**指针是一个变量，其值为另一个变量的内存地址**。通过指针，我们可以间接访问和修改内存中的数据，实现动态内存分配、高效传参、数据结构构建（链表、树）等底层操作。指针的类型告诉编译器如何解释所指向的内存——`int*` 指向整数，`double*` 指向双精度浮点数，`char*` 指向字符。

与指针相关的两个核心运算符是：`&`（取地址运算符，获取变量的地址）和 `*`（解引用运算符，访问指针指向的值）。指针本身也有大小，在 64 位系统上通常是 8 字节，无论它指向什么类型。C++11 引入了 `nullptr` 关键字表示空指针，取代了旧的 `NULL`（`NULL` 在 C++ 中被定义为 0，可能引起重载歧义）。空指针不能解引用，否则会导致程序崩溃。

### 原理

**指针与内存模型**：计算机内存可以看作一个巨大的字节数组，每个字节有唯一的地址。变量存储在内存的某个位置，指针存储的就是这个位置的起始地址。指针的类型决定了访问多少字节以及如何解释这些字节——`int*` 访问 4 字节并按整数解释，`char*` 访问 1 字节按字符解释。指针算术（如 `p+1`）会根据类型大小跳转：`int* p; p+1` 实际地址增加 `sizeof(int)` 即 4 字节。

**指针的危险性**：C++ 不对指针进行边界检查和空指针检查，以下错误都是未定义行为（UB），可能导致程序崩溃或数据损坏：
- **野指针**：未初始化的指针，指向随机地址。
- **悬空指针**：指向已释放内存的指针（如函数返回局部变量地址）。
- **内存泄漏**：`new` 分配的内存忘记 `delete`。
- **重复释放**：同一块内存 `delete` 两次。

**指针的应用场景**：
1. **动态内存分配**：`new`/`delete` 在堆上分配/释放内存。
2. **函数参数**：通过指针让函数修改调用者的变量（也可用引用）。
3. **数据结构**：链表节点通过指针连接，树通过指针指向子节点。
4. **多态**：通过基类指针调用派生类方法（第 12 讲详解）。
5. **函数指针**：将函数作为参数传递，实现回调机制。

**`const` 与指针**：`const int* p`（指向常量的指针，不能通过 p 修改值）、`int* const p`（常量指针，p 本身不能改指向）、`const int* const p`（两者都常）。记忆口诀：`const` 在 `*` 左边修饰指向的值，在右边修饰指针本身。

### 例子

```cpp
#include <iostream>

int main() {
    // 1. 基本指针操作
    int value = 42;
    int* ptr = &value;          // 取地址
    std::cout << "value = " << value << std::endl;
    std::cout << "&value = " << &value << std::endl;
    std::cout << "ptr = " << ptr << std::endl;
    std::cout << "*ptr = " << *ptr << std::endl;   // 解引用

    *ptr = 100;                 // 通过指针修改原变量
    std::cout << "修改后 value = " << value << std::endl;  // 100

    // 2. 空指针
    int* nullPtr = nullptr;
    if (nullPtr == nullptr) {
        std::cout << "指针为空，不能解引用" << std::endl;
    }

    // 3. 指针与数组
    int arr[] = {10, 20, 30, 40, 50};
    int* pArr = arr;            // 数组名退化为首元素地址
    std::cout << "arr[2] = " << *(pArr + 2) << std::endl;  // 30，指针算术
    std::cout << "pArr[2] = " << pArr[2] << std::endl;     // 30，等价写法

    // 4. 动态内存分配
    int* dynamic = new int(25);         // 在堆上分配一个 int
    std::cout << "*dynamic = " << *dynamic << std::endl;
    delete dynamic;                     // 释放内存
    dynamic = nullptr;                  // 好习惯：置空避免悬空指针

    // 动态数组
    int* dynArr = new int[5]{1, 2, 3, 4, 5};
    for (int i = 0; i < 5; ++i) {
        std::cout << dynArr[i] << " ";
    }
    std::cout << std::endl;
    delete[] dynArr;                    // 数组用 delete[]
    dynArr = nullptr;

    // 5. const 与指针
    int x = 10, y = 20;
    const int* p1 = &x;         // 指向常量的指针：不能 *p1 = ...
    int* const p2 = &x;         // 常量指针：不能 p2 = &y
    const int* const p3 = &x;   // 两者都常

    // *p1 = 15;    // 错误：不能通过 const int* 修改
    p1 = &y;        // 正确：可以改变 p1 的指向
    *p2 = 15;       // 正确：可以修改指向的值
    // p2 = &y;     // 错误：int* const 不能改变指向

    std::cout << "x = " << x << ", *p1 = " << *p1 << std::endl;

    return 0;
}
```

**输出**：
```
value = 42
&value = 0x7ffd...
ptr = 0x7ffd...
*ptr = 42
修改后 value = 100
指针为空，不能解引用
arr[2] = 30
pArr[2] = 30
*dynamic = 25
1 2 3 4 5
x = 15, *p1 = 20
```

### 总结

- 指针存储变量的内存地址，通过 `&` 取地址、`*` 解引用。
- 使用 `nullptr` 表示空指针，取代旧的 `NULL`。
- `new`/`delete` 管理堆内存，数组用 `new[]`/`delete[]`，必须配对使用。
- `const` 与指针组合有三种形式，注意 `const` 相对 `*` 的位置。
- **注意事项**：指针必须初始化，避免野指针；释放内存后立即置空，避免悬空指针；不要返回局部变量的地址；现代 C++ 推荐使用智能指针（第 17 讲）替代裸指针，自动管理内存生命周期。

## 第 8 讲：引用与结构体

### 概念

**引用**是已存在变量的别名，声明引用时必须初始化，且初始化后不能再绑定到其他变量。引用的本质是通过指针实现的，但使用上更简洁安全。引用分为三种：**左值引用**（`T&`，绑定到可修改的变量）、**常量引用**（`const T&`，绑定到常量或临时值，不可修改）、**右值引用**（`T&&`，C++11 引入，绑定到临时值，用于移动语义，第 18 讲详解）。引用最常用于函数参数传递，避免拷贝开销同时保证安全。

**结构体**（`struct`）是用户自定义的复合数据类型，将多个不同类型的变量组合成一个整体。结构体中的每个变量称为**成员**。C++ 的 `struct` 与 `class` 几乎相同，唯一区别是 `struct` 默认成员为 `public`，`class` 默认为 `private`。结构体常用于表示现实世界中的实体，如学生（姓名、年龄、成绩）、点（x, y 坐标）、日期（年、月、日）等。C++11 引入了结构体初始化列表和 `constexpr` 构造，使结构体更灵活。

### 原理

**引用的实现原理**：引用在底层通常被实现为常量指针。声明 `int& ref = value;` 类似于 `int* const ptr = &value;`，每次使用 `ref` 编译器自动解引用。因此引用和指针在效率上基本相同，但引用更安全——它必须初始化、不能为空、不能重新绑定，避免了空指针解引用和悬空指针等问题。引用作为函数参数时，实参的地址被传递，函数内对引用的修改直接影响原变量。

**常量引用的特殊能力**：`const T&` 可以绑定到右值（临时值），这是 C++ 的一个特殊规则。例如 `const std::string& s = "hello"` 是合法的，编译器会创建一个临时 `string` 对象并延长其生命周期至引用的作用域结束。这一特性使常量引用成为接收字符串、容器等大型对象参数的首选方式——既避免拷贝，又能接受字面量等临时值。

**结构体内存布局**：结构体成员按声明顺序在内存中排列，但为了访问效率，编译器会进行**内存对齐**——在成员之间插入填充字节，使每个成员的地址是其大小的整数倍。例如 `struct {char c; int i;}` 在 64 位系统上占 8 字节（c 占 1 字节，填充 3 字节，i 占 4 字节）。可以使用 `#pragma pack` 或 `alignas` 控制对齐方式。结构体的大小可用 `sizeof` 查看。

**结构体与函数**：结构体可以按值传递（拷贝整个结构体）、按引用传递（推荐，避免拷贝）、按指针传递。C++ 允许结构体拥有成员函数、构造函数等（与 class 相同），使结构体不仅能存储数据，还能封装操作。

### 例子

```cpp
#include <iostream>
#include <string>
#include <vector>

// 定义结构体：学生
struct Student {
    std::string name;
    int age;
    double score;

    // 成员函数
    void print() const {
        std::cout << "姓名：" << name
                  << "，年龄：" << age
                  << "，成绩：" << score << std::endl;
    }
};

// 定义结构体：点
struct Point {
    double x, y;
};

// 引用作为函数参数：修改原变量
void increment(int& n) {
    ++n;
}

// const 引用：避免拷贝，不修改
void printStudent(const Student& s) {
    s.print();    // 调用 const 成员函数
}

// 通过引用返回结构体成员，可修改
double& getScore(Student& s) {
    return s.score;
}

// 结构体作为返回值
Point makePoint(double x, double y) {
    return {x, y};    // C++11 初始化列表
}

int main() {
    // 1. 引用基础
    int value = 10;
    int& ref = value;       // ref 是 value 的别名
    ref = 20;
    std::cout << "value = " << value << std::endl;  // 20

    increment(value);
    std::cout << "increment 后 value = " << value << std::endl;  // 21

    // 2. const 引用绑定临时值
    const int& cref = 100;  // 合法，延长临时值生命周期
    std::cout << "cref = " << cref << std::endl;

    // 3. 结构体使用
    Student s1 = {"张三", 20, 85.5};    // C++11 初始化列表
    s1.print();

    Student s2{.name = "李四", .age = 22, .score = 92.0};  // C++20 指定初始化
    printStudent(s2);

    // 通过引用返回修改成员
    getScore(s1) = 90.0;
    std::cout << "修改后 s1 成绩：" << s1.score << std::endl;

    // 4. 结构体数组与 vector
    std::vector<Student> students = {
        {"张三", 20, 85.5},
        {"李四", 22, 92.0},
        {"王五", 21, 78.0}
    };
    for (const auto& stu : students) {   // const 引用遍历
        stu.print();
    }

    // 5. 结构体内存大小（注意对齐）
    std::cout << "Student 大小：" << sizeof(Student) << " 字节" << std::endl;
    std::cout << "Point 大小：" << sizeof(Point) << " 字节" << std::endl;

    // 6. 函数返回结构体
    Point p = makePoint(3.0, 4.0);
    std::cout << "Point: (" << p.x << ", " << p.y << ")" << std::endl;

    return 0;
}
```

**输出**：
```
value = 20
increment 后 value = 21
cref = 100
姓名：张三，年龄：20，成绩：85.5
姓名：李四，年龄：22，成绩：92
修改后 s1 成绩：90
姓名：张三，年龄：20，成绩：85.5
姓名：李四，年龄：22，成绩：92
姓名：王五，年龄：21，成绩：78
Student 大小：56 字节
Point 大小：16 字节
Point: (3, 4)
```

### 总结

- 引用是变量的别名，必须初始化且不可重新绑定，比指针更安全。
- 函数参数推荐使用 `const T&`，兼顾效率（避免拷贝）和安全（不可修改）。
- `const` 引用可以绑定到临时值（右值），这是 C++ 的特殊规则。
- 结构体将多个相关变量组合成一个整体，C++ 的 `struct` 可包含成员函数。
- 结构体存在内存对齐，可用 `sizeof` 查看实际大小。
- **注意事项**：不要返回局部变量的引用；引用必须初始化；结构体作为参数优先用引用避免拷贝；注意内存对齐对结构体大小的影响，紧凑排列可节省空间。

# 第三章：面向对象编程

## 第 9 讲：类与对象

### 概念

**类**是面向对象编程（OOP）的核心概念，是一种用户自定义的数据类型，将数据（成员变量）和操作数据的行为（成员函数）封装在一起。**对象**是类的实例，就像变量是数据类型的实例一样。类是蓝图/模板，对象是根据蓝图创建的具体实体。例如，"汽车"是一个类，而"我的那辆红色丰田"是一个对象。

C++ 中类通过 `class` 关键字定义，支持三种**访问修饰符**：`public`（公有，外部可访问）、`private`（私有，仅类内部可访问）、`protected`（受保护，类内部和派生类可访问）。封装是 OOP 的第一支柱——通过将数据设为 `private`，只通过 `public` 的成员函数（称为**接口**）访问和修改数据，可以保证数据的完整性和一致性，防止外部代码随意修改内部状态。这种"数据隐藏"机制是良好设计的基础。

### 原理

**类的内存模型**：一个类定义本身不占用内存，它只是一个模板。当创建对象时，系统根据类定义为对象分配内存，存储其成员变量。成员函数并不在每个对象中存储副本——所有对象共享同一份成员函数代码，编译器通过隐式传递 `this` 指针让函数知道操作的是哪个对象。`this` 指针指向当前对象，在成员函数内可以使用 `this->成员` 访问当前对象的成员。空类（无任何成员）的对象大小通常为 1 字节，用于区分不同对象的地址。

**访问控制原理**：访问修饰符是编译期的概念，编译器在编译时检查访问权限，运行时没有开销。`private` 成员只能被本类的成员函数和友元访问；`public` 成员可以被任何代码访问；`protected` 成员可以被本类和派生类访问。良好的封装原则是：数据成员设为 `private`，通过 `public` 的 getter/setter 函数控制访问，在 setter 中加入数据有效性检查。

**内联成员函数**：在类定义内部直接实现的成员函数默认是 `inline` 的，编译器可能将其代码直接展开到调用处，消除函数调用开销。在类外部定义的成员函数需要用 `类名::函数名` 限定，若希望内联需显式加 `inline` 关键字。短小的成员函数建议在类内定义（内联），复杂的逻辑在类外定义。

**const 成员函数**：在成员函数参数列表后加 `const` 关键字，表示该函数不会修改对象的状态（不修改成员变量）。`const` 对象只能调用 `const` 成员函数。这是"逻辑常量性"的体现——函数从逻辑上不改变对象，即使内部可能修改 `mutable` 成员。

### 例子

```cpp
#include <iostream>
#include <string>

class BankAccount {
private:
    std::string owner;      // 账户持有人
    double balance;         // 余额

public:
    // 构造函数（下讲详解）
    BankAccount(const std::string& name, double initialBalance)
        : owner(name), balance(initialBalance) {
        if (balance < 0) {
            balance = 0;
            std::cout << "初始余额不能为负，已设为 0" << std::endl;
        }
    }

    // 存款
    void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
            std::cout << owner << " 存入 " << amount
                      << "，余额：" << balance << std::endl;
        }
    }

    // 取款
    bool withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
            std::cout << owner << " 取出 " << amount
                      << "，余额：" << balance << std::endl;
            return true;
        }
        std::cout << "取款失败：余额不足" << std::endl;
        return false;
    }

    // const 成员函数：获取余额（不修改对象）
    double getBalance() const {
        return balance;
    }

    const std::string& getOwner() const {
        return owner;       // 返回 const 引用，避免拷贝
    }

    // 类外定义的成员函数
    void display() const;
};

// 在类外部定义成员函数
void BankAccount::display() const {
    std::cout << "账户[" << owner << "] 余额：" << balance << " 元" << std::endl;
}

int main() {
    // 创建对象
    BankAccount acc1("张三", 1000);
    BankAccount acc2("李四", 500);

    // 通过 public 接口操作
    acc1.deposit(500);          // 存入 500
    acc1.withdraw(200);         // 取出 200
    acc1.withdraw(5000);        // 失败：余额不足

    acc2.deposit(100);
    acc2.withdraw(300);

    // 使用 const 成员函数
    std::cout << acc1.getOwner() << " 当前余额：" << acc1.getBalance() << std::endl;

    // const 对象只能调用 const 成员函数
    const BankAccount& ref = acc1;
    std::cout << "通过 const 引用查询余额：" << ref.getBalance() << std::endl;
    // ref.deposit(100);  // 错误：const 对象不能调用非 const 成员函数

    acc1.display();
    acc2.display();

    return 0;
}
```

**输出**：
```
张三 存入 500，余额：1500
张三 取出 200，余额：1300
取款失败：余额不足
李四 存入 100，余额：600
李四 取出 300，余额：300
张三 当前余额：1300
通过 const 引用查询余额：1300
账户[张三] 余额：1300 元
账户[李四] 余额：300 元
```

### 总结

- 类是数据与行为的封装，对象是类的实例，成员函数通过 `this` 指针操作当前对象。
- 三种访问修饰符：`public`（对外接口）、`private`（内部数据）、`protected`（继承时使用）。
- 封装原则：数据设为 `private`，通过 `public` 函数控制访问，保证数据安全。
- `const` 成员函数不修改对象状态，`const` 对象只能调用 `const` 成员函数。
- **注意事项**：类定义末尾必须有分号；成员函数在类内定义默认内联，类外定义需 `类名::` 限定；不要在构造函数中调用虚函数（此时对象尚未完全构造）；优先使用初始化列表初始化成员（下讲详解）。

## 第 10 讲：构造函数、析构函数与拷贝控制

### 概念

**构造函数**是一种特殊的成员函数，在对象创建时自动调用，用于初始化对象的状态。构造函数与类同名，没有返回类型，可以重载（多个参数不同的构造函数）。C++ 提供多种构造函数：**默认构造函数**（无参数）、**带参构造函数**、**拷贝构造函数**（用同类型对象初始化）、**移动构造函数**（C++11，窃取资源）。

**析构函数**是另一种特殊成员函数，在对象销毁时自动调用，用于释放资源（如动态内存、文件句柄、网络连接）。析构函数名为 `~类名`，无参数无返回值，不可重载。每个类只能有一个析构函数。如果类管理了动态资源，必须自定义析构函数；否则编译器生成的默认析构函数就足够了。

**拷贝控制**由三个函数组成（C++11 后为五个，加上移动语义）：**拷贝构造函数**（`T(const T&)`）、**拷贝赋值运算符**（`T& operator=(const T&)`）、**析构函数**。它们决定了对象被拷贝、赋值和销毁时的行为。遵循**三/五法则**：如果你需要自定义其中任何一个，通常也需要自定义其他几个。

### 原理

**构造函数的初始化顺序**：成员变量的初始化顺序由它们在类中**声明**的顺序决定，而非初始化列表中的顺序（这是常见陷阱）。初始化列表 `: member(value)` 比在构造函数体内赋值更高效——前者直接构造成员，后者先默认构造再赋值。对于 `const` 成员、引用成员和没有默认构造函数的类类型成员，必须使用初始化列表。

**拷贝构造函数的触发时机**：
1. 用一个对象初始化另一个对象：`T b(a);` 或 `T b = a;`（注意这是拷贝构造，不是赋值）。
2. 函数按值传递对象参数。
3. 函数按值返回对象（现代编译器通常通过 RVO 优化掉）。

**深拷贝 vs 浅拷贝**：编译器默认生成的拷贝构造函数执行**浅拷贝**——逐成员拷贝。如果类中有指针成员指向动态内存，浅拷贝会导致两个对象指向同一块内存，析构时重复释放（double free），造成崩溃。此时必须自定义拷贝构造函数实现**深拷贝**——为新对象分配独立内存并复制内容。

**拷贝赋值运算符**：处理 `a = b`（a 已存在）的情况。需要处理自我赋值（`a = a`）、释放旧资源、分配新资源、复制内容。经典模式是"拷贝并交换"（copy-and-swap）。

**析构函数调用时机**：局部对象在离开作用域时销毁；`new` 创建的对象在 `delete` 时销毁；全局/静态对象在程序结束时销毁；容器中的对象在容器销毁时销毁。析构顺序与构造顺序相反（栈的后进先出特性）。

### 例子

```cpp
#include <iostream>
#include <cstring>

class String {
private:
    char* data;
    size_t length;

public:
    // 1. 普通构造函数
    String(const char* str = "") {
        length = std::strlen(str);
        data = new char[length + 1];        // +1 存 '\0'
        std::strcpy(data, str);
        std::cout << "构造: \"" << data << "\"" << std::endl;
    }

    // 2. 拷贝构造函数（深拷贝）
    String(const String& other) {
        length = other.length;
        data = new char[length + 1];
        std::strcpy(data, other.data);
        std::cout << "拷贝构造: \"" << data << "\"" << std::endl;
    }

    // 3. 拷贝赋值运算符（copy-and-swap 惯用法）
    String& operator=(String other) {   // 注意：参数按值传递（触发拷贝构造）
        swap(other);                     // 交换资源
        std::cout << "拷贝赋值: \"" << data << "\"" << std::endl;
        return *this;
    }

    // 4. 析构函数
    ~String() {
        std::cout << "析构: \"" << (data ? data : "") << "\"" << std::endl;
        delete[] data;
    }

    // 辅助函数：交换
    void swap(String& other) noexcept {
        std::swap(data, other.data);
        std::swap(length, other.length);
    }

    // const 成员函数
    const char* c_str() const { return data; }
    size_t size() const { return length; }
};

// 函数按值传递和返回（触发拷贝构造）
String makeGreeting(const String& name) {
    String greeting = "Hello, ";
    // 实际应用中会用 += 拼接，这里简化
    return greeting;
}

int main() {
    std::cout << "=== 创建 s1 ===" << std::endl;
    String s1("Hello");

    std::cout << "\n=== 拷贝构造 s2 ===" << std::endl;
    String s2 = s1;            // 拷贝构造

    std::cout << "\n=== 创建 s3 后赋值 ===" << std::endl;
    String s3("World");
    s3 = s1;                   // 拷贝赋值

    std::cout << "\n=== 自我赋值 ===" << std::endl;
    s1 = s1;                   // 自我赋值，copy-and-swap 安全处理

    std::cout << "\n=== 函数调用 ===" << std::endl;
    String g = makeGreeting(s1);

    std::cout << "\n=== 离开 main，析构顺序与构造相反 ===" << std::endl;
    return 0;
}
```

**输出**（简化）：
```
=== 创建 s1 ===
构造: "Hello"

=== 拷贝构造 s2 ===
拷贝构造: "Hello"

=== 创建 s3 后赋值 ===
构造: "World"
拷贝构造: "Hello"
拷贝赋值: "Hello"
析构: "World"

=== 自我赋值 ===
拷贝构造: "Hello"
拷贝赋值: "Hello"
析构: "Hello"

=== 函数调用 ===
构造: "Hello, "
拷贝构造: "Hello, "

=== 离开 main，析构顺序与构造相反 ===
析构: "Hello, "
析构: "Hello"
析构: "Hello"
析构: "Hello"
```

### 总结

- 构造函数初始化对象，析构函数释放资源，二者自动调用。
- 拷贝构造函数在对象初始化、值传递、值返回时触发。
- 管理动态资源的类必须实现深拷贝，避免浅拷贝导致的重复释放。
- 遵循三/五法则：自定义析构、拷贝构造、拷贝赋值（加上移动构造和移动赋值共五个）。
- **注意事项**：成员初始化顺序由声明顺序决定，与初始化列表顺序无关；拷贝赋值要处理自我赋值；析构顺序与构造顺序相反；现代 C++ 推荐遵循"规则零"——使用智能指针和 STL 容器管理资源，让编译器生成的默认拷贝控制就足够。

## 第 11 讲：继承体系

### 概念

**继承**是面向对象编程的第二大支柱，允许创建一个新类（**派生类**/子类）从已有类（**基类**/父类）继承成员变量和成员函数，实现代码复用和层次化设计。继承表达了"是一个"（is-a）的关系——例如"学生是一个人"，"汽车是一种交通工具"。通过继承，派生类无需重复编写基类的代码，只需添加或修改特有部分。

C++ 支持三种继承方式：`public`（最常用，基类的 `public` 成员在派生类中仍为 `public`）、`protected`（基类的 `public` 和 `protected` 成员在派生类中都变为 `protected`）、`private`（默认方式，基类所有成员在派生类中变为 `private`）。C++ 还支持**多重继承**——一个派生类可以同时继承多个基类，但需要小心处理名称冲突和菱形继承问题。

### 原理

**继承的内存布局**：派生类对象在内存中包含一个完整的基类子对象和派生类新增的成员。即派生类对象 = 基类部分 + 派生类部分。当用基类指针指向派生类对象时，指针实际上指向基类子对象的起始位置，因此只能访问基类部分（除非使用虚函数实现多态）。

**成员访问规则**：
- 基类的 `private` 成员虽然被继承，但派生类无法直接访问（可通过基类的 `public`/`protected` 函数间接访问）。
- 基类的 `protected` 成员可以被派生类直接访问，但不能被外部代码访问——这是专为继承设计的访问级别。
- `public` 继承保持基类成员的访问属性不变。

**构造与析构顺序**：
- 构造：先构造基类部分，再构造派生类部分（先父后子）。
- 析构：先析构派生类部分，再析构基类部分（先子后父）。
- 派生类构造函数通过初始化列表调用基类构造函数，传递所需参数。

**名称遮蔽**：如果派生类定义了与基类同名的成员（函数或变量），基类的同名成员会被"遮蔽"（隐藏），默认情况下派生类对象调用的是自己的版本。可以使用 `using 基类::函数名` 将基类版本引入派生类作用域，或通过 `对象.基类::函数名()` 显式调用。函数重载在继承中不会自动继承——派生类同名函数会隐藏基类所有同名重载版本。

**多重继承与菱形继承**：当 D 同时继承 B 和 C，而 B 和 C 都继承 A 时，形成"菱形"。D 中会有两份 A 的成员，造成二义性和内存浪费。解决方案是**虚继承**（`virtual` 继承），使共享的基类只有一份拷贝。

### 例子

```cpp
#include <iostream>
#include <string>

// 基类：人
class Person {
protected:
    std::string name;
    int age;

public:
    Person(const std::string& n, int a) : name(n), age(a) {
        std::cout << "Person 构造" << std::endl;
    }

    virtual ~Person() {
        std::cout << "Person 析构" << std::endl;
    }

    void introduce() const {
        std::cout << "我是 " << name << "，今年 " << age << " 岁" << std::endl;
    }

    std::string getName() const { return name; }
};

// 派生类：学生（public 继承 Person）
class Student : public Person {
private:
    std::string school;

public:
    // 通过初始化列表调用基类构造函数
    Student(const std::string& n, int a, const std::string& s)
        : Person(n, a), school(s) {
        std::cout << "Student 构造" << std::endl;
    }

    ~Student() override {
        std::cout << "Student 析构" << std::endl;
    }

    // 新增成员函数
    void study() const {
        std::cout << name << " 在 " << school << " 学习" << std::endl;
    }

    // 遮蔽基类的 introduce（不推荐，演示用）
    void introduce() const {
        Person::introduce();    // 调用基类版本
        std::cout << "我就读于 " << school << std::endl;
    }
};

// 派生类：教师
class Teacher : public Person {
private:
    std::string subject;

public:
    Teacher(const std::string& n, int a, const std::string& sub)
        : Person(n, a), subject(sub) {}

    void teach() const {
        std::cout << name << " 教授 " << subject << std::endl;
    }
};

int main() {
    std::cout << "=== 创建学生 ===" << std::endl;
    Student stu("张三", 20, "清华大学");
    stu.introduce();       // 调用派生类版本
    stu.study();
    stu.Person::introduce();  // 显式调用基类版本

    std::cout << "\n=== 创建教师 ===" << std::endl;
    Teacher tea("李老师", 45, "数学");
    tea.introduce();       // 继承自基类
    tea.teach();

    std::cout << "\n=== 基类指针指向派生类对象 ===" << std::endl;
    Person* p = &stu;
    p->introduce();        // 调用基类版本（非虚函数，静态绑定）

    std::cout << "\n=== 析构顺序（先子后父）===" << std::endl;
    return 0;
}
```

**输出**：
```
=== 创建学生 ===
Person 构造
Student 构造
我是 张三，今年 20 岁
我就读于 清华大学
张三 在 清华大学 学习
我是 张三，今年 20 岁

=== 创建教师 ===
Person 构造
我是 李老师，今年 45 岁
李老师 教授 数学

=== 基类指针指向派生类对象 ===
我是 张三，今年 20 岁

=== 析构顺序（先子后父）===
Student 析构
Person 析构
Teacher 析构
Person 析构
```

### 总结

- 继承表达"是一个"关系，派生类复用基类的代码，`public` 继承最常用。
- 构造顺序"先父后子"，析构顺序"先子后父"，派生类通过初始化列表调用基类构造函数。
- `protected` 成员专为继承设计，派生类可访问但外部不可访问。
- 派生类同名成员会遮蔽基类成员，可用 `using` 或 `基类::` 显式调用。
- **注意事项**：基类析构函数应声明为 `virtual`（下讲详解），确保通过基类指针删除派生类对象时正确析构；避免过度使用继承，优先组合（has-a）而非继承（is-a）；多重继承慎用，注意菱形问题。

## 第 12 讲：多态与虚函数

### 概念

**多态**是面向对象编程的第三大支柱，指同一接口可以表现多种形态。C++ 的多态分为两种：**编译时多态**（静态多态，通过函数重载和模板实现，编译期决定调用哪个函数）和**运行时多态**（动态多态，通过虚函数和继承实现，运行期根据对象实际类型决定调用哪个函数）。本讲聚焦运行时多态，它是 OOP 的精髓所在。

**虚函数**通过 `virtual` 关键字声明，允许派生类重写（override）基类的实现。当通过基类指针或引用调用虚函数时，实际调用的是对象真实类型（而非指针/引用的静态类型）的版本——这就是**动态绑定**。多态使我们能够用统一的接口操作不同类型的对象，极大提高了代码的灵活性和可扩展性。例如，一个 `Shape` 基类有 `area()` 虚函数，`Circle`、`Rectangle`、`Triangle` 各自重写 `area()`，我们可以用一个 `Shape*` 数组统一计算所有图形的面积。

### 原理

**虚函数表（vtable）**：编译器为每个含有虚函数的类生成一个虚函数表，是一个函数指针数组，存储该类所有虚函数的地址。每个对象内部包含一个指向其所属类 vtable 的指针（vptr）。当通过基类指针调用虚函数时，程序通过对象的 vptr 找到 vtable，再根据函数在表中的偏移找到正确的函数地址并调用。这一过程在运行时完成，因此称为动态绑定。虚函数的调用比普通函数多一次指针解引用，有微小开销。

**虚函数的规则**：
- 一旦函数在基类声明为 `virtual`，它在所有派生类中都是虚函数（无论是否加 `virtual`）。
- 派生类重写虚函数时，函数签名（名称、参数、返回类型）必须完全一致（协变返回类型例外）。
- C++11 引入 `override` 关键字，显式标记重写，编译器会检查签名是否匹配，避免因拼写错误导致的意外遮蔽。
- C++11 引入 `final` 关键字，禁止派生类进一步重写该虚函数或禁止该类被继承。

**纯虚函数与抽象类**：`virtual 返回类型 函数名(参数) = 0;` 声明纯虚函数，含有纯虚函数的类是**抽象类**，不能实例化，只能作为基类。派生类必须实现所有纯虚函数才能实例化。抽象类用于定义接口规范，强制派生类提供实现。

**虚析构函数**：如果类有虚函数，其析构函数几乎总是应该声明为 `virtual`。否则，通过基类指针 `delete` 派生类对象时，只会调用基类析构函数，派生类部分不会被析构，导致资源泄漏。虚析构函数确保正确调用整个继承链的析构函数。

### 例子

```cpp
#include <iostream>
#include <vector>
#include <memory>

// 抽象基类：形状
class Shape {
public:
    virtual double area() const = 0;       // 纯虚函数
    virtual void draw() const {             // 虚函数（有默认实现）
        std::cout << "绘制形状" << std::endl;
    }
    virtual ~Shape() = default;             // 虚析构函数
};

class Circle : public Shape {
private:
    double radius;
public:
    Circle(double r) : radius(r) {}
    double area() const override {          // override 确保正确重写
        return 3.14159 * radius * radius;
    }
    void draw() const override {
        std::cout << "绘制圆形（半径=" << radius << "）" << std::endl;
    }
};

class Rectangle : public Shape {
private:
    double width, height;
public:
    Rectangle(double w, double h) : width(w), height(h) {}
    double area() const override {
        return width * height;
    }
    void draw() const override {
        std::cout << "绘制矩形（" << width << "x" << height << "）" << std::endl;
    }
};

class Triangle : public Shape {
private:
    double base, height;
public:
    Triangle(double b, double h) : base(b), height(h) {}
    double area() const override {
        return 0.5 * base * height;
    }
    // 不重写 draw()，使用基类默认实现
};

// 多态函数：接受基类引用，调用实际类型的版本
void printShapeInfo(const Shape& s) {
    s.draw();
    std::cout << "面积 = " << s.area() << std::endl;
}

int main() {
    // Shape s;  // 错误：抽象类不能实例化

    Circle c(5);
    Rectangle r(4, 6);
    Triangle t(3, 8);

    // 通过基类引用调用（多态）
    printShapeInfo(c);
    printShapeInfo(r);
    printShapeInfo(t);

    std::cout << "\n=== 用基类指针数组统一管理 ===" << std::endl;
    std::vector<std::unique_ptr<Shape>> shapes;
    shapes.push_back(std::make_unique<Circle>(10));
    shapes.push_back(std::make_unique<Rectangle>(3, 4));
    shapes.push_back(std::make_unique<Triangle>(6, 5));

    double totalArea = 0;
    for (const auto& shape : shapes) {
        shape->draw();
        totalArea += shape->area();
    }
    std::cout << "总面积 = " << totalArea << std::endl;

    return 0;
}
```

**输出**：
```
绘制圆形（半径=5）
面积 = 78.5398
绘制矩形（4x6）
面积 = 24
绘制形状
面积 = 12

=== 用基类指针数组统一管理 ===
绘制圆形（半径=10）
面积 = 314.159
绘制矩形（3x4）
面积 = 12
绘制形状
面积 = 15
总面积 = 341.159
```

### 总结

- 多态分编译时（重载、模板）和运行时（虚函数），运行时多态是 OOP 核心。
- 虚函数通过 vtable 实现动态绑定，运行时根据对象实际类型调用对应版本。
- 纯虚函数（`= 0`）定义抽象类，抽象类不能实例化，派生类必须实现所有纯虚函数。
- 使用 `override` 显式标记重写，`final` 禁止进一步重写或继承。
- **注意事项**：有虚函数的类必须声明虚析构函数；不要在构造/析构函数中调用虚函数（此时对象类型不完整，不会触发多态）；虚函数有微小性能开销（vtable 查找），但灵活性收益远大于此；多态需要通过指针或引用调用，直接按值传递会发生对象切片（丢失派生类部分）。

## 第 13 讲：运算符重载

### 概念

**运算符重载**允许为自定义类型定义运算符的行为，使对象可以像内置类型一样使用 `+`、`-`、`==`、`<<` 等运算符。例如，两个 `Vector` 对象可以用 `v1 + v2` 相加，`std::cout << obj` 可以输出对象。运算符重载本质上是函数调用——`a + b` 等价于 `operator+(a, b)` 或 `a.operator+(b)`。这一特性使自定义类型的代码更直观、更符合数学表达习惯。

C++ 中大部分运算符都可以重载，但有例外：`.`（成员访问）、`.*`（成员指针访问）、`::`（作用域）、`?:`（三元条件）、`sizeof`、`typeid` 不能重载。运算符重载可以通过**成员函数**或**非成员函数（通常是友元）**实现。一些运算符必须作为成员函数（如 `=`、`[]`、`()`、`->`），一些通常作为非成员函数（如 `<<`、`>>`，因为左操作数是 `ostream`/`istream`）。

### 原理

**成员函数 vs 非成员函数**：
- 成员函数形式：`T operator+(const T& rhs) const`，左操作数是 `this` 对象，右操作数是参数。适用于左操作数是自定义类型的场景。
- 非成员函数形式：`T operator+(const T& lhs, const T& rhs)`，两个操作数都是参数。适用于左操作数不是自定义类型的场景（如 `ostream << obj`），或希望支持左右操作数的隐式转换。

**重载规则**：
- 不能改变运算符的优先级、结合性和操作数个数（`+` 必须是二元，`~` 必须是一元）。
- 不能发明新运算符（如 `**` 不行）。
- 至少一个操作数必须是自定义类型，不能重载内置类型间的运算（如 `int + int`）。
- 短路求值特性在重载的 `&&` 和 `||` 中会丢失（因为变成函数调用，所有参数都会求值），且无法重载逗号运算符的求值顺序，因此**不建议重载 `&&`、`||` 和 `,`**。

**常见运算符的重载模式**：
- 算术运算符（`+`、`-`、`*`、`/`）：通常返回新对象（值），不修改操作数。可以基于复合赋值（`+=`）实现：`a + b` 等价于 `T result = a; result += b; return result;`。
- 复合赋值（`+=`、`-=`）：通常作为成员函数，修改 `this` 并返回 `*this` 的引用。
- 比较运算符（`==`、`!=`、`<`、`>`）：返回 `bool`，C++20 引入太空船运算符 `<=>` 可一次性生成所有比较。
- 流运算符（`<<`、`>>`）：作为非成员友元函数，返回 `ostream&`/`istream&` 引用以支持链式调用。
- 下标运算符 `[]`：成员函数，常提供 `const` 和非 `const` 两个版本。
- 函数调用运算符 `()`：成员函数，使对象可像函数一样调用（函数对象/仿函数）。

### 例子

```cpp
#include <iostream>

class Vector2D {
private:
    double x, y;

public:
    Vector2D(double x = 0, double y = 0) : x(x), y(y) {}

    // 1. 算术运算符（成员函数）
    Vector2D operator+(const Vector2D& rhs) const {
        return Vector2D(x + rhs.x, y + rhs.y);
    }

    Vector2D operator-(const Vector2D& rhs) const {
        return Vector2D(x - rhs.x, y - rhs.y);
    }

    // 2. 复合赋值运算符
    Vector2D& operator+=(const Vector2D& rhs) {
        x += rhs.x;
        y += rhs.y;
        return *this;
    }

    // 3. 一元负号
    Vector2D operator-() const {
        return Vector2D(-x, -y);
    }

    // 4. 比较运算符
    bool operator==(const Vector2D& rhs) const {
        return x == rhs.x && y == rhs.y;
    }

    // 5. 下标运算符（const 和非 const 版本）
    double& operator[](int i) {
        return i == 0 ? x : y;
    }
    const double& operator[](int i) const {
        return i == 0 ? x : y;
    }

    // 6. 函数调用运算符（函数对象）
    double operator()(const Vector2D& other) const {
        return x * other.x + y * other.y;  // 点积
    }

    // 友元：流运算符（非成员函数，需要访问私有成员）
    friend std::ostream& operator<<(std::ostream& os, const Vector2D& v);
    friend std::istream& operator>>(std::istream& is, Vector2D& v);
};

// 流输出运算符
std::ostream& operator<<(std::ostream& os, const Vector2D& v) {
    os << "(" << v.x << ", " << v.y << ")";
    return os;     // 返回引用支持链式：cout << a << b
}

// 流输入运算符
std::istream& operator>>(std::istream& is, Vector2D& v) {
    is >> v.x >> v.y;
    return is;
}

int main() {
    Vector2D v1(3, 4);
    Vector2D v2(1, 2);

    std::cout << "v1 = " << v1 << std::endl;
    std::cout << "v2 = " << v2 << std::endl;

    Vector2D sum = v1 + v2;
    std::cout << "v1 + v2 = " << sum << std::endl;

    Vector2D diff = v1 - v2;
    std::cout << "v1 - v2 = " << diff << std::endl;

    v1 += v2;
    std::cout << "v1 += v2 后 v1 = " << v1 << std::endl;

    Vector2D neg = -v1;
    std::cout << "-v1 = " << neg << std::endl;

    std::cout << "v1 == v2? " << (v1 == v2 ? "是" : "否") << std::endl;

    std::cout << "v1[0] = " << v1[0] << ", v1[1] = " << v1[1] << std::endl;

    Vector2D v3(2, 3);
    double dot = v1(v3);    // 函数对象调用，计算点积
    std::cout << "v1 · v3 = " << dot << std::endl;

    return 0;
}
```

**输出**：
```
v1 = (3, 4)
v2 = (1, 2)
v1 + v2 = (4, 6)
v1 - v2 = (2, 2)
v1 += v2 后 v1 = (4, 6)
-v1 = (-4, -6)
v1 == v2? 否
v1[0] = 4, v1[1] = 6
v1 · v3 = 26
```

### 总结

- 运算符重载本质是函数调用，使自定义类型能用运算符直观操作。
- 成员函数形式左操作数是 `this`，非成员形式两个操作数都是参数。
- `=`、`[]`、`()`、`->` 必须作为成员函数；`<<`、`>>` 通常作为非成员友元。
- 流运算符返回引用以支持链式调用：`cout << a << b`。
- **注意事项**：重载应保持运算符的语义一致性（`+` 应该是加法，不要做成减法）；不要重载 `&&`、`||`、`,`（会丢失短路特性）；算术运算符返回值，复合赋值返回引用；自增自减 `++`/`--` 要区分前置（`++a`）和后置（`a++`，用 `int` 哑参数区分）；C++20 推荐用 `<=>` 简化比较运算符。

# 第四章：泛型与异常

## 第 14 讲：模板编程

### 概念

**模板**是 C++ 泛型编程的核心机制，允许编写与类型无关的代码。模板就像一个"代码生成器"——你编写一份通用代码，编译器根据实际使用的类型自动生成具体版本。这实现了"一次编写，多种类型使用"，避免了为每种类型重复编写相同逻辑。模板分为**函数模板**和**类模板**两种。

函数模板用 `template<typename T>` 声明，其中 `T` 是类型参数。调用时编译器根据实参类型推导 `T` 的具体类型，生成对应的函数实例。类模板用 `template<typename T>` 声明类，使用时需指定具体类型如 `MyClass<int>`。模板还支持**非类型参数**（如 `template<typename T, int N>`，`N` 是编译期常量）和**可变参数模板**（C++11，`template<typename... Args>`，接受任意数量的参数）。模板是 C++ 标准库（STL）的基石——`vector`、`map`、`sort` 等都是模板实现。

### 原理

**模板的实例化机制**：模板本身不是代码，而是代码的"蓝图"。当编译器遇到模板的具体使用（如 `max<int>(3, 5)` 或 `vector<int>`）时，会用实际类型替换类型参数，生成一份具体的函数或类代码，这一过程称为**实例化**。每个不同的类型组合会生成不同的实例，例如 `max<int>` 和 `max<double>` 是两个独立的函数。模板代码必须在使用前可见（通常放在头文件中），因为编译器需要完整定义才能实例化。

**类型推导**：函数模板的参数类型可以自动推导——调用 `max(3, 5)` 时编译器推导 `T = int`。但如果实参类型不一致（如 `max(3, 5.0)`），推导会失败，需要显式指定 `max<double>(3, 5.0)` 或进行类型转换。C++17 引入了类模板参数推导（CTAD），`vector v = {1,2,3}` 可自动推导为 `vector<int>`。

**特化与偏特化**：有时通用模板对某些类型不适用或效率低，需要特殊处理。**全特化**为特定类型提供完全定制的实现：`template<> max<const char*>(...)`。**偏特化**（仅类模板支持）为一类类型提供定制：`template<typename T> class Vector<T*>` 为指针类型特化。函数模板不支持偏特化，但可用函数重载达到类似效果。

**SFINAE 与概念**：模板的灵活性也带来复杂性——如何约束模板参数满足某些条件？C++17 之前主要用 SFINAE（替换失败不是错误）技巧，晦涩难懂。C++20 引入了**概念（Concepts）**，用直观的语法约束模板参数，如 `template<std::integral T>` 要求 `T` 是整数类型，大幅提升了模板代码的可读性和错误信息的友好度。

### 例子

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <type_traits>

// 1. 函数模板：求最大值
template <typename T>
T maxValue(const T& a, const T& b) {
    return (a > b) ? a : b;
}

// 2. 函数模板全特化：针对 const char*（字符串比较）
template <>
const char* maxValue<const char*>(const char* const& a, const char* const& b) {
    return (std::string(a) > std::string(b)) ? a : b;
}

// 3. 类模板：栈
template <typename T, size_t MaxSize = 100>   // 非类型参数 + 默认值
class Stack {
private:
    T data[MaxSize];
    size_t top;
public:
    Stack() : top(0) {}

    void push(const T& value) {
        if (top < MaxSize) {
            data[top++] = value;
        }
    }

    T pop() {
        if (top > 0) {
            return data[--top];
        }
        throw std::out_of_range("栈为空");
    }

    bool empty() const { return top == 0; }
    size_t size() const { return top; }
};

// 4. 类模板偏特化：针对指针类型
template <typename T>
class Wrapper<T*> {
private:
    T* ptr;
public:
    Wrapper(T* p) : ptr(p) {}
    T& operator*() { return *ptr; }
    T* get() { return ptr; }
};

// 5. 可变参数模板（C++11）：递归展开
void print() {}  // 终止函数

template <typename T, typename... Args>
void print(const T& first, const Args&... rest) {
    std::cout << first << " ";
    print(rest...);   // 递归调用
}

// 6. C++20 概念约束
// 需要 #include <concepts>，这里用 static_assert 模拟
template <typename T>
T add(const T& a, const T& b) {
    static_assert(std::is_arithmetic<T>::value, "T 必须是算术类型");
    return a + b;
}

int main() {
    // 函数模板
    std::cout << "max(3, 7) = " << maxValue(3, 7) << std::endl;
    std::cout << "max(3.14, 2.72) = " << maxValue(3.14, 2.72) << std::endl;
    std::cout << "max(\"apple\", \"banana\") = " << maxValue("apple", "banana") << std::endl;

    // 类模板
    Stack<int> intStack;
    intStack.push(10);
    intStack.push(20);
    intStack.push(30);
    std::cout << "栈大小：" << intStack.size() << std::endl;
    std::cout << "弹出：" << intStack.pop() << std::endl;

    Stack<std::string, 5> strStack;   // 指定非类型参数
    strStack.push("Hello");
    strStack.push("World");
    std::cout << "弹出：" << strStack.pop() << std::endl;

    // 可变参数模板
    std::cout << "可变参数：";
    print(1, 2.5, "hello", 'A', true);
    std::cout << std::endl;

    // 概念约束
    std::cout << "add(3, 5) = " << add(3, 5) << std::endl;
    // add(std::string("a"), std::string("b"));  // 编译错误：不是算术类型

    return 0;
}
```

**输出**：
```
max(3, 7) = 7
max(3.14, 2.72) = 3.14
max("apple", "banana") = banana
栈大小：3
弹出：30
弹出：World
可变参数：1 2.5 hello A 1
add(3, 5) = 8
```

### 总结

- 模板是泛型编程的核心，编译器根据类型实例化生成具体代码。
- 函数模板自动推导类型，类模板需指定类型参数（C++17 后可自动推导）。
- 特化为特定类型提供定制实现，偏特化（仅类模板）为一类类型定制。
- 可变参数模板（`...`）接受任意数量参数，通过递归展开。
- **注意事项**：模板代码通常放在头文件中；模板错误信息冗长难读，C++20 概念可改善；避免模板代码膨胀（每种类型生成一份实例，增大二进制体积）；非类型模板参数必须是编译期常量。

## 第 15 讲：异常处理机制

### 概念

**异常处理**是 C++ 提供的错误处理机制，用于处理程序运行时出现的异常情况（如除零、内存不足、文件不存在、数组越界等）。异常将"错误检测"和"错误处理"分离——函数检测到错误后**抛出**（throw）异常，调用链上某处**捕获**（catch）并处理异常，中间函数无需关心错误处理，代码更清晰。

C++ 异常处理由三个关键字构成：`throw`（抛出异常）、`try`（标记可能抛出异常的代码块）、`catch`（捕获并处理异常）。异常可以是任何类型的对象，但标准库提供了 `std::exception` 基类及其派生类（如 `std::runtime_error`、`std::logic_error`、`std::out_of_range`），建议自定义异常继承自 `std::exception`。异常沿调用栈向上传播，直到被匹配的 `catch` 捕获；如果一直没有捕获，程序调用 `std::terminate` 终止。

### 原理

**异常的抛掷与捕获机制**：当执行 `throw obj;` 时，程序创建异常对象的副本，立即停止当前函数的执行，开始沿调用栈向上寻找匹配的 `catch` 块。这一过程称为**栈展开**（stack unwinding）。在栈展开过程中，所有已构造的局部对象会按构造的相反顺序被析构（RAII 的关键，确保资源释放）。如果找到类型匹配的 `catch`，执行其中的处理代码；如果到达 `main` 仍未捕获，调用 `std::terminate`（默认调用 `std::abort` 终止程序）。

**异常类型匹配**：`catch` 块按声明顺序匹配，使用第一个类型兼容的块。匹配规则比函数参数严格——不进行隐式类型转换（除了派生类到基类、数组到指针、函数到函数指针等少数情况）。`catch(...)` 可以捕获任何类型的异常，但无法获取异常对象。建议按"从派生类到基类"的顺序排列 `catch` 块，否则基类的 `catch` 会先匹配，派生类版本永远不会执行。

**异常安全等级**：良好的代码应提供异常安全保证，分四个等级：
1. **不抛异常保证**（noexcept）：承诺不抛出任何异常。
2. **强异常保证**（commit-or-rollback）：操作要么完全成功，要么回滚到操作前的状态（如 copy-and-swap）。
3. **基本异常保证**：异常发生时程序处于有效状态，无资源泄漏。
4. **无异常保证**：异常发生时程序可能处于任何状态（应避免）。

**noexcept 关键字**（C++11）：`void func() noexcept;` 声明函数不抛出异常。如果 `noexcept` 函数抛出异常，程序直接 `terminate`。这既是文档（告诉调用者无需 try-catch），也是优化（编译器无需生成异常处理代码）。移动构造函数通常声明为 `noexcept`，使容器在扩容时优先使用移动而非拷贝。

**RAII 与异常**：RAII（资源获取即初始化）是 C++ 异常安全的核心。将资源（内存、文件、锁）封装在对象中，构造时获取，析构时释放。即使异常发生，栈展开也会调用析构函数，自动释放资源。这是智能指针、`std::lock_guard` 等的设计思想。

### 例子

```cpp
#include <iostream>
#include <stdexcept>
#include <vector>
#include <memory>

// 1. 自定义异常类，继承 std::exception
class DivisionByZeroError : public std::runtime_error {
public:
    DivisionByZeroError()
        : std::runtime_error("除数不能为零") {}
};

// 2. 可能抛出异常的函数
double safeDivide(int a, int b) {
    if (b == 0) {
        throw DivisionByZeroError();    // 抛出自定义异常
    }
    return static_cast<double>(a) / b;
}

// 3. 抛出标准异常
int getElement(const std::vector<int>& vec, size_t index) {
    if (index >= vec.size()) {
        throw std::out_of_range("索引超出范围: " + std::to_string(index));
    }
    return vec[index];
}

// 4. noexcept 函数
void logMessage(const std::string& msg) noexcept {
    std::cout << "[LOG] " << msg << std::endl;
    // 如果这里抛出异常，程序会 terminate
}

// 5. 异常安全：RAII 保证资源释放
void processData() {
    // 即使中途抛出异常，智能指针也会自动释放内存
    auto data = std::make_unique<int[]>(1000);
    data[0] = 42;

    // 模拟可能失败的操作
    if (data[0] > 10) {
        throw std::runtime_error("数据值过大");
    }
    // 如果到这里抛出异常，data 的析构函数会自动调用
}

int main() {
    // 1. 捕获自定义异常
    try {
        double result = safeDivide(10, 0);
        std::cout << "结果：" << result << std::endl;
    } catch (const DivisionByZeroError& e) {
        std::cerr << "捕获到除零错误：" << e.what() << std::endl;
    }

    // 2. 捕获标准异常
    try {
        std::vector<int> vec = {1, 2, 3};
        int val = getElement(vec, 10);
        std::cout << "元素：" << val << std::endl;
    } catch (const std::out_of_range& e) {
        std::cerr << "捕获到越界错误：" << e.what() << std::endl;
    } catch (const std::exception& e) {
        // 基类 catch 放在后面
        std::cerr << "捕获到标准异常：" << e.what() << std::endl;
    }

    // 3. 捕获所有异常
    try {
        processData();
    } catch (...) {
        std::cerr << "捕获到未知异常" << std::endl;
    }

    // 4. 异常重新抛出
    try {
        try {
            throw std::runtime_error("内部错误");
        } catch (const std::runtime_error& e) {
            std::cout << "内层捕获：" << e.what() << "，重新抛出" << std::endl;
            throw;    // 重新抛出当前异常
        }
    } catch (const std::exception& e) {
        std::cout << "外层捕获：" << e.what() << std::endl;
    }

    // 5. noexcept 函数调用
    logMessage("程序正常执行");

    return 0;
}
```

**输出**：
```
捕获到除零错误：除数不能为零
捕获到越界错误：索引超出范围: 10
捕获到未知异常
内层捕获：内部错误，重新抛出
外层捕获：内部错误
[LOG] 程序正常执行
```

### 总结

- 异常处理将错误检测与处理分离，`throw` 抛出、`try` 标记、`catch` 捕获。
- 栈展开过程中局部对象自动析构，RAII 是异常安全的核心。
- 自定义异常应继承 `std::exception`，实现 `what()` 方法。
- `catch` 按顺序匹配，派生类在前基类在后；`catch(...)` 捕获所有异常。
- **注意事项**：不要在析构函数中抛出异常（栈展开时会导致 terminate）；不要用异常替代正常的控制流（性能开销）；构造函数抛出异常时成员不会完全构造，析构函数不会调用，需手动清理已构造的部分；`noexcept` 既是承诺也是优化提示，移动构造函数应尽量声明为 `noexcept`。

## 第 16 讲：STL 容器与算法

### 概念

**STL（Standard Template Library，标准模板库）** 是 C++ 标准库的核心组成部分，提供了一组通用的、高效的、模板化的数据结构和算法。STL 的设计哲学是"泛型编程"——将数据结构和算法分离，通过**迭代器**连接二者，使算法可以作用于任意容器。STL 由三大组件构成：**容器**（存储数据）、**算法**（操作数据）、**迭代器**（遍历容器，连接容器与算法）。

STL 容器分为几大类：**序列容器**（`vector`、`deque`、`list`、`array`、`forward_list`）按顺序存储元素；**关联容器**（`map`、`set`、`multimap`、`multiset`）按键排序存储，基于红黑树实现，查找 O(log n)；**无序关联容器**（`unordered_map`、`unordered_set` 等，C++11）基于哈希表，平均查找 O(1)；**容器适配器**（`stack`、`queue`、`priority_queue`）封装序列容器提供特定接口。STL 算法（如 `sort`、`find`、`copy`、`transform`、`accumulate`）定义在 `<algorithm>` 头文件中，通过迭代器操作容器，与容器类型无关。

### 原理

**迭代器**：迭代器是指针的泛化，提供统一的方式遍历容器。STL 迭代器分为五类：**输入迭代器**（只读，单向）、**输出迭代器**（只写，单向）、**前向迭代器**（读写，单向）、**双向迭代器**（读写，双向）、**随机访问迭代器**（读写，随机跳转）。不同容器提供不同级别的迭代器——`vector` 提供随机访问迭代器，`list` 提供双向迭代器，`forward_list` 提供前向迭代器。算法根据所需迭代器类别选择适用的容器。

**容器选择原则**：
- 需要随机访问、尾部增删：`vector`（首选）。
- 频繁头部和尾部增删：`deque`。
- 频繁中间增删：`list`（双向链表）。
- 需要键值对映射，有序：`map`。
- 需要键值对映射，无序，快速查找：`unordered_map`。
- 需要去重集合：`set` / `unordered_set`。
- 需要栈/队列/优先队列：`stack` / `queue` / `priority_queue`。

**算法的复杂度**：
- 排序 `sort`：O(n log n)，基于内省排序（introsort，快排+堆排的混合）。
- 查找 `find`（无序）：O(n)；`binary_search`（有序）：O(log n)。
- `std::accumulate` 求和：O(n)。
- `std::copy`、`std::transform`：O(n)。

**函数对象与 Lambda**：STL 算法常需要函数或函数对象作为参数（如 `sort` 的比较函数、`for_each` 的操作函数）。C++11 后，Lambda 表达式是最常用的方式，它可以在调用处定义匿名函数，简洁直观。

### 例子

```cpp
#include <iostream>
#include <vector>
#include <list>
#include <map>
#include <unordered_map>
#include <set>
#include <algorithm>
#include <numeric>
#include <string>

int main() {
    // 1. vector + 算法
    std::vector<int> nums = {5, 2, 8, 1, 9, 3, 7, 4, 6};

    // 排序（默认升序）
    std::sort(nums.begin(), nums.end());
    std::cout << "升序：";
    for (int n : nums) std::cout << n << " ";
    std::cout << std::endl;

    // 降序排序（用 Lambda）
    std::sort(nums.begin(), nums.end(), [](int a, int b) {
        return a > b;
    });
    std::cout << "降序：";
    for (int n : nums) std::cout << n << " ";
    std::cout << std::endl;

    // 查找
    auto it = std::find(nums.begin(), nums.end(), 7);
    if (it != nums.end()) {
        std::cout << "找到 7，位置：" << (it - nums.begin()) << std::endl;
    }

    // 求和
    int sum = std::accumulate(nums.begin(), nums.end(), 0);
    std::cout << "总和：" << sum << std::endl;

    // transform：每个元素乘以 2
    std::vector<int> doubled;
    std::transform(nums.begin(), nums.end(), std::back_inserter(doubled),
                   [](int x) { return x * 2; });
    std::cout << "翻倍：";
    for (int n : doubled) std::cout << n << " ";
    std::cout << std::endl;

    // 2. map（有序键值对）
    std::map<std::string, int> scores;
    scores["张三"] = 85;
    scores["李四"] = 92;
    scores["王五"] = 78;
    scores["赵六"] = 88;

    std::cout << "\n=== map（按 key 排序）===" << std::endl;
    for (const auto& [name, score] : scores) {   // C++17 结构化绑定
        std::cout << name << ": " << score << std::endl;
    }

    auto it2 = scores.find("李四");
    if (it2 != scores.end()) {
        std::cout << "李四成绩：" << it2->second << std::endl;
    }

    // 3. unordered_map（哈希表，无序，快速查找）
    std::unordered_map<std::string, int> hashScores;
    hashScores["apple"] = 1;
    hashScores["banana"] = 2;
    hashScores["cherry"] = 3;
    std::cout << "\n=== unordered_map ===" << std::endl;
    std::cout << "banana = " << hashScores["banana"] << std::endl;  // O(1) 平均

    // 4. set（有序去重集合）
    std::set<int> uniqueNums = {3, 1, 4, 1, 5, 9, 2, 6, 5};
    std::cout << "\n=== set（自动去重排序）===" << std::endl;
    for (int n : uniqueNums) std::cout << n << " ";
    std::cout << std::endl;

    // 5. list（双向链表，适合中间增删）
    std::list<std::string> names = {"Alice", "Bob", "Charlie"};
    names.push_front("Zero");
    names.push_back("David");
    auto lit = std::find(names.begin(), names.end(), "Bob");
    if (lit != names.end()) {
        names.insert(lit, "Bob2");   // 在 Bob 前插入
    }
    std::cout << "\n=== list ===" << std::endl;
    for (const auto& name : names) std::cout << name << " ";
    std::cout << std::endl;

    // 6. for_each 算法
    std::cout << "\n=== for_each ===" << std::endl;
    std::for_each(nums.begin(), nums.end(), [](int x) {
        if (x > 5) std::cout << x << " ";
    });
    std::cout << "(大于5的元素)" << std::endl;

    return 0;
}
```

**输出**：
```
升序：1 2 3 4 5 6 7 8 9
降序：9 8 7 6 5 4 3 2 1
找到 7，位置：6
总和：45
翻倍：18 16 14 12 10 8 6 4 2

=== map（按 key 排序）===
张三: 85
李四: 92
王五: 78
赵六: 88
李四成绩：92

=== unordered_map ===
banana = 2

=== set（自动去重排序）===
1 2 3 4 5 6 9

=== list ===
Zero Alice Bob2 Bob Charlie David

=== for_each ===
9 8 7 6 (大于5的元素)
```

### 总结

- STL 由容器、算法、迭代器三大组件构成，通过泛型编程实现复用。
- 序列容器按顺序存储，关联容器按键排序，无序容器基于哈希表。
- 根据操作特点选择容器：随机访问用 `vector`，中间增删用 `list`，键值映射用 `map`/`unordered_map`。
- 算法通过迭代器操作容器，与容器类型解耦，`<algorithm>` 提供丰富算法。
- **注意事项**：`vector` 扩容会使迭代器失效，扩容后需重新获取；`map` 的 `operator[]` 会在 key 不存在时插入默认值，`find` 不会；遍历容器时删除元素要小心迭代器失效；`unordered_map` 最坏情况 O(n)（哈希冲突），但平均 O(1)；优先使用 STL 而非手写数据结构和算法。

# 第五章：现代 C++ 与进阶

## 第 17 讲：智能指针与 RAII

### 概念

**智能指针**是 C++11 引入的自动管理内存的指针类，利用 **RAII（Resource Acquisition Is Initialization，资源获取即初始化）** 原则，在对象析构时自动释放所管理的内存，从根本上解决内存泄漏问题。智能指针的行为类似裸指针（支持 `*`、`->`），但额外管理所指对象的生命周期，是现代 C++ 替代 `new`/`delete` 的首选方案。

C++ 提供三种智能指针（定义在 `<memory>` 头文件中）：**`std::unique_ptr`**（独占所有权，不可拷贝，可移动）、**`std::shared_ptr`**（共享所有权，通过引用计数管理，可拷贝）、**`std::weak_ptr`**（弱引用，不增加引用计数，配合 `shared_ptr` 解决循环引用）。此外，`std::make_unique`（C++14）和 `std::make_shared`（C++11）是创建智能指针的安全工厂函数，推荐优先使用。

### 原理

**RAII 原则**：RAII 是 C++ 资源管理的核心思想——将资源（内存、文件、锁、套接字）的生命周期绑定到对象的生命周期。构造时获取资源，析构时释放资源。由于 C++ 保证析构函数在对象离开作用域时自动调用（即使发生异常），RAII 确保资源总是被正确释放，无需手动管理。智能指针、`std::lock_guard`、`std::fstream` 等都是 RAII 的应用。

**`unique_ptr` 的独占所有权**：`unique_ptr` 独占所管理的对象，同一时刻只能有一个 `unique_ptr` 指向某个对象。它不可拷贝（删除了拷贝构造和拷贝赋值），但可以移动——通过 `std::move` 转移所有权，转移后原指针变为 `nullptr`。`unique_ptr` 几乎没有额外开销（大小等于裸指针，除非指定自定义删除器），是默认的智能指针选择。它还支持数组形式 `unique_ptr<T[]>`，自动调用 `delete[]`。

**`shared_ptr` 的引用计数**：`shared_ptr` 允许多个指针共享同一对象，内部维护一个**引用计数**。每次拷贝 `shared_ptr`（如赋值给另一个、传入函数、放入容器），引用计数加 1；每次销毁（离开作用域、被重置），引用计数减 1。当引用计数降为 0 时，所管理的对象被析构释放。引用计数的操作是原子性的（线程安全的），但对象本身的访问不是。`shared_ptr` 的开销比 `unique_ptr` 大——需要额外的控制块存储引用计数和弱引用计数，且原子操作有性能成本。

**`weak_ptr` 与循环引用**：当两个对象互相用 `shared_ptr` 指向对方时，形成循环引用，两者的引用计数永远不为 0，导致内存泄漏。`weak_ptr` 是 `shared_ptr` 的弱引用——它指向 `shared_ptr` 管理的对象，但不增加引用计数。使用前需调用 `lock()` 提升为 `shared_ptr`（如果对象已被释放，返回空）。`weak_ptr` 常用于观察者模式、缓存、打破循环引用。

**`make_unique` / `make_shared` 的优势**：
1. 异常安全：`func(std::make_shared<T>(), risky())` 不会泄漏，而 `func(new T, risky())` 可能泄漏（如果 `risky()` 在 `new` 后抛异常）。
2. 性能：`make_shared` 一次分配同时创建对象和控制块，减少一次内存分配。
3. 代码简洁：无需写 `new`。

### 例子

```cpp
#include <iostream>
#include <memory>
#include <vector>

class Resource {
public:
    Resource(const std::string& name) : name(name) {
        std::cout << "获取资源: " << name << std::endl;
    }
    ~Resource() {
        std::cout << "释放资源: " << name << std::endl;
    }
    void use() const {
        std::cout << "使用资源: " << name << std::endl;
    }
private:
    std::string name;
};

// 1. unique_ptr：独占所有权
void uniquePtrDemo() {
    std::cout << "\n=== unique_ptr ===" << std::endl;
    std::unique_ptr<Resource> p1 = std::make_unique<Resource>("资源A");
    p1->use();

    // std::unique_ptr<Resource> p2 = p1;  // 错误：不可拷贝
    std::unique_ptr<Resource> p2 = std::move(p1);  // 移动所有权
    std::cout << "移动后 p1 是否为空：" << (p1 == nullptr ? "是" : "否") << std::endl;
    p2->use();

}

// 2. shared_ptr：共享所有权

    std::cout << "\n=== shared_ptr ===" << std::endl;
    auto p1 = std::make_shared<Resource>("资源B");
    std::cout << "引用计数: " << p1.use_count() << std::endl;  // 1

    {
        auto p2 = p1;   // 拷贝，引用计数 +1
        std::cout << "p2 作用域内引用计数: " << p1.use_count() << std::endl;  // 2
        p2->use();
    }   // p2 销毁，引用计数 -1

    std::cout << "p2 离开后引用计数: " << p1.use_count() << std::endl;  // 1
    // p1 离开作用域，引用计数降为 0，释放资源B
}

// 3. weak_ptr：打破循环引用
void weakPtrDemo() {
    std::cout << "\n=== weak_ptr ===" << std::endl;
    auto shared = std::make_shared<Resource>("资源C");
    std::weak_ptr<Resource> weak = shared;   // 弱引用，不增加计数

    std::cout << "shared 引用计数: " << shared.use_count() << std::endl;  // 1
    std::cout << "weak 过期? " << (weak.expired() ? "是" : "否") << std::endl;

    // 使用前提升为 shared_ptr
    if (auto locked = weak.lock()) {
        locked->use();
        std::cout << "提升后引用计数: " << shared.use_count() << std::endl;  // 2
    }   // locked 销毁，引用计数恢复 1

    shared.reset();   // 手动释放
    std::cout << "shared 释放后，weak 过期? " << (weak.expired() ? "是" : "否") << std::endl;
}

// 4. 容器中存储智能指针
void containerDemo() {
    std::cout << "\n=== 容器存储智能指针 ===" << std::endl;
    std::vector<std::unique_ptr<Resource>> resources;
    resources.push_back(std::make_unique<Resource>("资源1"));
    resources.push_back(std::make_unique<Resource>("资源2"));
    resources.push_back(std::make_unique<Resource>("资源3"));

    for (const auto& r : resources) {
        r->use();
    }
    // vector 销毁时，所有 unique_ptr 自动释放
}

int main() {
    uniquePtrDemo();
    sharedPtrDemo();
    weakPtrDemo();
    containerDemo();

    std::cout << "\n=== 程序结束 ===" << std::endl;
    return 0;
}
```

### 总结

- 智能指针基于 RAII，自动管理内存，是现代 C++ 替代裸 `new`/`delete` 的首选。
- `unique_ptr` 独占所有权，不可拷贝可移动，几乎无额外开销，是默认选择。
- `shared_ptr` 共享所有权，通过引用计数管理，开销较大，用于需要共享的场景。
- `weak_ptr` 不增加引用计数，用于打破循环引用和观察者模式。
- **注意事项**：优先用 `make_unique`/`make_shared` 创建智能指针；不要用 `shared_ptr` 管理同一个裸指针两次（会 double free）；避免 `shared_ptr` 循环引用导致内存泄漏；不要用 `get()` 返回的指针初始化另一个智能指针；智能指针的线程安全仅限于引用计数操作，对象本身的访问需额外同步。

## 第 18 讲：Lambda 表达式与移动语义

### 概念

**Lambda 表达式**（C++11）是创建匿名函数对象的便捷语法，允许在调用处定义函数，常用于 STL 算法的回调、短小的一次性函数。Lambda 的语法为 `[捕获列表](参数列表) -> 返回类型 { 函数体 }`，其中返回类型可省略（由 `return` 推导）。Lambda 本质上是一个编译器生成的闭包类（closure type）的实例，捕获列表决定如何将外部变量传入闭包。

**移动语义**（C++11）是 C++ 最重要的性能优化之一，允许将资源（如动态内存）从一个对象"窃取"到另一个对象，而非拷贝。移动通过**右值引用**（`T&&`）实现——右值引用绑定到即将销毁的临时对象（右值），可以安全地窃取其资源。移动构造函数和移动赋值运算符实现了资源的转移。`std::move` 是一个无条件的右值转换工具，它本身不移动任何东西，只是将左值转换为右值引用，使移动构造函数被调用。

### 原理

**Lambda 的捕获机制**：
- `[]`：不捕获任何变量。
- `[=]`：按值捕获所有外部变量（只读，除非加 `mutable`）。
- `[&]`：按引用捕获所有外部变量（可修改，注意生命周期）。
- `[x]`：按值捕获变量 `x`。
- `[&x]`：按引用捕获变量 `x`。
- `[=, &x]`：默认按值捕获，但 `x` 按引用捕获。
- `[this]`：捕获 `this` 指针（成员函数中的 Lambda 常用）。

按值捕获的变量在 Lambda 创建时拷贝，之后外部变量的修改不影响 Lambda 内的副本。`mutable` 关键字允许修改按值捕获的副本（但不影响外部）。按引用捕获要注意引用的对象在 Lambda 调用时是否仍然有效——如果引用了局部变量而 Lambda 在变量销毁后被调用，会导致悬空引用。

**左值与右值**：
- **左值**（lvalue）：有名字、可取地址的表达式，如变量名、`*p`、`arr[i]`。可以出现在赋值号左边。
- **右值**（rvalue）：没有名字、不可取地址的临时值，如字面量 `42`、表达式 `a+b`、函数返回的临时对象。即将销毁，可以安全窃取资源。
- **右值引用** `T&&`：绑定到右值的引用，表明"这个值即将销毁，可以移动其资源"。

**移动构造与移动赋值**：移动构造函数 `T(T&& other) noexcept` 将 `other` 的资源"窃取"给新对象——将指针成员赋值为 `other` 的指针，然后将 `other` 的指针置为 `nullptr`，使 `other` 析构时不会释放资源。移动比拷贝快得多——只需交换几个指针，无需深拷贝。移动赋值类似，但需先释放自身的旧资源。

**`std::move` 的本质**：`std::move(x)` 是 `static_cast<T&&>(x)` 的封装，将左值无条件转换为右值引用。它不移动任何东西，只是告诉编译器"我不再需要这个值了，你可以移动它"。转换后，如果目标类型有移动构造函数，就会调用移动；否则退化为拷贝。移动后的源对象处于"有效但未指定"的状态，只能析构或重新赋值，不应假设其值。

**完美转发**（Perfect Forwarding）：`std::forward<T>(arg)` 配合万能引用 `T&&`，保持参数的左右值属性，使模板函数能将参数原样转发给其他函数。这在工厂函数、包装器中非常有用。

### 例子

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <string>
#include <utility>

// 1. 移动语义：自定义可移动的类
class StringList {
private:
    std::string* data;
    size_t count;
public:
    // 构造函数
    StringList(std::initializer_list<std::string> init) : count(init.size()) {
        data = new std::string[count];
        size_t i = 0;
        for (const auto& s : init) {
            data[i++] = s;
        }
        std::cout << "构造，count=" << count << std::endl;
    }

    // 拷贝构造（深拷贝，慢）
    StringList(const StringList& other) : count(other.count) {
        data = new std::string[count];
        for (size_t i = 0; i < count; ++i) {
            data[i] = other.data[i];
        }
        std::cout << "拷贝构造，count=" << count << std::endl;
    }

    // 移动构造（窃取资源，快）
    StringList(StringList&& other) noexcept
        : data(other.data), count(other.count) {
        other.data = nullptr;    // 置空，防止 other 析构时释放
        other.count = 0;
        std::cout << "移动构造，count=" << count << std::endl;
    }

    ~StringList() {
        delete[] data;
    }

    size_t size() const { return count; }
};

int main() {
    // === Lambda 表达式 ===
    std::cout << "=== Lambda 表达式 ===" << std::endl;

    // 1. 基本用法：作为算法回调
    std::vector<int> nums = {5, 2, 8, 1, 9, 3};
    std::sort(nums.begin(), nums.end(), [](int a, int b) {
        return a > b;   // 降序
    });
    std::cout << "降序排序：";
    for (int n : nums) std::cout << n << " ";
    std::cout << std::endl;

    // 2. 捕获外部变量
    int factor = 10;
    auto multiply = [factor](int x) { return x * factor; };  // 按值捕获
    std::cout << "multiply(5) = " << multiply(5) << std::endl;  // 50

    int sum = 0;
    std::for_each(nums.begin(), nums.end(), [&sum](int x) {  // 按引用捕获
        sum += x;
    });
    std::cout << "总和 = " << sum << std::endl;

    // 3. mutable Lambda：修改按值捕获的副本
    int counter = 0;
    auto increment = [counter]() mutable {
        return ++counter;   // 修改的是副本，不影响外部
    };
    std::cout << "increment() = " << increment() << std::endl;  // 1
    std::cout << "increment() = " << increment() << std::endl;  // 2
    std::cout << "外部 counter = " << counter << std::endl;     // 0，未变

    // 4. Lambda 作为变量存储和传递
    auto greet = [](const std::string& name) {
        return "Hello, " + name + "!";
    };
    std::cout << greet("World") << std::endl;

    // === 移动语义 ===
    std::cout << "\n=== 移动语义 ===" << std::endl;

    StringList list1 = {"apple", "banana", "cherry"};

    // 拷贝构造
    std::cout << "--- 拷贝构造 ---" << std::endl;
    StringList list2 = list1;

    // 移动构造（list1 的资源被窃取）
    std::cout << "--- 移动构造 ---" << std::endl;
    StringList list3 = std::move(list1);
    std::cout << "list1 移动后 size = " << list1.size() << std::endl;  // 0
    std::cout << "list3 size = " << list3.size() << std::endl;          // 3

    // vector 扩容时优先移动（如果移动构造是 noexcept）
    std::cout << "\n--- vector 存储与移动 ---" << std::endl;
    std::vector<StringList> vec;
    vec.reserve(3);
    vec.push_back(StringList{"one"});
    vec.push_back(StringList{"two"});
    vec.push_back(StringList{"three"});

    return 0;
}
```

**输出**：
```
=== Lambda 表达式 ===
降序排序：9 8 5 3 2 1
multiply(5) = 50
总和 = 28
increment() = 1
increment() = 2
外部 counter = 0
Hello, World!

=== 移动语义 ===
构造，count=3
--- 拷贝构造 ---
拷贝构造，count=3
--- 移动构造 ---
移动构造，count=3
list1 移动后 size = 0
list3 size = 3

--- vector 存储与移动 ---
构造，count=1
构造，count=2
构造，count=3
```

### 总结

- Lambda 是匿名函数对象，`[捕获](参数) -> 返回 {体}`，常用于算法回调和短小函数。
- 捕获方式：`[]` 不捕获、`[=]` 按值、`[&]` 按引用、`[x]`/`[&x]` 指定变量。
- 移动语义通过右值引用 `T&&` 窃取资源，避免昂贵的深拷贝，大幅提升性能。
- `std::move` 是无条件的右值转换，本身不移动，触发移动构造/赋值。
- **注意事项**：按引用捕获要注意对象生命周期，避免悬空引用；`mutable` 允许修改按值捕获的副本；移动后的源对象处于"有效但未指定"状态，不要使用其值；移动构造函数应声明为 `noexcept`，否则容器扩容时会退化为拷贝；不要对 `const` 对象使用 `std::move`（会退化为拷贝）。

## 第 19 讲：并发编程入门

### 概念

**并发编程**是指程序中多个任务同时执行的能力。现代 CPU 普遍是多核的，并发编程可以充分利用多核性能，提高程序吞吐量和响应速度。C++11 首次在标准库中引入了并发支持，包括**线程**（`std::thread`）、**互斥锁**（`std::mutex`）、**条件变量**（`std::condition_variable`）、**原子操作**（`std::atomic`）、**未来值**（`std::future`/`std::promise`）等，使跨平台并发编程成为可能。

并发编程的核心挑战是**线程安全**——多个线程同时访问共享数据时，如果不加保护，会导致数据竞争（data race）和未定义行为。解决方法包括：**互斥锁**（确保同一时刻只有一个线程访问共享数据）、**原子操作**（不可分割的操作，无需加锁）、**消息传递**（线程间通过通道通信，不共享数据）。C++ 的并发工具围绕这些方法设计。

### 原理

**线程的创建与生命周期**：`std::thread` 创建一个新线程，接受一个可调用对象（函数、Lambda、函数对象）及其参数。线程创建后立即开始执行，调用 `join()` 等待线程结束（阻塞当前线程），或调用 `detach()` 分离线程（后台运行，无法再 join）。如果线程对象销毁时既未 join 也未 detach，程序会调用 `std::terminate` 终止。因此必须确保对每个线程调用 `join()` 或 `detach()`。

**数据竞争与互斥锁**：当多个线程同时读写同一变量，且至少一个是写操作时，发生数据竞争，结果是未定义的。`std::mutex` 提供互斥访问——线程访问共享数据前先 `lock()`，访问完 `unlock()`，确保同一时刻只有一个线程能访问。但直接使用 `lock`/`unlock` 容易出错（忘记 unlock 或异常导致死锁），推荐使用 **RAII 风格的锁守卫** `std::lock_guard` 或 `std::unique_lock`，它们在构造时加锁，析构时自动解锁，即使发生异常也能正确释放锁。

**死锁**：当两个线程互相等待对方持有的锁时，发生死锁，程序永久阻塞。避免死锁的方法：始终以相同顺序加锁；使用 `std::lock(m1, m2)` 一次性获取多个锁（避免死锁）；尽量减少锁的持有时间；优先使用单线程设计或无锁数据结构。

**原子操作**：`std::atomic<T>` 提供对变量的原子访问，无需互斥锁。原子操作不可分割——读取-修改-写入在一条指令中完成，不会被其他线程打断。适用于简单的计数器、标志位等场景，比互斥锁更高效。常用操作：`load()`（原子读取）、`store()`（原子写入）、`fetch_add()`（原子加法）、`compare_exchange_weak/strong()`（CAS，比较并交换）。

**条件变量**：`std::condition_variable` 用于线程间的通知机制。一个线程可以 `wait()` 等待某个条件成立（同时释放锁，避免忙等待），另一个线程在条件满足时 `notify_one()` 或 `notify_all()` 唤醒等待的线程。常用于生产者-消费者模式。

**`std::async` 与 `std::future`**：`std::async` 启动一个异步任务，返回 `std::future`，可以通过 `future::get()` 获取结果（如果任务未完成会阻塞）。这是比直接使用 `thread` 更高层的异步编程方式，适合"执行任务并获取结果"的场景。

### 例子

```cpp
#include <iostream>
#include <thread>
#include <mutex>
#include <atomic>
#include <condition_variable>
#include <vector>
#include <queue>
#include <future>
#include <chrono>

// 1. 基本线程创建
void printNumbers(int start, int end) {
    for (int i = start; i < end; ++i) {
        std::cout << i << " ";
    }
    std::cout << std::endl;
}

// 2. 互斥锁保护共享数据
std::mutex mtx;
int sharedCounter = 0;

void incrementWithLock(int times) {
    for (int i = 0; i < times; ++i) {
        std::lock_guard<std::mutex> lock(mtx);   // RAII 加锁
        ++sharedCounter;
    }
}

// 3. 原子操作（无需锁）
std::atomic<int> atomicCounter{0};

void incrementAtomic(int times) {
    for (int i = 0; i < times; ++i) {
        ++atomicCounter;   // 原子自增，线程安全
    }
}

// 4. 生产者-消费者模型
std::queue<int> dataQueue;
std::mutex queueMtx;
std::condition_variable cv;
bool finished = false;

void producer() {
    for (int i = 1; i <= 5; ++i) {
        {
            std::lock_guard<std::mutex> lock(queueMtx);
            dataQueue.push(i);
            std::cout << "生产: " << i << std::endl;
        }
        cv.notify_one();    // 通知消费者
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
    }
    {
        std::lock_guard<std::mutex> lock(queueMtx);
        finished = true;
    }
    cv.notify_one();
}

void consumer() {
    while (true) {
        std::unique_lock<std::mutex> lock(queueMtx);
        cv.wait(lock, [] { return !dataQueue.empty() || finished; });

        while (!dataQueue.empty()) {
            int value = dataQueue.front();
            dataQueue.pop();
            std::cout << "消费: " << value << std::endl;
        }

        if (finished) break;
    }
}

// 5. async 异步任务
int computeSum(int a, int b) {
    std::this_thread::sleep_for(std::chrono::milliseconds(500));
    return a + b;
}

int main() {
    // 1. 基本线程
    std::cout << "=== 基本线程 ===" << std::endl;
    std::thread t1(printNumbers, 1, 6);
    std::thread t2(printNumbers, 10, 15);
    t1.join();
    t2.join();

    // 2. 互斥锁
    std::cout << "\n=== 互斥锁 ===" << std::endl;
    std::vector<std::thread> threads;
    for (int i = 0; i < 5; ++i) {
        threads.emplace_back(incrementWithLock, 10000);
    }
    for (auto& t : threads) t.join();
    std::cout << "加锁计数器结果: " << sharedCounter << " (期望 50000)" << std::endl;

    // 3. 原子操作
    std::cout << "\n=== 原子操作 ===" << std::endl;
    threads.clear();
    for (int i = 0; i < 5; ++i) {
        threads.emplace_back(incrementAtomic, 10000);
    }
    for (auto& t : threads) t.join();
    std::cout << "原子计数器结果: " << atomicCounter << " (期望 50000)" << std::endl;

    // 4. 生产者-消费者
    std::cout << "\n=== 生产者-消费者 ===" << std::endl;
    std::thread prod(producer);
    std::thread cons(consumer);
    prod.join();
    cons.join();

    // 5. async 异步任务
    std::cout << "\n=== async 异步任务 ===" << std::endl;
    std::future<int> result = std::async(std::launch::async, computeSum, 10, 20);
    std::cout << "任务已启动，做其他事情..." << std::endl;
    int sum = result.get();   // 阻塞等待结果
    std::cout << "异步结果: " << sum << std::endl;

    return 0;
}
```

```

=== 互斥锁 ===

=== 原子操作 ===
原子计数器结果: 50000 (期望 50000)

=== 生产者-消费者 ===
生产: 1
消费: 1
生产: 2
消费: 2
生产: 3
消费: 3
生产: 4
消费: 4
生产: 5
消费: 5

任务已启动，做其他事情...
```

### 总结

- C++11 引入标准并发支持：`thread`、`mutex`、`condition_variable`、`atomic`、`future`。
- 线程必须 `join()` 或 `detach()`，否则程序终止。
- 共享数据需用互斥锁保护，优先用 `lock_guard`/`unique_lock`（RAII 自动解锁）。
- `atomic` 提供无锁的原子操作，适合简单计数器和标志位。
- 条件变量实现线程间通知，常用于生产者-消费者模式。
- **注意事项**：避免数据竞争（共享数据的读写必须同步）；避免死锁（按固定顺序加锁，用 `std::lock` 一次获取多个锁）；不要在持有锁时调用未知代码（可能死锁）；`condition_variable::wait` 要用谓词形式防止虚假唤醒；`std::async` 的 `get()` 只能调用一次；并发编程复杂度高，优先考虑无共享设计。
