# 第1章 游戏架构基础

游戏开发与普通应用开发有本质区别：游戏是实时响应、持续渲染、状态频繁变化的系统。本章讲解游戏开发的整体架构，包括游戏循环、状态管理、模块划分等核心概念，为后续所有章节奠定架构基础。

## 第1讲 游戏开发概述与开发栈

### 概念

游戏开发是一个跨学科领域，涉及图形学、物理学、人工智能、音频处理、人机交互等多个方向。本讲从宏观角度介绍 2D 游戏开发的技术栈、SDL2 在其中的定位，以及游戏开发与普通应用开发的本质区别。

游戏开发栈（Game Development Stack）是指开发一款游戏所需的技术层次结构。对于 2D 游戏而言，典型的技术栈从底到顶包括：操作系统 API → 图形 API（OpenGL/Direct3D）→ 窗口与输入库（SDL2）→ 游戏框架（自定义或第三方）→ 游戏逻辑。SDL2 处于中间层，提供跨平台的硬件抽象，开发者在此之上构建自己的游戏框架。

### 原理

**游戏程序的本质特征**：

1. **实时循环**：游戏不是事件驱动的被动响应程序，而是主动持续运行的循环。每帧（通常 1/60 秒）都要处理输入、更新逻辑、渲染画面，无论用户是否操作。

2. **状态持续演化**：游戏世界中的对象（玩家、敌人、粒子）状态随时间持续变化，需要基于时间步长（delta time）更新，而非离散事件触发。

3. **资源密集**：游戏需要管理大量资源（纹理、音频、动画），这些资源的加载、卸载、缓存策略直接影响性能。

4. **多子系统协作**：一个游戏包含渲染、物理、AI、音频、UI 等多个子系统，它们需要协同工作，架构设计决定了代码的可维护性。

**SDL2 游戏开发栈的层次**：

```
┌─────────────────────────────────┐
│        游戏逻辑层               │  ← 玩家行为、关卡规则、得分
├─────────────────────────────────┤
│      游戏框架层（自研）         │  ← 实体系统、场景管理、状态机
├─────────────────────────────────┤
│  SDL2 + 扩展库（image/ttf/mixer）│  ← 窗口、渲染、输入、音频
├─────────────────────────────────┤
│   操作系统（Windows/Linux/macOS）│  ← 硬件驱动、系统服务
└─────────────────────────────────┘
```

**为什么需要自研游戏框架层**：SDL2 只提供底层能力（画一个矩形、加载一张图片），不提供游戏开发的高层抽象（什么是"敌人"、如何管理"关卡"）。开发者必须在 SDL2 之上构建游戏框架，将游戏逻辑与底层 API 解耦。这个框架层是本课程的核心内容。

**游戏引擎 vs 游戏框架**：游戏引擎（如 Unity、Unreal）是完整的开发环境，包含编辑器、脚本系统、物理引擎等；游戏框架是轻量级的代码库，只提供基础结构，开发者有更大控制权。本课程教授的是基于 SDL2 的游戏框架开发，适合理解游戏底层原理。

**最小游戏框架骨架**（后续章节会逐步扩展）：

```c
#include <SDL2/SDL.h>
#include <stdio.h>

/* 游戏配置 */
typedef struct {
    int window_width;
    int window_height;
    int target_fps;
    SDL_bool vsync;
} GameConfig;

/* 游戏主结构 */
typedef struct {
    SDL_Window* window;
    SDL_Renderer* renderer;
    GameConfig config;
    SDL_bool running;
    Uint32 last_frame_time;
} Game;

/* 初始化游戏 */
int Game_Init(Game* game, GameConfig config) {
    game->config = config;
    game->running = SDL_TRUE;

    if (SDL_Init(SDL_INIT_VIDEO | SDL_INIT_AUDIO | SDL_INIT_TIMER) != 0) {
        printf("SDL_Init 失败: %s\n", SDL_GetError());
        return -1;
    }

    game->window = SDL_CreateWindow(
        "SDL2 Game",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        config.window_width, config.window_height,
        SDL_WINDOW_SHOWN
    );
    if (!game->window) return -1;

    Uint32 flags = SDL_RENDERER_ACCELERATED;
    if (config.vsync) flags |= SDL_RENDERER_PRESENTVSYNC;
    game->renderer = SDL_CreateRenderer(game->window, -1, flags);
    if (!game->renderer) return -1;

    game->last_frame_time = SDL_GetTicks();
    return 0;
}

/* 处理输入 */
void Game_HandleInput(Game* game) {
    SDL_Event event;
    while (SDL_PollEvent(&event)) {
        if (event.type == SDL_QUIT) game->running = SDL_FALSE;
        if (event.type == SDL_KEYDOWN &&
            event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
            game->running = SDL_FALSE;
    }
}

/* 更新逻辑 */
void Game_Update(Game* game, float delta) {
    /* 游戏逻辑更新，后续章节扩展 */
}

/* 渲染 */
void Game_Render(Game* game) {
    SDL_SetRenderDrawColor(game->renderer, 30, 30, 40, 255);
    SDL_RenderClear(game->renderer);
    /* 渲染游戏对象，后续章节扩展 */
    SDL_RenderPresent(game->renderer);
}

/* 清理 */
void Game_Cleanup(Game* game) {
    SDL_DestroyRenderer(game->renderer);
    SDL_DestroyWindow(game->window);
    SDL_Quit();
}

int main(int argc, char* argv[]) {
    Game game;
    GameConfig config = {
        .window_width = 800,
        .window_height = 600,
        .target_fps = 60,
        .vsync = SDL_TRUE
    };

    if (Game_Init(&game, config) != 0) {
        printf("游戏初始化失败\n");
        return 1;
    }

    /* 主循环 */
    while (game.running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - game.last_frame_time) / 1000.0f;
        game.last_frame_time = current_time;

        /* 防止 delta 过大（如程序暂停后恢复） */
        if (delta > 0.1f) delta = 0.1f;

        Game_HandleInput(&game);
        Game_Update(&game, delta);
        Game_Render(&game);
    }

    Game_Cleanup(&game);
    return 0;
}
```

### 总结

- 游戏开发栈分为：操作系统 → SDL2 → 游戏框架 → 游戏逻辑，SDL2 处于中间层
- 游戏程序的本质特征：实时循环、状态持续演化、资源密集、多子系统协作
- 必须在 SDL2 之上自研游戏框架层，将游戏逻辑与底层 API 解耦
- 良好的项目目录结构是可维护游戏代码的基础
- **常见坑**：不要把所有代码堆在 main.c 中，游戏代码量增长很快，早期就要做好模块划分；游戏框架层应与具体游戏逻辑分离，便于复用

## 第2讲 游戏循环架构设计

### 概念

游戏循环（Game Loop）是游戏程序的心脏，它以固定节奏驱动整个游戏的运行。本讲深入讲解游戏循环的架构设计，包括输入处理、逻辑更新、渲染三个阶段的执行顺序，以及固定时间步长与可变时间步长的选择。

游戏循环的质量直接决定游戏的流畅度、一致性和可维护性。一个设计良好的游戏循环能让游戏在不同硬件上表现一致，而设计糟糕的循环会导致"快电脑游戏太快、慢电脑游戏太慢"或物理模拟不稳定等问题。

### 原理

**游戏循环的三个阶段**：

每帧执行三个阶段，顺序固定：

1. **输入处理（Input）**：收集用户输入（键盘、鼠标、手柄），更新输入状态。这一阶段应尽可能快，不涉及游戏逻辑。

2. **逻辑更新（Update）**：根据输入和当前状态更新游戏世界。包括移动对象、碰撞检测、AI 决策、物理模拟等。这是最耗时的阶段。

3. **渲染（Render）**：将游戏世界绘制到屏幕。渲染应只读取状态，不修改状态。

**顺序的重要性**：输入→更新→渲染的顺序确保一帧内的逻辑一致。如果先渲染再处理输入，会导致输入延迟一帧显示；如果更新中修改了渲染正在读取的状态，会导致画面撕裂。

**可变时间步长（Variable Timestep）**：

每帧计算实际经过的时间 delta，所有更新基于 delta 计算。优点是简单直接，缺点是物理模拟在帧率波动时不稳定（浮点误差累积、碰撞穿透）。

```
delta = 当前时间 - 上一帧时间
更新所有对象（基于 delta）
渲染
```

**固定时间步长（Fixed Timestep）**：

逻辑更新使用固定的时间间隔（如 1/60 秒），渲染使用实际时间。实现方式是累积 delta，每达到一个步长执行一次更新。

```
accumulator += delta
while (accumulator >= FIXED_DT) {
    更新所有对象（基于 FIXED_DT）
    accumulator -= FIXED_DT
}
渲染（基于 accumulator / FIXED_DT 做插值）
```

优点是物理模拟稳定、确定性可重现（对网络同步和录像回放重要），缺点是实现复杂，需要插值避免画面卡顿。

**帧率独立的运动**：

无论使用哪种步长，运动计算都应基于时间而非帧数。错误做法：`x += speed`（每帧移动 speed，帧率不同速度不同）。正确做法：`x += speed * delta`（每秒移动 speed，帧率无关）。

**最大 delta 钳制**：

程序暂停（如窗口最小化、调试断点）后恢复时，delta 可能非常大（几秒甚至几十秒）。这会导致物体瞬移、物理爆炸。应在每帧开始时钳制 delta 最大值（如 0.1 秒）。

### 例子

下面实现三种游戏循环，对比它们的差异：

```c
#include <SDL2/SDL.h>
#include <stdio.h>

/* ============ 方案1：可变时间步长（简单） ============ */
void GameLoop_Variable(SDL_Window* window, SDL_Renderer* renderer) {
    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();
    float x = 0.0f;
    float speed = 200.0f;  /* 每秒 200 像素 */

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;
        if (delta > 0.1f) delta = 0.1f;  /* 钳制最大 delta */

        /* 输入 */
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
        }

        /* 更新 */
        x += speed * delta;
        if (x > 800) x = 0;

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect r = {(int)x, 280, 50, 50};
        SDL_RenderFillRect(renderer, &r);
        SDL_RenderPresent(renderer);
    }
}

/* ============ 方案2：固定时间步长（推荐） ============ */
#define FIXED_DT 0.016667f  /* 1/60 秒 */
#define MAX_FRAME_TIME 0.25f

typedef struct {
    float x, y;
    float vx, vy;
} PhysicsBody;

void GameLoop_Fixed(SDL_Window* window, SDL_Renderer* renderer) {
    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();
    float accumulator = 0.0f;

    PhysicsBody body = {0.0f, 0.0f, 150.0f, 0.0f};
    PhysicsBody prev_state = body;  /* 用于渲染插值 */

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float frame_time = (current_time - last_time) / 1000.0f;
        last_time = current_time;

        /* 钳制帧时间，防止暂停后大跳跃 */
        if (frame_time > MAX_FRAME_TIME) frame_time = MAX_FRAME_TIME;

        /* 输入 */
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
        }

        /* 累积时间，执行固定步长更新 */
        accumulator += frame_time;
        while (accumulator >= FIXED_DT) {
            prev_state = body;  /* 保存更新前状态 */
            /* 物理更新（使用固定步长） */
            body.x += body.vx * FIXED_DT;
            body.y += body.vy * FIXED_DT;
            /* 简单边界碰撞 */
            if (body.x < 0 || body.x > 750) body.vx = -body.vx;
            if (body.y < 0 || body.y > 550) body.vy = -body.vy;
            accumulator -= FIXED_DT;
        }

        /* 渲染插值：在 prev_state 和 body 之间插值 */
        float alpha = accumulator / FIXED_DT;
        float render_x = prev_state.x + (body.x - prev_state.x) * alpha;
        float render_y = prev_state.y + (body.y - prev_state.y) * alpha;

        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);
        SDL_SetRenderDrawColor(renderer, 100, 255, 100, 255);
        SDL_Rect r = {(int)render_x, (int)render_y, 50, 50};
        SDL_RenderFillRect(renderer, &r);
        SDL_RenderPresent(renderer);
    }
}

/* ============ 方案3：帧率限制（手动控制） ============ */
void GameLoop_Capped(SDL_Window* window, SDL_Renderer* renderer, int target_fps) {
    SDL_bool running = SDL_TRUE;
    Uint32 frame_delay = 1000 / target_fps;
    Uint32 last_time = SDL_GetTicks();
    float x = 0.0f;

    while (running) {
        Uint32 frame_start = SDL_GetTicks();
        float delta = (frame_start - last_time) / 1000.0f;
        last_time = frame_start;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
        }

        x += 200.0f * delta;
        if (x > 800) x = 0;

        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);
        SDL_SetRenderDrawColor(renderer, 255, 200, 100, 255);
        SDL_Rect r = {(int)x, 280, 50, 50};
        SDL_RenderFillRect(renderer, &r);
        SDL_RenderPresent(renderer);

        /* 手动限制帧率 */
        Uint32 frame_time = SDL_GetTicks() - frame_start;
        if (frame_time < frame_delay) {
            SDL_Delay(frame_delay - frame_time);
        }
    }
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow(
        "游戏循环示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED);

    printf("测试固定时间步长循环（按 ESC 退出）\n");
    GameLoop_Fixed(window, renderer);

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 游戏循环三阶段：输入 → 更新 → 渲染，顺序固定不可打乱
- 可变时间步长简单但物理不稳定，固定时间步长复杂但稳定且可重现
- 所有运动计算必须基于时间（`speed * delta`），不能基于帧数
- 必须钳制最大 delta，防止暂停后恢复时逻辑爆炸
- 固定步长需要渲染插值（alpha 混合上一帧和当前帧状态）避免卡顿
- **常见坑**：可变步长下碰撞检测可能穿透（物体一帧移动距离大于障碍物厚度）；固定步长累积器溢出（长时间暂停后 while 循环执行太多次），需限制最大累积值；渲染中修改状态会导致逻辑与显示不同步

## 第3讲 游戏状态管理

### 概念

游戏由多个状态组成：主菜单、游戏中、暂停、游戏结束、设置界面等。游戏状态管理（Game State Management）负责在这些状态之间切换，并确保每个状态的资源独立加载和卸载。本讲讲解状态栈模式及其实现。

### 原理

**为什么需要状态管理**：

如果所有逻辑都堆在主循环中，代码会变成巨大的 if-else 链：
```c
if (state == MENU) { ... }
else if (state == PLAYING) { ... }
else if (state == PAUSED) { ... }
else if (state == GAME_OVER) { ... }
```
这导致代码难以维护，且状态切换时资源管理混乱（菜单的纹理在游戏中还占用内存）。

**状态模式（State Pattern）**：

将每个状态封装为独立对象，包含四个核心方法：
- `OnEnter()`：进入状态时调用，加载资源、初始化
- `OnExit()`：退出状态时调用，释放资源
- `Update(delta)`：每帧更新逻辑
- `Render(renderer)`：每帧渲染

主循环只调用当前状态的方法，不关心具体是什么状态。

**状态栈模式（State Stack）**：

相比单一当前状态，状态栈更灵活。栈顶状态是活跃状态，下面的状态被"暂停"（不更新但可能仍渲染）。典型应用：

- 主菜单（栈底）→ 游戏中 → 暂停界面（栈顶）
- 暂停界面在栈顶，接收输入；游戏中的 Update 不执行，但 Render 仍执行（暂停画面下显示游戏画面）
- 关闭暂停界面后，游戏中恢复 Update

**状态切换类型**：
- `PUSH`：将新状态压入栈顶，当前状态暂停
- `POP`：弹出栈顶状态，恢复下层状态
- `SWITCH`：弹出栈顶并压入新状态（原子操作）

**资源管理**：每个状态在 OnEnter 加载资源，OnExit 释放资源。状态栈确保资源生命周期与状态生命周期一致，避免内存泄漏。

**状态间通信**：状态可能需要传递数据（如游戏结束状态需要知道得分）。解决方案：
1. 全局游戏上下文（简单但不优雅）
2. 状态切换时传递参数
3. 事件系统（状态发布事件，其他状态订阅）

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>
#include <stdlib.h>

/* 前向声明 */
typedef struct GameState GameState;
typedef struct Game Game;

/* 游戏状态接口 */
struct GameState {
    const char* name;
    int (*OnEnter)(Game* game);
    void (*OnExit)(Game* game);
    void (*HandleInput)(Game* game);
    void (*Update)(Game* game, float delta);
    void (*Render)(Game* game);
};

/* 游戏主结构 */
struct Game {
    SDL_Window* window;
    SDL_Renderer* renderer;
    SDL_bool running;
    Uint32 last_frame_time;

    /* 状态栈 */
    GameState* state_stack[16];
    int state_count;

    /* 全局游戏数据 */
    int score;
    int player_health;
};

/* 状态栈操作 */
void Game_PushState(Game* game, GameState* state) {
    if (game->state_count >= 16) return;
    if (game->state_count > 0) {
        /* 当前栈顶状态暂停（无需显式调用，Update 不执行即可） */
    }
    game->state_stack[game->state_count] = state;
    game->state_count++;
    if (state->OnEnter) state->OnEnter(game);
    printf("进入状态: %s\n", state->name);
}

void Game_PopState(Game* game) {
    if (game->state_count <= 0) return;
    GameState* top = game->state_stack[game->state_count - 1];
    if (top->OnExit) top->OnExit(game);
    printf("退出状态: %s\n", top->name);
    game->state_count--;
}

void Game_SwitchState(Game* game, GameState* state) {
    Game_PopState(game);
    Game_PushState(game, state);
}

GameState* Game_GetTopState(Game* game) {
    if (game->state_count <= 0) return NULL;
    return game->state_stack[game->state_count - 1];
}

/* ============ 主菜单状态 ============ */
int Menu_OnEnter(Game* game) {
    printf("  加载菜单资源\n");
    return 0;
}
void Menu_OnExit(Game* game) {
    printf("  卸载菜单资源\n");
}
void Menu_HandleInput(Game* game) {
    SDL_Event event;
    while (SDL_PollEvent(&event)) {
        if (event.type == SDL_QUIT) game->running = SDL_FALSE;
        if (event.type == SDL_KEYDOWN) {
            if (event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                game->running = SDL_FALSE;
            if (event.key.keysym.scancode == SDL_SCANCODE_RETURN) {
                /* 切换到游戏状态 */
                extern GameState PlayingState;
                Game_SwitchState(game, &PlayingState);
            }
        }
    }
}
void Menu_Update(Game* game, float delta) {
    /* 菜单动画等 */
}
void Menu_Render(Game* game) {
    SDL_SetRenderDrawColor(game->renderer, 40, 20, 60, 255);
    SDL_RenderClear(game->renderer);

    /* 绘制菜单选项（用矩形代替文字） */
    SDL_SetRenderDrawColor(game->renderer, 200, 180, 100, 255);
    SDL_Rect start_btn = {300, 250, 200, 50};
    SDL_RenderFillRect(game->renderer, &start_btn);

    SDL_SetRenderDrawColor(game->renderer, 150, 150, 150, 255);
    SDL_Rect quit_btn = {300, 320, 200, 50};
    SDL_RenderFillRect(game->renderer, &quit_btn);

    SDL_RenderPresent(game->renderer);
}

GameState MenuState = {
    .name = "Menu",
    .OnEnter = Menu_OnEnter,
    .OnExit = Menu_OnExit,
    .HandleInput = Menu_HandleInput,
    .Update = Menu_Update,
    .Render = Menu_Render
};

/* ============ 游戏中状态 ============ */
typedef struct {
    float x, y;
} PlayingData;

static PlayingData playing_data;

int Playing_OnEnter(Game* game) {
    printf("  加载游戏资源\n");
    playing_data.x = 400;
    playing_data.y = 300;
    game->score = 0;
    game->player_health = 100;
    return 0;
}
void Playing_OnExit(Game* game) {
    printf("  卸载游戏资源\n");
}
void Playing_HandleInput(Game* game) {
    SDL_Event event;
    while (SDL_PollEvent(&event)) {
        if (event.type == SDL_QUIT) game->running = SDL_FALSE;
        if (event.type == SDL_KEYDOWN) {
            if (event.key.keysym.scancode == SDL_SCANCODE_ESCAPE) {
                /* ESC 暂停 */
                extern GameState PauseState;
                Game_PushState(game, &PauseState);
            }
            if (event.key.keysym.scancode == SDL_SCANCODE_P) {
                /* P 键游戏结束 */
                extern GameState GameOverState;
                Game_SwitchState(game, &GameOverState);
            }
        }
    }
}
void Playing_Update(Game* game, float delta) {
    const Uint8* keys = SDL_GetKeyboardState(NULL);
    float speed = 300.0f;
    if (keys[SDL_SCANCODE_W] || keys[SDL_SCANCODE_UP])
        playing_data.y -= speed * delta;
    if (keys[SDL_SCANCODE_S] || keys[SDL_SCANCODE_DOWN])
        playing_data.y += speed * delta;
    if (keys[SDL_SCANCODE_A] || keys[SDL_SCANCODE_LEFT])
        playing_data.x -= speed * delta;
    if (keys[SDL_SCANCODE_D] || keys[SDL_SCANCODE_RIGHT])
        playing_data.x += speed * delta;

    /* 边界 */
    if (playing_data.x < 0) playing_data.x = 0;
    if (playing_data.x > 780) playing_data.x = 780;
    if (playing_data.y < 0) playing_data.y = 0;
    if (playing_data.y > 580) playing_data.y = 580;

    game->score += (int)(delta * 10);
}
void Playing_Render(Game* game) {
    SDL_SetRenderDrawColor(game->renderer, 20, 40, 30, 255);
    SDL_RenderClear(game->renderer);

    /* 绘制玩家 */
    SDL_SetRenderDrawColor(game->renderer, 100, 200, 255, 255);
    SDL_Rect player = {(int)playing_data.x, (int)playing_data.y, 20, 20};
    SDL_RenderFillRect(game->renderer, &player);

    /* 绘制分数（用矩形长度表示） */
    SDL_SetRenderDrawColor(game->renderer, 255, 255, 100, 255);
    SDL_Rect score_bar = {10, 10, game->score / 10, 20};
    SDL_RenderFillRect(game->renderer, &score_bar);

    SDL_RenderPresent(game->renderer);
}

GameState PlayingState = {
    .name = "Playing",
    .OnEnter = Playing_OnEnter,
    .OnExit = Playing_OnExit,
    .HandleInput = Playing_HandleInput,
    .Update = Playing_Update,
    .Render = Playing_Render
};

/* ============ 暂停状态 ============ */
int Pause_OnEnter(Game* game) {
    printf("  进入暂停\n");
    return 0;
}
void Pause_OnExit(Game* game) {
    printf("  退出暂停\n");
}
void Pause_HandleInput(Game* game) {
    SDL_Event event;
    while (SDL_PollEvent(&event)) {
        if (event.type == SDL_QUIT) game->running = SDL_FALSE;
        if (event.type == SDL_KEYDOWN) {
            if (event.key.keysym.scancode == SDL_SCANCODE_ESCAPE ||
                event.key.keysym.scancode == SDL_SCANCODE_P) {
                Game_PopState(game);  /* 返回游戏 */
            }
            if (event.key.keysym.scancode == SDL_SCANCODE_Q) {
                /* Q 退出到主菜单 */
                Game_PopState(game);  /* 弹出暂停 */
                extern GameState MenuState;
                Game_SwitchState(game, &MenuState);  /* 切换菜单 */
            }
        }
    }
}
void Pause_Update(Game* game, float delta) {
    /* 暂停状态不更新游戏逻辑 */
}
void Pause_Render(Game* game) {
    /* 先渲染下层状态（游戏画面） */
    if (game->state_count >= 2) {
        GameState* below = game->state_stack[game->state_count - 2];
        if (below->Render) below->Render(game);
    }

    /* 再渲染半透明遮罩 */
    SDL_SetRenderDrawBlendMode(game->renderer, SDL_BLENDMODE_BLEND);
    SDL_SetRenderDrawColor(game->renderer, 0, 0, 0, 150);
    SDL_Rect overlay = {0, 0, 800, 600};
    SDL_RenderFillRect(game->renderer, &overlay);

    /* 绘制暂停文字（用矩形代替） */
    SDL_SetRenderDrawColor(game->renderer, 255, 255, 255, 255);
    SDL_Rect text_bg = {300, 280, 200, 40};
    SDL_RenderFillRect(game->renderer, &text_bg);

    SDL_RenderPresent(game->renderer);
}

GameState PauseState = {
    .name = "Pause",
    .OnEnter = Pause_OnEnter,
    .OnExit = Pause_OnExit,
    .HandleInput = Pause_HandleInput,
    .Update = Pause_Update,
    .Render = Pause_Render
};

/* ============ 游戏结束状态 ============ */
int GameOver_OnEnter(Game* game) {
    printf("  游戏结束，得分: %d\n", game->score);
    return 0;
}
void GameOver_OnExit(Game* game) {}
void GameOver_HandleInput(Game* game) {
    SDL_Event event;
    while (SDL_PollEvent(&event)) {
        if (event.type == SDL_QUIT) game->running = SDL_FALSE;
        if (event.type == SDL_KEYDOWN) {
            if (event.key.keysym.scancode == SDL_SCANCODE_RETURN) {
                extern GameState MenuState;
                Game_SwitchState(game, &MenuState);
            }
            if (event.key.keysym.scancode == SDL_SCANCODE_ESCAPE) {
                game->running = SDL_FALSE;
            }
        }
    }
}
void GameOver_Update(Game* game, float delta) {}
void GameOver_Render(Game* game) {
    SDL_SetRenderDrawColor(game->renderer, 60, 20, 20, 255);
    SDL_RenderClear(game->renderer);

    /* 用矩形表示游戏结束文字 */
    SDL_SetRenderDrawColor(game->renderer, 255, 100, 100, 255);
    SDL_Rect text = {250, 250, 300, 60};
    SDL_RenderFillRect(game->renderer, &text);

    /* 分数条 */
    SDL_SetRenderDrawColor(game->renderer, 255, 255, 100, 255);
    SDL_Rect score_bar = {200, 350, game->score / 2, 20};
    SDL_RenderFillRect(game->renderer, &score_bar);

    SDL_RenderPresent(game->renderer);
}

GameState GameOverState = {
    .name = "GameOver",
    .OnEnter = GameOver_OnEnter,
    .OnExit = GameOver_OnExit,
    .HandleInput = GameOver_HandleInput,
    .Update = GameOver_Update,
    .Render = GameOver_Render
};

/* ============ 主函数 ============ */
int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);

    Game game = {0};
    game.window = SDL_CreateWindow(
        "状态管理示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN);
    game.renderer = SDL_CreateRenderer(game.window, -1,
        SDL_RENDERER_ACCELERATED);
    game.running = SDL_TRUE;
    game.last_frame_time = SDL_GetTicks();

    /* 初始状态：主菜单 */
    Game_PushState(&game, &MenuState);

    printf("操作说明:\n");
    printf("  菜单: 回车开始游戏\n");
    printf("  游戏: WASD移动, ESC暂停, P结束游戏\n");
    printf("  暂停: ESC/P继续, Q退出到菜单\n");
    printf("  结束: 回车返回菜单\n\n");

    /* 主循环 */
    while (game.running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - game.last_frame_time) / 1000.0f;
        game.last_frame_time = current_time;
        if (delta > 0.1f) delta = 0.1f;

        GameState* top = Game_GetTopState(&game);
        if (top) {
            top->HandleInput(&game);
            top->Update(&game, delta);
            top->Render(&game);
        } else {
            game.running = SDL_FALSE;
        }
    }

    /* 清理所有状态 */
    while (game.state_count > 0) {
        Game_PopState(&game);
    }

    SDL_DestroyRenderer(game.renderer);
    SDL_DestroyWindow(game.window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 游戏状态管理将每个状态封装为独立对象，包含 OnEnter/OnExit/Update/Render 四个方法
- 状态栈模式支持状态叠加（如暂停界面叠加在游戏画面上），栈顶状态活跃
- 三种状态切换：PUSH（压入）、POP（弹出）、SWITCH（替换）
- 每个状态独立管理资源，OnEnter 加载，OnExit 释放
- 暂停状态通过先渲染下层状态再渲染遮罩实现"游戏画面 + 暂停界面"效果
- **常见坑**：状态切换在 HandleInput 中发生时，当前帧后续的 Update/Render 应跳过（否则操作已销毁的状态会崩溃）；状态间数据传递要明确机制，避免全局变量泛滥；PopState 后不要继续访问被弹出的状态

# 第2章 游戏对象系统

游戏世界由大量对象组成：玩家、敌人、子弹、道具、地形等。如何高效组织和管理这些对象是游戏架构的核心问题。本章讲解游戏对象的设计模式，从简单的继承体系到现代的实体组件系统（ECS）。

## 第4讲 游戏对象与组件设计

### 概念

游戏对象（Game Object）是游戏中所有实体的基类。本讲讲解如何设计游戏对象的类层次结构，以及组件模式（Component Pattern）如何解决深层继承的问题。

传统的面向对象设计采用继承体系：GameObject → Character → Player / Enemy。但这种设计在游戏开发中会遇到"钻石继承"和"功能组合困难"的问题。组件模式通过将功能拆分为独立组件（渲染、物理、AI），通过组合而非继承实现功能复用。

### 原理

**继承体系的问题**：

考虑一个游戏有玩家、飞行敌人、地面敌人、Boss。继承设计可能是：
```
GameObject
├── Character
│   ├── Player
│   └── Enemy
│       ├── GroundEnemy
│       ├── FlyingEnemy  （需要飞行能力）
│       └── Boss         （需要飞行能力 + 特殊技能）
```

问题：
1. FlyingEnemy 和 Boss 都需要飞行能力，但飞行能力在哪个基类？
2. 如果放在 Enemy 中，GroundEnemy 也有飞行能力（错误）
3. 如果放在 FlyingEnemy 中，Boss 无法复用
4. 多继承会导致钻石继承问题

**组件模式（Component Pattern）**：

将功能拆分为独立组件，游戏对象持有所需组件的引用：
- `TransformComponent`：位置、旋转、缩放
- `PhysicsComponent`：速度、加速度、碰撞体
- `RenderComponent`：纹理、动画
- `InputComponent`：输入处理
- `AIComponent`：AI 行为
- `HealthComponent`：生命值

一个飞行敌人 = Transform + Physics + Render + AI + FlyingPhysics
一个地面敌人 = Transform + Physics + Render + AI
一个玩家 = Transform + Physics + Render + Input + Health

**组件的优势**：
1. 功能自由组合，无需多重继承
2. 新增功能只需新增组件类型，不修改现有代码（开闭原则）
3. 组件可独立测试和复用
4. 便于数据驱动设计（从配置文件加载组件）

**组件的通信**：组件需要相互访问（如 AI 组件需要修改 Physics 组件的速度）。解决方案：
1. 直接引用：组件持有其他组件的指针
2. 消息系统：组件发送消息，其他组件订阅
3. 共享数据：游戏对象维护共享数据字典

**更新顺序**：组件更新顺序很重要。通常顺序：Input → AI → Physics → Collision → Render。错误顺序会导致一帧延迟或状态不一致。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

/* ============ 组件定义 ============ */

/* 变换组件：位置和尺寸 */
typedef struct {
    float x, y;
    int width, height;
} TransformComponent;

/* 物理组件：速度 */
typedef struct {
    float vx, vy;
} PhysicsComponent;

/* 渲染组件：颜色（简化，实际应有纹理） */
typedef struct {
    Uint8 r, g, b, a;
} RenderComponent;

/* 生命值组件 */
typedef struct {
    int max_hp;
    int current_hp;
    SDL_bool invincible;
} HealthComponent;

/* AI 组件：简单的巡逻行为 */
typedef struct {
    float patrol_min_x, patrol_max_x;
    float speed;
    int direction;  /* 1 或 -1 */
} AIComponent;

/* ============ 游戏对象 ============ */

#define MAX_COMPONENTS 8

typedef enum {
    COMP_TRANSFORM = 0,
    COMP_PHYSICS,
    COMP_RENDER,
    COMP_HEALTH,
    COMP_AI,
    COMP_COUNT
} ComponentType;

typedef struct {
    int id;
    char name[32];
    SDL_bool active;

    /* 组件数组：NULL 表示无此组件 */
    void* components[COMP_COUNT];
    SDL_bool has_component[COMP_COUNT];
} GameObject;

/* 创建游戏对象 */
GameObject* GameObject_Create(const char* name) {
    static int next_id = 1;
    GameObject* obj = (GameObject*)calloc(1, sizeof(GameObject));
    obj->id = next_id++;
    strncpy(obj->name, name, 31);
    obj->active = SDL_TRUE;
    return obj;
}

/* 添加组件 */
void GameObject_AddComponent(GameObject* obj, ComponentType type, void* comp) {
    obj->components[type] = comp;
    obj->has_component[type] = SDL_TRUE;
}

/* 获取组件 */
void* GameObject_GetComponent(GameObject* obj, ComponentType type) {
    if (!obj->has_component[type]) return NULL;
    return obj->components[type];
}

/* 销毁游戏对象 */
void GameObject_Destroy(GameObject* obj) {
    for (int i = 0; i < COMP_COUNT; i++) {
        if (obj->has_component[i] && obj->components[i]) {
            free(obj->components[i]);
        }
    }
    free(obj);
}

/* ============ 系统函数（操作组件） ============ */

/* 输入系统：处理玩家输入 */
void InputSystem_Update(GameObject* obj, float delta) {
    if (!obj->active) return;
    PhysicsComponent* phys = (PhysicsComponent*)GameObject_GetComponent(obj, COMP_PHYSICS);
    if (!phys) return;

    /* 假设有输入组件的对象是玩家 */
    const Uint8* keys = SDL_GetKeyboardState(NULL);
    float speed = 200.0f;
    phys->vx = 0;
    phys->vy = 0;
    if (keys[SDL_SCANCODE_LEFT])  phys->vx = -speed;
    if (keys[SDL_SCANCODE_RIGHT]) phys->vx = speed;
    if (keys[SDL_SCANCODE_UP])    phys->vy = -speed;
    if (keys[SDL_SCANCODE_DOWN])  phys->vy = speed;
}

/* AI 系统：处理敌人巡逻 */
void AISystem_Update(GameObject* obj, float delta) {
    if (!obj->active) return;
    AIComponent* ai = (AIComponent*)GameObject_GetComponent(obj, COMP_AI);
    TransformComponent* trans = (TransformComponent*)GameObject_GetComponent(obj, COMP_TRANSFORM);
    PhysicsComponent* phys = (PhysicsComponent*)GameObject_GetComponent(obj, COMP_PHYSICS);
    if (!ai || !trans || !phys) return;

    /* 巡逻逻辑 */
    phys->vx = ai->speed * ai->direction;
    phys->vy = 0;

    /* 到达边界则转向 */
    if (trans->x <= ai->patrol_min_x) ai->direction = 1;
    if (trans->x >= ai->patrol_max_x) ai->direction = -1;
}

/* 物理系统：更新位置 */
void PhysicsSystem_Update(GameObject* obj, float delta) {
    if (!obj->active) return;
    TransformComponent* trans = (TransformComponent*)GameObject_GetComponent(obj, COMP_TRANSFORM);
    PhysicsComponent* phys = (PhysicsComponent*)GameObject_GetComponent(obj, COMP_PHYSICS);
    if (!trans || !phys) return;

    trans->x += phys->vx * delta;
    trans->y += phys->vy * delta;
}

/* 渲染系统 */
void RenderSystem_Render(GameObject* obj, SDL_Renderer* renderer) {
    if (!obj->active) return;
    TransformComponent* trans = (TransformComponent*)GameObject_GetComponent(obj, COMP_TRANSFORM);
    RenderComponent* render = (RenderComponent*)GameObject_GetComponent(obj, COMP_RENDER);
    if (!trans || !render) return;

    SDL_SetRenderDrawColor(renderer, render->r, render->g, render->b, render->a);
    SDL_Rect rect = {(int)trans->x, (int)trans->y, trans->width, trans->height};
    SDL_RenderFillRect(renderer, &rect);
}

/* ============ 工厂函数：创建预设对象 ============ */

GameObject* CreatePlayer(float x, float y) {
    GameObject* obj = GameObject_Create("Player");

    TransformComponent* trans = calloc(1, sizeof(TransformComponent));
    trans->x = x; trans->y = y; trans->width = 30; trans->height = 30;
    GameObject_AddComponent(obj, COMP_TRANSFORM, trans);

    PhysicsComponent* phys = calloc(1, sizeof(PhysicsComponent));
    GameObject_AddComponent(obj, COMP_PHYSICS, phys);

    RenderComponent* render = calloc(1, sizeof(RenderComponent));
    render->r = 100; render->g = 200; render->b = 255; render->a = 255;
    GameObject_AddComponent(obj, COMP_RENDER, render);

    HealthComponent* health = calloc(1, sizeof(HealthComponent));
    health->max_hp = 100; health->current_hp = 100;
    GameObject_AddComponent(obj, COMP_HEALTH, health);

    return obj;
}

GameObject* CreatePatrolEnemy(float x, float y, float min_x, float max_x) {
    GameObject* obj = GameObject_Create("PatrolEnemy");

    TransformComponent* trans = calloc(1, sizeof(TransformComponent));
    trans->x = x; trans->y = y; trans->width = 25; trans->height = 25;
    GameObject_AddComponent(obj, COMP_TRANSFORM, trans);

    PhysicsComponent* phys = calloc(1, sizeof(PhysicsComponent));
    GameObject_AddComponent(obj, COMP_PHYSICS, phys);

    RenderComponent* render = calloc(1, sizeof(RenderComponent));
    render->r = 255; render->g = 100; render->b = 100; render->a = 255;
    GameObject_AddComponent(obj, COMP_RENDER, render);

    AIComponent* ai = calloc(1, sizeof(AIComponent));
    ai->patrol_min_x = min_x; ai->patrol_max_x = max_x;
    ai->speed = 100.0f; ai->direction = 1;
    GameObject_AddComponent(obj, COMP_AI, ai);

    return obj;
}

/* ============ 主程序 ============ */
int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow(
        "组件模式示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED);

    /* 创建游戏对象 */
    GameObject* player = CreatePlayer(400, 300);
    GameObject* enemy1 = CreatePatrolEnemy(100, 200, 50, 350);
    GameObject* enemy2 = CreatePatrolEnemy(500, 400, 450, 750);

    GameObject* objects[] = {player, enemy1, enemy2};
    int object_count = 3;

    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;
        if (delta > 0.1f) delta = 0.1f;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
        }

        /* 按系统类型批量更新 */
        /* 玩家用输入系统，敌人用 AI 系统 */
        InputSystem_Update(player, delta);
        AISystem_Update(enemy1, delta);
        AISystem_Update(enemy2, delta);

        /* 物理系统更新所有对象 */
        for (int i = 0; i < object_count; i++) {
            PhysicsSystem_Update(objects[i], delta);
        }

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);
        for (int i = 0; i < object_count; i++) {
            RenderSystem_Render(objects[i], renderer);
        }
        SDL_RenderPresent(renderer);
    }

    /* 清理 */
    for (int i = 0; i < object_count; i++) {
        GameObject_Destroy(objects[i]);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 组件模式通过组合而非继承实现功能复用，解决深层继承的钻石继承问题
- 每个组件负责单一功能（Transform、Physics、Render、AI、Health 等）
- 游戏对象持有组件引用，通过 `GetComponent` 获取
- 系统函数按类型批量处理所有对象的对应组件（InputSystem、AISystem、PhysicsSystem）
- 工厂函数封装常用对象组合，简化创建
- **常见坑**：组件间通信要避免循环依赖；组件销毁顺序要正确（先释放组件内存再释放对象）；系统更新顺序固定（Input → AI → Physics → Render）

## 第5讲 实体管理系统

### 概念

上一讲实现了组件模式的基础，本讲将其升级为完整的实体组件系统（Entity Component System, ECS）。ECS 是现代游戏引擎的主流架构，将实体（Entity）、组件（Component）、系统（System）三者严格分离，通过数据导向设计提升性能和灵活性。

### 原理

**ECS 三要素**：

1. **实体（Entity）**：纯粹的 ID，不包含任何数据或逻辑。只是一个标识符，表示"这个对象存在"。

2. **组件（Component）**：纯数据结构，不包含任何逻辑。每个组件类型存储在连续的内存数组中（数据导向设计），便于缓存命中和批量处理。

3. **系统（System）**：纯逻辑，遍历拥有特定组件集合的实体，更新其组件数据。系统之间通过组件数据通信。

**与传统 OOP 的区别**：

| 传统 OOP | ECS |
|---------|-----|
| 对象包含数据和方法 | 实体无数据无方法 |
| 功能通过继承获得 | 功能通过组件组合 |
| 对象分散在内存各处 | 组件数据连续存储 |
| 方法调用分散 | 系统批量处理 |

**数据导向设计（Data-Oriented Design）**：

传统 OOP 中，一个对象的数据分散在堆内存各处，访问时缓存命中率低。ECS 将同一类型组件存储在连续数组中，系统遍历时 CPU 缓存能预取后续数据，大幅提升性能。

```
传统：Player对象 → [Transform][Physics][Render][AI]  (分散)
ECS：  Transform数组 → [T1][T2][T3][T4]...  (连续，缓存友好)
```

**Archetype（原型）设计**：

拥有相同组件集合的实体归为一个 Archetype。系统只需遍历匹配的 Archetype，无需逐个检查组件。这是现代 ECS（如 Unity DOTS、Bevy）的核心优化。

**组件位掩码**：

用位掩码标识实体拥有的组件集合。系统查询时用位运算快速判断实体是否匹配，O(1) 复杂度。

```c
typedef Uint32 ComponentMask;
#define MASK_TRANSFORM  (1 << 0)
#define MASK_PHYSICS    (1 << 1)
#define MASK_RENDER     (1 << 2)

/* 系统需要 Transform + Physics */
ComponentMask required = MASK_TRANSFORM | MASK_PHYSICS;
if ((entity_mask & required) == required) { /* 匹配 */ }
```

**实体生命周期**：
- 创建：分配 ID，初始掩码为 0
- 添加组件：设置掩码位，存储组件数据
- 移除组件：清除掩码位，可选保留或删除数据
- 销毁：回收 ID，清除所有组件数据

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAX_ENTITIES 1024
#define MAX_COMPONENT_TYPES 8

/* 组件类型枚举 */
typedef enum {
    COMP_TRANSFORM = 0,
    COMP_VELOCITY,
    COMP_SPRITE,
    COMP_HEALTH,
    COMP_AI_PATROL,
    COMP_PLAYER_INPUT,
    COMP_COUNT
} ComponentType;

/* 组件位掩码 */
typedef Uint32 ComponentMask;
#define MASK(c) (1u << (c))

/* ============ 组件数据结构 ============ */
typedef struct { float x, y; int w, h; } C_Transform;
typedef struct { float vx, vy; } C_Velocity;
typedef struct { Uint8 r, g, b, a; } C_Sprite;
typedef struct { int hp, max_hp; } C_Health;
typedef struct { float min_x, max_x, speed; int dir; } C_AIPatrol;
typedef struct { float speed; } C_PlayerInput;

/* ============ ECS 世界 ============ */
typedef struct {
    /* 实体管理 */
    ComponentMask entity_masks[MAX_ENTITIES];
    SDL_bool entity_active[MAX_ENTITIES];
    int entity_count;

    /* 组件存储（每个类型一个数组） */
    C_Transform    transforms[MAX_ENTITIES];
    C_Velocity     velocities[MAX_ENTITIES];
    C_Sprite       sprites[MAX_ENTITIES];
    C_Health       healths[MAX_ENTITIES];
    C_AIPatrol     ai_patrols[MAX_ENTITIES];
    C_PlayerInput  player_inputs[MAX_ENTITIES];
} World;

void World_Init(World* world) {
    memset(world, 0, sizeof(World));
    world->entity_count = 0;
}

/* 创建实体，返回 ID */
int World_CreateEntity(World* world) {
    if (world->entity_count >= MAX_ENTITIES) return -1;
    int id = world->entity_count++;
    world->entity_masks[id] = 0;
    world->entity_active[id] = SDL_TRUE;
    return id;
}

/* 添加组件 */
void World_AddTransform(World* w, int id, C_Transform c) {
    w->transforms[id] = c; w->entity_masks[id] |= MASK(COMP_TRANSFORM);
}
void World_AddVelocity(World* w, int id, C_Velocity c) {
    w->velocities[id] = c; w->entity_masks[id] |= MASK(COMP_VELOCITY);
}
void World_AddSprite(World* w, int id, C_Sprite c) {
    w->sprites[id] = c; w->entity_masks[id] |= MASK(COMP_SPRITE);
}
void World_AddHealth(World* w, int id, C_Health c) {
    w->healths[id] = c; w->entity_masks[id] |= MASK(COMP_HEALTH);
}
void World_AddAIPatrol(World* w, int id, C_AIPatrol c) {
    w->ai_patrols[id] = c; w->entity_masks[id] |= MASK(COMP_AI_PATROL);
}
void World_AddPlayerInput(World* w, int id, C_PlayerInput c) {
    w->player_inputs[id] = c; w->entity_masks[id] |= MASK(COMP_PLAYER_INPUT);
}

/* 销毁实体 */
void World_DestroyEntity(World* w, int id) {
    w->entity_active[id] = SDL_FALSE;
    w->entity_masks[id] = 0;
}

/* ============ 系统 ============ */

/* 玩家输入系统：处理有 PlayerInput + Velocity 的实体 */
void System_PlayerInput(World* w, float delta) {
    ComponentMask required = MASK(COMP_PLAYER_INPUT) | MASK(COMP_VELOCITY);
    const Uint8* keys = SDL_GetKeyboardState(NULL);

    for (int i = 0; i < w->entity_count; i++) {
        if (!w->entity_active[i]) continue;
        if ((w->entity_masks[i] & required) != required) continue;

        C_PlayerInput* input = &w->player_inputs[i];
        C_Velocity* vel = &w->velocities[i];
        vel->vx = 0; vel->vy = 0;
        if (keys[SDL_SCANCODE_LEFT])  vel->vx = -input->speed;
        if (keys[SDL_SCANCODE_RIGHT]) vel->vx = input->speed;
        if (keys[SDL_SCANCODE_UP])    vel->vy = -input->speed;
        if (keys[SDL_SCANCODE_DOWN])  vel->vy = input->speed;
    }
}

/* AI 巡逻系统：处理有 AIPatrol + Velocity + Transform 的实体 */
void System_AIPatrol(World* w, float delta) {
    ComponentMask required = MASK(COMP_AI_PATROL) | MASK(COMP_VELOCITY) | MASK(COMP_TRANSFORM);

    for (int i = 0; i < w->entity_count; i++) {
        if (!w->entity_active[i]) continue;
        if ((w->entity_masks[i] & required) != required) continue;

        C_AIPatrol* ai = &w->ai_patrols[i];
        C_Velocity* vel = &w->velocities[i];
        C_Transform* trans = &w->transforms[i];

        vel->vx = ai->speed * ai->dir;
        vel->vy = 0;
        if (trans->x <= ai->min_x) ai->dir = 1;
        if (trans->x >= ai->max_x) ai->dir = -1;
    }
}

/* 移动系统：处理有 Transform + Velocity 的实体 */
void System_Movement(World* w, float delta) {
    ComponentMask required = MASK(COMP_TRANSFORM) | MASK(COMP_VELOCITY);

    for (int i = 0; i < w->entity_count; i++) {
        if (!w->entity_active[i]) continue;
        if ((w->entity_masks[i] & required) != required) continue;

        C_Transform* t = &w->transforms[i];
        C_Velocity* v = &w->velocities[i];
        t->x += v->vx * delta;
        t->y += v->vy * delta;

        /* 边界 */
        if (t->x < 0) t->x = 0;
        if (t->x > 800 - t->w) t->x = 800 - t->w;
        if (t->y < 0) t->y = 0;
        if (t->y > 600 - t->h) t->y = 600 - t->h;
    }
}

/* 渲染系统：处理有 Transform + Sprite 的实体 */
void System_Render(World* w, SDL_Renderer* renderer) {
    ComponentMask required = MASK(COMP_TRANSFORM) | MASK(COMP_SPRITE);

    for (int i = 0; i < w->entity_count; i++) {
        if (!w->entity_active[i]) continue;
        if ((w->entity_masks[i] & required) != required) continue;

        C_Transform* t = &w->transforms[i];
        C_Sprite* s = &w->sprites[i];
        SDL_SetRenderDrawColor(renderer, s->r, s->g, s->b, s->a);
        SDL_Rect rect = {(int)t->x, (int)t->y, t->w, t->h};
        SDL_RenderFillRect(renderer, &rect);
    }
}

/* ============ 主程序 ============ */
int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow(
        "ECS 示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED);

    World world;
    World_Init(&world);

    /* 创建玩家 */
    int player = World_CreateEntity(&world);
    World_AddTransform(&world, player, (C_Transform){400, 300, 30, 30});
    World_AddVelocity(&world, player, (C_Velocity){0, 0});
    World_AddSprite(&world, player, (C_Sprite){100, 200, 255, 255});
    World_AddHealth(&world, player, (C_Health){100, 100});
    World_AddPlayerInput(&world, player, (C_PlayerInput){250});

    /* 创建巡逻敌人 */
    int enemy1 = World_CreateEntity(&world);
    World_AddTransform(&world, enemy1, (C_Transform){100, 200, 25, 25});
    World_AddVelocity(&world, enemy1, (C_Velocity){0, 0});
    World_AddSprite(&world, enemy1, (C_Sprite){255, 100, 100, 255});
    World_AddAIPatrol(&world, enemy1, (C_AIPatrol){50, 350, 120, 1});

    int enemy2 = World_CreateEntity(&world);
    World_AddTransform(&world, enemy2, (C_Transform){500, 400, 25, 25});
    World_AddVelocity(&world, enemy2, (C_Velocity){0, 0});
    World_AddSprite(&world, enemy2, (C_Sprite){255, 150, 50, 255});
    World_AddAIPatrol(&world, enemy2, (C_AIPatrol){450, 750, 80, -1});

    /* 创建静态装饰物（只有 Transform + Sprite） */
    int decor = World_CreateEntity(&world);
    World_AddTransform(&world, decor, (C_Transform){350, 100, 100, 20});
    World_AddSprite(&world, decor, (C_Sprite){100, 100, 100, 255});

    printf("创建了 %d 个实体\n", world.entity_count);
    printf("操作：方向键移动玩家，ESC 退出\n");

    Uint32 last_time = SDL_GetTicks();

    while (running) {
        Uint32 current_time = SDL_GetTicks();

        last_time = current_time;
        if (delta > 0.1f) delta = 0.1f;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&

        System_PlayerInput(&world, delta);
        System_AIPatrol(&world, delta);
```

### 总结

- ECS 将实体（ID）、组件（数据）、系统（逻辑）严格分离
- 组件数据连续存储，系统批量处理，缓存友好性能高
- 位掩码快速查询实体是否拥有特定组件集合，O(1) 复杂度
- 系统按固定顺序执行：Input → AI → Movement → Collision → Render
- 新增功能只需新增组件类型和对应系统，不修改现有代码
- **常见坑**：实体销毁后系统仍可能访问其组件，需用 active 标志过滤；组件数组大小固定（MAX_ENTITIES），大量实体需改用动态数组或分块；系统遍历中修改组件掩码（如添加/删除组件）会导致迭代器失效

## 第6讲 场景管理与空间分区

### 概念

随着游戏对象增多，碰撞检测和查询的效率成为瓶颈。本讲讲解场景管理技术，包括空间分区（Spatial Partitioning）、四叉树（Quadtree）、网格分区（Grid Partition）等，将 O(n²) 的碰撞检测优化到接近 O(n)。

### 原理

**暴力碰撞检测的问题**：

n 个对象两两检测碰撞，需要 n*(n-1)/2 次，复杂度 O(n²)。100 个对象需要 4950 次检测，1000 个对象需要 499500 次。这在大型游戏中不可接受。

**空间分区的核心思想**：

将游戏空间划分为多个区域，每个对象归入其所在区域。碰撞检测时只检测同一区域（或相邻区域）内的对象，大幅减少检测次数。

**网格分区（Uniform Grid）**：

将空间划分为均匀的网格单元，每个单元维护一个对象列表。对象移动时更新所在单元。

优点：实现简单，查询快
缺点：对象大小差异大时效率低（大对象跨多个单元）

适用场景：对象大小相近的游戏（如塔防、弹幕游戏）

**四叉树（Quadtree）**：

递归地将 2D 空间划分为四个象限。当某个象限内对象超过阈值时，继续细分。对象只存储在叶子节点。

优点：自适应空间密度，稀疏区域少分割
缺点：实现复杂，对象移动时更新开销大

适用场景：对象分布不均的游戏（如开放世界）

**BVH（Bounding Volume Hierarchy）**：

用层次化的包围盒（AABB）组织对象。每个节点包含其子节点的合并包围盒。查询时通过包围盒测试快速排除不相关分支。

优点：动态对象更新高效（只需更新路径上的节点）
缺点：构建开销大

适用场景：动态场景（对象频繁移动）

**碰撞检测的两阶段**：

1. **Broad Phase（粗筛）**：用空间分区快速找出可能碰撞的对象对，O(n)
2. **Narrow Phase（精检）**：对候选对象对进行精确碰撞检测（AABB、SAT 等），O(k)（k 为候选对数）

**网格分区的实现要点**：
- 网格大小应略大于最大对象尺寸
- 对象跨多个单元时，可注册到所有覆盖单元，或只注册到中心所在单元
- 查询时检查当前单元及相邻 8 个单元

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>
#include <stdlib.h>

#define WINDOW_W 800
#define WINDOW_H 600
#define CELL_SIZE 80
#define GRID_COLS (WINDOW_W / CELL_SIZE + 1)
#define GRID_ROWS (WINDOW_H / CELL_SIZE + 1)
#define MAX_OBJECTS_PER_CELL 64
#define MAX_OBJECTS 500

/* 游戏对象 */
typedef struct {
    int id;
    float x, y;
    int radius;
    SDL_bool active;
} GameObject;

/* 网格单元 */
typedef struct {
    int object_ids[MAX_OBJECTS_PER_CELL];
    int count;
} GridCell;

/* 网格 */
typedef struct {
    GridCell cells[GRID_COLS][GRID_ROWS];
} Grid;

void Grid_Clear(Grid* grid) {
    memset(grid, 0, sizeof(Grid));
}

/* 计算对象所在的网格坐标 */
void Grid_GetCell(float x, float y, int* cx, int* cy) {
    *cx = (int)(x / CELL_SIZE);
    *cy = (int)(y / CELL_SIZE);
    if (*cx < 0) *cx = 0;
    if (*cx >= GRID_COLS) *cx = GRID_COLS - 1;
    if (*cy < 0) *cy = 0;
    if (*cy >= GRID_ROWS) *cy = GRID_ROWS - 1;
}

/* 将对象插入网格 */
void Grid_Insert(Grid* grid, GameObject* obj) {
    int cx, cy;
    Grid_GetCell(obj->x, obj->y, &cx, &cy);
    GridCell* cell = &grid->cells[cx][cy];
    if (cell->count < MAX_OBJECTS_PER_CELL) {
        cell->object_ids[cell->count++] = obj->id;
    }
}

/* 查询附近对象（当前单元 + 相邻 8 单元） */
void Grid_Query(Grid* grid, float x, float y, float radius,
                int* result_ids, int* result_count, int max_results) {
    int cx, cy;
    Grid_GetCell(x, y, &cx, &cy);
    *result_count = 0;

    /* 计算需要查询的单元范围（考虑半径） */
    int min_cx = cx, max_cx = cx, min_cy = cy, max_cy = cy;
    int r_cells = (int)(radius / CELL_SIZE) + 1;
    min_cx -= r_cells; max_cx += r_cells;
    min_cy -= r_cells; max_cy += r_cells;
    if (min_cx < 0) min_cx = 0;
    if (max_cx >= GRID_COLS) max_cx = GRID_COLS - 1;
    if (min_cy < 0) min_cy = 0;
    if (max_cy >= GRID_ROWS) max_cy = GRID_ROWS - 1;

    for (int i = min_cx; i <= max_cx; i++) {
        for (int j = min_cy; j <= max_cy; j++) {
            GridCell* cell = &grid->cells[i][j];
            for (int k = 0; k < cell->count; k++) {
                int id = cell->object_ids[k];
                /* 去重（简化：实际应用哈希集合） */
                SDL_bool found = SDL_FALSE;
                for (int r = 0; r < *result_count; r++) {
                    if (result_ids[r] == id) { found = SDL_TRUE; break; }
                }
                if (!found && *result_count < max_results) {
                    result_ids[(*result_count)++] = id;
                }
            }
        }
    }
}

/* 圆形碰撞检测 */
SDL_Bool CheckCircleCollision(GameObject* a, GameObject* b) {
    float dx = a->x - b->x;
    float dy = a->y - b->y;
    float dist_sq = dx * dx + dy * dy;
    float radius_sum = a->radius + b->radius;
    return dist_sq < radius_sum * radius_sum;
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow(
        "空间分区示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        WINDOW_W, WINDOW_H, SDL_WINDOW_SHOWN);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED);

    /* 创建大量对象 */
    GameObject objects[MAX_OBJECTS];
    int object_count = 300;
    for (int i = 0; i < object_count; i++) {
        objects[i].id = i;
        objects[i].x = (float)(rand() % WINDOW_W);
        objects[i].y = (float)(rand() % WINDOW_H);
        objects[i].radius = 5 + rand() % 10;
        objects[i].active = SDL_TRUE;
        /* 随机速度 */
        objects[i].vx = (float)(rand() % 100 - 50);
        objects[i].vy = (float)(rand() % 100 - 50);
    }

    Grid grid;
    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();
    int collision_count = 0;
    int check_count = 0;

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;
        if (delta > 0.1f) delta = 0.1f;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
        }

        /* 更新对象位置 */
        for (int i = 0; i < object_count; i++) {
            if (!objects[i].active) continue;
            objects[i].x += objects[i].vx * delta;
            objects[i].y += objects[i].vy * delta;
            /* 边界反弹 */
            if (objects[i].x < 0 || objects[i].x > WINDOW_W) objects[i].vx *= -1;
            if (objects[i].y < 0 || objects[i].y > WINDOW_H) objects[i].vy *= -1;
        }

        /* 清空并重建网格 */
        Grid_Clear(&grid);
        for (int i = 0; i < object_count; i++) {
            if (objects[i].active) Grid_Insert(&grid, &objects[i]);
        }

        /* 使用空间分区进行碰撞检测 */
        collision_count = 0;
        check_count = 0;
        for (int i = 0; i < object_count; i++) {
            if (!objects[i].active) continue;
            /* 查询附近对象 */
            int nearby[64];
            int nearby_count;
            Grid_Query(&grid, objects[i].x, objects[i].y,
                       objects[i].radius * 2, nearby, &nearby_count, 64);

            for (int j = 0; j < nearby_count; j++) {
                int id = nearby[j];
                if (id <= i) continue;  /* 避免重复检测 */
                if (!objects[id].active) continue;
                check_count++;
                if (CheckCircleCollision(&objects[i], &objects[id])) {
                    collision_count++;
                    /* 碰撞处理：简单分离 */
                    float dx = objects[id].x - objects[i].x;
                    float dy = objects[id].y - objects[i].y;
                    float dist = sqrtf(dx * dx + dy * dy);
                    if (dist > 0) {
                        float overlap = (objects[i].radius + objects[id].radius - dist) / 2;
                        objects[i].x -= dx / dist * overlap;
                        objects[i].y -= dy / dist * overlap;
                        objects[id].x += dx / dist * overlap;
                        objects[id].y += dy / dist * overlap;
                    }
                }
            }
        }

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        /* 绘制网格（可视化） */
        SDL_SetRenderDrawColor(renderer, 40, 40, 50, 255);
        for (int i = 0; i <= GRID_COLS; i++) {
            SDL_RenderDrawLine(renderer, i * CELL_SIZE, 0,
                              i * CELL_SIZE, WINDOW_H);
        }
        for (int j = 0; j <= GRID_ROWS; j++) {
            SDL_RenderDrawLine(renderer, 0, j * CELL_SIZE,
                              WINDOW_W, j * CELL_SIZE);
        }

        /* 绘制对象 */
        for (int i = 0; i < object_count; i++) {
            if (!objects[i].active) continue;
            SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
            /* 用矩形近似圆形 */
            SDL_Rect r = {(int)objects[i].x - objects[i].radius,
                          (int)objects[i].y - objects[i].radius,
                          objects[i].radius * 2, objects[i].radius * 2};
            SDL_RenderFillRect(renderer, &r);
        }

        SDL_RenderPresent(renderer);

        /* 每秒打印统计 */
        static Uint32 stat_timer = 0;
        static int frame_count = 0;
        frame_count++;
        if (current_time - stat_timer >= 1000) {
            printf("对象: %d, 检测次数: %d, 碰撞: %d (暴力检测需要 %d 次)\n",
                   object_count, check_count, collision_count,
                   object_count * (object_count - 1) / 2);
            stat_timer = current_time;
            frame_count = 0;
        }
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 空间分区将 O(n²) 碰撞检测优化到接近 O(n)
- 网格分区实现简单，适合对象大小相近的场景
- 四叉树自适应空间密度，适合对象分布不均的场景
- BVH 适合动态场景，对象移动时更新高效
- 碰撞检测两阶段：Broad Phase（粗筛）+ Narrow Phase（精检）
- 网格大小应略大于最大对象尺寸，查询时检查相邻单元
- **常见坑**：对象跨多个单元时需注册到所有覆盖单元或只注册中心单元；网格重建每帧开销大，可增量更新；查询结果需去重（同一对象可能在多个单元）

## 第7讲 碰撞检测基础（AABB与圆形）

### 概念

碰撞检测（Collision Detection）判断两个游戏对象是否在空间上重叠。本讲讲解两种最常用的碰撞检测方法：轴对齐包围盒（AABB）和圆形碰撞，它们覆盖了 80% 的 2D 游戏碰撞需求。

### 原理

**AABB（Axis-Aligned Bounding Box）**：

用与坐标轴对齐的矩形包围对象。两个 AABB 碰撞的条件是：在 x 轴和 y 轴上都重叠。

```
A.x < B.x + B.w  且  A.x + A.w > B.x  （x 轴重叠）
A.y < B.y + B.h  且  A.y + A.h > B.y  （y 轴重叠）
```

两者同时成立则碰撞。

**AABB 的优势**：
- 计算极简，只需 4 次比较
- 适合矩形对象（砖块、平台、UI 元素）
- 易于实现碰撞响应（计算最小分离向量）

**AABB 的局限**：
- 只能处理轴对齐矩形，旋转对象不适用
- 对非矩形对象（圆形、三角形）精度低

**圆形碰撞**：

两个圆碰撞的条件是：圆心距离小于半径之和。

```
dx = A.x - B.x
dy = A.y - B.y
distance² = dx² + dy²
radius_sum = A.r + B.r
碰撞条件：distance² < radius_sum²
```

注意：比较距离平方而非距离，避免昂贵的 sqrt 计算。

**圆形碰撞的优势**：
- 适合球形对象（球、粒子、子弹）
- 旋转无关（圆旋转后不变）
- 碰撞响应自然（沿圆心连线分离）

**碰撞响应（Collision Response）**：

检测到碰撞后需要处理：
1. **分离**：将对象移开，消除重叠
2. **反弹**：根据弹性系数改变速度方向
3. **事件触发**：触发碰撞回调（扣血、得分等）

AABB 的最小分离向量（MTV, Minimum Translation Vector）计算：
- 计算 x 轴和 y 轴的重叠量
- 选择较小的一个作为分离方向
- 沿该方向移开对象

**碰撞掩码（Collision Mask）**：

实际游戏中不是所有对象都应碰撞（如玩家不应被自己子弹击中）。用碰撞掩码过滤：
- 每个对象有 category（类别）和 mask（可碰撞类别掩码）
- 两个对象碰撞需满足：`(A.category & B.mask) && (B.category & A.mask)`

```c
#include <SDL2/SDL.h>
#include <stdio.h>
#include <math.h>

/* ============ 碰撞体定义 ============ */

typedef struct {
    float x, y;  /* 左上角 */
    int w, h;
} AABB;

typedef struct {
    float x, y;  /* 圆心 */
    float r;
} Circle;

/* ============ 碰撞检测函数 ============ */

/* AABB vs AABB */
SDL_bool AABB_vs_AABB(AABB a, AABB b) {
    return (a.x < b.x + b.w && a.x + a.w > b.x &&
            a.y < b.y + b.h && a.y + a.h > b.y);
}

/* Circle vs Circle */
SDL_bool Circle_vs_Circle(Circle a, Circle b) {
    float dx = a.x - b.x;
    float dy = a.y - b.y;
    float dist_sq = dx * dx + dy * dy;
    float r_sum = a.r + b.r;
    return dist_sq < r_sum * r_sum;
}

/* AABB vs Circle */
SDL_bool AABB_vs_Circle(AABB box, Circle c) {
    /* 找到 AABB 上离圆心最近的点 */
    float closest_x = c.x;
    float closest_y = c.y;
    if (closest_x < box.x) closest_x = box.x;
    if (closest_x > box.x + box.w) closest_x = box.x + box.w;
    if (closest_y < box.y) closest_y = box.y;
    if (closest_y > box.y + box.h) closest_y = box.y + box.h;

    float dx = c.x - closest_x;
    float dy = c.y - closest_y;
    return (dx * dx + dy * dy) < (c.r * c.r);
}

/* ============ 碰撞响应 ============ */

/* 计算 AABB 碰撞的最小分离向量 */
typedef struct { float x, y; } Vec2;

Vec2 AABB_GetMTV(AABB a, AABB b) {
    Vec2 mtv = {0, 0};
    /* 计算两个方向的重叠 */
    float overlap_x = 0, overlap_y = 0;

    /* x 轴重叠 */
    if (a.x < b.x) {
        overlap_x = (a.x + a.w) - b.x;
    } else {
        overlap_x = (b.x + b.w) - a.x;
        overlap_x = -overlap_x;
    }

    /* y 轴重叠 */
    if (a.y < b.y) {
        overlap_y = (a.y + a.h) - b.y;
    } else {
        overlap_y = (b.y + b.h) - a.y;
        overlap_y = -overlap_y;
    }

    /* 选择较小重叠方向 */
    if (fabs(overlap_x) < fabs(overlap_y)) {
        mtv.x = overlap_x;
    } else {
        mtv.y = overlap_y;
    }
    return mtv;
}

/* 圆形碰撞分离 */
void Circle_Separate(Circle* a, Circle* b) {
    float dx = b->x - a->x;
    float dy = b->y - a->y;
    float dist = sqrtf(dx * dx + dy * dy);
    if (dist < 0.0001f) {
        /* 完全重合，随机方向分离 */
        dx = 1; dy = 0; dist = 1;
    }
    float overlap = (a->r + b->r - dist) / 2;
    float nx = dx / dist;
    float ny = dy / dist;
    a->x -= nx * overlap;
    a->y -= ny * overlap;
    b->x += nx * overlap;
    b->y += ny * overlap;
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow(
        "碰撞检测示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED);

    /* 玩家（AABB） */
    AABB player = {375, 275, 50, 50};
    float player_speed = 300;

    /* 静态方块（AABB） */
    AABB walls[] = {
        {100, 100, 100, 100},
        {600, 100, 100, 100},
        {100, 400, 100, 100},
        {600, 400, 100, 100},
        {350, 250, 100, 100}
    };
    int wall_count = 5;

    /* 圆形对象 */
    Circle balls[] = {
        {200, 300, 20, 150, 100},
        {600, 300, 25, -120, 80}
    };
    int ball_count = 2;

    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;
        if (delta > 0.1f) delta = 0.1f;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
        }

        /* 玩家移动 */
        const Uint8* keys = SDL_GetKeyboardState(NULL);
        float old_x = player.x, old_y = player.y;
        if (keys[SDL_SCANCODE_LEFT])  player.x -= player_speed * delta;
        if (keys[SDL_SCANCODE_RIGHT]) player.x += player_speed * delta;
        if (keys[SDL_SCANCODE_UP])    player.y -= player_speed * delta;
        if (keys[SDL_SCANCODE_DOWN])  player.y += player_speed * delta;

        /* 玩家与墙的碰撞（AABB vs AABB） */
        for (int i = 0; i < wall_count; i++) {
            if (AABB_vs_AABB(player, walls[i])) {
                Vec2 mtv = AABB_GetMTV(player, walls[i]);
                player.x += mtv.x;
                player.y += mtv.y;
            }
        }

        /* 玩家边界 */
        if (player.x < 0) player.x = 0;
        if (player.x > 800 - player.w) player.x = 800 - player.w;
        if (player.y < 0) player.y = 0;
        if (player.y > 600 - player.h) player.y = 600 - player.h;

        /* 圆球运动与碰撞 */
        for (int i = 0; i < ball_count; i++) {
            balls[i].x += balls[i].vx * delta;
            balls[i].y += balls[i].vy * delta;
            /* 边界反弹 */
            if (balls[i].x - balls[i].r < 0) {
                balls[i].x = balls[i].r; balls[i].vx *= -1;
            }
            if (balls[i].x + balls[i].r > 800) {
                balls[i].x = 800 - balls[i].r; balls[i].vx *= -1;
            }
            if (balls[i].y - balls[i].r < 0) {
                balls[i].y = balls[i].r; balls[i].vy *= -1;
            }
            if (balls[i].y + balls[i].r > 600) {
                balls[i].y = 600 - balls[i].r; balls[i].vy *= -1;
            }
        }

        /* 圆球之间碰撞 */
        for (int i = 0; i < ball_count; i++) {
            for (int j = i + 1; j < ball_count; j++) {
                if (Circle_vs_Circle(balls[i], balls[j])) {
                    Circle_Separate(&balls[i], &balls[j]);
                    /* 简单速度交换（弹性碰撞） */
                    float tvx = balls[i].vx, tvy = balls[i].vy;
                    balls[i].vx = balls[j].vx;
                    balls[i].vy = balls[j].vy;
                    balls[j].vx = tvx;
                    balls[j].vy = tvy;
                }
            }
        }

        /* 圆球与墙碰撞（AABB vs Circle） */
        for (int i = 0; i < ball_count; i++) {
            for (int j = 0; j < wall_count; j++) {
                if (AABB_vs_Circle(walls[j], balls[i])) {
                    /* 简单处理：反弹 */
                    float cx = walls[j].x + walls[j].w / 2.0f;
                    float cy = walls[j].y + walls[j].h / 2.0f;
                    float dx = balls[i].x - cx;
                    float dy = balls[i].y - cy;
                    if (fabs(dx) > fabs(dy)) {
                        balls[i].vx *= -1;
                        balls[i].x += (dx > 0 ? 1 : -1) * 5;
                    } else {
                        balls[i].vy *= -1;
                        balls[i].y += (dy > 0 ? 1 : -1) * 5;
                    }
                }
            }
        }

        /* 玩家与圆球碰撞检测（仅显示，不响应） */
        SDL_bool player_hit = SDL_FALSE;
        for (int i = 0; i < ball_count; i++) {
            if (AABB_vs_Circle(player, balls[i])) {
                player_hit = SDL_TRUE;
            }
        }

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        /* 绘制墙 */
        SDL_SetRenderDrawColor(renderer, 100, 100, 120, 255);
        for (int i = 0; i < wall_count; i++) {
            SDL_Rect r = {(int)walls[i].x, (int)walls[i].y,
                         walls[i].w, walls[i].h};
            SDL_RenderFillRect(renderer, &r);
        }

        /* 绘制玩家（碰撞时变红） */
        SDL_SetRenderDrawColor(renderer,
            player_hit ? 255 : 100,
            player_hit ? 100 : 200, 255, 255);
        SDL_Rect pr = {(int)player.x, (int)player.y, player.w, player.h};
        SDL_RenderFillRect(renderer, &pr);

        /* 绘制圆球（用多边形近似） */
        for (int i = 0; i < ball_count; i++) {
            SDL_SetRenderDrawColor(renderer, 255, 200, 100, 255);
            for (int a = 0; a < 360; a += 5) {
                float rad = a * 3.14159f / 180.0f;
                int px = (int)(balls[i].x + cosf(rad) * balls[i].r);
                int py = (int)(balls[i].y + sinf(rad) * balls[i].r);
                SDL_RenderDrawPoint(renderer, px, py);
                /* 填充：画水平线 */
                if (a < 180) {
                    int x1 = (int)(balls[i].x - sinf(rad) * balls[i].r);
                    int x2 = (int)(balls[i].x + sinf(rad) * balls[i].r);
                    int y = (int)(balls[i].y + cosf(rad) * balls[i].r);
                    SDL_RenderDrawLine(renderer, x1, y, x2, y);
                }
            }
        }

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- AABB 用 4 次比较判断碰撞，适合矩形对象，计算极快
- 圆形碰撞用距离平方比较（避免 sqrt），适合球形对象
- AABB vs Circle 通过找最近点判断，处理混合形状
- 碰撞响应包括分离（MTV）、反弹、事件触发
- 碰撞掩码过滤不需要的碰撞对（如玩家与自己的子弹）
- **常见坑**：比较距离平方而非距离，避免 sqrt 开销；AABB 不适用于旋转对象；碰撞响应中先分离再处理速度，避免连续碰撞抖动

## 第8讲 高级碰撞检测（分离轴定理）

### 概念

AABB 只能处理轴对齐矩形，旋转对象需要更通用的方法。分离轴定理（Separating Axis Theorem, SAT）是 2D 凸多边形碰撞检测的核心算法，能处理任意凸形状的碰撞。本讲深入讲解 SAT 的原理和实现。

### 原理

**分离轴定理**：

两个凸多边形不碰撞的充要条件是：存在一条轴（直线），使得两个多边形在该轴上的投影不重叠。这条轴称为"分离轴"。

```
若存在轴 L，使 A 在 L 上的投影 与 B 在 L 上的投影 不重叠
则 A 与 B 不碰撞
```

**分离轴的候选**：

对于两个凸多边形，分离轴只需检查它们的边的法线。两个多边形的所有边的法线构成候选轴集合。如果所有候选轴上投影都重叠，则碰撞；任一轴上投影不重叠，则不碰撞。

**SAT 算法步骤**：

1. 获取两个多边形的所有边的法线，作为候选轴
2. 对每个候选轴：
   - 计算多边形 A 在轴上的投影（最小值、最大值）
   - 计算多边形 B 在轴上的投影（最小值、最大值）
   - 判断投影是否重叠
   - 若不重叠，返回"不碰撞"
   - 若重叠，记录重叠量
3. 所有轴都重叠，返回"碰撞"，最小重叠量即为 MTV

**投影计算**：

多边形在轴 L 上的投影：对每个顶点 v，计算 `dot(v, L)`，取最小值和最大值。

**边的法线**：

对于边 (v1, v2)，方向向量为 (v2.x - v1.x, v2.y - v1.y)，法线为 (v2.y - v1.y, v1.x - v2.x)（旋转 90 度）。

**SAT 的优势**：
- 适用于任意凸多边形（三角形、矩形、五边形等）
- 支持旋转
- 同时给出碰撞检测结果和最小分离向量（MTV）

**SAT 的局限**：
- 只适用于凸多边形，凹多边形需分解为凸多边形
- 计算量比 AABB 大（O(n+m) 顶点数）
- 不适合大量对象的实时碰撞（需配合空间分区）

**圆与多边形碰撞**：

圆是特殊形状，SAT 处理圆时：
- 候选轴包括多边形的所有边法线
- 还需添加"多边形最近顶点到圆心"方向的轴

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>
#include <math.h>

#define MAX_POLY_VERTS 8

typedef struct { float x, y; } Vec2;

typedef struct {
    Vec2 vertices[MAX_POLY_VERTS];
    int count;
    Vec2 center;      /* 中心点（用于旋转） */
    float angle;      /* 旋转角度（弧度） */
} Polygon;

/* 向量运算 */
Vec2 Vec2_Sub(Vec2 a, Vec2 b) { return (Vec2){a.x - b.x, a.y - b.y}; }
float Vec2_Dot(Vec2 a, Vec2 b) { return a.x * b.x + a.y * b.y; }
float Vec2_Length(Vec2 v) { return sqrtf(v.x * v.x + v.y * v.y); }
Vec2 Vec2_Normalize(Vec2 v) {
    float len = Vec2_Length(v);
    if (len < 0.0001f) return (Vec2){0, 0};
    return (Vec2){v.x / len, v.y / len};
}

/* 获取多边形边的法线 */
Vec2 GetEdgeNormal(Vec2 v1, Vec2 v2) {
    Vec2 edge = Vec2_Sub(v2, v1);
    /* 法线：旋转 90 度 */
    return (Vec2){-edge.y, edge.x};
}

/* 计算多边形在轴上的投影 */
void ProjectPolygon(Polygon* poly, Vec2 axis, float* min, float* max) {
    *min = *max = Vec2_Dot(poly->vertices[0], axis);
    for (int i = 1; i < poly->count; i++) {
        float proj = Vec2_Dot(poly->vertices[i], axis);
        if (proj < *min) *min = proj;
        if (proj > *max) *max = proj;
    }
}

/* SAT 碰撞检测 */
typedef struct {
    SDL_bool collide;
    Vec2 mtv;         /* 最小分离向量 */
    float overlap;    /* 重叠量 */
} CollisionResult;

CollisionResult SAT_Check(Polygon* a, Polygon* b) {
    CollisionResult result = {SDL_TRUE, {0, 0}, 1e30f};

    /* 检查两个多边形的所有边的法线 */
    for (int poly = 0; poly < 2; poly++) {
        Polygon* p = (poly == 0) ? a : b;
        for (int i = 0; i < p->count; i++) {
            int j = (i + 1) % p->count;
            Vec2 normal = GetEdgeNormal(p->vertices[i], p->vertices[j]);
            normal = Vec2_Normalize(normal);

            /* 投影 */
            float min_a, max_a, min_b, max_b;
            ProjectPolygon(a, normal, &min_a, &max_a);
            ProjectPolygon(b, normal, &min_b, &max_b);

            /* 检查重叠 */
            if (max_a < min_b || max_b < min_a) {
                /* 找到分离轴，不碰撞 */
                result.collide = SDL_FALSE;
                return result;
            }

            /* 计算重叠量 */
            float overlap = (max_a < max_b ? max_a : max_b) -
                           (min_a > min_b ? min_a : min_b);
            if (overlap < result.overlap) {
                result.overlap = overlap;
                result.mtv = normal;
                /* MTV 方向应从 A 指向 B */
                Vec2 d = Vec2_Sub(b->center, a->center);
                if (Vec2_Dot(d, normal) < 0) {
                    result.mtv.x = -normal.x;
                    result.mtv.y = -normal.y;
                }
            }
        }
    }
    return result;
}

/* 创建矩形多边形（带旋转） */
Polygon MakeRect(float cx, float cy, float w, float h, float angle) {
    Polygon p;
    p.count = 4;
    p.center = (Vec2){cx, cy};
    p.angle = angle;
    /* 局部坐标顶点 */
    Vec2 local[4] = {
        {-w/2, -h/2}, {w/2, -h/2}, {w/2, h/2}, {-w/2, h/2}
    };
    /* 旋转并平移 */
    float cos_a = cosf(angle), sin_a = sinf(angle);
    for (int i = 0; i < 4; i++) {
        p.vertices[i].x = cx + local[i].x * cos_a - local[i].y * sin_a;
        p.vertices[i].y = cy + local[i].x * sin_a + local[i].y * cos_a;
    }
    return p;
}

/* 创建三角形 */
Polygon MakeTriangle(float cx, float cy, float size, float angle) {
    Polygon p;
    p.count = 3;
    p.center = (Vec2){cx, cy};
    p.angle = angle;
    Vec2 local[3] = {
        {0, -size}, {size * 0.866f, size * 0.5f}, {-size * 0.866f, size * 0.5f}
    };
    float cos_a = cosf(angle), sin_a = sinf(angle);
    for (int i = 0; i < 3; i++) {
        p.vertices[i].x = cx + local[i].x * cos_a - local[i].y * sin_a;
        p.vertices[i].y = cy + local[i].x * sin_a + local[i].y * cos_a;
    }
    return p;
}

/* 绘制多边形 */
void DrawPolygon(SDL_Renderer* r, Polygon* p, Uint8 cr, Uint8 cg, Uint8 cb) {
    SDL_SetRenderDrawColor(r, cr, cg, cb, 255);
    for (int i = 0; i < p->count; i++) {
        int j = (i + 1) % p->count;
        SDL_RenderDrawLine(r,
            (int)p->vertices[i].x, (int)p->vertices[i].y,
            (int)p->vertices[j].x, (int)p->vertices[j].y);
    }
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow(
        "SAT 碰撞示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED);

    float angle1 = 0, angle2 = 0;
    float pos1_x = 300, pos1_y = 300;
    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
        }

        /* 控制 */
        const Uint8* keys = SDL_GetKeyboardState(NULL);
        float speed = 200;
        if (keys[SDL_SCANCODE_LEFT])  pos1_x -= speed * delta;
        if (keys[SDL_SCANCODE_RIGHT]) pos1_x += speed * delta;
        if (keys[SDL_SCANCODE_UP])    pos1_y -= speed * delta;
        if (keys[SDL_SCANCODE_DOWN])  pos1_y += speed * delta;
        if (keys[SDL_SCANCODE_Q])     angle1 -= 2.0f * delta;
        if (keys[SDL_SCANCODE_E])     angle1 += 2.0f * delta;

        /* 创建多边形 */
        Polygon poly1 = MakeRect(pos1_x, pos1_y, 80, 60, angle1);
        Polygon poly2 = MakeTriangle(550, 300, 50, angle2);
        angle2 += delta;

        /* SAT 碰撞检测 */
        CollisionResult cr = SAT_Check(&poly1, &poly2);

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        /* 碰撞时变红，否则绿色 */
        Uint8 r = cr.collide ? 255 : 100;
        Uint8 g = cr.collide ? 100 : 200;
        Uint8 b = cr.collide ? 100 : 100;
        DrawPolygon(renderer, &poly1, r, g, b);
        DrawPolygon(renderer, &poly2, r, g, b);

        /* 绘制 MTV（如果碰撞） */
        if (cr.collide) {
            SDL_SetRenderDrawColor(renderer, 255, 255, 100, 255);
            int cx = (int)poly1.center.x, cy = (int)poly1.center.y;
            int ex = cx + (int)(cr.mtv.x * cr.overlap * 5);
            int ey = cy + (int)(cr.mtv.y * cr.overlap * 5);
            SDL_RenderDrawLine(renderer, cx, cy, ex, ey);
        }

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 分离轴定理：两个凸多边形不碰撞当且仅当存在一条分离轴
- 候选轴是多边形所有边的法线，逐一检查投影是否重叠
- SAT 同时给出碰撞结果和最小分离向量（MTV）
- 适用于任意凸多边形和旋转对象
- 凹多边形需先分解为凸多边形再检测
- **常见坑**：法线必须归一化才能正确计算重叠量；MTV 方向需根据多边形中心相对位置调整；圆与多边形碰撞需额外检查"最近顶点到圆心"方向的轴

## 第9讲 简单物理模拟

### 概念

物理模拟让游戏世界更真实：物体受重力下落、跳跃后落回地面、碰撞后反弹。本讲讲解基础物理模拟，包括重力、速度积分、跳跃、摩擦力、弹性碰撞等，构建一个简单的 2D 物理系统。

### 原理

**基本物理量**：
- 位置（Position）：物体的坐标 (x, y)
- 速度（Velocity）：位置变化率 (vx, vy)，单位 像素/秒
- 加速度（Acceleration）：速度变化率 (ax, ay)，单位 像素/秒²

**牛顿运动定律**：
1. 第一定律：无外力时物体保持匀速直线运动（惯性）
2. 第二定律：F = ma，力等于质量乘以加速度
3. 第三定律：作用力与反作用力大小相等方向相反

**欧拉积分（Euler Integration）**：

最简单的物理积分方法：
```
velocity += acceleration * delta
position += velocity * delta
```

优点：简单快速
缺点：能量不守恒（误差累积），不适合精确模拟

**Verlet 积分**：

更稳定的方法，基于位置而非速度：
```
new_position = 2 * position - prev_position + acceleration * delta²
prev_position = position
position = new_position
```

优点：能量更守恒，约束求解方便
缺点：速度隐式，需额外计算

**重力模拟**：

重力是恒定加速度（向下）：
```
acceleration.y = GRAVITY  /* 如 980 像素/秒² */
```

每帧速度增加 `GRAVITY * delta`，位置增加 `velocity.y * delta`。

**跳跃实现**：

跳跃是瞬间给一个向上的速度：
```
if (on_ground && jump_pressed) {
    velocity.y = -JUMP_FORCE  /* 如 -500 */
}
```

跳跃高度由 `JUMP_FORCE` 决定，与重力配合。可变跳跃高度：松开跳跃键时减小向上速度。

**摩擦力**：

摩擦力使物体逐渐减速：
```
velocity.x *= FRICTION  /* 如 0.95，每帧保留 95% 速度 */
```

或基于物理的摩擦力：`F_friction = -μ * N * velocity_direction`

**弹性碰撞**：

两个物体碰撞后速度变化。一维弹性碰撞公式（质量 m1, m2，速度 v1, v2）：
```
v1' = ((m1 - m2) * v1 + 2 * m2 * v2) / (m1 + m2)
v2' = ((m2 - m1) * v2 + 2 * m1 * v1) / (m1 + m2)
```

**平台游戏物理**：

平台游戏（如超级马里奥）的物理特点：
- 重力恒定向下
- 玩家可左右移动，有地面摩擦
- 跳跃是瞬间向上速度
- 碰到平台顶部站立，碰到侧面阻挡
- "土狼时间"（Coyote Time）：离开平台后短时间内仍可跳跃，提升手感

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>

#define WINDOW_W 800
#define WINDOW_H 600
#define GRAVITY 1500.0f      /* 重力加速度 */
#define JUMP_FORCE 550.0f    /* 跳跃初速度 */
#define MOVE_SPEED 300.0f    /* 水平移动速度 */
#define FRICTION 0.85f       /* 地面摩擦 */
#define AIR_FRICTION 0.98f   /* 空气阻力 */
#define COYOTE_TIME 0.1f     /* 土狼时间（秒） */
#define JUMP_BUFFER 0.1f     /* 跳跃缓冲（秒） */

typedef struct {
    float x, y;
    float vx, vy;
    int w, h;
    SDL_bool on_ground;
    float coyote_timer;   /* 土狼时间计时器 */
    float jump_buffer_timer; /* 跳跃缓冲计时器 */
} PhysicsBody;

typedef struct {
    float x, y;
    int w, h;
} Platform;

/* AABB 碰撞检测 */
SDL_bool AABB_Collide(float ax, float ay, int aw, int ah,
                      float bx, float by, int bw, int bh) {
    return (ax < bx + bw && ax + aw > bx &&
            ay < by + bh && ay + ah > by);
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow(
        "物理模拟示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        WINDOW_W, WINDOW_H, SDL_WINDOW_SHOWN);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED);

    PhysicsBody player = {100, 100, 0, 0, 30, 40, SDL_FALSE, 0, 0};

    /* 平台 */
    Platform platforms[] = {
        {0, 550, 800, 50},      /* 地面 */
        {200, 450, 150, 20},
        {450, 350, 150, 20},
        {650, 250, 150, 20},
        {100, 200, 100, 20}
    };
    int platform_count = 5;

    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();
    SDL_bool jump_held = SDL_FALSE;

    printf("操作: A/D 或左右键移动, 空格或W跳跃, ESC退出\n");

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;
        if (delta > 0.1f) delta = 0.1f;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                (event.key.keysym.scancode == SDL_SCANCODE_SPACE ||
                 event.key.keysym.scancode == SDL_SCANCODE_W)) {
                /* 跳跃缓冲：记录跳跃意图 */
                player.jump_buffer_timer = JUMP_BUFFER;
            }
        }

        const Uint8* keys = SDL_GetKeyboardState(NULL);

        /* === 物理更新 === */

        /* 水平输入 */
        float input_x = 0;
        if (keys[SDL_SCANCODE_A] || keys[SDL_SCANCODE_LEFT])  input_x -= 1;
        if (keys[SDL_SCANCODE_D] || keys[SDL_SCANCODE_RIGHT]) input_x += 1;

        if (input_x != 0) {
            player.vx = input_x * MOVE_SPEED;
        } else {
            /* 摩擦力 */
            if (player.on_ground) {
                player.vx *= FRICTION;
                if (fabsf(player.vx) < 1) player.vx = 0;
            } else {
                player.vx *= AIR_FRICTION;
            }
        }

        /* 重力 */
        player.vy += GRAVITY * delta;

        /* 土狼时间：在地面时重置，离开后倒计时 */
        if (player.on_ground) {
            player.coyote_timer = COYOTE_TIME;
        } else {
            player.coyote_timer -= delta;
        }

        /* 跳跃缓冲倒计时 */
        if (player.jump_buffer_timer > 0) {
            player.jump_buffer_timer -= delta;
        }

        /* 执行跳跃（土狼时间 + 跳跃缓冲） */
        if (player.jump_buffer_timer > 0 && player.coyote_timer > 0) {
            player.vy = -JUMP_FORCE;
            player.on_ground = SDL_FALSE;
            player.coyote_timer = 0;
            player.jump_buffer_timer = 0;
        }

        /* 可变跳跃高度：松开跳跃键时减小向上速度 */
        jump_held = keys[SDL_SCANCODE_SPACE] || keys[SDL_SCANCODE_W];
        if (!jump_held && player.vy < -200) {
            player.vy = -200;
        }

        /* === 位置更新与碰撞 === */

        /* 分轴移动：先 X 后 Y，便于处理碰撞方向 */
        player.on_ground = SDL_FALSE;

        /* X 轴移动 */
        player.x += player.vx * delta;
        for (int i = 0; i < platform_count; i++) {
            Platform* p = &platforms[i];
            if (AABB_Collide(player.x, player.y, player.w, player.h,
                            p->x, p->y, p->w, p->h)) {
                if (player.vx > 0) {
                    player.x = p->x - player.w;
                } else if (player.vx < 0) {
                    player.x = p->x + p->w;
                }
                player.vx = 0;
            }
        }

        /* Y 轴移动 */
        player.y += player.vy * delta;
        for (int i = 0; i < platform_count; i++) {
            Platform* p = &platforms[i];
            if (AABB_Collide(player.x, player.y, player.w, player.h,
                            p->x, p->y, p->w, p->h)) {
                if (player.vy > 0) {
                    /* 落到平台上 */
                    player.y = p->y - player.h;
                    player.on_ground = SDL_TRUE;
                } else if (player.vy < 0) {
                    /* 头撞到平台底部 */
                    player.y = p->y + p->h;
                }
                player.vy = 0;
            }
        }

        /* 边界 */
        if (player.x < 0) { player.x = 0; player.vx = 0; }
        if (player.x > WINDOW_W - player.w) {
            player.x = WINDOW_W - player.w; player.vx = 0;
        }
        if (player.y > WINDOW_H) {
            /* 掉出屏幕，重置 */
            player.x = 100; player.y = 100;
            player.vx = 0; player.vy = 0;
        }

        /* === 渲染 === */
        SDL_SetRenderDrawColor(renderer, 30, 40, 60, 255);
        SDL_RenderClear(renderer);

        /* 绘制平台 */
        SDL_SetRenderDrawColor(renderer, 100, 100, 120, 255);
        for (int i = 0; i < platform_count; i++) {
            SDL_Rect r = {(int)platforms[i].x, (int)platforms[i].y,
                         platforms[i].w, platforms[i].h};
            SDL_RenderFillRect(renderer, &r);
        }

        /* 绘制玩家 */
        SDL_SetRenderDrawColor(renderer,
            player.on_ground ? 100 : 255, 200, 255, 255);
        SDL_Rect pr = {(int)player.x, (int)player.y, player.w, player.h};
        SDL_RenderFillRect(renderer, &pr);

        /* 绘制速度向量（调试用） */
        SDL_SetRenderDrawColor(renderer, 255, 255, 100, 255);
        int cx = (int)(player.x + player.w / 2);
        int cy = (int)(player.y + player.h / 2);
        SDL_RenderDrawLine(renderer, cx, cy,
            cx + (int)(player.vx * 0.1f), cy + (int)(player.vy * 0.1f));

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 欧拉积分简单但能量不守恒，Verlet 积分更稳定
- 重力是恒定向下加速度，跳跃是瞬间向上速度
- 摩擦力用乘法衰减速度（`v *= friction`）
- 分轴移动碰撞处理：先 X 后 Y，便于判断碰撞方向（顶/底/左/右）
- 土狼时间（Coyote Time）和跳跃缓冲（Jump Buffer）提升平台游戏手感
- 可变跳跃高度：松开跳跃键时减小向上速度
- **常见坑**：delta 过大时物理不稳定，需钳制或用固定步长；碰撞处理中先分离再清零速度，避免抖动；多平台碰撞需逐个处理，不能只处理第一个

# 第4章 动画与特效

动画让游戏世界充满生机，特效让游戏体验更加震撼。本章讲解精灵动画系统、粒子系统和屏幕后处理，这些都是提升游戏视觉品质的关键技术。

## 第10讲 精灵动画系统

### 概念

精灵动画是 2D 游戏角色表现动作的核心技术。本讲在基础精灵图基础上，构建完整的动画系统，包括动画状态机、动画混合、事件触发等高级功能，让角色动作流畅自然。

### 原理

**动画状态机（Animation State Machine）**：

角色有多种动作（站立、走路、跳跃、攻击），每种动作对应一段动画。动画状态机管理这些动画之间的切换规则：
- 站立 → 走路：速度大于阈值
- 走路 → 站立：速度变为 0
- 任意 → 跳跃：离开地面
- 攻击 → 站立：攻击动画播放完毕

状态切换有条件（condition）和过渡（transition）。过渡可以是立即切换或平滑混合。

**动画混合（Animation Blending）**：

切换动画时直接跳变会显得生硬。混合技术让两个动画平滑过渡：
- 线性插值：在过渡时间内，两个动画的帧按权重混合
- 交叉淡入淡出：旧动画淡出，新动画淡入

对于精灵动画，简单做法是在过渡时间内快速切换帧，或使用中间过渡帧。

**动画事件**：

动画播放过程中触发事件（如攻击动画在第 3 帧产生伤害、脚步动画在第 2 帧播放脚步声）。实现方式是为每帧附加事件标签，播放到该帧时触发对应事件。

**动画方向**：

角色有左右朝向，通常用一张精灵图 + 水平翻转实现。8 方向角色需要 8 套动画或用 3D 模型渲染。

**动画优先级**：

不同动画有不同优先级。攻击动画应打断走路动画，但不应被打断动画打断。优先级系统管理这种关系。

**帧率独立**：

动画播放速度应独立于渲染帧率。用累积器实现：每帧增加 delta，达到帧间隔时切换帧。

```c
#include <SDL2/SDL.h>
#include <SDL2/SDL_image.h>
#include <stdio.h>
#include <string.h>

/* ============ 动画系统 ============ */

#define MAX_FRAMES 16
#define MAX_ANIMS 8

typedef struct {
    int frames[MAX_FRAMES];  /* 帧索引 */
    int frame_count;
    float frame_duration;    /* 每帧持续时间（秒） */
    SDL_bool loop;
    int priority;
} Animation;

typedef enum {
    ANIM_IDLE = 0,
    ANIM_WALK,
    ANIM_JUMP,
    ANIM_ATTACK,
    ANIM_COUNT
} AnimType;

typedef struct {
    SDL_Texture* spritesheet;
    int frame_width, frame_height;
    int frames_per_row;

    Animation anims[ANIM_COUNT];
    AnimType current_anim;
    int current_frame;
    float frame_timer;

    /* 动画事件回调 */
    void (*on_event)(int event_type);
} Animator;

void Animator_Init(Animator* a, SDL_Texture* sheet, int fw, int fh, int fpr) {
    a->spritesheet = sheet;
    a->frame_width = fw;
    a->frame_height = fh;
    a->frames_per_row = fpr;
    a->current_anim = ANIM_IDLE;
    a->current_frame = 0;
    a->frame_timer = 0;
    a->on_event = NULL;
}

void Animator_SetAnimation(Animator* a, AnimType type) {
    if (type == a->current_anim) return;
    /* 优先级检查：新动画优先级必须 >= 当前动画 */
    if (a->anims[type].priority < a->anims[a->current_anim].priority) {
        /* 但如果当前动画不循环且已结束，允许切换 */
        if (a->anims[a->current_anim].loop) return;
    }
    a->current_anim = type;
    a->current_frame = 0;
    a->frame_timer = 0;
}

void Animator_Update(Animator* a, float delta) {
    Animation* anim = &a->anims[a->current_anim];
    a->frame_timer += delta;

    while (a->frame_timer >= anim->frame_duration) {
        a->frame_timer -= anim->frame_duration;
        a->current_frame++;

        /* 触发帧事件（示例：每帧触发） */
        if (a->on_event) {
            a->on_event(a->current_frame);
        }

        if (a->current_frame >= anim->frame_count) {
            if (anim->loop) {
                a->current_frame = 0;
            } else {
                /* 非循环动画播放完毕，回到 idle */
                a->current_frame = anim->frame_count - 1;
                Animator_SetAnimation(a, ANIM_IDLE);
                return;
            }
        }
    }
}

void Animator_Render(Animator* a, SDL_Renderer* r, int x, int y, SDL_bool flip) {
    Animation* anim = &a->anims[a->current_anim];
    int frame_idx = anim->frames[a->current_frame];
    SDL_Rect src = {
        (frame_idx % a->frames_per_row) * a->frame_width,
        (frame_idx / a->frames_per_row) * a->frame_height,
        a->frame_width, a->frame_height
    };
    SDL_Rect dest = {x, y, a->frame_width, a->frame_height};
    SDL_RenderCopyEx(r, a->spritesheet, &src, &dest, 0, NULL,
        flip ? SDL_FLIP_HORIZONTAL : SDL_FLIP_NONE);
}

/* ============ 角色控制器 ============ */

typedef struct {
    Animator animator;
    float x, y;
    float vx, vy;
    SDL_bool on_ground;
    SDL_bool facing_right;
    SDL_bool attacking;
    float attack_timer;
} Character;

void Character_Update(Character* c, float delta) {
    const Uint8* keys = SDL_GetKeyboardState(NULL);

    /* 水平移动 */
    float move = 0;
    if (keys[SDL_SCANCODE_A] || keys[SDL_SCANCODE_LEFT])  move -= 1;
    if (keys[SDL_SCANCODE_D] || keys[SDL_SCANCODE_RIGHT]) move += 1;

    c->vx = move * 200;
    if (move != 0) c->facing_right = (move > 0);

    /* 跳跃 */
    if ((keys[SDL_SCANCODE_SPACE] || keys[SDL_SCANCODE_W] ||
         keys[SDL_SCANCODE_UP]) && c->on_ground) {
        c->vy = -500;
        c->on_ground = SDL_FALSE;
    }

    /* 攻击 */
    if (keys[SDL_SCANCODE_J] && !c->attacking) {
        c->attacking = SDL_TRUE;
        c->attack_timer = 0.5f;  /* 攻击持续 0.5 秒 */
        Animator_SetAnimation(&c->animator, ANIM_ATTACK);
    }
    if (c->attacking) {
        c->attack_timer -= delta;
        if (c->attack_timer <= 0) c->attacking = SDL_FALSE;
    }

    /* 重力 */
    c->vy += 1200 * delta;
    c->x += c->vx * delta;
    c->y += c->vy * delta;

    /* 地面碰撞 */
    if (c->y > 400) {
        c->y = 400;
        c->vy = 0;
        c->on_ground = SDL_TRUE;
    }

    /* 边界 */
    if (c->x < 0) c->x = 0;
    if (c->x > 800 - 64) c->x = 800 - 64;

    /* 动画状态机 */
    if (!c->attacking) {
        if (!c->on_ground) {
            Animator_SetAnimation(&c->animator, ANIM_JUMP);
        } else if (fabsf(c->vx) > 10) {
            Animator_SetAnimation(&c->animator, ANIM_WALK);
        } else {
            Animator_SetAnimation(&c->animator, ANIM_IDLE);
        }
    }

    Animator_Update(&c->animator, delta);
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    IMG_Init(IMG_INIT_PNG);

    SDL_Window* window = SDL_CreateWindow(

    SDL_RenderClear(renderer);

    /* 第 0-3 帧：idle（轻微呼吸） */
    for (int i = 0; i < 4; i++) {
        int size = 40 + (i % 2) * 2;
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect body = {i * 64 + 12, 64 - size + 12, 40, size};
        SDL_RenderFillRect(renderer, &body);
        /* 眼睛 */
        SDL_SetRenderDrawColor(renderer, 0, 0, 0, 255);
        SDL_Rect eye = {i * 64 + 20, 20, 8, 8};
        SDL_RenderFillRect(renderer, &eye);
    }

    /* 第 4-7 帧：walk（腿部移动） */
    for (int i = 0; i < 4; i++) {
        int leg_offset = (i % 2) * 5;
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect body = {i * 64 + 12 + 64, 12, 40, 40};
        SDL_RenderFillRect(renderer, &body);
        SDL_SetRenderDrawColor(renderer, 80, 160, 200, 255);
        SDL_Rect leg1 = {i * 64 + 64 + 15, 52, 8, 12 + leg_offset};
        SDL_Rect leg2 = {i * 64 + 64 + 41, 52, 8, 12 - leg_offset + 10};
        SDL_RenderFillRect(renderer, &leg1);
        SDL_RenderFillRect(renderer, &leg2);
    }

    /* 第 8-11 帧：jump（向上） */
    for (int i = 0; i < 4; i++) {
        int y_offset = -i * 3;
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect body = {i * 64 + 12, 12 + y_offset + 128, 40, 40};
        SDL_RenderFillRect(renderer, &body);
    }

    /* 第 12-15 帧：attack（挥拳） */
    for (int i = 0; i < 4; i++) {
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect body = {i * 64 + 12, 12 + 192, 40, 40};
        SDL_RenderFillRect(renderer, &body);
        /* 手臂 */
        SDL_SetRenderDrawColor(renderer, 255, 200, 100, 255);
        SDL_Rect arm = {i * 64 + 52, 20 + i * 5 + 192, 12, 8};
        SDL_RenderFillRect(renderer, &arm);

    SDL_SetRenderTarget(renderer, NULL);

    /* 设置角色 */
    Character player;
    Animator_Init(&player.animator, sheet, 64, 64, 4);
    player.animator.on_event = OnAnimEvent;

    /* 配置动画 */
    /* idle: 帧 0-3，循环，0.2秒/帧，优先级 0 */
    player.animator.anims[ANIM_IDLE] = (Animation){
        .frames = {0, 1, 2, 3}, .frame_count = 4,
        .frame_duration = 0.2f, .loop = SDL_TRUE, .priority = 0
    };
    /* walk: 帧 4-7，循环，0.1秒/帧，优先级 1 */
    player.animator.anims[ANIM_WALK] = (Animation){
        .frames = {4, 5, 6, 7}, .frame_count = 4,
        .frame_duration = 0.1f, .loop = SDL_TRUE, .priority = 1
    };
    /* jump: 帧 8-11，不循环，0.15秒/帧，优先级 2 */
    player.animator.anims[ANIM_JUMP] = (Animation){
        .frames = {8, 9, 10, 11}, .frame_count = 4,
        .frame_duration = 0.15f, .loop = SDL_FALSE, .priority = 2
    };
    /* attack: 帧 12-15，不循环，0.1秒/帧，优先级 3（最高） */
    player.animator.anims[ANIM_ATTACK] = (Animation){
        .frames = {12, 13, 14, 15}, .frame_count = 4,
        .frame_duration = 0.1f, .loop = SDL_FALSE, .priority = 3
    };

    player.x = 400; player.y = 400;
    player.vx = 0; player.vy = 0;
    player.on_ground = SDL_TRUE;
    player.facing_right = SDL_TRUE;
    player.attacking = SDL_FALSE;

    printf("操作: A/D移动, 空格/W跳跃, J攻击, ESC退出\n");

    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;
        if (delta > 0.1f) delta = 0.1f;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
        }

        Character_Update(&player, delta);

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 40, 50, 70, 255);
        SDL_RenderClear(renderer);

        /* 地面 */
        SDL_SetRenderDrawColor(renderer, 80, 100, 80, 255);
        SDL_Rect ground = {0, 464, 800, 136};
        SDL_RenderFillRect(renderer, &ground);

        /* 角色 */
        Animator_Render(&player.animator, renderer,
            (int)player.x, (int)player.y, !player.facing_right);

        /* 显示当前动画状态 */
        const char* anim_names[] = {"IDLE", "WALK", "JUMP", "ATTACK"};
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_Rect status_bg = {10, 10, 100, 20};
        SDL_RenderFillRect(renderer, &status_bg);
        /* 用不同颜色表示不同动画 */
        Uint8 colors[][3] = {{100,200,255}, {100,255,100}, {255,200,100}, {255,100,100}};
        SDL_SetRenderDrawColor(renderer,
            colors[player.animator.current_anim][0],
            colors[player.animator.current_anim][1],
            colors[player.animator.current_anim][2], 255);
        SDL_Rect status = {12, 12, 96, 16};
        SDL_RenderFillRect(renderer, &status);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyTexture(sheet);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    IMG_Quit();
    SDL_Quit();
    return 0;
}
```

### 总结

- 动画状态机管理多种动画之间的切换，基于条件触发
- 动画优先级决定哪些动画能打断其他动画（攻击 > 跳跃 > 走路 > 站立）
- 动画事件在特定帧触发逻辑（伤害判定、音效播放）
- 帧率独立播放用累积器实现，动画速度不受渲染帧率影响
- 角色朝向用水平翻转实现，无需额外资源
- **常见坑**：非循环动画播放完毕后必须切换到默认动画，否则卡在最后一帧；动画切换时重置帧索引和计时器；优先级判断要考虑非循环动画是否已结束

## 第11讲 粒子系统

### 概念

粒子系统（Particle System）用于模拟火、烟、爆炸、雨雪、魔法效果等非刚性物体。它通过大量简单粒子的集体行为产生复杂视觉效果。本讲讲解粒子系统的设计、发射器、生命周期管理、渲染优化等。

### 原理

**粒子的本质**：

粒子是最简单的渲染单元，通常是一个带颜色的点或小矩形。每个粒子有：
- 位置、速度、加速度
- 颜色、大小、透明度
- 生命周期（剩余存活时间）

粒子系统通过更新和渲染大量粒子产生效果。

**发射器（Emitter）**：

发射器负责生成粒子，控制：
- 发射位置（点、线、区域）
- 发射速率（每秒生成多少粒子）
- 初始属性范围（速度方向、大小、颜色的随机变化）
- 发射模式（连续、爆发）

**粒子生命周期**：

粒子从生成到消亡的过程：
1. 生成：初始化属性
2. 更新：每帧更新位置、速度、颜色等
3. 消亡：生命周期结束，回收

生命周期内属性可以变化（如颜色渐变、大小缩小），产生丰富效果。

**力的模拟**：

粒子受各种力影响：
- 重力：恒定向下加速度
- 风力：水平方向力
- 阻力：与速度反向的力
- 吸引力：指向某点的力（如磁铁）
- 湍流：随机扰动

**渲染优化**：

粒子数量可能成千上万，渲染优化关键：
1. **对象池**：预分配粒子数组，复用消亡的粒子，避免频繁内存分配
2. **批量渲染**：同一纹理的粒子一次性绘制，减少状态切换
3. **LOD**：远处粒子用更简单的渲染（点而非纹理）
4. **粒子数量控制**：根据性能动态调整发射速率

**混合模式**：

粒子通常使用加法混合（`SDL_BLENDMODE_ADD`）产生发光效果，或 Alpha 混合产生柔和效果。加法混合让重叠粒子更亮，适合火焰、爆炸。

**粒子类型**：
- 点粒子：最简单，一个像素或小矩形
- 纹理粒子：使用小纹理（如星形、圆形），效果更丰富
- 拖尾粒子：记录历史位置，绘制连线

### 例子

```c
#include <SDL2/SDL.h>
#include <SDL2/SDL_image.h>
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define MAX_PARTICLES 2000

typedef struct {
    float x, y;
    float vx, vy;
    float ax, ay;          /* 加速度 */
    float life;            /* 剩余生命（秒） */
    float max_life;        /* 初始生命 */
    float size;
    Uint8 r, g, b;
    Uint8 start_alpha;
    SDL_bool active;
} Particle;

typedef enum {
    EMIT_POINT,      /* 点发射 */
    EMIT_CIRCLE,     /* 圆形区域发射 */
    EMIT_LINE,       /* 线段发射 */
    EMIT_CONE        /* 锥形发射 */
} EmitShape;

typedef struct {
    float x, y;
    EmitShape shape;
    float radius;          /* 圆形半径或线段长度 */
    float angle;           /* 锥形方向 */
    float spread;          /* 锥形扩散角度 */

    float emit_rate;       /* 每秒发射数 */
    float emit_accumulator;

    float min_life, max_life;
    float min_speed, max_speed;
    float min_size, max_size;
    float gravity;
    float drag;            /* 阻力系数 */

    Uint8 color_r, color_g, color_b;
    SDL_BlendMode blend_mode;
} ParticleEmitter;

typedef struct {
    Particle particles[MAX_PARTICLES];
    int next_free;
    int active_count;
} ParticleSystem;

void PS_Init(ParticleSystem* ps) {
    memset(ps, 0, sizeof(*ps));
}

Particle* PS_Spawn(ParticleSystem* ps) {
    /* 查找空闲粒子 */
    for (int i = 0; i < MAX_PARTICLES; i++) {
        int idx = (ps->next_free + i) % MAX_PARTICLES;
        if (!ps->particles[idx].active) {
            ps->next_free = (idx + 1) % MAX_PARTICLES;
            ps->particles[idx].active = SDL_TRUE;
            ps->active_count++;
            return &ps->particles[idx];
        }
    }
    return NULL;  /* 池满 */
}

void PS_Update(ParticleSystem* ps, float delta) {
    for (int i = 0; i < MAX_PARTICLES; i++) {
        Particle* p = &ps->particles[i];
        if (!p->active) continue;

        /* 更新速度（加速度 + 阻力） */
        p->vx += p->ax * delta;
        p->vy += p->ay * delta;
        p->vx *= (1.0f - 0.5f * delta);  /* 简单阻力 */
        p->vy *= (1.0f - 0.5f * delta);

        /* 更新位置 */
        p->x += p->vx * delta;
        p->y += p->vy * delta;

        /* 更新生命 */
        p->life -= delta;
        if (p->life <= 0) {
            p->active = SDL_FALSE;
            ps->active_count--;
        }
    }
}

void PS_Render(ParticleSystem* ps, SDL_Renderer* r, SDL_BlendMode blend) {
    SDL_SetRenderDrawBlendMode(r, blend);
    for (int i = 0; i < MAX_PARTICLES; i++) {
        Particle* p = &ps->particles[i];
        if (!p->active) continue;

        /* 根据生命比例计算 alpha 和大小 */
        float life_ratio = p->life / p->max_life;
        Uint8 alpha = (Uint8)(p->start_alpha * life_ratio);
        int size = (int)(p->size * life_ratio);
        if (size < 1) size = 1;

        SDL_SetRenderDrawColor(r, p->r, p->g, p->b, alpha);
        SDL_Rect rect = {(int)p->x - size/2, (int)p->y - size/2, size, size};
        SDL_RenderFillRect(r, &rect);
    }
}

/* 发射器更新 */
void Emitter_Update(ParticleEmitter* e, ParticleSystem* ps, float delta) {
    e->emit_accumulator += e->emit_rate * delta;
    while (e->emit_accumulator >= 1.0f) {
        e->emit_accumulator -= 1.0f;
        Particle* p = PS_Spawn(ps);
        if (!p) break;

        /* 计算初始位置 */
        p->x = e->x;
        p->y = e->y;
        if (e->shape == EMIT_CIRCLE) {
            float angle = (float)(rand() % 360) * 3.14159f / 180.0f;
            float r = (float)(rand() % 100) / 100.0f * e->radius;
            p->x += cosf(angle) * r;
            p->y += sinf(angle) * r;
        } else if (e->shape == EMIT_LINE) {
            p->x += (float)(rand() % 100) / 100.0f * e->radius - e->radius / 2;
        } else if (e->shape == EMIT_CONE) {
            float spread = (float)(rand() % 100) / 100.0f * e->spread - e->spread / 2;
            float angle = e->angle + spread;
```

## 第12讲 屏幕特效与后处理

### 概念

屏幕后处理（Post-Processing）是在渲染完成后对整个画面应用效果，如模糊、色彩调整、 vignette（暗角）、扫描线等。本讲讲解基于目标纹理的屏幕后处理实现，提升游戏视觉氛围。

### 原理

**后处理流程**：

1. 将整个场景渲染到目标纹理（而非屏幕）
2. 将目标纹理作为输入，应用各种效果
3. 将处理后的纹理渲染到屏幕

SDL2 的目标纹理（`SDL_TEXTUREACCESS_TARGET`）支持这一流程。

**常见后处理效果**：

1. **色彩调整**：修改每个像素的颜色（亮度、对比度、饱和度、色调）
2. **模糊**：降低画面清晰度，产生梦幻效果
3. **Vignette（暗角）**：画面边缘变暗，聚焦中心
4. **扫描线**：模拟 CRT 显示器效果
5. **色彩分级**：应用特定的色彩 LUT（查找表）
6. **泛光（Bloom）**：亮部发光扩散

**SDL2 后处理的局限**：

SDL2 的渲染器是固定管线，不支持自定义着色器（Shader）。复杂的后处理（如高斯模糊、Bloom）需要：
1. 多次渲染 + 纹理采样
2. 或使用 SDL2 的 OpenGL 上下文，直接写 GLSL 着色器

本讲用 SDL2 基础 API 实现简单后处理，复杂效果需结合 OpenGL。

**简单后处理实现**：

1. **色彩调整**：用 `SDL_SetTextureColorMod` 调整纹理颜色
2. **Vignette**：在画面上叠加一个边缘暗中心亮的半透明纹理
3. **扫描线**：每隔几行画一条暗线
4. **简单模糊**：将场景纹理多次以微小偏移绘制，半透明叠加

**性能考虑**：

后处理需要额外的渲染通道，性能开销大。移动平台或低端设备应谨慎使用，或降低后处理分辨率。

## 第13讲 寻路算法（A*）

### 概念

寻路（Pathfinding）是游戏AI的基础能力：让角色从A点移动到B点，绕过障碍物。A*（A-star）算法是最经典的寻路算法，结合了Dijkstra算法的最优性和贪心算法的速度。本讲深入讲解A*算法的原理和实现。

### 原理

**网格地图表示**：

2D游戏通常用网格表示地图，每个格子是可通行或障碍。寻路就是在网格上找一条从起点到终点的路径。

**A*算法核心思想**：

A*维护两个集合：
- **open set**：待探索的节点
- **closed set**：已探索的节点

每个节点维护三个值：
- **g(n)**：从起点到节点n的实际代价
- **h(n)**：从节点n到终点的启发式估计代价（启发函数）
- **f(n) = g(n) + h(n)**：总估计代价

A*每次从open set中取出f值最小的节点探索，保证找到最优路径。

**算法步骤**：

1. 将起点加入open set，g=0，h=启发估计，f=g+h
2. 循环：
   - 从open set取出f最小的节点current
   - 若current是终点，重建路径并返回
   - 将current移入closed set
   - 遍历current的邻居：
     - 若在closed set中，跳过
     - 计算 tentative_g = current.g + 移动代价
     - 若邻居不在open set，加入open set，设置g和parent
     - 若在open set且 tentative_g < 邻居.g，更新g和parent
3. open set为空，无路径

**启发函数（Heuristic）**：

常见的启发函数：
- **曼哈顿距离**：`|dx| + |dy|`，适合4方向移动
- **欧几里得距离**：`sqrt(dx² + dy²)`，适合任意方向移动
- **切比雪夫距离**：`max(|dx|, |dy|)`，适合8方向移动

启发函数必须"可采纳"（不高估实际代价），才能保证A*找到最优路径。

**数据结构优化**：

- open set用优先队列（最小堆）实现，O(log n) 取最小值
- closed set用哈希集合，O(1) 查找
- 节点用数组存储，用坐标索引

**路径平滑**：

A*生成的路径是网格中心点的折线，不够平滑。后处理方法：
- **路径简化**：移除共线的中间点
- **路径平滑**：用样条曲线或贝塞尔曲线平滑

**动态障碍**：

游戏中的障碍可能变化（如其他角色）。解决方案：
- 重新计算路径（开销大）
- 增量更新（D*算法）
- 局部避障（RVO算法）

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define GRID_W 40
#define GRID_H 30
#define CELL_SIZE 20

/* 网格类型 */
typedef enum {
    CELL_EMPTY = 0,
    CELL_WALL,
    CELL_START,
    CELL_END,
    CELL_PATH,
    CELL_VISITED
} CellType;

CellType grid[GRID_W][GRID_H];

/* A* 节点 */
typedef struct {
    int x, y;
    float g, h, f;
    int parent_x, parent_y;
    SDL_bool in_open;
    SDL_bool in_closed;
} AStarNode;

AStarNode nodes[GRID_W][GRID_H];

/* 优先队列（简化实现：线性查找最小值） */
typedef struct {
    AStarNode* data[GRID_W * GRID_H];
    int count;
} PriorityQueue;

void PQ_Init(PriorityQueue* pq) { pq->count = 0; }

void PQ_Push(PriorityQueue* pq, AStarNode* node) {
    pq->data[pq->count++] = node;
}

AStarNode* PQ_PopMin(PriorityQueue* pq) {
    if (pq->count == 0) return NULL;
    int min_idx = 0;
    for (int i = 1; i < pq->count; i++) {
        if (pq->data[i]->f < pq->data[min_idx]->f) {
            min_idx = i;
        }
    }
    AStarNode* min_node = pq->data[min_idx];
    pq->data[min_idx] = pq->data[pq->count - 1];
    pq->count--;
    return min_node;
}

/* 启发函数：曼哈顿距离 */
float Heuristic(int x1, int y1, int x2, int y2) {
    return (float)(abs(x1 - x2) + abs(y1 - y2));
}

/* 8方向移动 */
int directions[8][2] = {
    {0, -1}, {0, 1}, {-1, 0}, {1, 0},      /* 上下左右 */
    {-1, -1}, {1, -1}, {-1, 1}, {1, 1}     /* 对角线 */
};
float dir_costs[8] = {1, 1, 1, 1, 1.414f, 1.414f, 1.414f, 1.414f};

/* A* 寻路 */
SDL_bool AStar_FindPath(int sx, int sy, int ex, int ey) {
    /* 初始化节点 */
    for (int x = 0; x < GRID_W; x++) {
        for (int y = 0; y < GRID_H; y++) {
            nodes[x][y].x = x;
            nodes[x][y].y = y;
            nodes[x][y].g = 0;
            nodes[x][y].h = 0;
            nodes[x][y].f = 0;
            nodes[x][y].parent_x = -1;
            nodes[x][y].parent_y = -1;
            nodes[x][y].in_open = SDL_FALSE;
            nodes[x][y].in_closed = SDL_FALSE;
        }
    }

    PriorityQueue open;
    PQ_Init(&open);

    /* 起点 */
    AStarNode* start = &nodes[sx][sy];
    start->g = 0;
    start->h = Heuristic(sx, sy, ex, ey);
    start->f = start->g + start->h;
    start->in_open = SDL_TRUE;
    PQ_Push(&open, start);

    while (open.count > 0) {
        AStarNode* current = PQ_PopMin(&open);
        current->in_open = SDL_FALSE;
        current->in_closed = SDL_TRUE;

        /* 标记已访问（可视化） */
        if (grid[current->x][current->y] == CELL_EMPTY) {
            grid[current->x][current->y] = CELL_VISITED;
        }

        /* 到达终点 */
        if (current->x == ex && current->y == ey) {
            /* 重建路径 */
            int cx = ex, cy = ey;
            while (cx != sx || cy != sy) {
                if (grid[cx][cy] == CELL_EMPTY || grid[cx][cy] == CELL_VISITED) {
                    grid[cx][cy] = CELL_PATH;
                }
                int px = nodes[cx][cy].parent_x;
                int py = nodes[cx][cy].parent_y;
                cx = px; cy = py;
            }
            return SDL_TRUE;
        }

        /* 遍历邻居 */
        for (int i = 0; i < 8; i++) {
            int nx = current->x + directions[i][0];
            int ny = current->y + directions[i][1];

            /* 边界检查 */
            if (nx < 0 || nx >= GRID_W || ny < 0 || ny >= GRID_H) continue;
            /* 障碍检查 */
            if (grid[nx][ny] == CELL_WALL) continue;
            /* 对角线移动时检查角落（防止穿墙角） */
            if (i >= 4) {
                int dx = directions[i][0];
                int dy = directions[i][1];
                if (grid[current->x + dx][current->y] == CELL_WALL ||
                    grid[current->x][current->y + dy] == CELL_WALL) {
                    continue;
                }
            }

            AStarNode* neighbor = &nodes[nx][ny];
            if (neighbor->in_closed) continue;

            float tentative_g = current->g + dir_costs[i];

            if (!neighbor->in_open) {
                neighbor->g = tentative_g;
                neighbor->h = Heuristic(nx, ny, ex, ey);
                neighbor->f = neighbor->g + neighbor->h;
                neighbor->parent_x = current->x;
                neighbor->parent_y = current->y;
                neighbor->in_open = SDL_TRUE;
                PQ_Push(&open, neighbor);
            } else if (tentative_g < neighbor->g) {
                neighbor->g = tentative_g;
                neighbor->f = neighbor->g + neighbor->h;
                neighbor->parent_x = current->x;
                neighbor->parent_y = current->y;
            }
        }
    }
    return SDL_FALSE;  /* 无路径 */
}
```

### 总结

- A*算法结合Dijkstra的最优性和贪心算法的速度，f = g + h
- 启发函数必须可采纳（不高估），曼哈顿距离适合4方向，欧几里得适合任意方向
- open set用优先队列，closed set用哈希集合
- 8方向移动需检查对角线穿墙问题
- 路径后处理（简化、平滑）提升视觉效果
- **常见坑**：启发函数高估会导致非最优路径；优先队列用线性查找性能差，应用最小堆；动态障碍需重新寻路或增量更新

## 第14讲 有限状态机AI

### 概念

有限状态机（Finite State Machine, FSM）是游戏AI最常用的行为建模方法。它将AI行为划分为离散状态，状态之间通过条件触发转换。本讲讲解FSM的原理、实现和游戏AI应用。

### 原理

**FSM 的三要素**：
- **状态（State）**：AI当前的行为模式（巡逻、追击、攻击、逃跑）
- **转换（Transition）**：状态之间的切换，由条件触发
- **条件（Condition）**：触发转换的事件或判断（距离、生命值、视野）

**FSM 的工作方式**：

每个游戏帧，当前状态执行其逻辑（如巡逻状态让角色沿路径移动），并检查所有出转换的条件。若某条件满足，切换到目标状态。

**游戏AI的典型状态**：

- **巡逻（Patrol）**：沿预设路径移动
- **警戒（Alert）**：发现可疑目标，前往查看
- **追击（Chase）**：追击玩家
- **攻击（Attack）**：在攻击范围内攻击玩家
- **逃跑（Flee）**：生命值低时逃跑
- **死亡（Dead）**：生命值为0

**状态转换示例**：

```
巡逻 --(看到玩家)--> 追击
追击 --(距离<攻击范围)--> 攻击
攻击 --(距离>攻击范围)--> 追击
追击 --(玩家脱离视野)--> 巡逻
任意 --(生命值<30%)--> 逃跑
任意 --(生命值<=0)--> 死亡
```

**FSM 的实现方式**：

1. **switch-case**：简单直接，但状态多时代码冗长
2. **状态模式**：每个状态封装为对象，有 OnEnter/OnExit/Update 方法
3. **数据驱动**：状态和转换用数据表描述，运行时解释执行

**状态模式的优点**：
- 状态逻辑封装，易于维护
- 新增状态不影响现有代码
- 状态间数据通过共享上下文传递

**分层FSM（HFSM）**：

复杂AI需要状态嵌套（如"战斗"状态包含"接近"、"攻击"、"撤退"子状态）。分层FSM允许状态包含子FSM，提升结构化程度。

**FSM 的局限**：
- 状态多时转换关系爆炸（n²增长）
- 难以表达复杂决策逻辑（如"如果玩家有武器且我生命值低且无队友则逃跑"）
- 需要行为树等更高级方法

```c
#include <SDL2/SDL.h>
#include <stdio.h>
#include <math.h>

#define WINDOW_W 800
#define WINDOW_H 600

/* AI 状态 */
typedef enum {
    STATE_PATROL = 0,
    STATE_CHASE,
    STATE_ATTACK,
    STATE_FLEE,
    STATE_DEAD,
    STATE_COUNT
} AIState;

/* 敌人结构 */
typedef struct {
    float x, y;
    float vx, vy;
    int hp;
    int max_hp;
    AIState state;

    /* 巡逻路径 */
    float patrol_points[4][2];
    int patrol_current;
    float patrol_speed;

    /* 视野 */
    float view_range;
    float attack_range;

    /* 攻击 */
    float attack_cooldown;
    float attack_timer;
    int attack_damage;
} Enemy;

/* 玩家结构 */
typedef struct {
    float x, y;
    int hp;
} Player;

/* 状态名称（调试用） */
const char* state_names[] = {
    "巡逻", "追击", "攻击", "逃跑", "死亡"
};

/* 距离计算 */
float Distance(float x1, float y1, float x2, float y2) {
    float dx = x2 - x1, dy = y2 - y1;
    return sqrtf(dx * dx + dy * dy);
}

/* ============ 状态逻辑 ============ */

void State_Patrol(Enemy* e, Player* p, float delta) {
    /* 沿巡逻路径移动 */
    float* target = e->patrol_points[e->patrol_current];
    float dx = target[0] - e->x;
    float dy = target[1] - e->y;
    float dist = sqrtf(dx * dx + dy * dy);

    if (dist < 5) {
        /* 到达当前巡逻点，切换下一个 */
        e->patrol_current = (e->patrol_current + 1) % 4;
    } else {
        e->vx = dx / dist * e->patrol_speed;
        e->vy = dy / dist * e->patrol_speed;
        e->x += e->vx * delta;
        e->y += e->vy * delta;
    }

    /* 转换条件：看到玩家 */
    if (Distance(e->x, e->y, p->x, p->y) < e->view_range) {
        e->state = STATE_CHASE;
        printf("敌人: 巡逻 -> 追击\n");
    }
}

void State_Chase(Enemy* e, Player* p, float delta) {
    /* 追击玩家 */
    float dx = p->x - e->x;
    float dy = p->y - e->y;
    float dist = sqrtf(dx * dx + dy * dy);

    float chase_speed = e->patrol_speed * 1.5f;
    e->vx = dx / dist * chase_speed;
    e->vy = dy / dist * chase_speed;
    e->x += e->vx * delta;
    e->y += e->vy * delta;

    /* 转换条件 */
    if (dist < e->attack_range) {
        e->state = STATE_ATTACK;
        printf("敌人: 追击 -> 攻击\n");
    } else if (dist > e->view_range * 1.5f) {
        /* 玩家脱离视野 */
        e->state = STATE_PATROL;
        printf("敌人: 追击 -> 巡逻\n");
    }

    /* 生命值低转换 */
    if (e->hp < e->max_hp * 0.3f) {
        e->state = STATE_FLEE;
        printf("敌人: 追击 -> 逃跑\n");
    }
}

void State_Attack(Enemy* e, Player* p, float delta) {
    /* 攻击冷却 */
    e->attack_timer -= delta;
    if (e->attack_timer <= 0) {
        /* 执行攻击 */
        p->hp -= e->attack_damage;
        e->attack_timer = e->attack_cooldown;
        printf("敌人攻击! 玩家HP: %d\n", p->hp);
    }

    /* 转换条件 */
    float dist = Distance(e->x, e->y, p->x, p->y);
    if (dist > e->attack_range) {
        e->state = STATE_CHASE;
        printf("敌人: 攻击 -> 追击\n");
    }

    if (e->hp < e->max_hp * 0.3f) {
        e->state = STATE_FLEE;
        printf("敌人: 攻击 -> 逃跑\n");
    }
}

void State_Flee(Enemy* e, Player* p, float delta) {
    /* 远离玩家 */
    float dx = e->x - p->x;
    float dy = e->y - p->y;
    float dist = sqrtf(dx * dx + dy * dy);

    if (dist > 0.1f) {
        float flee_speed = e->patrol_speed * 2.0f;
        e->vx = dx / dist * flee_speed;
        e->vy = dy / dist * flee_speed;
        e->x += e->vx * delta;
        e->y += e->vy * delta;
    }

    /* 边界 */
    if (e->x < 0) e->x = 0;
    if (e->x > WINDOW_W) e->x = WINDOW_W;
    if (e->y < 0) e->y = 0;
    if (e->y > WINDOW_H) e->y = WINDOW_H;

    /* 转换条件：远离玩家足够远，恢复巡逻 */
    if (dist > e->view_range * 2) {
        e->state = STATE_PATROL;
        printf("敌人: 逃跑 -> 巡逻\n");
    }
}

void State_Dead(Enemy* e, Player* p, float delta) {
    /* 死亡状态，不执行任何动作 */
    e->vx = 0;
    e->vy = 0;
}

/* 状态更新分发 */
void Enemy_Update(Enemy* e, Player* p, float delta) {
    switch (e->state) {
    case STATE_PATROL: State_Patrol(e, p, delta); break;
    case STATE_CHASE:  State_Chase(e, p, delta); break;
    case STATE_ATTACK: State_Attack(e, p, delta); break;
    case STATE_FLEE:   State_Flee(e, p, delta); break;
    case STATE_DEAD:   State_Dead(e, p, delta); break;
    }

    /* 全局转换：死亡 */
    if (e->hp <= 0 && e->state != STATE_DEAD) {
        e->state = STATE_DEAD;
        printf("敌人: -> 死亡\n");
    }
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow(
        "FSM AI 示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        WINDOW_W, WINDOW_H, SDL_WINDOW_SHOWN);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED);

    Player player = {400, 300, 100};

    Enemy enemy = {0};
    enemy.x = 100; enemy.y = 100;
    enemy.hp = 100; enemy.max_hp = 100;
    enemy.state = STATE_PATROL;
    enemy.patrol_points[0][0] = 100; enemy.patrol_points[0][1] = 100;
    enemy.patrol_points[1][0] = 700; enemy.patrol_points[1][1] = 100;
    enemy.patrol_points[2][0] = 700; enemy.patrol_points[2][1] = 500;
    enemy.patrol_points[3][0] = 100; enemy.patrol_points[3][1] = 500;
    enemy.patrol_current = 0;
    enemy.patrol_speed = 100;
    enemy.view_range = 200;
    enemy.attack_range = 50;
    enemy.attack_cooldown = 1.0f;
    enemy.attack_timer = 0;
    enemy.attack_damage = 10;

    printf("操作: WASD移动玩家, J攻击敌人, ESC退出\n");

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;
        if (delta > 0.1f) delta = 0.1f;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)

        }

        const Uint8* keys = SDL_GetKeyboardState(NULL);
        float speed = 250;
        if (keys[SDL_SCANCODE_W]) player.y -= speed * delta;
        if (keys[SDL_SCANCODE_S]) player.y += speed * delta;
        if (keys[SDL_SCANCODE_A]) player.x -= speed * delta;

        /* 边界 */
        if (player.x < 0) player.x = 0;
        if (player.x > WINDOW_W - 20) player.x = WINDOW_W - 20;
        if (player.y < 0) player.y = 0;

        if (keys[SDL_SCANCODE_J]) {

            }

        /* 每秒打印状态 */

        /* 渲染 */

        /* 绘制玩家（蓝色） */

        Uint8* c = enemy_colors[enemy.state];
        SDL_SetRenderDrawColor(renderer, c[0], c[1], c[2], 255);
        SDL_Rect enemy_rect = {(int)enemy.x - 15, (int)enemy.y - 15, 30, 30};
        SDL_RenderFillRect(renderer, &enemy_rect);

        /* 绘制血条 */
```

### 总结

- FSM 用状态、转换、条件三要素建模AI行为
- 典型状态：巡逻、追击、攻击、逃跑、死亡
- 状态模式封装每个状态的逻辑，OnEnter/OnExit/Update
- 全局转换（如死亡）独立处理，不放在每个状态中
- 分层FSM支持状态嵌套，适合复杂AI
- **常见坑**：状态转换频繁抖动（如攻击和追击来回切换），需加滞回区间；状态间数据传递用共享上下文；状态多时转换关系复杂，考虑行为树

## 第15讲 行为树AI

### 概念

行为树（Behavior Tree, BT）是现代游戏AI的主流架构，相比FSM更灵活、可复用、易扩展。它用树形结构组织行为，通过节点类型（选择、序列、装饰、动作）实现复杂决策。本讲讲解行为树的原理和实现。

### 原理

**行为树 vs FSM**：

FSM的状态转换是网状的，n个状态有n²个可能转换，难以维护。行为树用层次化结构组织行为，父节点控制子节点的执行顺序，转换关系隐含在树结构中。

**行为树的节点类型**：

1. **动作节点（Action Node）**：执行具体行为（移动、攻击），返回成功/失败/运行中

2. **条件节点（Condition Node）**：检查条件（生命值、距离），返回成功/失败

3. **组合节点（Composite Node）**：控制子节点执行
   - **选择节点（Selector）**：依次执行子节点，任一成功则返回成功（类似OR）
   - **序列节点（Sequence）**：依次执行子节点，全部成功才返回成功（类似AND）

4. **装饰节点（Decorator Node）**：修饰单个子节点的行为
   - **反转（Inverter）**：反转子节点的结果
   - **重复（Repeater）**：重复执行子节点
   - **直到失败（UntilFail）**：重复执行直到子节点失败

**行为树的执行（Tick）**：

每帧从根节点开始"Tick"（心跳），向下传播到子节点。每个节点返回状态：
- **成功（Success）**：行为完成
- **失败（Failure）**：行为无法完成
- **运行中（Running）**：行为正在执行，需多帧完成

**选择节点示例**：

```
Selector
├── 条件: 生命值 < 30%
│   └── 动作: 逃跑
├── 条件: 看到玩家
│   └── Selector
│       ├── 条件: 在攻击范围
│       │   └── 动作: 攻击
│       └── 动作: 追击
└── 动作: 巡逻
```

执行逻辑：先检查生命值低则逃跑；否则检查是否看到玩家，看到则尝试攻击或追击；都不满足则巡逻。

**行为树的优势**：
- 模块化：每个节点独立，可复用
- 可读性：树结构清晰表达决策逻辑
- 可扩展：新增行为只需添加节点
- 数据驱动：树结构可从文件加载

**行为树的实现**：

用面向对象方式实现节点基类，派生出各种节点类型。C语言中用结构体 + 函数指针模拟。

**黑板（Blackboard）**：

行为树节点间共享数据的数据结构。节点从黑板读取输入（如玩家位置），写入输出（如移动目标）。黑板解耦了节点间的数据依赖。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

#define WINDOW_W 800
#define WINDOW_H 600

/* 节点状态 */
typedef enum {
    BT_SUCCESS = 0,
    BT_FAILURE,
    BT_RUNNING
} BTStatus;

/* 黑板：共享数据 */
typedef struct {
    float self_x, self_y;
    float target_x, target_y;
    int self_hp;
    int self_max_hp;
    float view_range;
    float attack_range;
    float move_speed;
    float patrol_target_x, patrol_target_y;
} Blackboard;

/* 行为树节点基类 */
typedef struct BTNode BTNode;
struct BTNode {
    BTStatus (*tick)(BTNode* self, Blackboard* bb, float delta);
    void (*destroy)(BTNode* self);
};

/* ============ 条件节点 ============ */

/* 条件：生命值低 */
typedef struct {
    BTNode base;
    float threshold;  /* 生命值百分比阈值 */
} ConditionLowHP;

BTStatus ConditionLowHP_Tick(BTNode* self, Blackboard* bb, float delta) {
    ConditionLowHP* node = (ConditionLowHP*)self;
    float ratio = (float)bb->self_hp / bb->self_max_hp;
    return (ratio < node->threshold) ? BT_SUCCESS : BT_FAILURE;
}

BTNode* CreateConditionLowHP(float threshold) {
    ConditionLowHP* node = malloc(sizeof(ConditionLowHP));
    node->base.tick = ConditionLowHP_Tick;
    node->base.destroy = NULL;
    node->threshold = threshold;
    return (BTNode*)node;
}

/* 条件：看到目标 */
typedef struct {
    BTNode base;
} ConditionSeeTarget;

BTStatus ConditionSeeTarget_Tick(BTNode* self, Blackboard* bb, float delta) {
    float dx = bb->target_x - bb->self_x;
    float dy = bb->target_y - bb->self_y;
    float dist = sqrtf(dx * dx + dy * dy);
    return (dist < bb->view_range) ? BT_SUCCESS : BT_FAILURE;
}

BTNode* CreateConditionSeeTarget() {
    ConditionSeeTarget* node = malloc(sizeof(ConditionSeeTarget));
    node->base.tick = ConditionSeeTarget_Tick;
    node->base.destroy = NULL;
    return (BTNode*)node;
}

/* 条件：在攻击范围 */
BTStatus ConditionInRange_Tick(BTNode* self, Blackboard* bb, float delta) {
    float dx = bb->target_x - bb->self_x;
    float dy = bb->target_y - bb->self_y;
    float dist = sqrtf(dx * dx + dy * dy);
    return (dist < bb->attack_range) ? BT_SUCCESS : BT_FAILURE;
}

BTNode* CreateConditionInRange() {
    ConditionSeeTarget* node = malloc(sizeof(ConditionSeeTarget));
    node->base.tick = ConditionInRange_Tick;
    node->base.destroy = NULL;
    return (BTNode*)node;
}

/* ============ 动作节点 ============ */

/* 动作：逃跑 */
BTStatus ActionFlee_Tick(BTNode* self, Blackboard* bb, float delta) {
    float dx = bb->self_x - bb->target_x;
    float dy = bb->self_y - bb->target_y;
    float dist = sqrtf(dx * dx + dy * dy);
    if (dist < 0.1f) return BT_RUNNING;

    bb->self_x += dx / dist * bb->move_speed * 2.0f * delta;
    bb->self_y += dy / dist * bb->move_speed * 2.0f * delta;

    /* 边界 */
    if (bb->self_x < 0) bb->self_x = 0;
    if (bb->self_x > WINDOW_W) bb->self_x = WINDOW_W;
    if (bb->self_y < 0) bb->self_y = 0;
    if (bb->self_y > WINDOW_H) bb->self_y = WINDOW_H;

    return BT_RUNNING;
}

BTNode* CreateActionFlee() {
    ConditionSeeTarget* node = malloc(sizeof(ConditionSeeTarget));
    node->base.tick = ActionFlee_Tick;
    node->base.destroy = NULL;
    return (BTNode*)node;
}

/* 动作：追击 */
BTStatus ActionChase_Tick(BTNode* self, Blackboard* bb, float delta) {
    float dx = bb->target_x - bb->self_x;
    float dy = bb->target_y - bb->self_y;
    float dist = sqrtf(dx * dx + dy * dy);
    if (dist < 0.1f) return BT_SUCCESS;

    bb->self_x += dx / dist * bb->move_speed * 1.5f * delta;
    bb->self_y += dy / dist * bb->move_speed * 1.5f * delta;
    return BT_RUNNING;
}

BTNode* CreateActionChase() {
    ConditionSeeTarget* node = malloc(sizeof(ConditionSeeTarget));
    node->base.tick = ActionChase_Tick;
    node->base.destroy = NULL;
    return (BTNode*)node;
}

/* 动作：攻击 */
typedef struct {
    BTNode base;
    float cooldown;
    float timer;
} ActionAttack;

BTStatus ActionAttack_Tick(BTNode* self, Blackboard* bb, float delta) {
    ActionAttack* node = (ActionAttack*)self;
    node->timer -= delta;
    if (node->timer <= 0) {
        node->timer = node->cooldown;
        printf("攻击! (模拟)\n");
    }
    return BT_RUNNING;
}

BTNode* CreateActionAttack(float cooldown) {
    ActionAttack* node = malloc(sizeof(ActionAttack));
    node->base.tick = ActionAttack_Tick;
    node->base.destroy = NULL;
    node->cooldown = cooldown;
    node->timer = 0;
    return (BTNode*)node;
}

/* 动作：巡逻 */
BTStatus ActionPatrol_Tick(BTNode* self, Blackboard* bb, float delta) {
    float dx = bb->patrol_target_x - bb->self_x;
    float dy = bb->patrol_target_y - bb->self_y;
    float dist = sqrtf(dx * dx + dy * dy);

    if (dist < 5) {
        /* 到达，选择新巡逻点 */
        bb->patrol_target_x = (float)(100 + rand() % 600);
        bb->patrol_target_y = (float)(100 + rand() % 400);
    } else {
        bb->self_x += dx / dist * bb->move_speed * delta;
        bb->self_y += dy / dist * bb->move_speed * delta;
    }
    return BT_RUNNING;
}

BTNode* CreateActionPatrol() {
    ConditionSeeTarget* node = malloc(sizeof(ConditionSeeTarget));
    node->base.tick = ActionPatrol_Tick;
    node->base.destroy = NULL;
    return (BTNode*)node;
}

/* ============ 组合节点 ============ */

#define MAX_CHILDREN 8

/* 选择节点 */
typedef struct {
    BTNode base;
    BTNode* children[MAX_CHILDREN];
    int child_count;
    int current_child;
} SelectorNode;

BTStatus Selector_Tick(BTNode* self, Blackboard* bb, float delta) {
    SelectorNode* node = (SelectorNode*)self;
    for (int i = 0; i < node->child_count; i++) {
        BTStatus status = node->children[i]->tick(node->children[i], bb, delta);
        if (status != BT_FAILURE) {
            return status;  /* 成功或运行中 */
        }
    }
    return BT_FAILURE;
}

BTNode* CreateSelector() {
    SelectorNode* node = calloc(1, sizeof(SelectorNode));
    node->base.tick = Selector_Tick;
    return (BTNode*)node;
}

void Selector_AddChild(BTNode* self, BTNode* child) {
    SelectorNode* node = (SelectorNode*)self;
    if (node->child_count < MAX_CHILDREN) {
        node->children[node->child_count++] = child;
    }
}

/* 序列节点 */
typedef struct {
    BTNode base;
    BTNode* children[MAX_CHILDREN];
    int child_count;
} SequenceNode;

BTStatus Sequence_Tick(BTNode* self, Blackboard* bb, float delta) {
    SequenceNode* node = (SequenceNode*)self;
    for (int i = 0; i < node->child_count; i++) {
        BTStatus status = node->children[i]->tick(node->children[i], bb, delta);
        if (status != BT_SUCCESS) {
            return status;  /* 失败或运行中 */
        }
    }
    return BT_SUCCESS;
}

BTNode* CreateSequence() {
    SequenceNode* node = calloc(1, sizeof(SequenceNode));
    node->base.tick = Sequence_Tick;
    return (BTNode*)node;
}

void Sequence_AddChild(BTNode* self, BTNode* child) {
    SequenceNode* node = (SequenceNode*)self;
    if (node->child_count < MAX_CHILDREN) {
        node->children[node->child_count++] = child;
    }
}

/* ============ 主程序 ============ */

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow(
        "行为树 AI 示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        WINDOW_W, WINDOW_H, SDL_WINDOW_SHOWN);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED);

    /* 构建行为树：
     * Selector (根)
     * ├── Sequence (逃跑)
     * │   ├── ConditionLowHP(0.3)
     * │   └── ActionFlee
     * ├── Sequence (战斗)
     * │   ├── ConditionSeeTarget
     * │   └── Selector
     * │       ├── Sequence (攻击)
     * │       │   ├── ConditionInRange
     * │       │   └── ActionAttack
     * │       └── ActionChase
     * └── ActionPatrol
     */
    BTNode* root = CreateSelector();

    BTNode* flee_seq = CreateSequence();
    Sequence_AddChild(flee_seq, CreateConditionLowHP(0.3f));
    Sequence_AddChild(flee_seq, CreateActionFlee());

    BTNode* combat_seq = CreateSequence();
    Sequence_AddChild(combat_seq, CreateConditionSeeTarget());

    BTNode* combat_sel = CreateSelector();
    BTNode* attack_seq = CreateSequence();
    Sequence_AddChild(attack_seq, CreateConditionInRange());
    Sequence_AddChild(attack_seq, CreateActionAttack(1.0f));
    Selector_AddChild(combat_sel, attack_seq);
    Selector_AddChild(combat_sel, CreateActionChase());

    Sequence_AddChild(combat_seq, combat_sel);

    Selector_AddChild(root, flee_seq);
    Selector_AddChild(root, combat_seq);
    Selector_AddChild(root, CreateActionPatrol());

    /* 黑板 */
    Blackboard bb = {
        .self_x = 400, .self_y = 300,
        .target_x = 100, .target_y = 100,
        .self_hp = 100, .self_max_hp = 100,
        .view_range = 250, .attack_range = 50,
        .move_speed = 100,
        .patrol_target_x = 200, .patrol_target_y = 200
    };

    printf("操作: WASD移动玩家(目标), J攻击敌人, ESC退出\n");

    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;
        if (delta > 0.1f) delta = 0.1f;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
        }

        const Uint8* keys = SDL_GetKeyboardState(NULL);
        float speed = 250;
        if (keys[SDL_SCANCODE_W]) bb.target_y -= speed * delta;
        if (keys[SDL_SCANCODE_S]) bb.target_y += speed * delta;
        if (keys[SDL_SCANCODE_A]) bb.target_x -= speed * delta;
        if (keys[SDL_SCANCODE_D]) bb.target_x += speed * delta;
        if (keys[SDL_SCANCODE_J]) bb.self_hp -= 1;
        if (bb.self_hp < 0) bb.self_hp = 0;
        /* 自动回血 */
        if (!keys[SDL_SCANCODE_J] && bb.self_hp < bb.self_max_hp) {
            bb.self_hp += (int)(10 * delta);
            if (bb.self_hp > bb.self_max_hp) bb.self_hp = bb.self_max_hp;
        }

        /* 边界 */
        if (bb.target_x < 0) bb.target_x = 0;
        if (bb.target_x > WINDOW_W - 20) bb.target_x = WINDOW_W - 20;
        if (bb.target_y < 0) bb.target_y = 0;
        if (bb.target_y > WINDOW_H - 20) bb.target_y = WINDOW_H - 20;

        /* 执行行为树 */
        root->tick(root, &bb, delta);

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);

        /* 视野范围 */
        SDL_SetRenderDrawColor(renderer, 80, 80, 50, 255);
        for (int a = 0; a < 360; a += 5) {
            float rad = a * 3.14159f / 180.0f;
            SDL_RenderDrawPoint(renderer,
                (int)(bb.self_x + cosf(rad) * bb.view_range),
                (int)(bb.self_y + sinf(rad) * bb.view_range));
        }

        /* 攻击范围 */
        SDL_SetRenderDrawColor(renderer, 120, 50, 50, 255);
        for (int a = 0; a < 360; a += 5) {
            float rad = a * 3.14159f / 180.0f;
            SDL_RenderDrawPoint(renderer,
                (int)(bb.self_x + cosf(rad) * bb.attack_range),
                (int)(bb.self_y + sinf(rad) * bb.attack_range));
        }

        /* 目标（玩家，蓝色） */
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect target_rect = {(int)bb.target_x, (int)bb.target_y, 20, 20};
        SDL_RenderFillRect(renderer, &target_rect);

        /* 敌人（红色） */
        SDL_SetRenderDrawColor(renderer, 255, 100, 100, 255);
        SDL_Rect enemy_rect = {(int)bb.self_x - 15, (int)bb.self_y - 15, 30, 30};
        SDL_RenderFillRect(renderer, &enemy_rect);

        /* 血条 */
        SDL_SetRenderDrawColor(renderer, 60, 60, 60, 255);
        SDL_Rect hp_bg = {(int)bb.self_x - 15, (int)bb.self_y - 25, 30, 5};
        SDL_RenderFillRect(renderer, &hp_bg);
        SDL_SetRenderDrawColor(renderer, 255, 50, 50, 255);
        SDL_Rect hp_fill = {(int)bb.self_x - 15, (int)bb.self_y - 25,
                           30 * bb.self_hp / bb.self_max_hp, 5};
        SDL_RenderFillRect(renderer, &hp_fill);

        SDL_RenderPresent(renderer);
        SDL_Delay(16);
    }

    /* 注意：实际项目应递归释放所有节点，此处省略 */
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 行为树用层次化结构组织AI行为，比FSM更灵活可维护
- 核心节点：动作、条件、选择（任一成功）、序列（全部成功）、装饰
- 节点返回成功/失败/运行中三种状态
- 黑板模式解耦节点间数据共享
- 选择节点实现优先级（前面的子节点优先），序列节点实现顺序执行
- **常见坑**：节点内存需递归释放，避免泄漏；运行中状态的节点下次Tick从头开始，需用记忆节点保持进度；行为树过深时性能下降，可分层或并行

# 第6章 游戏系统设计

游戏由多个子系统组成：UI、存档、音频等。本章讲解这些系统的设计模式与实现，让你的游戏具备完整的用户体验。

## 第16讲 游戏UI系统

### 概念

游戏UI（用户界面）包括菜单、HUD（血条、分数）、按钮、滑块、文本框等。本讲讲解游戏UI系统的设计，包括控件树、布局系统、事件分发、皮肤主题等。

### 原理

**控件树（Widget Tree）**：

UI采用树形结构组织，根节点是桌面（Desktop），子节点是窗口、面板，再下层是按钮、文本等。父控件管理子控件的位置、可见性、事件分发。

**控件基类**：

所有控件继承自基类 Widget，包含：
- 位置、尺寸（相对父控件）
- 可见性、启用状态
- 父子关系
- 事件处理回调（点击、悬停、按键）

**布局系统**：

控件位置可以用两种方式指定：
- **绝对布局**：直接指定像素坐标，简单但不灵活
- **相对布局**：基于父控件的百分比、边距、对齐方式，适应不同分辨率

**事件分发**：

UI事件（鼠标点击、键盘）从根控件向下分发：
1. 从根控件开始，检查子控件是否在事件位置
2. 最上层（最后绘制的）子控件优先接收
3. 若子控件处理了事件，停止向下分发
4. 若未处理，继续检查其他子控件

**HUD vs 菜单**：

- **HUD（Head-Up Display）**：游戏中的信息显示（血条、小地图、分数），不阻挡游戏操作
- **菜单**：全屏或模态界面，暂停游戏，需要用户交互

**皮肤系统**：

UI外观通过皮肤（Skin）控制，皮肤定义颜色、纹理、字体等。切换皮肤可改变整体风格，无需修改代码。

**锚点（Anchor）**：

控件相对于父控件的对齐方式。如右上角的按钮，锚点设为"右上"，无论分辨率如何变化都保持在右上角。

### 例子

```c

#include <stdio.h>
#include <string.h>

typedef struct Widget Widget;

/* 事件类型 */
typedef enum {
    UI_EVENT_CLICK,
    UI_EVENT_HOVER,
    UI_EVENT_KEY
} UIEventType;

typedef struct {
    UIEventType type;
    int x, y;       /* 鼠标位置 */
    int key;        /* 按键 */
} UIEvent;

/* 控件基类结构 */
struct Widget {
    char name[32];
    int x, y;           /* 相对父控件位置 */
    int width, height;
    SDL_bool visible;
    SDL_bool enabled;
    SDL_bool hovered;
    SDL_bool pressed;

    Widget* parent;
    Widget* children[16];
    int child_count;

    /* 虚函数 */
    void (*render)(Widget* self, SDL_Renderer* r, int abs_x, int abs_y);
    SDL_bool (*handle_event)(Widget* self, UIEvent* event, int abs_x, int abs_y);

    /* 点击回调 */
    void (*on_click)(Widget* self, void* user_data);
    void* user_data;
};

void Widget_Init(Widget* w, const char* name, int x, int y, int width, int height) {
    strncpy(w->name, name, 31);
    w->name[31] = '\0';
    w->x = x; w->y = y;
    w->width = width; w->height = height;
    w->visible = SDL_TRUE;
    w->enabled = SDL_TRUE;
    w->hovered = SDL_FALSE;
    w->pressed = SDL_FALSE;
    w->parent = NULL;
    w->child_count = 0;
    w->render = NULL;
    w->handle_event = NULL;
    w->on_click = NULL;
    w->user_data = NULL;
}

void Widget_AddChild(Widget* parent, Widget* child) {
    if (parent->child_count < 16) {
        parent->children[parent->child_count++] = child;
        child->parent = parent;
    }
}

/* 检查点是否在控件内 */
SDL_bool Widget_Contains(Widget* w, int abs_x, int abs_y, int px, int py) {
    int wx = px + w->x, wy = py + w->y;
    return (abs_x >= wx && abs_x < wx + w->width &&
            abs_y >= wy && abs_y < wy + w->height);
}

/* 事件分发 */
SDL_bool Widget_DispatchEvent(Widget* w, UIEvent* event, int px, int py) {
    if (!w->visible || !w->enabled) return SDL_FALSE;

    int abs_x = px + w->x, abs_y = py + w->y;

    /* 先分发给子控件（从后向前，后绘制的在上层） */
    for (int i = w->child_count - 1; i >= 0; i--) {
        if (Widget_DispatchEvent(w->children[i], event, abs_x, abs_y)) {
            return SDL_TRUE;
        }
    }

    /* 检查自身 */
    if (event->type == UI_EVENT_CLICK) {
        if (Widget_Contains(w, event->x, event->y, px, py)) {
            w->pressed = SDL_TRUE;
            return SDL_TRUE;
        }
    }
    if (event->type == UI_EVENT_HOVER) {
        SDL_bool was_hovered = w->hovered;
        w->hovered = Widget_Contains(w, event->x, event->y, px, py);
        if (w->hovered && !was_hovered) {
            /* 鼠标进入 */
        }
    }

    /* 自身处理 */
    if (w->handle_event) {
        return w->handle_event(w, event, abs_x, abs_y);
    }
    return SDL_FALSE;
}

/* 渲染分发 */
void Widget_Render(Widget* w, SDL_Renderer* r, int px, int py) {
    if (!w->visible) return;

    int abs_x = px + w->x, abs_y = py + w->y;

    /* 渲染自身 */
    if (w->render) {
        w->render(w, r, abs_x, abs_y);
    }

    /* 渲染子控件 */
    for (int i = 0; i < w->child_count; i++) {
        Widget_Render(w->children[i], r, abs_x, abs_y);
    }
}

                    if (mx >= 300 && mx < 500 && my >= 300 && my < 340) {
```

- UI采用控件树结构，父控件管理子控件的位置和事件分发
- 控件基类定义通用属性（位置、尺寸、可见性）和虚函数（render、handle_event）
- 事件从根控件向下分发，最上层控件优先接收
- 布局系统支持绝对布局和相对布局（锚点）
- HUD 是游戏中的信息显示，菜单是模态交互界面
- **常见坑**：事件分发顺序很重要，后绘制的控件应先接收事件；控件销毁前要解除父子关系；UI坐标和游戏坐标可能不同（如 UI 不随摄像机移动）

## 第17讲 存档与序列化

### 概念

存档系统让玩家保存游戏进度并在之后恢复。本讲讲解游戏数据的序列化（将内存对象转为可存储格式）和反序列化，包括二进制格式、JSON格式、版本兼容等。

### 原理

**序列化的需求**：

游戏状态包括玩家位置、生命值、物品栏、任务进度、关卡状态等。这些数据需要保存到文件，下次游戏时恢复。序列化就是将内存中的结构化数据转换为可存储的字节流。

**序列化格式**：

1. **二进制格式**：直接将内存字节写入文件
   - 优点：紧凑、读写快
   - 缺点：不可读、平台相关（字节序）、版本兼容难

2. **文本格式**（JSON、XML、INI）：
   - 优点：可读、易调试、跨平台
   - 缺点：体积大、解析慢

3. **自定义格式**：根据游戏需求设计，平衡可读性和效率

**二进制序列化的字节序问题**：

不同 CPU 架构的字节序不同（x86 小端，ARM 可大可小）。跨平台存档需用固定字节序（通常小端）。SDL2 提供 `SDL_SwapLE16`、`SDL_SwapLE32` 等函数处理字节序转换。

**版本兼容**：

游戏更新后存档格式可能变化。解决方案：
1. 存档文件头部包含版本号
2. 加载时根据版本号执行不同的加载逻辑
3. 新版本兼容旧版本数据（添加默认值）

**存档策略**：

1. **手动存档**：玩家主动保存（存档点、菜单）
2. **自动存档**：定期或关键节点自动保存
3. **检查点存档**：到达检查点时保存

**存档内容**：

- 玩家状态：位置、生命值、属性、装备
- 世界状态：已击败的敌人、已开启的门、已收集的物品
- 进度状态：任务进度、解锁的关卡、成就
- 设置状态：音量、按键映射、画质选项

**存档安全**：

- 写入临时文件，成功后重命名为正式文件（原子写入）
- 校验和（Checksum）检测存档损坏
- 加密防止篡改（可选）

```c
#define SAVE_VERSION 2

SDL_bool SaveGame_Binary(const char* filename, SaveData* data) {
    /* 写入临时文件，成功后重命名 */
    char tmp_filename[256];
    snprintf(tmp_filename, sizeof(tmp_filename), "%s.tmp", filename);

    SDL_RWops* file = SDL_RWFromFile(tmp_filename, "wb");
    if (!file) {
        printf("无法创建存档文件: %s\n", SDL_GetError());
        return SDL_FALSE;
    }

    /* 写入魔数（标识文件类型） */
    const char magic[] = "SAV2";
    SDL_RWwrite(file, magic, 4, 1);

    /* 写入版本号 */
    int version = SAVE_VERSION;
    SDL_RWwrite(file, &version, sizeof(int), 1);

    /* 写入校验和（简单异或） */
    Uint32 checksum = 0;
    Uint8* bytes = (Uint8*)data;
    for (size_t i = 0; i < sizeof(SaveData); i++) {
        checksum ^= bytes[i];
    }
    SDL_RWwrite(file, &checksum, sizeof(Uint32), 1);

    /* 写入数据 */
    SDL_RWwrite(file, data, sizeof(SaveData), 1);

    SDL_RWclose(file);

    /* 重命名临时文件为正式文件 */
    if (rename(tmp_filename, filename) != 0) {
        printf("重命名存档文件失败\n");
        return SDL_FALSE;
    }

    printf("存档保存成功: %s\n", filename);
    return SDL_TRUE;
}

SDL_bool LoadGame_Binary(const char* filename, SaveData* data) {
    SDL_RWops* file = SDL_RWFromFile(filename, "rb");
    if (!file) {
        printf("无法打开存档文件: %s\n", SDL_GetError());
        return SDL_FALSE;
    }

    /* 读取并验证魔数 */
    char magic[4];
    SDL_RWread(file, magic, 4, 1);
    if (strncmp(magic, "SAV2", 4) != 0) {
        printf("无效的存档文件格式\n");
        SDL_RWclose(file);
        return SDL_FALSE;
    }

    /* 读取版本号 */
    int version;
    SDL_RWread(file, &version, sizeof(int), 1);
    if (version > SAVE_VERSION) {
        printf("不支持的存档版本: %d\n", version);
        SDL_RWclose(file);
        return SDL_FALSE;
    }

    /* 读取校验和 */
    Uint32 saved_checksum;
    SDL_RWread(file, &saved_checksum, sizeof(Uint32), 1);

    /* 读取数据 */
    SDL_RWread(file, data, sizeof(SaveData), 1);
    SDL_RWclose(file);

    /* 验证校验和 */
    Uint32 computed_checksum = 0;
    Uint8* bytes = (Uint8*)data;
    for (size_t i = 0; i < sizeof(SaveData); i++) {
        computed_checksum ^= bytes[i];
    }
    if (computed_checksum != saved_checksum) {
        printf("存档文件已损坏\n");
        return SDL_FALSE;
    }

    /* 版本兼容处理 */
    if (version < SAVE_VERSION) {
        printf("升级存档从版本 %d 到 %d\n", version, SAVE_VERSION);
        /* 补充新字段的默认值 */
        if (version < 2) {
            /* 版本1没有 play_time 字段，设置默认值 */
            data->play_time = 0;
        }
    }

    printf("存档加载成功: %s (版本 %d)\n", filename, version);
    return SDL_TRUE;
}

    /* 清空数据，模拟重新启动 */
    printf("\n清空内存数据...\n");
    memset(&save_data, 0, sizeof(SaveData));

    /* 加载二进制存档 */
    printf("\n加载二进制存档...\n");
    if (LoadGame_Binary(save_path, &save_data)) {
        PrintSaveData(&save_data);
    }

    if (pref_path) SDL_free(pref_path);
    SDL_Quit();
    return 0;
}
```

### 总结

- 序列化将内存对象转为可存储格式，反序列化恢复
- 二进制格式紧凑快速但不可读，文本格式（JSON）可读但体积大
- 跨平台存档需处理字节序问题
- 版本兼容：存档头部包含版本号，加载时执行升级逻辑
- 原子写入：先写临时文件，成功后重命名，避免写入中断导致损坏
- 校验和检测存档损坏
- **常见坑**：结构体中的指针不能直接序列化，需单独处理；字节序在不同平台不同；存档格式变更需向后兼容

## 第18讲 音频管理系统

### 概念

游戏音频管理包括音效播放、背景音乐、3D 音效、音频淡入淡出、音量控制等。本讲设计一个完整的音频管理系统，整合这些功能，提供简洁的 API。

### 原理

**音频管理器的职责**：

1. **资源管理**：加载、缓存、卸载音频资源
2. **播放控制**：播放、停止、暂停、恢复
3. **音量控制**：主音量、音效音量、音乐音量、BGM 分组
4. **3D 音效**：根据声源与听者位置调整音量和立体声
5. **淡入淡出**：平滑过渡，避免声音突变
6. **通道管理**：多通道同时播放，优先级控制

**音频分组**：

将音频分为几组独立控制音量：
- BGM（背景音乐）
- SFX（音效）
- Voice（语音）
- Ambient（环境音）

玩家可分别调整各组音量，或一键静音。

**音频资源缓存**：

音效文件加载到内存，按名称索引。首次播放时加载，后续直接使用缓存。资源管理器跟踪引用计数，无人使用时卸载。

**3D 音效原理**：

2D 游戏中模拟空间音效：
- 距离衰减：声源越远音量越低
- 立体声平衡：声源在左侧，左声道音量大
- 遮挡效果：声源被墙阻挡，音量降低（简化版可忽略）

**淡入淡出实现**：

维护一个淡入淡出状态机：
- 当前音量
- 目标音量
- 淡变速率（每秒变化多少）

每帧更新当前音量，向目标值靠近。到达目标后停止。

**音频事件**：

音频播放完成时触发回调，用于：
- 链式播放（一个音效结束后播放下一个）
- 通知游戏逻辑（如语音播放完毕）

**音频池**：

对于频繁播放的音效（如枪声），预创建多个播放实例，避免每次加载。类似对象池模式。

### 例子

```c
#include <SDL2/SDL.h>
#include <SDL2/SDL_mixer.h>
#include <stdio.h>
#include <string.h>
#include <math.h>

/* ============ 音频管理器 ============ */

#define MAX_SOUNDS 32
#define MAX_MUSIC 8
#define AUDIO_CHANNELS 32

/* 音频分组 */
typedef enum {
    AUDIO_GROUP_BGM = 0,
    AUDIO_GROUP_SFX,
    AUDIO_GROUP_VOICE,
    AUDIO_GROUP_COUNT
} AudioGroup;

/* 音效资源 */
typedef struct {
    char name[32];
    Mix_Chunk* chunk;
    int ref_count;
} SoundResource;

/* 音乐资源 */
typedef struct {
    char name[32];
    Mix_Music* music;
} MusicResource;

/* 淡变状态 */
typedef struct {
    SDL_bool active;
    float current;
    float target;
    float rate;  /* 每秒变化量 */
} FadeState;

/* 音频管理器 */
typedef struct {
    SoundResource sounds[MAX_SOUNDS];
    int sound_count;
    MusicResource musics[MAX_MUSIC];
    int music_count;

    int group_volume[AUDIO_GROUP_COUNT];  /* 0-128 */
    int master_volume;

    /* 当前播放的音乐 */
    int current_music;
    FadeState music_fade;

    /* 通道分组（哪些通道属于哪个组） */
    int channel_group[AUDIO_CHANNELS];
} AudioManager;

void Audio_Init(AudioManager* am) {
    memset(am, 0, sizeof(*am));
    Mix_OpenAudio(44100, MIX_DEFAULT_FORMAT, 2, 2048);
    Mix_AllocateChannels(AUDIO_CHANNELS);

    /* 默认音量 */
    am->master_volume = 128;
    for (int i = 0; i < AUDIO_GROUP_COUNT; i++) {
        am->group_volume[i] = 100;
    }
    am->current_music = -1;

    /* 默认通道分组：0-3 BGM, 4-15 SFX, 16-31 Voice */
    for (int i = 0; i < 4; i++) am->channel_group[i] = AUDIO_GROUP_BGM;
    for (int i = 4; i < 16; i++) am->channel_group[i] = AUDIO_GROUP_SFX;
    for (int i = 16; i < 32; i++) am->channel_group[i] = AUDIO_GROUP_VOICE;
}

void Audio_Cleanup(AudioManager* am) {
    for (int i = 0; i < am->sound_count; i++) {
        if (am->sounds[i].chunk) Mix_FreeChunk(am->sounds[i].chunk);
    }
    for (int i = 0; i < am->music_count; i++) {
        if (am->musics[i].music) Mix_FreeMusic(am->musics[i].music);
    }
    Mix_CloseAudio();
}

/* 计算实际音量 = 主音量 * 组音量 / 128 */
int Audio_GetEffectiveVolume(AudioManager* am, AudioGroup group) {
    return am->master_volume * am->group_volume[group] / 128;
}

/* 加载音效 */
int Audio_LoadSound(AudioManager* am, const char* name, const char* path) {
    if (am->sound_count >= MAX_SOUNDS) return -1;
    Mix_Chunk* chunk = Mix_LoadWAV(path);
    if (!chunk) {
        printf("加载音效失败 %s: %s\n", path, Mix_GetError());
        return -1;
    }
    strncpy(am->sounds[am->sound_count].name, name, 31);
    am->sounds[am->sound_count].chunk = chunk;
    am->sounds[am->sound_count].ref_count = 0;
    return am->sound_count++;
}

/* 查找音效 */
int Audio_FindSound(AudioManager* am, const char* name) {
    for (int i = 0; i < am->sound_count; i++) {
        if (strcmp(am->sounds[i].name, name) == 0) return i;
    }
    return -1;
}

/* 播放音效 */
int Audio_PlaySound(AudioManager* am, const char* name, AudioGroup group) {
    int idx = Audio_FindSound(am, name);
    if (idx < 0) return -1;

    /* 找到该组的空闲通道 */
    int channel = -1;
    for (int i = 0; i < AUDIO_CHANNELS; i++) {
        if (am->channel_group[i] == group) {
            if (!Mix_Playing(i)) {
                channel = i;
                break;
            }
        }
    }
    if (channel < 0) {
        /* 没有空闲通道，强制使用第一个 */
        for (int i = 0; i < AUDIO_CHANNELS; i++) {
            if (am->channel_group[i] == group) {
                channel = i;
                break;
            }
        }
    }
    if (channel < 0) return -1;

    /* 设置音量 */
    Mix_Volume(channel, Audio_GetEffectiveVolume(am, group));

    /* 播放 */
    Mix_PlayChannel(channel, am->sounds[idx].chunk, 0);
    return channel;
}

/* 3D 音效播放 */
void Audio_PlaySound3D(AudioManager* am, const char* name,
                       float listener_x, float listener_y,
                       float source_x, float source_y,
                       float max_distance) {
    int idx = Audio_FindSound(am, name);
    if (idx < 0) return;

    float dx = source_x - listener_x;
    float dy = source_y - listener_y;
    float distance = sqrtf(dx * dx + dy * dy);

    /* 距离衰减 */
    float volume_ratio = 1.0f - (distance / max_distance);
    if (volume_ratio < 0) volume_ratio = 0;

    /* 立体声平衡 */
    float pan = dx / max_distance;
    if (pan > 1) pan = 1;
    if (pan < -1) pan = -1;

    /* 找通道并播放 */
    int channel = Audio_PlaySound(am, name, AUDIO_GROUP_SFX);
    if (channel >= 0) {
        /* 设置音量 */
        int vol = (int)(Audio_GetEffectiveVolume(am, AUDIO_GROUP_SFX) * volume_ratio);
        Mix_Volume(channel, vol);
        /* 设置立体声平衡 */
        Uint8 left = (Uint8)(255 * (1.0f - pan) / 2);
        Uint8 right = (Uint8)(255 * (1.0f + pan) / 2);
        Mix_SetPanning(channel, left, right);
    }
}

/* 播放音乐 */
void Audio_PlayMusic(AudioManager* am, const char* name, SDL_bool loop) {
    for (int i = 0; i < am->music_count; i++) {
        if (strcmp(am->musics[i].name, name) == 0) {
            am->current_music = i;
            Mix_VolumeMusic(Audio_GetEffectiveVolume(am, AUDIO_GROUP_BGM));
            Mix_PlayMusic(am->musics[i].music, loop ? -1 : 1);
            return;
        }
    }
}

/* 音乐淡入 */
void Audio_FadeMusic(AudioManager* am, float target, float duration) {
    am->music_fade.active = SDL_TRUE;
    am->music_fade.current = am->group_volume[AUDIO_GROUP_BGM] / 128.0f;
    am->music_fade.target = target;
    am->music_fade.rate = fabsf(target - am->music_fade.current) / duration;
}

/* 更新音频管理器 */
void Audio_Update(AudioManager* am, float delta) {
    /* 更新音乐淡变 */
    if (am->music_fade.active) {
        float diff = am->music_fade.target - am->music_fade.current;
        float step = am->music_fade.rate * delta;
        if (fabsf(diff) <= step) {
            am->music_fade.current = am->music_fade.target;
            am->music_fade.active = SDL_FALSE;
        } else {
            am->music_fade.current += (diff > 0 ? step : -step);
        }
        /* 应用到音乐音量 */
        int vol = (int)(am->music_fade.current * 128 *
                       am->master_volume / 128);
        Mix_VolumeMusic(vol);
    }
}

/* 设置组音量 */
void Audio_SetGroupVolume(AudioManager* am, AudioGroup group, int volume) {
    am->group_volume[group] = volume;
    if (group == AUDIO_GROUP_BGM) {
        Mix_VolumeMusic(Audio_GetEffectiveVolume(am, group));
    }
}

/* ============ 主程序 ============ */

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO | SDL_INIT_AUDIO);

    SDL_Window* window = SDL_CreateWindow(
        "音频管理示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    AudioManager audio;
    Audio_Init(&audio);

    printf("音频管理器初始化成功\n");
    printf("操作:\n");
    printf("  1 - 播放音效（需加载文件）\n");
    printf("  2 - 播放 3D 音效（鼠标位置）\n");
    printf("  3 - 音乐淡入\n");
    printf("  4 - 音乐淡出\n");
    printf("  +/- - 调整主音量\n");
    printf("  ESC - 退出\n");

    /* 模拟听者位置 */
    float listener_x = 400, listener_y = 300;

    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN) {
                switch (event.key.keysym.scancode) {
                case SDL_SCANCODE_ESCAPE:
                    running = SDL_FALSE;
                    break;
                case SDL_SCANCODE_1:
                    /* 播放音效（需实际文件） */
                    printf("播放音效（需加载音频文件）\n");
                    break;
                case SDL_SCANCODE_2: {
                    int mx, my;
                    SDL_GetMouseState(&mx, &my);
                    printf("3D 音效: 声源(%d, %d) 距离 %.0f\n",
                           mx, my,
                           sqrtf((mx-listener_x)*(mx-listener_x) +
                                (my-listener_y)*(my-listener_y)));
                    break;
                }
                case SDL_SCANCODE_3:
                    Audio_FadeMusic(&audio, 1.0f, 2.0f);
                    printf("音乐淡入\n");
                    break;
                case SDL_SCANCODE_4:
                    Audio_FadeMusic(&audio, 0.0f, 2.0f);
                    printf("音乐淡出\n");
                    break;
                case SDL_SCANCODE_EQUALS:
                    audio.master_volume = (audio.master_volume + 16 > 128) ?
                        128 : audio.master_volume + 16;
                    printf("主音量: %d\n", audio.master_volume);
                    break;
                case SDL_SCANCODE_MINUS:
                    audio.master_volume = (audio.master_volume - 16 < 0) ?
                        0 : audio.master_volume - 16;
                    printf("主音量: %d\n", audio.master_volume);
                    break;
                }
            }
        }

        Audio_Update(&audio, delta);

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);

        /* 绘制听者（中心） */
        SDL_SetRenderDrawColor(renderer, 100, 255, 100, 255);
        SDL_Rect listener = {(int)listener_x - 10, (int)listener_y - 10, 20, 20};
        SDL_RenderFillRect(renderer, &listener);

        /* 绘制鼠标位置 */
        int mx, my;
        SDL_GetMouseState(&mx, &my);
        SDL_SetRenderDrawColor(renderer, 255, 100, 100, 255);
        SDL_Rect mouse = {mx - 5, my - 5, 10, 10};
        SDL_RenderFillRect(renderer, &mouse);

        /* 绘制音量条 */
        for (int i = 0; i < AUDIO_GROUP_COUNT; i++) {
            int x = 10 + i * 200;
            SDL_SetRenderDrawColor(renderer, 60, 60, 60, 255);
            SDL_Rect bg = {x, 10, 180, 20};
            SDL_RenderFillRect(renderer, &bg);
            SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
            SDL_Rect fill = {x, 10, 180 * audio.group_volume[i] / 128, 20};
            SDL_RenderFillRect(renderer, &fill);
        }

        SDL_RenderPresent(renderer);
        SDL_Delay(16);
    }

    Audio_Cleanup(&audio);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

## 第19讲 渲染与内存优化

### 概念

渲染是游戏性能的主要瓶颈。本讲讲解渲染优化的各种技术，包括批处理、纹理图集、视锥剔除、LOD 等，以及内存优化策略，让游戏在低端设备上也能流畅运行。

### 原理

**渲染性能瓶颈分析**：

游戏渲染性能受以下因素影响：
1. **Draw Call 数量**：每次 `SDL_RenderCopy` 都是一次 Draw Call，GPU 状态切换开销大
2. **填充率（Fill Rate）**：每秒能渲染的像素数，大窗口或过度绘制会耗尽
3. **纹理带宽**：纹理上传和采样的内存带宽
4. **CPU 开销**：渲染命令的构建和提交

**批处理（Batching）**：

将相同纹理的多个绘制合并为一次 Draw Call。SDL2 2.0.10+ 的渲染器内部已支持批处理，但需要开发者配合：
- 相同纹理的对象集中绘制
- 避免频繁切换纹理
- 避免在绘制中间改变渲染状态（颜色、混合模式）

**纹理图集（Texture Atlas）**：

将多个小纹理合并为一张大纹理，绘制时通过源矩形切分。优势：
- 减少纹理绑定次数
- 减少 Draw Call
- 提高 GPU 纹理缓存命中率

**视锥剔除（Frustum Culling）**：

只渲染在摄像机视锥内的对象。2D 游戏中简化为屏幕边界剔除：不绘制完全在屏幕外的对象。

**LOD（Level of Detail）**：

根据对象与摄像机距离使用不同精度的资源：
- 近处：高分辨率纹理、复杂动画
- 远处：低分辨率纹理、简化动画

**过度绘制（Overdraw）**：

同一像素被多次绘制。多层半透明 UI、粒子系统容易导致过度绘制。优化方法：
- 减少不必要的半透明层
- 合并相邻的 UI 元素
- 粒子使用加法混合而非 Alpha 混合

**内存优化**：

1. **资源按需加载**：关卡资源在进入关卡时加载，退出时卸载
2. **纹理压缩**：使用 GPU 支持的压缩格式（DXT、ETC、PVRTC）
3. **对象池**：复用对象，避免频繁内存分配
4. **数据布局**：ECS 的连续内存布局提高缓存命中率

**性能分析**：

优化前必须测量。常用指标：
- FPS（每秒帧数）
- 帧时间（每帧毫秒数，更精确）
- Draw Call 数
- 内存占用

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>
#include <stdlib.h>

#define WINDOW_W 800
#define WINDOW_H 600
#define MAX_OBJECTS 2000

/* 游戏对象 */
typedef struct {
    float x, y;
    int w, h;
    int texture_id;  /* 纹理 ID */
    SDL_bool active;
} RenderObject;

/* 纹理图集（模拟） */
typedef struct {
    SDL_Texture* texture;
    int tile_size;
    int tiles_per_row;
} TextureAtlas;

/* 性能监控 */
typedef struct {
    int frame_count;
    Uint32 fps_timer;
    int current_fps;
    int draw_calls;
    int objects_rendered;
    int objects_culled;
} PerfMonitor;

void Perf_Init(PerfMonitor* pm) {
    pm->frame_count = 0;
    pm->fps_timer = SDL_GetTicks();
    pm->current_fps = 0;
    pm->draw_calls = 0;
    pm->objects_rendered = 0;
    pm->objects_culled = 0;
}

void Perf_Update(PerfMonitor* pm) {
    pm->frame_count++;
    Uint32 now = SDL_GetTicks();
    if (now - pm->fps_timer >= 1000) {
        pm->current_fps = pm->frame_count * 1000 / (now - pm->fps_timer);
        pm->frame_count = 0;
        pm->fps_timer = now;
        printf("FPS: %d, DrawCalls: %d, Rendered: %d, Culled: %d\n",
               pm->current_fps, pm->draw_calls,
               pm->objects_rendered, pm->objects_culled);
    }
}

/* 创建纹理图集 */
TextureAtlas CreateAtlas(SDL_Renderer* r, int tile_size, int tiles_per_row, int rows) {
    TextureAtlas atlas;
    atlas.tile_size = tile_size;
    atlas.tiles_per_row = tiles_per_row;
    atlas.texture = SDL_CreateTexture(r, SDL_PIXELFORMAT_RGBA8888,
        SDL_TEXTUREACCESS_TARGET, tile_size * tiles_per_row, tile_size * rows);
    SDL_SetRenderTarget(r, atlas.texture);
    SDL_SetRenderDrawColor(r, 0, 0, 0, 0);
    SDL_RenderClear(r);
    /* 生成不同颜色的方块 */
    for (int row = 0; row < rows; row++) {
        for (int col = 0; col < tiles_per_row; col++) {
            SDL_SetRenderDrawColor(r,
                50 + col * 20, 100 + row * 30, 200, 255);
            SDL_Rect tile = {col * tile_size, row * tile_size, tile_size, tile_size};
            SDL_RenderFillRect(r, &tile);
        }
    }
    SDL_SetRenderTarget(r, NULL);
    return atlas;
}

/* 视锥剔除：检查对象是否在屏幕内 */
SDL_bool IsVisible(RenderObject* obj, int cam_x, int cam_y) {
    int screen_x = (int)obj->x - cam_x;
    int screen_y = (int)obj->y - cam_y;
    return (screen_x + obj->w > 0 && screen_x < WINDOW_W &&
            screen_y + obj->h > 0 && screen_y < WINDOW_H);
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow(
        "性能优化示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        WINDOW_W, WINDOW_H, SDL_WINDOW_SHOWN);
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED | SDL_RENDERER_PRESENTVSYNC);

    TextureAtlas atlas = CreateAtlas(renderer, 32, 8, 4);

    /* 创建大量对象 */
    RenderObject objects[MAX_OBJECTS];
    for (int i = 0; i < MAX_OBJECTS; i++) {
        objects[i].x = (float)(rand() % 3200 - 400);  /* 世界范围比屏幕大 */
        objects[i].y = (float)(rand() % 2400 - 300);
        objects[i].w = 32;
        objects[i].h = 32;
        objects[i].texture_id = rand() % 32;
        objects[i].active = SDL_TRUE;
    }

    PerfMonitor perf;
    Perf_Init(&perf);

    int cam_x = 0, cam_y = 0;
    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();

    printf("操作: 方向键移动摄像机, 1切换优化模式, ESC退出\n");
    printf("优化模式: 0=无优化, 1=视锥剔除+排序\n");

    int optimize = 1;

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN) {
                if (event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                    running = SDL_FALSE;
                if (event.key.keysym.scancode == SDL_SCANCODE_1)
                    optimize = !optimize;
            }
        }

        /* 摄像机移动 */
        const Uint8* keys = SDL_GetKeyboardState(NULL);
        int cam_speed = 500;
        if (keys[SDL_SCANCODE_LEFT])  cam_x -= (int)(cam_speed * delta);
        if (keys[SDL_SCANCODE_RIGHT]) cam_x += (int)(cam_speed * delta);
        if (keys[SDL_SCANCODE_UP])    cam_y -= (int)(cam_speed * delta);
        if (keys[SDL_SCANCODE_DOWN])  cam_y += (int)(cam_speed * delta);

        /* 重置统计 */
        perf.draw_calls = 0;
        perf.objects_rendered = 0;
        perf.objects_culled = 0;

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        if (optimize) {
            /* 优化模式：视锥剔除 + 按纹理排序 */
            /* 第1步：收集可见对象 */
            RenderObject* visible[MAX_OBJECTS];
            int visible_count = 0;
            for (int i = 0; i < MAX_OBJECTS; i++) {
                if (!objects[i].active) continue;
                if (IsVisible(&objects[i], cam_x, cam_y)) {
                    visible[visible_count++] = &objects[i];
                } else {
                    perf.objects_culled++;
                }
            }

            /* 第2步：按纹理 ID 排序（简化冒泡） */
            for (int i = 0; i < visible_count - 1; i++) {
                for (int j = 0; j < visible_count - i - 1; j++) {
                    if (visible[j]->texture_id > visible[j+1]->texture_id) {
                        RenderObject* tmp = visible[j];
                        visible[j] = visible[j+1];
                        visible[j+1] = tmp;
                    }
                }
            }

            /* 第3步：批量绘制 */
            int current_tex = -1;
            for (int i = 0; i < visible_count; i++) {
                RenderObject* obj = visible[i];
                int tex_id = obj->texture_id;
                /* 计算源矩形（纹理图集中的位置） */
                SDL_Rect src = {
                    (tex_id % atlas.tiles_per_row) * atlas.tile_size,
                    (tex_id / atlas.tiles_per_row) * atlas.tile_size,
                    atlas.tile_size, atlas.tile_size
                };
                SDL_Rect dest = {
                    (int)obj->x - cam_x, (int)obj->y - cam_y,
                    obj->w, obj->h
                };
                SDL_RenderCopy(renderer, atlas.texture, &src, &dest);
                perf.objects_rendered++;
            }
            /* 使用纹理图集，所有绘制共用一个纹理，Draw Call 最少 */
            perf.draw_calls = 1;
        } else {
            /* 无优化模式：直接绘制所有对象 */
            for (int i = 0; i < MAX_OBJECTS; i++) {
                if (!objects[i].active) continue;
                SDL_Rect src = {
                    (objects[i].texture_id % atlas.tiles_per_row) * atlas.tile_size,
                    (objects[i].texture_id / atlas.tiles_per_row) * atlas.tile_size,
                    atlas.tile_size, atlas.tile_size
                };
                SDL_Rect dest = {
                    (int)objects[i].x - cam_x, (int)objects[i].y - cam_y,
                    objects[i].w, objects[i].h
                };
                SDL_RenderCopy(renderer, atlas.texture, &src, &dest);
                perf.objects_rendered++;
                perf.draw_calls++;
            }
        }

        SDL_RenderPresent(renderer);
        Perf_Update(&perf);
    }

    SDL_DestroyTexture(atlas.texture);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 渲染瓶颈：Draw Call 数量、填充率、纹理带宽、CPU 开销
- 批处理：相同纹理的对象集中绘制，减少 Draw Call
- 纹理图集：多个小纹理合并为大纹理，减少纹理切换
- 视锥剔除：只渲染屏幕内的对象，大幅减少绘制量
- LOD：根据距离使用不同精度资源
- 性能优化必须基于测量，用 FPS 和帧时间量化
- **常见坑**：过度绘制导致填充率耗尽；纹理切换频繁打断批处理；优化过度反而降低可读性，应先测量再优化

## 第20讲 资源管理与热加载

### 概念

游戏资源（纹理、音频、动画）的管理是大型项目的关键。本讲讲解资源管理器的设计、引用计数、资源缓存、热加载（Hot Reload）等技术，让资源管理高效且灵活。

### 原理

**资源管理器的职责**：

1. **加载**：从文件加载资源到内存
2. **缓存**：已加载资源保留在内存，避免重复加载
3. **引用计数**：跟踪资源使用者数量，无人使用时卸载
4. **查找**：按名称或路径快速查找资源
5. **生命周期管理**：资源的加载、使用、卸载时机

**引用计数（Reference Counting）**：

每个资源维护一个引用计数：
- 加载时计数为 0
- 使用者获取资源时计数 +1
- 使用者释放资源时计数 -1
- 计数归 0 时卸载资源

这避免了资源被多个对象使用时提前卸载的问题。

**资源缓存策略**：

1. **永久缓存**：常用资源（UI 纹理、基础音效）常驻内存
2. **LRU 缓存**：最近最少使用策略，内存不足时卸载最久未用的
3. **关卡缓存**：按关卡分组，退出关卡时卸载整组

**异步加载**：

资源加载是 I/O 密集操作，在主线程加载会导致卡顿。解决方案：
- 后台线程加载资源
- 加载完成后通过事件通知主线程
- 加载期间显示加载界面或占位资源

**热加载（Hot Reload）**：

开发期间修改资源文件后，无需重启程序即可看到效果。实现方式：
- 监控资源文件的修改时间
- 文件变化时重新加载
- 替换内部资源指针

热加载大幅提升开发效率，是现代游戏引擎的标配功能。

**资源打包**：

发布版本将资源打包为单个文件（如 PAK、ZIP），优势：
- 减少文件数量
- 支持压缩
- 支持加密
- 加载更快（顺序读取）

**资源依赖**：

资源间可能有依赖（如动画引用纹理）。卸载资源时需检查依赖，避免卸载被其他资源引用的资源。

```c
#define MAX_RESOURCES 128
#define MAX_NAME 64

typedef enum {
    RES_TEXTURE = 0,
    RES_SOUND,
    RES_FONT,
    RES_TYPE_COUNT
} ResourceType;

/* 资源头 */
typedef struct {
    char name[MAX_NAME];
    ResourceType type;
    int ref_count;
    Uint32 last_modified;  /* 文件修改时间（热加载用） */
    char path[256];
    void* data;  /* 实际资源指针 */
} Resource;

typedef struct {
    Resource resources[MAX_RESOURCES];
    int count;
    SDL_Renderer* renderer;
} ResourceManager;

void RM_Init(ResourceManager* rm, SDL_Renderer* r) {
    memset(rm, 0, sizeof(*rm));
    rm->renderer = r;
}

/* 查找资源 */
int RM_Find(ResourceManager* rm, const char* name) {
    for (int i = 0; i < rm->count; i++) {
        if (strcmp(rm->resources[i].name, name) == 0) return i;
    }
    return -1;
}

/* 加载纹理资源 */
SDL_Texture* RM_LoadTexture(ResourceManager* rm, const char* name, const char* path) {
    /* 检查是否已加载 */
    int idx = RM_Find(rm, name);
    if (idx >= 0) {
        rm->resources[idx].ref_count++;
        return (SDL_Texture*)rm->resources[idx].data;
    }

    /* 加载新资源 */
    if (rm->count >= MAX_RESOURCES) return NULL;

    SDL_Texture* tex = IMG_LoadTexture(rm->renderer, path);
    if (!tex) {
        /* 创建占位纹理 */
        tex = SDL_CreateTexture(rm->renderer, SDL_PIXELFORMAT_RGBA8888,
            SDL_TEXTUREACCESS_TARGET, 32, 32);
        SDL_SetRenderTarget(rm->renderer, tex);
        SDL_SetRenderDrawColor(rm->renderer, 255, 0, 255, 255);  /* 紫色表示缺失 */
        SDL_RenderClear(rm->renderer);
        SDL_SetRenderTarget(rm->renderer, NULL);

    res->ref_count = 1;

    res->data = tex;
    rm->count++;
```
