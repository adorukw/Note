# 第一章：Vue3 基础入门

本章将带你认识 Vue3 的全貌，搭建开发环境，并编写第一个 Vue3 应用。这是后续所有内容的基础。

## 第 1 讲：Vue3 概述与环境搭建

### 概念

Vue（发音为 /vjuː/，类似 view）是一套用于构建用户界面的**渐进式 JavaScript 框架**。Vue3 是其第三个主要版本，于 2020 年 9 月正式发布。所谓"渐进式"，是指你可以根据项目需求，从简单的页面增强逐步扩展到完整的单页应用（SPA），而不必一开始就引入整个生态。

Vue3 相比 Vue2 的核心改进包括：全新的 Composition API、基于 Proxy 的响应式系统、更好的 TypeScript 支持、更小的打包体积（Tree-shaking 友好），以及新增的 Teleport、Suspense、Fragments 等特性。

### 原理

Vue3 的架构设计遵循"声明式渲染 → 组件系统 → 客户端路由 → 状态管理 → 构建工具"的渐进式分层。其核心引擎由以下几部分组成：

1. **响应式系统（Reactivity）**：基于 ES6 Proxy 实现，能够自动追踪依赖关系，当数据变化时自动更新视图。
2. **编译器（Compiler）**：将模板编译为渲染函数，支持静态提升、补丁标记等优化。
3. **运行时（Runtime）**：负责创建组件实例、渲染虚拟 DOM、执行补丁操作。

Vue3 的虚拟 DOM 相比 Vue2 引入了**静态提升**和**补丁标记**优化：编译器在编译阶段会标记出哪些节点是动态的，运行时只对这些节点进行 diff，从而大幅提升性能。

### 例子

**方式一：使用 CDN 引入（适合学习演示）**

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Vue3 入门</title>
  <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
</head>
<body>
  <div id="app">
    <h1>{{ message }}</h1>
  </div>

  <script>
    const { createApp } = Vue
    createApp({
      data() {
        return { message: 'Hello, Vue3!' }
      }
    }).mount('#app')
  </script>
</body>
</html>
```

**方式二：使用 Vite 创建工程化项目（推荐）**

```bash

# 按提示选择配置后，进入项目目录

```

**方式三：使用 Vue CLI（传统方式）**

```bash

vue create my-project
```

### 总结

- Vue3 是渐进式框架，可从 CDN 引入到完整工程化项目灵活选择。
- Vue3 的核心改进：Composition API、Proxy 响应式、更优的编译优化、原生 TypeScript 支持。
- 学习阶段推荐用 CDN 快速试验；实际项目推荐用 Vite 创建。
- **注意事项**：Vue3 不再支持 IE11，需要现代浏览器；Node.js 版本建议 18 以上。

## 第 2 讲：创建第一个 Vue3 应用

### 概念

一个 Vue3 应用的起点是 `createApp` 函数。它接收一个根组件配置对象，返回一个应用实例。通过应用实例的 `mount` 方法，可以将整个应用挂载到 DOM 中的某个元素上。这是 Vue3 与 Vue2 在启动方式上的重要区别：Vue2 使用 `new Vue()`，而 Vue3 使用 `createApp()`。

### 原理

`createApp` 内部会创建一个应用实例，该实例维护着应用的配置（全局组件、指令、插件等）。调用 `mount` 时，Vue 会以根组件为模板，渲染出虚拟 DOM，再转换为真实 DOM 插入到挂载点。

应用实例还提供了一系列注册全局 API 的方法，如 `component`（注册全局组件）、`directive`（注册全局指令）、`use`（安装插件）、`provide`（全局注入）等。这些 API 都链式调用，例如 `app.component(...).directive(...).mount(...)`。

### 例子

**例子 1：Options API 风格（传统写法）**

```javascript
const { createApp } = Vue

const app = createApp({
  // 数据
  data() {
    return {
      count: 0,
      user: { name: '张三' }
    }
  },
  // 方法
  methods: {
    increment() {
      this.count++
    }
  },
  // 生命周期
  mounted() {
    console.log('应用已挂载')
  }
})

app.mount('#app')
```

**例子 2：Composition API 风格（Vue3 推荐）**

```javascript
const { createApp, ref, onMounted } = Vue

const app = createApp({
  setup() {
    const count = ref(0)
    const user = ref({ name: '张三' })

    function increment() {
      count.value++
    }

    onMounted(() => {
      console.log('应用已挂载')
    })

    return { count, user, increment }
  }
})

app.mount('#app')
```

对应的 HTML：

```html
<div id="app">
  <p>用户：{{ user.name }}</p>
  <p>计数：{{ count }}</p>
  <button @click="increment">+1</button>
</div>
```

**例子 3：应用配置与全局注册**

```javascript
const app = createApp({ /* 根组件 */ })

// 注册全局组件
app.component('MyButton', {
  template: '<button class="my-btn"><slot/></button>'
})

// 注册全局指令
app.directive('focus', {
  mounted(el) {
    el.focus()
  }
})

// 安装插件
app.use(myPlugin)

// 全局错误处理
app.config.errorHandler = (err, instance, info) => {
  console.error('全局错误：', err, info)
}

app.mount('#app')
```

### 总结

- `createApp` 是 Vue3 应用的入口，返回应用实例。
- `mount` 方法将应用挂载到 DOM 元素，一个应用只能挂载一次。
- 应用实例提供 `component`、`directive`、`use`、`provide` 等全局配置方法。
- **注意事项**：`mount` 必须放在所有全局配置之后调用；挂载后修改配置不会生效。Composition API 的 `setup` 是 Vue3 推荐的写法，后续章节会详细讲解。

## 第 3 讲：模板语法与指令

### 概念

Vue 使用基于 HTML 的模板语法，允许开发者声明式地将 DOM 绑定至底层组件实例的数据。所有 Vue 模板都是合法的 HTML，能被浏览器和 HTML 解析器解析。指令（Directives）是带有 `v-` 前缀的特殊属性，用于在模板中应用特定的行为。

### 原理

Vue 模板在底层会被编译成 JavaScript 渲染函数。渲染函数执行时返回虚拟 DOM 树，Vue 再通过 diff 算法将其与上一次的虚拟 DOM 比较，最终只更新变化的部分到真实 DOM。

指令的工作机制：当指令表达式中的值变化时，Vue 会将其副作用应用到 DOM 上。例如 `v-if` 会根据条件决定是否渲染元素，`v-bind` 会更新元素的属性。每个指令可以定义多个钩子（如 `created`、`mounted`、`updated`），在不同阶段执行逻辑。

### 例子

**例子 1：文本插值与表达式**

```html
<div id="app">
  <!-- 文本插值 -->
  <p>{{ message }}</p>
  <!-- JavaScript 表达式 -->
  <p>{{ number + 1 }}</p>
  <p>{{ ok ? 'YES' : 'NO' }}</p>
  <p>{{ message.split('').reverse().join('') }}</p>
</div>

<script>
const { createApp, ref } = Vue
createApp({
  setup() {
    const message = ref('Hello')
    const number = ref(10)
    const ok = ref(true)
    return { message, number, ok }
  }
}).mount('#app')
</script>
```

**例子 2：常用指令**

```html
<div id="app">
  <!-- v-bind：绑定属性，简写为 : -->
  <a :href="url" :title="linkTitle">链接</a>
  <img :src="imgSrc" :alt="imgAlt">

  <!-- v-on：监听事件，简写为 @ -->
  <button @click="handleClick">点击</button>
  <input @keyup.enter="onEnter">

  <!-- v-if / v-else-if / v-else：条件渲染 -->
  <p v-if="type === 'A'">A</p>
  <p v-else-if="type === 'B'">B</p>
  <p v-else>其他</p>

  <!-- v-show：通过 display 控制显示 -->
  <p v-show="visible">显示或隐藏</p>

  <!-- v-for：列表渲染，需提供 key -->
  <ul>
    <li v-for="(item, index) in items" :key="item.id">
      {{ index }} - {{ item.name }}
    </li>
  </ul>

  <!-- v-model：双向绑定 -->
  <input v-model="message" placeholder="输入内容">
  <p>你输入了：{{ message }}</p>

  <!-- v-html：渲染 HTML（注意 XSS 风险） -->
  <div v-html="rawHtml"></div>

  <!-- v-text：更新元素的 textContent -->
  <span v-text="message"></span>

  <!-- v-once：只渲染一次 -->
  <p v-once>{{ message }}</p>
</div>
```

**例子 3：v-model 的修饰符**

```html
<div id="app">
  <!-- .lazy：在 change 而非 input 时同步 -->
  <input v-model.lazy="msg">

  <!-- .number：自动转为数字 -->
  <input v-model.number="age" type="number">

  <!-- .trim：自动去除首尾空格 -->
  <input v-model.trim="name">
</div>
```

**例子 4：动态参数（Vue3 新特性）**

```html
<div id="app">
  <!-- 动态事件名 -->
  <a @[eventName]="doSomething">动态事件</a>
  <!-- 动态属性名 -->
  <a :[attrName]="url">动态属性</a>
</div>

<script>
const { createApp, ref } = Vue
createApp({
  setup() {
    const eventName = ref('click')
    const attrName = ref('href')
    const url = ref('https://vuejs.org')
    function doSomething() { alert('触发') }
    return { eventName, attrName, url, doSomething }
  }
}).mount('#app')
</script>
```

### 总结

- 模板语法核心：文本插值 `{{ }}`、指令 `v-*`、绑定 `:attr`、事件 `@event`。
- 常用指令：`v-bind`、`v-on`、`v-if`、`v-show`、`v-for`、`v-model`、`v-html`、`v-text`、`v-once`。
- `v-if` 与 `v-show` 的区别：`v-if` 是真正的条件渲染（销毁/重建），`v-show` 只是切换 `display`，频繁切换用 `v-show`，条件很少改变用 `v-if`。
- **注意事项**：`v-for` 必须提供 `key` 以提升 diff 性能；`v-html` 会导致 XSS 风险，只用于可信内容；`v-if` 和 `v-for` 不应同时用在同一元素上。

# 第二章：响应式系统

响应式系统是 Vue 的灵魂。本章将深入讲解 Vue3 基于 Proxy 的响应式实现，以及 `ref`、`reactive`、`computed`、`watch` 等核心 API。

---

## 第 4 讲：响应式基础 —— ref 与 reactive

### 概念

响应式（Reactivity）是指当数据发生变化时，依赖该数据的视图会自动更新。Vue3 提供了两个核心 API 来创建响应式数据：

- **`reactive`**：用于创建对象/数组类型的响应式数据，返回一个 Proxy 代理对象。
- **`ref`**：用于创建任意类型（包括基本类型）的响应式数据，返回一个包含 `.value` 属性的对象。

### 原理

**reactive 的原理**：Vue3 使用 ES6 的 `Proxy` 对对象进行代理，通过 `get` 拦截器追踪依赖（track），通过 `set` 拦截器触发更新（trigger）。这与 Vue2 使用 `Object.defineProperty` 不同，Proxy 可以监听属性的添加和删除，也能监听数组索引和长度变化，无需 Vue2 中的 `$set` 等特殊方法。

**ref 的原理**：由于 Proxy 只能代理对象，无法代理基本类型（如 number、string），Vue3 通过将基本类型包装成 `{ value: x }` 对象来实现响应式。访问和修改 ref 的值需要通过 `.value`，但在模板中 Vue 会自动解包，无需 `.value`。

**响应式对象是深层的**：`reactive` 会递归地将嵌套对象转换为响应式。当访问到嵌套对象时，会延迟转换（懒响应式），提升性能。

### 例子

**例子 1：reactive 基本用法**

```javascript
const { createApp, reactive } = Vue

createApp({
  setup() {
    const state = reactive({
      count: 0,
      user: { name: '张三', age: 20 },
      hobbies: ['读书', '运动']
    })

    function increment() {
      state.count++
      state.user.age++
      state.hobbies.push('音乐')  // Vue3 直接支持数组方法
    }

    return { state, increment }
  }
}).mount('#app')
```

```html
<div id="app">
  <p>计数：{{ state.count }}</p>
  <p>姓名：{{ state.user.name }}，年龄：{{ state.user.age }}</p>
  <p>爱好：{{ state.hobbies.join('、') }}</p>
  <button @click="increment">修改</button>
</div>
```

**例子 2：ref 基本用法**

```javascript
const { createApp, ref } = Vue

createApp({
  setup() {
    const count = ref(0)           // 数字
    const name = ref('张三')        // 字符串
    const visible = ref(false)     // 布尔
    const list = ref([1, 2, 3])    // 数组（也用 ref）

    function change() {
      count.value++              // 修改需通过 .value
      name.value = '李四'
      visible.value = !visible.value
      list.value.push(4)         // 修改数组也要通过 .value
    }

    return { count, name, visible, list, change }
  }
}).mount('#app')
```

```html
<div id="app">
  <!-- 模板中自动解包，无需 .value -->
  <p>{{ count }} - {{ name }}</p>
  <p v-show="visible">现在可见</p>
  <p>{{ list }}</p>
  <button @click="change">修改</button>
</div>
```

**例子 3：ref 与 reactive 的选择**

```javascript
import { ref, reactive } from 'vue'

// 基本类型必须用 ref
const count = ref(0)
const isLoading = ref(true)

// 对象/数组两者皆可，但要注意 reactive 的"解构丢失响应式"问题
const state = reactive({ count: 0 })
// ❌ 解构后 count 不再是响应式
// let { count } = state

// ✅ 使用 toRefs 保持响应式
import { toRefs } from 'vue'
const { count: countRef } = toRefs(state)

// ✅ 或者直接用 ref 包装对象
const user = ref({ name: '张三', age: 20 })
function changeName() {
  user.value.name = '李四'  // 修改对象内部属性
}
```

### 总结

- `reactive` 用于对象/数组，返回 Proxy 代理；`ref` 用于任意类型，通过 `.value` 访问。
- 模板中 ref 会自动解包，无需 `.value`；但在 JS 中必须用 `.value`。
- `reactive` 解构会丢失响应式，需用 `toRefs` / `toRef` 包装。
- **注意事项**：避免用 `reactive` 替换整个对象（如 `state = newObj`），这会丢失响应式；应修改属性或用 `Object.assign`。`ref` 是更安全、更通用的选择，新手推荐优先使用 `ref`。

## 第 5 讲：计算属性与侦听器

### 概念

- **计算属性（Computed）**：基于其他响应式数据派生出新值，具有**缓存特性**，只有依赖的数据变化时才会重新计算。
- **侦听器（Watch）**：当某个响应式数据变化时执行副作用（如异步操作、修改其他状态）。

两者都用于响应数据变化，但用途不同：计算属性用于"派生值"，侦听器用于"响应变化"。

### 原理

**计算属性的缓存机制**：计算属性内部维护一个 `dirty` 标志。首次访问时计算并缓存结果，`dirty` 设为 false；当依赖的响应式数据变化时，`dirty` 重新设为 true，下次访问才会重新计算。这意味着多次访问同一计算属性时，只会计算一次，性能优于方法调用。

**侦听器的执行时机**：`watch` 默认在组件更新后执行（post 模式），也可以配置为 `sync`（同步）或 `pre`（组件更新前）。`watch` 监听单个数据源；`watchEffect` 自动收集依赖并立即执行一次。

### 例子

**例子 1：计算属性**

```javascript
import { ref, computed } from 'vue'

setup() {
  const firstName = ref('张')
  const lastName = ref('三')

  // 只读计算属性
  const fullName = computed(() => `${firstName.value}${lastName.value}`)

  // 可写计算属性
  const fullNameWritable = computed({
    get() {
      return `${firstName.value}${lastName.value}`
    },
    set(newValue) {
      [firstName.value, lastName.value] = newValue.split(' ')
    }
  })

  return { firstName, lastName, fullName, fullNameWritable }
}
```

```html
<div>
  <p>全名：{{ fullName }}</p>
  <input v-model="firstName">
  <input v-model="lastName">
</div>
```

**例子 2：watch 侦听器**

```javascript
import { ref, watch } from 'vue'

setup() {
  const count = ref(0)
  const user = ref({ name: '张三', age: 20 })

  // 1. 侦听 ref
  watch(count, (newValue, oldValue) => {
    console.log(`count 从 ${oldValue} 变为 ${newValue}`)
  })

  // 2. 侦听 reactive 对象的属性（需用 getter 函数）
  watch(
    () => user.value.name,
    (newName, oldName) => {
      console.log(`名字从 ${oldName} 变为 ${newName}`)
    }
  )

  // 3. 侦听多个数据源
  watch([count, () => user.value.age], ([newCount, newAge], [oldCount, oldAge]) => {
    console.log('count 或 age 变化了')
  })

  // 4. 深度侦听（侦听对象内部变化）
  watch(
    user,
    (newUser, oldUser) => {
      console.log('user 对象变化了', newUser)
    },
    { deep: true, immediate: true }  // 深度侦听 + 立即执行
  )

  return { count, user }
}
```

**例子 3：watchEffect 自动收集依赖**

```javascript
import { ref, watchEffect } from 'vue'

setup() {
  const count = ref(0)
  const name = ref('张三')

  // 立即执行一次，并自动追踪内部用到的响应式数据
  watchEffect(() => {
    console.log(`count = ${count.value}, name = ${name.value}`)
  })
  // 输出：count = 0, name = 张三

  count.value++  // 输出：count = 1, name = 张三
  name.value = '李四'  // 输出：count = 1, name = 李四

  // 清理副作用
  watchEffect((onCleanup) => {
    const timer = setInterval(() => {
      console.log(count.value)
    }, 1000)
    onCleanup(() => clearInterval(timer))  // 重新执行前清理
  })
}
```

**例子 4：实际场景 —— 防抖搜索**

```javascript
import { ref, watch } from 'vue'

setup() {
  const keyword = ref('')
  const results = ref([])

  watch(keyword, (newVal) => {
    // 防抖：延迟 300ms 才搜索
    const timer = setTimeout(async () => {
      if (newVal) {
        const res = await fetch(`/api/search?q=${newVal}`)
        results.value = await res.json()
      }
    }, 300)
    // 下次变化前清除上次的定时器
    return () => clearTimeout(timer)
  })

  return { keyword, results }
}
```

### 总结

- 计算属性 `computed`：派生值，有缓存，依赖不变时不重复计算。
- 侦听器 `watch`：明确指定监听源，可获取新旧值，支持 `deep`、`immediate`、`flush` 配置。
- `watchEffect`：自动收集依赖，立即执行一次，适合"副作用跟随多个依赖"的场景。
- **注意事项**：避免在计算属性中产生副作用（如修改其他状态）；侦听 reactive 对象的属性必须用 getter 函数；`watch` 默认是浅层侦听，深层对象变化需 `deep: true`。

## 第 6 讲：响应式原理深入

### 概念

要真正理解 Vue3 的响应式，需要了解其底层的依赖收集（Dependency Tracking）与触发更新（Trigger）机制。Vue3 的响应式系统由 `@vue/reactivity` 包独立实现，核心包括 `reactive`、`ref`、`effect`、`track`、`trigger` 等模块。

### 原理

**核心数据结构**：

1. **依赖（Dep）**：每个响应式对象的每个属性都对应一个 `Dep` 实例，存储所有依赖该属性的"副作用函数"。
2. **副作用函数（Effect）**：通过 `effect` 函数注册的回调，当其依赖的响应式数据变化时会被重新执行。
3. **WeakMap → Map → Set**：Vue3 用三层结构存储依赖关系：
   - `WeakMap<target, Map<key, Set<effect>>>`
   - target 是响应式对象，key 是属性名，Set 是所有依赖该属性的 effect。

**track（依赖收集）**：当 effect 函数执行时，如果访问了响应式对象的属性，会触发 `get` 拦截器，调用 `track` 将当前 effect 加入该属性的 Dep 中。

**trigger（触发更新）**：当响应式对象的属性被修改时，触发 `set` 拦截器，调用 `trigger` 遍历该属性的 Dep，依次执行所有 effect。

**简化流程图**：

```
effect 执行 → 访问 obj.key → get 拦截器 → track(obj, key)
                                              ↓
                              将 effect 加入 Dep
                                              ↓
修改 obj.key → set 拦截器 → trigger(obj, key)
                                              ↓
                              遍历 Dep，重新执行所有 effect
```

### 例子

**例子 1：手写简化版响应式**

```javascript
// 全局变量：当前正在执行的 effect
let activeEffect = null

// 依赖存储
const targetMap = new WeakMap()

function track(target, key) {
  if (!activeEffect) return
  let depsMap = targetMap.get(target)
  if (!depsMap) {
    depsMap = new Map()
    targetMap.set(target, depsMap)
  }
  let dep = depsMap.get(key)
  if (!dep) {
    dep = new Set()
    depsMap.set(key, dep)
  }
  dep.add(activeEffect)
}

function trigger(target, key) {
  const depsMap = targetMap.get(target)
  if (!depsMap) return
  const dep = depsMap.get(key)
  if (dep) {
    dep.forEach(effect => effect())
  }
}

function reactive(target) {
  return new Proxy(target, {
    get(obj, key) {
      track(obj, key)
      return Reflect.get(obj, key)
    },
    set(obj, key, value) {
      const result = Reflect.set(obj, key, value)
      trigger(obj, key)
      return result
    }
  })
}

function effect(fn) {
  activeEffect = fn
  fn()  // 立即执行一次，触发依赖收集
  activeEffect = null
}

// 测试
const state = reactive({ count: 0 })
effect(() => {
  console.log('count 变化了：', state.count)
})
// 输出：count 变化了：0

state.count = 1   // 输出：count 变化了：1
state.count = 10  // 输出：count 变化了：10
```

**例子 2：使用 Vue3 的 effect API**

```javascript
import { reactive, effect, ref, computed } from 'vue'

const state = reactive({ count: 0 })

// effect 类似 watchEffect，是响应式系统的底层 API
effect(() => {
  console.log('state.count =', state.count)
})

state.count++  // 自动触发 effect 重新执行

// computed 本质上也是一个 effect
const double = computed(() => state.count * 2)
console.log(double.value)  // 2
state.count = 5
console.log(double.value)  // 10
```

**例子 3：ref 的实现原理**

```javascript
// 简化版 ref 实现
function ref(value) {
  return {
    get value() {
      track(this, 'value')
      return value
    },
    set value(newVal) {
      if (newVal !== value) {
        value = newVal
        trigger(this, 'value')
      }
    }
  }
}
```

**例子 4：响应式工具函数**

```javascript
import { reactive, readonly, shallowRef, shallowReactive, toRaw, markRaw } from 'vue'

// readonly：只读响应式对象
const original = reactive({ count: 0 })
const copy = readonly(original)
// copy.count = 1  // 警告：只读

// shallowReactive：只有根级是响应式（不递归）
const shallow = shallowReactive({
  nested: { count: 0 }  // nested 不是响应式
})

// shallowRef：浅层 ref，替换 .value 才触发更新
const sRef = shallowRef({ count: 0 })
sRef.value.count = 1   // 不会触发更新
sRef.value = { count: 1 }  // 触发更新

// toRaw：获取响应式对象的原始对象
const raw = toRaw(original)

// markRaw：标记对象永远不被转为响应式
const obj = markRaw({ data: '不会被响应式化' })
```

### 总结

- 响应式核心：Proxy 拦截 + 依赖收集（track）+ 触发更新（trigger）。
- 依赖存储结构：`WeakMap<target, Map<key, Set<effect>>>`。
- `effect` 是响应式系统的底层 API，`computed`、`watch`、`watchEffect` 都基于它实现。
- 工具函数：`readonly`（只读）、`shallowReactive`/`shallowRef`（浅层）、`toRaw`（取原始对象）、`markRaw`（标记不响应式）。
- **注意事项**：性能敏感场景可用 `shallowRef` 避免深层响应式开销；避免在响应式对象中存储大型不可变数据，可用 `markRaw` 标记。

# 第三章：组件系统

组件是 Vue 应用的构建块。本章将系统讲解组件的注册、通信、插槽和依赖注入，这是构建复杂应用的核心能力。

## 第 7 讲：组件基础与注册

### 概念

组件（Component）是可复用的 Vue 实例，带有预定义的选项。一个 Vue 应用由嵌套的组件树构成：根组件下包含若干子组件，子组件又可以包含自己的子组件。组件化的核心价值在于**复用**、**隔离**和**组合**。

Vue3 的组件注册分为两种：
- **全局注册**：在应用实例上通过 `app.component()` 注册，所有组件都可使用。
- **局部注册**：在组件的 `components` 选项中注册，只在当前组件可用。

### 原理

每个组件本质上是一个包含 `template`、`setup`、`data`、`methods` 等选项的配置对象。当 Vue 渲染组件时，会为每个组件创建独立的实例，拥有独立的状态和作用域。

全局注册的组件会被添加到应用实例的 `components` 表中，渲染时 Vue 会先在当前组件的局部注册表中查找，找不到再到全局注册表查找。局部注册的组件只在当前组件的渲染作用域内可见，这避免了全局命名污染。

单文件组件（SFC，Single File Component）是 Vue 推荐的组件组织方式，将模板、逻辑、样式写在 `.vue` 文件中，由 `@vitejs/plugin-vue` 或 `vue-loader` 编译。

### 例子

**例子 1：单文件组件（.vue 文件）**

```vue
<!-- Hello.vue -->
<template>
  <div class="hello">
    <h2>{{ title }}</h2>
    <p>{{ message }}</p>
    <button @click="onClick">点击 {{ count }} 次</button>
  </div>
</template>

<script setup>
import { ref } from 'vue'

// props 定义
const props = defineProps({
  title: { type: String, default: '默认标题' }
})

const message = ref('Hello Vue3!')
const count = ref(0)

function onClick() {
  count.value++
}
</script>

<style scoped>
.hello {
  border: 1px solid #eee;
  padding: 16px;
}
</style>
```

**例子 2：全局注册**

```javascript
// main.js
import { createApp } from 'vue'
import App from './App.vue'
import Hello from './components/Hello.vue'

const app = createApp(App)

// 全局注册组件
app.component('Hello', Hello)
app.component('MyButton', {
  template: '<button class="btn"><slot/></button>'
})

app.mount('#app')
```

```vue
<!-- 任何组件中都可以直接使用 -->
<template>
  <div>
    <Hello title="首页" />
    <MyButton>按钮</MyButton>
  </div>
</template>
```

**例子 3：局部注册**

```vue
<!-- App.vue -->
<template>
  <div>
    <Hello title="首页" />
  </div>
</template>

<script>
import Hello from './components/Hello.vue'

export default {
  components: {
    Hello  // 局部注册
  }
}
</script>
```

**例子 4：使用 `<script setup>` 自动导入（推荐）**

```vue
<template>
  <div>
    <Hello title="首页" />
    <World />
  </div>
</template>

<script setup>
import Hello from './components/Hello.vue'
import World from './components/World.vue'
// 在 script setup 中导入的组件可直接在模板中使用，无需注册
</script>
```

### 总结

- 组件是可复用的 Vue 实例，应用由组件树构成。
- 注册方式：全局注册（`app.component`）和局部注册（`components` 选项）。
- `<script setup>` 中导入的组件自动可用，无需手动注册，是 Vue3 推荐写法。
- **注意事项**：全局注册的组件即使未使用也会被打包，影响 Tree-shaking；优先使用局部注册。组件名建议使用 PascalCase（如 `MyButton`），模板中可用 kebab-case（`<my-button>`）。

## 第 8 讲：Props 与组件通信

### 概念

组件通信是组件化开发的核心问题。Vue 提供了多种通信方式：

- **Props**：父组件向子组件传递数据（单向）。
- **Emits**：子组件向父组件发送事件。
- **v-model**：父子组件双向绑定。
- **ref / expose**：父组件直接访问子组件方法。
- **Event Bus / Mitt**：任意组件间通信（Vue3 移除了 `$on`、`$emit` 全局事件，需用第三方库如 mitt）。

### 原理

**Props 单向数据流**：父组件的数据通过 props 传给子组件，子组件不能直接修改 props（会警告）。如果需要基于 props 派生值，应使用计算属性或本地状态副本。

**Emits 事件机制**：子组件通过 `emit` 触发自定义事件，父组件用 `@event` 监听。Vue3 推荐用 `defineEmits` 显式声明事件，便于文档和类型检查。

**v-model 原理**：`v-model` 是 `:modelValue` + `@update:modelValue` 的语法糖。Vue3 支持多个 `v-model` 绑定到同一组件。

### 例子

**例子 1：Props 传递数据**

```vue
<!-- Child.vue -->
<template>
  <div>
    <p>姓名：{{ name }}</p>
    <p>年龄：{{ age }}</p>
    <p>爱好：{{ hobbies.join('、') }}</p>
  </div>
</template>

<script setup>
// 定义 props
defineProps({
  name: { type: String, required: true },
  age: { type: Number, default: 18 },
  hobbies: { type: Array, default: () => [] }
})
</script>
```

```vue
<!-- Parent.vue -->
<template>
  <Child
    :name="user.name"
    :age="user.age"
    :hobbies="user.hobbies"
  />
</template>

<script setup>
import Child from './Child.vue'
const user = {
  name: '张三',
  age: 20,
  hobbies: ['读书', '运动']
}
</script>
```

**例子 2：Emits 子传父**

```vue
<!-- Child.vue -->
<template>
  <button @click="handleClick">点击我</button>
</template>

<script setup>
const emit = defineEmits(['click', 'submit'])

function handleClick() {
  // 触发事件并传参
  emit('click', { time: new Date() })
  emit('submit', '表单数据')
}
</script>
```

```vue
<!-- Parent.vue -->
<template>
  <Child @click="onChildClick" @submit="onSubmit" />
</template>

<script setup>
import Child from './Child.vue'

function onChildClick(payload) {
  console.log('子组件点击了', payload)
}
function onSubmit(data) {
  console.log('收到提交', data)
}
</script>
```

**例子 3：v-model 双向绑定**

```vue
<!-- CustomInput.vue -->
<template>
  <input
    :value="modelValue"
    @input="$emit('update:modelValue', $event.target.value)"
  />
</template>

<script setup>
defineProps(['modelValue'])
defineEmits(['update:modelValue'])
</script>
```

```vue

  <CustomInput v-model="message" />
  <p>输入内容：{{ message }}</p>

  <!-- 多个 v-model -->
  <UserForm v-model:name="user.name" v-model:age="user.age" />
</template>

<script setup>
import { ref, reactive } from 'vue'
import CustomInput from './CustomInput.vue'

const message = ref('')
const user = reactive({ name: '', age: 0 })
</script>
```

**例子 4：ref 访问子组件**

```vue
<!-- Child.vue -->
<template>
  <div>子组件</div>
</template>

<script setup>
import { ref } from 'vue'

const count = ref(0)
function increment() {
  count.value++
  console.log('子组件方法被调用')
}

// 显式暴露，否则父组件无法访问

```

```vue
<!-- Parent.vue -->
<template>
  <Child ref="childRef" />
  <button @click="callChildMethod">调用子组件方法</button>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import Child from './Child.vue'

const childRef = ref(null)

function callChildMethod() {
  childRef.value.increment()       // 调用子组件方法
  console.log(childRef.value.count) // 访问子组件数据
}

onMounted(() => {
  console.log(childRef.value)  // 子组件实例
})
</script>
```

**例子 5：跨层级通信 —— mitt 事件总线**

```javascript
// eventBus.js
import mitt from 'mitt'
export const emitter = mitt()
```

```vue
<!-- 组件 A -->
<script setup>
import { emitter } from './eventBus'

  emitter.emit('custom-event', { data: '来自 A' })
}
</script>
```

```vue
<!-- 组件 B -->

import { onMounted } from 'vue'
import { emitter } from './eventBus'

  })
})
</script>
```

### 总结

- 父传子用 Props，子传父用 Emits，双向用 v-model。
- 父访问子用 `ref` + `defineExpose`，跨层级用 `provide/inject`（下讲讲解）或 mitt 事件总线。
- Vue3 的 `v-model` 支持多绑定（`v-model:name`），更灵活。
- **注意事项**：Props 是单向的，子组件不能直接修改；如需修改，通过 emit 通知父组件。`defineProps`、`defineEmits`、`defineExpose` 是编译宏，无需导入。

## 第 9 讲：插槽 Slots

### 概念

插槽（Slot）是 Vue 组件内容分发的机制，允许父组件向子组件传递模板内容。它让组件更加灵活和可复用。Vue3 提供三种插槽：

- **默认插槽**：未命名的插槽，接收父组件传入的默认内容。
- **具名插槽**：通过 `name` 区分多个插槽位置。
- **作用域插槽**：子组件向父组件传递数据，父组件根据数据渲染内容。

### 原理

插槽的本质是**返回渲染函数**的函数。当父组件在子组件标签内写内容时，Vue 会将这些内容编译为渲染函数传给子组件；子组件的 `<slot>` 标签相当于一个"占位符"，渲染时被替换为父组件传入的内容。

作用域插槽的工作机制：子组件在 `<slot>` 上绑定属性，这些属性会作为参数传给父组件的插槽渲染函数。父组件通过 `v-slot:slotName="slotProps"` 接收，从而能访问子组件传递的数据。

### 例子

**例子 1：默认插槽**

```vue
<!-- Card.vue -->
<template>
  <div class="card">
    <div class="card-body">
      <slot></slot>  <!-- 父组件传入的内容会渲染在这里 -->
    </div>
  </div>
</template>
```

```vue
<!-- Parent.vue -->
<template>
  <Card>
    <h3>卡片标题</h3>
    <p>卡片内容...</p>
  </Card>

  <!-- 带后备内容（父组件未传时显示） -->
  <Card>
    <template #default>
      自定义内容
    </template>
  </Card>

  <Card />  <!-- 显示空 -->
</template>
```

**例子 2：具名插槽**

```vue
<!-- Layout.vue -->
<template>
  <div class="layout">
    <header>
      <slot name="header"></slot>
    </header>
    <main>
      <slot></slot>  <!-- 默认插槽 -->
    </main>
    <footer>
      <slot name="footer"></slot>
    </footer>
  </div>
</template>
```

```vue
<!-- Parent.vue -->
<template>
  <Layout>
    <template #header>
      <h1>网站标题</h1>
    </template>

    <template #default>
      <p>主体内容</p>
    </template>

    <template #footer>
      <p>版权信息 © 2024</p>
    </template>
  </Layout>
</template>
```

**例子 3：作用域插槽**

```vue
<!-- List.vue -->
<template>
  <ul>
    <li v-for="(item, index) in items" :key="item.id">
      <!-- 把 item 和 index 传给父组件 -->
      <slot :item="item" :index="index"></slot>
    </li>
  </ul>
</template>

<script setup>
defineProps({
  items: { type: Array, required: true }
})
</script>
```

```vue
<!-- Parent.vue -->
<template>
  <List :items="users">
    <!-- 接收子组件传来的数据 -->
    <template #default="{ item, index }">
      <span>{{ index + 1 }}. {{ item.name }} ({{ item.age }}岁)</span>
    </template>
  </List>

  <!-- 也可以用解构 + 默认值 -->
  <List :items="users">
    <template #default="{ item, index = 0 }">
      <strong>{{ item.name }}</strong>
    </template>
  </List>
</template>

<script setup>
import List from './List.vue'
const users = [
  { id: 1, name: '张三', age: 20 },
  { id: 2, name: '李四', age: 25 }
]
</script>
```

**例子 4：具名作用域插槽**

```vue
<!-- DataTable.vue -->
<template>
  <table>
    <thead>
      <tr>
        <slot name="header" :columns="columns"></slot>
      </tr>
    </thead>
    <tbody>
      <tr v-for="row in data" :key="row.id">
        <slot name="row" :row="row"></slot>
      </tr>
    </tbody>
  </table>
</template>
```

```vue
<template>
  <DataTable :columns="cols" :data="rows">
    <template #header="{ columns }">
      <th v-for="col in columns" :key="col">{{ col }}</th>
    </template>

    <template #row="{ row }">
      <td>{{ row.name }}</td>
      <td>{{ row.age }}</td>
    </template>
  </DataTable>
</template>
```

### 总结

- 默认插槽：`<slot></slot>`，父组件直接传内容。
- 具名插槽：`<slot name="x">`，父组件用 `#x` 或 `v-slot:x` 指定。
- 作用域插槽：子组件在 `<slot>` 上绑定数据，父组件用 `#default="{ data }"` 接收。
- **注意事项**：插槽内容在**父组件作用域**编译，无法访问子组件数据（除非通过作用域插槽传入）；`v-slot` 只能用在 `<template>` 或组件标签上。

## 第 10 讲：依赖注入 provide / inject

### 概念

`provide` 和 `inject` 是 Vue 提供的依赖注入机制，用于**跨层级组件通信**。父组件通过 `provide` 提供数据，所有后代组件（无论嵌套多深）都可以通过 `inject` 获取。这解决了 props 逐层传递（"prop drilling"）的繁琐问题。

### 原理

依赖注入基于组件树的结构。当组件调用 `provide` 时，数据被存储在当前组件实例上；后代组件调用 `inject` 时，Vue 会从当前组件向上逐层查找，直到找到对应的 provider。

**响应式原理**：如果 `provide` 的是 `ref` 或 `reactive` 对象，后代组件 `inject` 后能保持响应式。但要注意：直接 `provide` 一个普通值，后代修改不会影响父组件；要实现双向通信，应 `provide` 一个方法，让后代调用方法修改父组件状态。

**Symbol 作为 key**：为了避免命名冲突，推荐用 `Symbol` 或唯一的字符串作为注入 key，并通过单独的文件导出。

### 例子

**例子 1：基础用法**

```vue
<!-- 祖先组件 -->
<template>
  <div>
    <Child />
  </div>
</template>

<script setup>
import { ref, provide } from 'vue'
import Child from './Child.vue'

const theme = ref('dark')
const user = ref({ name: '张三' })

// 提供数据
provide('theme', theme)
provide('user', user)
</script>
```

```vue
<!-- 后代组件（无论嵌套多深） -->
<template>
  <div :class="theme">
    <p>当前用户：{{ user.name }}</p>
  </div>
</template>

<script setup>
import { inject } from 'vue'

// 注入数据，可提供默认值
const theme = inject('theme', 'light')
const user = inject('user', { name: '默认用户' })
</script>
```

**例子 2：响应式 + 修改方法**

```vue

// 提供数据 + 修改方法

  count.value++
}
function reset() {
  count.value = 0
}

provide('count', count)
provide('countActions', { increment, reset })
</script>
```

```vue
<!-- 后代组件 -->
<template>
  <button @click="actions.increment">+1 ({{ count }})</button>
  <button @click="actions.reset">重置</button>
</template>

<script setup>

const count = inject('count')
const actions = inject('countActions')
</script>
```

**例子 3：用 Symbol 作为 key（推荐）**

```javascript

```


```vue

// 通过方法修改

  state.value = newVal
```

### 总结

- `provide` / `inject` 解决跨层级通信，避免 prop drilling。
- 注入 `ref` / `reactive` 可保持响应式；普通值则不响应。
- 推荐用 `Symbol` 作为 key 避免冲突；用 `readonly` 包装防止后代直接修改。
- **注意事项**：依赖注入是**单向**的（父→后代），不适合兄弟组件通信；滥用会让数据流难以追踪，建议仅用于主题、用户信息、国际化等全局配置。

# 第四章：Composition API

Composition API 是 Vue3 最重要的特性之一，它解决了 Options API 在复杂组件中逻辑分散的问题。本章将深入讲解组合式 API 的使用、自定义组合式函数和生命周期钩子。

---

## 第 11 讲：组合式 API 详解

### 概念

组合式 API（Composition API）是一组以函数形式提供的 API，用于在组件中组织逻辑。它包括 `setup`、`ref`、`reactive`、`computed`、`watch`、生命周期钩子等。与 Options API（通过 `data`、`methods`、`computed` 等选项组织）相比，Composition API 允许按**逻辑关注点**组织代码，而非按选项类型。

`<script setup>` 是 Composition API 的编译时语法糖，让代码更简洁，是 Vue3 推荐的组件写法。

### 原理

**Options API 的问题**：当组件逻辑变复杂时，同一功能的代码散落在 `data`、`methods`、`computed`、`watch` 中，阅读时需要在不同选项间跳转，难以维护。

**Composition API 的解决思路**：将相关逻辑聚合在一起，形成"组合式函数"。`setup` 函数是入口，在组件创建前执行，返回的内容暴露给模板和实例。

**`<script setup>` 的原理**：它是 `setup` 函数的语法糖。在编译时，`<script setup>` 内的顶层变量、函数会自动暴露给模板；导入的组件自动可用；`defineProps`、`defineEmits` 等编译宏无需导入。这大幅减少了样板代码。

### 例子

**例子 1：Options API vs Composition API 对比**

```javascript
// Options API 写法
export default {
  data() {
    return {
      count: 0,
      double: 0
    }
  },
  computed: {
    doubleCount() { return this.count * 2 }
  },
  methods: {
    increment() { this.count++ }
  },
  mounted() {
    console.log('mounted')
  }
}
```

```javascript
// Composition API 写法（setup 函数）
import { ref, computed, onMounted } from 'vue'

export default {
  setup() {
    const count = ref(0)
    const doubleCount = computed(() => count.value * 2)

    function increment() {
      count.value++
    }

    onMounted(() => {
      console.log('mounted')
    })

    return { count, doubleCount, increment }
  }
}
```

```vue
<!-- <script setup> 写法（推荐） -->
<script setup>
import { ref, computed, onMounted } from 'vue'

const count = ref(0)
const doubleCount = computed(() => count.value * 2)

function increment() {
  count.value++
}

onMounted(() => {
  console.log('mounted')
})
</script>
```

**例子 2：`<script setup>` 的特性**

```vue
<script setup>
import { ref, computed } from 'vue'
import ChildComponent from './Child.vue'

// 1. 顶层变量自动暴露给模板

// 2. 导入的组件直接可用
// 3. defineProps / defineEmits 编译宏

  title: String
})
const emit = defineEmits(['change'])

// 4. computed、watch 等正常使用

// 5. 顶层 await（需 Suspense 支持）
// const data = await fetch('/api').then(r => r.json())
</script>
```

**例子 3：按逻辑关注点组织代码**

```vue
<!-- 一个用户管理组件，包含搜索、列表、分页三块逻辑 -->
<template>
  <div>
    <input v-model="keyword" @input="search">
    <ul>
      <li v-for="user in filteredUsers" :key="user.id">{{ user.name }}</li>
    </ul>
    <button @click="prevPage">上一页</button>
    <button @click="nextPage">下一页</button>
  </div>
</template>

<script setup>

import { useSearch } from './composables/useSearch'
import { usePagination } from './composables/usePagination'

// 搜索逻辑
const { keyword, results, search } = useSearch('/api/users')

// 分页逻辑

// 派生数据

  search()

```

**例子 4：响应式 API 补充**

```javascript
import { ref, reactive, toRef, toRefs, unref, isRef, isReactive, customRef } from 'vue'

const state = reactive({ name: '张三', age: 20 })

// toRef：从 reactive 对象的属性创建 ref
const nameRef = toRef(state, 'name')

// toRefs：将 reactive 对象的所有属性转为 ref
const { name, age } = toRefs(state)

// unref：如果是 ref 返回 .value，否则原样返回
const val = unref(nameRef)  // '张三'

// isRef / isReactive：类型判断
console.log(isRef(nameRef))      // true
console.log(isReactive(state))   // true

// customRef：自定义 ref，可控制依赖追踪和触发
function debouncedRef(value, delay = 200) {
  let timer
  return customRef((track, trigger) => ({
    get() {
      track()
      return value
    },
    set(newVal) {
      clearTimeout(timer)
      timer = setTimeout(() => {
        value = newVal
        trigger()
      }, delay)
    }
  }))
}
```

### 总结

- Composition API 按逻辑关注点组织代码，解决 Options API 逻辑分散问题。
- `<script setup>` 是语法糖，顶层变量自动暴露，组件自动可用，编译宏无需导入。
- 响应式工具：`toRef`、`toRefs`、`unref`、`isRef`、`customRef` 等。
- **注意事项**：`setup` 在组件创建前执行，此时还没有 `this`（`this` 是 undefined）；`<script setup>` 中无法直接使用 `this`；顶层 `await` 需要组件被 `<Suspense>` 包裹。

## 第 12 讲：自定义组合式函数（Composables）

### 概念

组合式函数（Composables）是利用 Composition API 封装的可复用逻辑。它是一个约定俗成的命名规则（以 `use` 开头，如 `useMouse`、`useFetch`）的函数，返回响应式数据和方法。组合式函数是 Vue3 中复用逻辑的**首选方式**，替代了 Vue2 的 Mixins。

### 原理

组合式函数本质是一个普通函数，内部使用 `ref`、`computed`、`watch`、生命周期钩子等响应式 API，返回响应式引用和方法。当在组件的 `setup` 中调用时，这些响应式 API 会绑定到当前组件实例上，从而能正确追踪依赖和清理副作用。

**与 Mixins 的对比**：
- Mixins 的属性来源不清晰，命名容易冲突，难以追踪。
- 组合式函数显式返回所需内容，来源清晰，无命名冲突，可灵活组合。

**约定**：
- 命名以 `use` 开头。
- 返回值推荐用普通对象（包含 ref 和方法），便于解构使用。
- 如果有副作用（如事件监听、定时器），应在 `onUnmounted` 中清理。

### 例子

**例子 1：useMouse —— 追踪鼠标位置**

```javascript
// composables/useMouse.js
import { ref, onMounted, onUnmounted } from 'vue'

export function useMouse() {
  const x = ref(0)
  const y = ref(0)

  function update(event) {
    x.value = event.pageX
    y.value = event.pageY
  }

  onMounted(() => {
    window.addEventListener('mousemove', update)
  })

  onUnmounted(() => {
    window.removeEventListener('mousemove', update)
  })

  return { x, y }
}
```

```vue
<!-- 使用 -->
<template>
  <div>鼠标位置：{{ x }}, {{ y }}</div>
</template>

<script setup>
import { useMouse } from './composables/useMouse'
const { x, y } = useMouse()
</script>
```

**例子 2：useFetch —— 数据请求**

```javascript
// composables/useFetch.js
import { ref, watchEffect, isRef, unref } from 'vue'

export function useFetch(url) {
  const data = ref(null)
  const error = ref(null)
  const loading = ref(false)

  async function doFetch() {
    loading.value = true
    error.value = null
    data.value = null

    try {
      const res = await fetch(unref(url))
      if (!res.ok) throw new Error('请求失败')
      data.value = await res.json()
    } catch (e) {
      error.value = e.message
    } finally {
      loading.value = false
    }
  }

  // 如果 url 是 ref，自动重新请求
  if (isRef(url)) {
    watchEffect(doFetch)
  } else {
    doFetch()
  }

  return { data, error, loading, refresh: doFetch }
}
```

```vue
<template>
  <div v-if="loading">加载中...</div>
  <div v-else-if="error">错误：{{ error }}</div>
  <div v-else>{{ data }}</div>
  <button @click="refresh">刷新</button>
</template>

<script setup>
import { ref } from 'vue'
import { useFetch } from './composables/useFetch'

const userId = ref(1)
const { data, error, loading, refresh } = useFetch(
  () => `/api/users/${userId.value}`  // 也可以传 ref
)
</script>
```

**例子 3：useLocalStorage —— 持久化响应式状态**

```javascript
// composables/useLocalStorage.js
import { ref, watch, customRef } from 'vue'

export function useLocalStorage(key, defaultValue) {
  const value = ref(localStorage.getItem(key) || defaultValue)

  watch(value, (newVal) => {
    localStorage.setItem(key, newVal)
  }, { deep: true })

  return value
}
```

```vue
<script setup>

// 自动同步到 localStorage

const todos = useLocalStorage('todos', [])
</script>
```

**例子 4：useEventListener —— 事件监听封装**

```javascript
// composables/useEventListener.js
import { onMounted, onUnmounted } from 'vue'

export function useEventListener(target, event, callback) {
  onMounted(() => target.addEventListener(event, callback))
  onUnmounted(() => target.removeEventListener(event, callback))
}
```

```javascript

export function useMouse() {
  const x = ref(0)
  const y = ref(0)
  useEventListener(window, 'mousemove', (e) => {
    x.value = e.pageX
    y.value = e.pageY
  })
  return { x, y }
}
```

### 总结

- 组合式函数以 `use` 开头，是 Vue3 复用逻辑的首选方式。
- 必须在 `setup` 或其他组合式函数中调用，才能正确绑定生命周期。
- 副作用（事件、定时器）需在 `onUnmounted` 中清理。
- **注意事项**：返回值推荐用对象（而非数组），便于解构和扩展；多个组合式函数可嵌套组合，形成更复杂逻辑。

## 第 13 讲：生命周期钩子

### 概念

生命周期钩子是组件从创建到销毁过程中各个阶段的回调函数。Vue3 的 Composition API 将所有钩子改为函数形式（加 `on` 前缀），如 `onMounted`、`onUpdated`、`onUnmounted`。理解生命周期有助于在正确时机执行逻辑（如初始化、清理、监听）。

### 原理

Vue 组件的生命周期分为四大阶段：**创建 → 挂载 → 更新 → 卸载**。每个阶段前后都有对应的钩子。此外还有错误捕获和调试钩子。

**关键阶段说明**：
- `setup`：组件创建前执行，此时响应式数据已建立，但 DOM 未生成。
- `onBeforeMount` / `onMounted`：挂载前后。`onMounted` 时 DOM 已生成，可操作 DOM。
- `onBeforeUpdate` / `onUpdated`：数据变化导致重新渲染前后。`onUpdated` 时 DOM 已更新。
- `onBeforeUnmount` / `onUnmounted`：卸载前后。`onUnmounted` 用于清理副作用。

**与 Options API 的对应关系**：
- `beforeCreate` / `created` → 直接在 `setup` 中编写
- `beforeMount` → `onBeforeMount`
- `mounted` → `onMounted`
- `beforeUpdate` → `onBeforeUpdate`
- `updated` → `onUpdated`
- `beforeUnmount` → `onBeforeUnmount`（Vue2 是 `beforeDestroy`）
- `unmounted` → `onUnmounted`（Vue2 是 `destroyed`）

### 例子

**例子 1：完整生命周期演示**

```vue
<template>
  <div>
    <p>{{ count }}</p>
    <button @click="count++">+1</button>
    <button @click="destroy">销毁</button>
  </div>
</template>

<script setup>
import { ref, onBeforeMount, onMounted, onBeforeUpdate, onUpdated, onBeforeUnmount, onUnmounted } from 'vue'

const count = ref(0)

console.log('setup 执行')

onBeforeMount(() => {
  console.log('onBeforeMount：即将挂载')
})

onMounted(() => {
  console.log('onMounted：已挂载，可操作 DOM')
})

onBeforeUpdate(() => {
  console.log('onBeforeUpdate：数据变化，即将更新 DOM')
})

onUpdated(() => {
  console.log('onUpdated：DOM 已更新')
})

onBeforeUnmount(() => {
  console.log('onBeforeUnmount：即将卸载')
})

onUnmounted(() => {
  console.log('onUnmounted：已卸载，清理副作用')
})

function destroy() {
  // 实际通过 v-if 控制销毁
}
</script>
```

**例子 2：在 onMounted 中操作 DOM**

```vue

  <input ref="inputRef" placeholder="自动聚焦">
</template>

  // DOM 已生成，可操作

```

```vue

  // 启动定时器

    count.value++
  }, 1000)
```

**例子 4：onErrorCaptured 错误捕获**

```vue
<!-- 父组件 -->

  <Child />
</template>

import Child from './Child.vue'

onErrorCaptured((err, instance, info) => {
  console.error('捕获到子组件错误：', err)
```

**例子 5：调试钩子 onRenderTracked / onRenderTriggered**

```javascript

  console.log('追踪依赖：', e)

// 依赖变化触发重新渲染时触发

```

### 总结

- 生命周期分四阶段：创建（setup）、挂载（onMounted）、更新（onUpdated）、卸载（onUnmounted）。
- `onMounted` 适合操作 DOM、启动定时器、发起请求；`onUnmounted` 适合清理副作用。
- `onErrorCaptured` 可捕获后代组件错误；`onRenderTracked` / `onRenderTriggered` 用于调试。
- **注意事项**：钩子函数只能在 `setup` 中同步调用（不能在异步回调中调用，否则无法绑定到当前实例）；`onUpdated` 中避免修改状态，否则可能死循环。

# 第五章：进阶特性

本章讲解 Vue3 的进阶特性，包括内置组件（Teleport、Suspense、Transition）、自定义指令和插件开发。这些特性在构建复杂应用时非常有用。

---

## 第 14 讲：内置组件（Teleport、Suspense、Transition）

### 概念

Vue3 提供了几个特殊的内置组件，用于解决特定场景的问题：

- **Teleport**：将组件内容渲染到 DOM 树的其他位置（如 `body` 下），常用于模态框、通知。
- **Suspense**：处理异步组件的加载状态，显示 fallback 内容直到异步组件就绪。
- **Transition** / **TransitionGroup**：为元素或组件的插入、更新、移除添加过渡动画。

### 原理

**Teleport 原理**：Teleport 在渲染时，会将子内容渲染到指定的 `to` 目标元素中，但保持组件的逻辑关系（props、事件、插槽等仍正常工作）。这解决了模态框被父组件 `overflow: hidden` 或 `z-index` 层叠上下文限制的问题。

**Suspense 原理**：Suspense 内部维护一个状态机。当子组件是异步的（如 `defineAsyncComponent` 或 `setup` 中有顶层 `await`），Suspense 会先渲染 `fallback` 插槽；当异步操作完成，再渲染默认插槽。Suspense 仍是实验性特性，API 可能变化。

**Transition 原理**：Transition 通过监听元素的插入、删除和更新，在合适的时机添加/移除 CSS 类名（如 `v-enter-from`、`v-enter-active`、`v-enter-to`），配合 CSS 过渡或动画实现效果。也支持 JavaScript 钩子用于集成第三方动画库（如 GSAP）。

### 例子

**例子 1：Teleport 模态框**

```vue
<!-- Modal.vue -->
<template>
  <button @click="show = true">打开模态框</button>

  <Teleport to="body">
    <div v-if="show" class="modal">
      <div class="modal-content">
```

## 第 15 讲：自定义指令

### 概念

自定义指令（Custom Directives）用于封装对底层 DOM 的访问逻辑，当内置指令（如 `v-model`、`v-show`）不够用时使用。例如自动聚焦、权限控制、拖拽、懒加载等场景。指令以 `v-` 开头，注册后可在模板中使用。

### 原理

指令是一个包含若干钩子函数的对象。Vue3 的指令钩子与组件生命周期类似：

- `created`：元素属性和事件监听器设置前。
- `beforeMount`：元素挂载前。
- `mounted`：元素挂载后（最常用）。
- `beforeUpdate`：更新前。
- `updated`：更新后。
- `beforeUnmount`：卸载前。
- `unmounted`：卸载后。

每个钩子接收参数：`el`（DOM 元素）、`binding`（绑定对象，包含 `value`、`oldValue`、`arg`、`modifiers` 等）、`vnode`、`prevVnode`。

**与 Vue2 的区别**：Vue3 将钩子名改为与组件生命周期一致（`bind` → `beforeMount`，`inserted` → `mounted`，`unbind` → `unmounted`）。

### 例子

**例子 1：全局注册指令 —— v-focus 自动聚焦**

```javascript
// main.js
import { createApp } from 'vue'
import App from './App.vue'

const app = createApp(App)

app.directive('focus', {
  mounted(el) {
    el.focus()
  }
})

app.mount('#app')
```

```vue
<template>
  <input v-focus>
</template>
```

**例子 2：局部注册指令**

```vue

  <p v-highlight="'yellow'">高亮文字</p>

  mounted: (el) => el.focus()
}

// 函数简写：相当于 mounted 和 updated 都执行
const vHighlight = (el, binding) => {
  el.style.backgroundColor = binding.value
}
</script>
```

```javascript

  mounted(el, binding) {
    const observer = new IntersectionObserver((entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          el.src = binding.value
          observer.unobserve(el)
        }
      })
    })
    observer.observe(el)
    el._observer = observer  // 保存引用以便清理
  },

    if (el._observer) {
      el._observer.disconnect()
    }
  }
}
```

### 总结

- 自定义指令封装 DOM 操作逻辑，钩子与组件生命周期对齐。
- 注册方式：全局 `app.directive()`，局部在 `<script setup>` 中用 `vXxx` 命名。
- 函数简写：`const vFoo = (el, binding) => {...}` 相当于 `mounted` + `updated`。
- **注意事项**：指令应只做 DOM 操作，避免修改组件状态；指令的 `binding.value` 是任意值，`binding.arg` 是参数（如 `v-foo:arg`），`binding.modifiers` 是修饰符（如 `v-foo.bar` 的 `{ bar: true }`）。

## 第 16 讲：插件开发

### 概念

插件（Plugin）是 Vue 中扩展全局功能的机制。当需要在多个组件中复用全局方法、属性、指令、过滤器、混入等时，可以封装为插件。Vue3 的插件是一个带有 `install` 方法的对象，或直接是一个函数。

### 原理

插件通过 `app.use(plugin, ...options)` 注册。注册时，Vue 会调用插件的 `install` 方法（或直接调用插件函数），传入 `app` 实例和额外参数。插件内部可以：

- 添加全局方法或属性：`app.config.globalProperties.$xxx`
- 注册全局组件、指令：`app.component()`、`app.directive()`
- 提供 / 注入：通过 `app.provide()` 让所有组件可 `inject`
- 修改 `app.config` 全局配置

**插件执行时机**：`app.use()` 调用时立即执行，且同一插件只会执行一次（Vue 内部去重）。

### 例子

**例子 1：简单插件 —— 全局通知**

```javascript
// plugins/notify.js
export default {
  install(app, options = {}) {
    const defaultDuration = options.duration || 3000

    // 添加全局方法
    app.config.globalProperties.$notify = (message, duration = defaultDuration) => {
      const div = document.createElement('div')
      div.textContent = message
      div.style.cssText = `
        position: fixed; top: 20px; right: 20px;
        background: #333; color: white; padding: 10px 20px;
        border-radius: 4px; z-index: 9999;
      `
      document.body.appendChild(div)
      setTimeout(() => div.remove(), duration)
    }

    // 也可以通过 provide/inject
    app.provide('notify', app.config.globalProperties.$notify)
  }
}
```

```javascript
// main.js
import { createApp } from 'vue'
import App from './App.vue'
import Notify from './plugins/notify'

const app = createApp(App)
app.use(Notify, { duration: 2000 })
app.mount('#app')
```

## 第 17 讲：Vue Router 路由管理

### 概念

Vue Router 是 Vue.js 的官方路由管理器，用于构建单页应用（SPA）。它通过监听 URL 变化，在不刷新页面的情况下切换组件，实现"页面"导航。Vue Router 4 是专为 Vue3 设计的版本。

核心概念：
- **路由（Route）**：URL 与组件的映射关系。
- **路由器（Router）**：管理所有路由的实例。
- **导航（Navigation）**：在不同路由间切换。
- **动态路由**：URL 中带参数的路由（如 `/user/:id`）。
- **嵌套路由**：路由的父子关系。

### 原理

Vue Router 使用 HTML5 History API（`pushState`、`popstate`）或 hash 模式实现 URL 监听。当 URL 变化时，Router 匹配对应的路由配置，渲染对应的组件到 `<router-view>` 中。

**两种模式**：
- **Hash 模式**：URL 带 `#`（如 `/#/about`），兼容性好，无需服务器配置。
- **History 模式**：URL 无 `#`（如 `/about`），更美观，但需服务器配置回退到 `index.html`。

**路由匹配**：Router 按配置顺序匹配，动态路由用 `:param` 标记参数，通过 `route.params` 访问。

### 例子

**例子 1：基础路由配置**

```javascript
// router/index.js
import { createRouter, createWebHistory } from 'vue-router'
import Home from '../views/Home.vue'
import About from '../views/About.vue'

const routes = [
  { path: '/', name: 'home', component: Home },
  { path: '/about', name: 'about', component: About }
]

const router = createRouter({
  history: createWebHistory(),  // History 模式
  routes
})

export default router
```

## 第 18 讲：Pinia 状态管理

### 概念

Pinia 是 Vue3 官方推荐的状态管理库，是 Vuex 的继任者。它用于管理跨组件共享的状态，如用户信息、购物车、主题等。相比 Vuex，Pinia 更简洁、对 TypeScript 支持更好、无 mutations 概念、支持组合式 API 风格。

Pinia 的核心概念：
- **Store**：存储状态的地方，分为 `state`（数据）、`getters`（计算属性）、`actions`（方法）。
- **State**：响应式数据。
- **Getters**：派生状态，类似组件的 `computed`。
- **Actions**：同步或异步操作，可直接修改 state。

### 原理

Pinia 基于 Vue3 的响应式系统实现。每个 Store 内部用 `reactive` 创建响应式 state，用 `computed` 创建 getters，actions 是普通函数。Pinia 通过 `provide/inject` 在应用中共享 Store 实例。

**与 Vuex 的对比**：
- 无 mutations：Pinia 的 actions 可直接修改 state，更简洁。
- 更好的 TS 支持：自动类型推导，无需复杂类型声明。
- 模块化：每个 Store 独立，无需嵌套模块。
- 体积更小：约 1KB。

### 例子

**例子 1：定义 Store（Options 风格）**

```javascript
// stores/counter.js
import { defineStore } from 'pinia'

export const useCounterStore = defineStore('counter', {
  state: () => ({
    count: 0,
    history: []
  }),

  getters: {
    double: (state) => state.count * 2,
    // 访问其他 getter
    quadruple() {
      return this.double * 2
    }
  },

  actions: {
    increment() {
      this.count++
      this.history.push('+1')
    },
    // 异步 action
    async incrementAsync() {
      await new Promise(r => setTimeout(r, 1000))
      this.increment()
    },
    reset() {
      this.count = 0
      this.history = []
    }
  }
```

**例子 2：定义 Store（Composition 风格，推荐）**

```javascript
// stores/user.js
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useUserStore = defineStore('user', () => {
  // state
  const user = ref(null)
  const token = ref('')

  // getters
  const isLoggedIn = computed(() => !!token.value)
  const username = computed(() => user.value?.name || '游客')

  // actions
  async function login(credentials) {
    const res = await fetch('/api/login', {
      method: 'POST',
      body: JSON.stringify(credentials)
    })
    const data = await res.json()
    user.value = data.user
    token.value = data.token
    localStorage.setItem('token', data.token)
  }

  function logout() {
    user.value = null
    token.value = ''
    localStorage.removeItem('token')
  }

  return { user, token, isLoggedIn, username, login, logout }
})
```

**例子 6：持久化插件**

```javascript
// stores/index.js
import { createPinia } from 'pinia'

const pinia = createPinia()

// 简单的持久化插件
pinia.use(({ store }) => {
  // 从 localStorage 恢复
  const saved = localStorage.getItem(store.$id)
  if (saved) {
    store.$patch(JSON.parse(saved))
  }
  // 订阅变化，保存到 localStorage
  store.$subscribe((mutation, state) => {
    localStorage.setItem(store.$id, JSON.stringify(state))
  })
})

export default pinia
```

### 总结

- Pinia 是 Vue3 官方状态管理库，替代 Vuex，更简洁、TS 友好。
- 两种定义风格：Options（`state/getters/actions`）和 Composition（`ref/computed/function`）。
- 解构 state/getter 需用 `storeToRefs`，action 可直接解构。
- **注意事项**：Store 是单例的，整个应用共享；避免在 Store 中存储组件级状态（应用 `ref` 局部管理）；`$reset`、`$patch`、`$subscribe` 是 Store 的实用方法。

## 第 19 讲：Vite 构建与部署

### 概念

Vite 是 Vue 团队开发的下一代前端构建工具，是 Vue3 项目的默认选择。相比 Webpack，Vite 在开发模式下利用浏览器原生 ES 模块实现**极速冷启动**和**按需编译**；生产环境使用 Rollup 打包，输出优化后的代码。

核心特性：
- **极速启动**：开发服务器无需打包，毫秒级启动。
- **HMR（热模块替换）**：修改代码后即时更新，保留应用状态。
- **按需编译**：只有被请求的模块才会编译。
- **开箱即用**：内置 TypeScript、JSX、CSS 预处理器、静态资源处理等支持。

### 原理

**开发模式**：Vite 启动一个开发服务器，拦截浏览器请求。当浏览器请求 `main.js` 时，Vite 编译 `.vue` 文件并返回原生 ES 模块。浏览器通过 `import` 自动加载依赖，Vite 按需编译，无需打包整个应用。

**生产构建**：Vite 使用 Rollup 打包，支持 Tree-shaking、代码分割、懒加载等优化。输出的是高度优化的静态资源。

**依赖预构建**：Vite 启动时会用 esbuild 预构建依赖（如 Vue、Lodash），将 CommonJS/UMD 转为 ESM，并合并小模块减少请求。

```nginx
    server_name example.com;
    root /usr/share/nginx/html;
    index index.html;

    # SPA 路由回退
    location / {
        try_files $uri $uri/ /index.html;

    location /api/ {
        proxy_pass http://backend:8080/;

    # 静态资源缓存

        expires 1y;
```

### 总结

- Vite 是 Vue3 默认构建工具，开发模式极速，生产模式基于 Rollup 优化。
- 核心配置：`plugins`、`resolve.alias`、`server.proxy`、`build.rollupOptions`。
- 环境变量以 `VITE_` 开头，通过 `import.meta.env` 访问。
- **注意事项**：生产部署需配置服务器 SPA 回退（`try_files ... /index.html`）；静态资源放 `public`（不处理）或 `src/assets`（带 hash）；分包策略能优化首屏加载。
