# 第 1 章 JavaScript 基础入门

本章是整个课程的起点。我们将从 JavaScript 的历史与定位讲起，逐步引入变量、数据类型、运算符和控制流程这些所有编程语言共有的基础构件。如果你已有其他语言基础，本章可以快速浏览；如果是零基础，请务必扎实掌握每一讲的内容，因为后续所有章节都建立在这些基础之上。

## 第 1 讲 JavaScript 简介与运行环境

### 概念

JavaScript（简称 JS）是一种**动态、弱类型、多范式**的解释型脚本语言，最初由 Brendan Eich 在 1995 年用 10 天时间为 Netscape 浏览器设计而成。它最初的名字叫 Mocha，后改名 LiveScript，最终为了蹭 Java 的热度而定名为 JavaScript——但实际上它与 Java 在语法和设计哲学上几乎没有关系。

今天的 JavaScript 已经是 Web 开发的"三件套"之一（HTML 负责结构、CSS 负责表现、JS 负责行为），并且通过 Node.js 进入了服务器端、命令行工具、桌面应用（Electron）、甚至嵌入式领域。它遵循 ECMAScript 标准，目前主流版本是 ES2023+。

### 原理

JavaScript 的运行依赖于**JavaScript 引擎**。不同的环境使用不同的引擎：

- **浏览器端**：Chrome 使用 V8、Firefox 使用 SpiderMonkey、Safari 使用 JavaScriptCore。
- **服务器端**：Node.js 同样使用 V8 引擎，但提供了文件系统、网络等浏览器中没有的 API。

JS 代码的执行过程大致是：源代码 → 词法/语法分析 → 抽象语法树（AST）→ 解释执行（早期）或即时编译（JIT，现代引擎）。现代引擎如 V8 会在运行时将热点代码编译为机器码以提升性能，这就是为什么 JS 虽然是"解释型语言"却能达到接近原生速度的原因。

JS 是**单线程**语言，通过事件循环（Event Loop）机制处理并发，这一点我们会在第 15 讲深入讲解。

### 例子

**在浏览器中运行 JS 的三种方式：**

```html
<!-- 方式 1：行内事件（不推荐，仅作了解） -->
<button onclick="alert('Hello!')">点击我</button>

<!-- 方式 2：script 标签内嵌 -->
<script>
  console.log('页面加载完成');
</script>

<!-- 方式 3：外部文件引入（推荐） -->
<script src="app.js"></script>
```

**第一个 JS 程序：**

```javascript
// 在控制台输出
console.log('Hello, JavaScript!');

// 弹窗提示
alert('欢迎学习 JavaScript');

// 操作网页内容
document.title = '我的第一个 JS 页面';
```

**使用 Node.js 运行：**

将上述代码（去掉 `alert` 和 `document` 相关行）保存为 `hello.js`，然后在终端执行：

```bash
node hello.js
# 输出：Hello, JavaScript!
```

### 总结

- JavaScript 是一门动态、弱类型、多范式的脚本语言，是 Web 开发的核心语言之一。
- 它运行在 JS 引擎之上，浏览器和 Node.js 是两大主流运行环境。
- 现代引擎使用 JIT 技术提升性能，JS 虽单线程但通过事件循环支持异步。
- 学习建议：浏览器控制台（F12）是最方便的实验环境，Node.js 适合写脚本和后端。
- 注意：JS 与 Java 是两门完全不同的语言，不要混淆。

## 第 2 讲 变量与数据类型

### 概念

**变量**是用于存储数据的命名容器。JavaScript 提供三种声明变量的关键字：`var`、`let`、`const`。

**数据类型**分为两大类：

- **原始类型（Primitive）**：`string`、`number`、`boolean`、`null`、`undefined`、`symbol`、`bigint`（共 7 种）
- **引用类型（Reference）**：`object`（包括普通对象、数组、函数、日期等）

### 原理

**三种声明方式的区别：**

| 特性 | `var` | `let` | `const` |
|------|-------|-------|---------|
| 作用域 | 函数作用域 | 块级作用域 | 块级作用域 |
| 变量提升 | 是（初始化为 undefined） | 有提升但存在"暂时性死区" | 同 let |
| 重复声明 | 允许 | 不允许 | 不允许 |
| 重新赋值 | 允许 | 允许 | 不允许 |

**弱类型**意味着 JS 变量没有固定的类型，类型由值决定，且会在运算时自动转换。例如 `'5' + 3` 得到字符串 `'53'`，而 `'5' - 3` 得到数字 `2`。这种隐式转换是 JS 著名的"坑"之一。

**原始类型 vs 引用类型**的核心区别在于存储方式：原始类型按值存储和传递，引用类型按引用（内存地址）存储和传递。

### 例子

**变量声明：**

```javascript
// 现代写法：优先使用 const，需要重新赋值时用 let，避免使用 var
const PI = 3.14159;        // 常量，不可重新赋值
let count = 0;             // 可变变量
count = count + 1;         // 合法
// PI = 3.14;              // 报错：Assignment to constant variable

// const 声明的对象，属性仍可修改（因为引用没变）
const user = { name: 'Alice' };
user.name = 'Bob';         // 合法
// user = { name: 'Bob' }; // 报错：不能重新赋值整个变量
```

**数据类型判断：**

```javascript
// typeof 适合判断原始类型
console.log(typeof 'hello');     // 'string'
console.log(typeof 42);          // 'number'
console.log(typeof true);        // 'boolean'
console.log(typeof undefined);   // 'undefined'
console.log(typeof null);        // 'object'  ← 这是一个历史遗留的 bug！
console.log(typeof {});          // 'object'
console.log(typeof []);          // 'object'   ← 数组也是 object
console.log(typeof function(){});// 'function'

// 精确判断 null 和数组
console.log(null === null);              // true
console.log(Array.isArray([1, 2, 3]));   // true
console.log(Array.isArray('123'));       // false
```

**类型转换：**

```javascript
// 显式转换（推荐）
Number('123');      // 123
String(123);        // '123'
Boolean(0);         // false
Boolean('');        // false
Boolean(null);      // false
Boolean('hello');   // true

// 隐式转换（容易出 bug，要小心）
console.log(1 + '2');      // '12'  字符串拼接
console.log('5' - 2);      // 3     数字相减
console.log('5' * '2');    // 10
console.log([] + {});      // '[object Object]'
console.log(true + 1);     // 2
```

### 总结

- 优先使用 `const`，需要重新赋值时用 `let`，**永远不要在新代码中使用 `var`**。
- JS 有 7 种原始类型和 1 种引用类型（object）。
- `typeof null` 返回 `'object'` 是历史 bug，判断 null 用 `=== null`。
- 判断数组用 `Array.isArray()`，不要用 `typeof`。
- 弱类型的隐式转换是 JS 的双刃剑：方便但易错，建议养成显式转换的习惯。
- 记住"假值"清单：`false`、`0`、`''`、`null`、`undefined`、`NaN`，其余都是真值。

## 第 3 讲 运算符与表达式

### 概念

**运算符**是用于执行某种操作的符号，JS 提供算术、赋值、比较、逻辑、位、三元等多种运算符。**表达式**是任何能求值出结果的代码片段，如 `1 + 2`、`a > b ? '大' : '小'`。

### 原理

JS 运算符有几个关键特性需要理解：

1. **运算符优先级与结合性**：决定复杂表达式的求值顺序，如 `2 + 3 * 4` 等于 14 而非 20。
2. **`==` vs `===`**：`==` 会进行类型转换后比较，`===` 严格相等不转换。现代规范**强烈推荐始终使用 `===`**。
3. **短路求值**：逻辑运算符 `&&` 和 `||` 在能确定结果时不再计算右侧，这一特性常用于默认值和条件执行。
4. **`??` 空值合并运算符**：ES2020 引入，仅在左侧为 `null` 或 `undefined` 时返回右侧，比 `||` 更精确。

### 例子

**算术与赋值：**

```javascript
let x = 10;
x += 5;     // x = x + 5 = 15
x **= 2;    // x = x ** 2 = 225（幂运算）
x %= 7;     // x = x % 7 = 1（取模）

// 自增自减
let i = 5;
console.log(i++);  // 5（先返回再自增）
console.log(i);    // 6
console.log(++i);  // 7（先自增再返回）
```

**比较运算：**

```javascript
// == 会做类型转换，结果常常出人意料
console.log(1 == '1');     // true  ← 不推荐
console.log(0 == false);   // true  ← 不推荐
console.log(null == undefined); // true ← 不推荐
console.log(NaN == NaN);   // false ← NaN 不等于任何值，包括自己

// === 严格相等，推荐始终使用
console.log(1 === '1');    // false
console.log(0 === false);  // false

// 判断 NaN 的正确方式
console.log(Number.isNaN(NaN));  // true
console.log(Object.is(NaN, NaN)); // true
```

**逻辑运算与短路：**

```javascript
// && 短路：左侧为假则不计算右侧
const user = null;
console.log(user && user.name);  // null

// || 默认值
const name = userInput || '匿名';

// ?? 空值合并（ES2020）：仅 null/undefined 触发
const count = 0;
console.log(count || 10);   // 10  ← 0 被当作假值
console.log(count ?? 10);   // 0   ← 0 是有效值，保留

// 三元运算符
const age = 18;
const status = age >= 18 ? '成年' : '未成年';
console.log(status);  // '成年'
```

**展开运算符（Spread）：**

```javascript
// 数组展开
const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5];  // [1, 2, 3, 4, 5]

// 对象展开（浅拷贝 + 合并）
const defaults = { theme: 'light', fontSize: 14 };
const userConfig = { fontSize: 16 };
const merged = { ...defaults, ...userConfig };
// { theme: 'light', fontSize: 16 }
```

### 总结

- 始终使用 `===` 和 `!==` 进行比较，避免 `==` 的隐式转换陷阱。
- `||` 用于默认值时会把 `0`、`''`、`false` 等有效值也覆盖，需要默认值时优先用 `??`。
- 短路求值是编写简洁代码的利器，但不要滥用以免降低可读性。
- 展开运算符 `...` 是浅拷贝，嵌套对象仍是引用。
- `NaN` 是 JS 中唯一不等于自身的值，判断时用 `Number.isNaN()`。

## 第 4 讲 控制流程（条件与循环）

### 概念

**控制流程**决定程序的执行路径。JS 提供两类控制结构：

- **条件分支**：`if...else`、`switch`
- **循环**：`for`、`while`、`do...while`、`for...of`、`for...in`

### 原理

条件语句根据表达式的真假选择执行路径。JS 中所有值都能转为布尔，假值有 6 个：`false`、`0`、`''`、`null`、`undefined`、`NaN`，其余皆为真。

循环用于重复执行代码块。不同循环有不同适用场景：

- `for`：已知次数的循环
- `while`：条件驱动的循环
- `for...of`：遍历可迭代对象（数组、字符串、Map、Set 等），ES6 引入
- `for...in`：遍历对象的可枚举属性（包括继承的），慎用于数组

`break` 立即跳出循环，`continue` 跳过本次迭代进入下一次。

### 例子

**条件分支：**

```javascript
const score = 85;

// if...else if...else
if (score >= 90) {
  console.log('优秀');
} else if (score >= 80) {
  console.log('良好');  // 输出
} else if (score >= 60) {
  console.log('及格');
} else {
  console.log('不及格');
}

// switch 适合多值匹配（注意 break 和 default）
const day = 'Mon';
switch (day) {
  case 'Sat':
  case 'Sun':
    console.log('周末');
    break;          // 不写 break 会"穿透"到下一个 case
  default:
    console.log('工作日');  // 输出
}
```

**经典 for 循环：**

```javascript
// 求 1 到 100 的和
let sum = 0;
for (let i = 1; i <= 100; i++) {
  sum += i;
}
console.log(sum);  // 5050

// 遍历数组（传统方式）
const fruits = ['apple', 'banana', 'cherry'];
for (let i = 0; i < fruits.length; i++) {
  console.log(i, fruits[i]);
}
```

**for...of 与 for...in：**

```javascript
// for...of：遍历值（推荐用于数组）
const colors = ['red', 'green', 'blue'];
for (const color of colors) {
  console.log(color);
}
// red / green / blue

// for...in：遍历键（推荐用于对象）
const person = { name: 'Alice', age: 25, city: '北京' };
for (const key in person) {
  console.log(key, ':', person[key]);
}
// name : Alice / age : 25 / city : 北京

// 注意：for...in 遍历数组会得到字符串索引 '0','1','2'，且可能遍历到原型属性，不推荐
```

**while 与 do...while：**

```javascript
// while：先判断后执行
let n = 5;
while (n > 0) {
  console.log(n--);  // 5 4 3 2 1
}

// do...while：先执行后判断，至少执行一次
let m = 0;
do {
  console.log('执行一次');
} while (m > 0);
```

**break 与 continue：**

```javascript
// 找到第一个能被 7 整除的三位数
for (let i = 100; i < 1000; i++) {
  if (i % 7 === 0) {
    console.log(i);  // 105
    break;
  }
}

// 跳过所有偶数
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue;
  console.log(i);  // 1 3 5 7 9
}
```

### 总结

- 条件判断时注意假值清单，避免 `if (count)` 在 count 为 0 时误判。
- `switch` 必须配 `break`，否则会发生"穿透"（除非刻意利用）。
- 遍历数组用 `for...of`，遍历对象用 `for...in`，不要混用。
- `for...in` 会遍历继承属性，必要时用 `Object.hasOwn()` 过滤。
- 死循环 `while (true)` 必须配合 `break` 使用，否则会卡死程序。
- 现代数组遍历更推荐 `forEach`、`map`、`filter` 等高阶函数（第 9 讲详解）。

# 第 2 章 函数与作用域

函数是 JavaScript 的"一等公民"，可以作为变量赋值、作为参数传递、作为返回值返回。本章将深入函数的方方面面，包括作用域、闭包、`this` 等 JS 最具特色也最容易踩坑的语言机制。理解本章是掌握 JavaScript 的关键。

## 第 5 讲 函数基础与参数

### 概念

**函数**是一段可重复使用的代码块，接收输入（参数）、执行操作、返回输出（返回值）。JS 中函数是**一等公民**（First-Class Citizen），意味着函数本身就是一种值，与其他类型地位平等。

### 原理

JS 函数有四种声明方式，它们在提升行为和适用场景上有所不同：

1. **函数声明**：`function foo() {}`，会被提升到作用域顶部，可在声明前调用。
2. **函数表达式**：`const foo = function() {}`，不会提升，必须先定义后使用。
3. **箭头函数**：`const foo = () => {}`，ES6 引入，没有自己的 `this`（第 8 讲详解）。
4. **构造函数**：`new Function()`，几乎不用，了解即可。

**参数机制**有几个要点：

- JS 函数参数是**按值传递**的，但引用类型传的是引用的副本。
- 形参个数与实参个数不必匹配，多余实参被忽略，缺失形参为 `undefined`。
- ES6 引入**默认参数**、**剩余参数**（rest）、**命名参数**（解构）等特性。

### 例子

**四种声明方式：**

```javascript
// 1. 函数声明（有提升）
function greet(name) {
  return `Hello, ${name}!`;
}

// 2. 函数表达式（无提升）
const greet2 = function(name) {
  return `Hello, ${name}!`;
};

// 3. 箭头函数
const greet3 = (name) => `Hello, ${name}!`;

// 4. Function 构造（不推荐）
const greet4 = new Function('name', 'return "Hello, " + name + "!"');

console.log(greet('Alice'));   // 4 种方式调用结果相同
```

**默认参数与剩余参数：**

```javascript
// 默认参数
function createUser(name, role = 'user', active = true) {
  return { name, role, active };
}
console.log(createUser('Bob'));
// { name: 'Bob', role: 'user', active: true }

console.log(createUser('Carol', 'admin'));
// { name: 'Carol', role: 'admin', active: true }

// 剩余参数（rest）：收集多余实参为数组
function sum(...nums) {
  return nums.reduce((a, b) => a + b, 0);
}
console.log(sum(1, 2, 3, 4, 5));  // 15

// 结合普通参数
function log(tag, ...messages) {
  console.log(`[${tag}]`, ...messages);
}
log('INFO', '启动成功', '端口 3000');
// [INFO] 启动成功 端口 3000
```

**参数解构：**

```javascript
// 命名参数：通过对象解构实现，调用时更清晰
function render({ title, content = '', theme = 'light' }) {
  console.log(`标题：${title}，主题：${theme}`);
  console.log(`内容：${content}`);
}

render({ title: '欢迎', content: '你好世界' });
render({ title: '通知', theme: 'dark' });
```

**函数作为值：**

```javascript
// 函数作为参数（回调）
[1, 2, 3].forEach(function(item) {
  console.log(item * 2);
});

// 函数作为返回值（高阶函数）
function multiplier(factor) {
  return function(x) {
    return x * factor;
  };
}
const double = multiplier(2);
const triple = multiplier(3);
console.log(double(5));   // 10
console.log(triple(5));   // 15
```

### 总结

- 函数是 JS 的一等公民，可以像普通值一样传递和返回。
- 优先使用函数声明或箭头函数，避免 `new Function`。
- 默认参数让函数更健壮，剩余参数替代了过时的 `arguments` 对象。
- 命名参数（解构）能显著提升函数调用的可读性，尤其当参数较多时。
- 函数声明有提升，函数表达式没有——为避免混淆，统一遵循"先定义后使用"。
- 高阶函数（接收函数为参数或返回函数）是函数式编程的基础，第 9 讲会大量使用。

## 第 6 讲 作用域与作用域链

### 概念

**作用域（Scope）**是变量和函数可被访问的范围。JS 有三种作用域：

- **全局作用域**：在所有函数之外声明的变量，处处可访问。
- **函数作用域**：在函数内声明的变量，仅在函数内可访问（`var` 适用）。
- **块级作用域**：在 `{}` 块内用 `let`/`const` 声明的变量，仅在块内可访问。

**作用域链**是函数在定义时形成的、由内向外查找变量的链式结构。

### 原理

理解作用域的关键是区分**词法作用域**（Lexical Scope）和**动态作用域**。JS 采用**词法作用域**（也叫静态作用域），即函数的作用域在**定义时**就确定了，而不是在调用时。

`var` 声明的变量具有**函数作用域**，会发生**变量提升**——声明被提升到函数顶部，但赋值留在原地。这会导致一些反直觉的行为。

`let` 和 `const` 具有**块级作用域**，虽然也会提升，但存在**暂时性死区（TDZ）**——从作用域开始到声明语句之间的区域，访问变量会报 `ReferenceError`。

### 例子

**三种作用域对比：**

```javascript
// 全局作用域
const globalVar = '我是全局的';

function outer() {
  // 函数作用域
  var functionVar = '我是函数级的';
  
  if (true) {
    // 块级作用域
    let blockVar = '我是块级的';
    var notBlock = 'var 不受块限制';
    console.log(globalVar);      // 可访问
    console.log(functionVar);    // 可访问
    console.log(blockVar);       // 可访问
  }
  
  console.log(globalVar);        // 可访问
  console.log(functionVar);      // 可访问
  // console.log(blockVar);      // 报错：blockVar is not defined
  console.log(notBlock);         // 可访问（var 穿透了块）
}
```

**var 的变量提升：**

```javascript
console.log(a);  // undefined（不是报错！）
var a = 5;
console.log(a);  // 5

// 上面代码等价于：
var a;           // 声明被提升
console.log(a);  // undefined
a = 5;           // 赋值留在原地
console.log(a);  // 5

// 对比 let 的暂时性死区
// console.log(b);  // ReferenceError: Cannot access 'b' before initialization
let b = 5;
```

**词法作用域：**

```javascript
const message = '外层';

function foo() {
  console.log(message);  // '外层'，函数定义时就确定了作用域
}

function bar() {
  const message = '内层';
  foo();  // foo 仍然访问外层的 message
}

bar();  // 输出 '外层'，不是 '内层'
```

**作用域链查找：**

```javascript
const a = 1;
function f1() {
  const b = 2;
  function f2() {
    const c = 3;
    // 查找顺序：f2 作用域 → f1 作用域 → 全局作用域
    console.log(a, b, c);  // 1 2 3
  }
  f2();
}
f1();
```

### 总结

- 优先使用 `let`/`const` 的块级作用域，避免 `var` 的函数作用域和变量提升带来的混乱。
- JS 是词法作用域，函数能访问的变量在定义时就确定了，与调用位置无关。
- 作用域链是变量查找的路径，从内向外，找到即停，找不到则 `ReferenceError`。
- 暂时性死区（TDZ）让 `let`/`const` 比 `var` 更安全，强制"先声明后使用"。
- 全局变量会污染全局命名空间，应尽量减少使用，必要时用模块化封装（第 19 讲）。

## 第 7 讲 闭包

### 概念

**闭包（Closure）**是函数和其词法环境的组合。简单说，当一个函数在其定义作用域之外被调用，但仍能访问定义时的局部变量时，就形成了闭包。闭包让函数"记住"了它诞生时的环境。

### 原理

闭包的本质是：**函数持有对其词法作用域中变量的引用**，即使该作用域已经"结束"，变量也不会被垃圾回收，因为函数仍然引用着它们。

每次调用外部函数都会创建一个新的闭包，每个闭包维护自己独立的变量状态。这是实现私有变量、模块模式、函数工厂等模式的基础。

闭包的常见应用场景：

1. **数据私有化**：模拟私有变量（JS 没有真正的 private，class 私有字段 `#` 是 ES2022 才有的）。
2. **函数工厂**：根据参数生成具有特定行为的函数。
3. **回调与异步**：保留状态供回调使用。
4. **模块模式**：封装一组相关功能，只暴露公共接口。

### 例子

**基本闭包：**

```javascript
function makeCounter() {
  let count = 0;  // 这个变量被闭包"捕获"
  return function() {
    count++;
    return count;
  };
}

const counter = makeCounter();
console.log(counter());  // 1
console.log(counter());  // 2
console.log(counter());  // 3

// 每次调用 makeCounter 创建独立的闭包
const counter2 = makeCounter();
console.log(counter2());  // 1（与 counter 互不影响）

// 外部无法直接访问 count
// console.log(count);  // ReferenceError
```

**函数工厂：**

```javascript
function makeAdder(x) {
  return function(y) {
    return x + y;
  };
}

const add5 = makeAdder(5);
const add10 = makeAdder(10);

console.log(add5(2));   // 7
console.log(add10(2));  // 12
// add5 记住了 x=5，add10 记住了 x=10
```

**模块模式（数据私有化）：**

```javascript
const createBankAccount = (initialBalance) => {
  let balance = initialBalance;  // 私有变量
  
  return {
    deposit(amount) {
      balance += amount;
      return balance;
    },
    withdraw(amount) {
      if (amount > balance) {
        throw new Error('余额不足');
      }
      balance -= amount;
      return balance;
    },
    getBalance() {
      return balance;
    }
  };
};

const account = createBankAccount(100);
console.log(account.deposit(50));   // 150
console.log(account.withdraw(30));  // 120
console.log(account.getBalance());  // 120
// account.balance  // undefined，无法直接访问
```

**经典陷阱：循环中的闭包**

```javascript
// ❌ 错误写法：所有定时器都输出 3
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// 输出：3 3 3（因为 var 是函数作用域，3 个闭包共享同一个 i）

// ✅ 修正 1：用 let
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
// 输出：0 1 2（每次迭代创建新的块作用域）

// ✅ 修正 2：用 IIFE 立即执行函数
for (var i = 0; i < 3; i++) {
  (function(j) {
    setTimeout(() => console.log(j), 100);
  })(i);
}
// 输出：0 1 2
```

### 总结

- 闭包 = 函数 + 词法环境，让函数"记住"定义时的作用域。
- 闭包常用于数据私有化、函数工厂、模块封装、回调状态保持。
- 每次调用外部函数都会创建新的闭包，闭包之间状态独立。
- 注意闭包陷阱：循环中使用 `var` 会导致所有闭包共享同一变量，改用 `let` 即可解决。
- 闭包会持有对外部变量的引用，可能导致内存无法回收，长期运行的程序要注意释放（将引用置为 null）。

## 第 8 讲 `this` 指向与箭头函数

### 概念

`this` 是函数执行时的**当前对象**引用，是 JS 中最令人困惑的概念之一。它的值**在调用时确定**，而非定义时，取决于函数的调用方式。

**箭头函数**（Arrow Function）是 ES6 引入的简洁函数语法，最重要的特性是**没有自己的 `this`**，而是继承外层作用域的 `this`。

### 原理

`this` 的指向遵循以下规则（按优先级从高到低）：

1. **`new` 调用**：`this` 指向新创建的对象。
2. **`call`/`apply`/`bind` 显式绑定**：`this` 指向传入的对象。
3. **方法调用**（`obj.fn()`）：`this` 指向 `obj`。
4. **普通函数调用**：非严格模式下 `this` 指向全局对象（浏览器中是 `window`，Node 中是 `global`）；严格模式下是 `undefined`。
5. **箭头函数**：没有自己的 `this`，继承外层。

`call`、`apply`、`bind` 三者的区别：

- `fn.call(thisArg, arg1, arg2)`：立即调用，参数逐个传递。
- `fn.apply(thisArg, [arg1, arg2])`：立即调用，参数以数组传递。
- `fn.bind(thisArg, arg1, arg2)`：不立即调用，返回一个绑定了 `this` 的新函数。

### 例子

**`this` 的四种绑定方式：**

```javascript
// 1. 默认绑定（普通调用）
function showThis() {
  console.log(this);
}
showThis();  // 非严格模式：window/global；严格模式：undefined

// 2. 隐式绑定（方法调用）
const obj = {
  name: 'Alice',
  greet() {
    console.log(`Hello, ${this.name}`);
  }
};
obj.greet();  // 'Hello, Alice'，this 指向 obj

// 3. 显式绑定（call/apply/bind）
function introduce(greeting) {
  console.log(`${greeting}, I'm ${this.name}`);
}
const person = { name: 'Bob' };
introduce.call(person, 'Hi');     // 'Hi, I'm Bob'
introduce.apply(person, ['Hi']);  // 'Hi, I'm Bob'
const bound = introduce.bind(person, 'Hello');
bound();  // 'Hello, I'm Bob'

// 4. new 绑定
function User(name) {
  this.name = name;
}
const u = new User('Carol');
console.log(u.name);  // 'Carol'
```

**this 丢失的经典问题：**

```javascript
const obj = {
  name: 'Alice',
  greet() {
    console.log(`Hello, ${this.name}`);
  }
};

// 直接调用，this 是 obj
obj.greet();  // 'Hello, Alice'

// 把方法赋值给变量再调用，this 丢失
const fn = obj.greet;
fn();  // 'Hello, undefined'（非严格模式下 this 是 window）

// 回调中也会丢失
setTimeout(obj.greet, 100);  // 'Hello, undefined'
```

**箭头函数解决 this 问题：**

```javascript
const obj = {
  name: 'Alice',
  friends: ['Bob', 'Carol'],
  
  // ❌ 普通函数：回调中 this 丢失
  printFriendsBad() {
    this.friends.forEach(function(friend) {
      console.log(`${this.name} 的朋友：${friend}`);  // this.name 是 undefined
    });
  },
  
  // ✅ 箭头函数：继承外层 this
  printFriendsGood() {
    this.friends.forEach(friend => {
      console.log(`${this.name} 的朋友：${friend}`);  // this 是 obj
    });
  }
};

obj.printFriendsBad();   // undefined 的朋友：Bob / Carol
obj.printFriendsGood();  // Alice 的朋友：Bob / Carol
```

**箭头函数的其他特性：**

```javascript
// 1. 没有自己的 arguments（继承外层）
function outer() {
  const inner = () => {
    console.log(arguments);  // 这是 outer 的 arguments
  };
  inner(1, 2, 3);
}
outer('a', 'b');

// 2. 不能作为构造函数
// const Foo = () => {};
// new Foo();  // TypeError: Foo is not a constructor

// 3. 没有 prototype 属性
const arrow = () => {};
console.log(arrow.prototype);  // undefined

// 4. 简写：单参数可省括号，单表达式可省 return 和 {}
const square = x => x * x;
console.log(square(5));  // 25

// 5. 返回对象字面量需用括号包裹
const makeUser = name => ({ name, role: 'user' });
console.log(makeUser('Alice'));  // { name: 'Alice', role: 'user' }
```

### 总结

- `this` 在调用时确定，取决于调用方式，而非定义方式。
- 四种绑定优先级：`new` > 显式绑定（call/apply/bind）> 隐式绑定（方法调用）> 默认绑定。
- 方法赋值或作为回调传递时 `this` 会丢失，需用 `bind` 绑定或改用箭头函数。
- 箭头函数没有自己的 `this`、`arguments`、`prototype`，不能作为构造函数。
- **使用建议**：需要对象方法中的 `this` 指向对象本身时用普通函数；需要继承外层 `this`（如回调）时用箭头函数。
- 不要用箭头函数定义对象方法，否则 `this` 不会指向对象：
  ```javascript
  const obj = {
    name: 'Alice',
    greet: () => console.log(this.name)  // ❌ this 不是 obj
  };
  ```

# 第 3 章 核心数据结构

本章介绍 JavaScript 中最常用的三种数据结构：数组、对象、字符串。它们是日常编程的基石，掌握其内置方法能极大提升开发效率。本章还会涉及 ES6 引入的解构赋值和扩展运算符，这些是现代 JS 代码的标配写法。

## 第 9 讲 数组及其方法

### 概念

**数组（Array）**是一种有序的、可变长度的数据集合，可以存放任意类型的元素。JS 数组是动态的、弱类型的，长度可随时改变，元素类型可以混合。

### 原理

JS 数组本质上是**对象**，其索引被转为字符串作为属性名，`length` 属性会自动维护。这意味着：

- 数组可以有不连续的索引（稀疏数组）。
- `typeof []` 返回 `'object'`，需用 `Array.isArray()` 判断。
- 数组是引用类型，赋值传递的是引用而非副本。

数组方法按是否修改原数组分为两类：

- **修改原数组（mutator）**：`push`/`pop`、`shift`/`unshift`、`splice`、`sort`、`reverse`、`fill`。
- **返回新数组（accessor）**：`slice`、`concat`、`map`、`filter`、`flat`、`flatMap`。

ES5+ 引入了一批强大的**高阶函数**：`forEach`、`map`、`filter`、`reduce`、`find`、`some`、`every`，它们是函数式编程在 JS 中的核心应用。

### 例子

**创建与基本操作：**

```javascript
// 创建数组
const arr1 = [1, 2, 3];
const arr2 = new Array(5);       // [empty × 5]
const arr3 = Array.from('hello'); // ['h','e','l','l','o']
const arr4 = Array.of(7);        // [7]（区别于 new Array(7)）

// 访问与修改
const fruits = ['apple', 'banana', 'cherry'];
console.log(fruits[0]);          // 'apple'
console.log(fruits.length);      // 3
fruits[1] = 'blueberry';
console.log(fruits);             // ['apple', 'blueberry', 'cherry']

// 增删
fruits.push('date');             // 末尾添加，返回新长度
fruits.pop();                    // 末尾删除，返回删除元素
fruits.unshift('avocado');       // 头部添加
fruits.shift();                  // 头部删除
```

**增删改查：splice / slice / concat：**

```javascript
const nums = [1, 2, 3, 4, 5];

// splice(起始索引, 删除个数, ...插入元素)：修改原数组
nums.splice(1, 2);              // 删除索引 1 起 2 个 → [1, 4, 5]
nums.splice(1, 0, 'a', 'b');    // 插入 → [1, 'a', 'b', 4, 5]
nums.splice(1, 2, 'x');         // 替换 → [1, 'x', 4, 5]

// slice(起始, 结束)：返回新数组，不改原数组
const part = [1, 2, 3, 4, 5].slice(1, 4);  // [2, 3, 4]
const copy = [1, 2, 3].slice();             // 浅拷贝

// concat：合并数组
const merged = [1, 2].concat([3, 4], [5]);  // [1, 2, 3, 4, 5]
// 等价于展开运算符：[...[1,2], ...[3,4], ...[5]]
```

**高阶函数（重点）：**

```javascript
const nums = [1, 2, 3, 4, 5, 6];

// map：映射，返回新数组
const doubled = nums.map(n => n * 2);
// [2, 4, 6, 8, 10, 12]

// filter：过滤
const evens = nums.filter(n => n % 2 === 0);
// [2, 4, 6]

// reduce：归约，常用于求和、累计
const sum = nums.reduce((acc, n) => acc + n, 0);  // 21
const max = nums.reduce((a, b) => Math.max(a, b)); // 6

// find / findIndex：查找第一个满足条件的元素
const firstEven = nums.find(n => n % 2 === 0);     // 2
const firstEvenIdx = nums.findIndex(n => n % 2 === 0); // 1

// some / every：判断
const hasNegative = nums.some(n => n < 0);   // false
const allPositive = nums.every(n => n > 0);  // true

// forEach：遍历（无返回值）
nums.forEach((n, i) => console.log(i, n));
```

**链式调用：**

```javascript
const users = [
  { name: 'Alice', age: 25, active: true },
  { name: 'Bob', age: 17, active: true },
  { name: 'Carol', age: 30, active: false },
  { name: 'Dave', age: 16, active: true }
];

// 找出所有活跃的成年用户的名字
const names = users
  .filter(u => u.active)
  .filter(u => u.age >= 18)
  .map(u => u.name);
// ['Alice']
```

**排序与扁平化：**

```javascript
// sort 默认按字符串排序，数字排序需传比较函数
const nums = [10, 2, 33, 4];
nums.sort();                          // [10, 2, 33, 4] ← 错误！
nums.sort((a, b) => a - b);           // [2, 4, 10, 33] ← 升序
nums.sort((a, b) => b - a);           // [33, 10, 4, 2] ← 降序

// flat：扁平化嵌套数组
const nested = [1, [2, [3, [4]]]];
nested.flat();      // [1, 2, [3, [4]]]   默认展平 1 层
nested.flat(2);     // [1, 2, 3, [4]]
nested.flat(Infinity);  // [1, 2, 3, 4]   全部展平

// flatMap：先 map 再 flat(1)
[1, 2, 3].flatMap(n => [n, n * 2]);
// [1, 2, 2, 4, 3, 6]
```

### 总结

- 数组本质是对象，用 `Array.isArray()` 判断，不要用 `typeof`。
- 区分修改原数组的方法（push/splice/sort 等）和返回新数组的方法（slice/map/filter 等），函数式编程倾向后者。
- `map`/`filter`/`reduce` 是三大核心高阶函数，掌握它们能写出简洁优雅的代码。
- `sort` 默认按字符串排序，数字排序必须传比较函数 `(a, b) => a - b`。
- 链式调用让代码更声明式，但要注意每一步都创建新数组，大数据量场景考虑性能。
- 数组拷贝是浅拷贝，嵌套对象仍是引用，深拷贝可用 `structuredClone()`（现代浏览器支持）。

## 第 10 讲 对象基础与解构

### 概念

**对象（Object）**是 JS 中最常用的数据结构，由键值对组成，键必须是字符串或 Symbol，值可以是任意类型。对象是引用类型，赋值和传参传递的是引用。

**解构赋值（Destructuring）**是 ES6 引入的语法，可以从数组或对象中按模式提取值并赋给变量，大幅简化代码。

### 原理

对象的属性访问有两种方式：

- **点语法** `obj.key`：键必须是合法标识符。
- **方括号语法** `obj['key']`：键可以是任意字符串或表达式，更灵活。

ES6 引入了若干对象相关的语法糖：

- **属性简写**：当属性名与变量名相同时可简写。
- **方法简写**：`{ foo() {} }` 等价于 `{ foo: function() {} }`。
- **计算属性名**：`{ [expr]: value }`，键可以是表达式。
- **展开运算符**：`{ ...obj }` 浅拷贝或合并对象。

对象的遍历方法：

- `Object.keys(obj)`：返回键数组。
- `Object.values(obj)`：返回值数组。
- `Object.entries(obj)`：返回 `[key, value]` 二维数组。

### 例子

**对象创建与属性操作：**

```javascript
// 对象字面量（最常用）
const user = {
  name: 'Alice',
  age: 25,
  'favorite-color': 'blue',  // 非合法标识符的键需用引号
  greet() {                  // 方法简写
    return `Hi, I'm ${this.name}`;
  }
};

// 属性访问
console.log(user.name);            // 'Alice'（点语法）
console.log(user['favorite-color']); // 'blue'（方括号）
const key = 'age';
console.log(user[key]);            // 25（动态键）

// 添加 / 修改 / 删除
user.email = 'alice@example.com';  // 添加
user.age = 26;                     // 修改
delete user.email;                 // 删除

// 判断属性是否存在
console.log('name' in user);              // true
console.log(user.hasOwnProperty('name')); // true（旧写法）
console.log(Object.hasOwn(user, 'name')); // true（ES2022 推荐）
```

**ES6 语法糖：**

```javascript
const name = 'Alice';
const age = 25;

// 属性简写
const user = { name, age };  // 等价于 { name: name, age: age }

// 计算属性名
const field = 'score';
const student = {
  name: 'Bob',
  [field]: 95,           // 键是变量 field 的值 'score'
  [`total_${field}`]: 100  // 模板字符串也可
};
console.log(student.score);        // 95
console.log(student.total_score);  // 100
```

**对象解构：**

```javascript
const user = { name: 'Alice', age: 25, city: '北京', role: 'admin' };

// 基本解构
const { name, age } = user;
console.log(name, age);  // 'Alice' 25

// 重命名
const { name: userName } = user;
console.log(userName);  // 'Alice'

// 默认值
const { country = '中国' } = user;
console.log(country);  // '中国'

// 嵌套解构
const company = {
  name: 'Acme',
  address: { city: '上海', street: '南京路' }
};
const { address: { city } } = company;
console.log(city);  // '上海'

// 函数参数解构（非常常用）
function render({ title, content = '无内容', theme = 'light' }) {
  console.log(title, content, theme);
}
render({ title: '通知' });  // '通知' '无内容' 'light'
```

**数组解构：**

```javascript
// 基本解构
const [a, b, c] = [1, 2, 3];
console.log(a, b, c);  // 1 2 3

// 跳过元素
const [first, , third] = [1, 2, 3];
console.log(first, third);  // 1 3

// 默认值
const [x = 10, y = 20] = [5];
console.log(x, y);  // 5 20

// 交换变量（经典用法）
let m = 1, n = 2;
[m, n] = [n, m];
console.log(m, n);  // 2 1

// 剩余元素
const [head, ...tail] = [1, 2, 3, 4];
console.log(head, tail);  // 1 [2, 3, 4]
```

**对象遍历与拷贝：**

```javascript
const user = { name: 'Alice', age: 25, city: '北京' };

// 遍历键
for (const key of Object.keys(user)) {
  console.log(key);  // name / age / city
}

// 遍历值
for (const val of Object.values(user)) {
  console.log(val);
}

// 遍历键值对
for (const [key, val] of Object.entries(user)) {
  console.log(`${key}: ${val}`);
}

// 浅拷贝
const shallowCopy = { ...user };
const shallowCopy2 = Object.assign({}, user);

// 深拷贝（简单场景）
const deepCopy = structuredClone(user);

// 合并对象（后者覆盖前者）
const defaults = { theme: 'light', lang: 'zh' };
const userConfig = { theme: 'dark' };
const config = { ...defaults, ...userConfig };
// { theme: 'dark', lang: 'zh' }
```

### 总结

- 对象是键值对集合，键为字符串或 Symbol，值为任意类型。
- 点语法用于固定键，方括号用于动态键和非标识符键。
- 解构赋值大幅简化对象/数组的取值，是现代 JS 代码的标配。
- 展开运算符 `...` 实现浅拷贝和合并，深拷贝用 `structuredClone()`。
- `Object.keys/values/entries` 是遍历对象的三剑客，配合 `for...of` 使用。
- 对象属性顺序：整数键按升序排列，字符串和 Symbol 键按添加顺序排列。

## 第 11 讲 字符串与正则表达式

### 概念

**字符串（String）**是表示文本的不可变序列。JS 字符串使用 UTF-16 编码，每个字符占 2 字节（少数辅助平面字符占 4 字节，需用代理对表示）。

**正则表达式（RegExp）**是一种描述字符串模式的微型语言，用于匹配、查找、替换文本。JS 正则语法与 Perl 兼容。

### 原理

字符串的**不可变性**意味着所有字符串方法都返回新字符串，原字符串不变。频繁拼接大量字符串时，应使用数组 `join` 或模板字符串，避免 `+` 在循环中产生大量临时字符串。

ES6 引入了**模板字符串**（Template Literal），用反引号包裹，支持多行和 `${}` 插值，几乎完全取代了传统的字符串拼接。

正则表达式由**字面量字符**和**元字符**组成。常用元字符包括：

- `.` 任意字符、`\d` 数字、`\w` 字母数字下划线、`\s` 空白
- `*` 0+ 次、`+` 1+ 次、`?` 0/1 次、`{n,m}` n 到 m 次
- `^` 开头、`$` 结尾、`[]` 字符集、`()` 分组、`|` 或
- 修饰符：`g` 全局、`i` 忽略大小写、`m` 多行、`s` 让 `.` 匹配换行

### 例子

**字符串基础方法：**

```javascript
const str = 'Hello, World!';

// 长度与索引
console.log(str.length);       // 13
console.log(str[0]);           // 'H'
console.log(str.charAt(0));    // 'H'
console.log(str.charCodeAt(0)); // 72（'H' 的 ASCII 码）

// 查找
console.log(str.indexOf('o'));     // 4（首次出现的索引）
console.log(str.lastIndexOf('o')); // 8
console.log(str.includes('World')); // true（ES6）
console.log(str.startsWith('Hello')); // true
console.log(str.endsWith('!'));       // true

// 截取
console.log(str.slice(0, 5));    // 'Hello'
console.log(str.slice(-6));      // 'World!'
console.log(str.substring(0, 5)); // 'Hello'（不支持负数）
console.log(str.substr(7, 5));   // 'World'（已废弃，不推荐）

// 大小写转换
console.log(str.toUpperCase());  // 'HELLO, WORLD!'
console.log(str.toLowerCase());  // 'hello, world!'

// 分割与拼接
console.log('a,b,c,d'.split(','));     // ['a','b','c','d']
console.log(['a','b','c'].join('-'));  // 'a-b-c'

// 替换
console.log('hello'.replace('l', 'L'));   // 'heLlo'（只替换第一个）
console.log('hello'.replaceAll('l', 'L')); // 'heLLo'（ES2021，全部替换）
console.log('hello'.replace(/l/g, 'L'));   // 'heLLo'（正则全局替换）

// 去除空白
console.log('  hi  '.trim());      // 'hi'
console.log('  hi  '.trimStart()); // 'hi  '
console.log('  hi  '.trimEnd());   // '  hi'
```

**模板字符串：**

```javascript
const name = 'Alice';
const age = 25;

// 插值
const greeting = `你好，我叫${name}，今年${age}岁`;
console.log(greeting);  // '你好，我叫Alice，今年25岁'

// 多行
const html = `
  <div>
    <h1>${name}</h1>
    <p>年龄：${age}</p>
  </div>
`;

// 表达式
console.log(`2 + 3 = ${2 + 3}`);          // '2 + 3 = 5'
console.log(`${age >= 18 ? '成年' : '未成年'}`);  // '成年'

// 标签模板（高级用法）
function highlight(strings, ...values) {
  return strings.reduce((result, str, i) => 
    result + str + (values[i] ? `<b>${values[i]}</b>` : ''), '');
}
console.log(highlight`名字是${name}，年龄${age}`);
// '名字是<b>Alice</b>，年龄<b>25</b>'
```

**正则表达式基础：**

```javascript
// 创建正则
const re1 = /hello/gi;             // 字面量（推荐）
const re2 = new RegExp('hello', 'gi'); // 构造函数（动态模式时用）

// test：是否匹配
console.log(/hello/i.test('Hello World'));  // true

// exec：返回匹配详情
const match = /(\w+)@(\w+)\.(\w+)/.exec('联系我：alice@example.com');
console.log(match[0]);  // 'alice@example.com'（完整匹配）
console.log(match[1]);  // 'alice'（第一个分组）
console.log(match[2]);  // 'example'
console.log(match[3]);  // 'com'

// match / matchAll
console.log('a1b2c3'.match(/\d/g));  // ['1','2','3']
for (const m of 'a1b2c3'.matchAll(/\d/g)) {
  console.log(m[0], m.index);  // '1' 1 / '2' 3 / '3' 5
}

// replace 配合正则
const masked = '手机号：13812345678'.replace(/(\d{3})\d{4}(\d{4})/, '$1****$2');
console.log(masked);  // '手机号：138****5678'
```

**常见正则案例：**

```javascript
// 邮箱
const emailRe = /^[\w.-]+@[\w-]+\.[\w.-]+$/;
console.log(emailRe.test('alice@example.com'));  // true

// 中国手机号
const phoneRe = /^1[3-9]\d{9}$/;
console.log(phoneRe.test('13812345678'));  // true

// URL
const urlRe = /^https?:\/\/[\w.-]+(?:\/[\w./-]*)?$/;

// 提取所有数字
const nums = '价格 100 元，数量 5 个'.match(/\d+/g).map(Number);
console.log(nums);  // [100, 5]

// 驼峰转下划线
const toSnake = str => str.replace(/[A-Z]/g, m => '_' + m.toLowerCase());
console.log(toSnake('userName'));  // 'user_name'
console.log(toSnake('getHTTPResponse'));  // 'get_h_t_t_p_response'（注意局限性）
```

### 总结

- 字符串不可变，所有方法返回新字符串。
- 优先使用模板字符串进行拼接，可读性远胜 `+`。
- `slice` 比 `substring`/`substr` 更现代，`substr` 已废弃。
- `replaceAll`（ES2021）替代了 `replace` + `/g` 的全局替换场景。
- 正则表达式功能强大但学习曲线陡峭，建议掌握基础元字符和常用案例即可，复杂场景查文档。
- 正则字面量 `/pattern/` 用于固定模式，`new RegExp()` 用于动态构建模式。
- 处理 emoji 等辅助平面字符时，注意 UTF-16 代理对问题，必要时用 `[...str]` 按码点遍历。

# 第 4 章 面向对象编程

JavaScript 的面向对象机制与 Java、C++ 等基于类的语言截然不同——它基于**原型（Prototype）**而非类。虽然 ES6 引入了 `class` 关键字让语法看起来像传统 OOP，但其底层仍是原型链。理解原型是掌握 JS 高级特性的必经之路。本章将带你从原型链到 class 语法，再到继承与多态，完整理解 JS 的 OOP。

## 第 12 讲 原型与原型链

### 概念

**原型（Prototype）**是 JS 实现继承和共享方法的机制。每个对象都有一个内部属性 `[[Prototype]]`（可通过 `Object.getPrototypeOf()` 访问，或通过 `__proto__` 访问），指向另一个对象——它的原型。

**原型链（Prototype Chain）**是对象通过原型相互链接形成的链式结构。访问对象属性时，若对象自身没有，会沿原型链向上查找，直到找到或到达链尾（`null`）。

### 原理

JS 中"继承"的本质是**对象继承对象**，而非类继承类。原型链查找规则：

1. 访问 `obj.prop` 时，先在 `obj` 自身属性中查找。
2. 找不到则去 `obj.__proto__`（即 `obj` 的原型）上找。
3. 继续向上，直到 `Object.prototype.__proto__`（即 `null`）。
4. 全程找不到返回 `undefined`。

几个关键关系：

- 函数的 `prototype` 属性指向一个对象，该对象将成为由该函数创建的所有实例的原型。
- 实例的 `__proto__` 指向构造函数的 `prototype`。
- `Object.prototype` 是所有对象的根原型，其 `__proto__` 为 `null`。
- `Function.prototype` 是所有函数的原型。

### 例子

**原型链查找：**

```javascript
const obj = { name: 'Alice' };

// obj 自身没有 toString，但原型链上有
console.log(obj.toString());  // '[object Object]'
console.log(obj.hasOwnProperty('name'));  // true

// 原型链结构
console.log(obj.__proto__ === Object.prototype);           // true
console.log(Object.prototype.__proto__);                   // null（链尾）
console.log(Object.getPrototypeOf(obj) === Object.prototype); // true（推荐写法）
```

**函数的 prototype 与实例：**

```javascript
function Person(name) {
  this.name = name;
}

// 在原型上添加方法，所有实例共享
Person.prototype.greet = function() {
  return `Hi, I'm ${this.name}`;
};

const alice = new Person('Alice');
const bob = new Person('Bob');

console.log(alice.greet());  // 'Hi, I'm Alice'
console.log(bob.greet());    // 'Hi, I'm Bob'

// 实例共享同一个原型方法
console.log(alice.greet === bob.greet);  // true

// 原型链关系
console.log(alice.__proto__ === Person.prototype);              // true
console.log(Person.prototype.__proto__ === Object.prototype);  // true
console.log(alice.__proto__.__proto__ === Object.prototype);   // true
```

**原型链继承：**

```javascript
function Animal(name) {
  this.name = name;
}
Animal.prototype.eat = function() {
  console.log(`${this.name} 在吃东西`);
};

function Dog(name, breed) {
  Animal.call(this, name);  // 借用构造函数，继承实例属性
  this.breed = breed;
}

// 关键：让 Dog 的原型指向 Animal 的实例，实现方法继承
Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;  // 修复 constructor 指向

Dog.prototype.bark = function() {
  console.log(`${this.name} 汪汪叫`);
};

const dog = new Dog('旺财', '中华田园犬');
dog.eat();   // '旺财 在吃东西'（继承自 Animal）
dog.bark();  // '旺财 汪汪叫'

console.log(dog instanceof Dog);    // true
console.log(dog instanceof Animal); // true
```

**Object.create 与原型操作：**

```javascript
// Object.create(proto)：创建一个以 proto 为原型的新对象
const proto = { greet() { return 'hello'; } };
const obj = Object.create(proto);
console.log(obj.greet());  // 'hello'
console.log(Object.getPrototypeOf(obj) === proto);  // true

// 设置原型（ES6，性能差，不推荐在生产用）
const child = {};
Object.setPrototypeOf(child, proto);

// 原型上的属性会被实例"看到"，但 hasOwnProperty 返回 false
console.log(obj.hasOwnProperty('greet'));  // false
console.log('greet' in obj);               // true
```

### 总结

- 原型是 JS 实现继承的机制，每个对象都有原型（`[[Prototype]]`）。
- 原型链是属性查找的路径，从对象自身到 `Object.prototype` 再到 `null`。
- 函数有 `prototype` 属性，由它创建的实例的原型（`__proto__`）指向它。
- 原型链继承的经典模式：`Child.prototype = Object.create(Parent.prototype)`，并修复 `constructor`。
- `__proto__` 是非标准但广泛支持的属性，标准写法是 `Object.getPrototypeOf()` / `Object.setPrototypeOf()`。
- 所有方法定义在原型上而非构造函数内，这样实例共享同一份方法，节省内存。
- 现代开发推荐使用 `class` 语法（下一讲），但其底层仍是原型链。

## 第 13 讲 构造函数与 `class` 语法

### 概念

**构造函数**是用 `new` 调用、用于创建和初始化对象的函数。约定首字母大写。

**`class` 语法**是 ES6 引入的面向对象语法糖，底层仍是基于原型的继承机制，但提供了更清晰、更接近传统 OOP 语言的写法。

### 原理

`new` 操作符执行以下四步：

1. 创建一个空对象。
2. 将该对象的原型指向构造函数的 `prototype`。
3. 将构造函数的 `this` 绑定到新对象并执行。
4. 如果构造函数返回对象则用该对象，否则返回新对象。

`class` 语法本质上就是构造函数 + 原型方法的语法糖：

- `constructor` 方法对应构造函数体。
- 类中定义的方法自动添加到 `prototype` 上。
- `static` 方法定义在类本身上而非原型上。
- `extends` 实现继承，`super` 调用父类。
- 类**没有变量提升**，必须先声明后使用。
- 类体默认运行在严格模式下。

ES2022 引入了**私有字段** `#field`，真正实现了封装。

### 例子

**构造函数 vs class：**

```javascript
// 传统构造函数写法
function PersonES5(name, age) {
  this.name = name;
  this.age = age;
}
PersonES5.prototype.greet = function() {
  return `Hi, I'm ${this.name}`;
};
PersonES5.create = function(name) {  // 静态方法
  return new PersonES5(name, 0);
};

// ES6 class 写法（等价）
class PersonES6 {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
  
  greet() {  // 自动加到原型上
    return `Hi, I'm ${this.name}`;
  }
  
  static create(name) {  // 静态方法
    return new PersonES6(name, 0);
  }
}

const p1 = new PersonES5('Alice', 25);
const p2 = new PersonES6('Alice', 25);
console.log(p1.greet(), p2.greet());  // 都是 "Hi, I'm Alice"
console.log(typeof PersonES6);  // 'function'（class 本质是函数）
```

**私有字段与访问器：**

```javascript
class BankAccount {
  #balance;  // 私有字段（ES2022）
  
  constructor(owner, initialBalance = 0) {
    this.owner = owner;        // 公有字段
    this.#balance = initialBalance;
  }
  
  // getter
  get balance() {
    return this.#balance;
  }
  
  // setter
  set balance(amount) {
    if (amount < 0) throw new Error('余额不能为负');
    this.#balance = amount;
  }
  
  deposit(amount) {
    if (amount <= 0) throw new Error('存款必须为正');
    this.#balance += amount;
    return this.#balance;
  }
  
  withdraw(amount) {
    if (amount > this.#balance) throw new Error('余额不足');
    this.#balance -= amount;
    return this.#balance;
  }
  
  // 私有方法（ES2022）
  #log(message) {
    console.log(`[${this.owner}] ${message}`);
  }
}

const acc = new BankAccount('Alice', 100);
console.log(acc.balance);   // 100（通过 getter 访问）
acc.deposit(50);
console.log(acc.balance);   // 150
acc.balance = 200;          // 通过 setter 修改
// acc.#balance;            // 语法错误：私有字段外部不可访问
// acc.balance = -100;      // 报错：余额不能为负
```

**静态成员与字段简写：**

```javascript
class Counter {
  static instanceCount = 0;  // 静态字段
  count = 0;                 // 实例字段（ES2022，可省略 constructor）
  
  constructor() {
    Counter.instanceCount++;
  }
  
  increment() {
    this.count++;
    return this.count;
  }
  
  static getTotalInstances() {
    return Counter.instanceCount;
  }
}

new Counter(); new Counter(); new Counter();
console.log(Counter.instanceCount);  // 3
console.log(Counter.getTotalInstances());  // 3
```

### 总结

- `class` 是构造函数 + 原型方法的语法糖，本质仍是基于原型的继承。
- `new` 做四件事：创建对象、设置原型、绑定 this、返回对象。
- 类没有变量提升，必须先声明后使用；类体默认严格模式。
- 私有字段 `#field`（ES2022）实现了真正的封装，外部无法访问。
- `get`/`set` 访问器让属性访问像字段一样自然，同时可加入校验逻辑。
- 静态成员属于类本身而非实例，常用于工厂方法、计数器、工具函数。
- 实例字段可直接在类体声明（ES2022），不必都写在 constructor 里。

## 第 14 讲 继承与多态

### 概念

**继承（Inheritance）**是子类获得父类属性和方法的能力。**多态（Polymorphism）**是同一方法在不同子类中表现出不同行为。JS 通过 `extends` 和 `super` 实现继承，通过方法重写实现多态。

### 原理

`class extends` 的底层做了两件事：

1. `Child.prototype` 的原型设为 `Parent.prototype`（`Object.setPrototypeOf(Child.prototype, Parent.prototype)`）。
2. `Child` 本身的原型设为 `Parent`（`Object.setPrototypeOf(Child, Parent)`），使子类能继承父类的静态方法。

`super` 有两种用法：

- **作为函数** `super(...)`：在子类 `constructor` 中调用父类构造函数，必须在使用 `this` 之前调用。
- **作为对象** `super.method()`：调用父类的方法，`this` 仍绑定到子类实例。

多态通过**方法重写（Override）**实现：子类定义与父类同名的方法，调用时根据对象的实际类型决定执行哪个版本。JS 是动态语言，多态天然支持，无需声明。

### 例子

**基本继承：**

```javascript
class Animal {
  constructor(name) {
    this.name = name;
  }
  
  speak() {
    return `${this.name} 发出声音`;
  }
  
  static create(name) {
    return new this(name);  // 注意 this 指向调用类
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);       // 必须先调用 super，才能使用 this
    this.breed = breed;
  }
  
  speak() {            // 方法重写，实现多态
    return `${this.name} 汪汪叫`;
  }
  
  fetch() {            // 子类特有方法
    return `${this.name} 在捡球`;
  }
}

class Cat extends Animal {
  speak() {
    return `${this.name} 喵喵叫`;
  }
}

const dog = new Dog('旺财', '田园犬');
const cat = new Cat('咪咪');

console.log(dog.speak());  // '旺财 汪汪叫'（多态）
console.log(cat.speak());  // '咪咪 喵喵叫'（多态）
console.log(dog.fetch());  // '旺财 在捡球'

// 继承静态方法
const newDog = Dog.create('小黑');
console.log(newDog instanceof Dog);  // true
```

**多态的经典应用：**

```javascript
class Shape {
  area() {
    return 0;
  }
  describe() {
    return `形状面积：${this.area()}`;
  }
}

class Circle extends Shape {
  constructor(radius) {
    super();
    this.radius = radius;
  }
  area() {
    return Math.PI * this.radius ** 2;
  }
}

class Rectangle extends Shape {
  constructor(width, height) {
    super();
    this.width = width;
    this.height = height;
  }
  area() {
    return this.width * this.height;
  }
}

class Triangle extends Shape {
  constructor(base, height) {
    super();
    this.base = base;
    this.height = height;
  }
  area() {
    return 0.5 * this.base * this.height;
  }
}

// 多态：同一接口，不同行为
const shapes = [new Circle(5), new Rectangle(4, 6), new Triangle(3, 8)];
shapes.forEach(s => console.log(s.describe()));
// 形状面积：78.53981633974483
// 形状面积：24
// 形状面积：12
```

**super 调用父类方法：**

```javascript
class Logger {
  log(message) {
    console.log(`[LOG] ${message}`);
  }
}

class TimestampLogger extends Logger {
  log(message) {
    const time = new Date().toISOString();
    super.log(`[${time}] ${message}`);  // 调用父类 log
  }
}

class ErrorLogger extends TimestampLogger {
  log(message) {
    super.log(`ERROR: ${message}`);  // 链式调用，会经过 TimestampLogger
  }
}

new ErrorLogger().log('系统崩溃');
// 输出：[LOG] [2024-...] ERROR: 系统崩溃
```

**Mixin 模式（多重继承替代）：**

```javascript
// JS 不支持多重继承，但可用 Mixin 模式组合多个能力
const Serializable = {
  serialize() {
    return JSON.stringify(this);
  },
  staticDeserialize(json) {
    return JSON.parse(json);
  }
};

const Comparable = {
  equals(other) {
    return JSON.stringify(this) === JSON.stringify(other);
  }
};

class User {}
// 将 Mixin 的方法复制到原型上
Object.assign(User.prototype, Serializable, Comparable);

const u1 = new User();
u1.name = 'Alice';
console.log(u1.serialize());  // '{"name":"Alice"}'
```

### 总结

- `extends` 实现继承，`super` 调用父类构造函数和方法。
- 子类 `constructor` 中必须先调用 `super()` 才能使用 `this`。
- 多态通过方法重写实现，调用时根据对象实际类型决定执行版本。
- `super.method()` 中的 `this` 仍指向子类实例，便于扩展而非替换父类行为。
- 静态方法也会被继承，`static create` 中用 `new this()` 可实现工厂模式的多态。
- JS 不支持多重继承，需要组合多个能力时使用 Mixin 模式（`Object.assign` 到原型）。
- 继承层次不宜过深（建议不超过 3 层），否则维护困难，优先考虑组合而非继承。

# 第 5 章 异步编程

异步编程是 JavaScript 的核心难点之一，也是真实业务中无处不在的场景——网络请求、定时器、文件读写、用户交互都涉及异步。本章将带你完整走过 JS 异步编程的演进历程：从回调函数到 Promise，再到 async/await，最后掌握并发控制技巧。理解事件循环是掌握异步的前提，我们会从底层机制讲起。

## 第 15 讲 事件循环与回调函数

### 概念

**事件循环（Event Loop）**是 JS 单线程模型下处理异步任务的机制。它持续检查调用栈和任务队列，当调用栈为空时，将队列中的任务推入执行。

**回调函数（Callback）**是作为参数传递给另一个函数、在未来某个时机被调用的函数，是 JS 最原始的异步编程方式。

### 原理

JS 是**单线程**语言，意味着同一时刻只能执行一段代码。为了避免耗时操作（如网络请求）阻塞主线程，JS 采用**事件循环**模型：

1. 同步代码在**调用栈（Call Stack）**中执行。
2. 异步操作交给浏览器/Web API 处理（如定时器、网络请求）。
3. 异步操作完成后，其回调被推入**任务队列（Task Queue）**。
4. 事件循环不断检查：调用栈为空时，从队列取出任务执行。

任务队列分两种：

- **宏任务（Macrotask）**：`setTimeout`、`setInterval`、I/O、UI 渲染、`setImmediate`（Node）。
- **微任务（Microtask）**：`Promise.then`、`MutationObserver`、`queueMicrotask`。

执行顺序：**同步代码 → 微任务队列清空 → 一个宏任务 → 微任务队列清空 → 一个宏任务 → ...**。微任务优先级高于宏任务，且每次宏任务后都会清空所有微任务。

### 例子

**回调函数基础：**

```javascript
// 同步函数
function syncAdd(a, b) {
  return a + b;
}
console.log(syncAdd(1, 2));  // 3

// 异步函数：setTimeout 接收回调
console.log('开始');
setTimeout(() => {
  console.log('1 秒后执行');
}, 1000);
console.log('结束');
// 输出顺序：开始 → 结束 → （1秒后）1 秒后执行
```

**事件循环演示：**

```javascript
console.log('1. 同步开始');

setTimeout(() => {
  console.log('2. 宏任务 setTimeout');
}, 0);

Promise.resolve().then(() => {
  console.log('3. 微任务 Promise');
});

console.log('4. 同步结束');

// 输出顺序：
// 1. 同步开始
// 4. 同步结束
// 3. 微任务 Promise    ← 微任务先于宏任务
// 2. 宏任务 setTimeout
```

**回调地狱（Callback Hell）：**

```javascript
// 模拟依次请求用户 → 订单 → 商品详情
function getUser(userId, callback) {
  setTimeout(() => callback({ id: userId, name: 'Alice' }), 100);
}

function getOrders(userId, callback) {
  setTimeout(() => callback([{ id: 1, productId: 101 }]), 100);
}

function getProduct(productId, callback) {
  setTimeout(() => callback({ id: productId, name: '手机' }), 100);
}

// 嵌套回调，可读性极差
getUser(1, (user) => {
  getOrders(user.id, (orders) => {
    getProduct(orders[0].productId, (product) => {
      console.log(`${user.name} 购买了 ${product.name}`);
      // 如果还有后续请求，继续嵌套...
    });
  });
});
```

**错误优先回调（Node.js 风格）：**

```javascript
// Node.js 约定：回调第一个参数是错误对象，null 表示无错误
function readConfig(callback) {
  setTimeout(() => {
    if (Math.random() > 0.5) {
      callback(null, { theme: 'dark' });  // 成功
    } else {
      callback(new Error('读取失败'));      // 失败
    }
  }, 100);
}

readConfig((err, config) => {
  if (err) {
    console.error('出错：', err.message);
    return;
  }
  console.log('配置：', config);
});
```

### 总结

- JS 单线程，通过事件循环处理异步，避免阻塞主线程。
- 任务分宏任务和微任务，微任务优先级更高，每次宏任务后清空所有微任务。
- 回调是 JS 最早的异步方案，但嵌套多了会形成"回调地狱"，难以维护。
- Node.js 采用"错误优先回调"约定，第一个参数是 error。
- 理解事件循环是面试高频考点，记住执行顺序：同步 → 微任务 → 宏任务。
- 现代开发已很少直接用回调，Promise 和 async/await 是更好的选择（后续两讲）。

## 第 16 讲 Promise 详解

### 概念

**Promise** 是 ES6 引入的异步编程解决方案，代表一个**未来才会确定结果**的值。它有三种状态：

- **pending（待定）**：初始状态，既未成功也未失败。
- **fulfilled（已兑现）**：操作成功完成。
- **rejected（已拒绝）**：操作失败。

状态一旦从 pending 变为 fulfilled 或 rejected，就**不可逆**，称为"已敲定（settled）"。

### 原理

Promise 通过**链式调用**解决回调地狱问题。每个 `.then()` 返回一个新的 Promise，使异步操作可以线性串联：

- `promise.then(onFulfilled, onRejected)`：注册成功和失败回调。
- `promise.catch(onRejected)`：等价于 `.then(null, onRejected)`，捕获错误。
- `promise.finally(onFinally)`：无论成功失败都执行（ES2018）。

Promise 的核心静态方法：

- `Promise.resolve(value)`：返回一个已兑现的 Promise。
- `Promise.reject(reason)`：返回一个已拒绝的 Promise。
- `Promise.all(iterable)`：所有都成功才成功，任一失败即失败。
- `Promise.allSettled(iterable)`：等待所有完成，无论成功失败（ES2020）。
- `Promise.race(iterable)`：第一个敲定的决定结果。
- `Promise.any(iterable)`：第一个成功的决定结果，全失败才失败（ES2021）。

### 例子

**基本用法：**

```javascript
// 创建 Promise
const promise = new Promise((resolve, reject) => {
  const success = Math.random() > 0.5;
  setTimeout(() => {
    if (success) {
      resolve('操作成功');  // 将状态改为 fulfilled
    } else {
      reject(new Error('操作失败'));  // 将状态改为 rejected
    }
  }, 500);
});

// 消费 Promise
promise
  .then(result => {
    console.log('成功：', result);
  })
  .catch(error => {
    console.error('失败：', error.message);
  })
  .finally(() => {
    console.log('无论成功失败都执行');
  });
```

**链式调用解决回调地狱：**

```javascript
// 把上一讲的回调地狱改写为 Promise
function getUser(userId) {
  return new Promise(resolve => {
    setTimeout(() => resolve({ id: userId, name: 'Alice' }), 100);
  });
}

function getOrders(userId) {
  return new Promise(resolve => {
    setTimeout(() => resolve([{ id: 1, productId: 101 }]), 100);
  });
}

function getProduct(productId) {
  return new Promise(resolve => {
    setTimeout(() => resolve({ id: productId, name: '手机' }), 100);
  });
}

// 链式调用，扁平化结构
getUser(1)
  .then(user => {
    return getOrders(user.id).then(orders => ({ user, orders }));
  })
  .then(({ user, orders }) => {
    return getProduct(orders[0].productId).then(product => ({ user, product }));
  })
  .then(({ user, product }) => {
    console.log(`${user.name} 购买了 ${product.name}`);
  })
  .catch(err => {
    console.error('任一步出错都会到这里：', err);
  });
```

**Promise.all 并发：**

```javascript
// 同时请求多个接口，全部完成才继续
const p1 = fetch('/api/user').then(r => r.json());
const p2 = fetch('/api/orders').then(r => r.json());
const p3 = fetch('/api/products').then(r => r.json());

Promise.all([p1, p2, p3])
  .then(([user, orders, products]) => {
    console.log('全部完成：', user, orders, products);
  })
  .catch(err => {
    console.error('任一失败：', err);
  });

// Promise.allSettled：即使部分失败也要全部结果
Promise.allSettled([p1, p2, p3]).then(results => {
  results.forEach(r => {
    if (r.status === 'fulfilled') {
      console.log('成功：', r.value);
    } else {
      console.log('失败：', r.reason);
    }
  });
});
```

**Promise.race 与超时控制：**

```javascript
// 实现请求超时
function fetchWithTimeout(url, timeout = 5000) {
  const fetchPromise = fetch(url);
  const timeoutPromise = new Promise((_, reject) => {
    setTimeout(() => reject(new Error('请求超时')), timeout);
  });
  return Promise.race([fetchPromise, timeoutPromise]);
}

fetchWithTimeout('/api/data', 3000)
  .then(r => r.json())
  .then(data => console.log(data))
  .catch(err => console.error(err.message));  // 可能输出"请求超时"
```

**Promise 链中的错误处理与传递：**

```javascript
// 错误会沿链向下传递，直到遇到 catch
Promise.resolve()
  .then(() => { throw new Error('第一步出错'); })
  .then(() => console.log('不会执行'))  // 跳过
  .then(() => console.log('也不会执行'))
  .catch(err => console.log('捕获：', err.message))  // 捕获：第一步出错
  .then(() => console.log('catch 后继续'));  // 会执行，因为 catch 已处理错误

// 注意：catch 后再 then，错误已被"消化"
```

### 总结

- Promise 有三种状态：pending、fulfilled、rejected，状态变化不可逆。
- `.then` 返回新 Promise，实现链式调用，解决回调地狱。
- 错误沿链向下传递，直到被 `.catch` 捕获；catch 后的 then 仍会执行。
- `Promise.all` 适合"全部成功"场景，`allSettled` 适合"全部完成不管成败"。
- `Promise.race` 实现超时控制，`Promise.any` 取第一个成功结果。
- Promise 一旦创建就会立即执行，不是"调用 then 才执行"。
- Promise 链中返回普通值会包成 `Promise.resolve(value)`，返回 Promise 则等其敲定。

## 第 17 讲 async/await

### 概念

**async/await** 是 ES2017 引入的异步语法糖，让异步代码看起来像同步代码。`async` 声明异步函数，`await` 等待 Promise 敲定。它本质上是 Promise 的语法糖，但极大提升了可读性。

### 原理

`async` 函数**总是返回一个 Promise**：

- 返回普通值 → 包成 `Promise.resolve(value)`。
- 返回 Promise → 直接返回该 Promise。
- 抛出异常 → 包成 `Promise.reject(error)`。

`await` 会**暂停** async 函数的执行，等待 Promise 敲定：

- Promise 兑现 → 返回兑现值。
- Promise 拒绝 → 抛出异常，可用 try/catch 捕获。

注意：`await` 只能在 `async` 函数内使用（顶层 await 是 ES2022 才支持的模块特性）。`await` 暂停的是 async 函数本身，不会阻塞主线程，事件循环照常工作。

### 例子

**基本用法：**

```javascript
// 把上一讲的 Promise 链改写为 async/await
function getUser(userId) {
  return new Promise(resolve => {
    setTimeout(() => resolve({ id: userId, name: 'Alice' }), 100);
  });
}

function getOrders(userId) {
  return new Promise(resolve => {
    setTimeout(() => resolve([{ id: 1, productId: 101 }]), 100);
  });
}

function getProduct(productId) {
  return new Promise(resolve => {
    setTimeout(() => resolve({ id: productId, name: '手机' }), 100);
  });
}

// async/await 写法，像同步代码一样清晰
async function fetchPurchaseInfo(userId) {
  const user = await getUser(userId);
  const orders = await getOrders(user.id);
  const product = await getProduct(orders[0].productId);
  return `${user.name} 购买了 ${product.name}`;
}

fetchPurchaseInfo(1).then(msg => console.log(msg));
// 'Alice 购买了 手机'
```

**错误处理：**

```javascript
async function fetchData(url) {
  try {
    const response = await fetch(url);
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }
    const data = await response.json();
    return data;
  } catch (error) {
    console.error('请求失败：', error.message);
    return null;  // 返回默认值，让调用方继续处理
  }
}

// 也可以在调用方 catch
async function main() {
  const data = await fetchData('/api/user');
  if (data) {
    console.log('用户：', data);
  }
}
```

**并发请求（重点）：**

```javascript
// ❌ 错误：串行 await，3 个请求共耗时 3 秒
async function slowFetch() {
  const a = await fetch('/api/a');  // 1 秒
  const b = await fetch('/api/b');  // 1 秒
  const c = await fetch('/api/c');  // 1 秒
  return [a, b, c];
}

// ✅ 正确：用 Promise.all 并发，总耗时约 1 秒
async function fastFetch() {
  const [a, b, c] = await Promise.all([
    fetch('/api/a'),
    fetch('/api/b'),
    fetch('/api/c')
  ]);
  return [a, b, c];
}

// 部分依赖时：先并发无依赖的，再 await 依赖项
async function mixedFetch() {
  const [user, config] = await Promise.all([
    fetch('/api/user').then(r => r.json()),
    fetch('/api/config').then(r => r.json())
  ]);
  // user 和 config 并发，orders 依赖 user.id
  const orders = await fetch(`/api/orders?userId=${user.id}`).then(r => r.json());
  return { user, config, orders };
}
```

**循环中的 await：**

```javascript
// 串行处理：依次 await
async function processSequentially(urls) {
  const results = [];
  for (const url of urls) {
    const data = await fetch(url).then(r => r.json());
    results.push(data);
  }
  return results;
}

// 并发处理：全部同时发起
async function processConcurrently(urls) {
  const promises = urls.map(url => fetch(url).then(r => r.json()));
  return Promise.all(promises);
}

// 限制并发数（见下一讲详解）
async function processWithLimit(urls, limit = 3) {
  const results = [];
  for (let i = 0; i < urls.length; i += limit) {
    const batch = urls.slice(i, i + limit);
    const batchResults = await Promise.all(
      batch.map(url => fetch(url).then(r => r.json()))
    );
    results.push(...batchResults);
  }
  return results;
}
```

### 总结

- `async` 函数总是返回 Promise，`await` 暂停函数等待 Promise 敲定。
- async/await 是 Promise 的语法糖，本质相同，但代码更接近同步风格。
- 错误用 `try/catch` 捕获，比 `.catch()` 更直观。
- **关键陷阱**：多个独立请求不要串行 `await`，用 `Promise.all` 并发。
- `await` 只能在 async 函数内（模块顶层 await 是 ES2022 特性）。
- 循环中 `for...of + await` 是串行，`map + Promise.all` 是并发，按需选择。
- async/await 不会阻塞主线程，它只是"暂停"当前 async 函数的执行。

## 第 18 讲 异步并发控制

### 概念

**并发控制**是管理多个异步任务执行节奏的技术。当任务数量庞大时（如批量请求 1000 个 URL），直接 `Promise.all` 会同时发起所有请求，可能压垮服务器或触发限流。并发控制通过限制"同时进行"的任务数，在效率和稳定性之间取得平衡。

### 原理

并发控制的核心思路是**维护一个固定大小的"执行池"**：

1. 初始时启动 N 个任务（N 为并发数）。
2. 每当有任务完成，立即从等待队列取下一个任务启动。
3. 直到所有任务完成。

实现方式有两种：

- **递归 + 计数**：手动管理活跃任务数。
- **Promise 池**：利用 `Promise.race` 监听最先完成的任务，再补充新任务。

ES2024 引入了 `Promise.withResolvers()`，让手动控制 Promise 的 resolve/reject 更方便，常用于并发控制实现。

### 例子

**简单并发限制（分批处理）：**

```javascript
// 最简单的并发控制：分批，每批 N 个
async function batchProcess(items, batchSize, asyncFn) {
  const results = [];
  for (let i = 0; i < items.length; i += batchSize) {
    const batch = items.slice(i, i + batchSize);
    const batchResults = await Promise.all(batch.map(asyncFn));
    results.push(...batchResults);
  }
  return results;
}

// 示例：每次并发 3 个请求
const urls = Array.from({ length: 10 }, (_, i) => `/api/item/${i}`);
const results = await batchProcess(urls, 3, url => 
  fetch(url).then(r => r.json())
);
```

**动态并发池（推荐）：**

```javascript
// 经典并发池实现：始终保持 N 个任务在执行
async function asyncPool(limit, items, iteratorFn) {
  const results = [];      // 所有结果
  const executing = [];    // 正在执行的 Promise
  
  for (const item of items) {
    // 创建任务 Promise
    const p = Promise.resolve().then(() => iteratorFn(item));
    results.push(p);
    
    // 当任务数达到上限，等待其中一个完成
    if (items.length >= limit) {
      const e = p.then(() => executing.splice(executing.indexOf(e), 1));
      executing.push(e);
      if (executing.length >= limit) {
        await Promise.race(executing);
      }
    }
  }
  
  return Promise.all(results);
}

// 使用示例
const urls = Array.from({ length: 20 }, (_, i) => `https://api.example.com/${i}`);
const data = await asyncPool(5, urls, async (url) => {
  const res = await fetch(url);
  return res.json();
});
console.log(`完成 ${data.length} 个请求`);
```

**带重试的并发请求：**

```javascript
// 单个请求带重试
async function fetchWithRetry(url, retries = 3, delay = 1000) {
  for (let i = 0; i < retries; i++) {
    try {
      const res = await fetch(url);
      if (!res.ok) throw new Error(`HTTP ${res.status}`);
      return await res.json();
    } catch (err) {
      if (i === retries - 1) throw err;
      console.log(`第 ${i + 1} 次失败，${delay}ms 后重试：${err.message}`);
      await new Promise(r => setTimeout(r, delay));
      delay *= 2;  // 指数退避
    }
  }
}

// 配合并发池使用
const urls = ['/api/a', '/api/b', '/api/c'];
const results = await asyncPool(2, urls, url => fetchWithRetry(url, 3));
```

**进度跟踪：**

```javascript
// 带进度的并发处理
async function processWithProgress(items, limit, asyncFn, onProgress) {
  let completed = 0;
  const total = items.length;
  
  await asyncPool(limit, items, async (item) => {
    const result = await asyncFn(item);
    completed++;
    onProgress(completed, total, result);
    return result;
  });
}

// 使用
await processWithProgress(
  urls,
  5,
  url => fetch(url).then(r => r.text()),
  (done, total) => {
    console.log(`进度：${done}/${total} (${(done / total * 100).toFixed(1)}%)`);
  }
);
```

### 总结

- 批量异步任务不要无脑 `Promise.all`，可能压垮服务或触发限流。
- 简单场景用"分批处理"，复杂场景用"动态并发池"保持固定并发数。
- 网络请求应配合重试机制，指数退避避免雪崩。
- 并发数选择：一般 3-10 比较合理，根据服务器承受能力和网络状况调整。
- 进度跟踪让用户感知任务进展，提升体验。
- 生产环境推荐使用成熟库：`p-limit`、`p-queue`、`async` 等，避免重复造轮子。

本章涵盖 JavaScript 中较为高级的语言特性：模块化系统、错误处理与调试技巧、Symbol/迭代器/生成器。这些特性在日常开发中虽不如前几章频繁，但理解它们能让你写出更健壮、更优雅的代码，也是阅读现代框架源码的基础。

## 第 19 讲 模块化（ES Modules）

### 概念

**模块化**是将程序拆分为独立、可复用模块的机制。**ES Modules（ESM）**是 ES6 引入的官方模块系统，使用 `import` 和 `export` 语法，是现代 JavaScript 的标准模块方案。

### 原理

在 ES Modules 之前，JS 社区发展出多种模块方案：

- **CommonJS**（Node.js）：`require` / `module.exports`，同步加载。
- **AMD**（浏览器）：`define` / `require`，异步加载，代表库 RequireJS。
- **UMD**：兼容 CommonJS 和 AMD 的通用方案。

ES Modules 与它们的本质区别：

- **静态结构**：`import`/`export` 必须在顶层，模块依赖在编译时确定，便于 Tree Shaking（死代码消除）。
- **严格模式**：ESM 默认运行在严格模式，无需 `'use strict'`。
- **`this` 是 `undefined`**：模块顶层 `this` 不再指向全局对象。
- **异步加载**：浏览器中通过 `<script type="module">` 加载，默认 `defer`。
- **导出的是引用**：导入的值是导出变量的**实时引用**，而非副本（CommonJS 是值拷贝）。

### 例子

**导出（export）：**

```javascript
// math.js

// 命名导出：逐个导出
export const PI = 3.14159;
export function add(a, b) {
  return a + b;
}
export class Calculator {
  // ...
}

// 命名导出：统一导出（推荐，便于管理）
const subtract = (a, b) => a - b;
const multiply = (a, b) => a * b;
export { subtract, multiply };

// 重命名导出
export { subtract as minus };

// 默认导出：每个模块只能有一个默认导出
export default function square(x) {
  return x * x;
}
```

**导入（import）：**

```javascript
// main.js

// 导入命名导出
import { PI, add } from './math.js';
console.log(add(PI, 1));  // 4.14159

// 导入默认导出（无需花括号，可任意命名）
import square from './math.js';
console.log(square(5));  // 25

// 同时导入默认和命名
import squareFn, { PI, add } from './math.js';

// 重命名导入
import { subtract as sub } from './math.js';

// 导入整个模块（命名空间导入）
import * as math from './math.js';
console.log(math.PI, math.add(1, 2));

// 动态导入（返回 Promise，按需加载）
const module = await import('./math.js');
console.log(module.default(5));  // 25

// 副作用导入：仅执行模块，不导入任何绑定
import './polyfill.js';
```

**实时引用特性：**

```javascript
// counter.js
export let count = 0;
export function increment() {
  count++;
}

// main.js
import { count, increment } from './counter.js';
console.log(count);  // 0
increment();
console.log(count);  // 1（引用更新，不是拷贝）

// 注意：导入的变量是只读的
// count = 10;  // TypeError: Assignment to constant variable
```

**浏览器与 Node.js 中使用：**

```html
<!-- 浏览器：type="module" -->
<script type="module">
  import { add } from './math.js';
  console.log(add(1, 2));
</script>

<!-- 动态导入 -->
<script type="module">
  document.getElementById('btn').addEventListener('click', async () => {
    const { add } = await import('./math.js');
    console.log(add(1, 2));
  });
</script>
```

```javascript
// Node.js：package.json 中设置 "type": "module"
// 或使用 .mjs 扩展名
import { readFile } from 'node:fs/promises';
const data = await readFile('./data.txt', 'utf-8');
console.log(data);
```

### 总结

- ES Modules 是 JS 官方模块系统，使用 `import`/`export`，静态结构支持 Tree Shaking。
- 命名导出可多个，默认导出每模块一个；导入时命名导出需花括号，默认导出不需要。
- ESM 导出的是**实时引用**，CommonJS 是值拷贝，这是两者关键区别。
- 动态 `import()` 返回 Promise，用于按需加载、路由懒加载、减少首屏体积。
- 浏览器用 `<script type="module">`，Node.js 用 `.mjs` 或 `package.json` 的 `"type": "module"`。
- 现代项目优先使用 ESM，CommonJS 主要在旧 Node 项目中维护。

## 第 20 讲 错误处理与调试

### 概念

**错误处理**是编写健壮程序的关键。JS 通过 `try/catch/finally` 捕获同步错误，通过 Promise 的 `.catch()` 或 async/await 的 `try/catch` 捕获异步错误。**调试**是定位和修复错误的过程，浏览器 DevTools 和 Node.js 调试器是主要工具。

### 原理

JS 的错误分为几类：

- **SyntaxError**：语法错误，代码无法解析，如漏写括号。
- **ReferenceError**：引用未定义变量。
- **TypeError**：类型错误，如调用 `undefined` 的方法。
- **RangeError**：值越界，如无限递归导致栈溢出。
- **自定义错误**：继承 `Error` 创建。

`throw` 可以抛出任意值，但建议抛出 `Error` 实例，便于堆栈追踪。`try/catch` 只能捕获同步错误，异步错误需在回调/Promise 中处理。

错误处理的最佳实践：

- 只捕获你能处理的错误，不要"吞掉"异常。
- 捕获后要么处理、要么重新抛出、要么记录日志。
- 在合适层级统一处理（如全局错误处理器）。
- 提供有意义的错误信息，便于排查。

### 例子

**try/catch/finally：**

```javascript
function divide(a, b) {
  if (b === 0) {
    throw new Error('除数不能为零');
  }
  return a / b;
}

try {
  const result = divide(10, 0);
  console.log(result);
} catch (error) {
  console.error('捕获错误：', error.message);  // '除数不能为零'
} finally {
  console.log('无论是否出错都执行');  // 常用于资源清理
}
```

**自定义错误：**

```javascript
// 自定义错误类
class ValidationError extends Error {
  constructor(field, message) {
    super(message);
    this.name = 'ValidationError';
    this.field = field;
  }
}

class NetworkError extends Error {
  constructor(url, status) {
    super(`请求 ${url} 失败，状态码 ${status}`);
    this.name = 'NetworkError';
    this.url = url;
    this.status = status;
  }
}

// 使用
function validateUser(user) {
  if (!user.name) {
    throw new ValidationError('name', '用户名不能为空');
  }
  if (user.age < 0) {
    throw new ValidationError('age', '年龄不能为负');
  }
}

try {
  validateUser({ name: '', age: -1 });
} catch (err) {
  if (err instanceof ValidationError) {
    console.error(`字段 ${err.field} 校验失败：${err.message}`);
  } else {
    throw err;  // 重新抛出未知错误
  }
}
```

**异步错误处理：**

```javascript
// Promise 错误
fetch('/api/data')
  .then(r => r.json())
  .catch(err => console.error('请求失败：', err));

// async/await 错误
async function fetchData() {
  try {
    const r = await fetch('/api/data');
    return await r.json();
  } catch (err) {
    console.error('失败：', err);
    throw err;  // 重新抛出，让调用方处理
  }
}

// 全局未捕获 Promise 错误
window.addEventListener('unhandledrejection', event => {
  console.error('未处理的 Promise 拒绝：', event.reason);
  event.preventDefault();
});
```

**调试技巧：**

```javascript

console.warn('警告');
console.info('信息');

console.time('耗时'); /* ... */ console.timeEnd('耗时');

// 2. 断点调试

  debugger;  // 代码执行到这里会暂停（DevTools 打开时）
  return n * 2;
}

// 3. 堆栈追踪

  console.log(new Error().stack);  // 打印调用栈
  // 或 console.trace()

// 在 Sources 面板点行号设断点，右键可设条件，如 i === 50
```

**错误边界（前端模式）：**

```javascript
// 统一的 API 请求封装
async function request(url, options) {
  try {
    const res = await fetch(url, options);
    if (!res.ok) {
      throw new NetworkError(url, res.status);
    }
    return await res.json();
  } catch (err) {
    // 统一上报
    reportError(err);
    // 转换为用户友好提示
    if (err instanceof NetworkError) {
      throw new Error('网络异常，请稍后重试');
    }
    throw err;
  }
}

// 全局错误捕获

  console.error('全局错误：', msg, error);

};
```

### 总结

- `try/catch` 只捕获同步错误，异步错误用 Promise `.catch` 或 async/await 的 `try/catch`。
- 自定义错误继承 `Error`，用 `instanceof` 区分错误类型，便于针对性处理。
- 捕获错误后要么处理、要么重抛、要么记录，不要静默吞掉。
- `finally` 块用于资源清理，无论是否出错都执行。
- `debugger` 语句配合 DevTools 是断点调试的利器。
- 生产环境应有全局错误处理器，统一上报和提示，避免白屏。
- `console.table`、`console.time`、`console.group` 等方法让调试输出更清晰。

## 第 21 讲 Symbol、迭代器与生成器

### 概念

**Symbol** 是 ES6 引入的第七种原始类型，表示唯一且不可变的数据，常用于定义对象的"私有"属性或内置行为。

**迭代器（Iterator）**是一种协议，任何对象实现 `next()` 方法并返回 `{value, done}` 就成为迭代器，可被 `for...of` 遍历。

**生成器（Generator）**是用 `function*` 定义的特殊函数，可通过 `yield` 暂停执行，是创建迭代器的便捷方式。

### 原理

**Symbol 的核心特性是唯一性**：`Symbol() === Symbol()` 永远为 `false`。即使描述相同，也是不同的 Symbol。Symbol 作为对象属性键时，不会出现在 `for...in`、`Object.keys()` 中，具有一定"隐藏"性（但可用 `Object.getOwnPropertySymbols()` 获取）。

JS 内置了一批**知名 Symbol**，用于自定义对象的内置行为：

- `Symbol.iterator`：定义默认迭代器，使对象可被 `for...of` 遍历。
- `Symbol.toPrimitive`：定义对象转原始值的逻辑。
- `Symbol.hasInstance`：自定义 `instanceof` 行为。
- `Symbol.toStringTag`：自定义 `Object.prototype.toString` 的输出。

**可迭代协议（Iterable）**：对象实现 `[Symbol.iterator]()` 方法，返回一个迭代器。

**迭代器协议（Iterator）**：对象实现 `next()` 方法，返回 `{value, done}`。

内置可迭代对象：Array、String、Map、Set、arguments、NodeList。普通对象默认不可迭代。

### 例子

**Symbol 基础：**

```javascript
// 创建 Symbol
const s1 = Symbol();
const s2 = Symbol('description');  // 描述仅用于调试
const s3 = Symbol('description');

console.log(s2 === s3);  // false（即使描述相同也唯一）
console.log(typeof s1);  // 'symbol'

// 作为对象属性键
const SIZE = Symbol('size');
const obj = {
  [SIZE]: 100,
  name: 'Alice'
};

console.log(obj[SIZE]);  // 100
console.log(Object.keys(obj));              // ['name']（Symbol 不出现）
console.log(Object.getOwnPropertySymbols(obj));  // [Symbol(size)]

// Symbol.for：全局注册，相同 key 返回同一 Symbol
const g1 = Symbol.for('shared');
const g2 = Symbol.for('shared');
console.log(g1 === g2);  // true
console.log(Symbol.keyFor(g1));  // 'shared'
```

**知名 Symbol：自定义迭代行为：**

```javascript
// 让普通对象可迭代
class Range {
  constructor(start, end) {
    this.start = start;
    this.end = end;
  }
  
  [Symbol.iterator]() {
    let current = this.start;
    const end = this.end;
    return {
      next() {
        return current <= end
          ? { value: current++, done: false }
          : { value: undefined, done: true };
      }
    };
  }
}

const range = new Range(1, 5);
for (const n of range) {
  console.log(n);  // 1 2 3 4 5
}

// 展开运算符也依赖迭代器
console.log([...new Range(1, 3)]);  // [1, 2, 3]
```

**生成器函数：**

```javascript
// 生成器：function* + yield
function* idGenerator() {
  let id = 1;
  while (true) {
    yield id++;
  }
}

const gen = idGenerator();
console.log(gen.next());  // {value: 1, done: false}
console.log(gen.next());  // {value: 2, done: false}
console.log(gen.next());  // {value: 3, done: false}
// 生成器是惰性的，不会无限循环

// 生成器可迭代
function* take(gen, n) {
  for (const x of gen) {
    if (n-- <= 0) break;
    yield x;
  }
}

for (const id of take(idGenerator(), 3)) {
  console.log(id);  // 1 2 3
}
```

**yield 双向通信：**

```javascript
function* conversation() {
  const question1 = yield '你好';  // yield 返回 next() 传入的值
  console.log('收到：', question1);
  const question2 = yield '再见';
  console.log('收到：', question2);
}

const talk = conversation();
console.log(talk.next().value);         // '你好'（首次 next 不能传值）
console.log(talk.next('在吗').value);   // 收到：在吗 → '再见'
console.log(talk.next('好的'));          // 收到：好的 → {done: true}
```

**生成器实现异步流程（历史意义）：**

```javascript
// 在 async/await 出现前，生成器常用于简化异步代码
function* fetchFlow() {
  try {
    const user = yield fetch('/api/user').then(r => r.json());
    const orders = yield fetch(`/api/orders?uid=${user.id}`).then(r => r.json());
    console.log(user, orders);
  } catch (e) {
    console.error(e);
  }
}

// 自动执行器（简化版）
function run(gen) {
  const it = gen();
  function step(val) {
    const { value, done } = it.next(val);
    if (done) return;
    value.then(step, err => it.throw(err));
  }
  step();
}
run(fetchFlow);
// 现代 JS 直接用 async/await，生成器方案已少用
```

### 总结

- Symbol 是唯一且不可变的原始类型，常用于定义"隐藏"属性和内置行为。
- `Symbol.for()` 全局注册共享 Symbol，`Symbol()` 每次创建新的。
- 知名 Symbol（如 `Symbol.iterator`）用于自定义对象的内置行为。
- 可迭代对象实现 `[Symbol.iterator]()`，迭代器实现 `next()` 返回 `{value, done}`。
- 生成器 `function*` + `yield` 是创建迭代器的便捷方式，惰性求值。
- `yield` 可双向通信：`next(value)` 的 value 作为上一个 yield 的返回值。
- 生成器曾是异步编程的过渡方案，现代开发用 async/await，但生成器在惰性序列、状态机等场景仍有价值。

## 第 22 讲 DOM 操作与事件机制

### 概念

**DOM（Document Object Model）**是浏览器将 HTML 文档解析为树形结构的对象模型，JS 通过 DOM API 增删改查页面元素。

**事件（Event）**是用户或浏览器触发的交互信号（点击、输入、加载等），JS 通过事件监听器响应。

### 原理

DOM 树的根是 `document`，每个 HTML 元素是一个**节点（Node）**，节点有多种类型：元素节点、文本节点、注释节点等。`document` 提供多种查询方法获取元素引用，拿到引用后可修改其内容、属性、样式、类名等。

事件机制的核心是**事件流**：捕获阶段（从 window 向下到目标）→ 目标阶段 → 冒泡阶段（从目标向上到 window）。`addEventListener` 的第三个参数控制在捕获还是冒泡阶段触发，默认 `false`（冒泡）。

**事件委托**是利用事件冒泡，在父元素上统一监听子元素的事件，避免给每个子元素单独绑定，特别适合动态添加的元素。

```javascript
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

function throttle(fn, interval) {
  let last = 0;
  return (...args) => {
    const now = Date.now();
    if (now - last >= interval) {
      last = now;
      fn(...args);
    }
  };
}

}, 200));
```

- `textContent` 安全（防 XSS），`innerHTML` 灵活但有风险，渲染用户输入时务必转义。
- `classList` API 比直接操作 `className` 字符串更方便。
- 事件流分捕获、目标、冒泡三阶段，默认在冒泡阶段触发。
- **事件委托**是高频面试题和实用技巧，利用冒泡在父元素统一监听，适合动态列表。
- 高频事件（scroll、resize、input）务必配合防抖或节流，避免性能问题。
- `e.target` 是触发事件的元素，`e.currentTarget` 是绑定监听的元素，注意区分。

## 第 23 讲 Fetch 与 API 调用

### 概念

**Fetch API** 是现代浏览器提供的网络请求接口，基于 Promise 设计，取代了老旧的 XMLHttpRequest（XHR）。**RESTful API** 是前后端通信的主流风格，通过 HTTP 方法（GET/POST/PUT/DELETE）操作资源。

### 原理

Fetch 的设计哲学：

- **基于 Promise**：天然支持链式调用和 async/await。
- **分离请求和响应**：`fetch()` 返回 Response 对象，需手动调用 `.json()`/`.text()` 读取主体。
- **不会拒绝 HTTP 错误**：4xx、5xx 状态码不会触发 `.catch`，需检查 `response.ok`。
- **默认不带 Cookie**：需设置 `credentials: 'include'`。

HTTP 请求的核心要素：

- **方法**：GET（查询）、POST（创建）、PUT/PATCH（更新）、DELETE（删除）。
- **URL**：资源地址，GET 参数拼在 query string。
- **请求头**：`Content-Type`、`Authorization` 等。
- **请求体**：POST/PUT 携带的数据，常用 JSON 格式。
- **响应**：状态码、响应头、响应体。

### 例子

**GET 请求：**

```javascript

  .then(res => res.json())

// async/await 写法

  const res = await fetch(`/api/users?${params}`);
```

```javascript
// 实战级封装：统一处理 token、错误、JSON
class ApiClient {
  constructor(baseURL = '/api') {
    this.baseURL = baseURL;
  }
  
  async request(path, options = {}) {
    const url = `${this.baseURL}${path}`;
    const token = localStorage.getItem('token');
    
    const config = {
      ...options,
      headers: {
        'Content-Type': 'application/json',
        ...(token && { Authorization: `Bearer ${token}` }),
        ...options.headers
      },
      credentials: 'include'  // 携带 Cookie
    };
    
    if (options.body && typeof options.body === 'object') {
      config.body = JSON.stringify(options.body);
    }
    
    try {
      const res = await fetch(url, config);
      
      // 统一处理 HTTP 错误
      if (!res.ok) {
        if (res.status === 401) {
          // 跳转登录
          location.href = '/login';
          return;
        }
        const error = await res.json().catch(() => ({}));
        throw new Error(error.message || `HTTP ${res.status}`);
      }
      
      // 204 无内容
      if (res.status === 204) return null;
      
      return res.json();
    } catch (err) {
      // 网络错误
      if (err instanceof TypeError) {
        throw new Error('网络异常，请检查连接');
      }
      throw err;
    }
  }
  
  get(path) { return this.request(path); }
  post(path, body) { return this.request(path, { method: 'POST', body }); }
  put(path, body) { return this.request(path, { method: 'PUT', body }); }
  delete(path) { return this.request(path, { method: 'DELETE' }); }
}

// 使用
const api = new ApiClient('/api');
const users = await api.get('/users');
const newUser = await api.post('/users', { name: 'Bob' });
```

```javascript
    xhr.upload.addEventListener('progress', e => {
      if (e.lengthComputable) {
        onProgress(e.loaded / e.total * 100);

    xhr.addEventListener('error', reject);
```

### 总结

- Fetch 基于 Promise，是现代网络请求首选，但 4xx/5xx 不会自动 reject，需检查 `response.ok`。
- POST/PUT 请求需设置 `Content-Type: application/json` 并 `JSON.stringify` 请求体。
- Fetch 默认不带 Cookie，跨域请求需 `credentials: 'include'`。
- 实战中应封装统一请求函数，处理 token、错误、JSON 序列化等通用逻辑。
- 文件上传用 `FormData`，不要手动设 Content-Type，浏览器会自动加 boundary。
- 需要上传进度时 Fetch 无能为力，需回退到 XMLHttpRequest。
- 复杂场景考虑使用 axios 等库，提供拦截器、取消请求、超时等增强功能。

## 第 24 讲 浏览器存储与 Web API 实战

### 概念

浏览器提供多种**客户端存储**机制：`localStorage`、`sessionStorage`、`Cookie`、`IndexedDB`。此外还有丰富的 **Web API**：`IntersectionObserver`（懒加载）、`MutationObserver`（DOM 变化监听）、`Web Workers`（多线程）、`Notification`（通知）等。

### 原理

各存储机制对比：

| 机制 | 容量 | 生命周期 | 是否随请求发送 | API |
|------|------|----------|----------------|-----|
| localStorage | ~5-10MB | 永久 | 否 | 同步，简单 |
| sessionStorage | ~5MB | 当前会话 | 否 | 同步，简单 |
| Cookie | ~4KB | 可设置过期 | 是 | 字符串，繁琐 |
| IndexedDB | 数百MB+ | 永久 | 否 | 异步，事务型 |

选择原则：

- **少量简单数据**（如 token、主题偏好）：`localStorage`。
- **会话级数据**（如临时表单）：`sessionStorage`。
- **需要发给服务端**（如认证）：`Cookie`。
- **大量结构化数据**（如离线缓存）：`IndexedDB`。

### 例子

**localStorage / sessionStorage：**

```javascript
function setCookie(name, value, days) {
  const expires = new Date(Date.now() + days * 864e5).toUTCString();

// 读取 Cookie
function getCookie(name) {
  const cookies = document.cookie.split('; ');
  for (const c of cookies) {
    const [k, v] = c.split('=');

  }
  return null;
}
```

```javascript
function openDB(name, version, upgradeCallback) {
  return new Promise((resolve, reject) => {
    const req = indexedDB.open(name, version);
    req.onupgradeneeded = e => upgradeCallback(e.target.result);
    req.onsuccess = e => resolve(e.target.result);
    req.onerror = e => reject(e.target.error);
  });
}

  if (!db.objectStoreNames.contains('notes')) {
    db.createObjectStore('notes', { keyPath: 'id' });
  }
});

  const db = await dbPromise;
  return new Promise((resolve, reject) => {
    const tx = db.transaction('notes', 'readwrite');
    tx.objectStore('notes').add(note);
    tx.oncomplete = resolve;
    tx.onerror = () => reject(tx.error);
  });
}

async function getAllNotes() {
  const db = await dbPromise;
  return new Promise((resolve, reject) => {
    const req = db.transaction('notes').objectStore('notes').getAll();
    req.onsuccess = () => resolve(req.result);
    req.onerror = () => reject(req.error);
  });
}
```

### 总结

- `localStorage` 适合少量永久数据，`sessionStorage` 适合会话数据，API 简单但同步阻塞。
- Cookie 容量小（4KB）且每次请求自动携带，适合认证等需发给服务端的场景。
- `IndexedDB` 容量大、异步、支持事务和索引，适合离线应用和大量结构化数据。
- `IntersectionObserver` 是懒加载、无限滚动的现代方案，性能远优于 scroll 事件监听。
- `Web Workers` 让 JS 实现"多线程"，适合 CPU 密集计算，但与主线程通信只能通过 postMessage。
- 存储敏感数据（如 token）时注意 XSS 风险，重要数据应加密或存 HttpOnly Cookie。
- 实战中可使用 `idb`、`localforage` 等库简化 IndexedDB 操作。

## 课程结语

恭喜你完成了这 24 讲的 JavaScript 系统学习之旅！从最基础的变量与数据类型，到函数、作用域、闭包，再到面向对象、异步编程、高级特性，最后落地到浏览器实战，你已经掌握了 JavaScript 这门语言的核心全貌。

**接下来的学习建议：**

1. **巩固练习**：每讲的代码示例都动手敲一遍，尝试修改并观察结果。
2. **项目实战**：用所学知识构建一个完整项目，如待办事项、天气应用、博客系统。
3. **深入框架**：学习 React、Vue 等现代框架，理解其设计理念（它们大量运用了本课程的知识）。

5. **工程化**：了解 Webpack、Vite、ESLint、测试等工程化工具链。
6. **持续跟进**：JS 每年都有新特性（ES2024、ES2025...），关注 TC39 提案。

JavaScript 是一门充满活力、不断演进的语言。本课程为你打下了坚实基础，但学习永无止境。祝你在 Web 开发的道路上越走越远！
