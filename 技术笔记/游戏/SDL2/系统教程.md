## 第1讲 SDL2 简介与环境搭建

### 概念

SDL（Simple DirectMedia Layer）是一套开源的跨平台多媒体开发库，用 C 语言编写，通过直接访问底层硬件（音频、键盘、鼠标、显示、3D 硬件等）为开发者提供统一的 API。SDL2 是其第二个主要版本，相比 SDL1.2 在渲染架构、输入系统、多窗口支持等方面有重大改进。

SDL2 的核心定位是"硬件抽象层"而非"游戏引擎"。它不提供碰撞检测、场景管理、AI 等高级功能，而是专注于把不同平台的底层差异（Windows 的 Direct3D、Linux 的 X11/Wayland、macOS 的 Metal、移动端的 OpenGL ES）封装成统一接口。这种"薄而广"的设计哲学使得 SDL2 既轻量又灵活，被众多知名项目采用，包括 Valve 的 Source 引擎、众多独立游戏（如《Stardew Valley》《FTL》）、模拟器（如 RetroArch）等。

### 原理

SDL2 的工作原理可以从三个层面理解：

**硬件抽象层**：SDL2 在每个目标平台上都有对应的"后端实现"。例如在 Windows 上，窗口管理使用 Win32 API，渲染可以使用 Direct3D 或 OpenGL；在 Linux 上使用 X11 或 Wayland，渲染使用 OpenGL。开发者只需调用统一的 `SDL_CreateWindow()`、`SDL_RenderClear()` 等函数，SDL2 内部会自动选择合适的后端。

**子系统划分**：SDL2 将功能划分为多个独立子系统，每个子系统可以单独初始化和关闭：
- `SDL_INIT_VIDEO`：视频（窗口、渲染）
- `SDL_INIT_AUDIO`：音频
- `SDL_INIT_EVENTS`：事件
- `SDL_INIT_JOYSTICK`：摇杆
- `SDL_INIT_HAPTIC`：力反馈
- `SDL_INIT_GAMECONTROLLER`：游戏控制器
- `SDL_INIT_TIMER`：定时器

这种设计的好处是按需加载，减少资源占用。例如一个只需要窗口的程序不需要初始化音频子系统。

**动态加载**：SDL2 支持动态加载扩展库（如 SDL_image、SDL_ttf、SDL_mixer、SDL_net），这些库以独立动态链接库形式存在，可以在运行时加载，便于功能扩展和版本更新。

### 例子


**macOS 环境搭建（Homebrew）**：

```bash

```

**验证安装的测试程序**（`hello.c`）：

```c
#include <SDL2/SDL.h>
#include <stdio.h>

int main(int argc, char* argv[]) {
    /* 初始化 SDL，只启用 VIDEO 子系统 */
    if (SDL_Init(SDL_INIT_VIDEO) < 0) {
        printf("SDL 初始化失败: %s\n", SDL_GetError());
        return 1;
    }

    /* 打印编译时版本和运行时版本 */
    SDL_version compiled;
    SDL_version linked;

    printf("运行时版本: %d.%d.%d\n", linked.major, linked.minor, linked.patch);

    /* 退出 SDL */
    SDL_Quit();
    return 0;
}
```

```bash

# Windows (MSYS2)

```

### 总结

- SDL2 是跨平台多媒体开发库，定位为硬件抽象层，不是游戏引擎
- 采用子系统划分设计，可按需初始化
- 安装时建议同时安装 SDL2 主库和常用扩展库（image、ttf、mixer）
- 编译时需要链接对应的库，Linux/macOS 可用 `sdl2-config` 工具自动获取编译参数
- **常见坑**：Windows 下使用 MinGW 时，必须链接 `-lmingw32` 和 `-lSDL2main`，且顺序很重要（main 函数被 SDL2main 重定义）；如果出现 "undefined reference to WinMain"，检查链接顺序

## 第2讲 创建第一个 SDL2 窗口

### 概念

本讲通过创建一个显示 3 秒后自动关闭的窗口，介绍 SDL2 程序的最小骨架。这个骨架包含所有 SDL2 程序共有的四个核心步骤：初始化、创建窗口、主循环、清理退出。理解这个骨架是后续所有学习的基础。

### 原理

SDL2 程序的生命周期遵循"初始化-创建资源-主循环-销毁资源-退出"的模式：

1. **初始化阶段**：调用 `SDL_Init()` 启动所需子系统。SDL2 内部会根据传入的标志位加载对应的后端驱动（如 Windows 上的 user32.dll、gdi32.dll）。

2. **资源创建阶段**：创建窗口（`SDL_CreateWindow`）。窗口是 SDL2 中所有可视内容的容器，对应操作系统的一个原生窗口对象。创建时需要指定标题、位置、尺寸和标志位（如是否全屏、是否可调整大小等）。

3. **主循环阶段**：程序持续运行，处理事件、更新状态、渲染画面。本讲为简化只调用 `SDL_Delay()` 等待，实际程序会在此循环中处理用户输入和绘制。

4. **清理阶段**：销毁窗口（`SDL_DestroyWindow`）释放显存和系统资源，调用 `SDL_Quit()` 关闭所有子系统并释放 SDL2 内部状态。

资源管理遵循"后创建先销毁"的栈式原则，类似 C++ 的 RAII。每个 `Create` 调用必须有对应的 `Destroy` 调用，否则会导致资源泄漏。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>

int main(int argc, char* argv[]) {
    /* 第1步：初始化视频子系统 */
    if (SDL_Init(SDL_INIT_VIDEO) != 0) {
        printf("SDL_Init 失败: %s\n", SDL_GetError());
        return 1;
    }

    /* 第2步：创建窗口
     * 参数：标题, x, y, 宽, 高, 标志位
     * SDL_WINDOWPOS_CENTERED 表示窗口居中显示
     */
    SDL_Window* window = SDL_CreateWindow(
        "我的第一个 SDL2 窗口",
        SDL_WINDOWPOS_CENTERED,
        SDL_WINDOWPOS_CENTERED,
        800, 600,
        SDL_WINDOW_SHOWN
    );

    if (window == NULL) {
        printf("窗口创建失败: %s\n", SDL_GetError());
        SDL_Quit();
        return 1;
    }

    /* 第3步：主循环（这里简化为延时3秒） */
    printf("窗口已显示，3秒后自动关闭...\n");
    SDL_Delay(3000);

    /* 第4步：清理资源 */
    SDL_DestroyWindow(window);
    SDL_Quit();

    return 0;
}
```

**编译运行**：

```bash
gcc first_window.c -o first_window `sdl2-config --cflags --libs`
./first_window
```

运行后会出现一个 800×600 的黑色窗口，3 秒后自动关闭。

### 总结

- SDL2 程序骨架：`SDL_Init` → `SDL_CreateWindow` → 主循环 → `SDL_DestroyWindow` → `SDL_Quit`
- `SDL_Init` 返回 0 表示成功，与许多返回 -1 的库不同，注意判断条件
- `SDL_GetError()` 是获取错误信息的关键函数，调试时务必使用
- `SDL_Delay(ms)` 让当前线程休眠指定毫秒数，简单但会阻塞事件处理
- **常见坑**：忘记调用 `SDL_Quit()` 会导致子系统资源未释放；窗口创建失败后必须先 `SDL_Quit()` 再 return，否则 SDL2 内部状态不一致

## 第3讲 SDL2 核心架构与生命周期

### 概念

本讲深入讲解 SDL2 的整体架构，包括子系统机制、错误处理、日志系统、版本兼容性等核心概念。掌握这些内容后，你将理解 SDL2 API 的设计模式，能更高效地查阅文档和编写健壮的代码。

### 原理

**子系统机制**：SDL2 的所有功能都组织为子系统。`SDL_Init(flags)` 可以一次初始化多个子系统（用按位或 `|` 连接），`SDL_InitSubSystem()` 可以在运行时动态加载额外子系统，`SDL_QuitSubSystem()` 单独卸载。每个子系统维护自己的内部状态，互不干扰。这种设计让 SDL2 既能作为完整多媒体库使用，也能作为轻量级工具库（如只用其定时器功能）。

**错误处理模型**：SDL2 采用"返回值 + 全局错误字符串"的错误处理模式。大多数函数失败时返回 NULL（指针类型）或负数（整数类型），并通过 `SDL_GetError()` 提供错误描述。错误字符串是线程局部的（thread-local），每个线程维护自己的错误信息，避免多线程冲突。需要注意的是，错误字符串在下次调用 SDL 函数失败时会被覆盖，因此应在检测到错误后立即获取。

**日志系统**：SDL2 提供分级日志系统 `SDL_Log()`，支持不同优先级（VERBOSE、DEBUG、INFO、WARN、ERROR、CRITICAL）。可以通过 `SDL_LogSetPriority()` 设置输出级别，通过 `SDL_LogSetOutputFunction()` 自定义输出目标（如写入文件）。相比 `printf`，日志系统在跨平台时更可靠（Windows 控制台程序中 printf 可能不输出）。

**版本兼容**：SDL2 通过 `SDL_VERSION` 宏（编译时）和 `SDL_GetVersion`（运行时）暴露版本号。开发者可以用 `SDL_VERSION_ATLEAST(major, minor, patch)` 宏判断当前版本是否满足需求，从而使用新版本特性时保持向后兼容。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>

int main(int argc, char* argv[]) {
    /* 版本检查：确保运行时版本至少为 2.0.10 */
    if (!SDL_VERSION_ATLEAST(2, 0, 10)) {
        SDL_Log("需要 SDL2 2.0.10 或更高版本");
        return 1;
    }

    /* 一次性初始化多个子系统 */
    if (SDL_Init(SDL_INIT_VIDEO | SDL_INIT_AUDIO | SDL_INIT_TIMER) != 0) {
        SDL_Log("SDL_Init 失败: %s", SDL_GetError());
        return 1;
    }
    SDL_Log("视频、音频、定时器子系统初始化成功");

    /* 运行时动态加载额外子系统 */
    if (SDL_InitSubSystem(SDL_INIT_EVENTS) == 0) {
        SDL_Log("事件子系统动态加载成功");
    } else {
        SDL_Log("事件子系统加载失败: %s", SDL_GetError());
    }

    /* 查询当前已初始化的子系统 */
    Uint32 subsystems = SDL_WasInit(SDL_INIT_EVERYTHING);
    printf("当前已初始化的子系统:\n");
    if (subsystems & SDL_INIT_VIDEO)         printf("  - VIDEO\n");
    if (subsystems & SDL_INIT_AUDIO)         printf("  - AUDIO\n");
    if (subsystems & SDL_INIT_TIMER)         printf("  - TIMER\n");
    if (subsystems & SDL_INIT_EVENTS)        printf("  - EVENTS\n");
    if (subsystems & SDL_INIT_JOYSTICK)      printf("  - JOYSTICK\n");

    /* 演示错误处理：故意触发一个错误 */
    SDL_Window* w = SDL_CreateWindow("test", 0, 0, 100, 100, 0);
    /* 此处省略正常使用，演示错误获取 */
    if (w == NULL) {
        SDL_Log("预期错误演示: %s", SDL_GetError());
    } else {
        SDL_DestroyWindow(w);
    }

    /* 单独卸载事件子系统 */
    SDL_QuitSubSystem(SDL_INIT_EVENTS);
    SDL_Log("事件子系统已卸载");

    /* 退出所有剩余子系统 */
    SDL_Quit();
    SDL_Log("SDL 已完全退出");
    return 0;
}
```

### 总结

- SDL2 采用子系统架构，支持 `SDL_Init`、`SDL_InitSubSystem`、`SDL_QuitSubSystem`、`SDL_Quit` 四个生命周期函数
- 错误处理模式：函数返回值 + `SDL_GetError()` 线程局部字符串
- 推荐使用 `SDL_Log` 替代 `printf`，跨平台更可靠且支持分级
- 使用 `SDL_VERSION_ATLEAST` 宏做版本兼容性检查
- `SDL_WasInit` 可查询当前已初始化的子系统，便于调试
- **常见坑**：`SDL_GetError()` 返回的字符串在下次错误时被覆盖，必须立即使用或复制；不要在多线程中混用子系统初始化和卸载，应在主线程完成

## 第4讲 窗口管理详解

### 概念

窗口是 SDL2 中所有可视内容的容器。本讲深入讲解窗口的创建、属性设置、全屏模式、多显示器支持、窗口图标等高级功能。SDL2 的窗口管理相比 SDL1.2 有了质的飞跃，支持多窗口、窗口可调整大小、无边框窗口、全屏窗口等多种模式。

### 原理

SDL2 窗口在内部对应一个原生窗口对象（Windows 上的 HWND、Linux 上的 Window、macOS 上的 NSWindow）。`SDL_CreateWindow()` 创建窗口时，SDL2 会调用对应平台的窗口创建 API，并将原生句柄保存在 `SDL_Window` 结构体中。

**窗口标志位**：窗口的行为通过标志位控制，可以按位或组合：
- `SDL_WINDOW_SHOWN`：窗口可见
- `SDL_WINDOW_HIDDEN`：窗口隐藏
- `SDL_WINDOW_FULLSCREEN`：全屏（独占模式）
- `SDL_WINDOW_FULLSCREEN_DESKTOP`：全屏（桌面模式，保持当前分辨率）
- `SDL_WINDOW_RESIZABLE`：可调整大小
- `SDL_WINDOW_BORDERLESS`：无边框
- `SDL_WINDOW_MINIMIZED` / `SDL_WINDOW_MAXIMIZED`：最小化/最大化
- `SDL_WINDOW_INPUT_GRABBED`：捕获鼠标输入
- `SDL_WINDOW_ALLOW_HIGHDPI`：支持高 DPI（Retina 屏）

**全屏模式区别**：`SDL_WINDOW_FULLSCREEN` 会切换显示器分辨率到指定尺寸，性能更好但切换有延迟；`SDL_WINDOW_FULLSCREEN_DESKTOP` 保持当前桌面分辨率，将窗口内容缩放铺满屏幕，切换更快但可能有缩放模糊。

**多显示器支持**：`SDL_GetNumVideoDisplays()` 获取显示器数量，`SDL_GetDisplayBounds()` 获取每个显示器的边界矩形，创建窗口时可以指定显示器索引。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);

    /* 查询显示器信息 */
    int num_displays = SDL_GetNumVideoDisplays();
    printf("检测到 %d 个显示器\n", num_displays);
    for (int i = 0; i < num_displays; i++) {
        SDL_Rect bounds;
        SDL_GetDisplayBounds(i, &bounds);
        printf("  显示器 %d: 位置(%d,%d) 尺寸 %dx%d\n",
               i, bounds.x, bounds.y, bounds.w, bounds.h);
    }

    /* 创建一个可调整大小的窗口 */
    SDL_Window* window = SDL_CreateWindow(
        "窗口管理示例",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600,
        SDL_WINDOW_SHOWN | SDL_WINDOW_RESIZABLE
    );

    /* 设置窗口图标（需要先加载一个表面） */
    /* SDL_Surface* icon = SDL_LoadBMP("icon.bmp"); */
    /* if (icon) { SDL_SetWindowIcon(window, icon); SDL_FreeSurface(icon); } */

    /* 演示窗口属性操作 */
    SDL_Delay(1000);

    /* 移动窗口到 (100, 100) */
    SDL_SetWindowPosition(window, 100, 100);
    printf("窗口已移动到 (100, 100)\n");
    SDL_Delay(1000);

    /* 调整窗口大小 */
    SDL_SetWindowSize(window, 400, 300);
    printf("窗口大小已调整为 400x300\n");
    SDL_Delay(1000);

    /* 最大化窗口 */
    SDL_MaximizeWindow(window);
    printf("窗口已最大化\n");
    SDL_Delay(1000);

    /* 恢复窗口 */
    SDL_RestoreWindow(window);
    printf("窗口已恢复\n");
    SDL_Delay(1000);

    /* 切换到桌面全屏模式 */
    SDL_SetWindowFullscreen(window, SDL_WINDOW_FULLSCREEN_DESKTOP);
    printf("已切换到桌面全屏模式\n");
    SDL_Delay(2000);

    /* 退出全屏 */
    SDL_SetWindowFullscreen(window, 0);
    printf("已退出全屏\n");
    SDL_Delay(1000);

    /* 获取窗口当前状态 */
    int x, y, w, h;
    SDL_GetWindowPosition(window, &x, &y);
    SDL_GetWindowSize(window, &w, &h);
    Uint32 flags = SDL_GetWindowFlags(window);
    printf("当前窗口: 位置(%d,%d) 尺寸 %dx%d 标志 0x%x\n", x, y, w, h, flags);

    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 窗口通过 `SDL_CreateWindow` 创建，标志位控制其行为
- 全屏有两种模式：独占模式（切换分辨率）和桌面模式（保持分辨率）
- 多显示器通过 `SDL_GetNumVideoDisplays` 和 `SDL_GetDisplayBounds` 支持
- 窗口属性可在运行时动态修改：位置、大小、全屏状态、标题等
- `SDL_GetWindowFlags` 可查询窗口当前状态（是否全屏、是否最小化等）
- **常见坑**：切换独占全屏时如果指定的分辨率不被显示器支持会失败；高 DPI 模式下 `SDL_GetWindowSize` 返回逻辑像素，`SDL_GL_GetDrawableSize` 或 `SDL_GetRendererOutputSize` 返回物理像素

## 第5讲 渲染器与基础图形绘制

### 概念

渲染器（Renderer）是 SDL2 引入的核心抽象，负责将绘制命令转换为底层图形 API 调用（Direct3D、OpenGL、Metal、软件渲染等）。本讲介绍渲染器的创建、配置，以及点、线、矩形等基础图形的绘制方法。

### 原理

SDL2 的渲染架构相比 SDL1.2 有根本性变化。SDL1.2 中直接在屏幕表面（Surface）上绘制，使用 CPU 软件渲染；SDL2 引入渲染器抽象，可以利用 GPU 硬件加速。

**渲染器 vs 表面**：
- `SDL_Surface`：CPU 内存中的像素数据，软件渲染，跨平台一致但慢
- `SDL_Texture`：上传到 GPU 的纹理，硬件加速，绘制快
- `SDL_Renderer`：绘制命令的执行者，将纹理绘制到后缓冲

**渲染后端**：SDL2 支持多种渲染后端，通过 `SDL_RendererFlags` 选择：
- `SDL_RENDERER_SOFTWARE`：纯软件渲染，兼容性最好但最慢
- `SDL_RENDERER_ACCELERATED`：硬件加速（默认优先）
- `SDL_RENDERER_PRESENTVSYNC`：垂直同步，防止画面撕裂
- `SDL_RENDERER_TARGETTEXTURE`：支持渲染到纹理

**绘制流程**：渲染器采用"命令缓冲"模式。所有绘制命令（`SDL_RenderDrawLine`、`SDL_RenderFillRect` 等）先记录在内部缓冲区，调用 `SDL_RenderPresent()` 时一次性提交到 GPU 并显示。这种模式减少了 GPU 状态切换，性能更高。

**坐标系**：SDL2 使用屏幕坐标系，原点在左上角，x 向右增大，y 向下增大。这与数学坐标系不同，但符合屏幕扫描顺序。

### 例子

```c
#include <SDL2/SDL.h>

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);

    SDL_Window* window = SDL_CreateWindow(
        "渲染器示例",
        SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );

    /* 创建渲染器：硬件加速 + 垂直同步 */
    SDL_Renderer* renderer = SDL_CreateRenderer(
        window, -1,
        SDL_RENDERER_ACCELERATED | SDL_RENDERER_PRESENTVSYNC
    );
    if (!renderer) {
        /* 回退到软件渲染 */
        renderer = SDL_CreateRenderer(window, -1, SDL_RENDERER_SOFTWARE);
    }

    /* 查询渲染器信息 */
    SDL_RendererInfo info;
    SDL_GetRendererInfo(renderer, &info);
    printf("当前渲染器: %s\n", info.name);

    SDL_bool running = SDL_TRUE;
    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN && event.key.keysym.sym == SDLK_ESCAPE)
                running = SDL_FALSE;
        }

        /* 1. 清屏（设置背景色并填充） */
        SDL_SetRenderDrawColor(renderer, 30, 30, 50, 255); /* 深蓝灰 */
        SDL_RenderClear(renderer);

        /* 2. 绘制点 */
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255); /* 白色 */
        for (int i = 0; i < 50; i++) {
            SDL_RenderDrawPoint(renderer, 100 + i * 12, 100);
        }

        /* 3. 绘制线 */
        SDL_SetRenderDrawColor(renderer, 255, 0, 0, 255); /* 红色 */
        SDL_RenderDrawLine(renderer, 50, 200, 750, 200);

        /* 4. 绘制矩形边框 */
        SDL_SetRenderDrawColor(renderer, 0, 255, 0, 255); /* 绿色 */
        SDL_Rect rect_outline = {100, 300, 200, 100};
        SDL_RenderDrawRect(renderer, &rect_outline);

        /* 5. 绘制填充矩形 */
        SDL_SetRenderDrawColor(renderer, 0, 0, 255, 255); /* 蓝色 */
        SDL_Rect rect_fill = {400, 300, 200, 100};
        SDL_RenderFillRect(renderer, &rect_fill);

        /* 6. 绘制多个矩形 */
        SDL_SetRenderDrawColor(renderer, 255, 255, 0, 255); /* 黄色 */
        SDL_Rect rects[] = {
            {100, 450, 50, 50},
            {200, 450, 50, 50},
            {300, 450, 50, 50}
        };
        SDL_RenderFillRects(renderer, rects, 3);

        /* 7. 提交渲染 */
        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 渲染器是 SDL2 的核心绘制抽象，支持硬件加速
- 创建渲染器时建议使用 `SDL_RENDERER_ACCELERATED | SDL_RENDERER_PRESENTVSYNC`
- 绘制流程：`SetRenderDrawColor` → `RenderClear` → 绘制命令 → `RenderPresent`
- 所有绘制命令在 `RenderPresent` 之前不会显示
- 坐标系原点在左上角，y 轴向下
- **常见坑**：忘记调用 `SDL_RenderClear` 会导致上一帧画面残留；忘记 `SDL_RenderPresent` 会导致画面不更新；绘制颜色包含 alpha 通道时，默认混合模式会影响结果

## 第6讲 纹理加载与显示

### 概念

纹理（Texture）是 SDL2 中显示图像的核心对象。本讲介绍如何从 BMP 文件加载纹理，以及纹理的绘制、缩放、旋转等操作。纹理存储在 GPU 显存中，绘制效率远高于直接操作像素表面。

### 原理

**纹理与表面的区别**：
- `SDL_Surface` 在系统内存中，CPU 可直接读写像素，但绘制需要逐像素操作
- `SDL_Texture` 在 GPU 显存中，CPU 无法直接访问像素，但 GPU 绘制极快

数据流：磁盘文件 → `SDL_Surface`（CPU 内存）→ `SDL_Texture`（GPU 显存）→ 渲染到屏幕。

**纹理创建方式**：
1. `SDL_CreateTexture`：创建空白纹理，可指定像素格式和访问模式
2. `SDL_CreateTextureFromSurface`：从 Surface 转换为 Texture
3. `SDL_UpdateTexture`：更新纹理的像素数据

**纹理访问模式**：
- `SDL_TEXTUREACCESS_STATIC`：纹理数据很少变化（默认）
- `SDL_TEXTUREACCESS_STREAMING`：纹理数据频繁变化（如视频帧）
- `SDL_TEXTUREACCESS_TARGET`：纹理可作为渲染目标（离屏渲染）

**纹理绘制函数**：
- `SDL_RenderCopy`：将整个纹理绘制到指定矩形（可缩放）
- `SDL_RenderCopyEx`：支持旋转、翻转、中心点设置

**像素格式**：SDL2 支持多种像素格式（RGB888、RGBA8888、BGRA8888 等）。GPU 通常偏好 BGRA 格式，因为这与显示器的物理布局一致，避免格式转换开销。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>

/* 辅助函数：从 BMP 文件加载纹理 */
SDL_Texture* LoadBMPTexture(SDL_Renderer* renderer, const char* file) {
    /* 1. 从文件加载 Surface */
    SDL_Surface* surface = SDL_LoadBMP(file);
    if (!surface) {
        printf("无法加载 %s: %s\n", file, SDL_GetError());
        return NULL;
    }

    /* 2. 将 Surface 转换为 Texture */
    SDL_Texture* texture = SDL_CreateTextureFromSurface(renderer, surface);
    if (!texture) {
        printf("无法创建纹理: %s\n", SDL_GetError());
    }

    /* 3. Surface 不再需要，释放 */
    SDL_FreeSurface(surface);
    return texture;
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);

    SDL_Window* window = SDL_CreateWindow(
        "纹理示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(
        window, -1, SDL_RENDERER_ACCELERATED
    );

    /* 加载纹理（需要准备一个 test.bmp 文件） */
    SDL_Texture* texture = LoadBMPTexture(renderer, "test.bmp");
    int tex_w = 0, tex_h = 0;
    if (texture) {
        SDL_QueryTexture(texture, NULL, NULL, &tex_w, &tex_h);
        printf("纹理尺寸: %dx%d\n", tex_w, tex_h);
    }

    /* 创建一个程序生成的纹理（彩色渐变） */
    SDL_Texture* gradient = SDL_CreateTexture(
        renderer, SDL_PIXELFORMAT_RGBA8888,
        SDL_TEXTUREACCESS_STREAMING, 256, 256
    );
    Uint32 pixels[256 * 256];
    for (int y = 0; y < 256; y++) {
        for (int x = 0; x < 256; x++) {
            Uint8 r = (Uint8)x;
            Uint8 g = (Uint8)y;
            Uint8 b = (Uint8)(255 - (x + y) / 2);
            pixels[y * 256 + x] = (r << 24) | (g << 16) | (b << 8) | 0xFF;
        }
    }
    SDL_UpdateTexture(gradient, NULL, pixels, 256 * sizeof(Uint32));

    SDL_bool running = SDL_TRUE;
    float angle = 0.0f;
    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
        }

        SDL_SetRenderDrawColor(renderer, 0, 0, 0, 255);
        SDL_RenderClear(renderer);

        /* 绘制 BMP 纹理：原始尺寸 */
        if (texture) {
            SDL_Rect dest = {50, 50, tex_w, tex_h};
            SDL_RenderCopy(renderer, texture, NULL, &dest);
        }

        /* 绘制渐变纹理：缩放到 200x200 */
        SDL_Rect dest_grad = {500, 50, 200, 200};
        SDL_RenderCopy(renderer, gradient, NULL, &dest_grad);

        /* 旋转绘制渐变纹理 */
        SDL_Rect dest_rot = {300, 350, 150, 150};
        SDL_Point center = {75, 75};
        SDL_RenderCopyEx(renderer, gradient, NULL, &dest_rot,
                         angle, &center, SDL_FLIP_NONE);
        angle += 1.0f;
        if (angle >= 360.0f) angle = 0.0f;

        SDL_RenderPresent(renderer);
        SDL_Delay(16); /* 约 60 FPS */
    }

    SDL_DestroyTexture(texture);
    SDL_DestroyTexture(gradient);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 纹理是 GPU 显存中的图像数据，绘制效率高
- 加载流程：`SDL_LoadBMP` → `SDL_CreateTextureFromSurface` → `SDL_FreeSurface`
- `SDL_QueryTexture` 查询纹理的格式、宽高
- `SDL_RenderCopy` 绘制纹理，`SDL_RenderCopyEx` 支持旋转和翻转
- 频繁更新的纹理使用 `SDL_TEXTUREACCESS_STREAMING` 模式
- **常见坑**：Surface 用完必须 `SDL_FreeSurface` 释放，否则内存泄漏；纹理的源矩形（src）和目标矩形（dst）尺寸不同时会自动缩放；旋转角度单位是度，顺时针方向

## 第7讲 渲染循环与双缓冲

### 概念

渲染循环是游戏和图形应用的心脏。本讲讲解渲染循环的结构、帧率控制、双缓冲机制、垂直同步等关键概念。理解这些内容后，你将能编写流畅、不撕裂、不闪烁的图形程序。

### 原理

**双缓冲机制**：屏幕显示需要时间（通常 16.67ms 对应 60Hz）。如果直接在前缓冲（正在显示的缓冲）上绘制，用户会看到绘制过程中的"半成品"，导致撕裂感。双缓冲使用两块内存：前缓冲（显示中）和后缓冲（绘制中）。绘制完成后，通过 `SDL_RenderPresent` 交换两块缓冲，瞬间显示完整画面。

**垂直同步（VSync）**：显示器按固定频率刷新（60Hz、120Hz、144Hz 等）。垂直同步让缓冲交换与显示器刷新同步，避免一帧画面在刷新中途被替换（撕裂）。开启 VSync 后，`SDL_RenderPresent` 会阻塞直到下一次垂直同步信号，自动限制帧率到显示器刷新率。

**帧率控制**：不开启 VSync 时，渲染循环会以 CPU/GPU 最大速度运行，可能导致：
1. 帧率过高（数百 FPS），浪费电量和资源
2. 帧率不稳定，画面卡顿

解决方案有两种：
1. 开启 VSync（推荐）：自动同步到显示器刷新率
2. 手动延迟：计算本帧耗时，剩余时间用 `SDL_Delay` 休眠

**增量时间（Delta Time）**：游戏逻辑应基于时间而非帧数。每帧计算 `delta = 当前时间 - 上一帧时间`，所有运动以"每秒移动多少单位"计算，乘以 delta 得到本帧位移。这样无论帧率高低，物体运动速度一致。

**固定时间步长**：物理模拟通常使用固定时间步长（如 1/60 秒），避免帧率波动导致物理行为不一致。实现方式是累积 delta 时间，每达到一个步长执行一次物理更新。

### 例子

```c
#include <SDL2/SDL.h>

#define TARGET_FPS 60
#define FRAME_TIME (1000 / TARGET_FPS)

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO | SDL_INIT_TIMER);

    SDL_Window* window = SDL_CreateWindow(
        "渲染循环示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );

    /* 不开启 VSync，演示手动帧率控制 */
    SDL_Renderer* renderer = SDL_CreateRenderer(
        window, -1, SDL_RENDERER_ACCELERATED
    );

    SDL_bool running = SDL_TRUE;
    float x = 0.0f;          /* 矩形 x 坐标 */
    float speed = 200.0f;    /* 速度：每秒 200 像素 */
    Uint32 last_time = SDL_GetTicks();
    int frame_count = 0;
    Uint32 fps_timer = SDL_GetTicks();

    while (running) {
        /* 处理事件 */
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
        }

        /* 计算增量时间（秒） */
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;

        /* 更新逻辑：基于时间的运动 */
        x += speed * delta;
        if (x > 800) x = -50;  /* 超出右边则从左边重新出现 */

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect rect = { (int)x, 280, 50, 50 };
        SDL_RenderFillRect(renderer, &rect);

        SDL_RenderPresent(renderer);

        /* 帧率控制：手动限制到 60 FPS */
        Uint32 frame_time = SDL_GetTicks() - current_time;
        if (frame_time < FRAME_TIME) {
            SDL_Delay(FRAME_TIME - frame_time);
        }

        /* FPS 统计 */
        frame_count++;
        if (SDL_GetTicks() - fps_timer >= 1000) {
            printf("FPS: %d\n", frame_count);
            frame_count = 0;
            fps_timer = SDL_GetTicks();
        }
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 双缓冲避免画面撕裂：在后缓冲绘制，`RenderPresent` 交换缓冲
- 垂直同步自动同步到显示器刷新率，最简单的帧率控制方式
- 不用 VSync 时需手动 `SDL_Delay` 限制帧率
- 游戏逻辑应基于增量时间（delta time），而非帧数
- `SDL_GetTicks()` 返回毫秒级时间，`SDL_GetPerformanceCounter()` 提供更高精度
- **常见坑**：`SDL_Delay` 精度有限（约 10ms），短延迟可能不准；delta time 在第一帧可能很大（程序启动耗时），应钳制最大值；FPS 统计应每秒计算一次，而非每帧

# 第3章 事件系统

事件系统是 SDL2 与用户交互的核心。本章讲解事件队列、事件类型、事件循环等概念，让你能响应键盘、鼠标、窗口等各种用户操作。

---

## 第8讲 事件系统总览

### 概念

事件（Event）是 SDL2 通知应用程序"发生了某事"的机制。用户按键、移动鼠标、调整窗口大小、插入设备等操作都会产生事件。本讲介绍 SDL2 事件系统的整体架构、事件队列模型、事件类型分类，以及事件循环的标准写法。

### 原理

**事件队列模型**：SDL2 在内部维护一个全局事件队列（线程安全）。当底层系统产生输入事件时，SDL2 的事件收集线程将其转换为 `SDL_Event` 结构并推入队列。应用程序通过 `SDL_PollEvent()` 从队列取出事件处理，或通过 `SDL_WaitEvent()` 阻塞等待事件。

**事件结构**：`SDL_Event` 是一个联合体（union），不同类型的事件共享同一块内存。`event.type` 字段标识事件类型，根据类型可以访问对应的子结构（如 `event.key`、`event.mouse`、`event.window` 等）。这种设计既节省内存又便于统一处理。

**事件类型分类**：
- 窗口事件：`SDL_WINDOWEVENT`（大小变化、聚焦、最小化等）
- 键盘事件：`SDL_KEYDOWN`、`SDL_KEYUP`、`SDL_TEXTINPUT`
- 鼠标事件：`SDL_MOUSEMOTION`、`SDL_MOUSEBUTTONDOWN`、`SDL_MOUSEBUTTONUP`、`SDL_MOUSEWHEEL`
- 摇杆/控制器事件：`SDL_JOYAXISMOTION`、`SDL_CONTROLLERBUTTONDOWN` 等
- 退出事件：`SDL_QUIT`（用户点击关闭按钮）
- 用户自定义事件：`SDL_USEREVENT`

**事件过滤与拦截**：`SDL_SetEventFilter` 可以设置全局事件过滤器，在事件进入队列前拦截。`SDL_AddEventWatch` 添加事件监听器（不消费事件）。这些机制适用于全局快捷键、事件日志等场景。

**事件推送**：应用程序可以通过 `SDL_PushEvent()` 主动推送事件，常用于自定义事件和跨线程通信。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);

    SDL_Window* window = SDL_CreateWindow(
        "事件系统示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    SDL_bool running = SDL_TRUE;
    int event_count = 0;

    while (running) {
        SDL_Event event;
        /* PollEvent 非阻塞地取出事件，无事件时返回 0 */
        while (SDL_PollEvent(&event)) {
            event_count++;

            switch (event.type) {
            case SDL_QUIT:
                printf("[事件 %d] 用户请求退出\n", event_count);
                running = SDL_FALSE;
                break;

            case SDL_KEYDOWN:
                printf("[事件 %d] 键盘按下: %s (扫描码 %d)\n",
                       event_count,
                       SDL_GetKeyName(event.key.keysym.sym),
                       event.key.keysym.scancode);
                if (event.key.keysym.sym == SDLK_ESCAPE) {
                    running = SDL_FALSE;
                }
                break;

            case SDL_KEYUP:
                printf("[事件 %d] 键盘释放: %s\n",
                       event_count,
                       SDL_GetKeyName(event.key.keysym.sym));
                break;

            case SDL_MOUSEMOTION:
                printf("[事件 %d] 鼠标移动: (%d, %d)\n",
                       event_count, event.motion.x, event.motion.y);
                break;

            case SDL_MOUSEBUTTONDOWN:
                printf("[事件 %d] 鼠标按下: 按钮 %d 位置 (%d, %d)\n",
                       event_count, event.button.button,
                       event.button.x, event.button.y);
                break;

            case SDL_MOUSEWHEEL:
                printf("[事件 %d] 鼠标滚轮: x=%d y=%d\n",
                       event_count, event.wheel.x, event.wheel.y);
                break;

            case SDL_WINDOWEVENT:
                printf("[事件 %d] 窗口事件: %d\n",
                       event_count, event.window.event);
                break;

            default:
                printf("[事件 %d] 其他事件类型: %u\n",
                       event_count, event.type);
                break;
            }
        }

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 50, 50, 50, 255);
        SDL_RenderClear(renderer);
        SDL_RenderPresent(renderer);
    }

    printf("总共处理了 %d 个事件\n", event_count);

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- SDL2 使用全局事件队列，通过 `SDL_PollEvent`（非阻塞）或 `SDL_WaitEvent`（阻塞）获取事件
- `SDL_Event` 是联合体，通过 `event.type` 判断具体类型并访问对应字段
- 事件循环应在每帧开始时清空所有积压事件，避免事件堆积
- `SDL_QUIT` 是用户点击窗口关闭按钮产生的事件，必须处理否则无法正常退出
- **常见坑**：忘记处理 `SDL_QUIT` 会导致窗口关闭按钮无效；事件循环中只处理一个事件（用 `if` 而非 `while`）会导致事件积压，程序响应迟钝

## 第9讲 键盘与鼠标事件处理

### 概念

键盘和鼠标是最常用的输入设备。本讲深入讲解键盘事件（按键、释放、修饰键、文本输入）和鼠标事件（移动、点击、滚轮、相对模式）的细节，以及如何在实际应用中正确处理这些输入。

### 原理

**键盘事件细节**：
- `SDL_KEYDOWN` / `SDL_KEYUP`：按键按下和释放
- `event.key.keysym.sym`：虚拟键码（如 `SDLK_A`、`SDLK_SPACE`、`SDLK_RETURN`）
- `event.key.keysym.scancode`：物理扫描码（如 `SDL_SCANCODE_A`），与键盘布局无关
- `event.key.keysym.mod`：修饰键状态（Ctrl、Shift、Alt、GUI）
- `event.key.repeat`：是否为按住自动重复产生的事件

**虚拟键码 vs 扫描码**：
- 虚拟键码（sym）经过键盘布局转换，"W" 键在 AZERTY 布局上会变成其他 sym
- 扫描码（scancode）是物理按键位置，适合做游戏控制（WASD 移动）
- 游戏开发推荐使用 scancode，避免不同键盘布局导致按键错乱

**文本输入**：`SDL_TEXTINPUT` 事件提供用户输入的实际字符（考虑输入法、Shift、CapsLock 等）。需要先调用 `SDL_StartTextInput()` 启用，处理完调用 `SDL_StopTextInput()`。适合文本框输入场景。

**鼠标事件细节**：
- `SDL_MOUSEMOTION`：`event.motion.x/y` 是窗口内坐标，`event.motion.xrel/yrel` 是相对位移
- `SDL_MOUSEBUTTONDOWN/UP`：`event.button.button` 标识按钮（`SDL_BUTTON_LEFT` 等）
- `SDL_MOUSEWHEEL`：`event.wheel.x/y` 是滚动量，y 正方向向上
- 鼠标坐标原点在窗口左上角

**鼠标相对模式**：`SDL_SetRelativeMouseMode(SDL_TRUE)` 启用后，鼠标被锁定在窗口中心，`SDL_MOUSEMOTION` 只提供相对位移（xrel/yrel），适合第一人称视角游戏。`SDL_ShowCursor(SDL_DISABLE)` 隐藏鼠标光标。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>
#include <string.h>

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);

    SDL_Window* window = SDL_CreateWindow(
        "键盘鼠标示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    /* 玩家位置（用 WASD 控制） */
    float px = 400.0f, py = 300.0f;
    float speed = 300.0f;  /* 每秒 300 像素 */

    /* 文本输入缓冲 */
    char text[256] = "";
    SDL_bool text_input_active = SDL_FALSE;

    Uint32 last_time = SDL_GetTicks();
    SDL_bool running = SDL_TRUE;

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            switch (event.type) {
            case SDL_QUIT:
                running = SDL_FALSE;
                break;

            case SDL_KEYDOWN:
                /* F1 切换文本输入模式 */
                if (event.key.keysym.scancode == SDL_SCANCODE_F1 && !event.key.repeat) {
                    if (text_input_active) {
                        SDL_StopTextInput();
                        text_input_active = SDL_FALSE;
                        printf("文本输入关闭\n");
                    } else {
                        SDL_StartTextInput();
                        text_input_active = SDL_TRUE;
                        text[0] = '\0';
                        printf("文本输入开启（输入字符，回车结束）\n");
                    }
                }
                /* ESC 退出 */
                if (event.key.keysym.scancode == SDL_SCANCODE_ESCAPE) {
                    running = SDL_FALSE;
                }
                /* 回车确认文本输入 */
                if (event.key.keysym.scancode == SDL_SCANCODE_RETURN && text_input_active) {
                    printf("输入的文本: %s\n", text);
                }
                /* 退格删除字符 */
                if (event.key.keysym.scancode == SDL_SCANCODE_BACKSPACE && text_input_active) {
                    int len = strlen(text);
                    if (len > 0) text[len - 1] = '\0';
                }
                break;

            case SDL_TEXTINPUT:
                if (strlen(text) + strlen(event.text.text) < 255) {
                    strcat(text, event.text.text);
                }
                break;

            case SDL_MOUSEBUTTONDOWN:
                printf("鼠标点击: (%d, %d) 按钮 %d\n",
                       event.button.x, event.button.y, event.button.button);
                /* 右键切换相对鼠标模式 */
                if (event.button.button == SDL_BUTTON_RIGHT) {
                    SDL_bool relative = SDL_GetRelativeMouseMode();
                    SDL_SetRelativeMouseMode(!relative);
                    printf("相对鼠标模式: %s\n", !relative ? "开启" : "关闭");
                }
                break;

            case SDL_MOUSEWHEEL:
                printf("滚轮: y=%d\n", event.wheel.y);
                break;
            }
        }

        /* 使用键盘状态（非事件）实现持续移动 */
        const Uint8* keystate = SDL_GetKeyboardState(NULL);
        if (keystate[SDL_SCANCODE_W] || keystate[SDL_SCANCODE_UP])    py -= speed * delta;
        if (keystate[SDL_SCANCODE_S] || keystate[SDL_SCANCODE_DOWN])  py += speed * delta;
        if (keystate[SDL_SCANCODE_A] || keystate[SDL_SCANCODE_LEFT])  px -= speed * delta;
        if (keystate[SDL_SCANCODE_D] || keystate[SDL_SCANCODE_RIGHT]) px += speed * delta;

        /* 边界限制 */
        if (px < 0) px = 0;
        if (px > 780) px = 780;
        if (py < 0) py = 0;
        if (py > 580) py = 580;

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 30, 30, 30, 255);
        SDL_RenderClear(renderer);

        /* 绘制玩家（蓝色方块） */
        SDL_SetRenderDrawColor(renderer, 100, 180, 255, 255);
        SDL_Rect player = { (int)px, (int)py, 20, 20 };
        SDL_RenderFillRect(renderer, &player);

        /* 绘制鼠标位置（红色方块） */
        int mx, my;
        SDL_GetMouseState(&mx, &my);
        SDL_SetRenderDrawColor(renderer, 255, 100, 100, 255);
        SDL_Rect cursor = { mx - 5, my - 5, 10, 10 };
        SDL_RenderFillRect(renderer, &cursor);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 键盘事件提供 sym（虚拟键码）和 scancode（物理扫描码），游戏推荐用 scancode
- 修饰键状态通过 `event.key.keysym.mod` 获取
- 文本输入需 `SDL_StartTextInput` 启用，处理 `SDL_TEXTINPUT` 事件
- 鼠标事件包含绝对坐标和相对位移，相对模式适合 FPS 游戏
- 持续按键移动应使用 `SDL_GetKeyboardState` 轮询，而非依赖 `SDL_KEYDOWN` 事件
- **常见坑**：`SDL_KEYDOWN` 的 repeat 字段标识自动重复事件，单次触发逻辑应检查 `!event.key.repeat`；文本输入与按键事件会同时触发，需要根据场景选择处理

## 第10讲 窗口事件与多窗口

### 概念

窗口事件让程序能响应窗口大小变化、聚焦切换、最小化等状态变化。本讲讲解窗口事件的处理，以及 SDL2 的多窗口支持——一个程序可以同时管理多个窗口，每个窗口独立渲染。

### 原理

**窗口事件类型**：`SDL_WINDOWEVENT` 是一个复合事件，通过 `event.window.event` 字段区分具体类型：
- `SDL_WINDOWEVENT_SHOWN` / `SDL_WINDOWEVENT_HIDDEN`：窗口显示/隐藏
- `SDL_WINDOWEVENT_EXPOSED`：窗口需要重绘（被其他窗口遮挡后重新可见）
- `SDL_WINDOWEVENT_MOVED`：窗口移动
- `SDL_WINDOWEVENT_RESIZED` / `SDL_WINDOWEVENT_SIZE_CHANGED`：窗口大小变化
- `SDL_WINDOWEVENT_MINIMIZED` / `SDL_WINDOWEVENT_MAXIMIZED` / `SDL_WINDOWEVENT_RESTORED`：最小化/最大化/恢复
- `SDL_WINDOWEVENT_ENTER` / `SDL_WINDOWEVENT_LEAVE`：鼠标进入/离开窗口
- `SDL_WINDOWEVENT_FOCUS_GAINED` / `SDL_WINDOWEVENT_FOCUS_LOST`：键盘焦点获取/失去
- `SDL_WINDOWEVENT_CLOSE`：窗口请求关闭

**RESIZED vs SIZE_CHANGED**：`SDL_WINDOWEVENT_RESIZED` 由用户操作（拖动边框）触发；`SDL_WINDOWEVENT_SIZE_CHANGED` 包括程序调用 `SDL_SetWindowSize` 等所有尺寸变化。两者都会触发，但语义不同。

**多窗口架构**：SDL2 支持创建多个窗口，每个窗口关联独立的渲染器。事件通过 `event.window.windowID` 标识来自哪个窗口，`SDL_GetWindowID()` 获取窗口的 ID。多窗口程序需要为每个窗口维护独立的渲染逻辑。

**渲染目标切换**：多窗口时，每个窗口的渲染器独立。渲染前需确保使用正确的渲染器，`SDL_RenderClear` 和 `SDL_RenderPresent` 只作用于当前渲染器关联的窗口。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>

#define NUM_WINDOWS 3

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);

    SDL_Window* windows[NUM_WINDOWS];
    SDL_Renderer* renderers[NUM_WINDOWS];
    SDL_Color colors[NUM_WINDOWS] = {
        {200, 80, 80, 255},    /* 红 */
        {80, 200, 80, 255},    /* 绿 */
        {80, 80, 200, 255}     /* 蓝 */
    };

    /* 创建 3 个窗口，错开排列 */
    for (int i = 0; i < NUM_WINDOWS; i++) {
        char title[32];
        sprintf(title, "窗口 %d", i + 1);
        windows[i] = SDL_CreateWindow(
            title,
            100 + i * 250, 100 + i * 50,
            400, 300,
            SDL_WINDOW_SHOWN | SDL_WINDOW_RESIZABLE
        );
        renderers[i] = SDL_CreateRenderer(windows[i], -1,
            SDL_RENDERER_ACCELERATED);
        printf("窗口 %d ID: %u\n", i + 1, SDL_GetWindowID(windows[i]));
    }

    SDL_bool running = SDL_TRUE;
    int active_window = 0;  /* 当前聚焦的窗口索引 */

    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            switch (event.type) {
            case SDL_QUIT:
                running = SDL_FALSE;
                break;

            case SDL_WINDOWEVENT:
                /* 找到事件对应的窗口 */
                for (int i = 0; i < NUM_WINDOWS; i++) {
                    if (SDL_GetWindowID(windows[i]) == event.window.windowID) {
                        switch (event.window.event) {
                        case SDL_WINDOWEVENT_FOCUS_GAINED:
                            active_window = i;
                            printf("窗口 %d 获取焦点\n", i + 1);
                            break;
                        case SDL_WINDOWEVENT_RESIZED:
                            printf("窗口 %d 调整为 %dx%d\n",
                                   i + 1, event.window.data1, event.window.data2);
                            break;
                        case SDL_WINDOWEVENT_CLOSE:
                            printf("窗口 %d 请求关闭\n", i + 1);
                            /* 隐藏而非销毁，演示 */
                            SDL_HideWindow(windows[i]);
                            break;
                        case SDL_WINDOWEVENT_EXPOSED:
                            /* 窗口需要重绘 */
                            SDL_SetRenderDrawColor(renderers[i],
                                colors[i].r, colors[i].g, colors[i].b, 255);
                            SDL_RenderClear(renderers[i]);
                            SDL_RenderPresent(renderers[i]);
                            break;
                        }
                        break;
                    }
                }
                break;

            case SDL_KEYDOWN:
                if (event.key.keysym.scancode == SDL_SCANCODE_ESCAPE) {
                    running = SDL_FALSE;
                }
                break;
            }
        }

        /* 渲染所有窗口 */
        for (int i = 0; i < NUM_WINDOWS; i++) {
            SDL_SetRenderDrawColor(renderers[i],
                colors[i].r, colors[i].g, colors[i].b, 255);
            SDL_RenderClear(renderers[i]);

            /* 在聚焦的窗口中绘制标记 */
            if (i == active_window) {
                SDL_SetRenderDrawColor(renderers[i], 255, 255, 255, 255);
                SDL_Rect mark = {10, 10, 20, 20};
                SDL_RenderFillRect(renderers[i], &mark);
            }

            SDL_RenderPresent(renderers[i]);
        }

        SDL_Delay(16);
    }

    for (int i = 0; i < NUM_WINDOWS; i++) {
        SDL_DestroyRenderer(renderers[i]);
        SDL_DestroyWindow(windows[i]);
    }
    SDL_Quit();
    return 0;
}
```

### 总结

- 窗口事件通过 `event.window.event` 区分具体类型，`event.window.windowID` 标识来源窗口
- `SDL_WINDOWEVENT_RESIZED` 由用户触发，`SIZE_CHANGED` 包括程序触发的尺寸变化
- 多窗口程序通过 `SDL_GetWindowID` 匹配事件与窗口
- 每个窗口需要独立的渲染器，渲染时分别处理
- `SDL_WINDOWEVENT_EXPOSED` 是窗口被遮挡后重新可见的重绘请求，必须响应
- **常见坑**：多窗口时事件循环要正确分发事件到对应窗口；关闭一个窗口不一定要退出程序，应根据业务逻辑判断

## 第11讲 SDL_image 图像加载

### 概念

SDL2 核心库只支持 BMP 格式，实际开发中需要加载 PNG、JPG、WEBP 等格式。SDL_image 是官方扩展库，提供多种图像格式的加载支持。本讲介绍 SDL_image 的初始化、图像加载、格式支持等。

### 原理

**SDL_image 的作用**：SDL_image 在 SDL_Surface 之上封装了多种图像解码器（libpng、libjpeg、libwebp 等），将文件解码为 `SDL_Surface`，再由开发者转换为 `SDL_Texture`。它屏蔽了不同图像格式的解码细节。

**初始化与退出**：SDL_image 2.0 使用 `IMG_Init(flags)` 初始化，flags 指定支持的格式：
- `IMG_INIT_JPG`：JPEG
- `IMG_INIT_PNG`：PNG
- `IMG_INIT_TIF`：TIFF
- `IMG_INIT_WEBP`：WEBP

可以按位或组合。`IMG_Quit()` 退出。返回值是实际初始化的格式掩码，可能少于请求（如系统未安装 libpng）。

**加载函数**：
- `IMG_Load(path)`：从文件加载，返回 `SDL_Surface*`
- `IMG_Load_RW(rwops, freesrc)`：从 `SDL_RWops` 加载（内存、网络等）
- `IMG_LoadTexture(renderer, path)`：一步到位加载为纹理（推荐）
- `IMG_LoadTexture_RW(renderer, rwops, freesrc)`：从 RWops 加载纹理

**PNG 的优势**：PNG 支持透明通道（Alpha），是游戏开发的首选格式。BMP 不支持透明，JPG 是有损压缩不适合像素艺术。WEBP 兼具高压缩比和无损模式，是现代选择。

**纹理缓存**：实际项目中应建立纹理缓存，避免重复加载同一文件。每次 `IMG_LoadTexture` 都会读取磁盘并解码，频繁加载会严重影响性能。

### 例子

```c
#include <SDL2/SDL.h>
#include <SDL2/SDL_image.h>
#include <stdio.h>

/* 通用纹理加载函数（带错误检查） */
SDL_Texture* LoadTexture(SDL_Renderer* renderer, const char* path) {
    SDL_Texture* texture = IMG_LoadTexture(renderer, path);
    if (!texture) {
        printf("加载 %s 失败: %s\n", path, IMG_GetError());
    }
    return texture;
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);

    /* 初始化 SDL_image，支持 PNG 和 JPG */
    int img_flags = IMG_INIT_PNG | IMG_INIT_JPG;
    if ((IMG_Init(img_flags) & img_flags) != img_flags) {
        printf("SDL_image 初始化失败: %s\n", IMG_GetError());
        SDL_Quit();
        return 1;
    }
    printf("SDL_image 初始化成功\n");

    SDL_Window* window = SDL_CreateWindow(
        "SDL_image 示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(
        window, -1, SDL_RENDERER_ACCELERATED
    );

    /* 加载 PNG 纹理（需要准备一个带透明通道的 PNG） */
    SDL_Texture* png_tex = LoadTexture(renderer, "sprite.png");
    /* 加载 JPG 纹理（背景图） */
    SDL_Texture* jpg_tex = LoadTexture(renderer, "background.jpg");

    int png_w = 0, png_h = 0;
    if (png_tex) {
        SDL_QueryTexture(png_tex, NULL, NULL, &png_w, &png_h);
        printf("PNG 纹理尺寸: %dx%d\n", png_w, png_h);
    }

    /* 演示从内存加载（模拟） */
    /* 实际场景：从压缩包、网络下载的数据加载 */
    /*
    SDL_RWops* rw = SDL_RWFromMem(data, size);
    SDL_Texture* mem_tex = IMG_LoadTexture_RW(renderer, rw, 1);
    */

    SDL_bool running = SDL_TRUE;
    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
        }

        SDL_SetRenderDrawColor(renderer, 50, 50, 50, 255);
        SDL_RenderClear(renderer);

        /* 绘制背景（拉伸到全屏） */
        if (jpg_tex) {
            SDL_Rect bg_dest = {0, 0, 800, 600};
            SDL_RenderCopy(renderer, jpg_tex, NULL, &bg_dest);
        }

        /* 绘制精灵（带透明通道） */
        if (png_tex) {
            SDL_Rect dest = {350, 250, png_w, png_h};
            SDL_RenderCopy(renderer, png_tex, NULL, &dest);
        }

        SDL_RenderPresent(renderer);
    }

    if (png_tex) SDL_DestroyTexture(png_tex);
    if (jpg_tex) SDL_DestroyTexture(jpg_tex);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    IMG_Quit();
    SDL_Quit();
    return 0;
}
```

**编译命令**（需链接 SDL_image）：

```bash
gcc image_demo.c -o image_demo `sdl2-config --cflags --libs` -lSDL2_image
```

### 总结

- SDL_image 扩展库支持 PNG、JPG、WEBP、TIFF 等多种格式
- 初始化时指定需要的格式，`IMG_Quit` 退出
- `IMG_LoadTexture` 一步加载为纹理，最常用
- PNG 是游戏开发首选格式（支持透明通道）
- 实际项目应建立纹理缓存，避免重复加载
- **常见坑**：忘记 `IMG_Init` 直接调用 `IMG_Load` 会失败；`IMG_GetError()` 而非 `SDL_GetError()` 获取 SDL_image 错误；编译时忘记链接 `-lSDL2_image`

## 第12讲 精灵动画与帧控制

### 概念

精灵动画是 2D 游戏的核心技术。通过快速切换精灵图（spritesheet）中的不同帧，产生动画效果。本讲讲解精灵图的概念、帧切分、动画播放控制等。

### 原理

**精灵图（Spritesheet）**：将一个角色的所有动画帧排列在一张大图上，称为精灵图。相比每帧单独一个文件，精灵图有以下优势：
1. 减少文件数量，便于管理
2. 减少磁盘 I/O（一次读取所有帧）
3. 减少 GPU 纹理切换（同一张纹理只需绑定一次）
4. 提高纹理缓存命中率

**帧切分**：精灵图通常是规则网格，每帧尺寸相同。通过源矩形（src rect）指定当前帧在大图中的位置：
```
src.x = (frame_index % columns) * frame_width
src.y = (frame_index / columns) * frame_height
src.w = frame_width
src.h = frame_height
```

**动画帧率**：动画播放速度独立于渲染帧率。例如角色走路动画 8 FPS，但游戏渲染 60 FPS。实现方式是累积时间，每达到 1/8 秒切换一帧。

**动画状态机**：角色通常有多种动画（站立、走路、跳跃、攻击等），通过状态机管理。每个状态对应精灵图中的一段帧序列，状态切换时跳转到对应序列。

**循环与单向动画**：走路等动画循环播放，攻击等动画播放一次后回到站立状态。需要标记动画是否循环。

### 例子

```c
#include <SDL2/SDL.h>
#include <SDL2/SDL_image.h>
#include <stdio.h>

/* 动画结构体 */
typedef struct {
    SDL_Texture* texture;   /* 精灵图纹理 */
    int frame_width;        /* 单帧宽度 */
    int frame_height;       /* 单帧高度 */
    int frames_per_row;     /* 每行帧数 */
    int total_frames;       /* 总帧数 */
    int current_frame;      /* 当前帧索引 */
    float frame_time;       /* 每帧持续时间（秒） */
    float accumulator;      /* 时间累积器 */
    SDL_bool loop;          /* 是否循环 */
} Animation;

void Animation_Update(Animation* anim, float delta) {
    anim->accumulator += delta;
    while (anim->accumulator >= anim->frame_time) {
        anim->accumulator -= anim->frame_time;
        anim->current_frame++;
        if (anim->current_frame >= anim->total_frames) {
            if (anim->loop) {
                anim->current_frame = 0;
            } else {
                anim->current_frame = anim->total_frames - 1;
            }
        }
    }
}

void Animation_Draw(Animation* anim, SDL_Renderer* renderer, int x, int y) {
    SDL_Rect src = {
        (anim->current_frame % anim->frames_per_row) * anim->frame_width,
        (anim->current_frame / anim->frames_per_row) * anim->frame_height,
        anim->frame_width,
        anim->frame_height
    };
    SDL_Rect dest = {x, y, anim->frame_width, anim->frame_height};
    SDL_RenderCopy(renderer, anim->texture, &src, &dest);
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    IMG_Init(IMG_INIT_PNG);

    SDL_Window* window = SDL_CreateWindow(
        "精灵动画示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED);

    /* 假设有一个 8x4 的精灵图，每帧 64x64，共 32 帧 */
    /* 实际使用时替换为你的精灵图 */
    SDL_Texture* sheet = IMG_LoadTexture(renderer, "spritesheet.png");
    /* 如果没有图片，创建一个程序生成的精灵图演示 */
    if (!sheet) {
        printf("未找到 spritesheet.png，使用程序生成演示\n");
        sheet = SDL_CreateTexture(renderer, SDL_PIXELFORMAT_RGBA8888,
            SDL_TEXTUREACCESS_TARGET, 512, 256);
        SDL_SetRenderTarget(renderer, sheet);
        SDL_SetRenderDrawColor(renderer, 0, 0, 0, 0);
        SDL_RenderClear(renderer);
        for (int row = 0; row < 4; row++) {
            for (int col = 0; col < 8; col++) {
                SDL_SetRenderDrawColor(renderer,
                    50 + col * 25, 100 + row * 30, 200, 255);
                SDL_Rect r = {col * 64 + 10, row * 64 + 10, 44, 44};
                SDL_RenderFillRect(renderer, &r);
            }
        }
        SDL_SetRenderTarget(renderer, NULL);
    }

    Animation walk_anim = {
        .texture = sheet,
        .frame_width = 64,
        .frame_height = 64,
        .frames_per_row = 8,
        .total_frames = 8,    /* 第一行 8 帧作为走路动画 */
        .current_frame = 0,
        .frame_time = 0.1f,   /* 每帧 0.1 秒 = 10 FPS */
        .accumulator = 0,
        .loop = SDL_TRUE
    };

    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
        }

        /* 更新动画 */
        Animation_Update(&walk_anim, delta);

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 40, 40, 50, 255);
        SDL_RenderClear(renderer);

        /* 在多个位置绘制动画 */
        Animation_Draw(&walk_anim, renderer, 100, 250);
        Animation_Draw(&walk_anim, renderer, 300, 250);
        Animation_Draw(&walk_anim, renderer, 500, 250);

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyTexture(sheet);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    IMG_Quit();
    SDL_Quit();
    return 0;
}
```

### 总结

- 精灵图将所有动画帧放在一张大图，减少文件数和 GPU 状态切换
- 帧切分通过源矩形（src rect）实现，规则网格计算简单
- 动画帧率独立于渲染帧率，通过时间累积器控制
- 动画状态机管理多种动画状态的切换
- 循环动画（走路）和单向动画（攻击）需要不同处理
- **常见坑**：动画累积器应用 `while` 而非 `if`，避免低帧率时动画卡顿；精灵图的帧索引计算注意行列顺序；纹理的 alpha 混合模式需设置为 `SDL_BLENDMODE_BLEND` 才能正确透明

## 第13讲 颜色混合与透明度

### 概念

颜色混合（Blending）决定了纹理如何与背景结合。本讲讲解 SDL2 的混合模式、纹理透明度、颜色调制等，这些是制作特效（淡入淡出、闪烁、染色）的基础。

### 原理

**Alpha 混合原理**：每个像素有 RGBA 四个通道，A（Alpha）表示不透明度（0 完全透明，255 完全不透明）。Alpha 混合公式：
```
result = src * src_alpha + dst * (1 - src_alpha)
```
即源像素按其透明度覆盖目标像素，目标像素保留 (1-alpha) 的比例。

**SDL2 混合模式**：
- `SDL_BLENDMODE_NONE`：无混合，直接覆盖（包括 Alpha 通道）
- `SDL_BLENDMODE_BLEND`：标准 Alpha 混合（最常用）
- `SDL_BLENDMODE_ADD`：加法混合，源像素加到目标上（适合光效、火焰）
- `SDL_BLENDMODE_MOD`：乘法混合，源像素乘以目标（适合阴影、色调调整）
- `SDL_BLENDMODE_MUL`：颜色相乘（SDL 2.0.12+）
- `SDL_BLENDMODE_INVALID`：特殊值

**纹理透明度**：`SDL_SetTextureAlphaMod(texture, alpha)` 设置整个纹理的透明度（0-255）。这是全局透明度，与像素自身的 Alpha 相乘。常用于淡入淡出效果。

**颜色调制**：`SDL_SetTextureColorMod(texture, r, g, b)` 将纹理的每个像素颜色乘以指定值（0-255 归一化为 0.0-1.0）。常用于：
- 染色效果（白色精灵变红色）
- 亮度调节
- 受伤闪烁（红色覆盖）

**混合模式应用场景**：
- 普通精灵：`BLEND` 模式
- 粒子光效、火焰、爆炸：`ADD` 模式
- 阴影、半透明遮罩：`MOD` 模式
- UI 元素淡入淡出：`BLEND` + `AlphaMod`

### 例子

```c
#include <SDL2/SDL.h>
#include <SDL2/SDL_image.h>

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    IMG_Init(IMG_INIT_PNG);

    SDL_Window* window = SDL_CreateWindow(
        "混合模式示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED);

    /* 创建一个白色圆形纹理用于演示 */
    SDL_Texture* circle = SDL_CreateTexture(renderer,
        SDL_PIXELFORMAT_RGBA8888, SDL_TEXTUREACCESS_TARGET, 200, 200);
    SDL_SetRenderTarget(renderer, circle);
    SDL_SetRenderDrawColor(renderer, 0, 0, 0, 0);
    SDL_RenderClear(renderer);
    SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
    /* 绘制圆形（用多个矩形近似） */
    for (int y = -100; y < 100; y++) {
        for (int x = -100; x < 100; x++) {
            if (x * x + y * y < 100 * 100) {
                SDL_RenderDrawPoint(renderer, x + 100, y + 100);
            }
        }
    }
    SDL_SetRenderTarget(renderer, NULL);

    /* 启用 Alpha 混合 */
    SDL_SetTextureBlendMode(circle, SDL_BLENDMODE_BLEND);

    SDL_bool running = SDL_TRUE;
    Uint32 start_time = SDL_GetTicks();

    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
        }

        Uint32 elapsed = SDL_GetTicks() - start_time;
        float t = elapsed / 1000.0f;

        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        /* 1. 普通混合（白色圆） */
        SDL_SetTextureColorMod(circle, 255, 255, 255);
        SDL_SetTextureAlphaMod(circle, 255);
        SDL_SetTextureBlendMode(circle, SDL_BLENDMODE_BLEND);
        SDL_Rect r1 = {50, 200, 150, 150};
        SDL_RenderCopy(renderer, circle, NULL, &r1);

        /* 2. 颜色调制（红色圆） */
        SDL_SetTextureColorMod(circle, 255, 50, 50);
        SDL_Rect r2 = {250, 200, 150, 150};
        SDL_RenderCopy(renderer, circle, NULL, &r2);

        /* 3. 透明度动画（淡入淡出） */
        Uint8 alpha = (Uint8)(128 + 127 * sin(t * 2.0f));
        SDL_SetTextureColorMod(circle, 100, 255, 100);
        SDL_SetTextureAlphaMod(circle, alpha);
        SDL_Rect r3 = {450, 200, 150, 150};
        SDL_RenderCopy(renderer, circle, NULL, &r3);

        /* 4. 加法混合（光效） */
        SDL_SetTextureBlendMode(circle, SDL_BLENDMODE_ADD);
        SDL_SetTextureColorMod(circle, 255, 200, 100);
        SDL_SetTextureAlphaMod(circle, 200);
        SDL_Rect r4 = {650, 200, 150, 150};
        SDL_RenderCopy(renderer, circle, NULL, &r4);

        /* 5. 乘法混合（阴影） */
        SDL_SetTextureBlendMode(circle, SDL_BLENDMODE_MOD);
        SDL_SetTextureColorMod(circle, 100, 100, 100);
        SDL_SetTextureAlphaMod(circle, 255);
        SDL_Rect r5 = {150, 400, 150, 150};
        SDL_RenderCopy(renderer, circle, NULL, &r5);

        /* 6. 旋转的彩色圆 */
        SDL_SetTextureBlendMode(circle, SDL_BLENDMODE_BLEND);
        Uint8 cr = (Uint8)(127 + 127 * sin(t));
        Uint8 cg = (Uint8)(127 + 127 * sin(t + 2.0f));
        Uint8 cb = (Uint8)(127 + 127 * sin(t + 4.0f));
        SDL_SetTextureColorMod(circle, cr, cg, cb);
        SDL_Rect r6 = {450, 400, 150, 150};
        SDL_Point center = {75, 75};
        SDL_RenderCopyEx(renderer, circle, NULL, &r6,
                         t * 90.0f, &center, SDL_FLIP_NONE);

        SDL_RenderPresent(renderer);
        SDL_Delay(16);
    }

    SDL_DestroyTexture(circle);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    IMG_Quit();
    SDL_Quit();
    return 0;
}
```

### 总结

- Alpha 混合公式：`result = src * src_alpha + dst * (1 - src_alpha)`
- SDL2 提供 NONE、BLEND、ADD、MOD、MUL 五种混合模式
- `SDL_SetTextureAlphaMod` 设置全局透明度，用于淡入淡出
- `SDL_SetTextureColorMod` 设置颜色调制，用于染色和亮度调节
- ADD 模式适合光效，MOD 模式适合阴影
- **常见坑**：使用带透明通道的 PNG 必须设置 `SDL_BLENDMODE_BLEND`，否则透明区域会显示为黑色；ColorMod 是乘法而非替换，白色纹理 (255,255,255) 才能精确染色；ADD 模式容易过曝，需控制 Alpha 值

## 第14讲 键盘状态轮询与输入管理

### 概念

第9讲介绍了键盘事件，本讲深入讲解键盘状态轮询机制。事件驱动适合处理单次按键（如跳跃、确认），而状态轮询适合处理持续输入（如移动、转向）。本讲讲解两种模式的区别、输入缓冲、按键映射等高级主题。

### 原理

**事件 vs 状态轮询**：
- 事件（`SDL_KEYDOWN`/`SDL_KEYUP`）：在按键状态变化时触发，适合离散动作（跳跃、开火、确认）
- 状态轮询（`SDL_GetKeyboardState`）：每帧查询当前按键状态，适合连续动作（移动、转向、加速）

**`SDL_GetKeyboardState` 工作原理**：返回一个指向内部键盘状态数组的指针，数组长度为 `SDL_NUM_SCANCODES`。每个元素为 1 表示对应键被按下，0 表示释放。这个数组由 `SDL_PumpEvents()`（在 `SDL_PollEvent` 内部自动调用）更新，因此必须在事件循环后查询。

**输入缓冲与延迟**：操作系统维护一个键盘输入缓冲区，按键事件先进入缓冲区再被应用程序取出。如果应用程序处理事件慢，缓冲区会积压事件，导致输入延迟。解决方法是每帧用 `while(SDL_PollEvent)` 清空所有积压事件。

**按键映射**：游戏应支持自定义按键映射。实现方式是定义逻辑动作（如 ACTION_JUMP、ACTION_MOVE_LEFT），通过配置文件将物理按键映射到逻辑动作。这样玩家可以自定义控制方案，也便于支持手柄等不同设备。

**修饰键处理**：`SDL_GetModState()` 返回当前修饰键状态（Ctrl、Shift、Alt、CapsLock 等）。注意区分左右修饰键（如 `KMOD_LCTRL` vs `KMOD_RCTRL`）。

**按键去抖动**：物理按键在按下/释放瞬间会有机械抖动，可能产生多次事件。SDL2 内部已处理硬件去抖动，但游戏逻辑可能需要软件去抖动（如攻击键的连击间隔限制）。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>

/* 逻辑动作定义 */
typedef enum {
    ACTION_MOVE_LEFT = 0,
    ACTION_MOVE_RIGHT,
    ACTION_MOVE_UP,
    ACTION_MOVE_DOWN,
    ACTION_JUMP,
    ACTION_FIRE,
    ACTION_COUNT
} Action;

/* 按键映射配置 */
typedef struct {
    SDL_Scancode scancodes[ACTION_COUNT];
    int pressed[ACTION_COUNT];      /* 当前是否按下 */
    int just_pressed[ACTION_COUNT]; /* 本帧刚按下 */
    int just_released[ACTION_COUNT];/* 本帧刚释放 */
} InputState;

void InputState_Init(InputState* state) {
    /* 默认按键映射 */
    state->scancodes[ACTION_MOVE_LEFT]  = SDL_SCANCODE_A;
    state->scancodes[ACTION_MOVE_RIGHT] = SDL_SCANCODE_D;
    state->scancodes[ACTION_MOVE_UP]    = SDL_SCANCODE_W;
    state->scancodes[ACTION_MOVE_DOWN]  = SDL_SCANCODE_S;
    state->scancodes[ACTION_JUMP]       = SDL_SCANCODE_SPACE;
    state->scancodes[ACTION_FIRE]       = SDL_SCANCODE_J;

    for (int i = 0; i < ACTION_COUNT; i++) {
        state->pressed[i] = 0;
        state->just_pressed[i] = 0;
        state->just_released[i] = 0;
    }
}

/* 每帧开始时调用，重置 just_pressed/just_released */
void InputState_PreUpdate(InputState* state) {
    for (int i = 0; i < ACTION_COUNT; i++) {
        state->just_pressed[i] = 0;
        state->just_released[i] = 0;
    }
}

/* 处理键盘事件，更新 just_pressed/just_released */
void InputState_HandleEvent(InputState* state, const SDL_Event* event) {
    if (event->type != SDL_KEYDOWN && event->type != SDL_KEYUP) return;
    if (event->key.repeat) return;  /* 忽略自动重复 */

    SDL_Scancode sc = event->key.keysym.scancode;
    for (int i = 0; i < ACTION_COUNT; i++) {
        if (state->scancodes[i] == sc) {
            if (event->type == SDL_KEYDOWN && !state->pressed[i]) {
                state->pressed[i] = 1;
                state->just_pressed[i] = 1;
            } else if (event->type == SDL_KEYUP) {
                state->pressed[i] = 0;
                state->just_released[i] = 1;
            }
        }
    }
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    SDL_Window* window = SDL_CreateWindow(
        "输入管理示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    InputState input;
    InputState_Init(&input);

    float px = 400, py = 300;
    float speed = 300.0f;
    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        float delta = (current_time - last_time) / 1000.0f;
        last_time = current_time;

        /* 1. 重置本帧状态 */
        InputState_PreUpdate(&input);

        /* 2. 处理事件 */
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
            InputState_HandleEvent(&input, &event);
        }

        /* 3. 使用输入状态更新逻辑 */
        /* 持续移动（状态轮询） */
        if (input.pressed[ACTION_MOVE_LEFT])  px -= speed * delta;
        if (input.pressed[ACTION_MOVE_RIGHT]) px += speed * delta;
        if (input.pressed[ACTION_MOVE_UP])    py -= speed * delta;
        if (input.pressed[ACTION_MOVE_DOWN])  py += speed * delta;

        /* 单次动作（事件触发） */
        if (input.just_pressed[ACTION_JUMP]) {
            printf("跳跃！\n");
        }
        if (input.just_pressed[ACTION_FIRE]) {
            printf("开火！\n");
        }
        if (input.just_released[ACTION_FIRE]) {
            printf("停止开火\n");
        }

        /* 边界限制 */
        if (px < 0) px = 0; if (px > 780) px = 780;
        if (py < 0) py = 0; if (py > 580) py = 580;

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);

        /* 玩家颜色根据开火状态变化 */
        SDL_SetRenderDrawColor(renderer,
            input.pressed[ACTION_FIRE] ? 255 : 100,
            180, 255, 255);
        SDL_Rect player = { (int)px, (int)py, 20, 20 };
        SDL_RenderFillRect(renderer, &player);

        /* 显示当前按下的键 */
        SDL_SetRenderDrawColor(renderer, 200, 200, 200, 255);
        int indicator_y = 550;
        const char* names[] = {"L", "R", "U", "D", "J", "F"};
        for (int i = 0; i < ACTION_COUNT; i++) {
            if (input.pressed[i]) {
                SDL_Rect ind = {10 + i * 30, indicator_y, 25, 25};
                SDL_RenderFillRect(renderer, &ind);
            }
        }

        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 事件适合离散动作（跳跃、确认），状态轮询适合连续动作（移动、转向）
- `SDL_GetKeyboardState` 返回内部数组指针，由 `SDL_PumpEvents` 更新
- 推荐使用逻辑动作抽象，支持自定义按键映射
- `just_pressed`/`just_released` 模式用于检测本帧的按键变化
- 修饰键通过 `SDL_GetModState` 查询
- **常见坑**：`SDL_GetKeyboardState` 必须在 `SDL_PollEvent` 之后调用，否则状态未更新；自动重复事件（`event.key.repeat`）应过滤，避免单次按键被多次触发

## 第15讲 鼠标与触摸输入

### 概念

鼠标和触摸是图形界面的主要交互方式。本讲讲解鼠标状态查询、光标管理、触摸事件处理，以及如何编写同时支持鼠标和触摸的跨平台代码。

### 原理

**鼠标状态查询**：`SDL_GetMouseState(&x, &y)` 返回当前鼠标位置和按钮状态（位掩码）。`SDL_GetGlobalMouseState` 获取全屏坐标（跨窗口）。`SDL_BUTTON(button)` 宏检查指定按钮是否按下。

**鼠标光标管理**：
- `SDL_ShowCursor(SDL_ENABLE/DISABLE)`：显示/隐藏系统光标
- `SDL_CreateCursor`：从位图创建自定义光标
- `SDL_CreateColorCursor`：从 Surface 创建彩色光标
- `SDL_SetCursor`：设置当前光标
- `SDL_FreeCursor`：释放光标

**触摸事件**：
- `SDL_FINGERDOWN`：手指按下
- `SDL_FINGERUP`：手指释放
- `SDL_FINGERMOTION`：手指移动

触摸事件使用归一化坐标（0.0-1.0），通过 `event.tfinger.x/y` 获取，`event.tfinger.fingerId` 标识手指。多触点通过不同的 fingerId 区分。

**鼠标与触摸的统一**：桌面平台产生鼠标事件，移动平台产生触摸事件。跨平台代码应同时处理两种事件，或将触摸转换为鼠标事件。SDL2 提供 `SDL_TOUCH_MOUSEID` 常量标识由触摸产生的模拟鼠标事件。

**相对鼠标模式**：`SDL_SetRelativeMouseMode(SDL_TRUE)` 锁定鼠标，只产生相对位移（`event.motion.xrel/yrel`），适合 3D 视角控制。`SDL_GetRelativeMouseState` 获取相对位移和按钮状态。

**拖拽实现**：记录鼠标按下时的位置和当前是否处于拖拽状态，鼠标移动时如果处于拖拽状态则更新对象位置，鼠标释放时结束拖拽。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>

#define MAX_FINGERS 10

typedef struct {
    int active;
    float x, y;        /* 归一化坐标 0-1 */
    int pixel_x, pixel_y;
} Finger;

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);

    SDL_Window* window = SDL_CreateWindow(
        "鼠标与触摸示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    /* 检查触摸设备 */
    int num_touch = SDL_GetNumTouchDevices();
    printf("检测到 %d 个触摸设备\n", num_touch);

    Finger fingers[MAX_FINGERS] = {0};

    /* 拖拽对象 */
    SDL_Rect drag_rect = {350, 250, 100, 100};
    SDL_bool dragging = SDL_FALSE;
    int drag_offset_x, drag_offset_y;

    SDL_bool running = SDL_TRUE;
    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            switch (event.type) {
            case SDL_QUIT:
                running = SDL_FALSE;
                break;

            case SDL_MOUSEBUTTONDOWN:
                if (event.button.button == SDL_BUTTON_LEFT) {
                    int mx = event.button.x, my = event.button.y;
                    /* 检查是否点击在矩形内 */
                    if (mx >= drag_rect.x && mx < drag_rect.x + drag_rect.w &&
                        my >= drag_rect.y && my < drag_rect.y + drag_rect.h) {
                        dragging = SDL_TRUE;
                        drag_offset_x = mx - drag_rect.x;
                        drag_offset_y = my - drag_rect.y;
                        printf("开始拖拽\n");
                    }
                }
                break;

            case SDL_MOUSEBUTTONUP:
                if (event.button.button == SDL_BUTTON_LEFT && dragging) {
                    dragging = SDL_FALSE;
                    printf("结束拖拽\n");
                }
                break;

            case SDL_MOUSEMOTION:
                if (dragging) {
                    drag_rect.x = event.motion.x - drag_offset_x;
                    drag_rect.y = event.motion.y - drag_offset_y;
                }
                break;

            case SDL_FINGERDOWN:
                if (event.tfinger.fingerId < MAX_FINGERS) {
                    int idx = (int)event.tfinger.fingerId;
                    fingers[idx].active = 1;
                    fingers[idx].x = event.tfinger.x;
                    fingers[idx].y = event.tfinger.y;
                    fingers[idx].pixel_x = (int)(event.tfinger.x * 800);
                    fingers[idx].pixel_y = (int)(event.tfinger.y * 600);
                    printf("手指 %d 按下: (%.2f, %.2f)\n",
                           idx, event.tfinger.x, event.tfinger.y);
                }
                break;

            case SDL_FINGERUP:
                if (event.tfinger.fingerId < MAX_FINGERS) {
                    fingers[(int)event.tfinger.fingerId].active = 0;
                }
                break;

            case SDL_FINGERMOTION:
                if (event.tfinger.fingerId < MAX_FINGERS) {
                    int idx = (int)event.tfinger.fingerId;
                    fingers[idx].x = event.tfinger.x;
                    fingers[idx].y = event.tfinger.y;
                    fingers[idx].pixel_x = (int)(event.tfinger.x * 800);
                    fingers[idx].pixel_y = (int)(event.tfinger.y * 600);
                }
                break;
            }
        }

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);

        /* 绘制可拖拽矩形 */
        SDL_SetRenderDrawColor(renderer,
            dragging ? 255 : 100, 180, 255, 255);
        SDL_RenderFillRect(renderer, &drag_rect);

        /* 绘制鼠标位置（十字光标） */
        int mx, my;
        Uint32 mouse_state = SDL_GetMouseState(&mx, &my);
        SDL_SetRenderDrawColor(renderer, 255, 255, 100, 255);
        SDL_RenderDrawLine(renderer, mx - 10, my, mx + 10, my);
        SDL_RenderDrawLine(renderer, mx, my - 10, mx, my + 10);

        /* 显示鼠标按钮状态 */
        if (mouse_state & SDL_BUTTON(SDL_BUTTON_LEFT)) {
            SDL_SetRenderDrawColor(renderer, 100, 255, 100, 255);
            SDL_Rect lbtn = {mx - 5, my - 5, 10, 10};
            SDL_RenderFillRect(renderer, &lbtn);
        }

        /* 绘制触摸点 */
        for (int i = 0; i < MAX_FINGERS; i++) {
            if (fingers[i].active) {
                SDL_SetRenderDrawColor(renderer, 255, 100, 255, 200);
                SDL_Rect f = {fingers[i].pixel_x - 20,
                              fingers[i].pixel_y - 20, 40, 40};
                SDL_RenderFillRect(renderer, &f);
            }
        }

        SDL_RenderPresent(renderer);
        SDL_Delay(16);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- `SDL_GetMouseState` 查询鼠标位置和按钮状态，`SDL_BUTTON` 宏检查按钮
- 触摸事件使用归一化坐标（0-1），通过 fingerId 区分多触点
- 跨平台代码应同时处理鼠标和触摸事件
- 拖拽实现：记录按下位置和偏移量，移动时更新对象位置
- `SDL_SetRelativeMouseMode` 用于 3D 视角控制
- **常见坑**：触摸坐标是归一化的，必须乘以窗口尺寸转换为像素坐标；触摸的 fingerId 是 SDL_FingerID 类型，直接用作数组索引需确保范围；移动平台默认不产生鼠标事件，需通过 `SDL_TOUCH_MOUSEID` 处理

## 第16讲 游戏手柄与控制器

### 概念

游戏手柄是游戏体验的重要组成部分。SDL2 区分"摇杆"（Joystick，原始设备）和"控制器"（GameController，标准化映射）。本讲讲解控制器的初始化、连接、输入处理，以及控制器映射的概念。

### 原理

**摇杆 vs 控制器**：
- 摇杆（Joystick）：直接暴露设备的原始轴和按钮，不同手柄的按钮编号不同，需要为每种手柄编写适配代码
- 控制器（GameController）：基于 SDL2 内置的映射数据库，将不同手柄的输入标准化为统一布局（A/B/X/Y、左摇杆、右摇杆、肩键等），开发者只需处理标准布局

**控制器布局**：SDL2 定义了标准控制器布局：
- 按钮：A、B、X、Y、Back、Guide、Start、左肩键、右肩键、左摇杆按下、右摇杆按下、方向键
- 轴：左摇杆 X/Y、右摇杆 X/Y、左扳机、右扳机

**控制器映射数据库**：SDL2 内置 `gamecontrollerdb.txt` 映射数据库，包含常见手柄的映射。`SDL_GameControllerAddMapping` 可添加自定义映射。Steam 平台会自动为连接的手柄生成映射。

**轴值范围**：摇杆轴值是 Sint16 类型，范围 -32768 到 32767。中心位置可能不是精确的 0（硬件漂移），需要设置死区（deadzone）过滤小幅度输入。扳机轴范围是 0 到 32767。

**热插拔支持**：SDL2 支持控制器热插拔，通过 `SDL_CONTROLLERDEVICEADDED` 和 `SDL_CONTROLLERDEVICEREMOVED` 事件通知。无需重启程序即可响应设备连接/断开。

**力反馈**：`SDL_Haptic` 子系统支持力反馈（震动）。`SDL_GameControllerRumble`（SDL 2.0.9+）提供简化的震动接口。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>

#define DEADZONE 8000  /* 摇杆死区 */

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO | SDL_INIT_GAMECONTROLLER);

    SDL_Window* window = SDL_CreateWindow(
        "控制器示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    /* 查询已连接的控制器数量 */
    int num_joysticks = SDL_NumJoysticks();
    printf("检测到 %d 个摇杆设备\n", num_joysticks);
    for (int i = 0; i < num_joysticks; i++) {
        if (SDL_IsGameController(i)) {
            printf("  设备 %d 是控制器: %s\n",
                   i, SDL_GameControllerNameForIndex(i));
        } else {
            printf("  设备 %d 是摇杆: %s\n",
                   i, SDL_JoystickNameForIndex(i));
        }
    }

    SDL_GameController* controller = NULL;
    /* 尝试打开第一个控制器 */
    for (int i = 0; i < num_joysticks; i++) {
        if (SDL_IsGameController(i)) {
            controller = SDL_GameControllerOpen(i);
            if (controller) {
                printf("已打开控制器: %s\n",
                       SDL_GameControllerName(controller));
                break;
            }
        }
    }

    float px = 400, py = 300;
    SDL_bool running = SDL_TRUE;

    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            switch (event.type) {
            case SDL_QUIT:
                running = SDL_FALSE;
                break;

            case SDL_CONTROLLERDEVICEADDED:
                if (!controller) {
                    controller = SDL_GameControllerOpen(
                        event.cdevice.which);
                    printf("控制器已连接: %s\n",
                        controller ? SDL_GameControllerName(controller) : "未知");
                }
                break;

            case SDL_CONTROLLERDEVICEREMOVED:
                if (controller && event.cdevice.which ==
                    SDL_JoystickInstanceID(
                        SDL_GameControllerGetJoystick(controller))) {
                    SDL_GameControllerClose(controller);
                    controller = NULL;
                    printf("控制器已断开\n");
                }
                break;

            case SDL_CONTROLLERBUTTONDOWN:
                printf("按钮按下: %d\n", event.cbutton.button);
                if (event.cbutton.button ==
                    SDL_CONTROLLER_BUTTON_START) {
                    /* Start 按钮震动测试 */
                    if (controller) {
                        SDL_GameControllerRumble(controller,
                            0xFFFF, 0xFFFF, 500);
                    }
                }
                if (event.cbutton.button ==
                    SDL_CONTROLLER_BUTTON_BACK) {
                    running = SDL_FALSE;
                }
                break;

            case SDL_CONTROLLERBUTTONUP:
                printf("按钮释放: %d\n", event.cbutton.button);
                break;
            }
        }

        /* 轮询摇杆轴状态 */
        if (controller) {
            Sint16 left_x = SDL_GameControllerGetAxis(controller,
                SDL_CONTROLLER_AXIS_LEFTX);
            Sint16 left_y = SDL_GameControllerGetAxis(controller,
                SDL_CONTROLLER_AXIS_LEFTY);

            /* 应用死区 */
            float move_x = 0, move_y = 0;
            if (abs(left_x) > DEADZONE) {
                move_x = left_x / 32767.0f;
            }
            if (abs(left_y) > DEADZONE) {
                move_y = left_y / 32767.0f;
            }

            /* 更新位置 */
            float speed = 300.0f;
            px += move_x * speed * (1.0f / 60.0f);
            py += move_y * speed * (1.0f / 60.0f);

            if (px < 0) px = 0; if (px > 780) px = 780;
            if (py < 0) py = 0; if (py > 580) py = 580;

            /* 右扳机控制震动强度 */
            Sint16 right_trigger = SDL_GameControllerGetAxis(controller,
                SDL_CONTROLLER_AXIS_TRIGGERRIGHT);
            if (right_trigger > 0) {
                SDL_GameControllerRumble(controller,
                    (Uint16)right_trigger, 0, 100);
            }
        }

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);

        SDL_SetRenderDrawColor(renderer, 100, 180, 255, 255);
        SDL_Rect player = { (int)px, (int)py, 20, 20 };
        SDL_RenderFillRect(renderer, &player);

        /* 显示控制器状态 */
        if (controller) {
            SDL_SetRenderDrawColor(renderer, 100, 255, 100, 255);
            SDL_Rect status = {10, 10, 100, 20};
            SDL_RenderFillRect(renderer, &status);
        } else {
            SDL_SetRenderDrawColor(renderer, 255, 100, 100, 255);
            SDL_Rect status = {10, 10, 100, 20};
            SDL_RenderFillRect(renderer, &status);
        }

        SDL_RenderPresent(renderer);
        SDL_Delay(16);
    }

    if (controller) SDL_GameControllerClose(controller);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 优先使用 GameController API（标准化布局），而非 Joystick API（原始设备）
- 控制器布局：A/B/X/Y 按钮、双摇杆、肩键、扳机、方向键
- 摇杆轴值范围 -32768 到 32767，需设置死区过滤漂移
- 支持热插拔：处理 `CONTROLLERDEVICEADDED`/`REMOVED` 事件
- `SDL_GameControllerRumble` 提供震动反馈（SDL 2.0.9+）
- **常见坑**：摇杆中心可能不是精确 0，必须设置死区；不同平台的手柄映射可能不同，测试时需覆盖常见设备；扳机轴范围是 0-32767（非负），与摇杆轴不同

## 第17讲 SDL_ttf 文字渲染

### 概念

SDL2 核心库不提供文字渲染功能，SDL_ttf 是官方扩展库，支持 TrueType 字体渲染。本讲讲解 SDL_ttf 的初始化、字体加载、文字渲染（实心、着色、混合、包裹），以及文字纹理的缓存优化。

### 原理

**TrueType 字体原理**：TrueType 字体是矢量字体，通过数学曲线描述字符轮廓。渲染时根据字号将曲线光栅化为像素位图。优点是任意缩放不失真，缺点是渲染计算量大。

**SDL_ttf 渲染流程**：
1. `TTF_Init()` 初始化
2. `TTF_OpenFont(path, size)` 加载字体文件，指定字号
3. `TTF_RenderText_*()` 将文字渲染为 `SDL_Surface`
4. `SDL_CreateTextureFromSurface()` 转换为纹理
5. `SDL_RenderCopy()` 绘制

**四种渲染模式**：
- `TTF_RenderText_Solid`：最快，无抗锯齿，质量差
- `TTF_RenderText_Shaded`：抗锯齿，有背景色（不透明）
- `TTF_RenderText_Blended`：抗锯齿，透明背景（最常用，质量最好）
- `TTF_RenderText_LCD`：LCD 子像素优化（SDL_ttf 2.0.15+）

**性能优化**：文字渲染是昂贵操作（光栅化 + 纹理上传）。每帧重新渲染动态文字会严重影响性能。优化策略：
1. **静态文字缓存**：菜单标题、按钮文字等不变的内容，渲染一次缓存纹理
2. **动态文字节流**：FPS 显示等频繁变化的文字，限制更新频率（如每 0.5 秒更新一次）
3. **文字图集**：将所有字符预渲染到一张大纹理，绘制时按字符切分（类似精灵图）

**字体度量**：`TTF_SizeText` 计算文字尺寸，`TTF_FontAscent`/`TTF_FontDescent` 获取字体上下沿，`TTF_FontLineSkip` 获取行间距。用于精确的文字布局。

**包裹文字**：`TTF_RenderText_Blended_Wrapped` 支持自动换行，指定最大宽度后自动在单词边界换行。

### 例子

```c
#include <SDL2/SDL.h>
#include <SDL2/SDL_ttf.h>
#include <stdio.h>
#include <string.h>

/* 文字纹理缓存结构 */
typedef struct {
    SDL_Texture* texture;
    int width;
    int height;
} TextTexture;

/* 渲染文字为纹理 */
TextTexture RenderText(SDL_Renderer* renderer, TTF_Font* font,
                       const char* text, SDL_Color color) {
    TextTexture result = {NULL, 0, 0};
    SDL_Surface* surface = TTF_RenderText_Blended(font, text, color);
    if (surface) {
        result.texture = SDL_CreateTextureFromSurface(renderer, surface);
        result.width = surface->w;
        result.height = surface->h;
        SDL_FreeSurface(surface);
    }
    return result;
}

void FreeTextTexture(TextTexture* tt) {
    if (tt->texture) {
        SDL_DestroyTexture(tt->texture);
        tt->texture = NULL;
    }
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    if (TTF_Init() != 0) {
        printf("TTF_Init 失败: %s\n", TTF_GetError());
        return 1;
    }

    SDL_Window* window = SDL_CreateWindow(
        "文字渲染示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED);

    /* 加载字体（需要准备字体文件，如 Arial.ttf） */
    TTF_Font* font_large = TTF_OpenFont("/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf", 48);
    TTF_Font* font_medium = TTF_OpenFont("/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf", 24);
    TTF_Font* font_small = TTF_OpenFont("/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf", 16);

    if (!font_large) {
        printf("字体加载失败: %s\n", TTF_GetError());
        /* 尝试其他路径 */
        font_large = TTF_OpenFont("arial.ttf", 48);
        font_medium = TTF_OpenFont("arial.ttf", 24);
        font_small = TTF_OpenFont("arial.ttf", 16);
    }

    /* 预渲染静态文字 */
    TextTexture title = {NULL, 0, 0};
    TextTexture hint = {NULL, 0, 0};
    if (font_large) {
        title = RenderText(renderer, font_large, "SDL2 文字渲染",
                          (SDL_Color){255, 255, 255, 255});
    }
    if (font_small) {
        hint = RenderText(renderer, font_small, "按 ESC 退出，空格切换颜色",
                         (SDL_Color){180, 180, 180, 255});
    }

    /* 动态文字（FPS）缓存 */
    TextTexture fps_text = {NULL, 0, 0};
    char fps_str[32];
    int frame_count = 0;
    Uint32 fps_timer = SDL_GetTicks();
    int current_fps = 0;

    SDL_bool running = SDL_TRUE;
    SDL_Color dynamic_color = {100, 200, 255, 255};
    SDL_bool color_toggle = SDL_FALSE;

    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN) {
                if (event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                    running = SDL_FALSE;
                if (event.key.keysym.scancode == SDL_SCANCODE_SPACE) {
                    color_toggle = !color_toggle;
                    dynamic_color = color_toggle ?
                        (SDL_Color){255, 200, 100, 255} :
                        (SDL_Color){100, 200, 255, 255};
                }
            }
        }

        /* FPS 计算（每秒更新一次） */
        frame_count++;
        Uint32 now = SDL_GetTicks();
        if (now - fps_timer >= 500) {  /* 每 0.5 秒更新 */
            current_fps = frame_count * 1000 / (now - fps_timer);
            frame_count = 0;
            fps_timer = now;
            /* 重新渲染 FPS 文字 */
            FreeTextTexture(&fps_text);
            if (font_medium) {
                sprintf(fps_str, "FPS: %d", current_fps);
                fps_text = RenderText(renderer, font_medium, fps_str,
                                     (SDL_Color){255, 255, 100, 255});
            }
        }

        if (title.texture) {
            SDL_Rect dest = {400 - title.width / 2, 50,
                            title.width, title.height};
            SDL_RenderCopy(renderer, title.texture, NULL, &dest);
        }

        /* 绘制 FPS */
        if (fps_text.texture) {
            SDL_Rect dest = {10, 10, fps_text.width, fps_text.height};
            SDL_RenderCopy(renderer, fps_text.texture, NULL, &dest);
        }

        /* 绘制动态颜色文字 */
        if (font_medium) {

                                dyn.width, dyn.height};
                SDL_RenderCopy(renderer, dyn.texture, NULL, &dest);

            SDL_Rect dest = {400 - hint.width / 2, 550,
                            hint.width, hint.height};
            SDL_RenderCopy(renderer, hint.texture, NULL, &dest);

    if (font_medium) TTF_CloseFont(font_medium);
    if (font_small) TTF_CloseFont(font_small);

    SDL_DestroyWindow(window);
    TTF_Quit();
    SDL_Quit();
```

## 第18讲 SDL_mixer 音频播放

### 概念

SDL2 核心库提供底层音频 API，但使用复杂。SDL_mixer 是高层音频库，简化了音效和音乐的播放。本讲讲解 SDL_mixer 的初始化、音频格式、音效（Chunk）和音乐（Music）的加载与播放。

### 原理

**SDL_mixer 的抽象层次**：SDL2 原生音频 API 要求开发者手动管理音频缓冲区、回调函数、混音逻辑。SDL_mixer 在此之上提供高层抽象：
- **音效（Chunk）**：短音频，整体加载到内存，支持多通道同时播放、混音
- **音乐（Music）**：长音频，流式播放（不全部加载到内存），同一时间只能播放一首

**音频格式基础**：
- 采样率（Frequency）：每秒采样次数，常见 44100Hz、48000Hz
- 格式（Format）：每个采样的位深，如 AUDIO_S16SYS（16 位有符号）
- 声道数（Channels）：1（单声道）或 2（立体声）
- 块大小（Chunksize）：每次传给音频设备的样本数，影响延迟

**初始化参数**：`Mix_OpenAudio(frequency, format, channels, chunksize)` 初始化音频设备。常用配置：44100Hz, AUDIO_S16SYS, 2 声道, 2048 样本。

**支持的格式**：SDL_mixer 支持多种格式，通过编译时选项决定：
- 音效：WAV、AIFF、VOC、OGG、MP3、FLAC
- 音乐：MOD、MIDI、MP3、OGG、FLAC、WAV

**音效通道**：SDL_mixer 支持多通道同时播放音效（默认 8 个）。`Mix_PlayChannel(channel, chunk, loops)` 在指定通道播放，`channel = -1` 自动选择空闲通道。每个通道可独立设置音量。

**混音原理**：SDL_mixer 内部维护一个混音器，将所有正在播放的通道的音频数据相加，再输出到音频设备。音量控制通过乘以系数实现。

### 例子

```c
#include <SDL2/SDL.h>
#include <SDL2/SDL_mixer.h>
#include <stdio.h>

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO | SDL_INIT_AUDIO);

    SDL_Window* window = SDL_CreateWindow(
        "音频示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    /* 初始化 SDL_mixer */
    if (Mix_OpenAudio(44100, MIX_DEFAULT_FORMAT, 2, 2048) < 0) {
        printf("Mix_OpenAudio 失败: %s\n", Mix_GetError());
        return 1;
    }
    printf("SDL_mixer 初始化成功\n");

    /* 查询音频格式 */
    int freq, channels;
    Uint16 format;
    Mix_QuerySpec(&freq, &format, &channels);
    printf("音频格式: %dHz, %d-bit, %d 声道\n",
           freq, format & 0xFF, channels);

    /* 分配 16 个音效通道 */
    Mix_AllocateChannels(16);

    /* 加载音效（需要准备 sound.wav） */
    Mix_Chunk* sound = Mix_LoadWAV("sound.wav");
    if (!sound) {
        printf("音效加载失败（正常，无文件）: %s\n", Mix_GetError());
    } else {
        printf("音效加载成功\n");
    }

    /* 加载音乐（需要准备 music.ogg） */
    Mix_Music* music = Mix_LoadMUS("music.ogg");
    if (!music) {
        printf("音乐加载失败（正常，无文件）: %s\n", Mix_GetError());
    } else {
        printf("音乐加载成功\n");
    }

    /* 设置音量（0-128） */
    if (sound) Mix_VolumeChunk(sound, 64);  /* 音效音量 */
    Mix_VolumeMusic(64);                     /* 音乐音量 */

    SDL_bool running = SDL_TRUE;
    SDL_bool music_playing = SDL_FALSE;

    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN) {
                switch (event.key.keysym.scancode) {
                case SDL_SCANCODE_ESCAPE:
                    running = SDL_FALSE;
                    break;

                case SDL_SCANCODE_1:
                    /* 播放音效 */
                    if (sound) {
                        int channel = Mix_PlayChannel(-1, sound, 0);
                        printf("音效在通道 %d 播放\n", channel);
                    }
                    break;

                case SDL_SCANCODE_2:
                    /* 播放音效 3 次 */
                    if (sound) {
                        Mix_PlayChannel(-1, sound, 2);  /* loops=2 表示播放 3 次 */
                    }
                    break;

                case SDL_SCANCODE_3:
                    /* 播放音乐 */
                    if (music && !music_playing) {
                        Mix_PlayMusic(music, -1);  /* -1 表示循环 */
                        music_playing = SDL_TRUE;
                        printf("音乐开始播放\n");
                    }
                    break;

                case SDL_SCANCODE_4:
                    /* 暂停/恢复音乐 */
                    if (music_playing) {
                        if (Mix_PausedMusic()) {
                            Mix_ResumeMusic();
                            printf("音乐恢复\n");
                        } else {
                            Mix_PauseMusic();
                            printf("音乐暂停\n");
                        }
                    }
                    break;

                case SDL_SCANCODE_5:
                    /* 停止音乐 */
                    if (music_playing) {
                        Mix_HaltMusic();
                        music_playing = SDL_FALSE;
                        printf("音乐停止\n");
                    }
                    break;

                case SDL_SCANCODE_UP:
                    /* 音量增加 */
                    {
                        int vol = Mix_VolumeMusic(-1);
                        Mix_VolumeMusic(vol + 16 > 128 ? 128 : vol + 16);
                        printf("音乐音量: %d\n", Mix_VolumeMusic(-1));
                    }
                    break;

                case SDL_SCANCODE_DOWN:
                    /* 音量减少 */
                    {
                        int vol = Mix_VolumeMusic(-1);
                        Mix_VolumeMusic(vol - 16 < 0 ? 0 : vol - 16);
                        printf("音乐音量: %d\n", Mix_VolumeMusic(-1));
                    }
                    break;
                }
            }
        }

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);

        /* 显示操作提示（用矩形代替文字，简化） */
        SDL_SetRenderDrawColor(renderer, 100, 180, 255, 255);
        SDL_Rect r1 = {50, 100, 200, 40};
        SDL_RenderFillRect(renderer, &r1);  /* 1: 播放音效 */

        SDL_SetRenderDrawColor(renderer, 100, 255, 100, 255);
        SDL_Rect r2 = {50, 160, 200, 40};
        SDL_RenderFillRect(renderer, &r2);  /* 2: 播放音效3次 */

        SDL_SetRenderDrawColor(renderer, 255, 180, 100, 255);
        SDL_Rect r3 = {50, 220, 200, 40};
        SDL_RenderFillRect(renderer, &r3);  /* 3: 播放音乐 */

        SDL_SetRenderDrawColor(renderer, 255, 100, 100, 255);
        SDL_Rect r4 = {50, 280, 200, 40};
        SDL_RenderFillRect(renderer, &r4);  /* 4: 暂停/恢复 */

        SDL_RenderPresent(renderer);
        SDL_Delay(16);
    }

    /* 清理 */
    if (sound) Mix_FreeChunk(sound);
    if (music) Mix_FreeMusic(music);
    Mix_CloseAudio();
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

```bash
gcc mixer_demo.c -o mixer_demo `sdl2-config --cflags --libs` -lSDL2_mixer
```

### 总结

- SDL_mixer 区分音效（Chunk，短音频，多通道）和音乐（Music，长音频，流式）
- 初始化：`Mix_OpenAudio(44100, MIX_DEFAULT_FORMAT, 2, 2048)`
- 音效通过通道播放，`Mix_PlayChannel(-1, chunk, loops)` 自动选择空闲通道
- 音乐同一时间只能播放一首，`Mix_PlayMusic(music, -1)` 循环播放
- 音量范围 0-128，`Mix_VolumeChunk` 和 `Mix_VolumeMusic` 分别设置
- **常见坑**：忘记 `Mix_OpenAudio` 直接播放无声；`Mix_LoadWAV` 加载失败返回 NULL 但不报错；音乐和音效的 API 不同，不能混用；`loops` 参数 0 表示播放 1 次，-1 表示无限循环

## 第19讲 音效与背景音乐管理

### 概念

本讲讲解实际项目中的音频管理，包括音频资源管理器、3D 音效定位、音频淡入淡出、通道分组等高级功能。掌握这些内容后，你能构建专业的音频系统。

### 原理

**音频资源管理器**：游戏通常有大量音效，需要统一管理。资源管理器负责：
1. 按名称索引音效资源
2. 引用计数（多个对象使用同一音效）
3. 批量加载和卸载
4. 内存预算控制

**3D 音效定位**：2D 游戏中模拟空间音效的方法：
- 根据声源与听者（玩家）的距离调整音量（距离越远音量越低）
- 根据左右相对位置调整立体声平衡（声源在左侧，左声道音量大）
- 距离衰减公式：`volume = max_volume * (1 - distance / max_distance)`

**音频淡入淡出**：`Mix_FadeInChannel` 和 `Mix_FadeInMusic` 支持淡入，`Mix_FadeOutChannel` 和 `Mix_FadeOutMusic` 支持淡出。淡入淡出时间以毫秒为单位，避免声音突变。

**通道分组**：`Mix_GroupChannels` 将多个通道分为一组，`Mix_PlayChannelTimed` 在指定组内播放。常见分组：音效组、语音组、环境音组，便于分别控制音量。

**音频回调**：`Mix_ChannelFinished` 设置通道播放结束回调，用于链式播放（一个音效结束后播放下一个）或状态更新。`Mix_HookMusicFinished` 设置音乐结束回调。

**音频格式转换**：不同音频文件可能有不同格式，SDL_mixer 在加载时自动转换到初始化时指定的格式。如果格式差异大（如采样率不同），转换会消耗 CPU。建议所有音频文件使用统一格式。

### 例子

```c
#include <SDL2/SDL.h>
#include <SDL2/SDL_mixer.h>
#include <stdio.h>
#include <math.h>

/* 音频资源管理器 */
#define MAX_SOUNDS 32

typedef struct {
    char name[32];
    Mix_Chunk* chunk;
} SoundEntry;

typedef struct {
    SoundEntry sounds[MAX_SOUNDS];
    int count;
    int master_volume;
    int sfx_volume;
    int music_volume;
} AudioManager;

void AudioManager_Init(AudioManager* am) {
    am->count = 0;
    am->master_volume = 128;
    am->sfx_volume = 100;
    am->music_volume = 80;
    Mix_AllocateChannels(32);
}

int AudioManager_Load(AudioManager* am, const char* name, const char* path) {
    if (am->count >= MAX_SOUNDS) return -1;
    Mix_Chunk* chunk = Mix_LoadWAV(path);
    if (!chunk) return -1;
    strncpy(am->sounds[am->count].name, name, 31);
    am->sounds[am->count].name[31] = '\0';
    am->sounds[am->count].chunk = chunk;
    return am->count++;
}

int AudioManager_Find(AudioManager* am, const char* name) {
    for (int i = 0; i < am->count; i++) {
        if (strcmp(am->sounds[i].name, name) == 0) return i;
    }
    return -1;
}

void AudioManager_Play(AudioManager* am, const char* name) {
    int idx = AudioManager_Find(am, name);
    if (idx < 0) return;
    /* 应用音量（主音量 * 音效音量 / 128） */
    int vol = am->master_volume * am->sfx_volume / 128;
    Mix_VolumeChunk(am->sounds[idx].chunk, vol);
    Mix_PlayChannel(-1, am->sounds[idx].chunk, 0);
}

/* 3D 音效播放（根据距离和方向） */
void AudioManager_Play3D(AudioManager* am, const char* name,
                         float listener_x, float listener_y,
                         float source_x, float source_y) {
    int idx = AudioManager_Find(am, name);
    if (idx < 0) return;

    float dx = source_x - listener_x;
    float dy = source_y - listener_y;
    float distance = sqrtf(dx * dx + dy * dy);

    /* 距离衰减（最大距离 500） */
    float max_dist = 500.0f;
    float volume_ratio = 1.0f - (distance / max_dist);
    if (volume_ratio < 0) volume_ratio = 0;

    /* 计算立体声平衡（-1 左, 0 中, 1 右） */
    float pan = dx / 500.0f;
    if (pan > 1) pan = 1;
    if (pan < -1) pan = -1;

    /* 应用音量 */
    int vol = (int)(am->master_volume * am->sfx_volume * volume_ratio / 128);
    if (vol < 0) vol = 0;
    if (vol > 128) vol = 128;
    Mix_VolumeChunk(am->sounds[idx].chunk, vol);

    /* 播放（SDL_mixer 不直接支持立体声平衡，需用 Mix_SetPanning） */
    int channel = Mix_PlayChannel(-1, am->sounds[idx].chunk, 0);
    if (channel >= 0) {
        Uint8 left = (Uint8)(255 * (1.0f - pan) / 2);
        Uint8 right = (Uint8)(255 * (1.0f + pan) / 2);
        Mix_SetPanning(channel, left, right);
    }
}

void AudioManager_Cleanup(AudioManager* am) {
    for (int i = 0; i < am->count; i++) {
        if (am->sounds[i].chunk) {
            Mix_FreeChunk(am->sounds[i].chunk);
        }
    }
    am->count = 0;
}

/* 通道播放结束回调 */
void ChannelFinished(int channel) {
    /* 可以在这里触发后续逻辑，如链式播放 */
    /* 注意：此回调在音频线程中执行，不要调用非线程安全函数 */
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO | SDL_INIT_AUDIO);
    Mix_OpenAudio(44100, MIX_DEFAULT_FORMAT, 2, 2048);

    SDL_Window* window = SDL_CreateWindow(
        "音频管理示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    AudioManager am;
    AudioManager_Init(&am);

    /* 设置通道结束回调 */
    Mix_ChannelFinished(ChannelFinished);

    /* 加载音效（实际使用时替换为真实文件） */
    /* AudioManager_Load(&am, "shoot", "shoot.wav"); */
    /* AudioManager_Load(&am, "explosion", "explosion.wav"); */

    /* 演示：创建一个简单的程序生成音效 */
    /* 实际项目中从文件加载 */
    printf("音频管理器已初始化\n");
    printf("操作说明:\n");
    printf("  1 - 播放普通音效（需加载文件）\n");
    printf("  2 - 播放 3D 音效（鼠标位置为声源）\n");
    printf("  3 - 淡入音乐\n");
    printf("  4 - 淡出音乐\n");

    SDL_bool running = SDL_TRUE;
    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN) {
                if (event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                    running = SDL_FALSE;
                if (event.key.keysym.scancode == SDL_SCANCODE_1) {
                    AudioManager_Play(&am, "shoot");
                }
                if (event.key.keysym.scancode == SDL_SCANCODE_2) {
                    int mx, my;
                    SDL_GetMouseState(&mx, &my);
                    AudioManager_Play3D(&am, "explosion", 400, 300, mx, my);
                }
            }
        }

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);

        /* 绘制听者位置（中心） */
        SDL_SetRenderDrawColor(renderer, 100, 255, 100, 255);
        SDL_Rect listener = {395, 295, 10, 10};
        SDL_RenderFillRect(renderer, &listener);

        /* 绘制鼠标位置 */
        int mx, my;
        SDL_GetMouseState(&mx, &my);
        SDL_SetRenderDrawColor(renderer, 255, 100, 100, 255);
        SDL_Rect source = {mx - 5, my - 5, 10, 10};
        SDL_RenderFillRect(renderer, &source);

        SDL_RenderPresent(renderer);
        SDL_Delay(16);
    }

    AudioManager_Cleanup(&am);
    Mix_CloseAudio();
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 音频资源管理器统一管理音效加载、索引、卸载
- 3D 音效通过距离衰减和立体声平衡模拟空间感
- `Mix_FadeInChannel`/`Mix_FadeOutChannel` 实现淡入淡出
- `Mix_SetPanning` 设置立体声平衡，`Mix_SetDistance` 设置距离效果
- 通道回调 `Mix_ChannelFinished` 用于链式播放，但注意在音频线程执行
- **常见坑**：通道回调在音频线程执行，不能调用非线程安全函数（如 SDL 渲染函数）；音量计算注意溢出，先乘后除；3D 音效的距离衰减公式应根据游戏类型调整

## 第20讲 多线程与定时器

### 概念

现代游戏需要多线程处理异步任务（资源加载、网络通信、AI 计算）。本讲讲解 SDL2 的线程 API、互斥锁、条件变量、定时器，以及多线程编程的注意事项。

### 原理

**SDL2 线程 API**：
- `SDL_CreateThread(fn, name, data)`：创建线程，fn 是线程函数，name 用于调试
- `SDL_DetachThread`：分离线程（后台运行，无需 join）
- `SDL_WaitThread`：等待线程结束并获取返回值
- `SDL_GetThreadID`：获取线程 ID
- `SDL_ThreadID`：获取当前线程 ID

**同步原语**：
- `SDL_CreateMutex` / `SDL_DestroyMutex`：互斥锁
- `SDL_LockMutex` / `SDL_UnlockMutex`：加锁/解锁
- `SDL_TryLockMutex`：尝试加锁（非阻塞）
- `SDL_CreateSemaphore` / `SDL_DestroySemaphore`：信号量
- `SDL_SemWait` / `SDL_SemPost` / `SDL_SemValue`：信号量操作
- `SDL_CreateCond` / `SDL_DestroyCond`：条件变量
- `SDL_CondWait` / `SDL_CondSignal` / `SDL_CondBroadcast`：条件变量操作

**原子操作**：`SDL_AtomicAdd`、`SDL_AtomicGet`、`SDL_AtomicSet`、`SDL_AtomicCAS` 提供原子操作，用于无锁编程。

**定时器**：
- `SDL_AddTimer(interval, callback, param)`：添加定时器，返回定时器 ID
- `SDL_RemoveTimer`：移除定时器
- 定时器回调返回下一次触发的间隔（毫秒），返回 0 表示停止

**线程安全注意事项**：
1. SDL2 的渲染函数（`SDL_Render*`）不是线程安全的，只能在创建渲染器的线程调用
2. 事件队列是线程安全的，可以从任何线程推送事件
3. 窗口操作应在主线程进行
4. 共享数据必须用互斥锁保护

**生产者-消费者模式**：经典的多线程模式。生产者线程产生数据放入队列，消费者线程从队列取出处理。用互斥锁保护队列，条件变量通知消费者有新数据。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>

/* 共享数据结构 */
typedef struct {
    SDL_mutex* mutex;
    SDL_cond* cond;
    int queue[16];
    int queue_size;
    int queue_head;
    int queue_tail;
    SDL_bool running;
} SharedData;

/* 生产者线程函数 */
int ProducerThread(void* data) {
    SharedData* sd = (SharedData*)data;
    int item = 0;
    while (sd->running) {
        SDL_LockMutex(sd->mutex);
        /* 等待队列不满 */
        while (sd->queue_size >= 16 && sd->running) {
            SDL_CondWait(sd->cond, sd->mutex);
        }
        if (!sd->running) {
            SDL_UnlockMutex(sd->mutex);
            break;
        }
        /* 入队 */
        sd->queue[sd->queue_tail] = item++;
        sd->queue_tail = (sd->queue_tail + 1) % 16;
        sd->queue_size++;
        printf("生产: %d (队列大小 %d)\n", item - 1, sd->queue_size);
        SDL_CondSignal(sd->cond);  /* 通知消费者 */
        SDL_UnlockMutex(sd->mutex);
        SDL_Delay(100 + (item % 5) * 50);  /* 模拟生产耗时 */
    }
    return 0;
}

/* 消费者线程函数 */
int ConsumerThread(void* data) {
    SharedData* sd = (SharedData*)data;
    while (sd->running) {
        SDL_LockMutex(sd->mutex);
        /* 等待队列不空 */
        while (sd->queue_size <= 0 && sd->running) {
            SDL_CondWait(sd->cond, sd->mutex);
        }
        if (!sd->running && sd->queue_size <= 0) {
            SDL_UnlockMutex(sd->mutex);
            break;
        }
        /* 出队 */
        int item = sd->queue[sd->queue_head];
        sd->queue_head = (sd->queue_head + 1) % 16;
        sd->queue_size--;
        printf("  消费: %d (队列大小 %d)\n", item, sd->queue_size);
        SDL_CondSignal(sd->cond);  /* 通知生产者 */
        SDL_UnlockMutex(sd->mutex);
        SDL_Delay(150);  /* 模拟消费耗时 */
    }
    return 0;
}

/* 定时器回调 */
Uint32 TimerCallback(Uint32 interval, void* param) {
    /* 定时器在单独线程执行，通过事件通知主线程 */
    SDL_Event event;
    event.type = SDL_USEREVENT;
    event.user.code = 1;
    event.user.data1 = NULL;
    event.user.data2 = NULL;
    SDL_PushEvent(&event);
    return interval;  /* 返回下一次间隔 */
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO | SDL_INIT_TIMER);

    SDL_Window* window = SDL_CreateWindow(
        "多线程示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    /* 初始化共享数据 */
    SharedData sd = {0};
    sd.mutex = SDL_CreateMutex();
    sd.cond = SDL_CreateCond();
    sd.running = SDL_TRUE;

    /* 创建生产者和消费者线程 */
    SDL_Thread* producer = SDL_CreateThread(ProducerThread, "Producer", &sd);
    SDL_Thread* consumer = SDL_CreateThread(ConsumerThread, "Consumer", &sd);

    /* 添加定时器，每 2 秒触发一次 */
    SDL_TimerID timer = SDL_AddTimer(2000, TimerCallback, NULL);

    SDL_bool running = SDL_TRUE;
    int timer_count = 0;
    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
            if (event.type == SDL_USEREVENT) {
                timer_count++;
                printf(">>> 定时器触发 %d 次\n", timer_count);
                if (timer_count >= 5) {
                    printf("停止生产消费...\n");
                    SDL_LockMutex(sd.mutex);
                    sd.running = SDL_FALSE;
                    SDL_CondBroadcast(sd.cond);
                    SDL_UnlockMutex(sd.mutex);
                }
            }
        }

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);

        /* 显示队列大小（用矩形长度表示） */
        SDL_LockMutex(sd.mutex);
        SDL_SetRenderDrawColor(renderer, 100, 200, 255, 255);
        SDL_Rect bar = {100, 300, sd.queue_size * 30, 30};
        SDL_RenderFillRect(renderer, &bar);
        SDL_UnlockMutex(sd.mutex);

        SDL_RenderPresent(renderer);
        SDL_Delay(16);
    }

    /* 清理 */
    SDL_RemoveTimer(timer);
    SDL_WaitThread(producer, NULL);
    SDL_WaitThread(consumer, NULL);
    SDL_DestroyMutex(sd.mutex);
    SDL_DestroyCond(sd.cond);

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- SDL2 提供完整的线程 API：`SDL_CreateThread`、`SDL_WaitThread`、`SDL_DetachThread`
- 同步原语：互斥锁（Mutex）、信号量（Semaphore）、条件变量（Cond）
- 原子操作 `SDL_Atomic*` 用于无锁编程
- 定时器 `SDL_AddTimer` 在单独线程执行回调，通过事件与主线程通信
- **关键规则**：渲染函数和窗口操作只能在主线程调用；事件队列线程安全
- **常见坑**：条件变量必须用 while 循环检查条件（防止虚假唤醒）；定时器回调在单独线程，不能直接调用渲染函数；线程退出前必须 join 或 detach，否则资源泄漏

## 第21讲 文件 I/O 与 RWops

### 概念

SDL2 提供 `SDL_RWops` 抽象层，统一文件、内存、网络等数据源的读写操作。本讲讲解 RWops 的使用、文件 I/O、资源打包等。

### 原理

**SDL_RWops 设计**：`SDL_RWops` 是一个抽象接口，提供统一的 `read`、`write`、`seek`、`close` 操作。不同后端（文件、内存、自定义）实现这些操作，上层代码无需关心数据来源。

**RWops 类型**：
- 文件 RWops：`SDL_RWFromFile`，从磁盘文件读写
- 内存 RWops：`SDL_RWFromMem` / `SDL_RWFromConstMem`，从内存缓冲区读写
- 自定义 RWops：手动设置函数指针，实现自定义数据源（如压缩包、网络）

**与 SDL 函数集成**：许多 SDL 函数支持 RWops 输入：
- `SDL_LoadBMP_RW`、`IMG_Load_RW`、`TTF_OpenFontRW`、`Mix_LoadMUS_RW` 等
- 通常有 `freesrc` 参数：非 0 表示函数负责关闭 RWops，0 表示调用者负责

**资源打包**：游戏发布时通常将资源打包成单个文件（如 ZIP、PAK），避免大量小文件。使用 RWops 可以从打包文件中读取资源，无需解压到磁盘：
1. 打开打包文件
2. 根据索引找到资源在文件中的偏移和大小
3. 用自定义 RWops 包装该区域
4. 传给 `IMG_Load_RW` 等函数

**路径处理**：
- `SDL_GetBasePath`：获取可执行文件所在目录（只读资源路径）
- `SDL_GetPrefPath`：获取用户配置/存档目录（可写路径）
- 这两个函数抽象了不同平台的路径差异

**异步 I/O**：SDL2 本身不提供异步文件 I/O，但可以结合线程实现。在后台线程读取文件，读取完成后通过事件通知主线程。

### 例子

```c
#include <SDL2/SDL.h>
#include <SDL2/SDL_image.h>
#include <stdio.h>
#include <string.h>

/* 自定义 RWops：从内存缓冲区读取 */
typedef struct {
    const Uint8* data;
    Sint64 size;
    Sint64 pos;
} MemContext;

Sint64 MemRWSize(SDL_RWops* ctx) {
    MemContext* mc = (MemContext*)ctx->hidden.unknown.data1;
    return mc->size;
}

Sint64 MemRWSeek(SDL_RWops* ctx, Sint64 offset, int whence) {
    MemContext* mc = (MemContext*)ctx->hidden.unknown.data1;
    Sint64 new_pos = mc->pos;
    switch (whence) {
    case RW_SEEK_SET: new_pos = offset; break;
    case RW_SEEK_CUR: new_pos = mc->pos + offset; break;
    case RW_SEEK_END: new_pos = mc->size + offset; break;
    }
    if (new_pos < 0) new_pos = 0;
    if (new_pos > mc->size) new_pos = mc->size;
    mc->pos = new_pos;
    return new_pos;
}

size_t MemRWRead(SDL_RWops* ctx, void* ptr, size_t size, size_t maxnum) {
    MemContext* mc = (MemContext*)ctx->hidden.unknown.data1;
    size_t total = size * maxnum;
    if (mc->pos + total > mc->size) {
        total = mc->size - mc->pos;
        maxnum = total / size;
    }
    if (total > 0) {
        memcpy(ptr, mc->data + mc->pos, total);
        mc->pos += total;
    }
    return maxnum;
}

int MemRWClose(SDL_RWops* ctx) {
    if (ctx->hidden.unknown.data1) {
        SDL_free(ctx->hidden.unknown.data1);
    }
    SDL_FreeRW(ctx);
    return 0;
}

SDL_RWops* CreateMemRWops(const Uint8* data, Sint64 size) {
    SDL_RWops* ctx = SDL_CreateRW();
    if (!ctx) return NULL;
    MemContext* mc = (MemContext*)SDL_malloc(sizeof(MemContext));
    mc->data = data;
    mc->size = size;
    mc->pos = 0;
    ctx->hidden.unknown.data1 = mc;
    ctx->size = MemRWSize;
    ctx->seek = MemRWSeek;
    ctx->read = MemRWRead;
    ctx->write = NULL;  /* 只读 */
    ctx->close = MemRWClose;
    return ctx;
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    IMG_Init(IMG_INIT_PNG);

    SDL_Window* window = SDL_CreateWindow(
        "RWops 示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1, 0);

    /* 1. 获取路径 */
    char* base_path = SDL_GetBasePath();
    char* pref_path = SDL_GetPrefPath("MyCompany", "MyGame");
    printf("Base path: %s\n", base_path ? base_path : "NULL");
    printf("Pref path: %s\n", pref_path ? pref_path : "NULL");

    /* 2. 文件 RWops 示例 */
    SDL_RWops* file = SDL_RWFromFile("test.txt", "wb");
    if (file) {
        const char* text = "Hello, SDL_RWops!";
        SDL_RWwrite(file, text, 1, strlen(text));
        SDL_RWclose(file);
        printf("已写入 test.txt\n");

        /* 读取回来 */
        file = SDL_RWFromFile("test.txt", "rb");
        if (file) {
            char buf[64] = {0};
            SDL_RWread(file, buf, 1, 63);
            printf("读取内容: %s\n", buf);
            SDL_RWclose(file);
        }
    }

    /* 3. 内存 RWops 示例 */
    const char* mem_data = "内存中的数据";
    SDL_RWops* mem_rw = SDL_RWFromConstMem(mem_data, strlen(mem_data));
    if (mem_rw) {
        char buf[64] = {0};
        SDL_RWread(mem_rw, buf, 1, 63);
        printf("从内存读取: %s\n", buf);
        SDL_RWclose(mem_rw);
    }

    /* 4. 自定义 RWops 示例 */
    Uint8 custom_data[] = {0x89, 'P', 'N', 'G', 0x0D, 0x0A};  /* PNG 头 */
    SDL_RWops* custom_rw = CreateMemRWops(custom_data, sizeof(custom_data));
    if (custom_rw) {
        printf("自定义 RWops 大小: %lld\n", (long long)SDL_RWsize(custom_rw));
        SDL_RWclose(custom_rw);
    }

    /* 5. 使用 RWops 加载图像 */
    /* SDL_RWops* img_rw = SDL_RWFromFile("sprite.png", "rb"); */
    /* SDL_Texture* tex = IMG_LoadTexture_RW(renderer, img_rw, 1); */

    if (base_path) SDL_free(base_path);
    if (pref_path) SDL_free(pref_path);

    /* 渲染循环 */
    SDL_bool running = SDL_TRUE;
    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
        }
        SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
        SDL_RenderClear(renderer);
        SDL_RenderPresent(renderer);
    }

    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    IMG_Quit();
    SDL_Quit();
    return 0;
}
```

### 总结

- `SDL_RWops` 是统一的 I/O 抽象层，支持文件、内存、自定义数据源
- `SDL_RWFromFile`、`SDL_RWFromMem` 创建标准 RWops
- SDL_image、SDL_ttf、SDL_mixer 都支持 RWops 输入（`*_RW` 函数）
- `SDL_GetBasePath` 获取只读资源路径，`SDL_GetPrefPath` 获取可写配置路径
- 资源打包通过自定义 RWops 实现，无需解压到磁盘
- **常见坑**：`freesrc` 参数为 1 时函数会关闭 RWops，为 0 时需手动关闭，避免重复关闭或泄漏；`SDL_RWclose` 既关闭又释放 RWops 对象；自定义 RWops 必须实现所有需要的函数指针

## 第22讲 离屏渲染与目标纹理

### 概念

离屏渲染（Off-screen Rendering）是将内容渲染到纹理而非屏幕的技术。本讲讲解目标纹理（Target Texture）的使用，以及它在光照效果、小地图、屏幕后处理等场景的应用。

### 原理

**目标纹理原理**：创建纹理时指定 `SDL_TEXTUREACCESS_TARGET` 访问模式，该纹理可以作为渲染目标。通过 `SDL_SetRenderTarget(renderer, texture)` 将渲染目标从默认的后缓冲切换到纹理，之后的所有绘制命令都绘制到纹理上。`SDL_SetRenderTarget(renderer, NULL)` 切换回屏幕。

**离屏渲染的应用**：
1. **光照效果**：将所有光源绘制到一张纹理，再与场景混合
2. **小地图**：将场景缩放渲染到小纹理，再绘制到屏幕角落
3. **屏幕后处理**：将整个场景渲染到纹理，再应用模糊、色彩调整等效果
4. **缓存复杂场景**：静态背景渲染一次到纹理，后续直接绘制纹理
5. **镜面/反射**：从特定视角渲染场景到纹理，作为镜面贴图

**纹理尺寸限制**：GPU 对纹理尺寸有限制（通常 4096x4096 或 8192x8192）。`SDL_GetRendererInfo` 可查询最大纹理尺寸。超出限制会创建失败。

**混合模式与目标纹理**：渲染到纹理时，混合模式同样适用。注意纹理的初始状态：新创建的纹理内容未定义，必须先 `SDL_RenderClear` 清空。

**性能考虑**：
1. 切换渲染目标有开销，应批量处理
2. 目标纹理的格式应与渲染器输出格式匹配，避免转换
3. 频繁更新的目标纹理使用 `SDL_TEXTUREACCESS_TARGET` 而非 `STREAMING`

**视口与裁剪**：渲染到纹理时可以设置视口（`SDL_RenderSetViewport`）和裁剪矩形（`SDL_RenderSetClipRect`），实现局部渲染。

### 例子

```c
#include <SDL2/SDL.h>
#include <stdio.h>

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);

    SDL_Window* window = SDL_CreateWindow(
        "离屏渲染示例", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        800, 600, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED | SDL_RENDERER_TARGETTEXTURE);

    /* 查询最大纹理尺寸 */
    SDL_RendererInfo info;
    SDL_GetRendererInfo(renderer, &info);
    printf("渲染器: %s, 最大纹理: %dx%d\n",
           info.name, info.max_texture_width, info.max_texture_height);

    /* 创建目标纹理（小地图） */
    SDL_Texture* minimap = SDL_CreateTexture(renderer,
        SDL_PIXELFORMAT_RGBA8888, SDL_TEXTUREACCESS_TARGET, 200, 150);
    SDL_SetTextureBlendMode(minimap, SDL_BLENDMODE_BLEND);

    /* 创建目标纹理（光照层） */
    SDL_Texture* lightmap = SDL_CreateTexture(renderer,
        SDL_PIXELFORMAT_RGBA8888, SDL_TEXTUREACCESS_TARGET, 800, 600);
    SDL_SetTextureBlendMode(lightmap, SDL_BLENDMODE_MOD);

    /* 创建目标纹理（场景缓存） */
    SDL_Texture* scene = SDL_CreateTexture(renderer,
        SDL_PIXELFORMAT_RGBA8888, SDL_TEXTUREACCESS_TARGET, 800, 600);

    float time = 0.0f;
    SDL_bool running = SDL_TRUE;

    while (running) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
        }
        time += 0.016f;

        /* === 第1步：渲染场景到 scene 纹理 === */
        SDL_SetRenderTarget(renderer, scene);
        SDL_SetRenderDrawColor(renderer, 20, 30, 50, 255);
        SDL_RenderClear(renderer);

        /* 绘制一些"游戏对象" */
        for (int i = 0; i < 5; i++) {
            int x = (int)(100 + i * 130 + sin(time + i) * 30);
            int y = (int)(200 + cos(time * 0.7f + i) * 50);
            SDL_SetRenderDrawColor(renderer,
                100 + i * 30, 200 - i * 20, 150, 255);
            SDL_Rect obj = {x, y, 40, 40};
            SDL_RenderFillRect(renderer, &obj);
        }

        /* === 第2步：渲染光照到 lightmap 纹理 === */
        SDL_SetRenderTarget(renderer, lightmap);
        SDL_SetRenderDrawColor(renderer, 60, 60, 80, 255);  /* 环境光 */
        SDL_RenderClear(renderer);

        /* 绘制光源（亮色圆形） */
        SDL_SetRenderDrawColor(renderer, 255, 240, 200, 255);
        int light_x = (int)(400 + sin(time) * 200);
        int light_y = (int)(300 + cos(time * 0.5f) * 100);
        for (int r = 100; r > 0; r -= 5) {
            Uint8 alpha = (Uint8)(255 * (1.0f - r / 100.0f) * 0.3f);
            SDL_SetRenderDrawColor(renderer, 255, 240, 200, alpha);
            for (int a = 0; a < 360; a += 10) {
                float rad = a * 3.14159f / 180.0f;
                SDL_RenderDrawPoint(renderer,
                    light_x + (int)(cos(rad) * r),
                    light_y + (int)(sin(rad) * r));
            }
        }

        /* === 第3步：渲染小地图到 minimap 纹理 === */
        SDL_SetRenderTarget(renderer, minimap);
        SDL_SetRenderDrawColor(renderer, 0, 0, 0, 200);
        SDL_RenderClear(renderer);
        /* 将场景缩放绘制到小地图 */
        SDL_Rect minimap_dest = {0, 0, 200, 150};
        SDL_RenderCopy(renderer, scene, NULL, &minimap_dest);
        /* 在小地图上标记光源位置 */
        SDL_SetRenderDrawColor(renderer, 255, 255, 0, 255);
        int mm_light_x = light_x * 200 / 800;
        int mm_light_y = light_y * 150 / 600;
        SDL_Rect mm_light = {mm_light_x - 2, mm_light_y - 2, 4, 4};
        SDL_RenderFillRect(renderer, &mm_light);

        /* === 第4步：合成到屏幕 === */
        SDL_SetRenderTarget(renderer, NULL);  /* 切换回屏幕 */
        SDL_SetRenderDrawColor(renderer, 0, 0, 0, 255);
        SDL_RenderClear(renderer);

        /* 绘制场景 */
        SDL_RenderCopy(renderer, scene, NULL, NULL);
        /* 叠加光照层（MOD 混合） */
        SDL_RenderCopy(renderer, lightmap, NULL, NULL);
        /* 绘制小地图（右上角） */
        SDL_Rect minimap_pos = {800 - 210, 10, 200, 150};
        SDL_SetRenderDrawColor(renderer, 255, 255, 255, 255);
        SDL_RenderDrawRect(renderer, &minimap_pos);
        minimap_pos.x++; minimap_pos.y++;
        minimap_pos.w -= 2; minimap_pos.h -= 2;
        SDL_RenderCopy(renderer, minimap, NULL, &minimap_pos);

        SDL_RenderPresent(renderer);
        SDL_Delay(16);
    }

    SDL_DestroyTexture(scene);
    SDL_DestroyTexture(lightmap);
    SDL_DestroyTexture(minimap);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 目标纹理通过 `SDL_TEXTUREACCESS_TARGET` 创建，`SDL_SetRenderTarget` 切换渲染目标
- 离屏渲染应用：光照、小地图、后处理、场景缓存、镜面反射
- 创建渲染器时需指定 `SDL_RENDERER_TARGETTEXTURE` 标志
- 目标纹理必须先 `RenderClear` 清空，初始内容未定义
- 切换渲染目标有开销，应批量处理
- **常见坑**：忘记 `SDL_SetRenderTarget(renderer, NULL)` 切换回屏幕，导致画面不更新；目标纹理的混合模式需正确设置；纹理尺寸不能超过 GPU 限制

## 第23讲 实战：贪吃蛇游戏

### 概念

本讲通过实现一个完整的贪吃蛇游戏，综合运用窗口、渲染、事件、输入、文字渲染等知识。游戏包含网格地图、蛇的移动与生长、食物生成、碰撞检测、计分系统等完整功能。

### 原理

**游戏架构**：贪吃蛇游戏采用经典的"模型-视图-控制器"（MVC）架构：
- **模型（Model）**：游戏状态数据（蛇的位置、方向、食物位置、分数）
- **视图（View）**：渲染逻辑，将模型绘制到屏幕
- **控制器（Controller）**：处理输入，更新模型

**网格系统**：游戏地图划分为网格（如 30x20），每个网格单元固定大小（如 20x20 像素）。蛇和食物的位置以网格坐标存储，渲染时转换为像素坐标。网格系统简化了碰撞检测和移动逻辑。

**蛇的数据结构**：蛇身由一系列网格坐标组成，使用数组存储。蛇头是数组的第一个元素，蛇尾是最后一个。移动时：
1. 根据方向计算新的蛇头位置
2. 将新头部插入数组开头
3. 如果吃到食物，不删除尾部（蛇变长）
4. 如果没吃到食物，删除尾部（蛇长度不变）

**碰撞检测**：
1. 蛇头与边界碰撞：游戏结束
2. 蛇头与自身碰撞：游戏结束
3. 蛇头与食物碰撞：吃到食物，生成分数，生成新食物

**移动节奏**：贪吃蛇是回合制游戏，蛇每隔固定时间（如 150ms）移动一格。使用累积器实现：每帧增加 delta 时间，达到移动间隔时执行一次移动。

**方向控制**：玩家按键改变蛇的移动方向，但不能直接反向（如向右移动时不能直接向左）。需要存储当前方向和下一个方向，移动时才应用下一个方向。

### 例子

```c
#include <SDL2/SDL.h>
#include <SDL2/SDL_ttf.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

/* 游戏配置 */
#define GRID_SIZE 20
#define GRID_COLS 30
#define GRID_ROWS 20
#define WINDOW_WIDTH (GRID_COLS * GRID_SIZE)
#define WINDOW_HEIGHT (GRID_ROWS * GRID_SIZE)
#define MOVE_INTERVAL 150  /* 蛇移动间隔（毫秒） */

/* 方向枚举 */
typedef enum {
    DIR_UP, DIR_DOWN, DIR_LEFT, DIR_RIGHT
} Direction;

/* 蛇身节点 */
typedef struct {
    int x, y;
} SnakeSegment;

/* 游戏状态 */
typedef struct {
    SnakeSegment snake[GRID_COLS * GRID_ROWS];
    int snake_length;
    Direction direction;
    Direction next_direction;
    SnakeSegment food;
    int score;
    int game_over;
    Uint32 move_timer;
} GameState;

/* 初始化游戏 */
void Game_Init(GameState* game) {
    /* 蛇初始位置在中间，长度 3，向右移动 */
    game->snake_length = 3;
    game->snake[0].x = 10; game->snake[0].y = 10;  /* 头 */
    game->snake[1].x = 9;  game->snake[1].y = 10;
    game->snake[2].x = 8;  game->snake[2].y = 10;
    game->direction = DIR_RIGHT;
    game->next_direction = DIR_RIGHT;
    game->score = 0;
    game->game_over = 0;
    game->move_timer = 0;

    /* 随机生成食物 */
    srand((unsigned)time(NULL));
    game->food.x = rand() % GRID_COLS;
    game->food.y = rand() % GRID_ROWS;
}

/* 生成新食物（不与蛇身重叠） */
void Game_SpawnFood(GameState* game) {
    int valid = 0;
    while (!valid) {
        game->food.x = rand() % GRID_COLS;
        game->food.y = rand() % GRID_ROWS;
        valid = 1;
        for (int i = 0; i < game->snake_length; i++) {
            if (game->snake[i].x == game->food.x &&
                game->snake[i].y == game->food.y) {
                valid = 0;
                break;
            }
        }
    }
}

/* 更新游戏逻辑 */
void Game_Update(GameState* game, Uint32 delta) {
    if (game->game_over) return;

    game->move_timer += delta;
    if (game->move_timer < MOVE_INTERVAL) return;
    game->move_timer = 0;

    /* 应用下一个方向 */
    game->direction = game->next_direction;

    /* 计算新蛇头位置 */
    SnakeSegment new_head = game->snake[0];
    switch (game->direction) {
    case DIR_UP:    new_head.y--; break;
    case DIR_DOWN:  new_head.y++; break;
    case DIR_LEFT:  new_head.x--; break;
    case DIR_RIGHT: new_head.x++; break;
    }

    /* 碰撞检测：边界 */
    if (new_head.x < 0 || new_head.x >= GRID_COLS ||
        new_head.y < 0 || new_head.y >= GRID_ROWS) {
        game->game_over = 1;
        return;
    }

    /* 碰撞检测：自身（不包括尾部，因为尾部会移动） */
    for (int i = 0; i < game->snake_length - 1; i++) {
        if (game->snake[i].x == new_head.x &&
            game->snake[i].y == new_head.y) {
            game->game_over = 1;
            return;
        }
    }

    /* 检查是否吃到食物 */
    int ate_food = (new_head.x == game->food.x &&
                    new_head.y == game->food.y);

    /* 移动蛇：将所有节点后移一位 */
    for (int i = game->snake_length - 1; i > 0; i--) {
        game->snake[i] = game->snake[i - 1];
    }
    game->snake[0] = new_head;

    /* 如果吃到食物，增加长度并生成新食物 */
    if (ate_food) {
        game->snake_length++;
        game->score += 10;
        Game_SpawnFood(game);
    }
}

/* 处理输入 */
void Game_HandleInput(GameState* game, SDL_Scancode scancode) {
    Direction new_dir = game->direction;
    switch (scancode) {
    case SDL_SCANCODE_UP:    new_dir = DIR_UP; break;
    case SDL_SCANCODE_DOWN:  new_dir = DIR_DOWN; break;
    case SDL_SCANCODE_LEFT:  new_dir = DIR_LEFT; break;
    case SDL_SCANCODE_RIGHT: new_dir = DIR_RIGHT; break;
    default: return;
    }

    /* 不能直接反向 */
    if ((game->direction == DIR_UP && new_dir == DIR_DOWN) ||
        (game->direction == DIR_DOWN && new_dir == DIR_UP) ||
        (game->direction == DIR_LEFT && new_dir == DIR_RIGHT) ||
        (game->direction == DIR_RIGHT && new_dir == DIR_LEFT)) {
        return;
    }
    game->next_direction = new_dir;
}

/* 渲染游戏 */
void Game_Render(GameState* game, SDL_Renderer* renderer,
                 TTF_Font* font) {
    /* 清屏 */
    SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
    SDL_RenderClear(renderer);

    /* 绘制网格线（可选） */
    SDL_SetRenderDrawColor(renderer, 30, 30, 40, 255);
    for (int x = 0; x <= GRID_COLS; x++) {
        SDL_RenderDrawLine(renderer, x * GRID_SIZE, 0,
                          x * GRID_SIZE, WINDOW_HEIGHT);
    }
    for (int y = 0; y <= GRID_ROWS; y++) {
        SDL_RenderDrawLine(renderer, 0, y * GRID_SIZE,
                          WINDOW_WIDTH, y * GRID_SIZE);
    }

    /* 绘制食物（红色） */
    SDL_SetRenderDrawColor(renderer, 255, 80, 80, 255);
    SDL_Rect food_rect = {
        game->food.x * GRID_SIZE + 2,
        game->food.y * GRID_SIZE + 2,
        GRID_SIZE - 4, GRID_SIZE - 4
    };
    SDL_RenderFillRect(renderer, &food_rect);

    /* 绘制蛇（头部亮色，身体暗色） */
    for (int i = 0; i < game->snake_length; i++) {
        if (i == 0) {
            SDL_SetRenderDrawColor(renderer, 100, 255, 100, 255);  /* 头部 */
        } else {
            SDL_SetRenderDrawColor(renderer, 60, 180, 60, 255);   /* 身体 */
        }
        SDL_Rect seg = {
            game->snake[i].x * GRID_SIZE + 1,
            game->snake[i].y * GRID_SIZE + 1,
            GRID_SIZE - 2, GRID_SIZE - 2
        };
        SDL_RenderFillRect(renderer, &seg);
    }

    /* 绘制分数 */
    if (font) {
        char score_str[32];
        sprintf(score_str, "Score: %d", game->score);
        SDL_Color white = {255, 255, 255, 255};
        SDL_Surface* surface = TTF_RenderText_Blended(font, score_str, white);
        if (surface) {
            SDL_Texture* tex = SDL_CreateTextureFromSurface(renderer, surface);
            SDL_Rect dest = {10, 5, surface->w, surface->h};
            SDL_RenderCopy(renderer, tex, NULL, &dest);
            SDL_DestroyTexture(tex);
            SDL_FreeSurface(surface);
        }
    }

    /* 游戏结束提示 */
    if (game->game_over && font) {
        const char* msg = "Game Over! Press R to Restart";
        SDL_Color yellow = {255, 255, 100, 255};
        SDL_Surface* surface = TTF_RenderText_Blended(font, msg, yellow);
        if (surface) {
            SDL_Texture* tex = SDL_CreateTextureFromSurface(renderer, surface);
            SDL_Rect dest = {
                WINDOW_WIDTH / 2 - surface->w / 2,
                WINDOW_HEIGHT / 2 - surface->h / 2,
                surface->w, surface->h
            };
            SDL_RenderCopy(renderer, tex, NULL, &dest);
            SDL_DestroyTexture(tex);
            SDL_FreeSurface(surface);
        }
    }

    SDL_RenderPresent(renderer);
}

int main(int argc, char* argv[]) {
    SDL_Init(SDL_INIT_VIDEO);
    TTF_Init();

    SDL_Window* window = SDL_CreateWindow(
        "贪吃蛇", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED,
        WINDOW_WIDTH, WINDOW_HEIGHT, SDL_WINDOW_SHOWN
    );
    SDL_Renderer* renderer = SDL_CreateRenderer(window, -1,
        SDL_RENDERER_ACCELERATED | SDL_RENDERER_PRESENTVSYNC);

    TTF_Font* font = TTF_OpenFont(
        "/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf", 20);
    if (!font) {
        font = TTF_OpenFont("arial.ttf", 20);
    }

    GameState game;
    Game_Init(&game);

    SDL_bool running = SDL_TRUE;
    Uint32 last_time = SDL_GetTicks();

    while (running) {
        Uint32 current_time = SDL_GetTicks();
        Uint32 delta = current_time - last_time;
        last_time = current_time;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN) {
                if (event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                    running = SDL_FALSE;
                if (event.key.keysym.scancode == SDL_SCANCODE_R)
                    Game_Init(&game);  /* 重新开始 */
                if (!game.game_over) {
                    Game_HandleInput(&game, event.key.keysym.scancode);
                }
            }
        }

        Game_Update(&game, delta);
        Game_Render(&game, renderer, font);
    }

    if (font) TTF_CloseFont(font);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    TTF_Quit();
    SDL_Quit();
    return 0;
}
```

## 第24讲 性能优化与跨平台部署

### 概念

本讲讲解 SDL2 程序的性能优化技巧和跨平台部署方法。性能优化包括渲染优化、内存优化、算法优化；跨平台部署包括 Windows、Linux、macOS、移动平台的构建和打包。

### 原理

**渲染性能优化**：

1. **纹理批处理**：SDL2 的渲染器内部会批处理绘制命令，但频繁切换纹理会打断批处理。将同一纹理的所有绘制集中处理，减少状态切换。SDL2.0.10+ 的 `SDL_RenderCopy` 已自动批处理。

2. **纹理图集**：将多个小纹理合并为一张大纹理，绘制时通过源矩形切分。避免频繁切换纹理绑定。

3. **避免每帧创建/销毁纹理**：纹理创建涉及 GPU 内存分配和上传，开销大。应在初始化时创建，程序结束时销毁。

4. **合理使用 VSync**：开启 VSync 自动限制帧率，避免不必要的渲染。但 VSync 会引入一帧延迟，对输入延迟敏感的游戏（如格斗游戏）可能需要关闭。

5. **降低渲染分辨率**：对于像素风格游戏，可以以低分辨率渲染再放大，减少填充率压力。

**内存优化**：

1. **资源按需加载**：关卡资源在进入关卡时加载，退出时卸载。避免一次性加载所有资源。

2. **纹理压缩**：使用 GPU 支持的压缩纹理格式（如 DXT、ETC、PVRTC），减少显存占用和上传带宽。SDL2 通过 `SDL_PIXELFORMAT_*` 支持部分压缩格式。

3. **对象池**：频繁创建销毁的对象（如子弹、粒子）使用对象池复用，避免内存碎片和分配开销。

4. **资源引用计数**：多个对象共享同一资源时，用引用计数管理，最后一个释放时才真正销毁。

**算法优化**：

1. **空间分区**：碰撞检测使用四叉树、网格等空间分区结构，避免 O(n²) 的两两检测。

2. **脏矩形渲染**：只重绘变化的区域，适合 UI 等静态场景较多的应用。

3. **LOD（Level of Detail）**：远处对象使用简化模型，近处使用精细模型。

**跨平台部署**：

1. **路径处理**：使用 `SDL_GetBasePath` 和 `SDL_GetPrefPath` 获取平台正确的路径，避免硬编码。

2. **条件编译**：使用 `#ifdef` 处理平台差异：
   ```c
   #ifdef __ANDROID__
       /* Android 特定代码 */
   #elif defined(__APPLE__) && defined(__MACH__)
       /* macOS/iOS 特定代码 */
   #elif defined(_WIN32)
       /* Windows 特定代码 */
   #elif defined(__linux__)
       /* Linux 特定代码 */
   #endif
   ```

3. **构建系统**：推荐使用 CMake 跨平台构建：
   ```cmake
   cmake_minimum_required(VERSION 3.10)
   project(MySDL2App)
   find_package(SDL2 REQUIRED)
   find_package(SDL2_image REQUIRED)
   add_executable(MySDL2App main.c)
   target_link_libraries(MySDL2App SDL2::SDL2 SDL2::SDL2main SDL2_image)
   ```

4. **移动平台适配**：
   - Android：通过 NDK 交叉编译，SDL2 提供 Android 项目模板
   - iOS：使用 Xcode 项目，SDL2 提供 iOS 项目模板
   - 触摸输入替代鼠标
   - 处理应用生命周期（暂停、恢复）

5. **打包发布**：
   - Windows：将 SDL2.dll 等依赖 DLL 与 exe 放在同一目录
   - Linux：使用 AppImage 或 Flatpak 打包，避免依赖问题
   - macOS：创建 .app 包，包含 Frameworks 目录

```c
/* 性能监控结构 */
typedef struct {
    Uint32 frame_count;
    Uint32 fps_timer;
    int current_fps;
    float frame_time_avg;
    Uint32 last_frame_time;
} PerfMonitor;

void Perf_Init(PerfMonitor* pm) {
    pm->frame_count = 0;
    pm->fps_timer = SDL_GetTicks();
    pm->current_fps = 0;
    pm->frame_time_avg = 0;
    pm->last_frame_time = SDL_GetTicks();
}

void Perf_Update(PerfMonitor* pm) {
    Uint32 now = SDL_GetTicks();
    Uint32 frame_time = now - pm->last_frame_time;
    pm->last_frame_time = now;

    /* 指数移动平均 */
    pm->frame_time_avg = pm->frame_time_avg * 0.9f + frame_time * 0.1f;

    pm->frame_count++;
    if (now - pm->fps_timer >= 1000) {
        pm->current_fps = pm->frame_count * 1000 / (now - pm->fps_timer);
        pm->frame_count = 0;
        pm->fps_timer = now;
    }
}

/* 对象池示例：粒子系统 */
#define MAX_PARTICLES 1000

typedef struct {
    float x, y;
    float vx, vy;
    Uint8 r, g, b, a;
    float life;
    int active;
} Particle;

typedef struct {
    Particle particles[MAX_PARTICLES];
    int next_free;
} ParticlePool;

void Pool_Init(ParticlePool* pool) {
    for (int i = 0; i < MAX_PARTICLES; i++) {
        pool->particles[i].active = 0;
    }
    pool->next_free = 0;
}

Particle* Pool_Spawn(ParticlePool* pool) {
    /* 查找空闲粒子（简化版：线性扫描） */
    for (int i = 0; i < MAX_PARTICLES; i++) {
        int idx = (pool->next_free + i) % MAX_PARTICLES;
        if (!pool->particles[idx].active) {
            pool->next_free = (idx + 1) % MAX_PARTICLES;
            pool->particles[idx].active = 1;
            return &pool->particles[idx];
        }
    }
    return NULL;  /* 池满 */
}

void Pool_Update(ParticlePool* pool, float delta) {
    for (int i = 0; i < MAX_PARTICLES; i++) {
        if (pool->particles[i].active) {
            Particle* p = &pool->particles[i];
            p->x += p->vx * delta;
            p->y += p->vy * delta;
            p->vy += 200.0f * delta;  /* 重力 */
            p->life -= delta;
            if (p->life <= 0) {
                p->active = 0;
            }
        }
    }
}

void Pool_Render(ParticlePool* pool, SDL_Renderer* renderer) {
    /* 批量渲染：设置一次颜色，绘制所有粒子 */
    /* 实际项目中可用纹理图集进一步优化 */
    for (int i = 0; i < MAX_PARTICLES; i++) {
        if (pool->particles[i].active) {
            Particle* p = &pool->particles[i];
            Uint8 alpha = (Uint8)(p->a * (p->life > 1.0f ? 1.0f : p->life));
            SDL_SetRenderDrawColor(renderer, p->r, p->g, p->b, alpha);
            SDL_Rect rect = {(int)p->x - 2, (int)p->y - 2, 4, 4};
            SDL_RenderFillRect(renderer, &rect);
        }
    }
}

    SDL_GetRendererInfo(renderer, &info);
    printf("渲染器: %s\n", info.name);
    printf("最大纹理: %dx%d\n", info.max_texture_width, info.max_texture_height);
    printf("支持批处理: %s\n",
           (info.flags & SDL_RENDERER_TARGETTEXTURE) ? "是" : "否");

    Perf_Init(&perf);

    ParticlePool pool;
    Pool_Init(&pool);

    float spawn_timer = 0;
    Uint32 last_time = SDL_GetTicks();
    SDL_bool running = SDL_TRUE;

    while (running) {
        Uint32 now = SDL_GetTicks();
        float delta = (now - last_time) / 1000.0f;
        last_time = now;

        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            if (event.type == SDL_QUIT) running = SDL_FALSE;
            if (event.type == SDL_KEYDOWN &&
                event.key.keysym.scancode == SDL_SCANCODE_ESCAPE)
                running = SDL_FALSE;
            if (event.type == SDL_MOUSEBUTTONDOWN) {
                /* 鼠标点击爆发粒子 */
                for (int i = 0; i < 50; i++) {
                    Particle* p = Pool_Spawn(&pool);
                    if (p) {
                        p->x = (float)event.button.x;
                        p->y = (float)event.button.y;
                        float angle = (float)(rand() % 360) * 3.14159f / 180.0f;
                        float speed = 50 + rand() % 150;
                        p->vx = cosf(angle) * speed;
                        p->vy = sinf(angle) * speed - 100;
                        p->r = 200 + rand() % 55;
                        p->g = 100 + rand() % 155;
                        p->b = 50 + rand() % 100;
                        p->a = 255;
                        p->life = 1.0f + (rand() % 100) / 100.0f;
                    }
                }
            }
        }

        /* 持续生成粒子（演示性能） */
        spawn_timer += delta;
        if (spawn_timer > 0.05f) {
            spawn_timer = 0;
            Particle* p = Pool_Spawn(&pool);
            if (p) {
                p->x = 400 + (rand() % 200 - 100);
                p->y = 100;
                p->vx = (rand() % 100 - 50);
                p->vy = 50 + rand() % 100;
                p->r = 100 + rand() % 155;
                p->g = 100 + rand() % 155;
                p->b = 255;
                p->a = 255;
                p->life = 2.0f;
            }
        }

        Pool_Update(&pool, delta);
        Perf_Update(&perf);

        /* 渲染 */
        SDL_SetRenderDrawColor(renderer, 20, 20, 30, 255);
        SDL_RenderClear(renderer);

        Pool_Render(&pool, renderer);

        /* 显示性能信息（用颜色表示） */
        /* 绿色: 60FPS+, 黄色: 30-60FPS, 红色: <30FPS */
        SDL_SetRenderDrawColor(renderer,
            perf.current_fps >= 60 ? 100 : (perf.current_fps >= 30 ? 200 : 255),
            perf.current_fps >= 60 ? 255 : (perf.current_fps >= 30 ? 200 : 100),
            100, 255);
        SDL_Rect perf_bar = {10, 10, perf.current_fps * 5, 20};
        SDL_RenderFillRect(renderer, &perf_bar);

        SDL_RenderPresent(renderer);
    }

    if (base_path) SDL_free(base_path);
    if (pref_path) SDL_free(pref_path);
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

### 总结

- 渲染优化：纹理批处理、纹理图集、避免频繁创建纹理、合理使用 VSync
- 内存优化：资源按需加载、纹理压缩、对象池、引用计数
- 算法优化：空间分区、脏矩形渲染、LOD
- 跨平台部署：使用 `SDL_GetBasePath`/`SDL_GetPrefPath` 处理路径，条件编译处理平台差异
- 推荐使用 CMake 作为跨平台构建系统
- 移动平台需处理触摸输入和应用生命周期
- **常见坑**：性能优化应基于测量（profiling）而非猜测；过早优化是万恶之源，先保证正确再优化；不同平台的 GPU 性能差异大，需在目标平台测试；Windows 发布时必须包含 SDL2.dll 等依赖
