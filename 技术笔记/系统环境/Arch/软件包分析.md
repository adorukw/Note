## 一、其他桌面环境（DE）的一部分，被单独拆出来使用

这些软件最初都是某个桌面环境自带的组件，并非完全独立的项目。

| 软件包 | 来源 DE | 用途 | 说明 |
|--------|---------|------|------|
| `gnome-keyring` | **GNOME** | 密钥/密码存储 | 属于 GNOME 组，niri 等环境借用其实现 `org.freedesktop.secrets` |
| `gnome-power-manager` | **GNOME** | 电源管理 | GNOME 官方组件（基于 upower） |
| `gvfs` | **GNOME** | 虚拟文件系统 | GNOME 组，为 Thunar 等提供挂载/网络文件支持 |
| `file-roller` | **GNOME** | 压缩文件管理 | 属 `gnome-extra` 组，被 thunar-archive-plugin 调用 |
| `networkmanager` | **GNOME**（现独立） | 网络管理 | 起源于 GNOME，现为跨 DE 的标准网络服务 |
| `network-manager-applet` | **GNOME** | 网络托盘小程序 | GNOME 项目，供无原生客户端的 DE 使用 |
| `thunar` | **XFCE** | 文件管理器 | XFCE 核心组件 |
| `tumbler` | **XFCE** | 缩略图服务 | XFCE 组件，供 Thunar 使用 |
| `thunar-archive-plugin` | **XFCE** | 压缩集成插件 | XFCE 组件 |
| `thunar-volman` | **XFCE** | 可移动设备管理 | XFCE 组件 |
| `sddm` | **KDE / QML** | 登录管理器 | KDE 主导开发，但独立于 Plasma 桌面 |
| `pavucontrol` | **PulseAudio 生态** | 音量控制 GUI | PulseAudio 项目配套工具（类 GNOME 风格） |

> 小结：本机相当于把 GNOME / XFCE / KDE 里的"零件"拆出来拼进 niri。

## 五、结论

- 你的环境是 **niri + 大量"外借"DE 组件** 的组合：GNOME（密钥环、电源、gvfs、file-roller）、XFCE（Thunar 全家桶）、KDE（SDDM）。
- fcitx5 系列（输入法）和绝大多数应用（终端、浏览器、编辑器、播放器）都是**完全独立**的。
- 如果日后想减少"DE 碎片"，最容易被替换的是：`gnome-power-manager`（可用 niri 自带的电源方案）、`file-roller`（可换独立的 archive 前端）、`pavucontrol`（可换 niri 生态的 `nwg-panel` 音量插件或 `helpful` 等）。
